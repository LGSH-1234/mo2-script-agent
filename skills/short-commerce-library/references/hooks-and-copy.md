# 商品钩子与种草文案（适配指南）

适用：前三秒创意、5 秒片头、15/30 秒种草、达人口播、食品脚本、剧情带货、直播话术。时长按用户要求和实际模型能力，下面的秒数只是规划例子。

## 从商品长出钩子

先列真实用途、外形、材质、声音、可见动作、客群场景和证据，再选一种主要注意力机制：痛点、信息差、反差、感官满足、结果先行或人物冲突。

可选三条路线：

1. 商品原生视觉：撕开、扣合、倾倒、展开、旋转等产品自身动作制造变化；只展示真实能发生的效果。
2. 口播语义：一句短台词制造问题，画面在重音处回答；不要台词说清洁、画面只拍包装。
3. 通用结构与商品结合：用尺度、开合、遮挡或运动制造峰值，让商品成为动作原因或答案；去掉商品仍能成立时，绑定通常太弱。

单条钩子只保留一个主事件和一次高潮。只要 Hook 就结束在接入正文的动作，不把证明、价格和 CTA 全挤进去。用户只要一个方案时直接选适合的一条。

## 种草正文

卖点按「一个主卖点、少量辅助卖点、可验证依据」组织。每个卖点填写：功能事实 → 用户收益 → 使用场景 → 可视证据。没有证明的效果承诺删去或列为待核验，不能仅靠加“亲测”增强说服力。

示例结构：问题出现 → 商品如何参与 → 功能演示 → 证据/限制条件 → 下一步行动。价格、优惠、运费险、限时和库存仅采用用户已提供且仍适用的信息；没有促销资料就使用了解规格、查看款式等行动提示。

逐镜交付：

| 镜头/时段 | 画面与商品动作 | 口播 | 后期字幕/贴片 | 声音 | 证据/素材 |
|---|---|---|---|---|---|

静音检查：拿掉口播后仍能理解核心商品与利益点；贴片通过后期叠加，不让生成模型画中文。台词长度按实际语速与停顿验证，不为了塞卖点把口播压快。

剧情带货可用五个功能拍：进入情境、建立期待、形成阻碍、商品参与转折、结果回收。商品解决的问题应在前面出现；删掉商品仍可原样演下去的剧情需重写。这个方法不要求固定动画风格、人物或每拍恰好三秒。

直播话术只交文本与节奏，不能宣称已启动直播间或数字人推流。人物证言和使用经历不得编造。
