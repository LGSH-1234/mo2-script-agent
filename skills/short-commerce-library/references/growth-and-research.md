# 热点、竞品与素材复盘（适配指南）

先区分任务：需要新选题、已有素材转化差、要竞品比较，还是要经营指标复盘。先使用用户已有资料，避免把每个文案任务扩展成全网调研。

## 热点与竞品

记录检索时间、事件发生/发布时间、平台、地区、关键词和来源。热榜与视频搜索是不同数据：`douyin_hot_list` 查询热点线索，`douyin_search_videos` 查询相关公开视频；浏览器采集使用现有 RPA 工具及其授权机制。没有取到真实数据就不能称“今日热门”。

竞品拆解按人群、痛点、开头、卖点证据、视觉表达、CTA 和发布时间比较。标注哪些是公开事实，哪些是对素材的判断；不能把公开点赞当成销售额或投放 ROI，也不能照搬竞品价格、活动、评价或素材。

网页 SEO/GEO、站点抓取和排名诊断在当前项目没有专用自动化接口。可以依据用户提供的页面内容作表达评审；没有取到网页和搜索数据时不输出虚构抓取结果或“被 AI 引用率”。

## 对齐指标再解释

数据表至少注明时间窗、平台、渠道、素材版本、币种、曝光、点击、订单/转化及费用口径；缺失字段不能当 0。退款、归因窗口、含税/不含税、成交额与回款口径不一致时先列差异。

以下仅是字段已经对齐时可采用的计算定义，不代替平台口径：

- CTR = 点击 / 曝光。
- CVR = 转化 / 已声明的分母（如点击），必须写明分母。
- CPA = 花费 / 转化。
- ROAS = 归因收入 / 广告花费；不把它直接称作净利润 ROI。
- 分母为 0 或缺失时记不可计算；不得输出无穷、0 或估算值充当真实结果。

数值计算用当前可用计算工具或由用户给出的可核验报表；不擅自安装源脚本。现有 `record_metrics` / `list_metrics` / `review_performance` 可保存和复盘其 schema 支持的指标，额外电商字段保存为结构化草稿，不能硬塞到不匹配的参数。

## 诊断落到下一条素材

| 可见问题 | 需要核对 | 下一次可测试变化 |
|---|---|---|
| 开头流失 | 首段留存、画面理解难度、人群是否匹配 | 一个钩子或第一镜 |
| 有观看少点击 | 商品露出、利益点、行动提示 | 让一个核心收益可见 |
| 有点击少转化 | 页面承接、规格/价格、证据、库存 | 详情页疑虑与视频承诺对齐 |
| 素材疲劳 | 相同人群/时段下的版本趋势 | 保留商品事实，改变场景或开头 |

输出：事实与来源 → 待验证假设 → 1–3 个素材方向 → 每个方向改变的变量 → 复盘指标与时间窗。不保证流量、销量或收益，不代用户投放。
