## 1. 音频来源自动判定逻辑

音频来源为无感处理，无需用户选择：
- 用户已上传音频 -> 执行 BPM 判定、前奏落点定位与重拍节拍时码提取
- 用户未上传音频 -> 自动生成 18s TETO 专用电子 BGM
- 用户明确指定无音频输出 -> 跳过音频生成步骤，分镜 music 轨道留空，输出静音 MP4

## 2. 用户已上传音频的解析流程

通过对音频进行多维特征识别，输出以下结构化音频信号：
- 音频的 BPM（每分钟拍数）及节拍拍号（如 4/4 拍）
- 精确的前奏结束点时码（识别为第一个强节拍或音频能量突增点，限制在 2s-5s 之间，若未识别到则默认取 3s；93BPM Dark Trap 固定为 5s）
- 高潮/副歌段落的起始点与强音爆发点
- 提取高对比度底鼓（Kick）、踩镲（Hi-hat）及人声等特定音色或歌词在时间轴上的瞬态能量落点，输出完整的强瞬态鼓点与关键节拍时码轴
- 对于 93BPM Dark Trap（包含人声特定歌词 "I know my guy" 及 "I'm in cheetah"），额外输出对应的关键人声起始与结束时码

**数据输出与对齐**：仅输出客观时码轴数据，自身不包含任何剪辑变速、镜头切换或特效触发等执行规则，完全交由时间线拼装阶段读取并处理。

**时长处理**：
- 若时长 < 18s，尾部循环补齐（保持音高不变）
- 若 > 18s，从最强能量起点截取前 18s
- 若分析失败，回落至默认时轴（环绕 0-3s / 蒙太奇 3-18s，爆发点 11s / 13.5s / 16s）

## 3. BPM 分档规则与建立段时长

| BPM 档位 | 建立段时长 | 蒙太奇段时长 | 说明 |
|---|---|---|---|
| BPM > 120（高速电子/EDM） | 3s | 15s | 默认时轴 |
| BPM 80-120（标准节奏/R&B） | 3s | 15s | 默认时轴 |
| BPM < 80（慢节奏氛围/Lo-Fi） | 5s | 13s | 建立段延长至 5s |
| 93BPM Dark Trap 专属 | 5s | 13s | 前奏固定 5s |
| 未上传音频（默认 120 BPM） | 3s | 15s | 自动生成 BGM |

其他 BPM 档位的环绕段时长 = 前奏结束点（最短 2s、最大 5s，默认 3s），蒙太奇段 = 18s 减去环绕段时长。

## 4. 93BPM Dark Trap 专属规则

当音频识别为 93BPM Dark Trap 时，自动启用专属卡点预设：
- 前奏铺垫段固定为 5s
- 蒙太奇段固定 13s（与分镜设计模块 93BPM 专属时轴对齐）
- 1/3 拍底鼓落点处：瞬爆推拉至 140% + 0.1s 球面膨胀畸变触发
- 2/4 拍踩镲落点处：RGB 红蓝通道 1-2px 色散偏移
- "I know my guy" 人声段：降低切镜密度（单镜最长 2s）蓄势
- "I'm in cheetah" 人声段：强制全套高潮特效全开

## 5. 用户未上传音频的自动生成

自动生成 18s 暗黑重低音电子 BGM：
- 结构：0-3s 无重拍舒缓段 / 3-18s BPM=120 快节奏段
- 环绕段固定 3s，蒙太奇段固定 15s
- 风格标签：dark trap, heavy 808 bass, cinematic, cold atmosphere, 93 BPM
- 生成后注册为核心资产并绑定至分镜 music 轨道
- 无需用户干预，如用户后续不满意可申请重新生成（最多 3 次）

## 6. 音频特征分析输出规格

输出结构化时码轴数据，供时间线拼装阶段读取：

```
BPM: [数值]
拍号: [如 4/4]
前奏结束点: [时码，2-5s 范围]
高潮起始点: [时码]
强音爆发点: [时码列表]
底鼓落点轴: [时码列表]
踩镲落点轴: [时码列表]
人声关键时码（仅 93BPM Dark Trap）:
  - "I know my guy": [起始-结束]
  - "I'm in cheetah": [起始-结束]
```

## 7. 落稿前自检

- BPM 档位是否正确分档？
- 建立段与蒙太奇段时长是否匹配 BPM 档位？
- 93BPM Dark Trap 是否启用了专属卡点预设？
- 时长不足 18s 是否安排了尾部循环补齐？
- 时长超过 18s 是否从最强能量起点截取？
- 分析失败是否回落至默认时轴？
- 未上传音频时是否自动生成了 BGM？
