# 动感锚点视频

## 核心原则

不要只做匀速运镜的普通展示视频，而要以锚点为圆心、以节拍为切割刀，制造爆发加速度与视觉冲击。每一个镜头的运动起点都有爆发感，每一次硬切都踩在鼓点上，锚点核心区域始终清晰锐利。

持久引擎（因果链）：

**参考图主体识别 -> 像素级锚点定位 -> 音频节拍提取 -> BPM 分档分镜规划 -> 锚点锁焦视频生成 -> 鼓点卡点拼装 -> 特效链渲染 -> 超分增强 -> 18 秒完整成片**

### 质量测试（可证伪）

成片只有通过这条测试才算成立：**如果去掉锚点锁焦和鼓点卡点，视频就退化为一段无重点的匀速环绕素材。** 锚点让每一帧都有视觉重心，鼓点让每一次切换都有节奏依据，两者缺一不可。

## 输入诊断

生产前，识别或合理假设以下维度：

- 参考图主体类型（PRODUCT / ARCHITECTURE / LANDSCAPE / ANIMAL / HUMAN / VEHICLE）：通过主体分类自动识别
- 执行模式（TETO 动感模式 / 产品 TVC 模式）：仅 PRODUCT 类主体触发用户选择；非 PRODUCT 类直接沿用 TETO 动感模式
- 像素级锚点坐标 (x_anchor, y_anchor)：自动定位，用户可手动覆盖
- 音频来源：用户已上传音频 / 未上传需自动生成
- BPM 档位与节拍时码轴：从上传音频提取，或使用默认 120 BPM
- 特效强度档位（普通 / 高能 / 狂暴）：用户在分镜确认后选择，默认高能
- 画幅：自适应原图或默认 9:16 竖屏
- 时长：默认 18 秒（TVC 模式可由用户声明 15-30 秒覆盖）
- 背景质量：是否需要替换背景
- 视觉风格：TETO 默认为暗黑病态胶片质感、高对比冷青电影调色、重音炸裂卡点、高级故障风；TVC 默认为莫兰迪低饱和柔光、高级灰调色、平滑推拉微距展示
- 合规敏感点：确保不生成涉政、色情、暴力等违规内容

若用户给的上下文很少，做合理假设并继续。仅当主体类型、模式选择或锚点位置确实无法推断时才发问。

## 工作流（步骤）

### 步骤 0：锁定全局规格参数

创建 Final_Video_Spec.md 文件，写入初始规格：
- 时长：18 秒（TVC 模式启用时可由用户声明覆盖，最长 30 秒）
- 画幅：自适应原图或默认 9:16 竖屏
- 执行模式：待步骤 2.5 确认后写入
- 视觉风格与音频策略：随模式写入对应描述
- TETO 默认风格：暗黑病态胶片质感、高对比冷青电影调色、重音炸裂卡点、高级故障风
- TVC 模式默认风格：莫兰迪低饱和柔光、高级灰调色、平滑推拉微距展示
- TETO 模式禁用：匀速运镜、柔和叠化、过度磨皮
- TVC 模式禁用：硬切、强运动模糊、高对比彩色闪烁

### 步骤 1：参考图主体分析

对参考图执行主体类型识别，输出分类标签与机位适配信息：

- **PRODUCT**（产品静物：鞋服、水杯、数码、摆件等桌面单品）-> 平视微俯 45° 电商机位，禁用垂直俯拍与远距离大广角
- **ARCHITECTURE**（建筑场景：楼宇、古建筑、地标、室内结构）-> 低角度仰拍 + 平视纵深构图，少量中景平拍
- **LANDSCAPE**（风景外景：山水、城市全景、旷野、自然场景）-> 全程高空航拍视角，禁用近距离微距与低位怼脸镜头
- **ANIMAL**（动物宠物：猫、狗及各类萌宠）-> 贴地平视，与动物眼睛高度齐平，跟随式运镜
- **HUMAN**（人物人像：人物、人像、人体出镜）-> 标准人像构图，平视 + 微仰，聚焦五官体态，规避畸形透视
- **VEHICLE**（车辆交通：机车、跑车、汽车、摩托等）-> 低位贴地仰拍 + 侧平机位，凸显车身低趴线条张力

### 步骤 2：像素级锚点定位

锚点必须是图像上的一个具体像素坐标 (x_anchor, y_anchor)，按以下优先级自动选取：
1. 高对比边缘交点：车灯边缘尖角、车标尖端、产品 logo 角落、建筑棱线顶点
2. 高光点：金属反光中心、水珠高光、瞳孔高光点
3. 几何特征点：螺丝中心、轮毂中心、瞳孔中心、产品品牌图案几何中心
4. 主体视觉重心（前三者均无显著特征点时备用）：人物眉心、动物鼻尖、建筑主立面中心交点、风景地平线视觉焦点

**LANDSCAPE 航拍锚点专属分级回退策略**（大场景无明显物理锚点时）：
- 第一优先：标志性地物（孤立山峰顶端、灯塔尖顶、岛屿最高点、瀑布核心水柱入水点）
- 第二优先：光影汇聚点（日落/日出切点、水面最强反光中心、云隙透射光束地面落点）
- 第三优先：几何汇聚点（透视消失点、道路延伸灭点、梯田/等高线视觉汇聚点）
- 第四优先：色彩密度中心（色彩饱和度与明度对比最集中的 100x100px 区域几何中心）
- 最终回退：黄金分割交叉点（约 x x 38.2%，y x 38.2%），同时向用户说明图像缺乏显著锚点特征

**LANDSCAPE 锚点辅助规则**：
- 所有航拍运镜须保持锚点持续可见，360° 环绕段通过镜头旋转而非平移保持锚点居中
- 黄金分割回退锚点生效时，蒙太奇段极限俯冲次数限制为不超过 2 次

输出锚点像素坐标及选取依据说明。

**人机协同节点一**：展示锚点位置预览，请用户确认或手动点击任意点覆盖。确认后锚点固化，全程不再变更。

### 步骤 2.5：模式选择（仅 PRODUCT 类主体触发）

若识别结果为 PRODUCT，暂停并询问用户选择执行模式：
- **产品 TVC 模式**：高级感、舒缓节奏、莫兰迪调色、三段式分镜、叠化转场
- **TETO 动感模式（默认）**：高对比、爆发快剪、两段式分镜、硬切卡点

用户选定后写入 Final_Video_Spec.md。若用户同时声明自定义时长（15-30 秒），一并写入覆盖默认 18 秒。非 PRODUCT 类主体直接沿用 TETO 动感模式，跳过本步骤。

### 步骤 2.6：背景质量评估与场景替换（可选，按需触发）

对背景区域执行质量判定。满足以下任一条件即判定为"背景不佳"：
- 杂乱背景：存在明显杂物、无关文字、水印、密集线条或不相关物体
- 光线平淡：无明暗对比层次，整体曝光均匀平坦
- 色彩失调：色彩脏乱、偏色，或与主体色调冲突，难以支撑冷青电影调色
- 空间层次缺失：纯色墙壁、白纸、单色布幕等无景深/空间感环境
- 用户手动标记要求更换背景（优先级最高）

**LANDSCAPE 类主体强制跳过本评估，直接保留原图。**

**人机协同节点零**：若判定背景不佳，暂停并询问是否替换背景（替换 / 保留原背景）。
- 选择替换：按主体类型从场景预设池生成 3 个候选背景图（分辨率 2K，比例按画幅），展示供用户选择（含"AI 自动最优"选项）；选定后将主体与新背景合成，执行四项质检（边缘融合度、光影一致性、色调融合度、主体完整性），展示合成预览供用户确认；确认后以合成图替代原图注册为主体视觉根基
- 选择保留：跳过，使用原图继续

背景替换的完整场景预设池与合成质检标准见 `references/formats/background-replacement.md`。

### 步骤 3：音频来源自动判定（无感处理，无需用户选择）

**用户已上传音频**：
- 执行 BPM 判定、前奏落点定位与重拍节拍时码提取
- 若识别为 93BPM Dark Trap：自动启用专属卡点预设，前奏铺垫段固定 5s，蒙太奇段 13s
- 其他 BPM 档位：环绕段时长 = 前奏结束点（最短 2s、最大 5s，默认 3s），蒙太奇段 = 18s 减去环绕段时长
- 若时长 < 18s，尾部循环补齐（保持音高）；若 > 18s，从最强能量起点截取 18s
- 若分析失败，回落至默认时轴（环绕 0-3s / 蒙太奇 3-18s，爆发点 11s / 13.5s / 16s）

**用户未上传音频**：
- 自动生成 18s TETO 专用电子 BGM（结构：0-3s 无重拍舒缓段 / 3-18s BPM=120 快节奏段）
- 环绕段固定 3s，蒙太奇段固定 15s
- 无需用户干预，如用户后续不满意可申请重新生成（最多 3 次）

完整的 BPM 分档规则、节拍时码轴定义与音频生成参数见 `references/formats/audio-rhythm.md`。

### 步骤 4：构建结构化分镜

读取 `references/formats/shot-design-and-effects.md`，按识别出的主体类型匹配专属机位逻辑，规划两段式 18 秒分镜与 1 条 music 轨道。

**两段式分镜时间线（TETO 模式，全品类通用）**：
- 建立段（0-3s）：1-2 个镜头，缓慢水平顺时针 180° 环绕 + 匀速前推（速度约 6°/s），全景展示主体与环境；单镜 1.5-2s，无扭曲/白闪，仅微量 RGB 色偏（正负 0.5px）；镜头始终以锚点为中心
- 高速蒙太奇段（3-18s）：以锚点为圆心进行多角度高速运镜组合；必须覆盖至少 4 个主要方向（正面、侧面、背面、俯视或仰视），每个方向至少出现 2 次

BPM 分档的分镜数量与单镜时长分配、主体类型专属分镜倾向、TVC 模式专属分镜规则详见 `references/formats/shot-design-and-effects.md` 与 `references/formats/tvc-mode.md`。

设计独立音频轨道：规划 1 条 music 类型轨道，时长 18 秒，标注前奏落点、人声入场时间点（93BPM 专属：约 5s）与高潮三重爆发（11s / 13.5s / 16s）时间锚点。

**人机协同节点二**：分镜完成后暂停，展示规划简报（主体类型、锚点坐标、机位方案、节奏分配），请用户确认特效强度档位（普通 / 高能 / 狂暴）。选定后写入 Final_Video_Spec.md，后续生成与拼装全程按对应档位执行。

### 步骤 5：绑定资产与分镜生成

注册主图为核心视觉资产，后续所有视频生成均以此原图（或合成图）为视觉一致性根基，禁止重新随机生成主体外貌。

按分镜依次生成视频片段：
- 将主图作为参考图传入，锁定主体多角度一致性
- 若当前分镜与上一镜头存在极强空间连续性（尤其是环绕段），可将上一镜头的成片作为参考视频辅助推演多视角物理合理性
- 提示词全程融入像素级锚点锁焦、冷青胶片、暗部压黑等视觉约束

**Shot 级视频质检（四项标准）**：每个片段生成后依次评估；任一不达标则更换随机种子自动重试（最多 2 次）；2 次仍不达标时停止重试，向用户说明失败项，提供"调整提示词重新生成"或"跳过本镜使用备用静帧"两个选项。

| 质检项 | 判定标准 | 不达标特征 | 重试干预措施 |
|---|---|---|---|
| 锚点清晰度 | 锚点周围核心区域（画幅短边 10% 半径内）清晰锐利，全帧无整体虚焦 | 锚点区域虚焦、全帧模糊、核心主体细节丢失 | 强化提示词"anchor zone razor sharp, ultra detailed center subject" |
| 运动张力 | 每个蒙太奇镜头须有明确加速度曲线，起止有爆发感，非匀速平滑 | 全段匀速缓移、无推拉加速冲入感、运动幅度低于设计意图 | 提示词追加"explosive acceleration, sudden burst movement, violent camera impact, no smooth easing" |
| 方向与景别符合度 | 运动方向与景别须与分镜描述一致（偏离不超过 45°，景别不跨越两档） | 方向偏离、景别跨越 | 精简提示词，突出方向与景别关键词，去除歧义修饰语 |
| 主体完整性 | 主体在运动过程中无肢体缺失、结构变形、或被运动模糊完全覆盖；锚点物理特征点全程可辨认 | 主体中心区域失去识别度、AI 幻觉变形、锚点特征点消失 | 追加"preserve subject structure integrity, maintain anchor feature point visible throughout motion" |

重试时仅更换随机种子并按上表干预措施补充关键词，不得擅自降低分镜规划的运镜强度档位或缩短单镜时长。若用户选择"跳过本镜使用备用静帧"，以对应时间点的主体参考图作为静帧填充，叠加正常特效后拼入时间轴。

**画面风格约束**：所有提示词均须融入冷青调色、暗部压黑、7%-12% 胶片颗粒等视觉统一性约束，确保跨镜头风格一致。

提示词文法与完整模板见 `references/formats/video-prompt-grammar.md`。TVC 模式专属生成策略见 `references/formats/tvc-mode.md`。

### 步骤 6：时间轴拼装与特效渲染

读取 `references/formats/shot-design-and-effects.md` 中的特效三档参数表，按鼓点时码对齐拼装。

**拼装流程**：
1. 导入 18s 背景音乐文件作为音频主轨；按节拍时码轴对齐所有视频片段
2. 第一阶段建立段剪辑：裁切并导入建立段视频，1.0 倍速匀速播放，对齐前奏，首尾各 0.2s 淡入/淡出；仅叠加微量 RGB 色偏（正负 0.5px），无扭曲无白闪
3. 第二阶段高能蒙太奇快剪：按 BPM 分档剪辑模板依次提取对应视频片段，按节拍点执行硬切、跳剪或 3 帧以内极短叠化转场
4. 像素级锚点锁焦：相邻硬切时通过 X/Y 轴微调确保前后镜头锚点屏幕偏差 <= 2px；超出阈值自动重试生成（最多 2 次），仍失败则跳过并标记

**三大高潮节点强制执行**（参数按特效强度档位代入参数表，不得使用硬编码值覆盖非高能档）：
- 11s：极速俯冲怼脸（LANDSCAPE 用高空俯冲）+ 球面膨胀畸变 + 白闪爆闪
- 13.5s：360° 高速环绕 + 四角液化拉伸 + RGB 全开色散
- 16s：全景拉出 + 低频明暗频闪 + 全片最重暗角；18s 精准收镜闭环

**空间约束**：所有运镜、畸变、光效、闪频 100% 同步鼓点联动，零节奏脱节；主体自然贴合场景表面，无悬浮/穿模/错位；画面边缘保持极致锐利。

TVC 模式专属拼装规则见 `references/formats/tvc-mode.md`。

### 步骤 7：超分辨率增强（可选）

全片拼装、特效渲染、音画对齐完成后，可对最终成片整体执行一次超分增强。按主体类型与 BPM 档位选取参数：

| 主体类型 | 推荐分辨率 | 说明 |
|---|---|---|
| PRODUCT | 4k | 材质纹理、Logo 细节密集，高分辨率直接影响质感输出 |
| VEHICLE | 4k | 车身曲线、车灯轮廓锐利度要求高，4K 强化金属质感 |
| ARCHITECTURE | 4k | 建筑线条层次丰富，高分辨率保留结构纵深感 |
| LANDSCAPE | 4k | 全域大场景信息量大，4K 防止远景细节糊化 |
| ANIMAL | 1080p | 毛发纹理已由生成模型处理，1080p 足够；4K 可选 |
| HUMAN | 1080p | 防止过度锐化导致皮肤质感失真；4K 仅限时装/商业人像场景 |

| BPM 档位 | 推荐 fps | 说明 |
|---|---|---|
| BPM > 120 | 60 | 极速推拉、跳剪密集，60fps 消除运动模糊堆积，卡点更锐利 |
| BPM 80-120 | 30 | 节奏均衡，30fps 保留轻微运动模糊，维持胶片质感 |
| BPM < 80 | 24 | 慢速环绕主导，24fps 原生帧率保留骤降变速的空间拉扯感 |
| 93BPM Dark Trap | 60 | 高潮段极速俯冲+全套特效密集，60fps 确保帧间特效不糊帧 |

- 对最终输出文件整体执行一次超分，而非对单个片段逐一处理
- 当用户要求"8K 输出"时，说明当前最高支持 4K，不强行写入不支持的分辨率
- 超分为可选步骤；若用户在意生成速度或无会员资格，可跳过或降级为 1080p 直接输出

### 视频时长与生成方式

时长 <= 15s 的成片用一次视频生成即可拿到完整片段，多段 beat 是同一条提示词内的时间轴描述，不是分段多次生成。只有成片 > 15s 时，才拆成若干 <= 15s 片段分别生成，再做后处理拼接。本技能默认产出 18 秒成片，需拆分为至少 2 个片段（如 0-9s / 9-18s）分别生成后拼接。

## 静默自检

交付前内部跑一遍质检清单并重写弱项。除非用户要求点评，否则不把这份清单输出给用户。

- 锚点是否在所有镜头中保持居中且偏差 <= 2px？
- 蒙太奇段是否覆盖至少 4 个主要方向，每个方向至少出现 2 次？
- 所有运镜是否有爆发加速度曲线，无匀速平滑段？
- 三大高潮节点（11s / 13.5s / 16s）是否按档位参数执行？
- 建立段与蒙太奇段的时长分配是否符合 BPM 分档规则？
- 所有镜头时长总和是否等于蒙太奇段可用时长（误差 <= 0.2s）？
- 跨镜头风格是否一致（冷青调色、暗部压黑、胶片颗粒）？
- 音画卡点是否零脱节？
- 特效强度档位参数是否从参数表直接代入，无自行插值或降级？
- 成片是否为 18s 完整闭环，16s 收尾、18s 精准收镜？
- TVC 模式下是否禁用了所有硬切、跳剪、畸变、白闪？
- 全文语言是否与目标市场一致、无混杂？
