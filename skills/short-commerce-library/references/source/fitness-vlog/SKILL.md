# 健身自律 Vlog

## 1. 核心原则

让一个真实的人完成一次完整的自律训练，不是表演，是生活切片。视频的力量来自「人物可信 × 动作真实 × 节奏呼吸感」三者同时成立。

**持久引擎（因果链）：**

用户上传人物图 → 人物形象锁定（脸/发型/体型/气质） → 干净训练空间搭建 → 四段式动作链（热身→主训练→拉伸→打卡） → 镜头在全身与局部间自然切换 → 汗水与呼吸细节真实 → 舒缓-发力-放松的节奏弧线 → 观众感受到「我也能做到」的自律感

**质量测试（可证伪）：** 如果把视频里的人物换成陌生人脸、或画面出现任何文字/字幕/贴纸，这条Vlog就不再是「这个人的自律记录」而变成了模板广告。人物身份一致和全程零文字是成立的硬条件，任一不满足则重做。

## 2. 输入

| 输入项 | 必需/可选 | 说明 |
|---|---|---|
| 人物图片 | 必需 | 用户上传的人物照片，作为唯一人物形象参考 |
| 训练类型 | 可选 | 默认居家无器械；用户可指定器械/户外/瑜伽等 |
| 画幅 | 可选 | 默认 9:16 竖屏 |
| 总时长 | 可选 | 默认 60s |
| 风格 | 可选 | 默认温柔治愈、真实自律感 |
| 字幕策略 | 可选 | 默认全程无字幕；用户说「去掉字幕/不加字幕/无字幕版」时确认此默认 |
| 旁白 | 可选 | 默认保留旁白声音但不转为画面文字 |

素材缺失时只追问缺失项。用户只说「做健身自律Vlog」并上传人物图时，其余参数走默认值，不追问。

## 3. 输入诊断

落 Prompt 前必须明确或合理假设以下维度：

- **人物形象**：从上传图片中提取脸部特征、发型发色、体型比例、穿搭风格、整体气质。人物图是唯一参考，不生成陌生人脸。
- **训练空间**：默认干净明亮的居家室内，窗边自然光。不把参考图中的杂乱背景带入视频。
- **训练类型**：默认居家无器械（开合跳、深蹲、平板支撑等）。用户指定其他类型时调整动作链。
- **画幅与时长**：默认 9:16 竖屏、60s。
- **风格基调**：低饱和暖色调，真实生活质感，镜头稳定流畅。
- **文字策略**：全程零文字——不生成字幕、标题卡、运动计数、打卡贴纸、花字、界面文字。旁白仅作为声音存在，不转成画面文字。
- **合规敏感点**：健身动作需标准安全，不生成可能导致受伤的错误动作；人物穿搭为自然合身的健身服，不暴露。

## 4. 路由表

| 输入特征 | 选用路线 | 说明 |
|---|---|---|
| 用户上传人物图 + 默认参数 | 标准 60s 四段式无字幕版 | 走下方默认分镜与 Prompt 模板 |
| 用户指定训练类型（器械/户外/瑜伽） | 调整动作链 | 替换四段式中的具体动作，保持结构不变 |
| 用户要求时长变更 | 按比例调整各段时长 | 保持热身→主训练→拉伸→收尾的四段比例 |
| 用户要求加字幕 | 切换为有字幕版 | 在 Prompt 中移除「全程无字幕」约束，另行处理字幕叠加 |

## 5. 工作流

### 步骤一：确认参数

读取用户上传的人物图片，确认或采用默认参数：

- 画幅：9:16 竖屏
- 时长：60s
- 训练类型：居家无器械
- 风格：温柔治愈、真实自律感
- 人物：严格参考用户上传图片的人物形象
- 文字策略：全程不出现字幕、标题、花字、贴纸、界面文字

### 步骤二：人物形象锁定

将用户上传的人物图片作为视频生成的参考素材传入。保持人物的：
- 脸部特征
- 发型发色
- 体型比例
- 穿搭风格（可合理延展为健身服）
- 整体气质

不改变人物身份，不生成陌生人脸，不把参考图中的杂乱背景带入视频。

### 步骤三：生成分镜规划

按以下四段式结构输出 60s 无字幕分镜：

| 段落 | 时长 | 画面内容 | 旁白/声音 |
|---|---|---|---|
| 热身 | 0–12s | 参考人物在干净室内窗边做肩颈环绕、腰部活动、原地高抬腿，动作舒缓，全身入镜 | 旁白：训练开始前，先把身体慢慢唤醒。 |
| 主训练 | 12–42s | 参考人物依次完成开合跳、深蹲、平板支撑，镜头在全身视角和局部动作细节间自然切换 | 旁白：稳住呼吸，动作不用快，专注每一次发力。 |
| 拉伸 | 42–54s | 参考人物进行腿部拉伸、背部拉伸、肩颈放松，节奏明显变慢 | 旁白：训练结束，别忘记让肌肉好好放松。 |
| 打卡收尾 | 54–60s | 参考人物停下休息，擦汗后看向镜头，轻轻点头或微笑，最后定格在自然完成训练的状态 | 旁白：今天的自律已完成，继续坚持。 |

### 步骤四：生成视频

总时长 60s 超过单次视频生成的 15s 上限，需拆分为 4 个片段分别生成，再做后处理拼接。拆分方案：

| 片段 | 对应段落 | 时长 | 说明 |
|---|---|---|---|
| 片段1 | 热身 | 0–12s | 一次生成（12s ≤ 15s） |
| 片段2 | 主训练上 | 12–27s | 一次生成（15s） |
| 片段3 | 主训练下 + 拉伸 | 27–54s | 一次生成（15s，含主训练尾段与完整拉伸） |
| 片段4 | 打卡收尾 | 54–60s | 一次生成（6s ≤ 15s） |

每个片段生成时，将用户上传的人物图片放入参考图片列表，并在 Prompt 中用 `@图片1` 引用该人物形象。

各片段 Prompt 应在以下基础模板上，针对各自段落截取对应动作描述：

**视频生成 Prompt 模板（完整版，用于整体描述；拆分时取对应段落）：**

> 9:16竖屏，真实健身自律Vlog，@图片1 所示人物严格参考其脸部特征、发型、体型比例和整体气质，穿自然合身的健身服。画面为干净明亮的居家训练空间，窗边自然光，低饱和暖色调，真实生活质感，镜头稳定流畅。四段式连续动作：先做肩颈环绕、腰部活动和原地高抬腿热身；接着进行开合跳、徒手深蹲和平板支撑主训练；随后做腿部、背部和肩颈拉伸；最后擦汗看向镜头，以自然微笑完成打卡收尾。全程不出现任何字幕、文字、标题、花字、贴纸或界面文字。动作标准，呼吸节奏自然，汗水细节真实，节奏从舒缓到发力再到放松，画面干净，无杂乱背景。

**片段拆分 Prompt 要点：**
- 每个片段的 Prompt 只描述该时段内的动作，不包含其他段落的动作
- 每个片段都必须包含「@图片1 所示人物」「全程不出现任何字幕、文字、标题、花字、贴纸或界面文字」「画面干净，无杂乱背景」这三条约束
- 片段之间的动作衔接要自然：片段1结尾动作过渡到片段2起始动作

### 步骤五：后处理拼接

将 4 个片段按顺序拼接为完整的 60s 视频。如用户需要旁白，在拼接后叠加旁白音频，旁白仅作为声音，不转成画面文字。

### 步骤六：输出交付

用户上传人物图后，直接输出：
1. 视频生成参数确认（画幅、时长、训练类型、风格、文字策略）
2. 60s 无字幕分镜表
3. 可直接使用的视频 Prompt（含片段拆分方案）

## 6. 输出契约

### 参数确认格式

```
画幅：9:16 竖屏
时长：60s
训练类型：居家无器械
风格：温柔治愈、真实自律感
人物参考：用户上传图片
文字策略：全程无字幕、无标题、无花字、无贴纸、无界面文字
```

### 分镜 beat 结构

| beat | 时间码 | 主体动作 | 镜头 | 光线/色调 | 声音 |
|---|---|---|---|---|---|
| 1 | 0–4s | 肩颈环绕，全身入镜 | 固定中景，窗边 | 暖色自然光 | 旁白+呼吸声 |
| 2 | 4–8s | 腰部活动+原地高抬腿 | 缓慢横移 | 暖色自然光 | 旁白+呼吸声 |
| 3 | 8–12s | 高抬腿收势，过渡 | 中景固定 | 暖色自然光 | 呼吸声 |
| 4 | 12–18s | 开合跳 | 全身→脚步特写切换 | 暖色自然光 | 旁白+呼吸声 |
| 5 | 18–25s | 徒手深蹲（多组） | 侧面中景 | 暖色自然光 | 旁白+呼吸声 |
| 6 | 25–32s | 深蹲继续，汗水出现 | 侧面中景+面部特写 | 暖色自然光 | 呼吸声 |
| 7 | 32–42s | 平板支撑 | 低角度侧面 | 暖色自然光 | 旁白+呼吸声 |
| 8 | 42–48s | 腿部拉伸 | 中景，节奏放慢 | 暖色自然光 | 旁白+呼吸声 |
| 9 | 48–54s | 背部+肩颈拉伸 | 中景固定 | 暖色自然光 | 旁白+呼吸声 |
| 10 | 54–60s | 擦汗，看向镜头，微笑点头 | 中景固定→定格 | 暖色自然光 | 旁白：今天的自律已完成，继续坚持。 |

### Prompt 措辞规则

- 使用正向措辞描述画面内容，用「全程不出现任何字幕、文字、标题、花字、贴纸或界面文字」一条否定式约束统一处理无文字要求
- 不堆叠多条否定式约束
- 人物参考用 `@图片1` 显式引用
- 每个片段 Prompt 控制在 150 字以内，聚焦当前段落动作

- [ ] 每个片段时长是否 ≤ 15s

- [ ] 每个片段 Prompt 是否包含「全程不出现任何字幕、文字、标题、花字、贴纸或界面文字」

- [ ] 穿搭是否为自然合身的健身服，无暴露
