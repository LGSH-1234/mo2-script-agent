
# 表情动作与组合参考

## 强度锚点

- 2/10：只有眼神、眼睑或单侧嘴角发生轻微变化。
- 5/10：眉眼与嘴部共同变化，观众能明确识别情绪。
- 8/10：加入呼吸、下颌、头部和肩颈反应，适合情绪峰值。

## 基础情绪

### 喜悦

眼角轻收、下眼睑微抬、双颊上提、嘴角自然上扬。真诚喜悦让眼周参与；礼貌微笑主要发生在嘴角。

### 悲伤

眉头内侧微抬并靠拢、上眼睑略沉、视线下移、嘴角失去支撑、下唇轻颤或下颌短暂绷紧。克制悲伤优先用停顿、吞咽和缓慢呼气。

### 愤怒

眉毛下压并靠拢、上眼睑收紧、目光锁定、鼻翼轻张、嘴唇压紧或下颌绷紧。压抑愤怒先静止和憋气，再出现短促呼气；避免默认张嘴咆哮。

### 恐惧

眉毛抬高并靠拢、上眼睑抬起、下眼睑紧张、瞳孔与视线快速寻找出口、嘴唇微张、呼吸变浅。强烈时加入身体后撤和肩膀抬起。

### 惊讶

眉毛快速抬起、眼睛睁大、下颌自然下落、动作短暂停顿。惊讶应短暂，随后转入喜悦、恐惧、困惑或警觉。

### 厌恶

鼻梁轻皱、上唇单侧或双侧抬起、眼睑略收、头部后撤。轻度厌恶可只用鼻翼和上唇的微小反应。

### 轻蔑

单侧嘴角短暂上提、目光略偏、下巴轻抬。保持不对称；双侧大笑会破坏轻蔑感。

### 困惑

双眉不对称、视线短暂游移、眼睑微眯、头部轻偏、嘴唇欲言又止。随后可通过重新聚焦视线表现理解。

## 常用混合情绪

- 苦笑：嘴角试图上扬，但眼神低落、眉心轻收，笑意无法到达眼底。
- 含泪欣慰：眼眶湿润与眉心紧张保留，呼吸放松，嘴角缓慢上扬。
- 紧张期待：眼神锁定目标，眨眼减少，嘴唇轻抿，吸气后短暂停住。
- 怀疑转确信：一侧眉毛微抬、眼睛轻眯、视线游移；发现证据后视线聚焦、眉毛放平、下颌放松。
- 隐忍愤怒：表面平静，嘴唇压紧、下颌肌短暂跳动、鼻翼轻张、呼气受控。
- 强装镇定：姿态稳定，但眨眼频率略高、吞咽、指尖紧张或呼吸变浅泄露真实情绪。

## 时间轴模板

### 渐进

`0–20% 保持基线 → 20–55% 出现第一个微表情信号 → 55–75% 多个面部区域共同变化并达到峰值 → 75–100% 回落并保留余韵`

### 突然反转

`0–40% 维持原情绪 → 40–48% 因触发事件短暂停顿 → 48–70% 眼神最先改变，眉眼和嘴部随后跟进 → 70–100% 新情绪稳定`

### 压抑后爆发

`0–45% 控制呼吸与嘴部，真实情绪仅从眼神泄露 → 45–65% 下颌和眉心紧张累积 → 65–80% 短促爆发 → 80–100% 呼吸紊乱或疲惫回落`

## 负面约束库

按需选择，不要全部堆叠：

`无表情瞬移，无五官抖动，无机械式周期眨眼，无僵硬假笑，无眉毛与嘴角情绪冲突，无左右脸无故变形，无嘴唇穿插，无牙齿闪烁，无瞳孔漂移，无头部抽动，无过度夸张表演，无蜡像感，无身份漂移，保持脸型与五官比例稳定。`
