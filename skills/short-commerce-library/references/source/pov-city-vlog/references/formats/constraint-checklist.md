# 铁律校验清单

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 逐镜重点校验


| 镜头   | 重点校验项                                     |
| ---- | ----------------------------------------- |
| 镜头1  | 男友手掌锚定石阶/步道；第一帧完整露出女主脸/肩颈/全身穿搭            |
| 镜头2  | 男友手掌放在桌沿锚定；女主体验本地风物不说话                    |
| 镜头3a | 品鉴特写动作量是否在3秒内可完成（嗅闻+浅笑+轻抿+台词）；固定镜头只指定1种运镜 |
| 镜头3b | 后拉全景是否展示整片景点远景；缓慢后拉只指定1种运镜；与3a的衔接是否自然     |
| 镜头4  | 硬切全新场景（菜馆），不延续景点环境；入座+说台词                 |
| 镜头5  | 菜品上桌看菜惊喜，无台词；男友手掌放在桌边锚点                   |
| 镜头6  | 男友手掌托碗承接，手腕以上在画外，木桌为物理锚点（可上传修复图）          |
| 镜头7  | 女主正面偏三分之四角度，面部全程可见；少量路人                   |
| 镜头8  | 桌边平视高度；女主望窗外黄昏城景                          |
| 镜头9  | 女主端茶杯望远山/城景（可上传修复图）；时长1.5秒                |
| 镜头10 | 画面唯一可见人物为女主；男友手掌可轻放桌面作锚点；时长1.5秒           |


## 视角铁律速查


| 检查项         | 要求                           |
| ----------- | ---------------------------- |
| 男友可见部位      | 仅允许同一只成年男性手掌偶尔入画，手腕及以上必须留在画外 |
| 手掌锚定        | 手掌必须依托台面/石阶等实体锚点，禁止悬空手、断肢感   |
| 男友面部/躯干/四肢  | 严禁出现                         |
| 男友影子/镜面倒影   | 严禁出现                         |
| 第二男性角色/双人合照 | 禁止                           |


## 画面铁律速查


| 检查项               | 要求                            |
| ----------------- | ----------------------------- |
| 可见文字              | 全片从第一帧到最后一帧绝对禁止任何可见文字         |
| 对白字幕/烧录字幕/标题/贴纸文字 | 禁止                            |
| Logo/水印/角标/界面文字   | 禁止                            |
| 招牌可读汉字            | 禁止，招牌/标识牌必须虚化至无法辨认            |
| 品牌LOGO            | 画面所有衣物、道具不出现任何品牌LOGO、文字标识     |
| 对白呈现方式            | 仅依靠人声+同步口型，画面永不显示台词；口型同步为尽力呈现 |


## 音频铁律速查


| 检查项          | 要求                  |
| ------------ | ------------------- |
| BGM/配乐/歌曲/旋律 | 全程禁止                |
| 真实环境现场声      | 保留（生成时尽量让模型生成自然环境声） |
| 女主人声对白       | 保留（简短；可后期用语音合成单独处理） |
| 男友说话         | 全程禁止                |


## 摄影质感铁律速查


| 检查项              | 要求         |
| ---------------- | ---------- |
| 拍摄方式             | iPhone手持拍摄 |
| 抖动               | 自然轻微呼吸抖动   |
| 变焦               | 推拉滑动变焦     |
| 曝光               | 环境曝光自动微调   |
| 材质质感             | 保留真实材质质感   |
| 强HDR/广告大片质感/塑料磨皮 | 拒绝         |


## 环境铁律速查


| 检查项        | 要求         |
| ---------- | ---------- |
| 自然路人/食客    | 有人场景必须保留少量 |
| 完全空荡的景点/餐厅 | 禁止         |
| 路人抢夺主角视线   | 禁止         |
| 重复人脸       | 禁止         |


## 穿帮修复校验


| 场景    | 校验项                                                    |
| ----- | ------------------------------------------------------ |
| 整片穿帮  | 重新生成30秒完整视频，保留原有参考图绑定                                  |
| 单镜头穿帮 | 单独生成该镜头片段，替换拼接进原成片对应时间段                                |
| 局部修改  | 使用视频编辑能力，传入原视频和参考图，指定时间段和空间位置编辑，保持人物面部/发型/动作/背景/光线完全不变 |
| 修复图绑定 | 上传修正图作为该镜头画面参考，优先修正穿帮部位                                |
