# 视频生成 Prompt 文法

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 八要素万能公式

每段视频生成的 prompt 按以下顺序撰写，模型对这个顺序的解析率最高：

```
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质参数 + 约束条件
```

每个beat以明确时间节点标注，在时间节点内按八要素顺序展开：

```
0-3秒：[主体] + [动作] + [场景] + [光影] + [运镜] + [风格/画质/约束]
3-6秒：[主体] + [动作] + [场景] + [光影] + [运镜] + [风格/画质/约束]
...
```

### 八要素逐条规范

**1. 精准主体**：明确角色身份、外貌特征、穿着，绑定对应参考图。

- 范例："@图片1 所示女主，温婉治愈甜妹，五官柔和，微卷锁骨发，白T搭配米色长裙"

**2. 动作细节**：写清具体动作、动作间过渡、情绪外化表现。

- 优先写缓慢、连续的小动作（缓慢行走、轻轻抬手、微微低头），避免高强度剧烈动作
- 必须写出动作间的过渡（如"借着刚才转身的惯性，从停顿自然过渡到抬手"），提升连贯性
- 情绪外化：用"嘴角微颤、眼眶渐红、肩膀微微抖动"这类身体信号，替代"很悲伤""非常愤怒"这类抽象情绪词
- 范例："女主三分之四侧身，缓步向前，借着前行的惯性自然转头，直视镜头浅笑"

**3. 场景环境**：明确空间、时间、天气、环境细节。

- 范例："午后侧逆光穿过树叶洒在石阶步道上，远处可见茶山入口轮廓"

**4. 光影色调**：指定光源方向、明暗氛围、整体色调。

- 范例："暖黄侧逆光，光影柔和，自然色调，环境曝光自动微调"
- 全段统一指定光影色调，多段制作复用同一套光影描述，避免段间色调割裂

**5. 镜头运镜**：景别 + 运镜方式。

- 直接使用中文专业术语：中景、特写、全景、缓慢推镜、平稳横移、固定镜头、手持晃动
- 单镜头内只指定1种运镜方式，禁止同时要求推拉摇移，会增加画面不稳定性
- 对话戏推荐：正反打镜头、缓慢推拉、浅景深对焦切换
- 范例："中景，缓慢推镜，iPhone手持拍摄带自然轻微呼吸抖动"

**6. 视觉风格**：画风、质感、美学方向。

- 范例："写实纪录片质感，保留真实材质质感，拒绝强HDR、广告大片质感、塑料磨皮"

**7. 画质参数**：分辨率、清晰度、细节程度。放在句末收紧效果。

- 范例："高清，细节丰富，色彩自然，光影柔和"

**8. 约束条件**：防翻车固定话术，降低变形、闪烁、跳脸概率。放在句末。

- 必加约束词："面部稳定不变形、五官清晰、人体结构正常、动作自然流畅、不僵硬、画面无卡顿、无闪烁"
- 铁律正向约束（用正向执行措辞，不堆否定式）：
  - "画面保持纯净，仅保留真实场景元素，无任何文字出现"
  - "仅同一只成年男性手掌从画面下缘伸出，依托木桌台面，手腕以上留在画外"
  - "画面中仅可见女主一人，周围少量自然路人作为背景"
  - "招牌标识虚化至模糊不可辨认"
  - "画面所有衣物、道具不出现任何品牌LOGO、文字标识"

## 动作过渡写法

每个beat内的动作描述必须包含过渡衔接，避免僵硬跳切：

- 范例1："女主凑近嗅闻，闭眼浅笑，借着抬头的惯性自然睁眼看向镜头"
- 范例2："女主拉开木椅入座，顺势抬头期待挑眉看向镜头"
- 范例3："女主拿起公筷夹起菜品递向镜头方向，同时直视镜头"

不要写孤立动作再靠模型自行连接，要写清动作之间的因果/惯性关系。

## 运镜单镜头规则

- 单个时间段内只指定1种运镜方式
- 如果一个镜头需要运镜变化（如先特写后拉全景），必须拆成两个独立时间段
- 范例（错误）："6-9秒：近脸特写女主嗅闻，然后镜头后拉展示全景" — 同一beat内两种运镜
- 范例（正确）："6-9秒：近脸特写，固定镜头，女主嗅闻浅笑" + "9-12秒：全景，缓慢后拉，展示整片景点远景"

## 实体标签绑定

使用 @图片N 引用 ImageList 中的参考素材：

- @图片1：女主定妆参考图（用户上传或自动生成，绑定到全部镜头）
- @图片2：场景参考图（可选，锁定环境与光影风格，推荐生成或上传1张）
- @图片3：镜头6修复图（仅绑定镜头6）
- @图片4：镜头9修复图（仅绑定镜头9）

素材配置策略：角色图1张 + 场景图1张 = 2-3个素材为稳妥配置，不要用满上限，过多素材会让模型难以判断优先级。

声明对应关系的正确写法（必须手动声明，模型无法自动匹配人名与图片序号）：

- "@图片1为女主，@图片2为场景参考，全程保持女主五官、发型、服装与@图片1完全一致"

## 段内硬切与段间拼接

- 单次直出30秒时：每个3秒beat在prompt中以明确时间节点标注，模型对段内硬切的理解不稳定，可能出现柔和过渡而非严格硬切，这是可接受的
- 分段生成时：段内beat分界可接受柔和过渡，段间拼接处为严格硬切

## 穿帮修复prompt规则

- 整片穿帮：重新生成30秒完整视频，保留原有参考图绑定
- 单镜头穿帮：单独生成该镜头3秒（或1.5秒）片段，prompt中仅描述该镜头内容，再手动替换拼接进原成片对应时间段
- 局部修改（换装/删元素）：使用视频编辑能力，传入原视频，指定需修改的时间段和空间位置，保持人物面部/发型/动作/背景/光线完全不变
- 上传修正图片作为该镜头的画面参考，优先修正穿帮部位
