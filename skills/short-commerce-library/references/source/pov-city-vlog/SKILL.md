# 男友第一视角城市文旅Vlog

## 核心原则

不要只拍风景，而要做"男友眼中的她与城市"。观众代入男友视角，镜头即男友双眼；城市风物与女主情绪交织，每镜皆有治愈松弛感而非营业假笑。

持久引擎（因果链）：

**城市输入 -&gt; 画幅确认 -&gt; 景点+菜馆双场景匹配 -&gt; 11镜固定结构填充 -&gt; 女主定妆锁定（上传或自动生成） -&gt; 铁律校验 -&gt; 参考图绑定 -&gt; 视频生成指令输出 -&gt; 后处理拼接与音频处理**

### 质量测试（可证伪）

如果第一帧画面出现了男友的脸/躯干/四肢/影子/镜面倒影，或者画面出现任何可见文字，或者出现了第二男性角色或双人合照，则该镜头不通过，必须重新生成。

## 输入诊断

生产前，识别或明确以下维度：

- 目标城市：用户指定的中国城市名称（唯一必填项）
- 画幅选择：9:16竖屏（默认）或16:9横屏（用户可选）
- 核心景点：该城市的自然/人文景点（茶山/湖畔/老街/古村/观景台等，用户可指定）
- 本地特色菜：该城市的代表性菜品（用户可指定）
- 特色茶饮：该城市的本地茶饮/风物（用户可指定）
- 女主定妆：是否上传女主参考图（上传则全片锁定；未上传则自动生成一张定妆参考图绑定全片）
- 镜头6修复图：是否上传图片替换镜头6（美食互动，修复手部/碗具穿帮）
- 镜头9修复图：是否上传图片替换镜头9（黄昏远景，修复场景穿帮）
- 女主基础设定：温婉治愈甜妹，松弛自然情绪，不做营业假笑（用户可修改年龄/穿搭/风格）
- 合规敏感点：全片无文字、无BGM、男友不说话、仅同一只手掌偶尔入画且必须锚定实体

若用户未指定景点/菜品/茶饮/画幅，根据城市名称做合理推断并继续，仅在无法推断时追问。画幅默认9:16竖屏。

## 工作流（步骤）

### 步骤1：收集用户输入

只需问用户一个问题：**目标城市**。其余信息根据城市名称自动推断（景点、菜品、茶饮），画幅默认9:16竖屏。用户如有素材可随时上传，不主动追问。

若用户主动指定景点/菜品/茶饮/画幅/修复图，则按用户指定填充。

### 步骤2：参考图资产准备

**女主定妆图：**

- 用户上传定妆图 -&gt; 直接用作全片人物参考
- 用户未上传 -&gt; 先生成一张女主全身定妆参考图（按基础设定：温婉治愈甜妹，完整露出五官/发型/肩颈/全身穿搭），再将该图绑定到全片所有镜头。生成定妆图是中间产物，不展示给用户。

**场景参考图（推荐生成）：**

- 用户上传场景图 -&gt; 直接用作环境参考
- 用户未上传 -&gt; 根据匹配的景点和菜馆场景，生成1-2张场景参考图（景点1张+菜馆1张），锁定环境与光影风格。场景图是中间产物，不展示给用户。

**素材总数控制：** 角色图1张 + 场景图1-2张 = 2-3个素材为稳妥配置，加上修复图不超过5个。不要用满上限，过多素材会让模型难以判断优先级。

### 步骤3：填充11镜头脚本模板

将用户输入填入下方标准模板，输出整理好的分镜表格。用户未指定的项，根据城市做合理推断填充。

注意：原镜头3因3秒内动作过密，已拆分为镜头3a（品鉴特写）和镜头3b（后拉全景），总镜头数为11个，每镜时长见分镜表。

### 步骤4：铁律校验

逐镜检查是否违反全局硬性画面铁律（见下方"全局铁律"章节）。发现冲突时优先遵守铁律，向用户提示冲突点。

### 步骤5：参考图绑定

- 女主定妆图（用户上传或自动生成）-&gt; 绑定到全部镜头的人物参考
- 场景参考图（用户上传或自动生成）-&gt; 绑定到对应场景镜头的环境参考
- 用户上传镜头6修复图 -&gt; 绑定到镜头6的画面参考
- 用户上传镜头9修复图 -&gt; 绑定到镜头9的画面参考
- 输出参考图绑定说明，标明每张图对应的镜头编号与用途
- 必须手动声明每张图的对应关系（如"@图片1为女主，@图片2为场景参考"），模型无法自动匹配人名与图片序号

### 步骤6：输出视频生成指令

用户确认分镜表与参考图无误后，生成完整视频生成指令。

**视频生成方式：** 成片总时长30秒，当前视频模型支持单次4-30秒直出，因此优先单次生成30秒完整视频，无需分段拼接或延长。

**单次直出策略（默认）：**

- 一次生成30秒完整视频，全部11个镜头写在同一条prompt中
- 每个beat以明确时间节点标注（如"0-3秒：""3-6秒："），帮助模型理解3秒分段
- prompt中统一指定角色图、场景图与光影描述，保证全片一致
- 优势：无拼接色调割裂风险，角色/场景一致性最强

**分段生成策略（备选，仅在用户要求或单次直出效果不佳时使用）：**

- 拆为2段：第一段（镜头1-3b + 镜头4-5，0-15秒）、第二段（镜头6-10，15-30秒）
- 两段独立生成，统一角色图、场景图与光影描述，后处理拼接
- 分段拼接处统一角色、场景、光影、风格参数，段间为严格硬切

**段内硬切说明：** 同一次生成内部的镜头分界，在prompt中以明确的时间节点标注每个3秒beat的起止动作。模型对段内硬切的理解不稳定，可能出现柔和过渡而非严格硬切，这是可接受的；若使用分段生成，段间拼接处（镜头5→镜头6）为严格硬切。

### 步骤7：音频处理

视频生成模型自带的音频能力有限，音频按以下策略处理：

- 生成视频时，prompt中写明环境声描述（风声/餐厅底噪/脚步声等），尽量让模型生成自然环境声
- 女主人声对白由模型尽力生成口型动作，口型同步为尽力呈现，不作为硬性质量门禁
- 若对音频质量有更高要求，可在后期使用语音合成工具单独生成女主人声对白音轨，再与环境声混音后覆盖到视频上
- 男友全程不说话，不生成任何人声音轨

### 步骤8：穿帮修复

用户反馈视频存在穿帮时，按以下流程处理：

- **整片重做**（多镜头有问题）：重新生成30秒完整视频，保留原有参考图绑定
- **单镜头穿帮**（仅1-2个镜头有问题）：单独生成该镜头3秒片段，再手动替换拼接进原成片对应时间段
- **局部修改**（换装/删元素/修复瑕疵）：使用视频编辑能力（TaskType为edit），传入原视频和参考图，在prompt中指定需修改的时间段和空间位置，要求保持人物面部、发型、动作以及背景环境、光线完全不变，色彩过渡自然无破绽
- 无论哪种方式，均可上传修正图片作为该镜头的画面参考，优先修正穿帮部位

## 全局铁律（任何场景、任何城市都不可打破，优先级最高）

### 视角规则

摄影机 = 男友双眼，观众代入男友。男友仅允许同一只成年男性手掌偶尔入画，手腕及以上必须留在画外。手掌必须依托台面/石阶等实体锚点，禁止悬空手、断肢感。严禁男友脸、躯干、四肢、影子、镜面倒影出现。禁止第二男性角色，禁止双人同框合照。

### 画面铁律

1. 全片从第一帧到最后一帧，绝对禁止任何可见文字：对白字幕、烧录字幕、标题、贴纸文字、Logo、水印、角标、界面文字、招牌可读汉字全部禁止。招牌、标识牌必须虚化至无法辨认。
2. 人物对白仅依靠人声+同步口型呈现，画面永远不显示台词。口型同步为尽力呈现，不作为硬性质量门禁；对白以人声呈现为主，可后期配音覆盖。
3. 音频规则：全程无BGM、无配乐、无歌曲、无旋律；只保留真实环境现场声+女主简短人声对白；男友全程不说话。视频生成时尽量让模型生成自然环境声；女主人声对白可后期用语音合成单独处理。
4. 镜头规范：固定11个镜头，清晰硬切为主。视频基础参数：时长30秒，画幅9:16竖屏（默认）或16:9横屏（用户可选）。分辨率跟随用户当前设置，不硬编码。段内可接受柔和过渡，分段生成时段间拼接处为严格硬切。
5. 摄影质感：iPhone手持拍摄，带有自然轻微呼吸抖动、推拉滑动变焦；环境曝光自动微调，保留真实材质质感；拒绝强HDR、广告大片质感、塑料磨皮。
6. 环境要求：有人场景必须保留少量自然路人、食客，不能出现完全空荡的景点/餐厅；路人不抢夺主角视线，不重复人脸。

### 人物模板

基础女主设定（用户可自由修改年龄、穿搭、风格）：温婉治愈甜妹，松弛自然情绪，不做营业假笑。情绪表达依靠浅笑、抬眼、嗅闻、惊叹、温柔对视。情绪外化用身体信号（嘴角微颤、眼眶渐红、肩膀微微抖动）替代抽象情绪词（如"很悲伤""非常愤怒"）。

基础体态：匀称比例，柔和肩颈线条；穿搭可自定义。一旦上传人物定妆参考图或自动生成定妆参考图，全片所有镜头必须严格锁定该人物五官、发型、身材比例、服装，禁止换脸、扭曲体态、增龄。

### 产出三：视频生成指令

视频生成方式：成片总时长30秒。默认单次直出：一次生成30秒完整视频，全部11个镜头写在同一条prompt中。仅在用户要求或单次直出效果不佳时，备选分段生成（拆为2段各15秒，后处理拼接）。

每条视频生成指令包含：

- 完整prompt（含场景描述、人物动作、台词口型、环境声、铁律约束）
- 参考图列表（ImageList）：女主定妆图 + 场景参考图 + 对应修复图（如有）
- 参数：画幅（9:16或16:9，跟随用户选择），时长30秒（单次直出）或15秒（分段），分辨率跟随用户当前设置

prompt撰写规则：

- 按八要素顺序展开：精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质参数 + 约束条件
- 每个beat在prompt中以明确时间节点标注（如"0-3秒：""3-6秒："），帮助模型理解3秒分段
- 动作细节必须写出动作间的过渡衔接（因果/惯性关系），避免孤立动作跳切
- 单个时间段内只指定1种运镜方式，需要运镜变化的镜头拆成独立时间段
- 情绪用身体信号外化（嘴角微颤、肩膀微抖），替代抽象情绪词
- 用稳定标签绑定复现实体（如女主@图片1、场景@图片2），必须手动声明对应关系
- 光影色调全段统一指定，多段复用同一套光影描述
- 句末加标准约束词：面部稳定不变形、五官清晰、人体结构正常、动作自然流畅、不僵硬、画面无卡顿、无闪烁
- 铁律约束以正向执行措辞写入（如"画面保持纯净无文字""仅保留同一只手掌入画且依托台面"）
- 段内beat分界处可接受柔和过渡，分段生成时段间拼接处为严格硬切

## 动态场景引擎

用户输入城市名称后，匹配该城市两类核心场景：

1. 自然/人文景点（茶山/湖畔/老街/古村/观景台等，用户可指定）
2. 本地特色家常菜馆（本地菜系、特色菜品，用户可指定）

场景自动分配到11镜结构：

- 镜头1：景点入口漫步（POV牵手前行）
- 镜头2：景点特色体验点位（茶席/观景台等，体验本地风物）
- 镜头3a：风物品鉴特写（近脸嗅闻+轻抿+台词）
- 镜头3b：景点远景后拉全景（无台词，展示环境）
- 镜头4：本地菜馆入座，女主拉开木椅+说台词
- 镜头5：本地特色菜品上桌，女主看菜惊喜（无台词）
- 镜头6：美食互动镜头（夹菜递向镜头，男友单手托碗接收）
- 镜头7：城市老街/步道漫步
- 镜头8：黄昏窗边观景（菜馆窗边）
- 镜头9：黄昏远景，举杯品鉴本地茶饮，望向城市山水
- 镜头10：菜馆窗边单人收尾镜头，女主面向镜头温柔道别

用户可以上传图片，指定覆盖任意镜头；上传图片自动作为对应镜头画面参考资产，优先修正穿帮。

## 静默自检

交付前内部执行，不外显给用户：

- 11个镜头是否完整覆盖0-30秒时间轴？每镜时长分配是否正确？
- 女主定妆图（用户上传或自动生成）是否绑定到全部镜头？上传修复图是否绑定到对应镜头？
- 场景参考图是否已生成并绑定到对应场景镜头？
- 素材总数是否控制在2-5个以内（角色1+场景1-2+修复图）？
- 视频生成策略是否优先单次30秒直出？
- prompt中每个beat是否以明确时间节点标注3秒分段？
- prompt是否按八要素顺序展开（主体+动作+场景+光影+运镜+风格+画质+约束）？
- prompt中动作之间是否写出了过渡衔接（因果/惯性关系）？
- 单个时间段内是否只指定1种运镜方式？
- 情绪是否用身体信号外化，而非抽象情绪词？
- 参考图对应关系是否手动声明（@图片1为女主，@图片2为场景）？
- 光影色调是否全段统一指定？
- 句末是否加了标准约束词（面部稳定不变形等）？
- 穿帮修复流程是否明确区分整片重做、单镜头替换与局部编辑？
- 画幅是否跟随用户选择（9:16或16:9）？分辨率是否跟随用户设置？总时长是否30秒？
