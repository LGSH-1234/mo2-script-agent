# 知识博主口播广告 · 极速上手指南（skill-intro.md）

> **一句话定位**：以 TikTok/抖音/B 站爆款知识博主干货口播为标杆，用专业干货讲解、专业口播光、四段式知识叙事与专业可信表演，把产品转化为可信任的知识种草欲望。**干货即信任，专业即权威，知识即种草。**

## 🚀 30 秒上手流程

1. **锁基准资产**：先定 `@CHAR_EXPERT`（知识博主 Model Card，专业可信亲和）+ `@PROD_ITEM`（产品，同款式同卖点）+ `@SCN_STUDIO`（演播室/书房）+ `@PROP_CHART`（白板/图表/数据动画），一次性锁定，全程 @ 引用禁止链式改（严禁博主/产品/图表漂移）。
2. **选文生图版本**：默认用 `SKILL.md §二` 的 MJ v8 专属版或常规通用版；用户点名"角色资产卡/Model Card/定妆卡"时才输出第三版本（10 格）。
3. **写剧本**：套四段式知识口播——①痛点提问开场（抛问题/悬念）→ ②干货知识讲解（专业科普/方法论）→ ③产品解决方案（知识落地）→ ④信任背书种草 CTA（详见 `02-viral-script-hooks.md`）。
4. **生成视频**：套 `SKILL.md §三` 的 11 段式多参引擎，**除台词外整体描述必须用中文**，竖屏 9:16 手机原生，博主逐段注入 AU 微表情、图表注入知识可视化动力学 + 光影五子层。
5. **配音效**：清晰口播人声 + 轻知识 BGM（简约/科技轻音乐）+ 图表切换音效（详见 `03-sound-design-asmr.md`）。

## 🎯 五大不可动摇配方速查

| 配方 | 数值锚点 |
|---|---|
| **专业口播光** | 窗光/环形柔光箱右侧 40° 5000K CRI 96 明亮干净专业，反光补光左侧 40°，Key:Fill 1.6:1 干净显面部，轮廓光柔和，明亮通透无阴影 |
| **口播三机位** | 手机竖屏口播中景 35mm 等效 + 讲解特写 50mm 等效 T2.0 + 产品图表微距 100mm 等效 T2.8，半身平视高度 1.4m，方位角 10° 近正面，浅景深演播室虚化 |
| **知识可视化动力学** | 图表呈现/白板书写/数据动画/产品演示，纯图表产品空镜 AU 转"知识可视化动力学"并声明 `[本镜无角色面部主体]` |
| **四段式知识节奏** | 痛点-干货-方案-背书，口播节奏 + 知识卡点，20-30 秒知识弧，专业可信韵律 |
| **专业可信 AU** | 讲解专注 AU4+AU7 皱眉眼睑收紧（C 级），强调笃定 AU9+AU10 皱鼻上唇提升（C 级），信任微笑 AU6+AU12（B 级） |

## ⚠️ 三条红线
- **严禁伪科学虚假科普**：专业知识须有科学依据/权威来源，绝不允许传播伪科学/谣言/"XX 致癌/包治/神效"式恐吓营销（违反《广告法》第二十八条虚假广告、《网络信息内容生态治理规定》）。
- **资质背书真实**：领域专家/机构背书须真实执业资质（医师/律师/教师/营养师等），严禁冒充专家/虚构头衔；涉及医疗/药品/保健品须遵守特殊广告审查，严禁非医疗广告涉及疾病治疗功能（违反《广告法》第十六条第三十八条、《医疗广告管理办法》）。
- **字幕铁律**：No subtitles.（字幕/知识点/产品信息/图表花字绝不由模型生成，须后期硬压）；软广须依法标注"广告"；台词保留原语言口语化专业可信，口型同步精准。
