# 知识博主口播 剧本钩子（02-viral-script-hooks.md）

1. **四段式知识口播结构**：①痛点提问开场（0-6s 抛出问题/悬念，4 秒钩子）→ ②干货知识讲解（6-14s 专业科普/方法论）→ ③产品解决方案（14-21s 知识落地/产品结合）→ ④信任背书种草 CTA（21-26s 专业背书/资质/客观建议）。
2. **4 秒痛点提问钩子**：开场即"最戳中痛点的问题"——一个反常识的提问/一个普遍困扰的痛点/一个悬念，用"原来我一直都想错了"的好奇抓住求知观众，绝不允许平铺直叙叫卖开场。
3. **干货讲解模板**：干货须放大"专业可信的知识密度"——方法论/原理/数据/对比，配合 50mm 讲解特写 push-in + 100mm 图表微距 + 知识可视化动力学，把知识转化为"讲得清的论据"，须有科学依据不伪科学。
4. **产品方案脚本**：产品须"作为知识落地的解决方案自然登场"——博主讲解产品如何解决前述痛点（AU6+AU12 信任微笑），产品演示/数据对比，把产品升华为"专业推荐"而非硬广植入。
5. **信任背书落点**：CTA 用博主口播讲"专业背书/资质/客观建议"的信任种草，信任真诚 AU6+AU12，把消费升华为"专家认可的信任"，客观建议收尾，须标资质严禁绝对化权威。
6. **单一源公理铁律**：全片博主 `@CHAR_EXPERT`、产品 `@PROD_ITEM`、场景 `@SCN_STUDIO`、图表 `@PROP_CHART` 从基准资产一次性生成，四段式知识所有镜头 @ 显式引用，产品须同款式同卖点，严禁链式修改导致漂移。
