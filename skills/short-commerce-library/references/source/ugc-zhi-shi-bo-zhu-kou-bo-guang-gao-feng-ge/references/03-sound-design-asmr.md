# 知识博主口播 声场工程（03-sound-design-asmr.md）

1. **清晰口播人声核心**：博主口播人声为绝对核心，清晰干净、无杂音、无回声，专业收音（领夹麦/电容麦），人声置于声场最前，是"专业可信知识输出"的第一载体——口播清晰度直接决定信任度。
2. **轻知识 BGM 基调**：简约/科技轻音乐为主的轻知识 BGM，中低节奏（70-95 BPM），音量克制垫底不压人声，可用极简电子/钢琴/科技感铺底，绝非喧闹快节奏——BGM 是"专业氛围"的辅助载体。
3. **图表切换音效**：知识图表呈现/白板书写/数据动画/产品演示用轻量音效（点击/滑动/数据滚动音），精准对齐知识卡点，放大"知识可视化"的节奏感，音量克制不干扰口播。
4. **演播室环境音分层**：演播室/书房真实环境音分层叠加——极轻房间底噪、翻页声、书写声，细腻还原真实知识空间，音量克制近乎无声，突出人声专业感。
5. **声画同步知识弧**：26 秒知识弧声画同步——痛点提问口播、干货讲解图表音效、产品方案演示音、CTA 背书口播，声音节奏与画面知识卡点严丝合缝，人声始终清晰主导。
6. **单一源公理铁律**：@CHAR_EXPERT 博主口播声线须与基准角色资产一致（同一博主声线），@PROD_ITEM/@PROP_CHART 音效须符合同款式同图表真实特征，声场服务于专业可信，严禁声画割裂或虚假音效。
