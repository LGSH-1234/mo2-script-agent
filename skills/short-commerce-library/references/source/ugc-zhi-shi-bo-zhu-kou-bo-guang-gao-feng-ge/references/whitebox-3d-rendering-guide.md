# 知识博主口播 3D 白模与轨迹锁定（whitebox-3d-rendering-guide.md）

1. **知识图表解算锁定**：先用 3D 白模（greybox）锁定 `@CHAR_EXPERT` 面部骨相基准、`@PROD_ITEM` 产品与 `@PROP_CHART` 知识图表基准，图表/数据动画用运动图形（motion graphics）解算——图表呈现/白板书写/数据滚动/产品演示，确保知识可视化动力学清晰可信（严禁图表乱码或数据失真）。
2. **口播轨迹锁定**：博主口播须用口型绑定（lip-sync rig）锁定，口型与台词音素精准对齐，视线锁定镜头（近正面直视），头部/手势自然配合讲解节奏，避免口型错位与视线漂移。
3. **知识卡点对齐**：知识卡点用时间轴精确标记——痛点提问/干货要点/图表切换/产品演示，卡点帧与口播重点、图表音效对齐，确保知识节奏清晰（卡点服务于知识密度）。
4. **强调手势与图表对齐**：博主强调手势（指点/计数/对比）用动画曲线锁定，手势与图表/产品呈现时机对齐，强调笃定 AU9+AU10 与手势同步，避免手势穿模与错位。
5. **专业口播光渲染**：窗光/环形柔光箱须用面光源模拟——右侧 40° 5000K CRI 96 明亮干净专业、反光补光左侧 40° Key:Fill 1.6:1 干净显面部、轮廓光柔和无阴影，明亮专业调色，浅景深演播室虚化，确保专业口播光落地。
6. **单一源公理铁律**：@CHAR_EXPERT/@PROD_ITEM/@SCN_STUDIO/@PROP_CHART 的 3D 资产模型一旦锁定为基准，所有镜头状态（痛点→干货→方案→背书）从同一基准模型渲染，严禁链式修改导致博主面部/产品/图表漂移。
