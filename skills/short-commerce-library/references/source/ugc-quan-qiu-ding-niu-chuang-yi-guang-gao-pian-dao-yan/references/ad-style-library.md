# 🎬 创意广告风格库（Ad Style Library）

> 本库把"抽象风格词"翻译成**可执行的光学/色彩/节奏配方**，供广告片导演在 Seedance 2.5（或同类图生视频模型）中直接落地。每种风格先答"服务哪个品牌情绪前提"，再选配方；**不为炫技而展示**，风格必须服务于产品/品牌传达。

---

## 1 · 泰国无厘头（Thai Absurd / Deadpan Surreal）

- **情绪前提**：用反差荒诞制造记忆点，让人"笑着记住"——适合保险、旅游、公益、日用爆品。
- **视觉配方**
  - 镜头：大量固定中景 + 偶尔轻微手持；不炫技，让荒诞来自"表演与情境"而非运镜。
  - 光影：自然光 / 平价白炽灯，暖调日常，拒绝高级感滤镜。
  - 色彩：高饱和但偏"生活脏色"（橙黄墙、绿植、塑料感），不统一调色。
  - 颗粒：轻微 35mm 粗颗粒，保留市井质感。
- **节奏**：冷面幽默——前一秒正常、后一秒反转；剪辑点卡在"意料之外"而非节拍器。
- **声音**：环境原声 + 突然静音（j cut）→ 旁白/泰式小调；**字幕禁用**（见同步声锁），台词走配音。
- **禁忌**：别用慢镜抒情、别上电影级打光——那会毁掉"平民荒诞感"。

## 2 · 复古胶片（Retro Film / 35mm Emulation）

- **情绪前提**：怀旧、温度、时间沉淀——适合老字号、酒类、情怀品牌、年代叙事。
- **视觉配方**
  - 镜头：缓慢推轨 / 温柔横摇；多用 40–58mm 标准镜，避免广角畸变。
  - 光影：窗光 / 钨丝灯，明显方向性；高光溢出（halation）为核心标志。
  - 色彩：褪色暖调或橙青分离；Kodak 2383 / 5207 模拟；暗部偏青、亮部偏橙。
  - 颗粒：细到中颗粒均匀铺满，边缘暗角（vignette）。
- **节奏**：抒情慢，给颗粒和光晕呼吸空间；长镜头优先。
- **声音**：磁带底噪 / 黑胶 crackle；配乐用复古乐器（钢琴、弦乐、Analog 合成）。
- **禁忌**：锐利数字感、死黑、霓虹高饱和——立刻出戏。

## 3 · 宝矿力导演（Pocari Sweat / Azure Youth）

- **情绪前提**：青春、汗水、微甜怅惘的"蓝色治愈"——适合饮料、运动、校园、年轻化品牌。
- **视觉配方**
  - 镜头：漂浮感运镜（缓慢上升 / 轻摇），柔焦高键；多天空、逆光发丝光。
  - 光影：高键光，天光为主，阴影干净；阳光透射感强。
  - 色彩：天蓝 `#5BC8E8` + 纯白 + 暖肤色；整体通透，低对比但亮。
  - 颗粒：几乎无颗粒，干净电影感。
- **节奏**：抒情诗意，慢切；给"汗水特写 + 仰头喝"留足时间。
- **声音**：温柔钢琴 / 轻弦乐 + 环境（风、球场、蝉鸣）；人声旁白清澈少年音。
- **禁忌**：暗黑、噪点、重口味调色——破坏"清爽治愈"。

## 4 · 极简 Apple 风（Minimal Product Hero）

- **情绪前提**：高级、克制、产品即主角——适合 3C、美妆、设计品。
- **视觉配方**
  - 镜头：锁定机位 + 微距；缓慢推近产品，负空间大。
  - 光影：柔光箱均匀打光，无硬影；产品边缘光勾边。
  - 色彩：白 / 浅灰背景 + 产品本色点缀；低饱和。
  - 颗粒：无。
- **节奏**：极慢、平滑；一个动作一镜。
- **声音**：极简环境 + 一声清脆反馈音（如开盖）。
- **禁忌**：杂乱背景、快剪、夸张调色。

## 5 · 快剪潮牌（Fast-Cut Hype / Street）

- **情绪前提**：能量、态度、潮——适合球鞋、服饰、夜店、青年文化。
- **视觉配方**
  - 镜头：whip pan、snap zoom、手持抖動；低角。
  - 光影：霓虹 / 硬闪光；高对比。
  - 色彩：霓虹青品红 + 黑；glitch 偶尔。
  - 颗粒：中粗，故意粗糙。
- **节奏**：0.5–1s 一剪，鼓点卡点。
- **声音**：重低音 trap / phonk + 环境 city 噪。
- **禁忌**：慢、干净、文艺。

## 6 · 赛博朋克（Cyberpunk）

- **情绪前提**：未来、冷酷科技、张力——适合科技、汽车、游戏、数码。
- **视觉配方**
  - 镜头：低角 + Dutch 角；缓慢环绕。
  - 光影：霓虹反射、体积雾、雨水高光。
  - 色彩：青 `#00E5FF` × 品红 `#FF00AA`；暗调。
  - 颗粒：细颗粒 + 扫描线可选。
- **节奏**：中速，蓄力感。
- **声音**：合成器 bass + 雨声 + 电子 glitch。
- **禁忌**：暖调田园、自然光主导。

## 7 · 黑白文艺（B&W Auteur）

- **情绪前提**：深沉、作者感、高级叙事——适合奢侈品、艺术联名、品牌精神片。
- **视觉配方**
  - 镜头：固定长镜头；框内构图极讲究。
  - 光影：chiaroscuro 明暗对比；单一硬光源。
  - 色彩：纯黑白，高反差。
  - 颗粒：中颗粒，电影黑白质感。
- **节奏**：极慢，留白。
- **声音**：钢琴 / 大提琴独奏，极简。
- **禁忌**：彩色、花哨运镜、快剪。

## 8 · 国风（Chinese Ink / 东方）

- **情绪前提**：东方意境、文化自信——适合茶、酒、文旅、国货。
- **视觉配方**
  - 镜头：摇臂缓升、横移长卷；多用留白构图。
  - 光影：柔光，晨雾感。
  - 色彩：水墨灰 + 朱砂红点缀；低饱和。
  - 颗粒：极细，宣纸质感可选。
- **节奏**：舒缓，似卷轴展开。
- **声音**：古琴 / 笛 + 环境（风、水）。
- **禁忌**：西式打光、高饱和撞色。

## 9 · 日系小清新（Japanese Soft / 弱饱和）

- **情绪前提**：温柔、日常治愈——适合护肤、家居、食品。
- **视觉配方**：柔光、弱饱和、高键、微晕；慢摇；钢琴/原声吉他。禁忌：重对比、噪点。

## 10 · 美式幽默（US Quirky / 快笑）

- **情绪前提**：机智、夸张、爽快——适合快餐、APP、日用品。
- **视觉配方**：明亮布光、中饱和、稳定中景 + 夸张特写；快剪 + 罐头笑料音；禁忌：沉闷文艺。

## 选用铁律
- **每支广告先定"品牌情绪前提"再选风格**，风格与前提冲突时改风格。
- 一支片**主风格 ≤ 1**，可加 1 个辅风格做转场/反差，禁止三风格混战。
- 所有视觉配方需配合 [references/15-director-shot-library.md](references/15-director-shot-library.md) 的镜头语法与 [references/03-cinedance-camera-optics.md](references/03-cinedance-camera-optics.md) 的 14 区块骨架落地。
- **同步声锁**：所有风格视频默认不生成字幕、不生成背景音乐（见 SKILL.md「⛔ 同步声锁」）；配乐仅用户显式要求才加，且由后期处理。
