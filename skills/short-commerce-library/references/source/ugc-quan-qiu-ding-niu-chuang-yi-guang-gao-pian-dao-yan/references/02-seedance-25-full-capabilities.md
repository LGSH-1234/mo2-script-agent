# 02-Seedance 2.5 全量模型能力手册 (Full Capabilities Manual)

> **归属模块**：字节跳动即梦 Seedance 2.5 官方模型全能指南  
> **核心突破**：相较于 2.0 版本，2.5 实现了“更长、更真、更听话”的全方位跨越，支持 180 秒超长视频直接生成、前后续写扩展、全模态 @引用绑定、BGM 无损分离、多人独立锁定与局部精准编辑。

## 一、 输入参数与软硬件限制字典 (Input Parameters & Technical Specs)

| 模态 / 参数类型 | 限制条件与格式要求 | 核心最佳实践法则 |
|---|---|---|
| **参考图片 (Images)** | - 单次最多上传 **30 张** (4K 分辨率以内)<br>- 格式：`jpeg, png, webp, bmp, tiff, gif, heic, heif`<br>- 宽高比范围：`[0.4, 2.5]`，单张大小 `< 30MB` | 1-5 主体效果最佳；多角色多角度建议使用**分图多视角资产图**（每视角单独一张图，禁止单图拼贴；无头全身照用取景框裁切语言，详见 `references/05` §二）而非上传 30 张散图 |
| **参考视频 (Videos)** | - 单次最多上传 **10 段**，总时长 **≤ 30 秒**<br>- 格式：`mp4, mov`；分辨率：480p-4K；FPS：24-60<br>- 单个视频时长：`[1.8s, 30.2s]` | 3D 白模或动作参考建议使用 10-20s 原原生高帧率视频 |
| **参考音频 (Audios)** | - 单次最多上传 **10 段**，总时长 **≤ 30 秒**<br>- 格式：`wav, mp3`；单文件 `< 15MB`<br>- **支持仅传音频驱动生成 (R2V 链路放开)** | 提供 24kHz 干净人声/音效，提示词中结合时间戳精准卡点 |
| **生成时长与分辨率** | - 单次普通生成：`4 - 30 秒` (即 `97 - 721 帧`)<br>- 输出分辨率：`480p, 720p+`<br>- **超长视频模式**：可直接生成 `30 秒 - 180 秒` | 长视频建议开启“超长视频模式”或采用多次“视频延长” |

## 二、 核心功能交互与提示词语法

### 1. 全模态 @ 引用语法 (Multimodal @ Syntax)
在提示词中，使用 `@` 符号精确锚定上传的素材：
- `@图片1`, `@图片2` ... 定向绑定角色五官、场景背景、道具材质。
- `@视频1`, `@视频2` ... 定向绑定 3D 白模运镜、人物走位、动作路线。
- `@音频1`, `@音频2` ... 定向绑定台词声线、动作音效、卡点节奏。

### 2. 时间戳文本控制 (Timestamp Prompt Control)
采用分秒语法精准锁定画面的发生时序：
```text
[00:00 - 00:03] 镜头一：全景镜头，@图片1角色站在雨夜江边。
[00:03 - 00:07] 镜头二：切至近景，角色微微抬头，一束冷蓝色光打在脸上。
[00:07 - 00:12] 镜头三：特写镜头，角色闭眼呼吸，雨滴从额头滑落。
```

## 三、 Seedance 2.5 8 大核心新特性深度详解

### 1. 🎵 分离 / 移除背景音乐 (BGM Isolation & Removal)
- **突破性能力**：以往视频自带配乐时，AI 往往无法剥离。Seedance 2.5 可精准解析音频轨，在**完全保留原视频图像、字幕与人声对白**的前提下，一键擦除干扰 BGM。
- **经典提示词**：
  ```text
  去除@视频1中的背景音乐，保留清晰的人声对白。同时参考@图片1给视频加入阳光照进房间的效果，保持真实感与原字幕。
  ```

### 2. ✨ 迁移创意 (Creative Style Migration)
- **突破性能力**：不仅能复刻简单的运镜，更能抓取参考视频中的物理运动轨迹、叙事情绪、色彩风格与高爆款“网感排版/分屏”。
- **分屏科普经典提示词**：
  ```text
  生成一段竖屏 (9:16) 健身动作对比科普视频，采用上下分屏对比布局，严格保留@视频1 中的 "正确动作" 和 "错误动作" 两套动作时序。对@视频1 进行渲染：上半屏角色参考@图片1，执行错误动作；下半屏角色参考@图片2，执行正确动作。
  ```

### 3. ✂️ 局部消除与高级编辑 (Inpainting & Erasing)
- **交互方式**：上传视频后，唤醒「高级编辑」模式，使用框选、画笔或标记工具对特定区域打上标签。
- **编辑公式**：`[标记位置/对象] + [修改动作] + [目标形态/去除]`
- **经典提示词**：
  ```text
  消除@视频1 中圈选标记的背景杂人物与水印。保留主体@图片1 角色，将背景环境平滑补全为干净的雪山废墟。
  ```

### 4. 🎥 空间视角修改 (3D Spatial View Modification)
- **突破性能力**：具备强悍的三维空间推理能力。上传一段平视视角视频，可通过 Prompt 直接指令模型切换为高空俯拍或俯角拉远，AI 能够合理补全未呈现的顶视/侧视视角空间。
- **经典提示词**：
  ```text
  参考@视频1 的人物走位，镜头从平视角度急速向上拉远升空，切为 90 度高空垂直俯拍视角，展现人物在巨大迷宫中的渺小走位。
  ```

### 5. 👥 多人参考升级 (Multi-Character Independent Lock)
- **突破性能力**：解决 2.0 时代多角色同框时“串脸（长相趋同）”、“穿错衣服”与“肢体交叠变怪兽”的沉重痛点。模型能够将输入的不同人物展板与空间中的特定个体做 **1:1 独立硬绑定**。
- **多人混战经典提示词**：
  ```text
  @图片1 的光头拳手、@图片2 的红发女格斗家、@图片3 的亚裔搏击手，在@图片4 场景内三方混战。三位角色外貌、服装、体型严格独立保持，互相不串脸。开场三人呈三角站位短暂对峙，随后@图片1 率先冲向@图片2 打出重拳，@图片2 侧身闪避，动作交错爆发。
  ```

### 6. 🟩 无缝绿幕编辑 (Green Screen Compositing)
- **突破性能力**：工业级前景与背景抠像分离，彻底消除边缘绿边溢色、发丝残影与环境光影不匹配。
- **经典提示词**：
  ```text
  将@视频1 中的绿幕主体无缝融合到@图片1 的暴风雪废墟场景中，根据场景调整角色的逆光受光与脚下雪地接触阴影。
  ```

### 7. 🕒 视频延长 (Video Extension & 180s Super Long Generation)
- **两种使用模式**：
  - **模式 A (超长视频直接生成)**：在即梦界面勾选「超长视频」，直接拉取 `30s - 180s` 时间轴生成。
  - **模式 B (视频延长/套娃延长)**：基于已生成的 30s 视频，输入“向前延长”或“向后延长”，单次延长 4-30s，可多次追加延长至 60s+。
- **一镜到底延长提示词**：
  ```text
  参考视频1的内容向后延长 5 秒。要求延长自然、动作衔接流畅，一镜到底，禁止生硬切镜，禁止物体凭空出现。角色继续向前行走并微微抬头。
  ```
- **切镜转场延长提示词**：
  ```text
  参考视频1的内容向后延长 5 秒。需要在切镜处使用“自然切镜”转场。镜头切至角色@图片1 的面部特写，一束晨光打在脸颊上，眼神表现为醒悟。
  ```

### 8. 🎞️ 多宫格分镜 (Multi-Grid Storyboard Input)
- **突破性能力**：支持上传手绘制片分镜、九宫格草图或火柴人线稿。Seedance 2.5 会逐格解析分镜图的景别与动作，在 Prompt 引导下一次性渲染出连续流畅的电影视频。
- **多宫格提示词**：
  ```text
  @图片1 为 9 宫格完整电影分镜脚本。每个宫格代表一个连续镜头。
  男孩参考@图片2，生日蛋糕参考@图片3。
  镜头 1（0-2s）：全景固定镜头，男孩坐在桌前。
  镜头 2（2-4s）：中景镜头，男孩看着蛋糕。
  镜头 3（4-6s）：近景特写，蜡烛火苗摇曳。
  ...全程色调温馨，生成一段连贯的生日记录视频。
  ```

## 四、 核心报错与避坑指南 (Failure Prevention Rules)

1. **防止画质崩坏与失真**：
   - 避免在 Prompt 中同时写入过多无意义的修饰词（如“超级无敌好看”、“神级大片”）。必须使用具象的物理光影与焦段描述。
2. **防止多人串脸**：
   - 上传角色图时，确保每位角色的**特征、服装、发色有强烈的视觉反差**；Prompt 中显式指定 `人物 A 参考@图片1，人物 B 参考@图片2，两人保持各自独立外貌，严禁特征混合`。
3. **防止延长切镜撕裂**：
   - 一镜到底延长时，务必包含约束词：`动作衔接自然、保持镜头呼吸感、禁止物体凭空出现`。
4. **⛔ 白模参考视频必须单段完整生成（最高优先级）**：
   - 当以白模参考视频（@视频1）作为生成锚点时，成片必须为**一个完整连续视频**，单次生成、整段输出。
   - **严禁**将白模视频按分镜/时间段切割为多个片段分别生成再拼接——会破坏运镜轨迹、空间遮挡与动作因果链，拼接处必然跳轴/穿模/动作突变。
   - 提示词内的**时间戳/时间段标注（如 0-7s、7-14s）仅用于描述材质与光影变化，绝不构成切分生成指令**；整条提示词只对应一次完整生成。
