# 15-名导演镜头技法库（前提优先 · 不为炫技）

> **归属**：Seedance 2.5 专属版镜头语言增强层
> **核心纪律**：每种名导演镜头是"情绪语法"而非装饰。落笔前必须能答"服务哪个剧情前提/爽点/钩子"，答不出即禁用。所有技法在 Seedance 2.5 中执行，竖屏(9:16)重译。
> **与 CINEDANCE 镜头系统关系**：本库是 [references/03-cinedance-camera-optics.md](03-cinedance-camera-optics.md) 的"作者化"补充——CINEDANCE 管 FOV/轴线/首帧/防漂移，本库管"用哪位大师的语法来讲这场戏"。

---

## 一、选用纪律（前提优先 · 不为炫技）

1. **前提匹配三问**（每镜动笔前必答）：
   - 这场戏的**剧情前提**是什么？（身份反转 / 英雄觉醒 / 关系裂痕 / 时空失控…）
   - 这个镜头语法能否**只服务于这一个前提**？
   - 换成普通推拉摇移是否就讲不清楚？——若普通镜头也行，则不用名导技法（不为炫技）。
2. **稀有性原则**：同一技法全片 ≤1–2 次；越稀有越有力。滥用 = 消解冲击力。
3. **竖屏重译铁律**（9:16）：
   - 人物占画幅 ≥60%，保证手机端情绪可读。
   - 大幅度环绕/大远景收敛为**小幅弧移/中近景**，避免主体过小。
   - 希区柯克变焦在竖屏改为**纵轴压缩感**（人物不动、背景透视剧变），而非横轴广角拉伸。
4. **绝不炫技展示**：技法若让观众"注意到镜头"而非"沉浸故事"，即失败。

## 三、组合与降级

- **前提叠加**：一场戏可同时用 2 种（如 斯皮尔伯格推镜 + 罗杰·狄金斯逆光），但必须都服务于同一前提。
- **降级到 CINEDANCE 基础**：若名导技法前提不成立，退回 [references/03](03-cinedance-camera-optics.md) 的 FOV/轴线/首帧/防漂移基础语法——把"讲故事"交给普通镜头。
- **质量门核对**：生成后按 [SKILL.md 奥斯卡审判门] 与 [references/0822-master-deep-enhancement.md] 消除AI感10法则验收；名导技法不得引入塑料感/穿帮。
