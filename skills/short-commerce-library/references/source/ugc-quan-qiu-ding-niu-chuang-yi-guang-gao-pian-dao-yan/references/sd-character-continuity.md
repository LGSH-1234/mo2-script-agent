# 角色连续性（资产锁定系统）· references/06

> **核心原则（R3 资产先于分镜）**：视频模型没有记忆，一致性靠提示词工程造出来。
> 角色/场景/道具进分镜前，必须先提炼 3–5 项锁定特征、分配 @ID、建三图角色卡、过十连压力测试。
> 本文件给出资产定义、三图角色卡、选脸标准、局部换装蒙版、十连测试、音色/表演基线锁定、
> 状态即资产、场景卡 3/4 视角、GEO 空间地图、@引用命名规范。吸收自 CINEDANCE 资产系统（同源）。
> 所有资产须达到**全员演技在线 · 超越真人感顶级质感 · 电影级别**（见 SKILL §10A）。

---

## 一、资产定义

```
一个资产 = descriptor(文字) + reference image(参考图)。两者缺一不可：
 · descriptor 是这个角色/地点的完整书面描述，后面每一条正式镜头提示词都要一字不差写进去。
 · 参考图是模型视觉锚点，但图片解决不了全部——模型仍需要文字反复"提醒"这是谁/这是哪。
 · 只有图没稳定文字 → 措辞每次换着写，一致性照样漂；只有文字没图 → 模型无锚点可贴。
```

---

## 二、三图角色卡（去头全身是关键）

```
角色卡固定三张图：
 1. 面部特写(close-up)          —— 脸的唯一来源
 2. 正面全身(full body, front)  —— 故意【不带头】
 3. 背面全身(full body, back)

去头原因（实测）：宽镜头里模型爱从全身小图取脸，而这张图脸小又糊 → 主角"换脸"。
去掉头后，模型取脸只剩特写一个来源，单独修复一整类翻车。
```

**选脸标准**：
```
 · 选"最可信"不是"最好看"的一版——"好看但假"的脸，视频里假得更明显且来不及改。
 · 瞳孔必须有 catch-light（高光）：没有高光的脸在静帧是"死"的，任何视频模型都演不出真实表演。
 · 模型理解最好的构图：大幅 3/4 侧脸肖像（脸微转开，不正对镜头）。
```

**建卡刻意"无聊"**：
```
 · 中性灰背景、平光、真实可见毛孔、不磨皮。
 · 电影感不属于角色卡——属于场景卡和正式提示词。过早把胶片颗粒/运镜感烤进角色卡，
   角色会带着这层"皮"走进每场戏，不再对新光线真实反应（像贴上去的）。
```

**局部变化（换装/伤口/血迹）蒙版工作流**：
```
 1. 在图像模型里基于【原始角色卡】生成局部改动（新外套/伤疤/血迹）。
 2. 用支持蒙版的编辑器，把改动【只贴回原图那一小块区域】，其余原封不动 → 皮肤纹理原样保留。
 规则：一张图永不完整过模型两次——每多过一次，纹理塌一次、变塑料无生气，拖累视频表演。
```

## 三、十连压力测试（资产上线前必过）

```
 · 不同姿势/不同光线跑十次生成，十次都能认出同一角色/地点。
 · 不只单独测——还要和其他资产同框测、放进真实场景光线里测（单独稳的常一同框/一进光就崩）。
 · 测试不过 → 问题在文字描述，不在模型。回去重写 descriptor 再测，不怪模型不将就。
```

## 四、音色锁定（写死文字，非图像资产）

```
写对白前先锁每个主角音色：音域/语速/口音/说话方式。原样粘贴进每次开口的 AUDIO 段，不再改。
例：Voice: deep, gravelly bass-baritone; slow, calculated pacing; London street accent; menacing calm — he never raises his voice.
同测外貌一样测音色会不会漂移；漂移=措辞不够硬，回去改词加固。
```

## 五、表演基线（"全员演技在线"的物理层）

```
每个有戏份角色写一段 behavior profile：怎么走路、手习惯忙什么、什么小动作、眼神怎么动、压力下怎么崩溃。
这段是"人设事实来源"——每镜按当下姿势/动作适配它，核心不变。
当某习惯这一镜物理上做不到（踱步的人这镜坐着）→ 把能量转移到别的动作（摇晃/手指敲/断续手势），不删除。
配合 references/04 的微动作规则：每 1–2s 一个可见微事件（呼吸/鼻翼/眉），分阶段眨眼，INNER 内心独白。
→ 这正是"全员演技在线"的落地：即便是反派/群演，也按 DNA 写表演基线，禁止站桩念台词。
```

## 六、状态即资产（杜绝"混合漂移"）

```
湿身/带伤/换装 = 三个不同资产：@CharID / @CharID_wet / @CharID_blood，各自独立 descriptor。
 · 多个状态混进同一段文字 → 模型在不同镜头自己混合这些状态（翻车根源）。
 · 拆开写比跟模型打架便宜得多。场景同理：白天/夜晚/雨天 = 三张不同场景卡。
 · 道具同理：关键神器有"完整版/沾血小版/隐藏版"各自 descriptor。
```

## 七、场景卡（为将来机位而生）

```
 · 用 3/4 视角拍，不要正面"美照"——正面图在宽镜变平面壁纸，超出边缘模型就现编。
   3/4 视角给深度信息，覆盖近乎一整圈机位。
 · 留一个锚点物件（柱子/灯/沙发），调度绑在它上："靠灯边面朝门"比"在房间里"精确。
 · 锁死一套光线逻辑：一个光源、一个阴影方向，绝不两个"太阳"——否则每新角度重发明打光。
反打（场景另一侧）两法：
 1. 直接生成同房间另一角落，匹配原图焦外柔化。
 2. 生成一段摄影机缓穿空场地的视频，截图所需角度精修材质光线——一张原图长出一整套场景卡。
```

## 八、@引用命名 + 继承禁令（喂给视频模型时必做）

```
 · 必须在提示词里点名每个引用扮演什么角色，否则模型自己猜（常把构图当脸、脸当配色）：
   @CharID for character reference   @SceneID for location reference
 · 场景引用额外加继承禁令：
   do not use as a starting frame, do not inherit the composition, the angle or the color — take only the space and the texture.
 · 所有资产统一 @标签 管理，文档/提示词/界面同一套名字，不出现同名不同叫。
```

## 九、GEO SPATIAL LAYOUT（治好"人物瞬移/跳轴"）

```
一份【纯空间地图】：地标物在哪、什么在左/右、摄影机站哪侧、绝不跨哪条 180° 轴。
不含人物和动作——只有地方本身。一场戏只写一次，原样贴进每镜提示词。
方位只从摄影机视角写（frame-left/frame-right），不用"在他左边"；位置用地标+米数（"祭坛旁 3 米"）。
配套【第一秒定妆规则】：每场戏开场留 1s 不写台词不写动作，让模型把站位/光"拍"下来并在后续保持；
回应的镜可把上一条台词尾音喂进这 1s，两段素材在剪辑点严丝合缝粘住。
```

**空白模板**：
```
GEO SPATIAL LAYOUT (locked across every shot — pure spatial map):
— [地标A] = [是什么、位置].
— [地标B]: [相对A方位, MID-RIGHT], ~[X]m from [A].
— 180° AXIS: camera ALWAYS stays on the [某侧] side — it NEVER crosses the line.
— [光线]: [类型] comes from [方向], [画面效果].
```

## 十、写新资产建卡提示词顺序（无范例时套用）

```
1. 主体：身份/功能，不写年龄，用衣着/职业/动作代替。
2. 构图：角色卡写 "close-up / full body front, headless / full body back"；场景卡写 "3/4 view, not frontal"。
3. 背景光（角色卡）：中性灰、平光、无修饰。
4. 材质：真实毛孔/非对称痣/自然肤色不均；场景写墙面地面材质与磨损。
5. 催生多版：选"可信非好看"一版，查瞳孔高光。
6. 禁止：不磨皮、不加电影颗粒、不加运镜感、不写年龄。
建完进十连压力测试；过则收进 @标签 库，进分镜阶段。
```

## 十一、竖屏注记 + 反模式

```
竖屏：脸占比大，catch-light/皮肤质感/色温一致更显眼；角色卡特写是"电影级真人感"的主力锚。
反模式：
 ❌ 全身带头的角色卡（宽镜取糊脸→换脸）
 ❌ 选"最好看"的脸（视频里更假）
 ❌ 无 catch-light（死脸演不了戏）
 ❌ 一张图整体过模型两次（塑料对称）
 ❌ 多状态混一段文字（混合漂移）
 ❌ 不给 GEO 地图（瞬移/跳轴）
 ❌ 写年龄数字（审核收紧）
```
