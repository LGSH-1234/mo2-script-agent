# 大师评审机制 + 质量门 · references/08

> **核心原则**：交付前必有独立审查与质量门。评审委员会以"诺兰十律 + 大众引力金线"为尺，
> 剪除一切可有可无，迭代出最具大众迷恋、零 AI 痕迹的终极方案。质量门用 12 项自检 + 五维评分兜底。
> 吸收自大师评审迭代系统（同源）与编剧分镜质量门。诚实边界：单模型内"审查"是结构化复核，非外部独立进程。

---

## 一、评审金线（不可妥协的依据）

**叙事深度金线（激活 ≥5 项）**：
```
1.时间迷宫 2.记忆骗局 3.身份迷失 4.归家执念 5.极端执念
6.虚实嵌套 7.牺牲交换 8.欺骗与魔术 9.父辈阴影与救赎 10.秩序与失控
```
**大众引力金线（必须全满足）**：
```
 · 前 3s 必须制造无法划走的心理真空（竖屏前 3s 给冲突/反转，见 references/02）。
 · 每 30s 必须锚定一处情感或好奇（爽点密度表兜底）。
 · 结尾必须留"陀螺仍在旋转"式余味与分享动机（结尾钩子 references/03）。
```

## 二、五环节闭环迭代（每环节 初审→优化→复评）

```
环节1 编剧与世界观：Hook 重铸("如果…那么…"高概念) / 世界观规则自带矛盾 / 主角欲望带自毁倾向 /
 诺兰基因标注 / 每场戏价值审问("删它情感或信息是否断裂？否→删")。
环节2 分镜必要性与剪辑：逐镜过"删除影响理解吗？"不影响则删 / 景别权力(全交代处境·特写传情绪·中景推进) /
 剪辑预埋(上下镜必有视觉动机) / 无声测试(关声能否叙事)。
环节3 提示词电影质感(去AI感)：AI污染清除(塑料皮/对称呆脸/无源荧光) / 物理灯光植入(主光位+辅光+色温+阴影硬) /
 镜头胶片参数化(Anamorphic/35mm/T2.8/Kodak 5219) / 构图叙事化(站位/视线/前景有心理依据) / 道具功能性。
环节4 声音人格与空间：声线身份卡(创伤/年龄/情绪定音质语速) / 潜台词演绎(重音/停顿/吞咽) /
 空间叙事(混响暗示孤独) / 音乐动机(3–5音,情感阀门开时进出)。
环节5 整体节奏与大众吸引终审：3s Hook 前置 / 节奏心电图(密后接呼吸镜) / 结尾余味(未回答问题/谜样道具/违预期微动作) /
 分享动机(只有我看懂的密码时刻/必讨论的反转)。
```
每环节输出"修改后的新版本 + 为什么更好"，未通过不进下一环节。

## 三、质量门 12 项自检清单

```
□ 1 叙事结构已落地为具体节拍点 + ≥1 创意颠覆技法 + 陈词滥调雷达核查过大纲？
□ 2 每核心角色有完整九维 DNA 与 300–600 字矛盾小传？记忆(M)/立场(P)已填？反派动机行为展示非独白？
□ 3 关键场次做过群智推演，无人设漂移/记忆越权/触发点错位？对白 Show-Don't-Tell、无直接情绪词？每场有进/出状态变化？
□ 4 核心角色/场景已锁定特征+分配 @ID，过用户确认才进分镜？剧本每块原文已入原文落实表(Coverage)？
□ 5 每镜提示词：三件套+情绪转译+瑕疵≥3 跨2类+前中后三层？每个可见主体有 @引用，清单与正文双重呈现？
□ 6 相邻镜头逐对过六维衔接（覆盖率=镜头数-1）？全篇无"同上/略"？台词字幕完整精确？可独立成立？
□ 7 每集 ≥3 爽点（小爽×2+大爽×1）且爽点密度表已建？余波镜存在？
□ 8 单集结尾 1–3 镜必落钩子（悬念/身份/反转/情感/利益之一）？钩子有视听载体+余震？
□ 9 全员演技在线：每个有戏份角色有表演基线+微动作+INNER？无站桩念台词？
□10 超越真人感：catch-light/毛孔/布料织法/有机颗粒具备？负向词禁 plastic/wax/airbrushed？
□11 电影级别：Style Prefix 锁定并逐字复制？跨镜色温/光位/色板一致？无滤镜堆高级感？
□12 每项产物标注 owner + 六状态之一？改动说明影响下游？无占位/无换脸漂移？
```

**五维评分门槛**（任一项不达标不交付）：
```
故事完整度 ≥9.5   物理精确度 ≥9.0   资产一致性 10.0   镜头丝滑度 10.0   结构效率 10.0
```

**修复动作表**：
```
抽象词→转译光学参数   @引用缺失→补清单+正文双重呈现   衔接缺失→补六维逐对
资产浮动→锁定特征回正并排查所有引用镜   瑕疵不足→补≥3 跨2类
占位→替换完整精确内容   覆盖缺失→补原文落实表对账   人设漂移→回 DNA 修订
无钩→补结尾钩子   演技僵→补表演基线+微动作   AI味→清塑料皮/对称脸/无源荧光
```

## 四、独立审查机制（交付把关）

```
审查范围：story_script / assets_continuity / storyboard_keyframes / video_prompts / full_episode
流程：
 1. 先跑结构校验（可证明事实）：块ID可解析、引用可追踪、六状态无矛盾、覆盖表与镜头表对账。
 2. 带证据审查内容：每个 finding 含 可定位段落/镜 + 短引文 + 对观众/制作影响 + 必须达到的修订 + owner + 严重程度。
 3. 跨层综合：守剧本原意与连续性（剧本事实→资产→镜头目的/边界→关键帧→动作→下一状态）。
 4. 给 verdict：APPROVE(无阻断) / APPROVE_WITH_NOTES(仅不阻断改进) / REVISE(结构/内容/限制冲突) / PROVISIONAL(输入不足暂无法判)。
 5. 按 owner 分派修订；复审需新明确请求，本轮不自动进。
严重程度：fatal(不安全/非公开) / error(阻断结构或内容错) / warning(有具体影响常用法问题) / note(不阻断润色)。
硬规则：没有证据不打分；不能只说"AI 味"——必须定位重复手法/套话模式并解释它伤害什么。
```

## 五、有界验证（治理硬顶）

```
revision ≤3 次/环节   send_back ≤3 次/环节   咨询式建议 ≤2 轮
超限 → 强制输出当前最优 + 标注待优化点 + 通知用户。
一次构建完整 → 批量自检一轮 → 一次性修好全部 → 最多一轮确认 → 停止打磨。
```

## 六、评审反模式

```
❌ 只说"有点 AI 味"无定位（须指具体手法）
❌ 五维任一项不达标仍交付
❌ 单集无钩子过审（R8）
❌ 反派结局独白洗白过审
❌ 资产未锁定就进分镜（最贵错误）
❌ 超限死磨单镜不简化结构
```
