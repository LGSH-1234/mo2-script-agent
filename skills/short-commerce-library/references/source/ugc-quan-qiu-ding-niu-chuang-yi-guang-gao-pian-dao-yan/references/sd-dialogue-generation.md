# 对白生成 · references/04

> **核心原则**：短剧对白不是"把情绪说出来"，而是"用最少的字，撬最大的爽感/悬念"。
> 本文件给出 Show-Don't-Tell 对白法则、爽感台词公式、分类型对白范式、台词构建原子公式、
> 以及"全员演技在线"在声音层的落实（声线卡/潜台词/微停顿）。吸收自 CINEDANCE 表演体系（references 同源），
> 专为短剧高频兑付重译。

---

## 一、Show-Don't-Tell（对白层）

```
禁止："{我很生气}" "{我好难过}" "{我爱你}" 这类直接情绪词——模型会演得很浅。
正确：用"事实/动作/潜台词"承载情绪，让爽感从对比中长出来。
法则：一句好对白 = 说出来的(表层) + 没说出来的(潜台词 INNER) + 同时发生的动作。
```

**三件事（对白分生死）**：
1. 反应在对方话完**前**就开始（脸先动，嘴后动）——接话才有"活人感"。
2. 情绪不瞬关：上一刻的颤/喘/红眼，余波延续进下一句（剪辑点粘合关键）。
3. 手一直忙别的事：他不是在"念台词"，是在整理/倒水/数钱，说话是顺便；他**停下手里那件事**的瞬间，才是重音。

## 二、爽感台词公式（四种爆款句式）

```
① 事实打脸（女频/男频通用）：用具体事实替代争吵
   反派："就你？也配？"  主角(不抬眼)："{这位置，三年前就是我设计的。}"
   → 爽点来自"事实碾压"，不吵不喊。

② 慢半拍气压（男频/狼人）：平静但延迟的支配感
   反派："穷鬼滚。"  主角(放下茶杯)："{从今天起，你家公司归我管。}"
   → 语速不变、气压骤升，比吼更有压迫。

③ 短句爆破（仙侠/动作）：等级/代价碾压，字少力沉
   反派："废物挑战我？"  主角(掌心浮光)："{三级，够杀你了。}"
   → 不超过 8 字，留白即爽。

④ 嘴硬动作诚（甜宠）：说的不算，做的才算
   他(塞她手进口袋不看她)："{手这么凉，自己不知道？}"
   → 甜度来自动作与台词的错位。
```

**带货对白**：演示优先、利益点准、不喊"买"。
```
她(对镜崩溃)："{卡了一层粉，斑还是看得见。}"  ← 痛点具象
画外(平静)："{换这个，三秒贴住，游泳都不掉。}"  ← 利益点，不喊下单
```

## 三、台词构建原子公式（落到提示词 AUDIO 段）

```
顺序固定：音色与情绪描述 → 引号里原话 → 配套身体动作 → 面部反应。
硬规则：
 · 台词只出现在 AUDIO 段；ACTION TIMING 段一个字台词都不许有。
 · 每个角色只说引号里那句，一个字不多；未持台词者保持完全沉默。
 · "半笑"这类写成纯面部表情，不带声音（否则模型自加即兴台词/嗯啊）。
 · 生僻名给音译提示，否则模型读错毁整句。
 · 非中文台词先标语言+口音：{美式英语·低沉克制} "{You are mine to protect.}"
```

**声线卡（每人锁定，原样贴进每次开口）**：
```
Voice: deep, gravelly bass-baritone; slow, calculated pacing; London street accent; menacing calm — he never raises his voice.
```
声线漂移=措辞不够硬，回去改词加固（同测外貌十连）。

## 四、分类型对白范式（与 references/01 联动）

```
女频：克制反击流——少说、用事实、让反派自己露怯；高潮一句身份揭晓。
男频：气压支配流——平静、慢半拍、字少；爆发时用动作而非音量。
甜宠：错位甜流——嘴硬动作诚、潜台词比明话甜；禁止工业糖精尬白。
带货：演示利益流——痛点具象、利益点准、不喊买；限时信息走字幕钩。
狼人吸血鬼(海外)：低沉克制+兽性底噪；英文为主，潜台词是"危险又甜"。
穿越仙侠：等级碾压流——用"级数/血脉"短句爆破；禁止无代价升级废话。
```

**反派台词铁律**：动机通过行为展示，禁止结局独白洗白。反派狠话要"有代价地狠"
（他每句威胁都对应一个已发生的压迫行为），不是空喊。

## 五、INNER 内心独白（让脸活起来的隐形层）

```
每段动作配一行 INNER(unspoken)：写清此刻"在想什么、要什么"。
例（女主被羞辱时的 INNER）：
 INNER: 她在记第三笔账——等总监看到稿，这场羞辱连本带利还。
→ 观众读不到字，但能从她"指尖停顿+不抬眼"的微动作里感到"她在布局"，爽感预埋。
```

**微动作规则（静止镜也活）**：每 1–2s 一个可见微事件（呼吸起伏/鼻翼/眉绷又松）；
分阶段眨眼：慢眨→双连眨→用力重置眨。这是"全员演技在线"最便宜也最关键的信号。

## 六、对白反模式

```
❌ 直接情绪词（"我很生气/我爱你"）——演浅
❌ 解说性台词（"你知道吗，其实我从小……"）——信息倾销
❌ 工业糖精尬白（无动作承载的"我爱你"）
❌ 台词写进 ACTION TIMING 段——模型自加戏
❌ 未持台词者出声——破坏沉默张力
❌ 反派结局独白洗白——动机须行为贯穿
❌ 海外剧用中文腔英文——先锁语言+口音
```
