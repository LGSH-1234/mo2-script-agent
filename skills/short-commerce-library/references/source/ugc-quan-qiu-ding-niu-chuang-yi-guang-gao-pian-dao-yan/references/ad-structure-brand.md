# 🎯 广告片结构 & 品牌整合引擎（Ad Structure & Brand Integration）

> 广告不是"好看视频"，是"在限定时长内把品牌/产品塞进用户记忆"。本引擎定义时长结构、3 秒钩子、产品 Hero、品牌植入与验收标准，配合 [references/11-user-asset-logo-placement.md](references/11-user-asset-logo-placement.md) 落地 Logo/产品资产。

---

## 一 · 时长结构（按秒拆解）

| 时长 | 结构 | 要点 |
|---|---|---|
| **15s** | 1 钩子 + 1 产品 Hero + CTA | 不铺垫，前 3s 即冲突/利益点；产品占 ≥40% 时长 |
| **30s** | 三幕：钩子(0–3s) → 体感(4–22s) → Hero+CTA(23–30s) | 中段给"使用场景/情绪证据"，末段产品特写 + 口播 |
| **60s** | 故事弧：钩子 → 展开 → 转折 → 升华 → Hero+CTA | 可承载剧情广告 / 品牌精神片 |
| **90s+** | 微电影 / 品牌纪录片 | 叙事优先，品牌后置升华 |

## 二 · 3 秒钩子（Hook-in-3s）

必须在前 3 秒制造**模式中断 / 好奇缺口 / 情绪冲击**，否则划走：
- **模式中断**：反常识画面（如产品从天而降）、反常表演（泰国无厘头首选）。
- **好奇缺口**：抛问题 / 半截信息（"你知道为什么…？"）。
- **情绪冲击**：强视觉反差、突如其来的静音或重音。
- 钩子必须与品牌/产品后续呼应，禁止"为钩而钩"孤立噱头。

## 三 · 产品 Hero & 品牌整合

- **产品 Hero 镜头**：专属高光时刻（微距、逆光勾边、慢推），占末段核心；配合 [ref/03](references/03-cinedance-camera-optics.md) 光学语言与 [ref/15](references/15-director-shot-library.md) 镜头。
- **Logo 植入**：按 [ref/11](references/11-user-asset-logo-placement.md) 流程——载体/透视/绿幕/双重指定；建议末段定格 + Logo 浮现，自然不突兀。
- **口播 / CTA**：人声旁白或角色台词收尾（配音，非字幕）；CTA 明确（"立即体验 / 搜索 XXX"）。
- **品牌识别**：全片色彩 / 字体气质与品牌 VI 一致；用户资产（Logo/产品图/声音样本）走 `@Asset_IMG` / `@CharID_AUDIO` 引用，禁止凭空生成品牌元素。

## 四 · 广告类型

- **品牌片（情感/精神）**：60s+，情绪弧优先，品牌后置升华；适用 宝矿力/国风/黑白文艺。
- **带货片（转化）**：15–30s，利益点 + 产品 Hero + CTA 直给；适用 极简/快剪/泰国无厘头。
- **种草片**：30–60s，使用场景 + 真实感测评感；适用 日系小清新/复古。
- **剧情广告**：60s，用故事承载产品；适用 泰国无厘头/宝矿力/国风。

## 五 · 验收标准（广告专用质量门）

1. **前 3 秒有钩子**，且不与品牌脱节。
2. **产品 / Logo 清晰可辨**，无凭空品牌元素（用户资产引用正确）。
3. **信息 3 秒可读**：利益点 / 品牌名在 3 秒内被"听到或看到（后期字幕）"。
4. **CTA 明确**，时长内可达。
5. **风格统一**：主风格 ≤ 1 + 可选 1 辅，符合 [ad-style-library](references/ad-style-library.md)。
6. **同步声锁达标**：成片无内嵌字幕、无自带 BGM（除非用户显式要求）——见 SKILL.md「⛔ 同步声锁」。
7. 通用电影级铁律（资产一致 / 无漂移 / 无 AI Slop）照常适用（见 奥斯卡审判门）。

> 广告片 = **创意风格（ad-style-library）× 结构纪律（本引擎）× 通用影视能力（电影大师 + 叙事）**。三者缺一，不是好广告。
