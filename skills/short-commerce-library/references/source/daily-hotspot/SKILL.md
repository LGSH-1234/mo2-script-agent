# 每日热点信息收集

## 核心原则

- 必须使用工具 `pippit_omni_search` 进行搜索；不要凭模型记忆回答热点。
- 先明确时间窗口。用户未指定时，默认使用“最近 24 小时”，同时可补充“近 7 天持续热”的趋势。
- 先明确地区和平台。用户未指定时，按用户语言和业务场景默认中国区；
- 给结论时标注“检索时间”“时间窗口”“来源”。无法确认发布时间或热度指标时明确写“来源未公开精确时间/指标”。
- 不编造热度、播放量、排名、评论量、转发量。只有来源明确给出时才写具体数值；否则使用“多来源出现”“近期讨论升温”等弱表述。
- `pippit_omni_search` 搜索热点有两个方式：
  - SearchType = text 为通用web搜索，搜索最近热点时请携带需要的日期 ：例如query = 2026年7月27日 洗衣机相关热点事件
  - SearchType = douyin_video 为抖音视频搜索，可以实时根据抖音搜索引擎搜索到现在的视频。例如query = 洗面奶 花西子洗面奶。
  - SearchType = hotspot为抖音热点搜索，可以持续搜索到抖音当前的热点视频：例如query = 吸尘器营销 小米吸尘器
- 抖音热点与抖音视频的区别：抖音热点为当前的热点query，抖音视频为实际在抖音搜索引擎里搜索，一些小众商品视频很难成为抖音热点，但是有抖音视频，搜索时应该兼具抖音视频与抖音热点搜索。

## 工作流

1. 识别用户目标：
   - 热点信息：新闻、社会、娱乐、体育、财经、科技、消费、旅游、本地事件，品牌营销等。
   - 热点视频：短视频选题、爆款视频、热门模板、热梗、拍摄角度、账号内容趋势等。
   - 创作选题：把热点转成可执行的内容方向、标题、脚本或素材建议。
2. 设定查询计划：
   - 无行业限制时，按“全网热点 + 与用户业务相关热点”两层收集。
   - 有行业/地域/平台时，优先围绕该限定条件查找。
   - 至少交叉查看 2 类来源；单来源结果只能作为线索，不直接当作“全网热点”。
3. 执行实时检索：
   - 必须使用 SearchType = text 和 hotspot 还有 douyin_video 三个方式多输入源进行广泛搜索，综合参考选择最符合用户意向的展示给用户。
   - 推荐进行渐进式搜索，比如先通过SearchType = text 搜索到相关热点信息，再通过 SearchType = text 和  对每个热点信息做精细化搜索，建议多轮搜索效果最佳。最少进行4轮搜索，多轮效果最佳。
   - 如果是偏营销场景的，比如吸尘器，面膜，化妆品等，搜索热点时建议多用 SearchType =hotspot 和 SearchType = douyin_video 进行抖音热点视频搜索，这些抖音热点视频对商家非常有用，后续可以根据商家的商品走复刻链路，一定要多搜集些商品信息。
4. 过滤与排序：
   - 去掉旧闻翻炒、纯广告、来源不明、低可信二次搬运。
   - 优先保留：发布时间近、跨平台出现、互动数据明确、与用户创作/业务目标相关、可转化成内容选题的热点。
5. 输出结构化结果：
   - 热点标题
   - 发生/发布时间
   - 热度依据
   - 为什么值得关注
   - 可执行建议（如果用户有创作/运营意图/商品）

## 推荐输出

- [IMPORTANT]使用Markdown输出到相关md文件中推送给用户。

### 热点信息

使用这类结构写入Markdown文件中

```text
检索时间：YYYY-MM-DD HH:mm
时间窗口：最近 24 小时/最近7天/最近一个月
范围：中国区 / 指定平台或行业

1. 热点标题
   时间：...
   来源：...
   热度依据：...
   关注原因：...
   可用方向：...
```

### 热点/抖音视频

使用这类结构：

```text
检索时间：YYYY-MM-DD HH:mm
时间窗口：最近 24 小时/最近7天
平台范围：抖音

1. 视频/话题标题
   平台/来源：...
   发布时间：...
   抖音链接(如果有必填)：...
   热度依据：...
   内容拆解：题材 / 结构 / 视觉钩子 / 情绪点
   可复用创作角度：...
```

## 创作转化

当用户是为了 Agent 内容生产、营销选题或视频生成而收集热点时，在热点列表后补一段“可执行选题”：

- 推荐优先级：给 6 个最值得做的方向，说明选择理由。
- 内容角度：给标题、开头钩子、画面元素、素材关键词。
- 风险提示：标出敏感、争议、版权、事实未确认或时效过短的内容。
- 抖音热点链接：给3个热度最高并且相关的视频。

## 结果引导

- [IMPORTANT]热点结果给到用户后可以发送问卷，**必须**调用`dynamic_questionnaire`工具询问用户是否要创建一个每日定时任务执行，或者是否要开始创作，或者创建定时任务并开始创作。
    1. 如果用户选择创建一个每日任务定时执行，那么学习`schedule-task-management` Skill 进行定时任务的创建。以满足用户每日获取相关热点追踪的意图。
    2. 如果用户选择开始创作那么进一步引导创作相关。
    3. 如果选择创建定时任务并开始创作就先走1. 创建定时任务，然后再2. 进行创作。
- 可以学习生图skill，将当前相关结果以图片返回给用户，图文一起给到用户效果更好，生的图片prompt不要太干扁只有文字。

## 失败与降级

- 如果实时检索失败，说明失败原因，并给出可继续执行的备用 query；不要用旧知识假装当天热点。
- 如果只有单一来源，标记为“单来源线索”，建议继续验证。
- 如果用户要求“今天/刚刚/最新”，但当前环境没有联网或实时工具，必须直接说明无法确认最新事实。
