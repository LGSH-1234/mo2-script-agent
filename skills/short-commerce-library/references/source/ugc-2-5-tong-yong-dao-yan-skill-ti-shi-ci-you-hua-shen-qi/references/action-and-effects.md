# 动作、多人交锋与特效导演

当任务涉及打斗、追逐中的交锋、多人协作、能力对抗、变形或效果驱动的环境变化时，按需使用本页。日常行动、安静观察和普通风雨无需全套启用。
先以 [导演方法](director-method.md) 确认用户要看的内容，再将本页决定编入 [提示词编译](prompt-compiler.md) 的实际镜头正文。成片诊断与局部返修见 [检查与修复](review-and-repair.md)。
本页是可迁移的导演方法，不是小云雀的参数说明或效果保证。不预设后端模型、时长、镜数、素材上限或工具能力；使用当前入口实际可用的选项。

## 1. 先保住用户要看的东西

- 继承源剧情、人物身份、对白、关键因果、结局，以及用户锁定的媒介、尺度和效果。将“爽、惨烈、轻盈、纪实、喜剧”等愿望转成可见的行动与观看回报。
- 区分用户硬约束、素材已显示的事实和导演可调的选择。导演自行采用的固定侧拍、弱特效或慢节奏不能覆盖用户的快剪、强冲击或巨大神通要求。
- 在既定创作范围内直接完成必要编排与表现强化；不要为换景别、组织交锋或明确效果路径另设确认关卡。
- 不悄悄改写人物关系、能力归属、关键对白或结局。若原文不足，优先采用兼容剧情的最少补充，简记为创作假设；只有会改变核心故事且无法合理判断的歧义才需要用户补充。
- 真人、CG、二维是媒介；写实格斗、玄幻、仙侠是世界规则。真人仙侠可以有巨大神通，CG 也可以表现贴身写实，不把现实落地规则施加给所有世界。
- 暴力强度沿用用户已确定且可处理的内容，不擅自削弱，也不无由升级。本页提供屏幕动作和影像设计，不展开现实伤害或危险特技的实施步骤。

## 2. 先编连续交锋，再分配镜头

以一组具有连续因果的交锋作为动作单元：一方争取位置或机会，对方怎样应对，新局面又迫使谁调整。单元可以跨镜，也可以在一镜内容纳多次行动，没有固定招数或秒数。

1. **锁住当前关系。** 明确距离、朝向、压力和可用空间。环境只有确实影响路线、支撑、遮挡或目标时才进入编排，不默认添加墙撞、台阶或道具。
2. **让对手持续参与。** 一次攻击被挡、落空或奏效之后，对手仍会追踪、改线、抢位、脱离或承受后果。选择来自人物能力与局面，不把对手写成只等挨打的靶子，也不强迫每组都反转优势。
3. **让恢复成为下一步的条件。** 收手、转身、落步有必要时间；对手可以在此时介入，恢复也可以接出下一次行动。不要把局部恢复扩大成双方收手、站稳、重新起招。
4. **保留代价与余势。** 格挡可能压缩护架，避让可能失去空间，追进可能受到截断；成功化解也可自然成立。切镜后继续承接已发生的位置变化、失衡、损坏和压力。
5. **只细化决定结果的机械关系。** 关键接触、持械手、承重和易误读方向需要明确；普通动作不逐关节列状态。先让距离、接触、支撑与反应相容，再写成正在发生的行动。

战斗身份应落实为可见的距离偏好、进入方式、连续应对与表演力度。只列拳种或技法名字无法形成可读交锋，故事胜负也不构成现实流派优劣判断。

### 把三个节奏层次一起设计

| 层次 | 需要决定 | 常见问题 |
|---|---|---|
| 动作内部 | 启动、加速、接触或擦过、反应、余势；持续施力也可成为重点 | 匀速伸出、停住展示、完整归位，只加“迅猛”形容词 |
| 攻防之间 | 连攻、抢拍、受阻、追踪、距离变化；必要蓄力和僵持承载威胁或选择 | 每招等双方恢复，同一关系反复出现而压力不变 |
| 整段观看 | 连续交锋、关键细节、空间确认、停顿与结果的时间分配 | 等距分镜、全程同速、高潮后重复确认结果 |

- 动作密度与剪辑密度分别决定。连续中景可以很密集，快速特写也可能只是在重复一个姿势。
- 对恢复、僵持、长镜和收尾做删短试读：缩短会失去什么动作条件、情绪或信息？保留有用停顿，压缩重复确认。
- 用户要慢镜、仪式感、喜剧停拍或持续观察时，按该风格的观看价值判断，不套统一的“越快越好”。
- 按动作复杂度、距离和读懂转折所需时间分配区间。不要为消除拖沓，把大量新动作硬塞进更短时间。

## 3. 摄影交代正在改变的关系

每次换视点都回答“此刻看什么，新画面增加什么”，同时比较继续留在原镜是否更有效。理由可以是信息、感觉、节奏或形式，不要求每镜都有新招式。

| 观看任务 | 可选覆盖 | 必须保住的关系 |
|---|---|---|
| 距离、进退与换位决定结果 | 双人宽景、侧向跟随、重新显露空间 | 谁压向谁，可走方向及必要的脚下支撑 |
| 化解或截断改变局面 | 能看清接触与即时反应的中近景 | 动作从哪里进入，怎样改变下一步 |
| 力量需要被感到 | 衣料、护具、兵刃、接触面的紧特写，再接反应或结果空间 | 来势、接触、余势属于同一次作用 |
| 压力突然贴近 | 随退让跟退、侧移让位或调整取景 | 摄影有可行路径，观看目标仍可追踪 |
| 镜内变化仍然丰富 | 连续观察与镜内调度 | 不为凑镜数拆断交锋 |
| 威胁或策略改变 | 新视点或镜内交接注意 | 观众得到新的关系，而非机械轮换远中近 |

- 切点可以在进入、转动、接触后的余势或有意停顿中。后镜接住相容的动作相位与方向，不让演员为了换机位先归位。
- 甩镜、闪白、烟雾和震动可以成为用户需要的形式，但不能偶然遮掉理解因果所必需的连接。
- 固定、稳定、长焦观察、主观失控和风格化虚拟摄影均可成立，按用户意图与当前观看任务选择。
- 同一镜头保留一条可理解的主运动。辅助偏移服务这条运动；若改变主运动，要有明确时机、目标和空间条件。

### 手持与肩扛：来自身体和观察

仅在用户要求或当前视点确有需要时使用。手持不覆盖既定固定机位，也不使一镜到底自动增加切镜。

- **原地观察：** 写清摄影师所在一侧和守住的对象。呼吸与换重心带来轻微、不规律的取景偏移，不必追随每个小动作。
- **同行跟随：** 写清从哪一侧沿什么可通行路径同行。起伏随步伐、减速、转身和注意变化，不是固定周期的上下摆动。
- **贴近操作或接触：** 给手、工具、兵刃与接触点留活动余量。关键瞬间减小干扰，以画幅和焦点保住先后关系，再继续观察。
- 摄影的修正由该机位能感知的事件触发；持续跟踪不必故意迟到，也不能先知地对准尚未发生的突然事件。
- 后撤、侧让、穿门或转身要有通行空间。空间不容许时改变观察关系，不倒穿墙体或瞬间跳到另一侧。
- 不将精确轨道环绕、随机大幅晃动、持续变焦同时叠在一句“自然手持”上，也不默认每次碰撞触发同幅震动。
- 呼吸感是身体传到取景的变化，不自动添加摄影师喘息声，不等于对焦呼吸、画面整体缩放或果冻变形。
- 末尾可以继续观察、继续同行或保持退让。只有事件与接续确实需要时才停住，不模板化地让每镜归零。

## 4. 多人动作：共同事件与焦点交接

当三名以上角色参与、一对多、多阵营混战、护送、突围或多人合击时启用。人数不决定镜数，也不要求每人等量戏份。

### 场上有谁，与这一刻看谁

- 简记阵营、可辨角色或群组、起始区域、当前任务、武器与能力归属。少数具名角色用实际服装、面部或道具辨识；大规模兵群按队列、方向和任务组织。
- 区分剧情总人数、本镜可见人数、遮挡或画外人物。分身、召唤物、飞剑是不同主体，不能无意增加演员。
- 角色参考按实际上传标记绑定。图片上印的名字不能自动当作小云雀已识别的映射；道具和能力也不能只靠发光颜色区分。
- 只锁当前行动需要的入口、出口、高低层、遮挡和路线。镜头变化后用这些锚点重新定位，区分世界方向与画面左右。

### 多个人共同改变同一局面

先确定正在变化的局面与各方目标，再写即时任务怎样相互影响：谁的牵制暴露了另一人的侧面，谁封住路线迫使对手升高，谁腾出进攻窗口，对手怎样识破或干扰。

| 当前关系 | 可用编排 | 需要避开的写法 |
|---|---|---|
| 一对多 | 不同角度的压力重叠，角色借地形使来路相互阻碍，其他人改线追踪 | 敌人围一圈，依次上前打一招 |
| 队伍对队伍 | 局部交锋有目标，第三人介入或场地变化影响另一组机会 | 几组双人回合互不影响 |
| 合击或破阵 | 共同信号或可见机会触发相容行动，对手分配应对，结果改变局势 | 同姿势发同色光，爆完一切不变 |
| 护送或突围 | 目标和出口持续构成压力，开路、阻截、接应在移动中接力 | 展示完招式后突然已到出口 |
| 远近或空地协作 | 远程限制路线，近身利用空隙，对手改变高度或遮挡使策略失效 | 远程效果与近身演员各打各的 |

- 每镜有一个主导事件或关系，也可以是一组同步碰撞；它不意味着只许一个人动。
- 旁侧、远处和画外人物有具体延续：追赶、绕位、封路、保护、拦截、恢复或维持持续能力。“背景也很激烈”不够。
- 无法立即加入要有场面原因，如距离、遮挡、受压或另有任务；不能让全员等待为主角清空表演时间。
- 多条动作争夺注意时，先把它们组织为一个共同结果，再用遮挡层次、声音引导或焦点交接区分。仍拥挤就调整取景或拆成相连事件，保住用户要求的人数和强度。
- 快切尽量让前镜目标、移动方向或声音接到后镜目标；长镜通过人物调度与重新取景交接注意。不要每换景别就重新起招。
- 切走后的时间仍属于人物行动。重新出现时承接位置、姿态、道具、目标和已受后果，只记录确实变化的状态。

## 5. 仙侠、玄幻与能力对抗

源内容有飞剑、法术、超常速度、力量或其他能力时启用。普通武打不自动加超能力，也不以微弱小火星给用户锁定的强效果封顶。

### 把观看回报变成事件

按本场选择以弱破强、抢拍反击、多人协作、远近骤换、速度爆发、强力碰撞、尺度揭示或战场改变，不要求全部出现。开场威胁怎样升级、主动权如何变化、高潮改变什么，应从镜头直接读出；势均力敌也可以有明确回报。

每个主要能力只明确本场必要的所有者、载体或形态、方向、作用对象，以及它如何被挡住、避开、利用或反制。规则服务读懂对抗，不强制新增弱点、冷却或整套功法设定。

- **能力应对：** 写清两种作用怎样在接触处改变彼此，角色怎样利用变化；避免“两人各放一道光，中央爆炸”结束所有关系。
- **速度爆发：** 先让封锁、追赶或即将错失的机会可读，再用加速改变局面。对手追踪、衣摆与周围流动继续响应，不全段以“极速”代替变化。
- **力量规模：** 让接触面、即时反应和更大范围的后果形成联系。只增亮度、晃动和爆音无法说明力量怎样改变场面。
- **多人斗法：** 持续改变战场、顶住压力、寻找侧线等任务相互影响。合击来自共同机会，对手也能识破或重组，不悬停排队施法。

### 飞行、法器与空间

- 人物、手持武器、独立飞剑和召唤物分别保持归属与路线。人物转向不意味着飞剑自动回到身旁，只细化决定攻防的路径和相交位置。
- 俯冲、升高、急停、反向、瞬移或空间扭曲按故事规则成立。已锁定的瞬移应设计重新定位线索和对手响应，不能用通用禁令删掉。
- 需要速度和尺度时，用本片已有的近处掠过物与远处锚点显示相对变化，不无由补入巨像、山体或建筑。
- 追击中的长时间并排平飞容易失去变化，应写清正在缩短或失去的机会；观景或用户指定舒缓飞行则保留，不人为塞入打斗。
- 宽景交代范围与逃路，中景交代抢拍、受压与反击，特写捕捉接触与材质后果。景别反差服从当前观看目标，不固定循环。

## 6. 特效的因果、现场响应与末态

适用于能量、天气、变形、破坏、环境变化和纯物体特效。没有演员的事件可以独立成立，不硬补施放者、攻击者或受击者。效果强度与视觉尺度继承用户要求。

按当前事件选择必要维度，不把所有镜头填成同一套层级：

1. **事件功能：** 要呈现人物行动、材质、空间变化还是奇观？环境过程不必强造战术障碍。
2. **发生条件：** 有触发时写可感知线索；开场已在持续的效果直接从当前状态开始，不补无来源的起手或口令。
3. **作用路径：** 写发生位置、方向、形态或材质变化、轨迹、遮挡和结果。并行变化围绕同一事件分配主次。
4. **变化过程：** 只写实际存在的启动、发展、峰值、维持或消散。持续效果可跨镜，不必每段重新蓄力再消失。
5. **现场响应：** 按需要写交互光、反射、接触、受风或受力；光学现象不必虚构冲击。受力要有来源、作用路径和承受对象，反应与支撑或自由飞行相容。
6. **结束与承接：** 保留主体状态、环境改变、效果运动相位、残留和声音尾巴，不强迫先落地、停稳或清空全部效果。

- 预判危险的主动闪避可以发生在接触前，被动撞击反应不能无因提前。用户确定的超自然规则仍然优先于通用现实判断。
- 真人与特效结合时，让触发接上演员行为；局部受光、衣发、道具和可触环境按作用响应。虚拟场景同样保持本片规则一致。
- 粒子、流体、实体碎片、方向性边缘和交互光按效果身份选用；没有这些层时不添加，不以全身泛光替代接触证据。
- 表演、对白和效果可以重叠，只要说话者、原话、行动与结果仍可辨，声音和身体负荷相容。需要时错峰，不默认说完才动、效果完才继续。
- 烟尘、闪白、黑场或完全遮挡可以成为事件或接缝。若用户要遮满，明确遮满过程、持续关系与显露内容，避免偶然吞掉必需信息。
- 摄影震动按事件选择幅度与恢复方式，强烈失控视点也可成立。冲击结束后可以接回原运动，不一律转成固定机位。
- 时间是导演计划。用动作事件和相位表达内部节奏，只对必要的切点、对白、接触或同步事件细化时间，不以密集小数伪装执行精度。

### 声音跟着作用变化

- 区分落空、擦过、格挡、受力、步伐与环境反应，不让每次动作套同一爆音。
- 蓄势、掠过、碰撞和余响可以组成变化；音乐与高潮的关系按用户要求决定，锁定无音乐时保留。
- 声音可跨切点连接同一事件，效果残响与下一镜空间相容。遮挡期间的对白可继续，但必须保持说话者、原话和顺序。
- 末态检查包含烟、碎屑、余光、损坏、持续风场、武器位置与声音尾巴。只延续实际存在的后果，不自动复原，也不无由增加残留。

## 7. 在正文里拦住问题

先判断用户要的观看强度、节奏、尺度和覆盖是否兑现，再查动作和连续性。关系正确只说明没有已知矛盾，不能证明交锋精彩。

| 审读方式 | 需要定位的问题 | 修复方向 |
|---|---|---|
| 去掉摄影与形容词，只读行动 | 是否轮流出一招、接一下、双方复位？ | 重编连续交锋，让对手与恢复参与推进 |
| 连读相邻动作末尾与开头 | 距离、余势和必要时间是否无因消失？ | 修承接，保留有用的准备与持续作用 |
| 试删恢复、重复攻防和收尾 | 删除后到底失去什么？ | 调整时间与信息分配，压缩重复确认 |
| 只读摄影，再与动作合读 | 是否看清转折？换视点是否迫使动作重做？ | 调整观察位置、景别、主运动与接点 |
| 遮掉主角，只读其他人的行动 | 多人是否共同改变局面，画外是否停摆？ | 修任务依赖、介入机会和焦点交接 |
| 联读效果、人物与空间 | 能力是否回应彼此，作用后是否改变下一步？ | 修作用路径、归属、响应和末态 |

检查结论定位到实际原句或区间，直接改正文。不要额外输出一张全填“通过”的空表，也不要在分镜后重复堆一份特效清单。
实际视频可用时，先正常速度看整组交锋与节奏，再针对接触、等待、换位和遮挡加密查看，并在能听音时检查声画。只做文字审读就报告设计检查，不宣称成片动作、手持或电影感已通过。

## 8. 参考学习与证据范围

用户要求学习参考、提供失败成片，或既有方法不能解释具体缺口时使用。普通且证据充分的小修改无需重新扩大研究。

1. **从问题出发：** 明确要解决轮流送招、主次不清、平飞过长、碰撞无后果、法术只有颜色或景别不变中的哪一项，不搜完标题就当研究完成。
2. **使用相匹配的证据：** 产品规格以当前官方入口为准；动作和剪辑可用创作者、剧组、摄影师说明；超自然效果可用实际视效团队拆解。真人拳击材料不能自动证明仙侠空战规律。
3. **说明实际看过什么：** 简记来源、查看日期、网页段落或媒体区间，以及连续播放、抽帧或听音范围。只有文字就写文字阅读，只有稀疏帧不声称看过精确速度、切点、接触时机或声音。
4. **分开观察、推断与原创决定：** 写清“可见证据 → 本场采用的方法 → 对应正文”，未观察到的原因标为推断；片名、剧情介绍和搜索摘要不能冒充镜头观摩。
5. **及时停止扩张：** 证据足够回答当前缺口后回到设计。参考中的招式、角色、镜数、时长和结局不自动迁入本片，也不凭画面气质断言器材、焦距或真实支撑方式。
6. **按实际输出验证：** 结构检查、另一位助手审读和文字修改仅证明对应范围。没有对照和参数证据，不把缺陷全部归因于模型、提示长度或某个词，也不把一次示例写成成功率保证。

使用现有成片修复时，先区分观看方向不符、指令矛盾、可能的执行偏差和证据不足。原因诊断尽量只改最能区分原因的一组因素，保留有效内容与原始输入。
有可用参考时按实际能力安排身份、位置或运动参考，并说明控制什么、允许改什么；无参考时继续交付可执行的文字方案，不冒充已上传素材，不以缺图中止已授权的设计。

## 9. 紧凑写法示意

拖沓：`甲进攻，乙挡住；甲收手站稳，乙恢复护架。切近景，甲再次进攻。全程激烈快剪，手持晃动。`

连续：`甲的推进逼乙让出半步；甲调整重心时，乙已斜进抢位。甲落步截住来路，乙顺着接触转出角度，让截击擦过，反击接着身体转动进入；甲边护挡边撤，乙继续压缩距离。摄影从双人侧前方跟住退让，转角改变机会时切近，看清介入的时机，再接住尚未结束的退势。`

特效：`既定能力从接触处改变防线，裂口出现后人物立即利用该机会移动；防守者追踪并调整作用方向。摄影先保住双方与裂口，再贴近看清受作用的材质，后镜接住人物位移及仍在持续的效果，声音余响延续到显露的新空间。`

示意只展示恢复接续、对手调整、作用后果和观看交接的方法，不是默认招式、人物、能力、镜数或时长。正式写作须换成本场已确定的主体、空间和事件，并落实到实际镜头正文。
