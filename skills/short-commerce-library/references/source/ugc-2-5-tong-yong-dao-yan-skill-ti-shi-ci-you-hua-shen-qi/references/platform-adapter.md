# 小云雀入口适配

本页处理任务衔接，导演内容见 [导演方法](director-method.md)。小云雀的产品入口、底层模型和账号能力可能变化；不能把模型家族文档或旧版截图直接当成当前入口的能力。

## 先识别在哪工作

| 环境 | 怎样推进 |
|---|---|
| 小云雀原生创作对话，只有自然语言入口 | 将导演要求写成清楚的创作任务，由当前 Agent 提供的流程承接；不输出虚构 API 调用 |
| 小云雀原生对话，暴露画布、镜头或生成工具 | 使用工具实际返回的项目、镜头、素材和任务标识，在现有项目中接续 |
| 外部 Agent 已连接小云雀 | 使用当前可用连接器/官方集成及其真实工具说明；本技能提供创作内容，不自带认证和请求脚本 |
| 仅能写文本，或尚未连接小云雀 | 完成导演方案、提示词、任务交接与必要素材清单；明确哪些还未执行 |

当前名称可能是通用创作、短剧/漫剧或其他可用入口，按实际界面和工具说明辨认。平台安排镜头的 Agent 工作流与直接请求某模型生成视频，接收的内容层级不同。

## 核实能力，只查与任务有关的项

在真实提交前，从当前界面、工具 schema、入口内的官方帮助或本次成功返回的信息核实：

- 当前项目/会话和创作方式，是否指定了模型。
- 单次生成允许的时长取值、整片/分集组织方式；区分范围、离散档位和总成片长度。
- 当前入口可用的画幅、分辨率，若用户要求则核实帧率和输出声音。
- 支持的输入媒体、可用引用方式、数量、格式和用途；图片上传成功不代表已绑定到本次生成。
- 首帧、尾帧、身份参考、续接、局部编辑、音画同步等当前任务真正需要的功能。
- 提示词输入长度、任务状态查询、结果查看或下载方式（如可见）。

能力为未知时，写“待当前入口核实”，不填猜测数字。用户指定的模型或规格暂不可用时，先保留其创作目标并完成方案；说明实际不匹配处和可执行替代选择，不暗中替换模型、压短剧情或更改画幅。纯提示词任务无需先拿到所有平台参数。

能力说明应能追到本次查看的入口和日期。底层模型宣称的最大长度不等于当前产品入口可选长度；也不把某次失败推断为永久不支持。

## 总任务、生成段和镜头

总任务给 Agent：最终片长、故事目标、锁定条件、素材职责、镜头顺序、生成段计划和验收重点。一个总任务可以包含多个镜头和生成段。

单次模型生成的提示词只覆盖实际交给该次生成的内容；根据已确认能力编译。独立段从 `0.00s` 计时，各自写足必要锚点。若入口要求逐镜填写，逐镜输出；若支持多镜生成，可将相连镜头放入同一生成段。不要把整片时长当单次模型时长，也不把长片自动截到三十秒。

能力未知的长片先按完整戏剧单元规划为待适配段，保留整片时间线。真实能力核实后重分生成段，保留剧情、对白和镜头关系；叙事分段不冒充平台已经接受的生成方案。

## 素材映射

记录“用户材料 → 平台实际素材 → 控制范围”：例如人物图控制外观，现场图控制空间，音轨控制节奏。引用真实素材名称、可区分的描述或上传后返回的标识。

无素材时明确“无外部参考，按文字设定生成”。缺少地点图时可以设计文字场景。未上传的图像仅能作为待制作素材清单，不能在可执行正文中冒用引用标签。

若请求生成图像资产，先按用户约束写身份、服装、背景和视图职责，完成生成后实际检查再选为参考；某次偶然生成的细节不自动变成剧情事实。无法查看时说明未视觉确认。

## 真实执行

1. 确定用户要方案、生成还是修改，以及要修改的真实对象。直接生成请求已提供当前任务所需的创作授权，按既有授权推进，不逐阶段重复确认。
2. 在当前项目中定位素材和已接受镜头；不因局部修改重新创建整片。
3. 提交已检查的任务，记录返回的实际任务标识和状态。异步受理仅说明已提交。
4. 按工具说明查询完成状态。状态不变时避免高频重查；适时给有信息的进度更新。提交超时或结果不明时先查原任务，避免重复产生同一生成。
5. 对真实结果查看画面、连续动作和声音；能看多少就评多少。交付可访问结果和尚存的具体问题。
6. 用户要求迭代时优先修指定镜头及受影响的承接。对同一失败，先分析原因再尝试；连续两次有针对性的修复仍无改善或触达用户预算时，停止同一路径重复生成，汇报现有结果与可选下一步，不无限抽卡。

文字方案无需认证信息。实际工具若要求连接，由宿主正规连接流程处理；不把密钥、账号字段或本机路径写入可分享技能内容。不要臆造接口、命令或平台自动化能力。

## 发布与导入兼容性

本包使用 `SKILL.md` 与相对路径参考文件，另提供合并的单文件版。它们是可携带的创作说明，不能由文件结构本身证明某平台已成功导入或会递归读取参考。

按当前小云雀界面实际提供的创建/导入方式使用：支持技能包时使用 ZIP；支持单个文档时使用单文件版；只有指令输入区时复制单文件版的适用正文，先验证是否完整保存。若界面限制长度，按本任务需要保留入口和相关模块，并明确尚未加载的部分，不能静默截断后声称全量生效。
