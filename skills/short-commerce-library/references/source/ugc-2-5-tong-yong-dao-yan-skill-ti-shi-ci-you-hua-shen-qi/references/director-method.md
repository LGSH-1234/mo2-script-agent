# 导演方法：把意图转成场面

只启用会改变当前作品的部分。对白、人物心理、复杂调度、导演参考和手持都不是每个任务的默认配置。编译时用 [提示词编译](prompt-compiler.md)；长期状态用 [生产与连续性](production-continuity.md)。

## 1. 读源与创作范围

先区别已完成的剧本和待发展的创意。忠实转译不擅自加结局；扩写创意可补足故事，但要继承用户明确的事实与边界。

- 事实：用户给的原话、身份、关系、事件、结果；实际看得见的构图、姿态、材质等。
- 导演设计：为当前表达选择的机位、布景、灯光、节奏、可逆动作和合理补足。重要设计对用户可见，内部记录简短依据。
- 未知：看不清的文字、被遮挡的结构、未说明的前史、未听过的声音。未知无需全部补齐；未影响执行的未知可以保留。

阅读参考视频时说明实际观看范围：连续动态、抽帧、静帧、声音或仅文字介绍。只能据抽帧分析可见构图和状态，不能冒称已确认连续动作与声画同步。参考是研究证据、生成输入还是要编辑的对象，需要分开。

逐字对白连同说话者、顺序、标点和版本保存。声音可在不同画面下持续，不能为了换镜重念或改说话者。用户授权润色台词时，明确采用哪一版；同一场不混用两版。

## 2. 导演读解

围绕当前材料回答：

- 观众要经历怎样的观看过程：发现、理解、等待、体验触感、感受关系、跟随行动或其他明确目标？
- 哪些内容必须在画面或声音里兑现？哪些只是留白？
- 角色此刻想完成什么，实际知道什么？环境和物体镜头的持续过程是什么？
- 什么事件改变行动选择，什么细节建立或兑现前面的信息？
- 结束时观众知道了什么，世界或主体处于什么状态？

主题从实际选择和后果归纳，不先写一个口号再改变剧情来证明。节拍是观看或行为单位，不是每句文本一格；反转、悬念、角色弧和伏笔只在来源或获准发展时建立。

把观众知识与角色知识分开。只给观众看的插镜、配乐或旁白，不自动触发角色的反应。悬念可先给观众信息；角色要在真正看到、听到或被告知之后才能据此行动。

## 3. 视觉与媒介

继承用户已确定的媒介和视觉方向。方向未定时，根据叙事距离、身体重量、表演尺度、空间可读性、材质、幻想规则和实际制作条件选择；只在有价值时提出少量候选并给出理由。

把“电影感”“高级”“某导演感”落实为当前场景的决定：

| 维度 | 写得出的决定 |
|---|---|
| 观看距离与构图 | 观众贴近谁、什么被遮住、哪里留空、前中后景承担什么 |
| 光线 | 光从何处来，照到什么，何时改变，主体靠什么可辨 |
| 色彩与材质 | 色彩附着在哪些衣物、墙面、道具和光上，如何与肤色或主物体分离 |
| 摄影 | 支撑方式、机位与透视、注意如何转移、运动由什么触发 |
| 剪辑与声音 | 信息如何进入，在哪切，原声如何持续，哪个声音属于现场 |
| 表演与媒介 | 行为强度和形变范围，与当前类型、角色和世界相符 |

不凭导演名推断固定色调或镜头公式。需要精确研究而资料不足时查实际可访问来源；无法查时把建议称为原创设计，不伪造观看经历或作者意图。

真人感来自空间中能存在的机位、真实光源关系、材质响应、接触与重量，不靠“8K、超真实”堆词。二维或定格可以有不同运动规律；明确的动画要求优先。色数、HEX、焦段和帧率只在用户锁定或确有设计用途时加入。

## 4. 表演不是情绪标签

对有表演任务的人物，用“当前目的 → 感知/主动选择 → 行为 → 伙伴获得的信息 → 当前末态”建立因果。角色自发做事不需要额外刺激。根据场景需要再加入障碍、代价、策略、潜台词；普通高兴和直接沟通也可以成立。

复杂人物可从稳定行为习惯、整场任务、局部策略到实际镜头逐层细化。角色掩饰时才考虑保护层及其失效；不让每个角色都经历隐忍、崩溃、释然。

将“紧张”写成与行动有关的可见行为，例如说到必须承诺的部分先看对方反应，再把物件移到对方面前。具体行为来自当前剧情，不把眨眼、咽口水、攥拳规定为所有紧张的表演。

### 对白与听者

- 明确是场内对话、对观众说话、自言自语还是旁白。只有真实听者才记录其感知与回应。
- 写人物在这句话中实际做什么：询问、解释、确认、招呼、试探、拒绝等。策略选择不能改变原话语义。
- 先确定对方能听到什么，再安排反应。允许说话中真实倾听和适当动作，不统一要求话落后停两秒。
- 音量、语速、换气和身体动作相容；奔跑、受伤或大幅动作时不要安排无法完成的平稳长句。
- 摄影可在同一句原声中切到听者，听者不开口冒领台词。镜头外真实声源保留明确位置。
- 字幕、音乐、旁白和拟声词按需求设计；无对白要求不自行添加台词。

自然表演可安静、热烈、滑稽、急促或失控，强度由类型和情境决定。使用可观察的自然语言；FACS/AU 等编码仅作近景校准，不能替代行为设计。全景中读不清的细微眼神不要作为唯一叙事证据。

## 5. 先世界位置，再画面位置

给场景几个足够清楚的锚点：入口、桌面、通道、窗、关键物件或地标。说明人物和物件的相对关系、可行动路径、朝向与视线。区分“角色自己的左手”和“画面左边”；切到新视点后不要混用坐标。

重要交接追踪持有者、哪只手、支撑面、松手时机及新持有者。接触说明接触双方、作用点、施力方向、身体支撑及结果；发生处的摄影要能读清。普通行走不需要逐步关节时间表。

多人物各有可感知目标和行动，不同时看向不存在的刺激，不因焦点转移全部静止。复杂交锋另读 [动作与特效](action-and-effects.md)。

### 景别、透视与运镜

先确定需要被看见的证据，再选景别、距离和遮挡。深焦不能补救主体太小；景深清楚也不等于每件细节都能同时读懂。

- 移动机位靠近会改变空间关系；光学变焦主要改变取景；同时要求时明确其目的与方向，不能混称“推进”。
- 拍摄位置应有空间可容纳；除明确选择虚拟穿越，摄影机不穿过实体台面或墙体。
- 摄影运动由跟随、揭示、情绪、节奏或观察触发，可以入镜已在移动，也可带着运动结束。
- 一个关键观看阶段有明确的主摄影任务；复合运动写清先后或相容关系，不把推、拉、环绕、甩镜同时堆在一句。
- 前景遮挡可以控制揭示，但必须保留关键接触或结果的证据；不要默认用闪白与晃动遮掉每次难动作。

### 手持、肩扛与纪录片观察

仅在用户要求或导演实际选择时启用。写摄影师在哪、如何支撑、是站立换重心还是行走、注意什么、何种事件导致取景修正。

原地握持可有细微非周期偏移；跟走时身体步态传到构图；肩扛可有承重与方向调整。不要每镜复制相同幅度和频率。手、目标或视线移动后再作有动机的小幅修正；关键证据处留足构图余量。呼吸感指身体影响取景，不默认添加摄影师喘息声。用户锁定稳定机位时继承稳定设计。

## 6. 把镜头组成观看序列

分别判断：连续镜头、同段剪辑、场景转换、独立生成段。它们的边界不同。不要把生成段数量当镜头数量，也不要把四栏当四镜。

每镜回答两次：**为什么现在进入？继续留在这里还能获得什么？** 信息、情感、节奏、空间、材质和持续过程都能成为理由。用户要求静观时可以完整观察；紧凑场景则检查重复信息、机械慢动作、无必要等待和拖长结尾。

考虑关系镜头、细节、改变视点、动作匹配、听者覆盖、镜内调度和声桥对当前场景的价值；不固定远景→中景→特写，不每句台词机械正反打。片内动作可从一镜中途接入下一镜，演员不为等摄影反复起手。

| 切法 | 执行需要写明的关系 |
|---|---|
| 动作匹配 | 出镜与入镜同一物件/身体，动作相位、方向和接触状态接续，不重做、不跳过必要过程 |
| 视线与所见 | 谁从哪个方向看什么；下一镜的视点是否属于此人；何时获得信息 |
| L-cut | 前镜开始的原声在后镜画面继续，明确声源和结束点，完整原话仅出现一次 |
| J-cut | 后场声音先出现，明确其所属时空，当前人物能否听见 |
| 场景硬切 | 新地点、时间或视点的识别锚点，保留源的时空与因果关系 |
| 省略/蒙太奇 | 来源或改编授权允许省略的过程，保留必须展示的对白、接触与关键转折 |
| 遮挡或甩镜接续 | 遮挡物/运动方向、覆盖窗口、两端相位、显露顺序和声音，见连续性参考 |

保持有用的轴线和屏幕方向。故意越轴、跳切或时空错位应能重新定位且符合表达需求；角度差不作为固定数学门槛。一镜到底通过镜内调度、焦点和构图改变观看，不私自添加切镜。

## 7. 声音作为现场与叙事

分开对白、环境声、动作声、配乐和旁白。声音来自哪里、距观众多远、是否属于画面所在时空要清楚。触发音与动作同步，持续声不随普通换镜无理由重启。

音乐若被请求，可设计节奏、层次、进入与退出，按实际音轨定位节拍；没有音频不要自称已听过或已精确卡点。MV 不要求每拍切画面，表演、运动和剪辑可共同回应音乐。广告中的字幕、品牌和卖点按提供资料保留，不凭空增加产品性能、认证或价格承诺。

结束可以带着风、行走、雨或其他持续过程。末态清楚不要求额外停两秒或冻结画面。
