# 小云雀导演提示词编译

将已确定的导演内容写成可复制正文。这里不改变用户源锁，也不重新拍脑袋添加故事。完整例见 [完整范例](worked-examples.md)，交付前用 [审核与修复](review-and-repair.md) 逐镜还原。

## 1. 先确定正文交给谁

- **Agent 总任务**：可描述全片故事、多个场景/生成段、资产及制作顺序。告诉 Agent 当前要完成的范围和最终验收目标。
- **单次生成提示词**：只包含该次实际生成的段或镜头，使用已确认规格；多个独立生成段分别可复制。
- **导演分析或分镜**：按用户所要的深度输出，不假装已经生成视频，不额外输出未请求的生成文本。

未核实单次长度时，仍可给清楚的目标时长和导演计划，在正文外简记入口待适配；不要用未知数字冒充平台参数。正文过长不意味着影片超时，影片超时也不能靠删形容词解决。

## 2. 内容冲突按权威处理

用户明确要求与源事实 → 已锁身份、空间、道具和状态 → 当前事件、表演与摄影 → 视觉声音修饰 → 可选装饰。

这是写作中的权威次序，不是平台原生权重。用户锁定的风格、光效、摄影、转场本身属于明确要求，不能按“修饰”任意删除。同一权威的矛盾先按用户最新版本、作用时间和素材职责解释；仍无法执行的源冲突要指出，不能写互斥结果让模型任选。

## 3. 四栏职责

| 栏目 | 应写什么 |
|---|---|
| 内容设定 | 当前生成范围、目标时长与画幅/媒介等必要规格，主体、情境、主要事件/持续过程、结果或留白、用户硬约束 |
| 素材分工 | 实际参考媒体和它控制的对象与范围；身份/首帧/构图等分开，无素材明确说明 |
| 整体基调 | 可观察的影像语言、当前人物/服装/空间/道具稳定项、光源与材质、色彩载体、共同摄影方式、表演尺度及声场 |
| 分镜 | 每镜进入状态、事件发展/持续过程、表演、原话、摄影如何见证、局部声光/效果、切点和退出状态 |

用户指定自己的格式时按其格式映射上述职责，不为了标题对齐拒绝交付。字幕、负面约束、末帧和时长放在相关位置，不再机械扩成八个主栏目。

## 4. 正文不是填表摘要

轻量、只要提示词、不要解释，限制的是交付范围和手续，不表示只写几句故事梗概。每个重要决定需要落入实际发生处：

1. 开场观众如何定位主体、物件、行动通道和观看重点。
2. 本镜正在持续或发生的事，必要的触发、感知、选择、接触与结果。
3. 摄影机在哪里、看什么，为什么移动/换焦/切镜，关键证据是否可见。
4. 台词、现场声音、光线或效果如何参与当前事件，先后关系是否清楚。
5. 本镜结束时真实状态是什么，下一镜如何接着看；末镜如何结束。

没有人物就不补心理，没有对白就不补台词；无声请求只保留必要画面说明；无接触不硬加力学节点；持续环境可只写整镜区间与变化趋势。普通走路、落座和转头用自然行为连接，只有影响结果的动作才展开机制。

例如“把盒子递给对方，镜头跟随”不足以表达关键交接。若本故事确有交接，应说明递出者从哪只手递向哪里、接收者何时托住、何时松手，以及构图如何让接触可见；不必写全部手指弯曲角度。

正文篇幅由当前事件复杂度和用户要求决定，不设通用最低字数。不以长保证效果，也不以去重删掉重要关系。用户给定字符范围时按其口径核对；实在无法兼顾时说明具体冲突。

## 5. 时间与对白

导演计划统一用 `0.00s—4.20s` 的两位小数区间，除非用户指定其他格式。先估实际行为再写秒点，精度不是模型执行保证。

- 每个生成段本地时间从零开始，所有镜头覆盖其计划时长，无意外重叠或空洞；分屏/并行视点须另说明。
- 关键开口、完成、接触、切点、效果触发按有意义的精度定位。普通连续过程不用拆高频微时刻。
- 原话只在开始发声处完整出现一次，明确说话者及总发声区间。跨同段画面切点时，后镜写“前镜说话者的原句继续至某时刻”，不用重复台词。
- 可见口型时明确对应发声者；听者画面中的画外原声不让听者对口型。人物反应依据其真实获得信息的时点。
- 独立生成段的对白边界与完整音轨按 [生产与连续性](production-continuity.md) 处理。

## 6. 参考、恒定项与变量

参考使用实际标记，不发明 `@图片1` 等已经绑定的假标签。无媒体写“无外部参考，人物与场景按文字设定生成”；只有角色图则说明背景由文字设计。

恒定信息在每个独立生成段写一次；该段的局部动作、光效和状态变化写在对应时间块。“整段灯关闭”和“后半灯打开”不能同时成为全局要求，应写开场关闭、操作后打开。

独立段不能仅写“人物同前”。需要延续的外观、服装、道具和空间锚点写足，动态状态按上一段实际出口更新。不要把未检查的上一段计划末帧说成真实生成末帧。

## 7. 可复制形态

下面只说明信息位置；实际交付要替换为完成的场面正文，不保留占位符，也不逐行一短句结束设计。

```text
【内容设定】
片段名称、当前生成范围与必要规格。
谁/什么在何时何地发生什么，观众看见什么变化或持续过程；锁定结果/留白与当前约束。

【素材分工】
每个实际参考的可识别名称、所控制主体与职责。无外部参考时明确说明。

【整体基调】
以场景中真实存在的构图、光源、色彩、材质、表演尺度、摄影支撑和声场落实视觉方向。
写清执行所需且整段稳定的主体、服装、物件、位置关系和世界规则。

【分镜】
镜头01｜起止时间｜景别、机位与必要运动
开场的空间与行为状态。用连贯段落写本镜实际发生的过程、重要表演/原话与摄影见证。
把本镜局部声光、接触、效果和观看重点写在对应事件中。给出切点和末态。

其余镜头依真实观看需要设置，一镜到底只写镜内阶段。
末镜结尾交代精确可理解的状态；只有实际存在后段时写必要交接。
```

## 8. 其他交付形态

**仅分镜**：可用“镜号/时间/观看目的/画面事件与表演/摄影及切点/声音/进入退出状态”的紧凑表格；表格太窄时用逐镜段落。当前没有音轨或台词，不填虚构声音。

**资产图提示词**：按用户已锁身份或物件、媒介、服装/材质、当前所需视图、背景和参考职责写。只有要做设定资产时才建议多视图；单张场景不强迫做角色四视图。图像生成同样按当前实际入口执行。

**完整制作包**：简明导演读解与重要选择、必要资产及状态、场景/段时间线、分镜、可复制任务正文、接续与待解决项。内部来源记录不必全部打印。

**局部修复**：问题与证据范围、需保留内容、完整替换镜头/段、必要相邻承接和复核点。用户只要替换提示词时交完整正文，省略内部分析。

如果只有对截图或旧片的文字描述，未看到可绑定素材，仍可完成动作、时间和摄影的文字修复；在素材分工中简记“基于描述的动作修复稿，外观与前后构图待绑定原素材核对”。不要用“沿用原片”冒充已经写足独立生成所需的身份、场景和空间锚点。若当前编辑入口确实绑定了原片，可用它维持未修改外观；否则这是等待补足外观/绑定的修复稿，不能称为已匹配前后镜的独立生成成稿。未知外观保持未知，动作设计仍完整交付。

所有形态按请求大小控制说明，不虚构评分、独立审核员、上传记录或生成完成状态。
