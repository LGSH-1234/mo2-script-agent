# 文本审核、成片复盘与局部修复

## 文本：从最终文字重建场面

先冻结一版完整交付文字，再从文字本身检查。脑中知道但正文没写清的关键决定，不算已经交付。

第一遍逐镜阅读，尝试还原开场摆位、事件过程、人物感知、摄影观看、声音、切点与末态。第二遍在实际修复之后，重读受影响镜头及其前后关系，确认没有新增冲突。小任务可全部由当前 Agent 自检，不冒称独立人员审核。

| 检查 | 可定位的缺陷 |
|---|---|
| 源与范围 | 改了原话、说话者、关系、结局或媒介；把创意当原图事实；出现用户没要求的生成 |
| 素材职责 | 不存在的引用；身份图锁死背景；把氛围图当剧情事实；未看素材却描述细节 |
| 表演与感知 | 只有情绪名；反应早于收到信息；为旁白虚构听者；每人同拍点头；强迫所有人克制 |
| 观看与摄影 | 机位无法存在；关键物件太小或被遮；指代含混；运镜互斥；没有目的的换角度或等待 |
| 动作与状态 | 手已占用仍取另一物；交接前松手；接触/支撑缺失；跨镜伤势、道具和位置复位 |
| 时间与声音 | 原话塞不下；换镜重念；口型归错人；未说明的音轨跳变；生成段和整片时间混淆 |
| 剪辑与承接 | 动作重演/漏关键过程；方向不明；场景变了无识别锚点；把隐藏剪辑冒充一镜到底 |
| 效果 | 触发、路径、响应或余势不成立；用光雾遮掉唯一关键证据；擅自减弱用户锁定效果 |
| 正文细节 | 只留术语与梗概；内部设计未落到镜头；重复词过多；为凑长加新剧情 |

无人物、无对白、无接触、无后继时跳过相关项。发现问题时记“哪镜/哪句话 → 具体矛盾 → 应改决定 → 修复结果”，不建立无用途的评分体系。

### 修复顺序

1. 源事实和用户锁定要求优先。
2. 修最早错误的身份、空间、道具、感知或力学状态。
3. 更新依赖这些状态的行为、机位、时间与接续。
4. 把修复写回完整可复制正文，再复查实际文字。

先去掉重复和无效修饰，再判断关键内容是否过载。过载通过更清晰的观看顺序、相容并行、适当覆盖或实际可行的分段解决；不要删除关键台词/结果来迁就方便的镜头。

## 生成结果：实际看到了什么才评什么

先记录证据范围：完整动态、部分片段、抽帧、单张截图、实际声音或用户口述。没有动态不能确认动作连续；没听声音不能判断配音和声画同步；没看到接缝不能称无缝。

在当前可观察范围比较原目标：

- 人物、服装、产品与空间是否稳定；源事件和结果是否出现。
- 原话是否完整、说话者和口型是否正确。
- 动作是否连贯有因果，交锋是否真实回应，重要接触是否看得清。
- 切点、节奏、景别和最长停留是否支持用户想要的观看体验。
- 光声效果与触发、余势和结束状态是否对应。
- 相邻段是否有明显错位、重演、断句或状态跳变。

报告“具体位置发生了什么”，不只说“塑料”“不高级”。用户口述的缺陷可直接据此修，但要说明依照反馈，不能声称亲自观察。

## 局部诊断与学习

先区分可能原因：源本身有冲突、场面设计遗漏、正文省略、时间过载、参考绑定错误、当前工具能力不足，或结果偏离已写清的要求。证据不足可保留多个假设，不能把某次失败断言为模型永久缺陷。

用户要求学习/检索、动作知识有真实缺口或失败无法从已有证据解释时，针对缺口读取实际可访问的一手资料或观看参考。记录看了哪部分、支持什么决定、还不能证明什么。资料不可访问时可继续做有标注的导演设计，不伪造检索成果。

修复只动必要范围。角色位置调整会影响后镜视线与轴线，应一并修；局部光效问题不重写身份和结局。对动作枯燥的反馈，检查连续交锋、对手应对、摄影覆盖和节奏，不只替换成更激烈的形容词。

用户已授权生成修复且工具可用时按 [小云雀适配](platform-adapter.md) 执行；收到新的实际结果后再验。只有文本修订时写“已修订提示词，待生成验证”。

## 如实交付

- 可说“已完成两遍文本自检”，仅当实际读稿、修复和复查完成。
- 可说“画面已查看，声音未核实”，若证据确如此。
- 不用确定性校验、文字齐全或自评分证明模型成片质量。
- 有未解决的关键冲突则说明影响和待选择项，不给虚假的全部通过。
