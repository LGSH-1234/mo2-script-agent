
# 行业场景策略与产品角色定位

## 产品角色模型

商业广告中产品扮演两种角色，交叉剪辑：

### 角色 A：产品在环境中（主角展示）
- 产品出现在使用场景中，动态展示 SKU 和实际部署
- 用于证明产品的真实使用价值和品牌活力
- 镜头特征：产品可见、人物或主观视角与产品互动、动作清晰

### 角色 B：辅助（功能与氛围）
- 强调产品优势但不一定展示产品本身
- 类型：
  - 纯环境画面（跳伞降落、演出人群、滑板滑行）暗示功能
  - 宏观纹理/UI/支架细节
  - 生活方式节奏画面
- 与角色 A 交叉剪辑，使成片不仅是"桌上的包装"

## 行业场景库

### 运动相机 / 户外电子
- **核心卖点：** 防水、防抖、便携、夜视、超广角
- **场景选择：**
  - 水下（潜水、冲浪、游泳）— 证明防水
  - 越野（山地骑行、越野跑）— 证明防抖
  - 跳伞/滑翔 — 证明超广角和稳定性
  - 滑板/极限运动 — 证明便携和抗冲击
  - 现场音乐/演唱会 — 证明低光和音频
- **产品角色 A：** 相机固定在头盔/胸前/车把上，第一人称或第三人称视角
- **辅助 B：** 纯环境画面（水花飞溅、山地俯冲、降落伞展开、人群欢呼）

### 护肤 / 美妆个护
- **核心卖点：** 质地、吸收度、遮瑕力、持久度、成分
- **场景选择：**
  - 梳妆台/浴室晨间 — 日常使用场景
  - 户外强光 — 证明防晒/持久
  - 夜间社交 — 证明持妆
  - 微距特写 — 质地和肤感
- **产品角色 A：** 产品在手心涂抹、上脸、对比使用前后
- **辅助 B：** 皮肤纹理微距、水滴滑落、光泽反射

### 食品 / 饮料
- **核心卖点：** 口感、新鲜度、原料、便利性、风味
- **场景选择：**
  - 厨房/餐桌 — 食用场景
  - 户外野餐/露营 — 便携场景
  - 原料产地 — 品质溯源
  - 制作过程 — 工艺展示
- **产品角色 A：** 开包装、倒出、入口、表情反应
- **辅助 B：** 食材微距、蒸汽升腾、色泽特写、环境氛围

### 消费电子 / 智能设备
- **核心卖点：** 性能、设计、续航、交互、AI 功能
- **场景选择：**
  - 办公桌/书房 — 日常使用
  - 通勤路上 — 便携场景
  - 游戏/创作场景 — 性能展示
  - UI 界面特写 — 交互展示
- **产品角色 A：** 手持设备操作、界面切换、功能演示
- **辅助 B：** 设备纹理、指示灯、环境光线反射、UI 动画

### 汽车 / 出行
- **核心卖点：** 动力、安全、空间、智能驾驶、设计
- **场景选择：**
  - 城市道路 — 日常通勤
  - 高速公路 — 动力展示
  - 山路弯道 — 操控展示
  - 夜间 — 灯光和氛围
  - 车内 — 空间和内饰
- **产品角色 A：** 车辆行驶中外观动态、内饰交互
- **辅助 B：** 轮胎特写、车灯轨迹、环境风光、仪表盘

### 服饰 / 时尚
- **核心卖点：** 面料、剪裁、功能性、百搭性
- **场景选择：**
  - 街头 — 日常穿搭
  - 运动 — 功能性展示
  - 室内 — 面料和剪裁细节
  - 户外极端环境 — 功能性极限
- **产品角色 A：** 模特穿着展示、动态走动、多角度展示
- **辅助 B：** 面料纹理微距、缝线细节、风动效果

## 场景设计原则

1. **至少两个场景：** 每个场景独立创建为元素，展示产品在不同环境中的优势
2. **场景与卖点对应：** 每个场景必须能证明一个具体卖点，而非纯装饰
3. **环境张力：** 场景本身要有视觉冲击力（极端环境、反差环境、美感环境）
4. **产品融入：** 产品在场景中是自然的，不是后期贴上去的
