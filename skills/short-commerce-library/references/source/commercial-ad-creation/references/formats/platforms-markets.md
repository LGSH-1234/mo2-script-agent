
# 平台规则与市场本地化

## 画幅与平台

| 平台 | 推荐画幅 | 备注 |
|---|---|---|
| YouTube / 横屏广告 | 16:9 | 默认格式，适合产品演示和场景叙事 |
| TikTok / Douyin / Reels / Shorts | 9:16 | 竖屏，构图需重新设计（竖向纵深） |
| Instagram Feed | 1:1 或 4:5 | 方形或近方形 |
| 电视/影院级 TVC | 16:9 或 2.39:1 | 宽银幕需注意安全区 |

## 市场本地化要点

### 语言与文案
- 旁白/对话语言由 Final_Video_Spec 的 Output Language 决定
- 屏幕文字/字幕跟随目标市场语言
- 不要只翻译语言，要本地化文化语境（俚语、习惯表达、文化符号）

### 合规敏感点

| 品类 | 注意事项 |
|---|---|
| 健康/医疗 | 不做疗效承诺，不展示诊断/治疗画面，标注免责声明 |
| 金融 | 不承诺收益，标注风险提示 |
| 酒精 | 不展示过量饮用，不面向未成年人，部分市场禁止广告 |
| 博彩 | 多数市场严格限制，需确认合规 |
| 儿童 | 需家长监护提示，不收集个人信息 |
| 可持续 | 环保宣称需有证据支持，避免"漂绿" |
| AI 真实性 | AI 生成内容需标注，不伪造真实场景 |
| 网红披露 | 付费合作需标注广告/赞助 |

- [ ] 屏幕文字是否本地化
