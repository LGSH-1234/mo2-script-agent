
# 视频提示词编写规则

## 语言规则（最高优先级）

当用户使用中文输入或处于中文语言环境时，提示词 prompt 用中文书写。但 prompt 中有关旁白/对话的内容严格遵循 Final_Video_Spec 中的 Output Language。

## 图像提示词

### 6 大核心规则（全局应用于所有图像 prompt）

将以下 6 条规则编织成流畅的自然语言描述，不要输出为带标签的分节：

1. **专业风格术语：** 结合专业艺术或电影术语与风格术语以提高准确性。引入"作者"和特定电影视觉锚点，如 `Neo-Noir style, David Fincher Style, inspired by Se7en`，而非泛泛说明 `Neo-Noir`。

2. **构图与镜头：** 明确指出电影化构图（如 `Over-the-shoulder shot` 肩后镜头、`Dutch angle` 荷兰角）和景别（如 `Close-up` 特写、`Medium shot` 中景）。

3. **光影：** 详细说明主光，强调"负补光"以增加对比度和戏剧感。如 `Strong chiaroscuro contrast`（强烈的明暗对比）、`dramatic interplay of light and shadow`（光影的戏剧性交织）、`deep facial shadows emphasizing facial structure`（强调面部结构的深面部阴影）。

4. **调色：** 使用高端好莱坞调色手法设定克制的色调。如 `deep teal-cyan shadows dominating 90%, zero warm fill`（90% 深青色阴影，零暖光填充）。除非用户明确要求，永远不要使用红蓝霓虹冲突。将图像限制在 90% 左右区域内仅使用一种主色调——极度克制。

5. **视觉渲染：** 描述整体视觉质量和纹理。如 `fine rendering quality`（精细渲染质量）、`rich and intricate details`（丰富错综的细节）、`soft-focus effect with subtle Gaussian blur`（带轻微高斯模糊的柔焦效果）。

6. **氛围与潜台词：** 描述角色的"潜台词"和微表情，将动作定格在戏剧性时刻。拒绝生硬摆拍。对无生命物体，描述其状态（如 `Destined aura` 宿命光环、`cold and detached atmosphere` 冷漠疏离的氛围）。

### 通用原则

- 提示词不仅是描述"画面里有什么"，更像一位真正的电影导演和调色师在指导团队
- 用通顺的自然语言描述场景内容（主体 + 行为 + 环境），用简短词组描述视觉美学（风格、颜色、光影、构图）
- 拒绝文学化修饰：不向 AI 解释角色动机或内心状态
- 不描述屏幕外或不可见的元素，只描述物理上可见的内容
- 条件元素 — 当场景中出现文字时，用引号包裹确切文本：`A neon sign in the background reads "DANGER".`

### 关键元素 prompt 结构

提供清晰、详细的元素视觉定义，以便在镜头间保持一致：

- **主体与身份：** 清楚说明元素是什么 — 角色、道具、场景或生物。对于角色，包括定义的身份特征（年龄、体型、显著特征等）
- **特征细节：** 具体描述关键视觉特征，优先考虑镜头间必须一致的特征：
  - 角色：面部特征（眼睛形状、下颌线、发型/颜色）、妆容与造型、服装与配饰（材质、剪裁、颜色、状况）
  - 道具/物体：形状、材质、颜色、尺寸、状况（新/风化/损坏）、独特标记
  - 氛围/情感基调：定义场景的情感潜台词

### 关键帧 prompt 结构

首先定位相应时刻（起始状态、结束状态、视觉/戏剧性最强瞬间），只描述那个瞬间的静态图像：

- **起始帧：** 动作开始前的场景 — 主体在运动前的姿态和意图（重心偏移、注视方向、肢体预加载）、环境基础状态、摄像机初始构图和角度
- **结束帧：** 动作完成后的直接结果 — 主体终结姿势或最终表情、环境变化后状态、摄像机最终位置
- **高亮帧：** 视觉或情感冲击力最强的那一刻 — 以最大细节描述（姿势、表情、光照状态、摄像机构图），使其可作为最具感染力的静止画面独立存在

## 视频提示词

### 参考图标签

在视频 prompt 中，为每张参考图标记，以便模型正确读取面部和造型。使用 `<<<image_1>>>`, `<<<image_2>>>` 等标签。

模板：`Subject 1 — facial features reference <<<image_1>>> (head shot); hair, makeup, and costume reference <<<image_2>>> (full-body shot).` 对 Subject 2 继续编号（`<<<image_3>>>` 头部，`<<<image_4>>>` 全身等）。

### 视频提示词结构（按顺序）

1. **摄像机** — 运动或镜头/剪辑变化（如 `static → push-in` 从静止到推入、`cut to new angle` 切到新角度、`orbit` 环绕、`pan` 摇镜头）
2. **主体** — 动作和表情（谁做了什么，面部动作节拍）
3. **空间** — 位置或环境变化（相对于空间的主体或摄像机位置；背景运动；深度/布局转换）
4. **音频** — 对话（如有）、音效、备注

### 动作细节

- 基于**特定身体部位**：手、腿、头、肩膀等
- 添加**程度**：幅度、速度、强度（如 *slowly raises one hand* 缓慢举起一只手、*snaps head left* 头迅速向左转、*pushes hard off the ground* 用力蹬地）
- 多个节拍按**主要动作，然后次要动作**的顺序列出（按故事时间顺序）

### 多节拍与内部剪辑

- 当工具接受长 prompt 时，可在单次生成中标记 **镜头 1, 镜头 2, 镜头 3** 用于摄像机或故事节拍的序列
- **精确的时钟计时（如"0-3 秒"、"3-6 秒"）无法可靠执行** — 不要强制按确切秒数范围分割 prompt，不要编写逐秒计划。描述**按顺序发生的事情**
- 可选润色：当简报是电影级真人拍摄时，可添加轻微手持微抖动或微妙胶片颗粒感，保持从属于四层顺序

### 特殊标记约定

- 音乐（描述正在播放的内容）：`(...)`，如 (fast-paced rock playing in the background)
- 音效：`<...>`，如 <distant dog barking>
- 口头对话：`{...}`，如 {Hello, world} — 若台词不是项目原始语言，在花括号前标注语言，如 *Says in Japanese:* `{こんにちは}`
- 屏幕标题/章节/字幕文字：`【...】`，如 【Chapter One: Departure】

### 负面约束（必须始终包含）

- 若分镜脚本表明该镜头有单独旁白音轨，不要在视频 prompt 中写入旁白文本，以避免音频冲突
- 为防止模型添加不需要的背景音乐，几乎应始终包含 `no music`
- 字幕在后期剪辑时添加，必须始终包含 `no subtitles`

## 落 prompt 前自检

- [ ] 6 大核心规则是否已编织进图像 prompt
- [ ] 视频提示词是否按 摄像机 → 主体 → 空间 → 音频 顺序
- [ ] 参考图标签是否正确编号
- [ ] 负面约束是否已包含（no music / no subtitles / 旁白不写入）
- [ ] prompt 语言是否跟随用户输入语言
- [ ] 旁白/对话是否遵循 Output Language
- [ ] 是否有逐秒时间码（应改为顺序描述）
- [ ] 措辞是否正向（不堆否定式）
