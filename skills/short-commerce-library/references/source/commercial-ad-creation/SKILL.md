# Commercial Ad Creation

## 核心原则

商业广告的本质是**用场景售卖产品所属的生活方式和功能价值**，而非展示"桌上的包装"。产品必须真实部署在目标场景中，通过环境张力证明其存在意义。成片的能量来自剪辑节奏与镜头语法的交替变换，而非单一长镜头的堆砌。

**持久引擎（因果链）：**
产品定位 → 品类张力（用户为什么需要这个） → 场景选择（产品在哪被使用） → 产品在场景中的主角展示 + 辅助氛围镜头交叉剪辑 → 功能可见证据 → 品牌Logo/包装收束 → 情感记忆点

**质量测试：** 如果把产品从画面中移除，剩余场景仍然能暗示产品的核心卖点（防水、防抖、便携、续航等），则创意成立。反之，如果移除产品后场景变得毫无意义，说明产品没有真正融入场景，创意不成立。

## 输入

**必需输入：**
- 产品信息：品类、核心卖点、品牌名称
- 产品素材：用户上传的产品图片（用于元素提取和绑定）

**可选输入：**
- 目标市场与语言（默认中文）
- 目标平台与画幅（默认 16:9）
- 视频时长（默认 15 秒以内，超过 15 秒需分段生成再拼接）
- 视觉风格偏好
- 旁白/配音需求
- 背景音乐风格偏好
- 合规要求（健康/金融/酒精/儿童等敏感品类限制）

**素材缺失处理：** 只追问缺失的必需项，已有信息直接使用。

## 输入诊断

落 prompt 前必须明确或合理假设以下维度：

| 维度 | 要点 |
|---|---|
| 产品品类 | 运动相机/护肤/食品/电子/汽车/服饰等，决定场景选择和镜头语言 |
| 核心卖点 | 产品的决定性功能（防水/防抖/便携/续航/口感/质地等），必须可视觉化 |
| 目标市场 | 中国大陆/海外，决定旁白语言、文化语境、合规边界 |
| 画幅与平台 | 16:9（横屏）/ 9:16（竖屏）/ 1:1，影响构图和镜头设计 |
| 视频时长 | ≤15s 一次生成完整成片；>15s 拆成多个 ≤15s 片段分别生成再拼接 |
| 体裁路线 | 产品主角展示 + 辅助氛围交叉剪辑（本技能默认路线） |
| 镜头节奏 | 商业广告优先短镜头 + 硬切，每次剪辑有清晰视觉变化 |
| 品牌要求 | 强制包装镜头、Logo 露出时长 |
| 合规敏感点 | 健康/金融/酒精/博彩/儿童/可持续/AI 真实性/网红披露等 |

## 工作流

### 阶段 1：视频规格定义

编写 `Final_Video_Spec.md`，包含以下字段：
- 标题
- 类型（产品广告/品牌片/功能演示）
- 比例（16:9 / 9:16 / 1:1）
- 时长（总时长；≤15s 一段生成，>15s 分段）
- 视觉风格（调色、质感、参照）
- 语言（旁白/对话语言，由用户指定）
- 模型偏好（图片/视频模型，如用户未指定则使用默认）

**暂停点：** 规格确定后，向用户展示规格卡片，确认后再进入下一阶段。

### 阶段 2：故事板设计

#### 2.1 关键元素设计

始终包含以下三类元素，每个元素独立生成一张图像：

- **产品对象：** 从用户上传的产品图片中提取描述，必须与素材匹配，不得矛盾。若用户已提供产品素材图，直接绑定到对应元素位置，不重复生成。
- **关键场景：** 设计至少两个展示产品优势的应用场景（如水下、越野、跳伞、现场音乐等）。每个场景创建为独立元素。
- **关键道具（如有）：** 支架、配件、包装等。

#### 2.2 镜头设计

**镜头分类（两类交叉剪辑）：**

1. **产品在环境中（主角展示）** — 产品出现在场景中，动态、清晰地展示 SKU 和使用场景。用于证明实际部署和品牌活力。
2. **辅助（功能与氛围）** — 强调产品优势但不一定展示产品本身：纯环境画面（跳伞降落、演出人群、滑板滑行）暗示功能；宏观纹理/UI/支架细节；生活方式节奏。

**节奏与剪辑：**
- 商业广告优先**短镜头 + 硬切**，每次剪辑有清晰视觉变化
- 当某镜头需要较长时长时，可在一次生成内用内部节奏（时间标记）实现
- 配速流程：建立（全景）→ 细节（中景）→ 情绪/纹理（特写）→ 高潮/Logo（全景或包装展示）
- 任何单个镜头不超过 15 秒（模型最大时长限制）

**镜头语法交替（营造张力和高级感）：**
- 荷兰角（倾斜角）/ 俯仰角
- 轻微旋转或转动
- 推入（向主体变焦）
- 拉出/揭示
- 摇摆或弧形运镜
- 甩镜头（少用）
- 在镜头之间**交替使用**这些运镜方式，使剪辑有驱动力而非平淡

**分镜头字段：**
- **元素引用：** 引用场景/道具元素 ID（如 `[Element_Underwater_Rig]`、`[Element_Trail_Run]`）
- **故事内容：** 产品主角镜头写明产品 + 主角/主观视角 + 动作；辅助镜头写明环境动作/抽象运动/细节，若无产品则明确标注
- **镜头语言：** 景别、角度、运动方式
- **时长：** 每镜头 ≤15s
- **品牌：** 标注强制包装镜头和 Logo 时长要求

#### 2.3 音频层设计

- **背景音乐：** 至少一个全局背景音轨。长视频（3 分钟+）且有清晰段落时，可设计多个音乐片段（各自 `audio_id` 和范围）。
- **旁白：** 若使用配音/旁白，定义声音特征、基调和确切脚本，用 `layout_instruction` 限定到相关镜头。

**暂停点：** 故事板确定后，向用户展示完整故事板，确认后再进入下一阶段。

### 阶段 3：关键元素图像生成

- 使用文生图生成场景元素，设置视觉基调，锁定产品颜色/材质/特征/调色板
- 使用图生图获取变体参考
- **用户已提供的素材直接绑定，不重复生成**
- 读取 `references/formats/video-prompt-grammar.md` 中的图像提示词规则编写 prompt

**暂停点：** 所有元素图像生成后，展示给用户审阅，确认后再进入下一阶段。

### 阶段 4：（可选）关键帧生成

当视频工具需要锁定第一帧时，在生成镜头视频前为每个镜头生成一个关键帧：
- **起始帧：** 动作开始前的场景 — 主体姿态、环境基础状态、摄像机初始构图
- **结束帧：** 动作完成后的结果 — 主体终结姿势、环境变化后状态、摄像机最终位置
- **高亮帧：** 视觉或情感冲击力最强的瞬间 — 以最大细节描述该静止画面

若不需要关键帧，直接执行阶段 5（元素 → 镜头视频）。

**暂停点：** 关键帧生成后（如执行），展示给用户确认。

### 阶段 5：镜头视频生成

- 每个镜头的参考输入：该镜头中出现的所有产品、场景和道具的元素图像
- 读取 `references/formats/video-prompt-grammar.md` 中的视频提示词规则编写 prompt
- ≤15s 的镜头用一次视频生成拿到完整片段
- >15s 的总时长需拆成多个 ≤15s 片段分别生成

**暂停点：** 所有镜头视频生成后，展示给用户确认。

### 阶段 6：音频层生成

- 基于故事板中的音频设计生成所有音频层
- 包括背景音乐和旁白（如有）

**暂停点：** 音频生成后，展示给用户确认。

### 阶段 7：最终剪辑与导出

- 所有视频片段和音频层就绪后进行最终合成
- 引导用户导出最终成片

### 用户素材处理规则

在生成内容之前，将用户上传的素材绑定并分配到适当的故事板位置。不要重复生成用户已提供的素材。具体操作：
1. 识别用户上传的素材类型（产品图、场景图、参考视频等）
2. 在故事板中标记对应元素为"用户素材绑定"
3. 生成时跳过已绑定的元素，直接使用用户素材作为参考输入

### 暂停确认机制

不要一次性运行所有步骤。在以下每个关键阶段停下来与用户确认：
- 规格确定后
- 故事板确定后
- 元素图像生成后
- 关键帧生成后（如执行）
- 镜头视频生成后
- 音频生成后

使用卡片或文字消息邀请用户审阅，获得确认后再进行下一步。

```

```

```
- 类型: [背景音乐 / 旁白]
- 范围: [Shot_XX - Shot_YY]
- 描述: [风格/基调/脚本]
- layout_instruction: [限定到哪些镜头]
```

## 视频生成方式

- 总时长 ≤15s 的成片：一次视频生成即可拿到完整片段，无需分段
- 总时长 >15s 的成片：拆成若干 ≤15s 片段各自一次生成，再后处理拼接/配乐/字幕
- 故事板中的多段 beat（如 0-3s/3-7s/7-12s）是同一次生成内部的时间轴描述，不等于要多次调用生成

## 静默自检

交付前内部跑一遍以下清单，不外显：

- [ ] 产品是否真实融入场景（非"桌面展示"）
- [ ] 首个镜头 3 秒内是否建立视觉钩子
- [ ] 产品在移除后场景是否仍暗示卖点（质量测试）
- [ ] 镜头语法是否交替变换（非全部平拍）
- [ ] 每个镜头是否 ≤15s
- [ ] ≤15s 成片是否一次生成（非分段拼接）
- [ ] >15s 成片是否已拆成 ≤15s 片段
- [ ] 用户素材是否已绑定（未重复生成）
- [ ] 负面约束是否已写进视频 prompt（no music / no subtitles / 旁白不写入视频 prompt）
- [ ] prompt 语言是否跟随用户输入语言（中文输入用中文 prompt）
- [ ] 旁白/对话语言是否遵循 Final_Video_Spec 的 Output Language
- [ ] 品牌要求（Logo/包装）是否在故事板中标注
- [ ] 措辞是否正向（不堆否定式约束）
- [ ] 宣称是否保守（无虚假/夸大）
- [ ] 合规敏感点是否已处理
- [ ] 全文语言是否与目标市场一致（无中英混杂）
