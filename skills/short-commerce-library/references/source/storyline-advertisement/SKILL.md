# 剧情广告

## 核心原则

产品融入高能剧情，霸总宠爱、绿茶修罗场、宫斗反转、重生逆袭……的风格剧情, 最终生成带货短视频。

## 输入诊断

每次生产前，识别并判断以下维度：

- 商品名称/卖点:(如果用户没输入则询问用户)
- 商品图片:(如果用户没输入则询问用户)
- 剧情风格: 霸道总裁 / 重生复仇 / 宫廷斗争 / 绿茶小三 / 家庭伦理 / 职场爽剧 / 悬疑反转 / 喜剧短剧 / 泰式误会 / 古装错位 / 末日生存 / 未来科幻 / 时间循环 / 娱乐综艺 (如果用户没输入则询问用户)
- 视频比例: (如果用户没输入则询问用户)

## 强制要求

必读：
- 必须使用`load_skill`工具加载 `marketing-video` 再进行创作
- 没有商品参考图则一定要反问用户要求输入
- 用户没有输入剧情风格则一定要反问用户要求选择
