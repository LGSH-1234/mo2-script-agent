# 风格变体参数

> 以下是可适配的风格参数，按创意选择一种，全片统一使用，不要混用。

## 风格选择规则

- 默认风格：**新国潮3D动画**
- 由 creative 的题材推断变体：古风/神话题材用水墨国风，科幻/未来题材用赛博国风，都市/现代题材用现代都市写实
- 同一成片内不得混用风格，角色造型必须前后一致

## 风格 1：新国潮3D动画（默认）

### 风格标签
`新国潮3D动画风格`

### 视觉特征
- 3D渲染质感，角色造型圆润有国风元素
- 色彩饱和度中高，偏暖色调
- 光影柔和但有方向性，类似动画电影的打光
- 材质有微妙的纹理感（布料、金属、石材）

### image_prompt 风格段
```
新国潮3D动画风格，3D渲染质感，国风角色造型，色彩饱和偏暖，柔和方向性光影，竖屏9:16
```

### 适用题材
- 公有领域IP改编（西游/山海经/聊斋）
- 原创国风角色故事
- 日常生活中的"国潮"美学表达

## 风格 2：水墨国风

### 风格标签
`水墨国风动画风格`

### 视觉特征
- 水墨渲染质感，笔触可见，留白多
- 色彩以墨色为主，点缀淡彩（青、赭、朱砂）
- 光影柔和散射，无强直射光
- 背景常有云雾、远山、竹林等国风元素

### image_prompt 风格段
```
水墨国风动画风格，水墨渲染笔触可见，墨色为主点缀淡彩，柔和散射光，大面积留白，竖屏9:16
```

### 适用题材
- 古代背景的哲理微叙事
- 山水/自然主题的情感短片
- 武侠/仙侠氛围的非动作场景

## 风格 3：赛博国风

### 风格标签
`赛博国风动画风格`

### 视觉特征
- 3D渲染+霓虹光效，传统国风元素与赛博朋克视觉混搭
- 色彩高饱和对比，霓虹色（青/品红/金黄）+暗色底
- 光影强烈，霓虹光源+体积光
- 场景含全息投影、电子符文、机械飞檐等混搭元素

### image_prompt 风格段
```
赛博国风动画风格，3D渲染霓虹光效，国风与赛博朋克混搭，高饱和对比色，霓虹光源体积光，竖屏9:16
```

### 适用题材
- 未来设定下的国风故事
- 科技与传统的碰撞冲突
- 赛博朋克美学的国风变体

## 风格 4：现代都市写实

### 风格标签
`现代都市写实动画风格`

### 视觉特征
- 3D渲染偏向写实，角色造型接近真人比例但有动画化处理
- 色彩自然真实，偏冷色调（灰蓝/水泥色/暖黄路灯）
- 光影模拟真实物理光照，窗光/路灯/屏幕光等实际光源
- 场景为现代都市环境（地铁/办公室/街道/公寓）

### image_prompt 风格段
```
现代都市写实动画风格，3D渲染偏写实，自然真实色调偏冷，物理光照模拟，现代城市场景，竖屏9:16
```

### 适用题材
- 都市生活中的微叙事
- 职场/情感/日常切片
- 现代社会现象的寓言化表达

## 角色一致性保障

无论选择哪种风格，保持角色一致性的方法：

1. **拍1关键帧定义角色**：拍1的 image_prompt 中完整描述角色造型（发型/脸型/服装/配色/体型），后续每拍复用同一描述
2. **后续拍引用拍1图**：拍2-5的 video_prompt 中用 `@图片1` 引用拍1关键帧作为角色参考
3. **服装与道具不变**：全片角色服装、配色、标志性道具不得变化
4. **表情可变造型不变**：角色表情随情绪变化，但五官比例/发型/服装固定

## 落 prompt 前自检

- 风格标签是否全片统一（5拍都用同一个风格段）？
- 角色造型描述是否在每拍都完整出现或通过图片引用保持一致？
- 风格选择是否与创意题材匹配？
- 是否在同一成片中混用了不同风格（禁止混用）？
