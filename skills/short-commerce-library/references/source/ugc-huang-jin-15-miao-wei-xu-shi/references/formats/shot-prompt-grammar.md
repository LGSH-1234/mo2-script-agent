# 分镜 prompt 文法与逐拍生成指令

> 以下是可适配的 prompt 模式，按创意改写，不要逐字照搬。

## 逐拍生成流程

每拍执行两步：

1. **文生图生成关键帧** — 先生成一张静态关键帧图片（竖屏 9:16）
2. **图生视频生成3秒片段** — 以关键帧为参考图，生成3秒动态视频

## image_prompt 文法

```
{风格标签}，{景别}，{画面主体描述}，{角色描述}，{场景描述}，{光线与色调}，{构图说明}，竖屏9:16
```

### 字段说明

| 字段 | 说明 | 示例 |
|---|---|---|
| 风格标签 | 从 style-variants.md 选取，全片统一 | 新国潮3D动画风格 |
| 景别 | 大特写/特写/近景/中景/全景/远景 | 大特写 |
| 画面主体描述 | 这一拍画面的核心内容，1-2句 | 少年睁开的眼睛，瞳孔中倒映着燃烧的星空 |
| 角色描述 | 角色造型、表情、姿态，需前后一致 | 齐耳短发少年，圆脸大眼，穿青色布衣，表情震惊 |
| 场景描述 | 环境与氛围 | 古寺屋檐下，夜空，远处山火映红云层 |
| 光线与色调 | 光源方向、色温、明暗对比 | 暖橙色逆光，暗部深蓝，高对比 |
| 构图说明 | 主体位置、视线方向、留白 | 主体居中偏上，下方留白，竖构图 |

### 各拍景别与镜头运动对照

| 拍 | 景别 | 镜头运动 | image_prompt 构图重点 |
|---|---|---|---|
| 拍1 | 大特写 | 静止/缓推 | 极近距离，一个细节占满画面，制造"侵入感" |
| 拍2 | 中景 | 手持微晃 | 主体与环境的关系可见，晃动感的构图留出运动空间 |
| 拍3 | 近景 | 极缓推/静默 | 主体面部或手部特写，画面极简，留白多，压低感 |
| 拍4 | 全景 | 快切/甩镜 | 大场面，主体在环境中比例小但动态强，冲击力来自规模 |
| 拍5 | 特写定格 | 定格/缓拉 | 主体一个关键细节定格，构图稳定，留出缓拉空间 |

## video_prompt 文法

```
@图片N 所示画面，{镜头运动描述}，{主体动作描述}，{环境变化描述}，{氛围变化描述}，3秒，竖屏9:16
```

### 字段说明

| 字段 | 说明 | 示例 |
|---|---|---|
| @图片N | 引用对应关键帧 | @图片1 所示画面 |
| 镜头运动描述 | 摄影机如何运动 | 镜头极缓慢向前推进 |
| 主体动作描述 | 角色在3秒内做什么 | 少年瞳孔微缩，眼睑轻颤 |
| 环境变化描述 | 场景在3秒内如何变化 | 远处火光渐强，云层流动 |
| 氛围变化描述 | 情绪氛围的细微变化 | 安静转为压抑，空气凝重 |

### 各拍 video_prompt 运动指引

**拍1（0-3s）钩子·建立异常**：
- 镜头：静止或极缓推（<5%位移）
- 主体：微表情或微动作，几乎静止
- 环境：单一元素缓慢变化（灯闪烁、水滴落、风吹发丝）
- 氛围：安静中的"不对劲"

**拍2（3-6s）加压·收紧**：
- 镜头：手持微晃，频率2-3Hz
- 主体：动作幅度增大，开始有明确方向性
- 环境：更多元素开始变化，声音层次增加
- 氛围：紧张感上升，压迫感增强

**拍3（6-9s）蓄力·断崖压低**：
- 镜头：极缓推或完全静止
- 主体：动作停滞或极慢，呼吸般的微动
- 环境：变化暂停，画面凝固
- 氛围：静默，空气稀薄，情绪真空

**拍4（9-12s）爆发·反转/高潮**：
- 镜头：快切或甩镜，大幅度运动
- 主体：用冲击帧+特效表达，避免复杂连续动作
- 环境：剧变，光/色/元素全面爆发
- 氛围：全频冲击，情绪释放

**拍5（12-15s）余韵·留钩**：
- 镜头：定格或缓拉
- 主体：回到静止，但状态已改变
- 环境：余波渐息，但留一个异常细节
- 氛围：回味+悬念，"故事还没结束"

## 拍4 动作规避策略

拍4是动作复杂度最高的一拍，直接生成复杂连续动作容易不稳定。规避策略：

1. **冲击帧优先**：用1-2个高冲击力的静态瞬间+快速转场替代连续动作
2. **特效替代动作**：用光效、粒子、环境剧变（爆炸/碎裂/光柱）替代角色复杂动作
3. **大场面缩小角色**：全景中角色比例小，动作简化为方向性运动，冲击力来自环境和镜头
4. **甩镜模糊**：快速镜头运动产生的动态模糊本身就是视觉冲击，不需要复杂角色动作

## 字幕口播设计指引

每拍字幕口播应满足：
- 单拍不超过15个字（3秒内可读完）
- 拍1-2用短句或词组建立氛围
- 拍3用最短的字（1-4字）或留白
- 拍4可以无声或仅一个词/短句爆发
- 拍5留一句悬念性文案

## 落 prompt 前自检

- image_prompt 是否包含风格标签且全片统一？
- image_prompt 是否标注竖屏9:16？
- video_prompt 是否引用了对应的关键帧图片（@图片N）？
- video_prompt 的主体动作是否在3秒内可完成？复杂动作是否已拆解或规避？
- 拍4是否用了冲击帧+特效策略规避动作难题？
- 字幕口播是否每拍不超过15字？
- 角色描述是否前后一致（同一造型、同一服装、同一特征）？
