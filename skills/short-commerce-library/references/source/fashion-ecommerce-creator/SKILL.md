# 女装电商带货全流程生成器

## 描述

本 Skill 为女装电商提供一站式素材生成能力，覆盖从模特四视图、KV 主视觉、

主图、长图、详情页到带货视频的全流程。

采用多参考图结构，分四阶段逐步锁定一致性：

- 阶段一 · 模特四视图（韩系纤瘦·素体净版锚点）：无模特图时由

  生成；单张模特图时延展为四视图。四视图 =

  左侧面部特写 + 右侧正面/侧面/背面站姿，16:9，白色背景，

  全程素体零配饰（不戴眼镜、无耳饰项链发饰帽子），

  默认模特为韩系女团脸 + 纤瘦高挑身材。锁定模特身份与身材，

  后续所有图复用。

- 阶段二 · 结构化反推 + 场景族构建：系统对 @参考图 执行 8 层结构化反推

  （镜头→主体→环境→服饰(4a服装/4b配饰)→色彩HEX→光影→质感→氛围），

  经「层级过滤矩阵」整层丢弃主体层与服装层、配饰层提取为建议清单

  供用户勾选、环境层差异化并扩展为「场景族」（1 主场景 + 3-5 个

  同风格不同地点子场景，每个子场景绑定完整摄影参数），产出

  「结构化反推卡 + 场景族锁定卡 + 配饰锁定卡」纯文本（原图全程不挂载）。

- 阶段三 · KV 主视觉：用模特四视图 + 服装图（@图1）在主场景 S0 生成

  一张 KV 大片，风格由过滤后的反推卡纯文本传递，配饰按配饰锁定卡

  采纳项文字注入。KV 通过自检与撞图核验后，对 KV 成图本身二次反推，

  产出「KV-DNA 卡」（含配饰基准层 + 场景族基准层）——本套素材延展的

  唯一风格事实来源。

- 阶段四 · 延展素材：用 @KV主视觉（图像挂载，锁风格基因）+ KV-DNA 卡

  （含配饰基准与授权子场景池的8层文本）双通道 + 模特四视图 +

  产品四视图（@图1）+ 服装 DNA 卡延展 5 张主图、长图、详情页、带货视频。

  含场景延展图从授权子场景池轮换选取不同地点（同套不重复），

  风格基因（色彩/光影/氛围/质感）全套锁定，实现"统一而不雷同"。

  带货视频执行「首帧-视频同体系锁」：UGC 类视频（方向①④）必须先由

  Step 5.5 专拍 9:16 镜前持机手机质感 UGC 首帧再生成视频，

  大片类/街拍类视频（方向③②）沿用 KV 系成图首帧——

  大片首帧出大片，UGC 首帧才出 UGC。

严格遵循淘宝 2026 新规：真实还原材质、人体比例和商品款式，白底图占比 80%+

且色值严格纯白，主图/详情页支持 3:4 竖图，视频前 3 秒出现核心穿着场景、

时长 ≤15s。

画面质量与一致性五引擎（本 Skill 核心机制）：

- 姿态与表情指令库（模块 A）：所有含模特的提示词禁止使用"自然""生动"

  "浅笑"等抽象形容词描述姿势与表情，必须从姿势池选择包含「重心与轴线 +

  手部任务 + 腿脚关系 + 头部与视线」的具体身体指令，并从表情池选择包含

  「眼部指令 + 嘴部指令 + 情绪由头」的表情微指令。

- 摄影质感系统 + 人体比例锁（模块 B，v4.7 增补）：每张图强制绑定

  五要素摄影参数（焦段+光圈+景深+机位+光影），缺一判提示词不合格；

  附加皮肤/面料质感锚点和针对性负面约束，杜绝塑料皮肤、平光死白和

  AI 渲染感；所有含模特图强制附加人体比例锁 + 纤瘦身材锚点

  （头身比约7.5、直角肩/四肢纤细/腿细长、机位腰胸高度、无广角畸变），

  严禁小尺寸直出，杜绝壮硕虚胖与病态骨感两个极端。

- 三重一致性锁定 + 场景族随机化 + 首帧-视频同体系锁

  （模块 C，v4.7 重写场景层，v4.8 增补视频首帧层）：

  约束前置写法 + 单模特强制锁 + 服装强制锁 + 场景族锁定卡。

  场景一致性从"全套同一地点"下沉为"风格基因级统一"：

  色彩HEX/光影/氛围/质感全套锁定，地点在授权子场景池内受控随机

  （不同房间/街角/户外角落），同套素材子场景不重复——

  既解决场景失控漂移，又解决全套雷同呆板。

  视频层执行首帧-视频同体系锁：首帧的视角/构图/布光 = 全片物理事实，

  UGC 视频必配 UGC 专拍首帧，禁止大片首帧+UGC 文字的失效组合。

- 强制双参考挂载 + 服装 DNA 卡 + 风格参考图物理隔离（模块 C0/C5）：

  每一次生图调用必须把 @图1（服装）与 @模特四视图（模特）作为参考图实际

  挂载进多参考输入，文本 @ 提及不算挂载；服装 DNA 卡 7 项特征写死进

  每条提示词。⚠️ @参考图 全流程禁止挂载——图像模型对挂载图片的

  模仿力远大于对否定文字的服从力，"挂图+文字禁止照搬"必然失效。

- 结构化反推引擎 + KV-DNA 延展链 + 模特原创性双保险

  （模块 C6/C7）：@参考图 与 KV 均使用同一套 8 层反推模板 +

  10-12 色 HEX 色板提取；@参考图 反推结果必须过「层级过滤矩阵」

  （主体层整层丢弃——长相/发型/眼镜文字零进入提示词、4a服装层

  整层丢弃、4b配饰层用户勾选后仅在 KV 阶段文字延迟注入且脸部遮挡类

  默认弃用、环境层差异化并扩展为场景族、水印剔除）；模特四视图为

  素体净版锚点（零配饰硬约束），模特长啥样只看四视图，戴什么只看

  配饰锁定卡，参考图对"人"的影响归零；KV 通过撞图核验后二次反推

  固化"生成偏移"为新基准（含配饰基准层+场景族基准层），延展图与 KV

  形成"直接父子"一致性——@参考图 只贡献被过滤后的风格基因，

  KV 是全套素材唯一视觉母本，且 KV 是自产资产、已过撞图核验，

  挂载它反而强化一致性。

## 使用场景

Use this skill when:

- 用户上传服装、包包、配饰等商品图片，意图生成电商素材

- 用户表达"做主图/详情页/带货视频/上新素材/淘宝图"等需求

- 用户需要为淘宝、天猫女装类目准备上新图片或短视频

Do NOT use this skill when:

- 用户仅需要普通图片生成，无电商用途

- 用户需要生成与商品实物不符的夸张效果图

- 用户未提供任何商品参考图

## 模块 A：姿态与表情指令库（所有含模特提示词强制套用）

### A1. 姿态构建公式

每个姿势由 5 个要素组成，缺一不可：

```

姿势 = 重心与轴线 + 手部任务 + 腿脚关系 + 头部与视线 + 表情微指令

```

硬规则（违反任意一条视为描述不合格，需重写提示词）：

- 禁用抽象词：提示词中禁止只写"站姿自然""姿势生动摆拍感"等形容词，

  必须替换为具体身体指令。

- 禁用表情抽象词：禁止只写"浅笑""表情自然""生动""有神"等空词，

  必须从表情微指令库（A5）选择包含「眼部+嘴部+情绪由头」的具体指令。

- 表情必须有"情绪由头"：写清她为什么是这个表情

  （如"像刚听到朋友喊她名字回头的瞬间"），禁止无来由的对镜假笑。

- 表情忌完美对称：嘴角单侧微扬、头微偏、眼睛不等幅眯起，

  才是活人；左右完全对称 = 假人。

- 忌平行对称：双臂双腿禁止平行、对称、同时垂直贴身；必须一曲一直

  或构成角度。

- 重心必偏移：重心落在单腿，胯部自然倾斜，形成 S 形或 K 形曲线。

- 手必须有任务：插口袋（露拇指）、拨发、扶帽檐、拎包、提裙摆、

  轻搭锁骨、单手叉腰——禁止双手垂放空置。

- 身体带角度：默认 45° 半侧身面对镜头，禁止正面直挺。

- 手掌不正对镜头，手指伸展有形，避免抓握拳状。

- v4.8 例外：UGC 对镜自拍类（Step 5.5 首帧与方向①④视频）持机手

  的任务固定为"举手机对镜"，另一手从姿势池手部任务中选取；

  "对镜自拍"本身是抽象词，必须写全「镜子位置 + 手机举法 +

  镜面反射构图」三要素（见 Step 5.5），禁止只写"女生对镜自拍"。

### A2. 分场景姿势池

生成时从对应池中选 1 个完整写入提示词，同套素材内姿势不得重复。

姿势池只定头部朝向，视线落点与表情统一由 A5 表情池配对供给。

```

另一手自然垂落指尖轻触大腿外侧，下颌微收，面朝镜头方向

P2: 3/4侧身，一手抬起轻拨耳侧头发，肘部打开形成三角形，另一手拎小包

垂在体侧，双腿一前一后交叉，回眸转头朝镜头方向

P3: 正面重心偏右腿，左腿膝盖内扣微弯，单手叉腰手指前三指露出，

另一手自然下垂，肩膀下沉放松，头部向叉腰侧微倾

P4: 侧身倚靠墙面/栏杆，一侧肩膀贴墙，一腿屈膝脚掌抵墙，双臂交叠环抱，

头转向镜头方向

```

```

### C6. 结构化反推引擎（v4.5 重写，v4.6 增补主体层丢弃与配饰拆分，

v4.7 增补环境层场景族扩展）

原理：图像模型对挂载图片的模仿力 >> 对否定文字的服从力。

"挂图 + 文字禁止照搬"是失效组合。正确做法是：

风格进文本，原图不进模型——文本反推允许逐层做外科手术式过滤，

而挂载图片是不可分割的整体信息注入。这就是"挂图必串、文本可滤"的根因。

v4.6 补充推论：文本同样会被执行——只要长相/眼镜描述进入提示词，

模型就会画出来，"仅供参考"四个字对图像模型无效。

所以主体层不再是"氛围参考"，而是整层丢弃。

v4.7 补充推论：环境层反推的价值不是"复刻一个地点"，而是提取

"空间类型 + 风格基因"，再裂变出一族同风格不同地点的子场景——

地点随机性与风格一致性可以同时成立。

v4.8 补充推论：视频模型是"让首帧动起来"——首帧的视角/构图/布光

就是全片物理事实，文字写一百遍"对镜自拍"也无法把第三人称大片

逆转成第一人称镜面自拍。首帧决定视角，文字改不了视角。

所以 UGC 视频必须专拍同体系首帧（见 Step 5.5 与 Step 6 同体系锁）。

#### C6.2 HEX 色板提取规则（12 色分析法）

- 提取 10-12 个色值，按明度排序

- 强制三分组并标注对应画面元素：

  - 中明度组（L 50-75）→ 通常对应环境主体/建筑/草地

  - 低明度组（L<50）→ 通常对应鞋/阴影/深色配饰

- 写入提示词时格式：

  `色系：奶白#F5F0E8为主，雾灰蓝#B0B8C2为辅，深褐#6E6553点缀，

  整体低饱和中高明度莫兰迪调`

### C7. KV-DNA 卡、配饰锁定卡与双通道延展（v4.5 新增，v4.6/v4.7 增补）
