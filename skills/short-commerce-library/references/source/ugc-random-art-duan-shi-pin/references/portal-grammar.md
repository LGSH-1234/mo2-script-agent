# Native portal grammar

The threshold must grow out of the selected movement's own material or spatial logic. Avoid a generic glowing ring.

## Transition families

| Family | Native threshold | Suitable carried-back motif |
|---|---|---|
| perspective | floor and wall lines converge, fold, or pull the room through one vanishing point | one impossible line or receding doorway |
| light | a motivated beam crosses the character and rewrites only what it touches | independent patch of light or shadow |
| brush / flat-color | edges break into strokes or hard color regions that spread from contact | one object retains the palette |
| ornament / botanical / gold-pattern | lines, leaves, or patterned foil grow from an existing edge | decorative border on an ordinary object |
| geometry / optical / spectrum | planes, grids, or color circles rotate into navigable space | one geometric object obeys the art-world rule |
| print / halftone / collage | paper tears, registration shifts, or pasted fragments reveal depth | one printed shadow or caption-shaped object |
| film / analog-video / chemical | flash, burn, emulsion, grain, or developing fluid changes the plate | a moving photograph or developed silhouette |
| dream / liminal / shadow | perspective or object scale becomes impossible while the camera stays calm | shadow, scale, or gravity anomaly |
| scanline / glitch / chrome | an existing screen, reflection, or interface expands into the environment | one object keeps a synthetic surface |
| mineral / linework / miniature | pigment, fine contour, or flat stacked space grows from a real surface | a mineral color trail or drawn creature |
| weather / mist / clarity | atmosphere changes first; the world rule emerges without a visible gate | wind, fog, or impossible clarity follows home |
| speed / cel | motion trails, held frames, or speed lines split one action into a passage | one delayed duplicate gesture |

## Character treatment

- Lock face, silhouette, hair, outfit, palette hierarchy, accessories, and proportions.
- Allow the selected medium to affect surface rendering after the crossing: brush texture, print edge, mineral pigment, film grain, or flat geometry.
- Keep at least three identity anchors unchanged and clearly visible in every art-space shot.
- At the threshold, transform environment first, then lighting, then surface medium. Do not morph face geometry.

## Conflict cleanup

Remove any negative prompt that forbids:

- people, figures, portraits, or the character's required anatomy
- the selected movement's light or shadow behavior
- the threshold material named in the transition family
- a required real-world opening shot

If the movement's core grammar still erases character readability, use the deterministic reroll rule in `SKILL.md`, report the rejected movement, and stop after three rejected draws.
