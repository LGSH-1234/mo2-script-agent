# Partial Video Editor

把用户口语化、模糊化、非技术化的视频局部修改需求，翻译成后期执行清单和视频编辑 Prompt。  
这个 skill 的目标不是“重做整条视频”，而是把改动**锁定在正确的时间、正确的区域、正确的对象**上，并且尽量保护其他内容不受影响。

## 一、这个 skill 真正要解决的问题

视频局部编辑最常见的问题，不是“不会改”，而是：

- 改动范围失控，最后整条画面一起漂
- 只想换一个局部元素，却把人物脸、构图、镜头一起改掉
- 前后帧连续性被破坏，出现闪烁、跳变、穿帮
- 用户说“只改这里”，但没有把“哪里”和“哪些别动”说清楚
- 输出太像创意文案，不像真正可执行的后期需求单

这个 skill 的职责，就是把这些风险前置消解掉。

## 二、适用场景

当用户出现以下需求时，优先使用本 skill：

### 1. 人物 / 物体局部替换
- 换衣服颜色、鞋子、帽子、配饰
- 替换手里的物品、桌上的产品、场景中的小道具
- 把一个指定物体换成另一个参考物
- 只改人物局部特征，不改整个人设

### 2. 背景局部修改
- 只改天空、地面、墙面、窗外、远景
- 删除路人、杂物、反光、污渍、穿帮元素
- 让某个区域加雨、加雾、改灯光氛围，但主体不动
- 扩一点背景，但不改变主体与镜头关系

### 3. 字幕 / UI / 招牌 / 包装信息修改
- 改招牌文字
- 改包装文案
- 改屏幕里的 UI
- 去水印、去贴纸、去字幕
- 只改信息层，不动底层真实场景

### 4. 表情 / 嘴型 / 动作微调
- 修嘴型
- 微调眼神方向
- 调整表情强弱
- 修正手势细节
- 只改局部表演细节，不重做动作设计

### 5. 限定时段编辑
- 只在某几秒生效
- 只改最后一个镜头
- 只改中间某一段
- 多镜头里只改其中一个镜头

## 三、优先级规则

当用户一个请求里同时混有多类编辑目标时，按下面优先级组织输出：

1. **人物 / 物体局部替换**
2. **背景局部修改**
3. **字幕 / UI / 招牌 / 包装信息修改**
4. **表情 / 嘴型 / 动作微调**
5. **限定时段编辑**

注意：  
“限定时段编辑”通常是**作用范围约束**，不是主编辑对象本身。  
所以如果用户说“第 3 秒到第 5 秒把包换成红色”，主任务仍然是“物体局部替换”，时间范围只是约束条件。

## 四、不适用场景

以下情况不要硬套本 skill：

- 用户要从零生成整条新视频
- 用户要重写整片剧情、脚本、分镜、节奏
- 用户要做全片风格改造
- 用户要完整的剪辑软件教学
- 用户只是泛泛想 brainstorm 视频创意，还没有明确局部编辑目标
- 用户要的是整片级重剪、重配音、重包装，而不是局部修正

如果用户需求已经明显超出局部编辑，应直接指出边界，而不是假装这个 skill 也能完美覆盖。

## 五、工作原则

### 原则 1：优先保护，不要优先发挥
局部编辑场景里，用户通常更在意“别把其他东西改坏”，而不是“你帮我顺便优化一下”。  
因此默认策略应该是：**最小必要改动**，不是“顺手美化全片”。

### 原则 2：先锁定范围，再写方案
不要一上来就写大段 Prompt。  
先把以下三件事搞清楚：

- 改动生效在哪个时间范围
- 改动发生在画面的哪个区域
- 哪个对象允许改，哪些对象必须锁住

### 原则 3：保护约束必须显式写出
很多局部编辑失败，不是因为模型不会改，而是因为“保持不变”的要求没有被明确写出来。  
所以凡是用户隐含表达了“其他别动”，都要转译成清晰约束。

### 原则 4：输出要像执行单，不要像创意提案
表达应偏后期制作语言，便于剪辑、特效、AI 视频编辑协作，不要写成泛泛的审美描述。

## 六、标准工作流

按下面顺序处理任务。

### Step 1. 识别编辑意图

先提取以下信息：

- **编辑对象**：谁 / 哪个物 / 哪块区域 / 哪层信息
- **编辑动作**：替换、删除、擦除、改字、修补、重绘、微调、绑定参考
- **时间范围**：全片 / 某镜头 / 某片段 / 某几秒
- **空间范围**：前景 / 背景 / 左侧 / 右上角 / 脸部 / 嘴部 / 手部 / 招牌 / UI 区域等
- **保护要求**：用户要求哪些内容不变
- **素材依赖**：是否有参考图、替换素材、风格图、原始资产
- **连续性要求**：是否必须与前后镜头、前后帧保持无缝衔接

如果用户没有明确给全，但足够推断，可以合理补全；如果关键变量缺失且影响结果，先补问。

### Step 2. 明确编辑边界

必须尽量把需求翻译成下面这种表达：

- **时间边界**：从哪里开始，到哪里结束
- **镜头边界**：只作用于哪个镜头
- **画面边界**：只作用于哪一块区域
- **对象边界**：只改哪个人物 / 物体 / 信息层
- **影响边界**：不要影响哪些邻近元素

如果用户说：

- “只改结尾”
- “就这一段”
- “这个人删掉”
- “右上角那个字改一下”
- “只修嘴型”

你要主动把这些模糊话，改写成清晰边界，而不是原样复述。

### Step 3. 主动补全保持不变项

除非用户明确允许，否则默认尽量保持以下内容稳定：

- 主体身份不变
- 未提及的人物与物体不变
- 姿态与站位不变
- 构图不变
- 景别不变
- 镜头角度不变
- 运镜节奏不变
- 灯光方向与亮度不变
- 整体时间氛围不变
- 未编辑区域的色彩与纹理不变
- 前后帧连续性不变
- 镜头前后衔接不变

如果是人物 / 物体替换类任务，尤其要强调：
- 不改脸
- 不改体型
- 不改动作
- 不改人物身份特征

如果是招牌 / UI / 字幕修改类任务，尤其要强调：
- 保留透视
- 保留原有表面材质
- 保留环境反光 / 阴影关系
- 不影响周围真实场景

如果是嘴型 / 表情 / 手势微调类任务，尤其要强调：
- 只改局部
- 不改变表演意图
- 不改变头部姿态
- 不改变身体动作节奏

### Step 4. 归类执行策略

将任务映射到最合适的执行策略，可单选，也可组合：

- **局部替换**：换掉局部物体或人物局部元素
- **局部删除 / 擦除**：删掉路人、杂物、反光、水印等
- **局部修补 / 重绘**：补背景、补边缘、修穿帮
- **信息层改写**：改字幕、包装文案、招牌、UI
- **局部表演修正**：修嘴型、眼神、表情、手势
- **限定时段编辑**：只在指定片段生效
- **参考图绑定替换**：按参考素材替换目标元素
- **多约束局部编辑**：同时存在“替换 + 时间限制 + 连续性保护”等复合要求

输出时明确说明：  
这次修改的主策略是什么，辅助约束是什么。

### Step 5. 预判风险

风险提示不要泛泛写“可能不稳定”。  
要具体到可执行层面，优先提示：

- 人物身份漂移
- 替换对象比例失真
- 边缘抠像痕迹 / 光边
- 帧间闪烁
- 背景透视错误
- 文字贴合错误
- 环境光不一致
- 局部运动轨迹不连续
- 嘴型与表演节奏不一致
- 改动段和前后镜头衔接跳变

通常提示 2~5 个最关键风险即可，不需要把所有可能性都列满。

## 七、补问策略

只有在以下信息缺失且明显影响执行质量时才补问：

- 不知道改哪个对象
- 不知道修改在哪个时间段生效
- 不知道修改在哪个画面区域生效
- 不知道什么必须保持不变
- 替换任务依赖参考图，但用户没有提供
- 用户说“改一下这个”，但上下文不足以定位“这个”是什么

补问时遵循以下规则：

- 一次最多问 2~4 个问题
- 问题必须短
- 问题必须可直接回答
- 优先问最影响结果的变量
- 如果能在合理范围内默认补全，就不要过度追问

## 八、输出规则

默认输出两部分，并且两部分必须对齐：

1. **结构化局部编辑单**
2. **成品 Prompt**

如果用户更像是在和后期同学协作，结构化编辑单要更偏制作语言。  
如果用户明显是要直接喂给模型，Prompt 要更完整、更强约束。

如有必要，可以在 Prompt 后追加：

- **Negative Constraints**
- **Optional Editor Notes**

## 九、标准输出模板

严格使用下面结构。

# 结构化局部编辑单

## 1. 编辑目标
用一句话概括要改什么，以及最终想达到什么效果。

## 2. 编辑范围
明确列出：
- **时间范围**
- **镜头范围**
- **画面区域**
- **编辑对象**
- **编辑类型**

## 3. 保持不变项
逐条列出必须锁定的内容，例如：
- 主体身份
- 脸部特征
- 姿态与动作
- 构图与景别
- 运镜方式
- 光线与氛围
- 未编辑区域
- 前后帧连续性
- 与前后镜头的衔接关系

## 4. 执行策略
用制作语言描述建议怎么做。  
应体现出遮罩、跟踪、局部替换、信息层改写、透视匹配、边缘修补、连续性控制等思路。

## 5. 风险提示
列出 2~5 个最可能出现的具体问题。

## 6. 后期备注
给剪辑 / 后期同学的执行提醒，例如：
- 哪个区域要重点跟踪
- 哪些边缘容易穿帮
- 哪个镜头衔接最容易跳
- 哪些材质和反光要保留
- 是否建议参考前后帧做一致性校正

# 成品 Prompt

写一个完整、简洁、约束明确的局部编辑 Prompt。要求：

- 明确说出只改什么
- 明确说出在哪个时间段改
- 明确说出在哪个区域改
- 明确说出哪些必须保持不变
- 强调前后帧与前后镜头连续性
- 如果有参考素材，要明确绑定
- 如果是文字 / UI / 招牌修改，要强调透视、贴合、材质、光影一致性
- 如果是人物局部替换，要强调身份、动作、镜头不变
- 如果是表情 / 嘴型微调，要强调只改局部表演细节，不改整段表演设计

必要时补：

## Negative Constraints
明确禁止出现的问题，例如：
- 不要改变主体身份
- 不要改变构图与运镜
- 不要影响画面其他区域
- 不要新增无关元素
- 不要改变灯光与时间氛围
- 不要产生闪烁、抠边、透视错误、比例错误、形变

## 十、表达风格要求

整体语气应像一个经验丰富的后期 lead 在下执行单：

- 精确
- 干净
- 有边界
- 可执行
- 少废话

避免：

- 大量空泛形容词
- 与执行无关的审美抒情
- 模糊词堆叠
- 不加约束的创意扩写

优先使用这类表达：

- “仅修改……”
- “将改动限制在……”
- “其余内容保持不变”
- “锁定主体……”
- “不要影响……”
- “保持前后帧连续”
- “保留原有透视 / 光影 / 材质关系”
- “只对该时间段生效”

## 十一、示例

### 示例 1：人物手持物替换
**用户说：**  
“最后一个镜头里把女生手上的包换成黑色皮质托特包，人物脸、动作和镜头都别动。”

**处理重点：**
- 主任务是人物 / 物体局部替换
- 时间范围是最后一个镜头
- 只改手持包
- 锁定脸、体态、动作、运镜、构图
- 关注手部接触边缘和包体运动一致性

### 示例 2：路人去除
**用户说：**  
“2 秒到 4 秒把左边前景那个路人擦掉，主角和背景氛围别变。”

**处理重点：**
- 主任务是局部删除
- 有明确时间范围
- 重点保护主角与背景连续性
- 注意删除后的地面、墙面、阴影补全

### 示例 3：招牌改字
**用户说：**  
“只改右上角招牌文字，街景、人物、灯光都不要动，透视保持一致。”

**处理重点：**
- 主任务是信息层改写
- 只改右上角招牌区
- 保留招牌表面结构、透视、环境反光与灯光关系

### 示例 4：嘴型微调
**用户说：**  
“这一句台词嘴型不太对，帮我只修嘴部，别把表情和头部动作改掉。”

**处理重点：**
- 主任务是局部表演修正
- 只改嘴部区域
- 锁定表情强度、头部姿态、身体动作和镜头节奏

### 示例 5：限定片段改天气
**用户说：**  
“第 3 秒到第 5 秒把窗外改成下雨，但室内人物、光位和镜头运动都不要动。”

**处理重点：**
- 主任务是背景局部修改
- 时间范围明确
- 只改窗外区域
- 保护室内人物、灯光逻辑、镜头运动和前后段衔接
