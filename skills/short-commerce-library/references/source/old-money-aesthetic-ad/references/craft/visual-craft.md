## 构图策略

| 构图类型 | 描述方式 | 效果 |
|---|---|---|
| 框架构图 | "通过前景物件（台灯/书架/门框）形成窥视视角" | 隐私感、窥探感、层次纵深 |
| 前景遮挡 | "前景的XX作为遮挡，画面焦点在背景" | 引导视线、空间纵深 |
| 对称构图 | "画面左右对称，产品在中轴线偏移位置" | 庄重、仪式感、不刻意 |
| 三分构图 | "产品位于画面三分线交叉点，非中心" | 不刻意展示、自然存在 |
| 负空间构图 | "大面积留白，产品在画面边缘" | 孤独、疏离、克制 |

## 产品融入策略

老钱美学的产品必须自然存在于场景中，不可被刻意展示：

| 策略 | 描述 | 适用产品 |
|---|---|---|
| 阴影隐藏 | "产品隐藏在书架旁的阴影里" | 电视/电子产品 |
| 桌面静物 | "产品作为桌面静物之一，旁边有茶杯和旧书" | 香水/小家电/酒类 |
| 环境反射 | "产品表面反射环境光线（壁炉火光/窗光）" | 电子产品/汽车/金属产品 |
| 人物手持 | "一只手（不露脸）自然地握着产品" | 酒杯/书籍/小件 |
| 远景点缀 | "产品在画面远处出现，非焦点" | 汽车/大型家电 |

## 35mm胶片质感描述模板

```
极度克制的纹理细节，模拟35mm胶片质感。细腻的胶片颗粒感，暗部有微弱的胶片噪点。低对比度画面，高光不溢出，暗部保留细节。
```

可根据场景微调：
- 室内场景追加："暖色调偏移，模拟室内灯光下的胶片白平衡。"
- 雨天场景追加："冷色调偏移，暗部偏青，模拟阴雨天的胶片白平衡。"
- 壁炉场景追加："暖色调偏移，高光偏橙红，模拟火光照射下的胶片白平衡。"
