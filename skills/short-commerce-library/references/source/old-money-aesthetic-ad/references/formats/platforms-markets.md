# 平台与市场适配

这些是可适配的模式与句式，按场景改写，不要逐字照搬。

## 默认规格

| 维度 | 默认值 | 备注 |
|---|---|---|
| 目标市场 | 中国大陆 / 中文 | 若用户指定其他市场，整体语言随之调整 |
| 画幅 | 16:9 横屏 | Old Money美学以横屏为主，宽幅画面支撑古典构图纵深 |
| 时长 | ≤15s | 一次生成完整成片；>15s拆分多段 |
| 帧率 | 24fps | 模拟胶片质感，24帧的动态模糊更接近35mm胶片 |
| 旁白语言 | 中文 | 旁白内容用中文书写，语速0.85倍速 |

## 平台适配

| 平台 | 画幅 | 时长限制 | 注意事项 |
|---|---|---|---|
| 品牌官网/TVC | 16:9 | 15-30s | 可接受>15s成片，拆分生成后拼接 |
| 抖音/快手 | 9:16 | ≤15s | 若需竖屏版，重新编写prompt，保持Old Money色调与克制运镜 |
| 小红书 | 3:4或1:1 | ≤15s | 适合产品融入场景图的静态展示 |
| 微信视频号 | 16:9或9:16 | ≤15s | 横竖皆可，默认16:9 |

## 画幅变化时的调整规则

若从16:9调整为9:16竖屏：
- 框架构图改为上下遮挡（顶部/底部前景）。
- 水平运镜改为垂直运镜（极缓上摇）。
- 产品融入策略不变，但构图重心从横向三分线改为纵向三分线。
- 色调、光线、质感、声音策略全部不变。

## 落prompt前自检

- [ ] 画幅是否确认？默认16:9。
- [ ] 时长是否≤15s？若是则一次生成。
- [ ] 旁白语言是否与目标市场一致？
- [ ] 帧率是否标注为24fps（若需胶片质感）？
