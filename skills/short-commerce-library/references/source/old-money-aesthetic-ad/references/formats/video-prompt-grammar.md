# 视频prompt文法与生成规则

这些是可适配的模式与句式，按场景改写，不要逐字照搬。

## prompt结构

视频生成prompt按以下顺序组织，每段以换行分隔：

```
产品外观参考 @图片1，环境参考 @图片2。
摄像机：<运动类型>，<速度描述>。
主体：<画面中的具体动作与状态>。
空间：<镜头中空间关系/焦点转移>。
光线：<光线类型与方向>。
色调：<Old Money三色>。
质感：<胶片/数字质感描述>。
音频：<BGM描述 + SFX提示>，无对话，无字幕。
```

## 摄像机运动词库

老钱美学只允许以下克制运镜，禁止快推/快拉/手持晃动/快速摇移：

| 运镜类型 | 描述方式 | 适用场景 |
|---|---|---|
| 极缓推进(Push-in) | "极其缓慢的推进，每秒移动不到2厘米，画面近乎静止" | 室内场景、产品融入 |
| 固定镜头(Static) | "固定镜头，画面完全静止" | 空镜环境建立、产品特写 |
| 极缓摇移(Slow Pan) | "极其缓慢的横向摇移，几乎不易察觉" | 展示空间全貌 |
| 缓推+焦点转移 | "镜头缓慢推进过程中，焦点从前景A缓缓转移到背景B" | 从环境到产品的过渡 |

## 光线词库

| 光线类型 | 描述方式 | 效果 |
|---|---|---|
| 侧逆光 | "侧逆光，使空气中的尘埃清晰可见" | 体积感、时间静止感 |
| 壁炉火光 | "壁炉里的微弱火光在金属/木质表面缓慢摇曳倒影" | 温暖、私密、时间流逝感 |
| 烛光散射 | "烛光的柔和散射，形成暖色光晕" | 亲密、仪式感 |
| 雨天漫射光 | "阴雨天的柔和漫射光，无直射光源" | 忧郁、内省 |
| 台灯光束 | "古铜色台灯形成的光束，照亮局部区域" | 阅读感、专注 |

## 色调词库

Old Money调性限定在以下色域，不可使用高饱和明亮色：

| 色调 | 色值描述 | 适用场景 |
|---|---|---|
| 深棕 | 深胡桃木/雪茄烟叶色 | 书房/壁炉室/木质环境 |
| 橄榄绿 | 磨损的墨绿色真皮/苔藓色 | 沙发/书房/花园 |
| 暗金 | 氧化的黄铜/旧金色 | 灯具/画框/产品金属件 |
| 勃艮第红 | 褪色的酒红色（可替代暗金） | 织物/书脊/靠垫 |
| 象牙白 | 泛黄的米白色/羊绒色 | 羊毛开衫/瓷器/亚麻 |
| 石板灰 | 建筑石材的灰青色 | 花园/外墙/石板路 |

## 质感词库

| 质感 | 描述方式 |
|---|---|
| 35mm胶片 | "模拟35mm胶片质感，极度克制的纹理细节" |
| 框架构图 | "框架构图，通过前景物件形成窥视视角" |
| 前景遮挡 | "古铜色台灯底座作为前景遮挡，形成窥视视角" |
| 胶片颗粒 | "细腻的胶片颗粒感，暗部有微弱的胶片噪点" |
| 低对比度 | "低对比度画面，高光不溢出，暗部保留细节" |

## 参考图引用规则

- prompt中使用 `@图片1`、`@图片2` 语法引用ImageList中的参考图。
- 产品图引用：`产品外观参考 @图片1`。
- 场景图引用：`环境参考 @图片2`。
- 若有角色参考：`人物形象参考 @图片3`。
- 必须在prompt开头声明所有引用，再描述画面。

## 15s一次成片规则

时长≤15s的成片用一次视频生成即可拿到完整片段。分镜中的beat（0-3s/3-7s/7-12s/12-15s）是同一条prompt内的时间轴描述，不分段多次生成。只有成片>15s时，才拆成多个≤15s片段各自一次生成，再做后处理拼接。

## 音频层prompt写法

在视频prompt末尾附加音频层描述：

```
音频：(背景播放着<具体BGM描述，含乐器和情绪>，混合着适量的黑胶底噪)，<有/无对话>，<有/无字幕>。
```

示例：
```
音频：(背景播放着低沉的大提琴与钢琴二重奏，混合着适量的黑胶底噪)，无对话，无字幕。
```

## 完整prompt示例

情境：15秒品牌广告，旁白驱动型。

```
画面呈现一个阴雨天、光线昏暗的古典书房内部。一台电视被巧妙地隐藏在书架旁边的阴影里，屏幕未开启，只反射出旁边壁炉里的微弱火光。前景是一张磨损的墨绿色真皮单人沙发，扶手上搭着一件随意叠放的米白色羊绒开衫。摄像构图采用框架构图，通过一座古铜色台灯的底座作为前景遮挡，形成窥视视角。色调为深棕、橄榄绿和暗金。电影级布光，强调侧逆光，使空气中的尘埃清晰可见。极度克制的纹理细节，模拟35mm胶片质感。

产品外观参考 @图片1，环境参考 @图片2。
摄像机：极其缓慢的推进（Push-in），每秒移动不到2厘米，画面近乎静止。
主体：窗外的人工降雨打在玻璃上，水流弯曲滑落。电视金属边框上有壁炉火光的缓慢摇曳倒影。无任何人物出现。
空间：镜头推进过程中，画面焦点从前景的沙发扶手，缓缓转移到背景的电视边框上。
光线：侧逆光，壁炉火光散射。
色调：深棕、橄榄绿和暗金。
质感：模拟35mm胶片，极度克制的纹理细节。
音频：(背景播放着低沉的大提琴与钢琴二重奏，混合着适量的黑胶底噪)，无对话，无字幕。
```

## 落prompt前自检

- [ ] 是否以引用参考图开头？
- [ ] 摄像机运动是否在允许的克制运镜范围内？
- [ ] 色调是否限定在Old Money色域内？
- [ ] 光线是否具体到方向和效果？
- [ ] 质感是否包含35mm胶片模拟？
- [ ] 音频层是否写明具体乐器和情绪？
- [ ] 是否标注"无对话，无字幕"（旁白驱动型除外）？
- [ ] 全文是否正向措辞（不堆否定式约束）？
