
# 视频分段规则（segmentation_guide）

本文件定义「视频本地化」流程中如何把整段视频切成便于逐段处理的片段。
分段质量既决定后续配音替换和口型同步的效果，也直接决定 Seedance 的调用次数，请严格按本规则产出分段方案。

分段的产物是一份**分段表**（见末尾格式），随后交给视频切割工具执行。

---

## 一、最高目标：分段越少越好，能一段就一段

分段的**首要目标是让 Seedance 的生成调用次数最少**——最理想的结果是**整条视频只有一段、只调用一次 Seedance**。因此每次分段都从同一个假设出发：

> **默认把整条视频当作"一整段"。只有被下面列出的硬性因素逼迫时，才引入切点；不到万不得已不切。**

必须反复强调的一点：**"场景切换 / 镜头切换 / 景别变化"本身不是切的理由。** 哪怕一段视频里有多次镜头切换、多个机位、多个不同动作，只要它们连起来是**一段完整的演绎**、没有把任何一句台词或一个连续动作卡在中间断开，就应当**保留为同一段**，交给 Seedance 一次直出。镜头切换点只是"万一需要切时，首选落刀的安静位置"，**不是"必须在此切"**。

**唯一需要引入切点的硬性因素只有一条：**

1. 整段时长**明显超过**所选模型上限（超出第三节的容差），且无法一次生成。

除此之外，一律**保持整段**。

> **【禁止】不得以"有无对白 / 有无台词"作为分段依据或切点。** 一段视频里某处没有台词（空镜、纯产品展示、片头片尾、说话间隙的静默等），**不构成任何切分理由**，绝不能因为"这一小段没有对白"就把它从整段里摘出来单独成段。分段只由"时长是否超上限"和"台词是否完整"决定，与该片段有没有对白**完全无关**。

## 二、两条铁律（优先级严格排序）

在"整段优先"的姿态下，权衡切点时有两条不可颠倒的铁律：

1. **【最高】台词完整**：任何一句台词都必须完整地落在同一个片段里，
   **绝对禁止把一句完整台词切成两半**。这是压倒一切的要求——哪怕因此片段偏长，
   也不能为了凑长度而切断台词。
2. **【次高】片段最大长度（软上限，带容差）**：在保证台词完整的前提下，单段时长尽量不超过
   **所选生成模型的上限**（见第三节）。但这是**软上限**——略超时先尝试直出、报错再拆
   （见第三节容差规则），**不做预防性拆段**。两条冲突时，永远让"最大长度"给"台词完整"让路。

其余考量（切点落在安静处、每段可独立编辑等）都在这两条之下、且在"分段越少越好"的前提下兼顾。

## 三、片段最大长度、容差与"先直出、报错再拆"

单段时长上限**取决于用户选用的视频生成模型**，切割前必须先确定用哪个模型：

| 生成模型 | 单段标称上限 |
| --- | --- |
| Seedance 2.0 | 15 秒 |
| Seedance 2.5 | 30 秒 |

- **用户未指定模型时，默认按 Seedance 2.5（上限 30 秒）分段。**
- 若未来接入其他模型，按该模型公布的单次生成时长上限取值。
- **单段时长不得低于 4 秒**（硬下限）。若某个候选片段不足 4 秒，不要让它单独成段——
  在不切断任何台词的前提下，把它与相邻片段合并，直到不短于 4 秒。**绝不允许把低于 4 秒的片段单独交给视频生成工具**（Seedance 对过短片段的生成效果不稳定）。

**关键：上限是"软目标"，不是"硬红线"。**

- **略超上限先直出**：当某段时长**只超过上限极小的幅度（最多 0.1 秒，绝不允许超过 0.1 秒）**时
  （例如上限 15s、实际 15.1s），**不要因此抢先拆段**——先把它当作"恰好到上限"、按**单段**规划，
  交给 Seedance **尝试一次直出**。**超过 0.1 秒的一律不算"略超"，按下面"明显超限"在分段阶段就拆。**
- **报错才回头重排**：**只有当 Seedance 真的因时长限制报错、无法一次生成时**，才回过头重新规划这一段，
  在最近的安静点（句间停顿 / 镜头切换处，**绝不切在台词内部**）把它拆成**尽量少**的段，再各自生成。
- **超限（超出 0.1 秒容差）**：只要一段超过上限达 0.1 秒以上（无论是 15.2s 还是 50s），
  就在分段阶段按铁律与安静点拆分，拆成尽量少的段数，不必等报错。
- 原则始终是：**尽可能少地调用 Seedance，能一次直出就不做预防性拆段。**

## 四、切点该落在哪里（仅当"确需切"时才用）

**先分清：本节讲的是"当第一/三节的硬性因素逼你必须切时，切点该落在哪"，而不是"看到这些点就要切"。**
若不需要切，直接忽略本节、保持整段。

确需切分时，按以下顺序寻找切点，命中高优先级就在此处切：

1. **镜头/场景切换点**：画面切镜、转场、机位大幅变化处——这是**落刀时**接缝最不可感知的位置。
   （再次强调：它是"需要切时的最佳落刀点"，**不是"必须切点"**。）
2. **说话人轮换的间隙**：A 说完、B 尚未开口之间的静默处切分，让每段尽量只含
   "一轮对话"或"同一说话人的一段连续台词"。
3. **同一说话人的自然停顿**：若一个人连续说很久（导致片段超上限且报错），
   在其**句子之间**的换气/停顿处切开——只能切在句与句之间，绝不切在句子内部。
> **注意：无对白/无台词的空镜、片头片尾、静默段落不是切点。** 不要因为"这里没台词"就在此切开、
> 更不要把它单独摘成一段（见第一节【禁止】）；它只应作为整段的一部分，随整段一起处理（见第五节）。

## 五、无对白片段：不因它切段；是否透传另有判据（不由"有无对白"决定）

**"有没有对白"只影响【要不要翻译/配音】，既不影响【怎么分段】，也不单独决定【要不要送 Seedance】。** 三件事彻底分开：

- **分段阶段**：无对白（空镜、纯产品展示、片头片尾、说话间隙的静默等)**绝不作为切点、绝不单独摘成一段**
  （见第一节【禁止】、第四节提示)。它应当**留在所属整段里**，随整段一起交给 Seedance 一次直出。
- **`has_dialogue` 字段**：只标记这段"要不要翻译/配音"。只有当某一整段(因时长超限被硬性切出来的段)**通篇没有任何对白**时，
  才标 `has_dialogue=false`。这是处理标记，**不是允许你为了摘无对白内容而额外切段**，
  **更不等于"该段可以原样透传、不用送 Seedance"**。
- **是否原样透传(不送 Seedance)——判据是"这段里有没有需要改的东西"，不是"有没有对白"**：
  「需要改的东西」= ①有要翻译/配音的台词，**或** ②有被用户要求替换的人物/道具在这段**出镜**（完整出镜、部分肢体都算）。
  - 满足 ① 或 ② 任一 → **必须送 Seedance**。**特别地：一段 `has_dialogue=false` 但待替换人物仍在画面里(哪怕不说话) → 仍要送 Seedance 换人**，否则成片里这个人会一会儿新形象、一会儿变回原样,前后穿帮。
  - **只有 ① ② 都不满足**（既无台词、也没有任何待替换人物/道具出镜，如纯空镜、纯环境镜头) → 才原样透传、不调用 Seedance。

换句话说：`has_dialogue` 字段照常记录，但它**永远不能反过来成为新增切点的理由，也不能单独用来判断能否透传**。
段内夹着的一两秒静默/换气/空镜过渡，一律算在同一段里，不拆。

## 六、硬约束

- **禁止在一句台词内部切断**（最高铁律）。若某句台词横跨候选切点，切点顺延到该句结束后的间隙。
- **单句本身就超过模型上限的极端情况**：这句仍**不可切分**，让该片段整体略超上限，
  并在分段表里标注 `over_limit: true` 提示后续处理（如需要可对该单句降级用更长上限的模型，或提示用户）。
  台词完整永远优先于长度上限。
- **单段时长范围 4 秒 ~ 模型上限（含容差）**：不得低于 4 秒（不足则与相邻片段合并，不切断台词，绝不把低于 4 秒的片段单独送生成工具）；
  上限为软目标，略超先直出、报错再拆（见第三节），只有超出容差才在分段阶段拆分。
- **一个片段内的说话人可以有多个**，但每个说话人的每一句都必须完整。
- **保留原始时间轴**：每段必须记录 `start`、`end`（精确到 0.1 秒），
  合并时按此顺序无缝拼接，保证总时长与原片一致。
- **不因"有无对白"增删切点**：无对白的空镜/静默只是整段的一部分，**不单独成段**（见第一、五节）；
  只有当某段(因时长超限被切出来的段)通篇无对白时才标 `has_dialogue=false`，该段照常保留在分段表里并保序，不得遗漏，否则合并会缺片。
- **相邻片段首尾相接**：前一段的 `end` 必须等于后一段的 `start`，不留空隙、不重叠。

## 七、如何从 marketing_video_analysis 结果推导分段

`marketing_video_analysis` 通常会返回镜头/场景切分、时间轴、每句台词的说话人与起止时间、
画面描述等信息。据此按"分段越少越好"推导：

1. **先假设整条视频就是一段**，算出总时长；
2. 若总时长在所选模型上限（**含容差**）之内 → **直接一段搞定**（无论段内有没有无对白片段，都不因此拆分，见第一、五节）；
3. 若总时长**明显超上限** → 才需要拆：在满足台词完整的前提下，按第四节的切点优先级，
   把它拆成**尽量少**的几段，每段尽量接近上限（能两段绝不三段）；
4. 对照第六节硬约束校验：切点是否落在台词内部（若是则顺延）；**未把无对白段落当作切点或单独摘段**；
   因时长切出的段若通篇无对白则已标 `has_dialogue=false` 并保序；
   相邻片段是否首尾相接；
5. 输出分段表。

若分析结果缺少逐句时间戳，则退化为按镜头切换点近似，但仍遵循"分段越少越好"——
能合并的相邻镜头仍合并成一段，不要一个镜头一段。

## 八、分段示例

**例：一条 15.1s 的带货视频，含 3 次场景切换，但为一段完整演绎**

解析结果：

- 0s–6s：女士完整出镜，手持磨砂膏展示、挖膏体，说台词（该句 6s）
- 6s–11s：膏体特写 + 仅手臂入镜涂抹冲洗，说台词（该句 5s）
- 11s–15.1s：女士完整出镜站台面后指向产品，说台词（该句 4s）

**正确分段：1 段。** 三部分虽有场景/景别切换，但连起来是"展示 → 演示 → 推荐"的一段完整演绎，
没有任何台词或动作被卡在中间。总时长 15.1s：对 Seedance 2.5（30s）远未到顶，对 2.0（15s）也仅超 0.1s
（在容差内）——因此**整条只出一段、尝试一次直出**。只有在用 2.0 且 Seedance 真的因时长报错时，
才按第四节从镜头切换点（如 11s 句间）拆成 `0–11s`、`11–15.1s` **两段**即可，**绝不拆成三段**。

```json
{
  "video": "...",
  "total_duration": 15.1,
  "target_language": "en",
  "generation_model": "Seedance 2.5",
  "max_segment_seconds": 30,
  "segments": [
    {
      "index": 1,
      "start": 0.0,
      "end": 15.1,
      "scene": "浴室，女士展示并演示身体磨砂膏后推荐",
      "has_dialogue": true,
      "over_limit": false,
      "speakers": ["女主"],
      "lines": [
        {"speaker": "女主", "start": 0.0, "end": 6.0, "text": "你们有没有那种洗完澡皮肤还是糙糙的，我用这个已经第三罐了，颗粒超细，搓身上一点都不拉扯"},
        {"speaker": "女主", "start": 6.0, "end": 11.0, "text": "烟酰胺提亮加温和去角质，洗完真的滑嫩嫩的，像做了个身体SPA"},
        {"speaker": "女主", "start": 11.0, "end": 15.1, "text": "想要滑嫩肌的姐妹，同款身体磨砂膏搜烟酰胺磨砂膏安排上"}
      ]
    }
  ]
}
```

## 九、分段表格式（JSON）

```json
{
  "video": "原视频标识或路径",
  "total_duration": 42.6,
  "target_language": "en",
  "generation_model": "Seedance 2.5",
  "max_segment_seconds": 30,
  "segments": [
    {
      "index": 1,
      "start": 0.0,
      "end": 6.2,
      "scene": "咖啡馆内景，两人对坐",
      "has_dialogue": true,
      "over_limit": false,
      "speakers": ["女主", "男主"],
      "lines": [
        {"speaker": "女主", "start": 0.5, "end": 2.3, "text": "你到底想干什么"},
        {"speaker": "男主", "start": 3.0, "end": 5.8, "text": "我只是想把话说清楚"}
      ]
    },
    {
      "index": 2,
      "start": 6.2,
      "end": 9.0,
      "scene": "窗外空镜",
      "has_dialogue": false,
      "over_limit": false,
      "speakers": [],
      "lines": []
    }
  ]
}
```

字段说明：

- `generation_model` / `max_segment_seconds`：记录所选模型及其单段上限，切割工具据此校验（上限为软目标，见第三节容差）。
- `over_limit`：仅当"单句本身超过模型上限、无法切分"时为 `true`，其余为 `false`。
- `lines` 保持**逐句列表**，**不要合并**成一整段——后续每句要单独评估语速、单独翻译、单独填进视频生成提示词。
- `has_dialogue=false` 仅表示该段**无需翻译/配音**；它**不代表该段可以原样透传**——若该段仍有待替换的人物/道具出镜，照样要送 Seedance 换人（是否透传的判据见第五节，取决于"有没有需要改的东西"，而非有没有对白）。
- `speakers` 用原片中稳定一致的角色名（与人物替换清单里的名字对齐）。
