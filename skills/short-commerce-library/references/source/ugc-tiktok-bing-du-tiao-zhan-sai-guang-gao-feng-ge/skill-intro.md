# TikTok 病毒挑战赛广告 · 极速上手指南（skill-intro.md）

> **一句话定位**：以 TikTok/抖音爆款 hashtag 病毒挑战赛为标杆，用可复制招牌动作、洗脑 BGM 强卡点、霓虹活力与全民 UGC 二创，把品牌转化为全民参与的可见病毒传播欲望。**动作即模因，卡点即病毒，参与即传播。**

## 🚀 30 秒上手流程

1. **锁基准资产**：先定 `@CHAR_CHALLENGER`（活力挑战发起人 Model Card）+ `@MOVE_SIGNATURE`（招牌病毒动作）+ `@SCN_CHALLENGE`（霓虹场景）+ `@PROP_BRAND`（品牌道具/logo），一次性锁定，全程 @ 引用禁止链式改。
2. **选文生图版本**：默认用 `SKILL.md §二` 的 MJ v8 专属版或常规通用版；用户点名"角色资产卡/Model Card/定妆卡"时才输出第三版本（10 格）。
3. **写剧本**：套四段式病毒挑战赛——①挑战发起招牌动作 → ②洗脑 BGM 卡点演示 → ③全民 UGC 二创混剪 → ④hashtag 召唤参与（详见 `02-viral-script-hooks.md`）。
4. **生成视频**：套 `SKILL.md §三` 的 11 段式多参引擎，**除台词外整体描述必须用中文**，竖屏 9:16 手机原生，逐段注入舞蹈动力学 + 光影五子层。
5. **配音效**：洗脑原创 BGM/热门神曲强卡点 + 口号 chant + hashtag 口播（详见 `03-sound-design-asmr.md`）。

## 🎯 五大不可动摇配方速查

| 配方 | 数值锚点 |
|---|---|
| **霓虹动感光** | 霓虹环形光右侧 20° 5500K 鲜艳，卡点频闪轮廓光后方 150° +1.5 档彩色边缘，Key:Fill 2:1 活力 |
| **竖屏全身舞蹈** | 手机 24mm 等效广角全身，1.3m 竖屏 9:16，固定机位 + 卡点甩动/推拉对齐 BGM 节拍 |
| **可复制招牌动作** | `@MOVE_SIGNATURE` 简单可复制模因，动作同步 beat，全民 UGC 二创零漂移裂变传播 |
| **舞蹈动力学** | 纯动作/道具/场景镜头 AU 转译为招牌动作节拍/肢体律动/霓虹脉冲/卡点闪光，声明 `[本镜无角色主体]` |
| **活力 AU 表演** | 发起 AU6+AU12 微笑（B 级），招牌动作 AU25+AU26 张口喊（D 级），全民混剪 AU6+AU12+AU25（C 级） |

## ⚠️ 三条红线
- **严禁不可复制**：招牌动作须简单易复制全民可参与，绝不允许高难度专业舞蹈、复杂不可模仿动作。
- **严禁无卡点**：动作必须同步洗脑 BGM 节拍卡点，绝不允许脱拍、慢节奏、无循环点。
- **字幕铁律**：No subtitles.（字幕/hashtag 花字绝不由模型生成，须后期硬压）；口号保留原语言口语化，口型同步精准。
