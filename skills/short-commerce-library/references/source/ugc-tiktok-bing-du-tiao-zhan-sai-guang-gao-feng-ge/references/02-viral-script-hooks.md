# TikTok 病毒挑战赛四段式剧本结构（02-viral-script-hooks.md）

1. **0-3s 挑战发起 (Launch)**：`@CHAR_CHALLENGER` 于 `@SCN_CHALLENGE` 霓虹场景亮相，手持 `@PROP_BRAND` 品牌道具，AU6+AU12 活力微笑直视镜头，口号 chant 发起挑战，手机竖屏 24mm 全身，病毒开场抓留存。
2. **3-8s 洗脑 BGM 卡点招牌动作演示 (Demo)**：`@CHAR_CHALLENGER` 表演 `@MOVE_SIGNATURE` 简单可复制招牌动作，AU25+AU26 张口活力喊，动作同步 BGM 节拍卡点，霓虹频闪，24mm 固定机位 + 卡点甩动，模因可复制。
3. **8-12s 全民参与 UGC 二创混剪 (Viral)**：多人复制 `@MOVE_SIGNATURE` 招牌动作，不同场景/服饰快闪混剪，活力灿笑 AU6+AU12+AU25，快节奏卡点切换，`[混剪空镜 AU 自动转为舞蹈动力学]`，病毒裂变感。
4. **12-15s hashtag 召唤参与 (CTA Loop)**：`@CHAR_CHALLENGER` 与 `@PROP_BRAND` 品牌定格，指向 hashtag，AU6+AU12 活力微笑召唤，口号 chant，病毒参与收尾（可循环回钩子）。
5. **单段生成铁律**：发起/演示/混剪/召唤四段可分段生成，但 `@CHAR_CHALLENGER` 与 `@MOVE_SIGNATURE` 全程单一源（面部/招牌动作节拍姿态零漂移，可复制模因一致）；剧本除台词外整体描述必须用中文；病毒链严禁断裂（发起→演示→裂变→召唤的模因传播链不可跳跃）。
