# TikTok 病毒挑战赛声场工程（03-sound-design-asmr.md）

1. **洗脑原创 BGM/热门神曲**：核心是"earworm 音乐钩子"——简单重复洗脑旋律/强节拍 drop，15 秒循环可复制，驱动全民模仿传播，选平台热门/上升 BGM 借势流量，绝不复杂无记忆点旋律。
2. **强节拍卡点（Beat Sync）**：BGM 节拍点对齐招牌动作关键帧与画面切换，drop 落在动作爆发点，节奏驱动病毒感，绝不脱拍。
3. **口号 chant**：品牌 hashtag 口号/洗脑 chant，简单重复易跟唱，配合招牌动作，强化记忆点与参与召唤（如品牌名 + 动作口令）。
4. **群喊/环境声层**：全民混剪段配群喊（多人 chant 叠加）、欢呼、节拍音效，营造"全民参与"的病毒裂变声势。
5. **动态范围铁律**：0-3s BGM 起 + 口号 chant 发起 → 3-8s BGM 强卡点 drop + 活力喊 → 8-12s 群喊叠加卡点高潮 → 12-15s hashtag 召唤 chant + BGM 循环点，15 秒循环无缝衔接，绝不冷场。
6. **台词与字幕铁律**：口号/chant 保留原语言口语化，口型同步精准锁定；No subtitles.（字幕/hashtag 花字绝不由模型生成，须后期硬压）。
