# TikTok 病毒挑战赛 3D 白模与轨迹锁定（whitebox-3d-rendering-guide.md）

1. **招牌动作轨迹白模锁定**：先用 3D 白模（greybox）绑定 `@MOVE_SIGNATURE` 招牌动作的关键姿态与节拍轨迹（骨骼动画曲线），锁定卡点对齐帧，确保动作简单可复制、节拍精准，再进入渲染。
2. **卡点节拍动力学**：招牌动作/镜头甩动/霓虹频闪须用节拍时间轴（beat timeline）驱动——动作关键帧对齐 BGM drop 点，卡点闪光对齐节拍，确保 beat sync 病毒节奏。
3. **全民混剪一致性**：多人 UGC 二创复制同一 `@MOVE_SIGNATURE` 时，须以基准动作白模为唯一源，不同角色/场景套同一动作轨迹，确保可复制模因零漂移（避免各跳各的）。
4. **霓虹光照渲染**：霓虹环形光须用彩色面光源（neon area light）模拟——20° 主光鲜艳 + 150° 卡点频闪轮廓光 + 品红/青色点缀，光晕 bloom 对齐节拍脉冲，营造舞池病毒氛围。
5. **运动模糊与质感 PBR**：卡点甩动/快速动作须用运动模糊（motion blur）强化节奏冲击，街头运动装弹性面料 PBR + 皮肤汗光 + 球鞋磨损，确保微观质感证据链落地。
6. **单一源公理铁律**：@CHAR_CHALLENGER/@MOVE_SIGNATURE/@SCN_CHALLENGE/@PROP_BRAND 的 3D 资产模型一旦锁定为基准，所有镜头状态（发起→演示→混剪→召唤）从同一基准模型渲染，严禁链式修改导致动作/面部/品牌漂移。
