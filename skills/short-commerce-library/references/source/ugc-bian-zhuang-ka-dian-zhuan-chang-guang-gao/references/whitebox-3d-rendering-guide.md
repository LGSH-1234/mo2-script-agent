# 变装卡点转场 3D 白模与轨迹锁定（whitebox-3d-rendering-guide.md）

1. **before/after 机位对齐锁定**：先用 3D 白模（greybox）锁定固定机位与 `@CHAR_TRANSFORMER` 站姿基准，before 与 after 共用同一机位参数（位置/高度/角度/焦段）与同一姿态骨架，确保切换帧严丝合缝对齐（对齐即魔法，错位即穿帮）。
2. **转场轨迹锁定**：手势遮挡/甩镜/跳切的转场动作须用动画曲线锁定关键帧轨迹——甩镜运动模糊帧精准覆盖切换点、手势遮挡帧对齐 beat drop，转场轨迹与音效节拍严格同步（音画对齐零漂移）。
3. **造型切换动力学**：服饰切换用布料/柔体解算（亮片垂坠摆动、面料飘动），转场闪光用体积光/粒子系统，多套连变用姿态匹配（morph/骨架对齐）确保同一站姿下造型瞬变，物理可信且惊艳。
4. **同一骨架姿态匹配**：before/after/多套造型须绑定同一 3D 骨架与同一站姿（pose matching），仅替换服饰/妆容/发型贴图与网格，保证"人还在原地、造型瞬间变身"的错觉，严禁姿态跳变破坏对齐。
5. **动感时尚光渲染**：时尚柔光箱须用面光源模拟——右侧 30° 5200K 动感塑形、Key:Fill 2.5:1 大片感、转场闪光后方 150° +1.5 档华丽边缘，before 低饱和 ↔ after 高饱和调色分层，确保 before/after 光影对比落地。
6. **单一源公理铁律**：@CHAR_TRANSFORMER/@OUTFIT_BEFORE/@OUTFIT_AFTER/@SCN_TRANSITION 的 3D 资产模型一旦锁定为基准，所有镜头状态（before→转场→多套 after→定格）从同一基准模型与同一机位渲染，严禁链式修改导致面部骨相/机位/造型漂移。
