# 变装卡点转场运镜光学（cinedance-camera-optics.md）

1. **固定锁定机位对齐（locked-off）**：transition 变装的运镜铁律——手机竖屏 26mm 等效广角全身，**固定锁定机位**保证 before/after 同机位、同姿态、同构图对齐（三脚架/固定支架），这是转场魔法的核心，严禁手持晃动、严禁机位漂移破坏对齐。
2. **甩镜/跳切转场运镜**：转场瞬间配甩镜（快速甩动制造运动模糊遮掩切换）或跳切（同机位硬切靠对齐制造魔法），甩动方向与 beat drop 对齐，运动模糊帧恰好覆盖切换点，实现"无缝变身"错觉。
3. **多套连变卡点快切**：after 阶段多套造型连变用卡点快切，每套造型对齐同一机位同一姿态，切换帧精准落在节拍点，快门等效 180° 保证动态清晰，快切密度与 BGM BPM 对齐。
4. **竖屏 9:16 全身构图**：手机竖屏 9:16 全身构图，机位高度约 1.3m 齐全身，安全区避让 TikTok UI（顶部 15% 底部 20%），before/after 主体在画面同一位置，绝不横屏 2.39:1 电影感。
5. **转场闪光光学**：转场瞬间配闪光过曝（+1.5 档）遮掩切换、强化魔法感，轮廓光后方 150° 华丽边缘光，after 光鲜艳高饱和 ↔ before 光平淡低饱和形成对比，11 点钟明亮眼神光。
6. **V4.1 光影角度量化铁律**：所有运镜提示词强制携带五子层——光源角度（时尚柔光箱右侧 30°+转场闪光后方 150°）、色温显色（5200K CRI 92+霓虹品红/青）、视角机位（26mm 全身+固定锁定 1.3m+竖屏 9:16）、微观质感证据链（华丽亮片垂坠/before 棉质/转场运动模糊）、大气体积介质（转场闪光光晕+大片鲜艳氛围）。
