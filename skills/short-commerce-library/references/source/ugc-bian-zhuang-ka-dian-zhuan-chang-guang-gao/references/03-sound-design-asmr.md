# 变装卡点转场声场工程（03-sound-design-asmr.md）

1. **卡点 BGM 骨架**：强节拍卡点 BGM 是 transition 变装的心跳——选择鼓点清晰、有明确 beat drop 的潮流电子/hip-hop/流行舞曲，BPM 与多套连变节奏对齐，15 秒循环结构，节拍点精准卡在每次造型切换帧。
2. **beat drop 对齐变装瞬间**：核心转场魔法的音效锚点——beat drop（鼓点坠落/bass 爆发）必须精准落在 before→after 的切换帧，音画同步的"轰"感放大变装惊艳，这是卡点变装爽感的灵魂。
3. **转场音效 whoosh 层**：每次转场切换叠加 whoosh（呼啸）/闪光音/切换音（swoosh-click），手势遮挡/甩镜/跳切各配对应转场音效，多套连变时密集叠加，强化"唰唰变身"的节奏爽感。
4. **服饰造型 ASMR 点缀**：after reveal 可点缀服饰质感音效——亮片摩擦、面料垂坠摆动、高跟鞋落地、饰品叮当，真实材质音强化华丽造型的沉浸质感。
5. **口播与字幕纪律**：变装广告以卡点 BGM + 音效为主，无台词或仅保留原语言口语化短口播（如"变身！"），口型同步精准锁定；No subtitles.（造型名/花字/品牌绝不由模型生成，须后期硬压）。
6. **单一源声场铁律**：BGM/音效须一次性锁定基准声场，卡点节拍与画面转场帧严格对齐（音画同步零漂移），严禁节拍错位导致转场脱拍、严禁 BGM 商用未授权。
