# 变装卡点转场剧本钩子（02-viral-script-hooks.md）

1. **三段式变装骨架（15 秒循环）**：①[0-3s] before 日常便服开场铺垫反差基线（松弛随意）→ ②[3-5s] beat drop 卡点转场魔法瞬间变装（手势遮挡/甩镜/跳切触发）→ ③[5-15s] after 惊艳 reveal 多套连变 + 定格（自信气场），可循环回 before 制造无限刷感。
2. **3 秒钩子（before 反差铺垫）**：开场必须用"最平淡/最松弛"的 before 状态制造反差期待——日常便服、素颜、家居松弛，配"你敢信等下会变身？"式悬念花字（后期硬压），3 秒内锁住停留。
3. **卡点转场技巧库**：①手势遮挡转场（手掌/衣物扫过镜头瞬间切 after）②甩镜转场（快速甩动镜头运动模糊中切换）③跳切转场（同机位同姿态硬切，靠对齐制造魔法）④道具遮挡转场（帽/包/手遮挡瞬间变身）——beat drop 精准落在切换帧。
4. **多套连变模板**：after 阶段卡点快切多套造型（休闲→职场→约会→派对→华丽压轴），每套对齐同一机位同一姿态，节拍越密连变越爽，最后一套为压轴高潮定格。
5. **before/after 对比收尾**：定格时用 before/after 同框分屏或闪回对比，放大反差冲击，配品牌/服饰 logo 花字（后期硬压）+ "哪套最戳你"式互动召唤，触发评论与循环。
6. **单一源公理铁律**：所有造型切换必须从 `@CHAR_TRANSFORMER` 基准达人资产一次性生成，before/after/多套造型面部骨相 100% 一致（严禁换脸），机位锁定确保对齐零漂移，严禁链式修改导致造型/机位漂移。
