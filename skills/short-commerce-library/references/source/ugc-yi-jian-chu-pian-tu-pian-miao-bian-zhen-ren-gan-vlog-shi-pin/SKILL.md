# 图片自动识别 → Vlog提示词 → Seedance 2.5 生成视频

## 核心工作流

按以下顺序执行，不可跳过：

### 第一步：批量读取所有上传图片

用户上传图片后，使用 `Read` 工具读取每一张图片`thumbnail_size` 统一设为 `large`。多张图片并行读取。

读取时仔细观察并记录每张图的：

- 主体内容（人/物/场景）

- 关键视觉特征（服装、颜色、材质、空间布局、地标等）

- 图片之间的关联（是否同一人物多角度、是否同一场景不同角度）

### 第二步：图片自动分类

将所有图片分为三类：

**A. 人物图**

- 特征：以人为主体，通常是多角度角色设定图（正面/侧面/背面/特写拼接），或单人写真

- 深度分析：仔细观察妆容（浓/淡、色系）、穿搭风格（甜酷/清纯/御姐/休闲/运动等）、发型发色、配饰、神态表情、肢体语言，据此**推导**：

  - 实际年龄感（年龄从图中判断）

  - 性格倾向（开朗活泼/高冷御姐/温柔知性/元气少女/慵懒随性等）

  - 职业或生活方式暗示（爱摄影/都市白领/学生/博主等）

- 记录：推导出的年龄、性格、职业标签，以及可见的发型、服装、配饰细节

- 编号规则：通常是图1，若有多个人物图按顺序标注

- 关键要求：推导出的人设必须**贯穿后续所有capture的动作行为描写**，性格开朗就写蹦跳自拍、主动互动；性格高冷就写慵懒倚靠、淡淡微笑；动作要符合人设，不能千人一面

**B. 道具图**

- 特征：单品特写，通常白底或纯色背景，如手机、耳机、相机、扇子、包包等

- 记录：物品名称、品牌、颜色、关键外观特征

- 编号规则：按出现顺序标注

- 关键要求：**只写图片中实际出现的道具**，没有道具图则道具说明整段省略，不默认保留任何道具

**C. 场景图**

- 特征：以环境/空间/景点/建筑为主，人物很小或没有人物

- 记录：场景类型（室内/室外、酒店房间/餐厅/古镇/景点等）、关键视觉元素、氛围

- 特殊处理：若两张图明显是同一空间的不同角度（如酒店房间的床侧和沙发侧），标注为"同一场景不同角度"，在提示词中合并引用

### 第三步：生成结构化Vlog提示词

严格按以下模板输出，段落标题和格式不可更改。未提供对应图片的类别/元素，**直接省略不写**，禁止编造未出现的道具或场景。

---

**【画面质感与参数】**

iPhone手机自拍摄影，前置摄像头摄影，手机摄影滑动变焦感，模拟手持拍摄的抖动，自然光线，不要音乐，不要台词，不要字幕，快切节奏

**【人物说明】**

女主角 [从图片推导的年龄感，如"约22岁"/"轻熟龄约28岁"] [从妆容穿搭推导的性格标签，如"元气活泼"/"清冷慵懒"/"温柔知性"] [从穿搭判断的风格，如"甜酷风"/"纯欲风"/"休闲运动风"]，[发型发色]，[服装具体描述]，[配饰具体描述]，[推导的职业/生活标签，如"爱摄影的都市女孩"/"精致独居白领"]（参考图X主角形象）

- 必须从人物图中分析推导，不可直接套用默认模板

- 年龄、性格、风格都要有图片依据

- 若无人物图则本段省略

**【道具说明】**

[道具1名称，带颜色/品牌/特征，如"白色无线耳机"]（参考图X），[道具2名称]（参考图Y）

- **严格只写图片中实际出现的道具**，一张道具图对应一个道具

- 没有任何道具图时，本段**整段省略**，不默认写手机或其他任何道具

**【画面情绪风格说明】**

日常的一天记录vlog分享，[根据场景和人设调整：户外多则写"清新自然风光，citywalk的感觉"；纯室内则写"宅家独居氛围"]，以女主手持iPhone相机自拍为主，[根据推导人设调整氛围词：元气活泼则写"轻松自然热烈的氛围感"；清冷慵懒则写"松弛治愈的氛围感"；温柔知性则写"安静细腻的氛围感"]，iPhone自然成像，自然皮肤纹理，切镜头剪辑，快切闪切快节奏vlog，部分模拟手机镜头拍摄的空镜头展示

- 氛围词必须与第二步推导的人设立场一致，不可固定套用

**【画面内容及视频动线及场景说明】重点！！！所有场景都要出现**

视频时长根据上传图片总数动态确定，capture数量和时间区间同步调整：

| 图片总数 | 视频时长 | capture数量 | 时间分配 |

|---|---|---|---|

| 2-3张 | 10秒 | 3个 | 0-3秒、3-7秒、7-10秒 |

| 4-6张 | 15秒 | 4个 | 0-4秒、4-7秒、7-11秒、11-15秒 |

| 7-10张 | 20秒 | 4-5个 | 每个capture约4-5秒 |

| 10张以上 | 25-30秒 | 5-6个 | 每个capture约5秒 |

每个capture标注时间区间，确保所有场景图都被引用。

每个capture写法：

```

captureX.（起始-结束秒）[动作/情节描述]，[场景视觉细节]（参考图X场景），[人物互动动作]，快切空镜头[另一场景描述]（参考图Y场景）

```

写作规则：

1. 每个场景图至少在一个capture中被明确引用（"参考图X"）

2. 同一场景不同角度的两张图，可在同一capture中分别引用或标注"图X图Y同一场景两个角度"

3. 道具图在对应capture的人物动作中自然出现（如"戴着白色耳机参考图2"）

4. **人设贯穿**：所有capture中的人物动作、表情、互动方式必须符合第二步从图片推导的人设——元气活泼型写蹦跳、转身、大笑、主动对镜头说话；清冷慵懒型写倚靠、托腮、淡淡微笑、慢动作；温柔知性型写轻抚物品、安静凝视、从容走动。禁止所有人设都写同一种"开朗活泼"动作

5. 人物图的服装特征在capture中保持一致

6. 未提供图片的场景/道具/情节，一律不写

7. 最后一个capture以符合人设的收尾动作结束（元气型举着物品对镜头笑、清冷型回眸、知性型举杯示意），快切闪切结束

---

### 第四步：生成前确认（必须执行，不可跳过）

生成提示词后，**必须**向用户展示以下完整确认信息，等待用户明确回复"确认/生成/可以"等肯定意图后，才能进入第五步：

1. **完整提示词**：以代码块或纯文本形式逐字展示生成的全部提示词内容

2. **视频时长**：明确标注根据图片数量动态确定的时长（如"共6张图，确定为15秒"）

3. **视频比例**：默认9:16竖版，若用户要求横版则标注16:9

4. **参考图片**：列出使用的图片数量及分类（如"人物图1张、道具图1张、场景图4张"）

5. **生成模型**：Seedance 2.5

最后以"是否确认以上信息，调用Seedance 2.5生成视频？"结束。

**确认规则**：

- 用户沉默、继续提问、只修改某一项、模糊表态，均不算确认，必须重新展示更新后的确认信息

- 用户修改提示词、时长、比例中任一项后，必须重新展示完整确认信息并再次等待确认

- 未获得用户明确肯定回复前，**严禁**调用任何视频生成工具

### 第五步：调用Seedance 2.5生成视频

获得用户明确确认后，执行以下操作：

1. 读取 `seedance-25` Skill 的 [SKILL.md](http://SKILL.md)，严格遵守其原文透传规则

2. 使用 `image_to_video` 工具生成视频，参数：

   - `model_version`: `seedance_2.5`（固定，不可更改）

   - `prompt`: 将用户确认的完整提示词**逐字传入**，不得改写、润色、增删

   - `duration`: 根据上传图片总数动态确定（2-3张=10秒，4-6张=15秒，7-10张=20秒，10张以上=25-30秒），用户另有指定则按用户要求

   - `ratio`: `"9:16"`（vlog竖版默认；若用户明确要求横版则`16:9`）

   - `image_reference_url_list`: 传入所有用户上传图片的URL（按人物图、道具图、场景图顺序排列）

3. 视频生成后，将结果交付给用户

## 注意事项

- **生成前必须确认**：严禁在未获得用户明确肯定回复前调用视频生成工具，确认环节不可省略或跳过

- **禁止编造**：没有图片对应的道具、场景、人物服装，一律不写入提示词；道具说明无图则整段省略

- **人设推导**：人物年龄、性格、风格必须从图片分析得出，动作行为全程符合推导人设，不套用默认开朗活泼模板

- **时长动态**：视频时长不设默认值，严格根据上传图片总数按规则确定，用户主动指定时长除外

- **场景不重复**：若用户提示"场景不能重复"，每个场景图只在一个capture中作为主场景出现，不重复用作不同情节

- **图片URL处理**：用户上传的附件通常同时提供本地路径和URL，调用视频工具时使用URL；若只有本地路径，先`FileBatchUpload`上传获取URL

- **提示词风格**：保持口语化、快节奏、有画面感，不要写成文学散文或分镜表
