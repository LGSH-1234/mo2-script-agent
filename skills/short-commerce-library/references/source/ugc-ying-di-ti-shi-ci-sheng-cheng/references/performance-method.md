# 表演提示词方法

本参考用于把选题中的抽象情绪改写成 Seedance 可观察、可计时、可执行的行为。

## 核心转换

不要停在“悲伤、愤怒、害怕、羞愧”。每个情绪都必须回答：

1. **WHY 人物目的**：此刻想让具体对象做什么。
2. **CUE 触发**：哪句话、哪个词、哪个事件让策略或表情变化。
3. **ACT 可见行为**：脸、目光、身体、呼吸、声音具体怎么变。
4. **NO 禁止反应**：哪些动作不能提前发生，峰值之后如何回落。

表演是压力下的行为，不是展示情绪。先确定目的、阻碍、失败代价、策略和潜台词；情绪是人物争取目标时保护层破裂的结果。

## 三层提示词结构

### 1. 全局控制

只固定会影响画面的信息：题材与质感、年代地点、环境光线、人物身份、服装道具、对白方式和连续性。平台界面已经设置的分辨率、模型、画幅或时长不必重复。

### 2. 镜头时间轴

每一镜明确起止秒、观察对象、景别、机位、摄影机动作和切换条件。同一镜头可以含多个情绪节拍；先划镜头，再在镜头内部放节拍。

### 3. 表演控制

逐节拍写人物目的、情绪弧、触发词、可见面部动作、AU 辅助、目光身体、声音呼吸、动作时序、结束状态和禁止反应。

## 情绪弧

优先采用因果曲线：

> 保护层维持 → 触发 → 策略失效或裂缝 → 峰值 → 回落后的新状态

不要把两种强情绪从第一帧同时端出来。例如“愤怒地哭”应拆成：愤怒维持 → 自证失败 → 声音破裂 → 悲伤浮现。眼泪、咆哮、微笑或逃避视线都需要等待触发。

每个节拍应发生可读变化：目的改变、策略改变、新信息进入或权力关系改变。变化通过停顿、姿态、语速、目光、距离或正在做的事被看见。

## 台词就是动作时间轴

有台词时标出：

- 开口前在维护或压抑什么；
- 触发词、加重词、转轻词和停顿点；
- 哪个词让面部、视线、身体或声音进入 ONSET；
- 哪个词达到 APEX；
- 最后一个词之后如何 OFFSET；
- 说完后人物进入什么新状态。

停顿不是空白。停顿中必须发生评估、决定、吞咽、吸气、屏息、目光下落、嘴唇欲言又止、手上动作停止或身体重心改变。

## 可信表演补充

- **倾听与反应**：人物可以在对方一句话尚未结束时先听懂，眼睛或身体先反应；不能等台词结束才突然开机。
- **身体任务**：让人物在谈话时做一件真实的小事。关键台词处突然停手，比持续比划更有力量。
- **目光生命**：写清注视对象、微扫视、眨眼质量和眼睛先于头部转动；克制不是冻结。
- **距离和地位**：靠近、后退、站起、坐下、转身或停止动作都应来自人物目的。
- **状态而非空泛过渡**：每个时间块给模型一个清楚的动作状态，用相邻状态构成变化。
- **情绪惯性**：强事件之后不能瞬间恢复中性；保留呼吸、余震和姿态后果，同时让峰值肌肉回落。

## 五区四问

观察五区：眉毛、眼睛／眼睑、鼻翼、嘴唇／嘴角、下巴／下颌。

每区只问四件事：哪里动、往哪动、强度多大、被哪句话或哪一秒触发。答不出来时先不要写 AU。

## 常见失败与修复

| 失败 | 修复 |
|---|---|
| 只写情绪标签 | 改写为目的、触发和可见证据 |
| 第一帧表情拉满 | 从 A/B 开始，延后 ONSET 和 APEX |
| 多种情绪同时出现 | 写清保护层和先后顺序，增加禁止反应 |
| 台词像朗读 | 绑定触发词、加重词、呼吸和目光变化 |
| 停顿像死机 | 给停顿一个评估或身体任务 |
| AU 堆叠 | 减到 2–4 个关键 AU，自然语言放前面 |
| 台词结束后仍张嘴或僵住 | 写 OFFSET、闭嘴、回收姿态和结束状态 |
| 眼神呆滞 | 加目标注视、微扫视、自然眨眼和思考先于开口 |
| 动作戏剧腔 | 写人物正在争取什么，并删掉装饰性手势 |
