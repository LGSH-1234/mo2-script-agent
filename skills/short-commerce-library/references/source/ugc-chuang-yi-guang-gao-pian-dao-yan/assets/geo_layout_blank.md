# GEO SPATIAL LAYOUT · 空白模板（空间连续性）

> 治好"人物瞬移/摄影机跳轴"。一场戏只写一次，原样贴进每镜提示词。完整规则见 references/06 第九节。

```
GEO SPATIAL LAYOUT (locked across every shot — pure spatial map):
— [地标物 A] = [它是什么、大致位置].
— [地标物 B]: [相对 A 方位, 如 MID-RIGHT / CENTER-LEFT], ~[X] m from [A].
— [其他地标物, 按需增加]:
— 180° AXIS: camera ALWAYS stays on the [某一侧] side — it NEVER crosses the line.
— [光线来源]: [光类型] comes from [方向], [在画面中造成的效果].
```

## 填写纪律
```
· 方位只从摄影机视角写（frame-left / frame-right），不用"在他左边"这类相对表达。
· 位置用地标物 + 米数定位（"祭坛旁 3 米"），不写"在房间里"无锚点描述。
· 明确写摄影机站哪侧、绝不跨哪条 180° 轴线。
· 每镜 FIRST FRAME 段重申"谁站哪、看向哪"（GEO 不自动补人物位置）。
· 第一秒定妆：开场留 1s 不写台词不写动作，让模型把站位/光"拍"下来并保持；
  回应的镜可把上一条台词尾音喂进这 1s，两段素材剪辑点严丝合缝。
· 完整保留贴进每镜，不因"这一镜好像用不上某行"删减。
```
