# 六大类型爽点公式库 · references/01

> **核心原则**：短剧不是"缩短的电影"，而是"高频情绪兑付机器"。每一类型有自己独特的爽点公式与情绪曲线，
> 不能套同一种模板。本文件给出六大爆款类型的完整公式：核心爽点、情绪曲线、人物原型、爽点分布、
> 对白范式、钩子偏好、竖屏分镜注记、创意颠覆技法、陈词滥调雷达、案例骨架。
> 所有成片须达到**全员演技在线 · 超越真人感顶级质感 · 电影级别**（见 SKILL §10A）。

## 一、类型选型决策树（P1 用）

```
用户需求
  ├─ 女性向·逆袭/情感碾压/被看见      → 精品女频
  ├─ 男性向·战力/财富/地位碾压        → 爆款男频
  ├─ 双向甜/暧昧/护短                 → 甜宠
  ├─ 产品种草/痛点解决/转化           → 带货短剧
  ├─ 海外·禁忌/兽性/宿命/暗黑         → 狼人吸血鬼（国外）
  ├─ 金手指/打脸/升级/奇观            → 穿越仙侠
  └─ 不确定 → 先问平台与受众，再按"情绪兑付频率"最高的类型试
```

**通用爽点公式（适用于一切类型）**：
`爽点 = 压抑/亏欠（铺垫） + 反转触发器（认知被推翻） + 兑付动作（打脸/逆袭/甜/救赎） + 余韵（观众代入的爽感释放）`
缺失"铺垫"则兑付无力；缺失"反转触发器"则平；缺失"余韵"则刷完即忘。

## 二、精品女频短剧

**核心爽点**：逆袭（被轻视→惊艳全场）、情感碾压（渣男/恶毒女配→悔不当初）、被看见（才华/身份揭晓）。
**情绪曲线**：压抑(★) → 隐忍(★★) → 反击触发(★★★) → 碾压释放(★★★★★) → 甜余韵(★★★)。
**目标受众/平台**：25–45 女，抖音/视频号/小红书。

**人物原型**：
- 女主：表面弱/透明，实则有硬核才华或隐藏身份（设计师/神医/财阀遗珠）。矛盾行为：对外示弱、对信任者护短。
- 男主（或贵人或觉醒盟友）：先误判女主，后成为最强护盾。声音(S)：低沉克制、只在护她时升温。
- 反派：恶毒女配/控制型前任，动机通过"当众羞辱被反杀"行为展示，禁止结局独白洗白。

**爽点分布（单集）**：小爽×2（职场打脸/才艺惊艳）+ 大爽×1（身份揭晓或渣男悔悟）。
**对白范式（爽感台词）**：
```
女配："就你？也配站在这里？" 
女主（不抬眼，继续做事）："{这位置，三年前就是我设计的。}"  ← 用事实打脸，不吵
```
**钩子偏好**：身份钩（真实身份揭晓前夜）、反转钩（最信任的人背叛）。
**竖屏分镜注记**：中近景为主，女主特写占 60%+；打脸镜用"对手脸→女主冷脸→全场反应"三镜快切；逆光剪影外化"被看见"。
**创意颠覆**：旁白不可靠（女主自述"我输了"但画面是她布局成功）/ 视角转换（从恶毒女配视角讲，最后发现她是棋子）。
**陈词滥调雷达**：雨中跪求复合、照镜子自我鼓励、"你配不上我"空喊口号无事实。

## 三、爆款男频短剧

**核心爽点**：战力/财富/地位碾压（被辱→爆发→封神）、扮猪吃虎、即时正义。
**情绪曲线**：受辱(★) → 隐忍蓄力(★★) → 爆发(★★★★) → 封神碾压(★★★★★) → 余波敬畏(★★★)。
**目标受众/平台**：18–40 男，抖音/快手/B站。

**人物原型**：
- 男主：表面窝囊/废柴，实则是退隐战神/首富/绝世强者。表演基线：平时佝肩慢步，爆发后肩打开、语速不变但气压骤升。
- 反派：势利眼/豪门管家/伪强者，靠"身份压制"横行，被反杀时表情从傲慢到碎裂。
- 女主/辅助：唯一早期相信男主的人，成为情感锚点。

**爽点分布（单集）**：小爽×2（轻微打脸/财富暗秀）+ 大爽×1（终极对决或身份曝光）。
**对白范式**：
```
反派："穷鬼，也敢碰我女儿？滚。"
男主（平静放下茶杯）："{从今天起，你家公司，归我管。}"  ← 慢半拍，气压取胜
```
**钩子偏好**：实力钩（还有更深背景未揭）、悬念钩（下一个羞辱他的人是谁）。
**竖屏分镜注记**：动作近景+慢镜高光（爆发后 0.5s 慢动作特写眼神/拳/车标）；机位从仰拍反派→平拍→俯拍男主完成权力反转；光比拉大外化碾压。
**创意颠覆**：时间颠倒（从"他已是首富"讲起倒推）/ 类型混搭（战神+带娃温情）。
**陈词滥调雷达**：无脑"老子弄死你"、从头打到尾无铺垫、女主全程花瓶尖叫。

## 四、甜宠短剧

**核心爽点**：双向奔赴、暧昧密度、被偏爱与护短（"她只能我欺负"）。
**情绪曲线**：暧昧(★★) → 心动(★★★) → 吃醋/误会用(★★★★) → 护短兑付(★★★★★) → 甜余韵(★★★★)。
**目标受众/平台**：18–35 女，抖音/小红书/TapTap。

**人物原型**：
- 双主：一个外冷内浊/一个直球甜；或"狼狗×小白""叔系×少女"。矛盾行为：嘴上说不关心，身体先护（参考 SKILL §04 三件事）。
- 助攻/情敌：制造吃醋催化剂，但不必真坏。

**爽点分布（单集）**：甜密度≥4 个情绪波动点（对视/靠近/护短/意外亲密），大爽=一次公开护短或告白前奏。
**对白范式（Show-Don't-Tell，用动作承载甜）**：
```
他（把她的手塞进自己口袋，没看她）："{手这么凉，自己不知道？}"  ← 嘴硬动作诚实地甜
```
**钩子偏好**：情感钩（意难平留白）、亲密钩（差一步的吻/未说完的话）。
**竖屏分镜注记**：过肩特写+眼神拉扯；A 左看右/B 右看左固定；两人同框占 70%，背景虚化突出亲密；微动作（他指尖蹭过她手背）是甜的最高密度信号。
**创意颠覆**：沉默主角（甜靠动作不靠告白）/ 类型反转（甜宠外壳下藏悬疑身份）。
**陈词滥调雷达**：工业糖精尬白、"我爱你"空喊、强制爱无 consent。

## 五、爆款带货短剧

**核心爽点**：痛点刺激→产品救赎→下单冲动（种草）。爽点=观众"我也需要"的代入。
**情绪曲线**：焦虑/痛点(★) → 放大困境(★★) → 产品出现(★★★) → 使用前/后对比兑付(★★★★★) → 限时利益钩(★★★★)。
**目标受众/平台**：全龄，抖音/视频号/淘宝短视频。

**人物原型**：
- 用户替身：被痛点折磨的真实状态（卡粉/脱发/油污/失眠），表演要"全员演技在线"的真实窘迫。
- 产品/专家：以"解决者"姿态出现，不硬广，用演示说话。

**爽点分布（单集）**：痛点×1（强共鸣）+ 对比兑付×1（使用前/后视觉冲击）+ 利益钩×1（限时福利/下集揭晓用法）。
**对白范式（少而准，演示优先）**：
```
她（对镜崩溃）："{卡了一层粉，斑还是看得见。}"  ← 痛点具象
画外（平静）："{换这个，三秒贴住，游泳都不掉。}"  ← 利益点，不喊买
```
**钩子偏好**：利益钩（"今晚 8 点同款福利价"）、悬念钩（"她后来怎么了？下集揭晓"）。
**竖屏分镜注记**：产品特写占 40%+；使用前/后必须用同机位同光比同角度对照（否则观众不信）；演示动作物理因果清晰（液体晃/粉贴住/污渍消失）。
**创意颠覆**：类型混搭（带货+悬疑："这瓶东西，救了要散伙的店"）/ 视角转换（从产品视角见证改变）。
**陈词滥调雷达**：无脑"家人们冲啊"、虚假对比、夸大功效违审核。

## 六、狼人吸血鬼（国外向）短剧

**核心爽点**：禁忌/兽性觉醒/宿命纠缠/暗黑浪漫（forbidden love + 身份危险）。
**情绪曲线**：压抑(★) → 兽性躁动(★★★) → 失控边缘(★★★★) → 宿命兑付(★★★★★) → 危险余韵(★★★)。
**目标受众/平台**：海外 18–35，TikTok/Reelshort/DramaBox。语言按目标市场（英/西/葡）。

**人物原型**：
- 狼人/吸血鬼：人形与兽形双重表演基线（人形克制、兽形瞳孔竖/獠牙/呼吸粗重）；catch-light 在兽化时转为冷光反光。
- 人类恋人：脆弱但勇敢，成为"该不该靠近"的张力源。
- 宿敌/族长：用规则压制主角，动机通过"追猎行为"展示。

**爽点分布（单集）**：小爽×2（兽性护短/身份暗示）+ 大爽×1（兽化高光或真身半揭）。
**对白范式（英文，低沉克制）**：
```
Alpha (low growl, not shouting): "{You are mine to protect. Even from myself.}"  ← 危险又甜
```
**钩子偏好**：身份钩（真身即将暴露）、悬念钩（月圆/血渴倒计时）。
**竖屏分镜注记**：低饱和冷调（4800–6500K）；瞳孔/獠牙/血丝特写是爽点核心；兽化用"瞳孔变+下颌绷+呼吸变"肌肉描述而非形容词；动作近景+手持微晃制造不安。
**创意颠覆**：视角转换（从猎物视角）、旁白不可靠（他自称无害但画面是猎手）。
**陈词滥调雷达**：无脑咆哮、全黑滤镜无细节、身份揭晓无铺垫。

## 七、穿越仙侠短剧

**核心爽点**：金手指/打脸/升级/奇观（弱小→奇遇→逆袭），"现代思维降维古代"。
**情绪曲线**：弱小受辱(★) → 奇遇觉醒(★★★) → 打脸升级(★★★★) → 大招逆袭(★★★★★) → 余韵(★★★)。
**目标受众/平台**：16–35，抖音/快手/B站/海外。

**人物原型**：
- 穿越主：带现代记忆/系统/废柴逆袭；表演基线：初期佝缩，得金手指后肩打开、眼里有光。
- 反派：宗门欺压者/渣爹，被"越级反杀"打脸。
- 师尊/灵宠：引导型辅助，制造升级节奏。

**爽点分布（单集）**：小爽×2（小技巧打脸）+ 大爽×1（越级大招/身份曝光）。
**对白范式**：
```
反派："废物也敢挑战我？"
主角（掌心浮起灵光，平静）："{三级，够杀你了。}"  ← 等级碾压的冷爽
```
**钩子偏好**：实力钩（系统新功能/更强大敌）、反转钩（所谓废物是上古血脉）。
**竖屏分镜注记**：大招近景+光效爆炸（粒子/灵光从掌心升起，物理因果：能量先聚后放）；升级用"衣袂/发丝被灵风掀起"微动作；色板 60:30:10（仙=青白主+金强调）。
**创意颠覆**：类型混搭（仙侠+甜宠）、时间颠倒（从"他已成仙"倒推）。
**陈词滥调雷达**：无脑升级无代价、特效堆砌无人物、反派降智送人头。

## 八、跨类型通用：爽点密度与节奏

```
单集 60–120s，情绪波动间隔 ≤20s 一个；爽点兑付后必须留 0.5–1s 余韵镜（角色反应/环境呼吸）。
"全员演技在线"要求：即便是反派/群演，也按 DNA 写表演基线，禁止"站桩念台词"。
"超越真人感"：皮肤/布料/眼神质感按 §10A 负向词禁用 plastic/wax；特效须有物理重量（光有惯性、烟尘有扩散）。
"电影级别"：每集锁定 Style Prefix，跨镜色温/光位/色板一致，不靠滤镜堆"高级感"。
```
