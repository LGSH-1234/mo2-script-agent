# 单集结构与爽点分布 · references/02

> **核心原则**：短剧单集是"独立兑付 + 连续追剧"的双重单元——既要让单集自洽爽完，又要为下集留钩。
> 本文件给出竖屏短剧单集的黄金结构、节拍密度、爽点分布表、多集连续弧线，以及"全员演技在线/电影级"在结构层的落实。

---

## 一、竖屏短剧单集标准

```
单集时长：60–120s（爆款常见 70–90s）
单集镜数：8–12 镜（每镜 6–12s，含 1–2 个反应/细节插入镜）
画幅：9:16（1080×1920）
情绪波动间隔：≤20s 一个（刷短视频的划走阈值）
爽点兑付：每集 ≥3（小爽×2 + 大爽×1）
结尾钩子：最后 1–3 镜必落（见 references/03）
```

---

## 二、黄金单集结构（时序占比）

```
[0–3s]   钩子开场：最直接的反转/冲突/悬念前置（不铺垫世界观，先给"发生了什么"）
          ↓ 例：耳光声 + 女主被泼酒 + 字幕"第 99 次被羞辱"
[10%]    建置：谁/在哪/什么状态（1–2 镜，信息极简）
[10–50%] 冲突升级：压抑积累，反派施压，主角隐忍（中近景，情绪 ★→★★★）
[50–70%] 爽点触发：反转器出现（认知被推翻的瞬间，1 镜特写）
[70%]    爽点爆发：兑付动作（打脸/逆袭/甜/救赎），大爽 ★★★★★
[85%]    余波：0.5–1s 反应镜/环境呼吸（让爽感沉淀，禁止立刻切走）
[最后 1–3 镜] 结尾钩子：为下集留悬念/身份/反转/情感/利益钩（R8 强制）
```

**无声测试**：关掉声音，分镜画面能否讲清"谁被欺→谁反击→留下什么悬念"？讲不清则补关键道具/眼神。

## 三、节拍密度计算器（按时长倒推）

```
总时长 → 节拍点数 → 每节拍镜数
60s   → 4–5 节拍（钩子/建置/升级/爆发+钩）  → 每节拍 1–3 镜
90s   → 5–6 节拍                         → 每节拍 1–4 镜
120s  → 6–8 节拍                         → 每节拍 1–5 镜

通用公式：节拍点数 = 总秒数 ÷ 12（向上取整），不小于 4
         总镜数 ≈ 节拍点数 × 1.5–2
         爽点密度：每 20s 至少一个情绪波动点（小爽/微甜/悬念/反应）
```

**案例：90s 女频单集镜数分配**
```
S01 (0–3s)   钩子开场：被泼酒 + 字幕（冲突前置）
S02 (3–10s)  建置：女主冷脸擦脸，全场窃笑（压抑★★）
S03 (10–25s) 升级：女配当众羞辱"也配设计？"（★★★）
S04 (25–35s) 反应：女主不语，指尖停顿（微动作+INNER：她在记账）
S05 (35–50s) 触发：总监拿起她的稿"这谁画的"——反转器（★★★★）
S06 (50–70s) 爆发：全场惊呆，女配脸色碎裂（大爽★★★★★）
S07 (70–80s) 余波：女主平静收稿离开，门边停一秒（沉淀）
S08 (80–90s) 钩子：门外站着传闻中的"神秘买手"，看向她（身份钩）
```

## 四、爽点密度表（每集必建 · 交付物）

```
| 镜号 | 时间点 | 爽点类型(小爽/大爽/微甜/悬念) | 情绪强度★ | 服务钩子 | 落点(视觉/对白) |
|------|--------|-------------------------------|-----------|----------|----------------|
| S03  | 10–25s | 小爽(受辱反击铺垫)            | ★★★       | —        | 女配羞辱→女主沉默 |
| S06  | 50–70s | 大爽(身份惊艳)                | ★★★★★     | S08      | 全场反应+女配碎裂 |
| S08  | 80–90s | 悬念钩                        | ★★★★      | 下集     | 神秘买手凝视     |
```

**填表规则**：
- 每个爽点必须可定位到具体镜 + 具体落点（不写"这里很爽"）。
- 大爽前必须有"触发镜"与"铺垫镜"，否则兑付无力。
- 余波镜不计入爽点，但必须存在（观众需要 0.5–1s 沉淀）。

## 五、多集连续弧线（季/系列）

```
集数结构：8–12 集/季常见；前 3 集定调（人设+核心冲突），中间集集集有小爽+小钩，
         季终集放大爽 + 季级大钩（身份总揭晓/生死危机/真相反转）。
每集钩子类型轮换：避免连续 3 集同类型钩（悬念→情感→反转→利益 交替）。
季弧线 = 主角欲望线（贯穿）+ 每集独立兑付（单元）。单元可独立成片，弧线保证追剧。
```

**季终大钩设计**：比单集钩更强一档（认知被彻底推翻/角色生死未卜/更大势力登场），留白 ≥2s。

## 六、结构层的"全员演技在线 / 电影级"落实

```
· 每个节拍的"反应镜"必须有表演：不是呆站，而是按 DNA 写微动作（呼吸/眉/手）。
· 爆发镜不靠喊，靠肌肉与眼神（下颌绷紧又松开/瞳孔变化/肩打开）；参考 references/04、06、07。
· 建置镜用"环境空镜+人物中景"建立电影级空间感，不靠字幕堆设定。
· 跨集色板/光位/机位逻辑锁定（Style Prefix），避免"每集像不同剧"。
```
