# 样片模板 · references/09

> **用途**：交付前给用户的"成品长什么样"范本。本文件给三类样片的完整结构 + 一个全工作量产示例
> （精品女频 90s 单集），演示选题卡→爽点密度表→资产锁定→分镜四段式(含电影级英文提示词+六维)→结尾钩子
> 的全链路，并附漫剧变体与单集试播片结构。所有示例须达 **全员演技在线 · 超越真人感 · 电影级别**。

---

## 一、样片交付结构（三类通用）

```
├── 选题卡（类型/受众/平台/单集时长/核心爽点/钩子类型）
├── 人物 DNA（核心角色九维精简 + 表演基线）
├── 资产锁定（@CharID/@SceneID 锁定特征 + 三图卡状态 + 十连结论）
├── 爽点密度表（每集必建）
├── 分镜矩阵（逐镜四段式 + 英文提示词 + 六维衔接）
├── 结尾钩子（类型/镜号/落点）
└── 漫剧变体注记（如产出漫剧：Ken Burns + 配音）
```

## 二、全工作量产示例：精品女频 90s 单集《第 99 次被羞辱》

### 选题卡
```
类型：精品女频 | 受众：25–40 女 | 平台：抖音/视频号 | 单集：90s / 8 镜 / 9:16
核心爽点：身份惊艳逆袭（事实打脸） | 钩子：身份钩（神秘买手凝视）
```

### 人物 DNA（精简）
```
女主 林晚 @LinWan：欲望=被看见的才华；伤口=被继母打压隐姓；矛盾行为=对外示弱对内护短；
 表演基线=平时垂眸慢步，反击时抬眸、指尖轻叩桌面；声音=清冷克制，只在护短时升温。
反派 表妹 @Cousin：动机通过"当众撕她稿"行为展示，禁止独白洗白。
```

### 资产锁定（确认后）
```
@LinWan：28岁亚裔女、齐肩黑发左侧别银夹、米白西装、右腕浅疤、重心偏左腿
@SceneID_Studio：暖白调/落地窗晨光/样衣人台/地毯、主光窗左 5200K
@Cousin：红唇、卷发、珍珠耳环、酒红连衣裙
（三图卡已建 + 十连通过；@LinWan_wet 等状态按需拆分）
```

### 爽点密度表
```
| 镜号 | 时间点 | 爽点类型 | 强度★ | 服务钩子 | 落点 |
| S03 | 10–25s | 小爽(受辱铺垫) | ★★★ | — | 表妹撕稿羞辱 |
| S06 | 50–70s | 大爽(身份惊艳) | ★★★★★ | S08 | 总监举稿"这是谁画的" |
| S08 | 80–90s | 身份钩 | ★★★★ | 下集 | 门外神秘买手凝视 |
```

### 分镜矩阵（四段式 · 竖屏）
**S01 / 8 · 发布会后台 · 0–3s**
- 镜头目的：钩子开场，冲突前置（不铺垫世界观）
- 画面：中近景，@LinWan 被泼酒，垂眸不擦；@Cousin 举杯冷笑。景别中近景|机位胸肩平视|焦段 50mm|运镜固定|构图三分前酒渍中脸后虚化背景|光影窗左 5200K 主光+侧补|动作物理因果(酒液沿颊落)|台词{就你也配站这？}
- @引用：@LinWan 形象参考(强) @Cousin 形象参考(强) @SceneID_Studio 环境参考(中)
- 提示词(EN)：`Medium close-up, 50mm lens, chest-height eye-level. @LinWan for character reference — black shoulder-length hair, silver clip left side, ivory blazer, faint scar on right wrist, weight on left leg; she stands still as wine drips down her cheek, does not wipe it. @Cousin for character reference — red lips, curly hair, pearl earrings, wine-red dress, smirking. @SceneID_Studio for location — warm white, morning window light from frame-left, dress forms, carpet; take only space and texture. Window key 5200K from left, soft fill. COLOR SCRIPT: ivory #F5EFE6 dominant, warm wood #B98B5E secondary, wine #7B2D3A accent. Pore-level skin, natural fabric weave, organic film grain, wet living eyes with catch-lights. Negative: plastic skin, wax figure, airbrushed, extra fingers, text overlay, cinematic feel. Photoreal. NON-IP. 9:16. 3s. SFX only. NO CGI. Cinematic.`
- 衔接：首镜无上一镜。

**S02 / 8 · 同场 · 3–10s**
- 镜头目的：建置压抑状态
- 画面：特写 @LinWan 指尖轻叩桌面(微动作+INNER：她在记账)；景别特写|45mm|平视|固定|三分|光同S01|动作指尖叩两下停顿
- @引用：@LinWan(强)
- 提示词(EN)：`Extreme close-up, 45mm, eye-level. @LinWan — index finger taps the table twice, pauses, jaw sets once (INNER: she is keeping the third tally). Catch-light in both eyes, pore-level skin. Window key 5200K. COLOR SCRIPT ivory/warm wood/wine. Negative: plastic, wax, airbrushed. Photoreal. NON-IP. 9:16. 7s. SFX only. Cinematic.`
- 衔接：①景别 中近→特写(合理) ②机位 同侧 ③运动 静止→静止 ④光影 同 5200K ⑤主体 左区→左区 ⑥情绪 ★→★★

**S03 / 8 · 同场 · 10–25s**
- 镜头目的：小爽铺垫（受辱）
- 画面：中景 @Cousin 当众撕稿"{也配设计？}"；@LinWan 垂眸
- @引用：@Cousin(强) @LinWan(中)
- 提示词(EN)：`Medium shot, 50mm. @Cousin rips a sketch in two, pearl earring catches light, voice (verbatim, mocking): "{You call this design?" — she says nothing else. @LinWan at frame-left, gaze down, unmoved. Window key 5200K. COLOR SCRIPT as locked. Negative: plastic, wax. Photoreal. NON-IP. 9:16. 15s. SFX only. Cinematic.`
- 衔接：①中景 ②同侧 ③静止 ④同 ⑤Cousin右区/LinWan左区 ⑥★★→★★★

**S04 / 8 · 同场 · 25–35s**
- 镜头目的：反转触发器前的"静"
- 画面：特写 @LinWan 嘴角极轻扬(0.4s)→复平；INNER：时机到了
- 衔接：特写，情绪 ★★★，余震 1s

**S05 / 8 · 同场 · 35–50s**
- 镜头目的：反转触发
- 画面：中景 总监 @Director 拾稿举高"{这谁画的？}"——全场静
- @引用：@Director(新资产需锁定) @LinWan(中) @Cousin(中)

**S06 / 8 · 同场 · 50–70s**
- 镜头目的：大爽爆发（身份惊艳）
- 画面：近景 @Cousin 脸从骄到碎；@LinWan 抬眸平静。慢半拍气压
- 提示词质量段：pore-level, 下颌绷紧又松开, catch-light, 色温同
- 衔接：近景，情绪 ★★★→★★★★★，余波 1s

**S07 / 8 · 同场 · 70–80s**
- 镜头目的：余波沉淀
- 画面：中景 @LinWan 收稿转身，门边停 1s（不切）
- 衔接：中景，情绪 ★★★★★→★★★ 余震

**S08 / 8 · 门外 · 80–90s**
- 镜头目的：身份钩（结尾 R8）
- 画面：大特写 门外阴影里 @Buyer 凝视她背影；黑场前定格 1.5s + 静默
- @引用：@Buyer(新资产锁定)
- 衔接：大特写，声音桥(高跟声渐远)，情绪 ★★★★，黑场收束
- **结尾钩子**：类型=身份钩 | 镜号=S08 | 落点=神秘买手凝视+黑场定格

### 漫剧变体注记（同集）
```
静帧用漫画风生成 S01–S08；每镜加 Ken Burns：S06 缓推 scale1→1.08 3s(大爽逼近)；
S08 横摇 x-3%→+3% 4s 揭示买手。配音按声线卡：LinWan 清冷、Cousin 尖刻、总监沉稳；
静帧对口型难→用画外音+气泡字幕+<>音效(酒泼/撕纸/高跟)。锁 60:30:10 调色跨镜。
```

## 三、单集试播片结构（男频/穿越仙侠简版）

```
选题卡(男频：战力碾压 / 平台抖音) → 人物 DNA(男主退隐战神+表演基线) → 资产锁定(@CharID 三图卡) →
爽点密度表(小爽×2+大爽×1) → 分镜矩阵 8–10 镜(打脸镜四段式见 references/05⑭) →
结尾钩子(实力钩：更深背景未揭) → 选 2–3 关键镜跑图生视频 Demo(references/07 三)验证一致性 → 交付 60–120s 试播片。
```

## 四、样片反模式

```
❌ 示例里角色脸无 catch-light（死脸）
❌ 提示词无负向词 plastic/wax（AI 味）
❌ 单集无钩子（R8）
❌ 爽点密度表缺失（无法证兑付）
❌ 六维衔接声明覆盖率 < 镜头数-1
❌ 漫剧 Ken Burns 幅度过大晕眩
```
