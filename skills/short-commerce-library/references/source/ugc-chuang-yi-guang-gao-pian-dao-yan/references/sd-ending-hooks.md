# 结尾钩子库 · references/03

> **核心原则（R8 强制）**：单集结尾 1–3 镜必须落一个强钩子，为下集完播率与追剧动机服务。
> 无钩不交付。钩子不是"随便留个问号"，而是用视听语言把"观众必须点下一集"焊进本能。
> 本文件给出五类钩子定义、30+ 可直接套用的模板、钩子×类型匹配表、钩子镜分镜注记。

---

## 一、五类钩子定义

```
① 悬念钩：抛出一个未解之谜/倒计时（"月圆前必须找到她"）
② 身份钩：真实身份揭晓的前夜（"你以为的废物，是上古血脉"）
③ 反转钩：观众的认知被推翻（"保护他的人，正是要杀他的人"）
④ 情感钩：意难平留白（差一步的吻/未说完的话/转身离去）
⑤ 利益钩（带货）：限时福利/下集揭晓用法（"今晚 8 点同款价，下集看效果"）
```

**钩子强度阶梯**：弱（一句台词疑问）< 中（一个未解画面）< 强（认知反转+情绪余震）。单集优先"中–强"，避免纯弱钩。

---

## 二、钩子镜分镜注记（竖屏）

```
· 钩子镜通常是特写/大特写（占 70%+），把"未揭之物"推到观众脸前。
· 必带"余震"：钩子抛出后停 0.5–1.5s 不切（角色反应/物体静止/黑场前定格）。
· 声音：钩子处常"抽离音乐/留环境音/一声静默"，用 silence 放大悬念（参考 references/07 音频规则）。
· 转场：钩子镜多用黑场/定格/匹配剪辑收束，让"未完"成为最后一帧的情绪。
· 六维：钩子镜与上一镜的衔接仍须过六维（主体位置/情绪强度尤其要顺），不靠硬切制造钩子。
```

## 三、30+ 钩子模板（按类）

### 悬念钩
```
1. 倒计时特写："还有 72 小时，她就会忘记所有人。"（字幕+时钟滴答）
2. 物体特写：桌上一枚带血的戒指，不是主角的（who 的血？）
3. 环境异变：窗外天空裂开一道缝（下一集才解释）
4. 声音钩：黑场里传来熟悉又不该出现的声音"{你以为我死了吗？}"
5. 线索中断：翻到日记最后一页被撕掉（剩下半句"凶手是……"）
```

### 身份钩
```
6. 神秘人凝视：门外/阴影里站着传闻中的人，目光锁死主角
7. 信物对齐：主角掏出的玉，与反派胸前的玉一模一样（同源？）
8. 名字揭示：反派念出主角真名，观众才知他一直隐瞒
9. 血脉显形：主角受伤，血在月光下泛起异色（非人类？）
10. 档案特写：翻开的档案照，主角与通缉令上是同一张脸
```

### 反转钩
```
11. 护者即敌：一直保护主角的手，缓缓握紧刀柄
12. 善意是局：盟友递来的"解药"，瓶身标着毒
13. 记忆骗局：主角以为的回忆，画面切到"那是他编的"
14. 立场倒转：最恨主角的人，跪下喊"少主"
15. 牺牲是假：以为死去的师父，在镜中一闪而过
```

### 情感钩
```
16. 差一步：唇已近，被敲门声打断（下一集续）
17. 未说完："{其实我……}" 字幕断在黑场
18. 转身离去：主角走远，身后的人伸手又收回
19. 误会加深：主角看到"误解画面"，转身决绝（实则真相相反）
20. 守护独白：他背对她说"{别回头}"，自己却红了眼
```

### 利益钩（带货）
```
21. 限时：屏幕角标"今晚 8 点同款福利价"
22. 用法未揭："{这瓶还能怎么用？下集见}"
23. 效果待续：使用前对比播完，使用后"明天同一时间揭晓"
24. 痛点延续：她用完一脸惊，"后来呢？"切黑（追更=看结果）
25. 暗号：评论区扣"1"解锁下集用法
```

### 跨类万能钩（强推荐）
```
26. 镜中倒影：主角看镜子，镜里的人笑了而他没笑
27. 手机弹窗：屏幕亮起一条匿名消息"{我知道你昨晚在哪}"
28. 门后声：主角开门，门后传来不属于任何人的呼吸
29. 时间错位：日历翻到"三年前同一天"，发生过的事重演
30. 物品归位：被杀的人，桌上的茶杯还冒着热气
31. 群体凝视：全场突然安静，齐刷刷看向主角（他不知自己暴露）
32. 留白物：黑场前切入一张倒扣的照片，风吹动一角（参考大师评审终审核）
```

## 四、钩子 × 类型匹配表

```
精品女频 → 身份钩(6–10) + 反转钩(11–15) + 情感钩(16–20)
爆款男频 → 实力钩(身份钩变体) + 悬念钩(1–5) + 反转钩(14)
甜宠     → 情感钩(16–20) + 亲密钩(差一步吻) + 反转钩(13 误会)
带货     → 利益钩(21–25) + 悬念钩(效果待续)
狼人吸血鬼→ 身份钩(9 血脉) + 悬念钩(4 声音/28 呼吸) + 反转钩(11)
穿越仙侠 → 实力钩(身份钩变体) + 反转钩(14 少主) + 悬念钩(3 天裂)
```

**轮换规则**：连续 3 集不重复同类型钩；季终用"强反转钩 + 悬念钩"双钩叠加。

## 五、钩子设计五问（每集结尾自检）

```
1. 观众看完这 1–3 镜，会"必须点下一集"吗？（无→加强）
2. 钩子靠"视听"还是"台词"？优先视听（特写/声音/黑场）。
3. 钩子与本条爽点/人物弧是否有关联？（无关→替换为关联钩）
4. 钩子抛出后留了余震吗？（无静止/黑场→补 0.5–1.5s）
5. 钩子类型与上一集重复吗？（重复→轮换）
```

## 六、钩子反模式

```
❌ 弱钩："下集更精彩"（空话，无视听载体）
❌ 钩子前无铺垫（凭空抛谜，观众无代入）
❌ 钩子镜疯狂硬切破坏六维（钩子靠内容不靠剪辑暴力）
❌ 每集同钩（疲劳）
❌ 钩子与爽点脱节（观众不知为何追）
```
