# 14-Seedance 2.5 长视频能力（30-180s 通用结构方法论）

> **归属**：Seedance 2.5 专属版长视频适配层
> **定位**：本文件为 **Seedance 2.5 长视频（30-180s）的通用结构方法论**——时长分层、场景分割表、跨段五铁律、节奏骨架、多模态参考用法。与 `0822-master-deep-enhancement.md`（深研方法论）叠加使用；冲突时以本文件优先。
> **默认模型**：视频一律在即梦 Seedance 2.5 中生成（用户指定其他模型不属本专属版范围）。

---

## 一、长视频时长分层与场景分配

| 时长段 | 场景数建议 | 单镜时长 | 结构策略 |
|---|---|---|---|
| 30-45s | 3-5 场景 | 4-6s | 单幕结构：引子→推进→收束，每场景 1-2 镜 |
| 45-90s | 5-8 场景 | 5-8s | 双幕：建置→冲突→转折→高潮，场景成组推进 |
| 90-120s | 8-12 场景 | 6-10s | 三幕完整：每幕 3-4 场景，幕间用转场镜衔接 |
| 120-180s | 12-18 场景 | 8-15s | 长片结构：多线交织/章节式，需场景分割表+时间戳控制 |

## 二、长视频场景分割表（生成前必填·内部工作纸）

| 字段 | 内容 | 说明 |
|---|---|---|
| 总时长 | 30-180s | 用户确认，绝不默认 |
| 场景序号 | S1-Sn | 按叙事链分组 |
| 场景时长 | 秒 | 单场景 8-30s 为佳，跨度过大必拆 |
| 镜数 | 1-4 镜/场景 | 长镜头或分切 |
| 核心动作 | 一句话 | 该场景"推动哪个五元素" |
| 首帧锚点 | 描述或 @引用 | 承接上一场景尾帧，防跳变 |
| 尾帧状态 | 描述 | 喂给下一场景首帧（尾音/尾帧跨接） |
| 共享资产 | @CharID/@SceneID/@PropID | 跨场景必须锁定的资产 |

## 三、长视频跨段连续性五铁律（30s 以上必守）

1. **资产全局锁定**：角色/场景/道具/音色在项目启动即注册，跨段只允许 `@引用`，禁止新生成主资产（补拍/变体除外）。
2. **首尾帧接力**：每段首帧 = 上一段尾帧（或明确的时间戳+状态描述），禁止各段独立抽卡。
3. **时间戳文本控制**：`[0:05]` `[0:12]` 等时间戳驱动事件，视频延长/续写时保持全局时钟。
4. **音频先行**：长视频先定声音结构（音乐段落/台词/音效卡点），画面按音频节拍切分。
5. **人物不串脸/不换装**：多段混剪前过"十连同框压测"，跨段服装/发型/伤情状态与资产表一致。

---

## 四、长视频节奏骨架（通用）

- **前 15%**：世界建立 + 共享真相锚定（广角+环境声，不急入戏）
- **15-45%**：建置推进，每 10-15s 一个叙事节拍点
- **45-70%**：冲突/转折区，节奏加密（镜长缩短），高潮前留静默 1s
- **70-90%**：高潮+余波，情绪峰值后留"呼吸镜"
- **90-100%**：收束，尾音跨接+字幕/主题呈现

## 五、长视频 vs 短视频生成差异（务必切换心智）

| 维度 | 短视频（≤30s） | 长视频（30-180s） |
|---|---|---|
| 生成方式 | 单段直出 | 分段生成 + 延长/续写/拼接 |
| 一致性 | 单段内自洽即可 | 跨段全局锁定（资产+时间戳+首尾帧） |
| 确认门 | 每镜确认 | 每**场景**确认（更省、更稳） |
| 失败回滚 | 重抽该镜 | 回退到该场景首帧重来，禁止链式修改 |
| 质量门 | 逐镜过 | 场景级过 + 全片拼接后复检接缝 |

## 六、长视频专属多模态参考用法（Seedance 2.5 能力）

- **@视频**：白模/预演/参考片段做运动轨迹锚定（冠军白模渲染）
- **@图片**：场景/角色/道具多参考图锁定（分镜多参考 I2V 管线）
- **@音频**：BGM/人声/音效驱动节奏与口型（音频驱动口型同步）
- **多参考混合**：每镜建议图片 3-5 张 + 音频 1 段 + 视频 ≤1 段，超限做优先级取舍
- 视频延长/前后续写：以时间戳+尾帧接力续写，禁止从零重抽
