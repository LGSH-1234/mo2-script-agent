# 07-HELL GRIND 工业级制片管线与质量治理 (Production Pipeline & Quality Jury)

> **工业级制片背景 (HELL GRIND Reference)**：  
> HELL GRIND 是一部由 15 人团队、历时 14 天生成完成的 95 分钟 AI 动作长片，并在 2026 戛纳电影节 Marché du Film 展映。全片基于 Seedance 系统生成，零实拍摄像机、零真人演员、零实景搭建。  
> 本规范将该长片的工业制片管线提取为 Agent 可执行的治理标准。
> **归属引擎**：六引擎 x 四机制体系完整方法论见 [references/10](10-capability-engines.md)；模型无关适配见 [references/12](12-model-agnostic-system.md)

---

## 一、 制作等级 (L/S/F) 与 Gates 确认门

在项目立项阶段 (Gate G0)，必须首先明确本次任务的**制作等级 (Tier)**：

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ L 级 (Legendary / 电影长片级): 完整 14 区块骨架 + 冠军白模/全资产锁定 + 中英双语 + 8K IMAX 标准│
│ S 级 (Standard / 标准短片级):  简化 8 区块骨架 + 核心资产展板 + 中英双语                      │
│ F 级 (Fast / 快速演示级):      5 字段核心描述 + 极速生成交付                                 │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

## 二、 六大 Master Agent 联合执政矩阵

整个制片管线由 **Executive Producer (EP) Agent** 统一调度管理，下设 6 位专业 Master Agent：

| Agent 代号 | 大师角色 | 主导阶段 | 核心交付物 |
|---|---|---|---|
| **EP Agent** | 制片兼质量监制大师 | 全阶段 / 治理层 | 项目立项、制作等级判定、Gate G0-G4 门禁把关、Oscar 评审 |
| **SD Agent** | 编剧兼声学导演大师 | Stage 1 (剧本) | 剧本拆解、大师十问基因选择、六维声学建模方案 |
| **AE Agent** | 影视级音频工程大师 | Stage 2 (音频) | 驱动 Seed Audio 1.0 生成 24kHz WAV 音频及 100ms 时间轴 |
| **VA Agent** | AI 视觉艺术指导大师 | Stage 3 (资产) | 并发提取角色/场景/道具 Identity Board，执行资产强锁定 |
| **DP Agent** | 电影摄影与分镜导演大师| Stage 4 (分镜) | 音频驱动分镜切割、14 区块蓝图编写、FOV 光学镜头设定 |
| **KD Agent** | AIGC 视觉生成与动态导演| Stage 5 (生成) | 调度 Seedance 2.5 批次生成、白模冠军渲染、物理因果链排查 |
| **CE Agent** | 剪辑与调音调色总监大师 | Stage 6 (后期) | 剪辑蓝图绘制、声画卡点对齐、Style Playbook 调色发布 |

### 四大智能机制 (Four Mechanisms — EP Agent 调度)
1. **Sequential（顺序编排）**：主链阶段严格按序推进，前序未过质量门绝不进入下一阶段。
2. **Parallel（并行编排）**：多角色/多场景/多镜独立任务并行产出，汇合到分镜-资产匹配清单。
3. **Loop Engineering（循环治理）**：每阶段产出 → EP 自动评审 → QA-PASS 进下一阶段 / QA-FAIL 进 Loop 修复（一次只改一处、上限 3 次、记录决策日志、实时汇报用户）。
4. **Agent Workflow（EP 主控调度）**：识别需求 → 路由引擎与机制 → 分发任务 → 汇总 → 组织审判 → 输出确认单。
5. **⏸️ 模型确认节点**：项目开始确认模型（默认 Seedance 2.5 / 用户指定可灵等）、分辨率、画幅、风格、时长——未确认不进入创作。

## 三、 奥斯卡级 Anti-Slop 质量审判表 (Oscar Quality Jury)

在生成任何镜头或最终交付前，必须经过以下 5 维打分（满分 100 分，低于 80 分打回重新迭代）：

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. 资产一致性 (Asset Continuity - 20分): @CHAR/@SCN/@PROP 是否全局无缝锁定？   │
│ 2. 物理与重力因果 (Physics & Inertia - 20分): 质量、接触阴影、惯性、碰撞是否真实？ │
│ 3. 镜头与空间逻辑 (Camera & Geometry - 20分): 是否遵守 180° 轴线与 FOV 光学规则？  │
│ 4. 去 AI 假感与肌理 (Anti-AI Texture - 20分): 是否有毛孔瑕疵、汗光与深沉阴影？ │
│ 5. 声画卡点与表演 (Sound & Acting - 20分): 台词动作是否强卡点？是否无魔改 BGM？ │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 四、 故障排查手册 (Failure Playbooks)

### Playbook 1：面部漂移与换脸
- **现象**：镜头切换或远景拉近时，角色长相变样。
- **根因**：使用了含小人脸的展板（单图拼贴导致模型补画头、面部采样源太小），或提示词漏写了全量描述符。
- **外科手术级修复**：
  1. 改用**分图多视角资产图**（吸收诺兰 06b 规范）：正面全身·无头（V1）、背面全身·无头（V2）、3/4 侧面含头（V3）、正面半身含头（V5）、面部极特写（V7）**各单独生成一张图，禁止单图内多视角拼贴**；无头全身照必须使用**取景框裁切语言**（`the frame starts below the collarbone, head completely outside the frame`）+ 负向词（`no head, no face, no hair, no ears`）——详见 `references/05` §二。
  2. 分镜生成时按景别上传对应参考图：全身戏传 V1/V2、半身戏传 V5、面部戏传 V7，面部采样只允许来自 V7 高清大肖像。
  3. 提示词 ACTIVE REFERENCES 区块中逐字补齐特征描述符（IDENTITY LOCK 英文锁定，禁止翻译回写）。

### Playbook 2：肢体穿模与动作变怪兽
- **现象**：角色手部多指、肢体扭曲或碰撞时穿透对方身体。
- **根因**：白模包含过细的几何线稿，或在一个 4 秒镜头中塞入了 >2 个复合动作。
- **外科手术级修复**：
  1. 简化白模为纯几何块。
  2. **仅适用于"非白模参考"的普通文生视频分镜**：拆分镜头，一镜只承担一个主要物理动作。
  3. **⛔ 白模参考视频例外（单段完整生成铁律）**：当使用 @视频1 白模参考视频生成时，**严禁按分镜切割为多段分别生成**——白模本身已含完整运镜与动作弧，必须单次生成整段成片。若动作过密导致崩坏，应**修改白模源文件**（简化几何/拆分动作到更长时段），而非切割渲染片段。

### Playbook 3：空间跳轴与左右颠倒
- **现象**：切镜后角色 A 原本在左边，突然跳到右边。
- **根因**：摄像机跨越了 180° 轴线。
- **外科手术级修复**：在 GEO SPATIAL LAYOUT 中硬性指定 `Camera stays on South Side; Character A on Frame-Left`.

## 五、 迭代纪律与终局规则 (Iteration Discipline)

> **吸收自 Hell Grind 制作简报 (Conclusion)**

### 1. 一次只改一处 (Change One Thing at a Time)
提示词是一台运转中的机器——整体重写，你会丢掉原本有效的部分。**每次迭代只改一行，其余逐字保留**，并全部记入日志（prompt 版本 / 改了什么 / 裁决）。没有日志，就无法复现好镜头。

### 2. 10-15 规则 (The Ten-to-Fifteen Rule)
一个镜头若在 10-15 次迭代内仍无法成形，**问题不在措辞**。简化镜头本身：拆成两镜、删一个动作、换个角度。死磕文字不如简化镜头。

### 3. 终局五规则 (Five Rules of the Whole Film)
1. **资产先行 (Assets First)**：一个镜头都不生成，直到每个角色/地点/道具锁定并通过压测。这一条省的钱比其余所有规则加起来都多。
2. **每次都完整描述 (Describe Everything, Every Time)**：模型没有记忆。描述符逐字进每个提示词，从不缩短。
3. **一次只改一处**：见上。
4. **给模型更少自由 (Give the Model Less Freedom)**：角落而不是房间、锚点而不是开放空间、地图而不是猜测、一镜一个动作。
5. **镜头不成就简化镜头，不是简化文字**：拆两镜、删动作、换角度。

## 六、 后期三 Pass 流程 (Post-Production: Cleanup, Color, Sound)

> **吸收自 Hell Grind 制作简报 (Post-Production)**

### Pass 1 — 剪辑与重生成 (Edit & Regenerate)
- 剪辑与生成并行：编辑器边收片边下单（"需要手部插入镜"、"需要更宽的"）——重拍只需几分钟，剪辑主动塑造制作。
- AI 生成通常偏慢节奏：**比感觉更激进地剪**；每段素材**裁掉首尾各 0.5 秒**——边缘帧会漂。
- 完片锁定后跑独立清理 pass：AI 素材几乎总有你干活时看不见、大银幕上看得见的缺陷——多指、"沸腾"纹理、标牌假文字。小缺陷逐帧修补，整镜崩坏的从保存的最终 prompt 重生成（只改一行）。**优先级：脸和手的特写。全部严格在调色之前。**

### Pass 2 — 色彩统一 (Color Unification)
- 每个生成自带内建调色——调色师先把同一场景相邻镜头统一到一种观感。
- 观感本身在预制作阶段已烤进地点资产——**调色师是精修，不是发明**。

### Pass 3 — 声音清理 (Sound Cleanup)
- 不重录音：Seedance 唇形同步台词直接清理（降噪、拉平片段间音色、把声音放进空间）；只有片段完全无可用人声时才进棚补录。
- 声音设计与音乐在后期铺在**连续环境底噪**之上：一条共享氛围把生成的镜头粘合成同一空间。
