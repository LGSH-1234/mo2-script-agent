# 竖屏分镜节奏 · references/05

> **核心原则（R2 竖屏先于横屏）**：默认 9:16（1080×1920）。横屏的所有景别/构图/运镜必须重译为竖屏逻辑。
> 本文件给出竖屏重译法则、分镜四段式（竖屏）、六维衔接竖屏注记、竖屏运镜库、时长核算，以及
> 14 类场景的竖屏压缩镜头序列库。六维引擎完整定义见 SKILL §9 / 同源 six-dimension-engine。

---

## 一、竖屏 9:16 重译法则

```
景别优先级：特写(ECU) > 近景(CU) > 中近景(MCU) > 中景(MS) >> 全景(FS) > 大远景(ELS)
 · 主体占画面 ≥60%；竖屏大远景信息稀薄，非必需不用。
 · 多用"上半身表演"机位（胸肩以上），人物情绪靠脸与手承接。
 · 对话/亲密戏：过肩特写（A 左看右 / B 右看左 固定，见六维⑤）。
 · 动作/大招：近景+慢镜高光，避免大幅横移（竖屏易糊、易丢主体）。

构图：三分法/黄金比仍适用，但竖向空间用于"前后景层次"——前景手/道具，中景脸，后景虚化环境。
运镜：幅度小、慢、稳。竖屏优先：缓推 / 微摇 / 轻微升降 / 手持呼吸感；少用大幅位移与快速变焦。

光比：竖屏脸大，主光方向决定"电影感"。侧窗硬光切割半脸（外化内心分裂）是短剧最常用电影级手法。
```

## 三、六维衔接引擎 · 竖屏注记

```
①景别节奏：竖屏避免"特写→大远景"两极跳（信息断崖）；推荐 特写↔中近景↔中景 波浪。
②机位逻辑：180° 线内；越轴需桥梁（人物穿镜/推特写/中性镜）。竖屏过肩对话务必 A左B右固定。
③运动方向：画左出→画左入。竖屏主体瞬移更刺眼，方向错即"往回跑"感。
④光影色温：同场景跳变 ≤±500K；竖屏脸大，色温漂移一眼可见，场景卡锁死主光方向。
⑤主体位置：A 左→B 右 固定；反应镜用"正面+视线匹配"而非错位。竖屏最易翻车的维度。
⑥情绪强度：波浪递进；大爽后留 0.5–1s 余波（★★★→★★★★★→余震★★★），不瞬关。
转场技法竖屏常用：切 / 匹配剪辑(形状色匹配) / 视线引导 / 动作匹配 / 声音桥 / 黑场(钩子收束)。
```

## 四、竖屏运镜库（小幅度·电影级）

```
缓推(dolly in slow)：情绪逼近，用在爆发前 1 镜。
微摇(small pan)：过肩对话的"呼吸"，≤5°。
手持呼吸(handheld breath)：真实感/不安（狼人/悬疑），幅度极小。
轻微升降(baby crane)：身份揭晓/升华，慢。
变焦推(zoom in)：强调特写，少用（易廉价）。
固定锁(fixed)：反应镜/余波镜，不动能量沉淀。
Ken Burns（漫剧用）：静帧缓推/横摇/变焦，见 references/07。
```

## 五、时长核算（分镜前先算账）

```
剧本阶段粗测：台词 4 字/秒，动作段 2 秒/段；差目标时长 2 倍以上点名。
分镜阶段：每镜时长建议 = 认领剧本块按同速率折算；总镜时长和 = 单集目标时长（允许带符号差值，须算对）。
竖屏单集 60–120s，每镜 6–12s；钩子镜可停 0.5–1.5s 不切。
```

## 六、14 类场景 · 竖屏压缩镜头序列库

> 横屏 5 镜模板压缩为竖屏 3–5 镜；建立→核心→特写反应→收束。每镜仍须四段式+六维。

```
① 对话（两人）竖屏 4 镜：中景建立(位置关系) → A过肩拍B(左看右) → B过肩拍A(右看左) → 特写反应(关键微表情)
   注：A左B右固定；争吵用近景快切+微越轴(焦虑)。

② 情感揭示 竖屏 4 镜：环境慢建(冷调) → 中景慢推(人物被氛围包围) → 眼部大特写(压抑波澜) → 拉远留白(余震)
   注：每镜停 3–6s；大特写瑕疵词最丰富(泪痕/布料折)。

③ 动作/追逐 竖屏 4 镜：中景跟拍(跑/追) → 手部碰撞特写(物理冲击) → POV 晃动(主观) → 全景收束(追上/未追上)
   注：运动矢量一致；竖屏少大幅横移。

④ 到达新地点 竖屏 3 镜：人物中景入画(走向) → 反应特写(惊叹/失望) → 手部特写(摸门把"到了")
   注：宏伟到达用仰角+人物极小。

⑤ 沉思独处 竖屏 3 镜：环境空镜(雨/光) → 人物中景静止 → 面部大特写(真情绪)
   注：不给手持晃动；静止=绷紧张力。

⑥ 通话/远程 竖屏 4 镜：近景拿手机(表情先于声) → 屏幕特写(信息) → 对面空镜(他在哪) → 挂断状态(静止)
   注：视频通话分屏/移轴拍屏。

⑦ 悬疑调查 竖屏 4 镜：细节特写(异常物) → 横摇环境(让观众看见角色没看见) → 人物警惕 → 发现反应定格
   注：80% 信息在环境暗示，不靠台词。

⑧ 角色介绍 竖屏 4 镜：远景出场 → 中景代表动作 → 面部特写(记住脸) → 标志道具特写
   注：女主用逆光剪影→照亮；反派背光→逐步照亮。

⑨ 闪回 竖屏 4 镜：触发物特写 → 虚焦转场(色偏) → 过去画面(降饱和+颗粒) → 拉回现实(新信息)
   注：过去色调标识必须明显。

⑩ 揭示发现 竖屏 4 镜：缓推主体 → 停顿 1–2s → 反应(不解→震惊) → 细节验证特写
   注：停顿最重要。

⑪ 早晨醒来 竖屏 4 镜：睁眼特写 → POV 模糊(抓手机) → 窗光(尘浮) → 起身中景
   注：用镜头呼吸感/对焦漂移，不"过于精确明亮"。

⑫ 梦境超现实 竖屏 4 镜：扭曲开场(物理反常) → 熟悉但错(细节错) → 色彩异常 → 惊醒跳切
   注：内部逻辑一致，不随意拼。

⑬ 表演舞台 竖屏 4 镜：中景表演 → 特写情绪(汗/投入) → 观众反应 → 高潮定格
   注：观众反应镜是情绪放大器，不省。

⑭ 打脸/逆袭(短剧特化) 竖屏 4 镜：反派羞辱中近景(★★★) → 主角冷脸特写(指尖停顿/INNER) → 反转触发特写(证据/身份) → 全场反应+反派碎裂(大爽★★★★★)
   注：这是短剧最高频场景，必须"事实打脸"而非吼；见 references/01、04。
```

## 七、名导演镜头技法库（服务剧情前提 · 不为炫技）

> **选用纪律（最高优先级）**：每一种名导演镜头都是"情绪语法"而非装饰。落笔前必须能回答
> "这个镜头服务哪个剧情前提/爽点/钩子？"——答不出就是炫技，禁用。同一技法全片≤1–2 次，
> 越稀有越有力。竖屏重译：人物占 ≥60%，幅度按 §四 收敛，大远景/大幅环绕慎用。

### 技法详解（每个含"服务前提 + 竖屏用法 + 禁忌"）

**希区柯克变焦（Dolly Zoom / Vertigo Shot）**
· 是什么：摄影机后退同时变焦推近（或反之），主体大小不变、背景透视扭曲。
· 服务前提：角色"世界塌缩/认知被推翻"的瞬间（身份揭晓、陷阱坠入、记忆骗局）。
· 竖屏：特写人脸 + 背景纵拉；1–2s，只落反转触发器镜。
· 禁忌：无前提硬塞 = 廉价眩晕；全片 ≤1–2 次。

**迈克尔·贝环绕（Michael Bay Orbit）**
· 是什么：摄影机绕主体 360° 环绕 + 缓推，常配微粒/光斑。
· 服务前提：英雄/战神登场、战力觉醒、封神高光（必须"人物值得被仰望"的节点）。
· 竖屏：绕上半身 180°–360°，幅度小、慢；落在大爽爆发镜。
· 禁忌：为爆炸/炫光而绕 = 背离前提；反派/弱者不配环绕；单集 ≤1 次。

**斯皮尔伯格推镜（Push-in）**
· 是什么：平稳缓推近，不带变焦，情绪向角色内心收束。
· 服务前提：角色做出艰难抉择、听到真相、情感 realization。
· 竖屏：中近景→特写，2–3s；落余波/钩子前。
· 禁忌：推镜过多 = 情绪通胀，每集 ≤2 次。

**库布里克单点透视（One-point Perspective）**
· 是什么：主体居于画面正中灭点，强对称纵深。
· 服务前提：权力压制/秩序窒息/体制碾压（男频反派势力、仙侠宗门威压）。
· 竖屏：走廊/门洞中心构图，人物极小；落压抑建置镜。
· 禁忌：无权力语境的对称 = 空洞美术。

**诺兰旋转长镜（Rotating Long-take）**
· 是什么：长镜中摄影机缓慢旋转/翻面，空间失重。
· 服务前提：时间迷宫/失控/秩序崩解（狼人兽化临界、仙侠秘境错乱）。
· 竖屏：小幅旋转 ≤30°，避免眩晕；落失控边缘镜。
· 禁忌：纯炫空间，无叙事失重感 = 炫技。

**王家卫抽帧慢镜（Step-printing）**
· 是什么：抽帧制造顿挫的慢动作 + 浓郁色。
· 服务前提：暧昧/回忆/悸动/意难平（甜宠心动、女频逆袭余韵）。
· 竖屏：特写眼神/指尖，0.5–1s 抽帧；落甜/余波镜。
· 禁忌：全片到处抽帧 = 廉价文艺。

**韦斯·安德森对称横移（Lateral Track）**
· 是什么：绝对对称构图 + 水平轨道横移。
· 服务前提：荒诞/工整/冷幽默（带货反差、甜宠误会用）。
· 竖屏：门框/长廊对称，横移揭示；落喜剧/反差镜。
· 禁忌：无幽默意图的对称 = 死板。

**蒂姆·伯顿低角（Low-angle Gothic）**
· 是什么：低角度仰拍 + 夸张比例 + 螺旋元素。
· 服务前提：暗黑童话/哥特宿命（狼人族群、仙侠邪殿）。
· 竖屏：仰拍人物占满，背景扭曲；落宿命镜。
· 禁忌：无暗黑基调硬加 = 违和。

**维伦纽瓦缓慢史诗（Slow Epic）**
· 是什么：极简构图 + 单一主导色 + 宏大景观 + 沉默张力。
· 服务前提：宏大/宿命/史诗孤独（仙侠登顶、男频封神远眺）。
· 竖屏：人物极小 + 环境极大（慎用，信息稀）；落升华镜。
· 禁忌：竖屏大远景滥用 = 主体过小。

**是枝裕和固定长镜（Fixed Long-take）**
· 是什么：固定机位长镜 + 自然光 + 生活噪音。
· 服务前提：日常/留白/生活质感（甜宠居家、女频平静前夜）。
· 竖屏：固定中景，靠表演微动作撑；落建置/余波镜。
· 禁忌：无表演支撑的固定 = 闷。

**今敏匹配转场（Match Cut）**
· 是什么：形状/色彩/动作匹配剪，时空无缝跳。
· 服务前提：虚实交织/心理视觉化（记忆骗局、穿越闪回）。
· 竖屏：用门框/圆物/色块匹配；落闪回/反转镜。
· 禁忌：为花哨匹配无叙事关联 = 跳戏。

**昆汀低角长对话（Low-angle Dialogue）**
· 是什么：低角度 + 长镜对话 + 高饱和。
· 服务前提：张力对峙/权力博弈（男频谈判、女配互撕）。
· 竖屏：过肩低角，对话两人；落冲突镜。
· 禁忌：无张力的闲聊低角 = 做作。

**保罗·格林格拉斯手持（Shaky Docu）**
· 是什么：手持微晃 + 纪实感。
· 服务前提：纪实/混乱/逃亡/真实感（狼人追猎、仙侠逃杀）。
· 竖屏：幅度极小，避免糊；落动作/逃亡镜。
· 禁忌：情绪戏手持 = 不安错位。

**奥逊·威尔斯深焦（Deep Focus）**
· 是什么：前中后景全清晰，多信息同框。
· 服务前提：阶层关系/因果同框（女频厅堂压迫、男频势力对比）。
· 竖屏：小光圈大景深；落建置镜。
· 禁忌：无多信息的深焦 = 杂乱。

**索菲亚·科波拉空镜（Empty Frame）**
· 是什么：人物极小/缺席的空镜，情绪留白。
· 服务前提：疏离/青春/无解（女频独处、甜宠错过）。
· 竖屏：环境占满，人物边缘；落余波/钩子镜。
· 禁忌：无情绪留白的空 = 拖。

**大卫·芬奇对称推镜（Symmetric Push）**
· 是什么：强对称 + 缓推，冷峻控制。
· 服务前提：冷峻控制/阴谋/算计（男频布局、反派谋划）。
· 竖屏：中心构图推近；落谋划镜。
· 禁忌：无控制的对称 = 僵硬。

**冈萨雷斯长镜（Birdman-style）**
· 是什么：一镜到底伪装实时，隐蔽切点。
· 服务前提：沉浸实时/情绪连续（漫剧/试播片可用缝合式单镜）。
· 竖屏：前景遮挡/黑场隐蔽切点；落单镜 Demo。
· 禁忌：无准备的长镜 = 一致性崩。

**罗杰·狄金斯逆光剪影（Contra-jour）**
· 是什么：逆光切割主体半脸/全身剪影，电影级质感。
· 服务前提：通用——外化内心分裂/被看见/宿命（可常用）。
· 竖屏：侧窗硬光，人物占 60%+；落身份揭晓/逆袭镜。
