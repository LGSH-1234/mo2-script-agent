# GRWM 美妆边化边聊广告 · 极速上手指南（skill-intro.md）

> **一句话定位**：以 TikTok/小红书爆款 GRWM（Get Ready With Me）美妆教程为标杆，用真实素颜、边化边聊闺蜜感、化妆步骤演示与妆效蜕变 reveal，把美妆产品转化为可见的闺蜜种草欲望。**素颜即真实，步骤即信任，蜕变即种草。**

## 🚀 30 秒上手流程

1. **锁基准资产**：先定 `@CHAR_MUA`（美妆博主 Model Card）+ `@PROD_MAKEUP`（美妆产品）+ `@SCN_VANITY`（明亮梳妆台）+ `@PROP_BRUSH`（化妆刷工具），一次性锁定，全程 @ 引用禁止链式改（素颜→妆效须同一面部骨相）。
2. **选文生图版本**：默认用 `SKILL.md §二` 的 MJ v8 专属版或常规通用版；用户点名"角色资产卡/Model Card/定妆卡"时才输出第三版本（10 格）。
3. **写剧本**：套四段式 GRWM——①素颜开场妆容预告 → ②化妆步骤边化边聊 → ③妆效 reveal → ④种草清单 CTA（详见 `02-viral-script-hooks.md`）。
4. **生成视频**：套 `SKILL.md §三` 的 11 段式多参引擎，**除台词外整体描述必须用中文**，竖屏 9:16 手机原生，逐段注入美妆质地动力学 + 光影五子层。
5. **配音效**：轻柔 BGM + 真实闺蜜口播 + 化妆品 ASMR（开盖/粉扑/刷子扫）（详见 `03-sound-design-asmr.md`）。

## 🎯 五大不可动摇配方速查

| 配方 | 数值锚点 |
|---|---|
| **环形灯显肤质光** | 环形灯正面柔光 0° 4800K CRI 95 显肤质讨喜，侧柔光塑形 55° Key:Fill 1.8:1 温柔，12 点钟环形眼神光 |
| **竖屏面部近景** | 手机前置 50mm 等效面部近景，齐眼 1.5m，竖屏 9:16，化妆步骤切产品质地特写，reveal 卡点缓推 |
| **真实素颜蜕变** | 真实皮肤毛孔细纹拒绝过度磨皮，素颜→妆效同一面部骨相 100% 一致，前后对比 reveal 震撼 |
| **美妆质地动力学** | 纯产品镜头 AU 转译为膏体挤出/粉质飞散/刷毛扫动/珠光流转，声明 `[本镜无角色主体]` |
| **闺蜜 AU 表演** | 素颜 AU6+AU12 闺蜜微笑（B 级），化妆 AU17+AU24 专注（A 级），reveal AU1+AU2+AU26 惊喜（D 级） |

## ⚠️ 三条红线
- **严禁过度磨皮**：真实皮肤毛孔细纹须保留显肤质，绝不允许过度磨皮假面、塑料感、失真瘦脸。
- **严禁换脸**：素颜与妆效须同一面部骨相 100% 一致，绝不允许妆前妆后像换脸（破坏信任）。
- **字幕铁律**：No subtitles.（字幕/产品名花字绝不由模型生成，须后期硬压）；台词保留原语言口语化，口型同步精准。
