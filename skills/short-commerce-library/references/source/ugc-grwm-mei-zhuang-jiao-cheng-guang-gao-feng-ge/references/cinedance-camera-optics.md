# GRWM 美妆运镜与光学（cinedance-camera-optics.md）

1. **手机前置 50mm 面部近景（0-5s 素颜）**：手机前置 50mm 等效面部近景，齐眼高度 1.5m，正方位角 0° 直视镜头对话感，竖屏 9:16 面部构图，环形灯显肤质，抓闺蜜亲密感。
2. **化妆步骤特写切换（5-18s）**：面部近景 ↔ 产品质地特写交替，50mm T2.0 浅景深突出妆容细节与产品质地，手动对焦呼吸感，教程步骤清晰可视。
3. **reveal 卡点缓推（18-25s）**：妆效 reveal 用缓慢推近（push in）+ 卡点对齐 BGM，素颜→妆效前后对比切换，强化蜕变震撼，环形灯显妆效通透。
4. **竖屏 9:16 面部安全区**：面部主体居中偏上（适配 TikTok UI），妆容细节清晰，产品名花字预留底部安全区，竖屏满屏亲密，绝不 2.39:1 横屏。
5. **亲密感运镜克制**：GRWM 运镜须克制舒缓（边化边聊），避免过度运镜破坏"闺蜜视频"亲密感，固定 + 缓推为主，卡点点睛，绝不电影级复杂运镜。
6. **V4.1 视角机位量化铁律**：每个镜头显式声明摄影机高度（1.5m 齐眼）+ 方位角（0° 正面）+ 焦段（50mm 手机等效面部）+ 光圈（T2.0）+ 快门等效（180°）+ 竖屏 9:16，严禁横屏电影机位描述。
