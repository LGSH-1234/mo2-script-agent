# GRWM 美妆声场工程（03-sound-design-asmr.md）

1. **化妆品 ASMR 核心**：开盖咔哒、粉扑轻拍上脸、刷子扫动、膏体挤出、喷雾细 mist、口红旋出，真实化妆品 ASMR 是 GRWM 沉浸的灵魂，强化质感与"想拥有"的欲望，须清晰细腻。
2. **真实闺蜜口播**：口语化中文（或原语言）边化边聊，"跟闺蜜视频化妆"的松弛亲密语气，分享技巧与心得，非念稿非播音腔，口型同步精准。
3. **轻柔 BGM 铺底**：轻柔 lo-fi/清新 BGM 低音量铺底，营造放松闺蜜氛围，绝不喧宾夺主盖过口播与 ASMR。
4. **reveal 音效强调**：妆效 reveal 卡点配上扬音效/叮（惊艳提示），强化素颜→妆效蜕变的震撼感。
5. **动态范围铁律**：0-5s 素颜轻柔 BGM + 闺蜜口播起 → 5-18s 化妆 ASMR 主导（开盖/粉扑/刷子）+ 边化边聊 → 18-25s reveal 上扬音效 + BGM 卡点小高潮 → 25-30s CTA 安利口播 + BGM 收尾，舒缓有起伏绝不吵闹。
6. **台词与字幕铁律**：口播台词保留原语言口语化，口型同步精准锁定；No subtitles.（字幕/产品名花字绝不由模型生成，须后期硬压）。
