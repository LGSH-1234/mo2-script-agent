# GRWM 美妆 3D 白模与轨迹锁定（whitebox-3d-rendering-guide.md）

1. **素颜→妆效渐变白模锁定**：先用 3D 白模（greybox）锁定 `@CHAR_MUA` 面部骨相基准，素颜与妆效共用同一面部拓扑/骨相，妆容用贴图分层（底妆/眼影/唇妆 mask）叠加渐变，确保蜕变过程"同一张脸"（严禁换脸）。
2. **化妆步骤动作轨迹**：手部化妆动作（粉扑轻拍/刷子扫动/口红涂抹）须用动画曲线锁定关键姿态与轨迹，对齐面部区域，避免手部穿模与动作僵硬。
3. **美妆质地动力学**：膏体挤出用流体/柔体解算，粉质飞散用粒子系统，刷毛扫动用毛发/柔体动力学，珠光流转用高光贴图动画，确保美妆质地物理可信诱人。
4. **环形灯光照渲染**：环形灯须用环形面光源（ring area light）模拟——正面 0° 柔和均匀显肤质、12 点钟圆形眼神光、Key:Fill 1.8:1 侧柔光塑形，确保美妆通透讨喜光。
5. **真实肤质感 PBR 工作流**：皮肤用真实 PBR（毛孔/细纹/绒毛/次表面散射 SSS，拒绝过度磨皮），妆容水光/珠光/缎光分层材质，产品包装真实质感，确保显肤质微观质感证据链落地。
6. **单一源公理铁律**：@CHAR_MUA/@PROD_MAKEUP/@SCN_VANITY/@PROP_BRUSH 的 3D 资产模型一旦锁定为基准，所有镜头状态（素颜→化妆→妆效→CTA）从同一基准模型渲染，严禁链式修改导致面部骨相/产品漂移。
