# 人物身份与场景细节指南

通过改变人物身份，可以微调工位场景与行为细节，以增强真实感。

| 人物身份 | 核心视觉特征 | 工位/行为细节 |
|---|---|---|
| 通用打工人 | 标准通勤装，中性气质 | 标准工位，单屏显示器，普通办公椅 |
| 互联网打工人 | 更有设计感或休闲的穿搭，可能背电脑包 | 双屏显示器，机械键盘，工位上有咖啡杯或零食 |
| 独居青年 | 更加随意的居家/通勤过渡感 | 卧室场景偏向简约/单人感，工位可能在小户型房间内 |
| 办公室新人 | 较为整洁、略显正式的穿搭 | 工位略显空旷，周围背景有模糊的同事身影，动作略显拘谨 |
| 自由职业者 | 休闲风格，随性，常带笔记本电脑 | 场景为咖啡店或共享办公空间，咖啡杯，笔记本电脑 |

## Prompt 追加建议

- **互联网打工人**：互联网公司工位，双屏显示器，机械键盘，桌上有咖啡杯和零食，休闲穿搭背电脑包
- **独居青年**：小户型卧室，单人床，简单家具，独居生活感
- **办公室新人**：工位略显空旷，同事背景模糊但存在，动作略带局促感，穿搭偏正式
- **自由职业者**：咖啡店或共享办公空间，笔记本电脑，咖啡杯，休闲随性穿搭
