# 视频 Prompt 文法

## 人物 Prompt 构造规则

每段视频生成的 Prompt 必须包含以下人物锚定描述，且必须引用用户上传的人物参考图：

```
保留 @图片1 所示人物的脸型、五官比例、发型、发色、年龄气质、性别表达和自然身份一致性；面部清晰自然，不换脸，不明星化，不改变人物身份。人物全片保持同一外貌、同一发型和同一套通勤穿搭，动作自然，人体结构真实。
```

### 人物一致性策略

1. **首帧锚定**：第一段起床镜头尽量清晰保留人物面部特征。
2. **服装延续**：后续通勤镜头保持同一套通勤穿搭。
3. **镜头节奏**：避免频繁特写脸部，用手部、包、早餐、电脑等细节增强真实感。
4. **风格统一**：全片保持同一色调与同一 Vlog 质感。
5. **允许的适配**：服装可在原穿搭基础上微调为通勤装；场景按通勤流程变化；镜头角度在合理范围内切换；允许手持 Vlog 视角、背影、侧面、第一视角辅助镜头。

## 场景 Prompt 模板

### 起床洗漱场景
```
清晨卧室，闹钟响起，人物迷迷糊糊坐起，揉眼睛，冷水洗脸，快速刷牙。冷调清晨自然光。
```

### 地铁通勤场景
```
人物背着包走出家门，进入地铁站，过闸机，挤上早高峰地铁，抓着扶手看时间。第一视角与跟拍交替，城市清晨灰蓝色调。
```

### 自驾通勤场景
```
人物坐进车内，系安全带，握方向盘，等红绿灯，车流缓慢前行。车内第一视角、手部特写、挡风玻璃外车流。
```

### 便利店早餐场景
```
人物走进便利店，拿饭团或三明治，买热豆浆，撕开包装，边走边吃。便利店暖黄灯光与清晨冷调形成对比。
```

### 到工位开工场景
```
人物到达办公室，放下包，打开电脑，按下开机键，深吸一口气，开始敲键盘。室内柔和光，电脑屏幕微亮。
```

## 画面文字禁止规则

每段 Prompt 必须包含以下硬约束：

```
全片不出现任何字幕、标题、花字、贴纸、水印或画面文字，不把旁白烧录为文字，不出现可读标语、品牌文字或界面文字。
```

## 正向措辞原则

- 场景描述用正向语言（"自然晨光"而非"不是夜晚"）
- 人物描述用正向语言（"真实自然"而非"不虚假"）
- 唯一例外：画面文字禁止规则使用否定式，因为"不出现文字"本身就是硬约束
- 不堆叠过多否定式约束，避免模型理解偏差
