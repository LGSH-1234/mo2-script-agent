# 平台与市场本地化指南

| 目标市场 | 平台 | 语言/风格建议 |
|---|---|---|
| 中国大陆 | 抖音 / 小红书 | 全文中文；追求高频快切、情绪价值、生活烟火气；适合使用轻量、高饱和或高对比度的视觉风格。 |
| 全球市场 | TikTok / Reels | 全文英文；追求极简、强节奏、全球化审美；适合使用胶片感或极简都市风。 |

## 合规与本地化提醒

1. **语言**：目标市场为中国大陆时，旁白必须为中文。
2. **品牌**：禁止在画面中出现可识别的真实品牌 Logo，应使用通用品牌感（如"一个咖啡杯"而非特定品牌杯）。
3. **文字**：严格执行"无文字"规则，避免模型自行生成乱码文字。
4. **人物真实感**：不美颜过度、不生成明星脸、人物动作符合真实人体结构。
