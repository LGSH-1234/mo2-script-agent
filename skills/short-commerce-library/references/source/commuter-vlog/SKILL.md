# 打工人通勤 Vlog

## 核心原则

打工人通勤 Vlog 的核心不是"拍了一条好看的上班视频"，而是"让每个打工人看到自己的影子"。真实的通勤没有滤镜，只有闹钟、赶路、便利店和工位。视频必须让人在 3 秒内产生"这就是我"的代入感，而非"这是一个演员在表演上班"。

持久引擎（因果链）：
**人物照片 → 身份锚定（脸型/发型/穿搭气质）→ 闹钟响起的真实疲惫 → 通勤路上的节奏紧迫 → 便利店早餐的烟火慰藉 → 工位坐下的闭环收尾 → 观众产生"这就是我的早八"共鸣**

人物一致性是这条链的地基。如果观众在第二段认不出第一段的人，整条因果链断裂，代入感归零。

质量测试（可证伪）：**如果视频中人物在起床、通勤、便利店、工位四个场景里的脸型、发型和穿搭气质无法被识别为同一个人，则技能失败，必须重做。** 第二条测试：**如果视频看起来像广告片或 MV 而不像手机随手拍的 Vlog，则风格失败。**

## 输入诊断

落 prompt 前必须明确或合理假设以下维度：

1. **人物身份特征**：从上传照片解析脸型、五官比例、发型、发色、年龄气质、性别表达、可见穿搭风格。这些是全片一致性锚点。
2. **通勤方式**：地铁 or 自驾，决定第二段镜头的内容差异（地铁站/闸机/车厢 vs 车内/方向盘/红绿灯）。
3. **时长选择**：15s 用一次视频生成即可拿到完整成片；30s 需拆成两段 ≤15s 片段分别生成，再后处理拼接。
4. **风格调性**：四种风格对应不同的色调、节奏、质感和旁白文案，见路由表。
5. **天气场景**：影响画面色调与人物状态（雨天撑伞/冷雾围巾/暴雨奔跑/酷暑擦汗）。
6. **人物身份**：影响工位细节（互联网人双屏/自由职业者咖啡店/办公室新人局促感）。
7. **旁白文案**：按风格从旁白文案库匹配对应文案。
8. **合规边界**：不出现真实品牌标识、不出现可读文字、不生成明星脸、不美颜过度、人物动作符合真实人体结构。

## 工作流

### Step 1：人物图输入与特征解析

接收用户上传的 1 张人物照片。从照片中解析以下特征并记录：
- 脸型与五官比例
- 发型与发色
- 年龄气质与性别表达
- 可见穿搭风格
- 整体身份一致性基线

将这些特征写入后续每一段视频生成的 Prompt 中，作为人物一致性锚点。

### Step 2：参数确认

如果用户未指定风格、时长、通勤方式等参数，使用默认值：
- 默认风格：丧系打工人
- 默认时长：15s
- 默认通勤：地铁通勤
- 默认天气：普通清晨
- 默认身份：通用打工人
- 默认旁白：轻声旁白
- 默认字幕：关闭

只追问缺失的必填项（人物照片），不追问已有项。

### Step 3：生成分镜脚本

根据时长生成分镜脚本。

**15s 精简版（默认，一次生成完整成片）：**

| 时间段 | 阶段 | 画面 | 人物呈现 | 镜头语言 |
|---|---|---|---|---|
| 0-3s | 起床洗漱 | 清晨卧室，闹钟响，人物迷迷糊糊坐起，揉眼，冷水洗脸 | 脸部清晰自然，保留原人物发型、年龄气质与身份特征 | 手持 Vlog，轻微晃动，冷调清晨自然光 |
| 3-7s | 通勤路上 | 地铁：背着包出门，进地铁站，过闸机，挤上早高峰地铁，抓扶手看时间 / 自驾：坐进车内，系安全带，握方向盘，等红绿灯 | 保持同一人物、同一发型与通勤穿搭 | 第一视角与跟拍交替，城市清晨灰蓝色调 |
| 7-10s | 便利店早餐 | 走进便利店，拿饭团或三明治，买热豆浆，撕开包装 | 同一人物、同一穿搭，可出现手部与侧脸 | 便利店暖黄灯光与清晨冷调对比 |
| 10-15s | 到工位开工 | 到达办公室，放下包，打开电脑，按下开机键，深吸一口气，开始敲键盘 | 人物坐在工位前，保留原人物特征与通勤穿搭 | 室内柔和光，电脑屏幕微亮，收尾特写键盘 |

15s 成片用一次视频生成即可拿到完整片段，上述时间段是同一条 Prompt 内的时间轴描述，不需要分段生成再拼接。

**30s 完整版（拆成两段 ≤15s 分别生成，再拼接）：**

第一段（0-15s）：起床洗漱 + 通勤路上前半
第二段（15-30s）：通勤路上后半 + 便利店早餐 + 到工位开工

两段生成时，第二段的 Prompt 中必须显式引用第一段的人物特征描述（脸型、发型、穿搭），确保跨段一致性。

### Step 4：构造 Prompt

按以下结构组装每一段视频生成的 Prompt：

**核心人物 Prompt（每段必含）：**
保留上传人物的脸型、五官比例、发型、发色、年龄气质、性别表达和自然身份一致性；面部清晰自然，不换脸，不明星化，不改变人物身份。人物全片保持同一外貌、同一发型和同一套通勤穿搭，动作自然，人体结构真实。

**场景 Prompt（按当前阶段选择）：**
真实生活化上班通勤 Vlog，[当前阶段场景描述]，手机手持拍摄质感，轻微抖动，自然晨光，[风格对应色调]，生活细节丰富但不杂乱。

**节奏 Prompt：**
按起床洗漱、通勤路上、便利店早餐、到工位开工的顺序推进，镜头切换流畅，人物状态从疲惫逐渐过渡到进入工作状态，整体节奏[风格对应节奏]。

**画面文字 Prompt（每段必含）：**
全片不出现任何字幕、标题、花字、贴纸、水印或画面文字，不把旁白烧录为文字，不出现可读标语、品牌文字或界面文字。

**天气 Prompt（按天气选择追加）：**
- 普通清晨：清晨自然光，天空微亮，城市刚苏醒
- 雨天通勤：细雨蒙蒙，人物撑伞，地面湿反光，灰蓝色调加深
- 冷雾清晨：薄雾笼罩，能见度低，人物围围巾，呼出白气
- 暴雨通勤：大雨倾盆，人物奔跑避雨，雨伞被风吹歪，路面积水
- 酷暑早高峰：烈日清晨，人物擦汗，短袖通勤装，阳光刺眼

**身份 Prompt（按身份选择追加）：**
- 通用打工人：标准工位，单屏电脑，普通办公椅
- 互联网打工人：双屏显示器，机械键盘，工位上有饮料杯和零食
- 独居青年：小户型卧室，独居感细节（单人床、简单家具）
- 办公室新人：工位略显空旷，同事背景模糊但存在，新人局促感
- 自由职业者：咖啡店或共享办公空间，笔记本电脑，咖啡杯

### Step 5：生成视频

- 15s：用一次视频生成即可拿到完整成片。将用户上传的人物照片作为参考图片传入，Prompt 中用 `@图片1` 引用并说明"画面中的人物应保持 @图片1 所示的外貌、发型和穿搭气质"。
- 30s：拆成两段 ≤15s 片段，每段分别生成。两段都以同一张人物参考图作为输入。生成后用后处理将两段拼接为完整成片。

### Step 6：输出

输出为 9:16 竖屏 Vlog。全片无字幕、无文字、无花字。如有旁白，旁白文案按风格从 `references/formats/narration-scripts.md` 匹配。

## 静默自检

出稿前内部跑一遍以下检查，不外显给用户：

1. **人物一致性**：每段 Prompt 是否都包含完整的脸型/发型/穿搭气质描述？是否引用了用户上传的人物参考图？
2. **风格一致**：全片是否使用同一种色调与 Vlog 质感？是否避免了不同风格参数混用？
3. **四阶段完整**：起床洗漱 → 通勤路上 → 便利店早餐 → 到工位开工，四个阶段是否全部出现且顺序正确？
4. **画面文字禁止**：Prompt 是否包含"全片不出现任何字幕、标题、花字、贴纸、水印或画面文字"的硬约束？
5. **时长与生成方式**：15s 是否用一次生成？30s 是否拆成两段 ≤15s？拆分时第二段是否显式引用人物特征保持跨段一致？
6. **通勤方式正确**：地铁和自驾的场景描述是否选对了分支？
7. **天气与身份**：天气场景和人物身份是否按用户选择（或默认值）正确追加到 Prompt？
8. **措辞正向**：Prompt 是否以正向描述为主，不堆否定式约束（画面文字禁止规则除外，该条必须保留）？
9. **真实感**：是否避免了广告片/电影感？是否保持了手机手持 Vlog 质感？
10. **比例**：是否指定 9:16 竖屏？
11. **合规**：是否不出现真实品牌标识、不生成明星脸、不美颜过度？
