
# Hollywood Craft

## Scope

好莱坞式创作在这里指可读的类型叙事和有目的的电影视听组织，不等于剧本排版、美国地名、白人演员、枪战爆炸或统一的青橙调色。保持用户地点、人物、基调、画幅和声音要求。只改一句话时不展开本流程；只要剧本时只交付剧本，不调用媒体工具。

## Dramatic Engine

完整写一场戏前，确定：主角此刻要得到什么、什么阻止他、他作出什么选择、选择改变了什么。开放故事要让观众在结尾看到行动后果或认知变化，不只看人物完成一项没有阻力的操作。阻力可来自时间、空间、不同目标或信息差，不必是反派或危及生命。

15秒聚焦一个目标和一次变化；30秒可有一次尝试及其后果，再完成选择。已有完整情节时识别其内在戏剧变化，不能为“更好莱坞”加追杀、秘密组织或新人物。不要对所有类型强加反转，喜剧的关系改变和剧情片的艰难让步同样可以收束。

## Genre to Screen

先选择用户要求的类型；用户未定时，从故事的核心情绪选择一个相容的方向。不把所有类型混在同一短片。

| 类型 | 戏剧与氛围如何落到画面和声音 |
|---|---|
| 悬疑、犯罪 | 明确观众与人物各知道什么；利用门框、遮挡、画外空间或反射限定信息。先建立具体声音来源，再让声音中断或位置变化推动人物判断。关键发现时改变景别或焦点，让观众看见证据。低调照明要保留眼睛、手和证物。 |
| 动作、冒险 | 先让观众读懂目标、危险方向、距离与出口，再靠人物动作改变空间。冲击后保留惯性、喘息、物件损坏或行动代价。节奏来自行动因果，不是任意快切和摇镜。 |
| 爱情、喜剧 | 同一空间里设不同目标或理解，用道具、站位和反应的时机制造期待与落差。暖光应有台灯、窗户等来源；笑点后留一个准确反应，不用煽情音乐替代人物互动。 |
| 剧情、温情 | 明确谁在给予、谁在拒绝、何时关系改变。用距离、视线、手部停顿和物件传递表达潜台词；在选择发生时靠近人物，保留有意义的沉默和生活声。温情也需要可读的心理过程，不必升级成惊险片。 |

每场选择少量共同服务故事的视听手段：一个可辨认的空间关系、一种有来源的主光、一个提示信息或人物关系的声音、一处由行动驱动的镜头或构图变化。固定机位也能依靠人物调度、景深和画外声音成立，不强制移动镜头。无音乐要求必须保留；不默认配预告片轰鸣、旁白、字幕或黑边。

## Performance and Subtext

台词表达人物当下的策略，不向观众复述剧情。表演写“看到什么、听到什么、视线和行动如何改变”，不是只写紧张、悲伤或电影感。一个角色把杯子推回去可以是拒绝，也可以是分享，要通过已有情境、停顿与对方反应让意义可见。不能用连续空镜或长期呆滞凝视代替戏。

## Production Handoff

用户明确要视频时，把已确定的类型、空间关系、光源、声音线索、表演和关键镜头与剧本一起传给制作流程。实际视频 Prompt/PromptPath 必须包含这些可执行信息，不能在分析里写好莱坞、到生成时只剩“写实风格”。中文请求默认使用中文自然语言生成正文（工具字段和路径保持原样），不额外生成英文版；明确要求的其他语言对白按原要求保留。

交接前检查：删掉“好莱坞、大片、电影感”等标签后，是否仍能从实际内容读出类型与氛围？目标—阻力—选择—结果是否在时长内可拍？用户精确剧情、固定机位、声音限制是否保留？若只能靠标签辨认风格，改写具体场景与视听证据；不要把文字检查通过说成成片质量已通过。
