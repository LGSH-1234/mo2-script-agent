# 首饰品牌片

## 核心原则

全片持续回避直给——面孔被发丝遮挡、主体被虚焦、人物被光晕淹没。这种「半遮半现」策略制造贯穿始终的观看欲望，是本技能的核心美学。

**持久引擎（因果链）：**
输入图分类提取 → 关键元素定义 → 12镜头叙事模板（局部悬念 → 人物建立 → 情绪爆发 → 呼吸转场 → 再现收束 → 离场）→ Elements前置生成 → A类关键帧 → A类视频 → B类图像+视频 → 音乐 → 最终剪辑合成

**质量测试（可证伪）：**
如果全片任意一帧出现人物直视镜头并摆出明显广告pose，或首饰未在任何镜头中作为画面核心对焦主体呈现，则该镜头不通过，须重做。010核心广告帧中首饰必须处于实焦位置且金属/宝石面有可见高光反射点，否则整片不成立。

## 输入

用户可上传1至多张参考图，按以下类别分组。未提供某类别时，对应元素由AI根据已有参考图风格自行推断生成。

| 类别标签 | 说明 |
|---|---|
| `[Character_Input]` | 模特参考图（可多张，含不同角度/造型） |
| `[Jewelry_Input]` | 首饰参考图（可多张，含细节/佩戴状态） |
| `[Environment_Input]` | 环境参考图（可多张，含建筑/街景/室内） |
| `[Brand_Input]` | 品牌参考图（可多张，含logo/slogan/视觉调性） |

**素材缺失处理：** 用户已提供某类别图片时，直接绑定为该类别参考；未提供时由AI基于已有参考推断。仅在缺失 `[Environment_Input]` 时需询问用户（见工作流步骤2）。

## 输入诊断

生产前必须明确或合理假设以下维度：

- **视频比例**：9:16 竖屏（适合小红书/抖音/Reels）或 16:9 横屏（适合YouTube/品牌官网）——启动时必须询问用户
- **候选视频数量**：每镜头生成3个候选版本（逐镜筛选，效果最优，积分消耗较多）或1个版本（节约积分，生成速度快）——启动时必须询问用户
- **首饰品类与核心卖点**：从 `[Jewelry_Input]` 提取的种类、材质、工艺
- **目标市场与语种**：影响环境调性与音乐风格
- **目标平台与画幅**：决定最终输出分辨率
- **环境来源**：用户提供 `[Environment_Input]` / 用户文字描述 / AI自动推断
- **品牌元素**：是否提供 `[Brand_Input]`，决定013镜头是否生成
- **合规敏感点**：避免过度暴露、低俗暗示；保持高级感与品牌调性

## 工作流

### 步骤1 · 启动配置（必须先于一切步骤）

询问用户以下两项配置，将结果写入 `Final_Video_Spec.md`：

**① 视频比例：**
- A. 9:16 竖屏（适合小红书/抖音/Reels）
- B. 16:9 横屏（适合YouTube/品牌官网）

**② 每个镜头生成的候选视频数量：**
- A. 每个镜头生成 **3个候选版本**（生成后逐镜筛选，效果最优，积分消耗较多）
- B. 每个镜头生成 **1个版本**（节约积分，生成速度快）

写入字段：`video_ratio`（值为 `9:16` 或 `16:9`）、`shot_candidates`（值为 `3` 或 `1`）。全流程沿用此配置。

### 步骤2 · 输入图分类分析

对用户上传的每一类参考图分别进行客观特征提取。严禁主观解读或美化，只做客观特征提取。提取结果作为后续所有分区的内容依据。

详细提取规范见 `references/industries/jewelry-visual-archive.md`。

**环境条件判断：** 若未检测到 `[Environment_Input]`，立即询问用户：
- A. 我来描述：请输入您的环境风格需求（风格/城市/光线/色调等）
- B. AI自动设计：基于角色与首饰参考图自动推断并扩展环境

将结果写入 `Final_Video_Spec.md` 作为 `[Environment_Ref]` 来源。

提取完成后，定义本次项目的关键元素：
- `[Character_Main]`：面部特征、发型、肤色、体型、造型（若有多套造型，注明 Look 1 / Look 2）
- `[Jewelry_Hero]`：首饰完整视觉档案（形态、材质、细节、佩戴状态）
- `[Environment_Ref]`：环境基调、光线特征、可用场景层次
- `[Brand_Ref]`：品牌文字、Logo、品牌视觉元素（若未提供则为空）

### 步骤3 · 12镜头故事板生成

按固定12镜头叙事逻辑生成故事板，所有内容从输入图提取，不套用固定场景描述。镜头列表见下方「12镜头叙事模板」。

**若已提供 `[Brand_Input]`，同步询问013镜头背景方案（三选一）：**
- A. 纯黑背景 + logo居中
- B. 品牌色调低饱和纯色背景（推荐高级感）
- C. 由AI设计带logo的创意收尾帧

将选择写入 `Final_Video_Spec.md`。

⏸ **暂停，等待用户确认故事板及013方案（若适用）。**

### 步骤4 · Elements图像生成（所有镜头生成前置）

生成三类元素图，2K分辨率：

**人物元素 `[Character_Main]`：**
直接以 `[Character_Input]` 中的参考图作为生成依据，生成全身三视图（头顶至鞋）：正面 / 侧面 / 背面。核验：面部特征、发型、肤色、服装、体型与输入图一致。

**首饰元素 `[Jewelry_Hero]`：**
直接以 `[Jewelry_Input]` 中的参考图作为生成依据，生成：正面特写 / 佩戴于人体状态图。核验：金属光泽、吊坠形态、工艺细节与输入图完全一致。

**环境元素 `[Environment_Ref]`：**
- 若用户提供 `[Environment_Input]`：直接以参考图为依据，生成代表性场景渲染图（空景 + 带人物占位）
- 若用户选择「A · 我来描述」：以用户文字描述为提示词生成
- 若用户选择「B · AI自动设计」：基于 `[Character_Main]` 与 `[Jewelry_Hero]` 风格特征自动推断环境氛围，生成3个候选方案供用户选择

生成：代表性空景全景 / 中景 / 纵深构图（各1张，作为B类镜头与A类背景共用参考）。核验：色调、光线方向、建筑风格与整体叙事调性匹配。

⏸ **暂停，等待用户确认角色、首饰与环境元素还原度。**

### 步骤5 · A类关键帧图像生成

每个A类镜头（001/002/003/004/005/009/010/011/012）生成关键帧图像，2K分辨率。每个镜头参考图同时包含：
1. `[Character_Main]` 元素图（正面或侧面，取决于镜头角度）
2. `[Jewelry_Hero]` 元素图
3. `[Environment_Input]` 中与该镜头场景最匹配的参考图
4. 同场景中前序镜头的关键帧（维持连贯性）

010镜头额外要求：`[Jewelry_Hero]` 处于实焦位置，金属/宝石面有可见高光点。

⏸ **暂停，等待用户确认。**

### 步骤6 · A类镜头视频生成

为每个A类镜头生成视频，1080p，比例按 `Final_Video_Spec.md` 中用户选择。每个镜头同时参考：`[Character_Main]` 元素图 + 该镜头关键帧图。

候选版本数量：读取 `Final_Video_Spec.md` 中的 `shot_candidates` 字段。单次生成可产出 ≤15s 的完整片段；本技能每个镜头时长均在3-5秒，一次生成即可拿到成片。

时长设定：
- 001 / 006 / 008 / 012：3-4秒
- 002 / 003 / 005 / 007 / 009 / 011：4-5秒
- 004 / 010：3秒

### 步骤7 · B类镜头图像+视频生成

B类镜头（006/007/008），基于步骤4环境elements生成：
- 006：以 `[Environment_Input]` 中的材质/植物细节参考图为依据，生成极浅景深微距，手持电影运镜
- 007：以 `[Environment_Input]` 的全景参考图为依据，生成无人物纯环境空镜，电影运镜
- 008：以 `[Environment_Input]` 的空间参考图为主体，`[Character_Main]` 作虚焦前景（三分之一位置），背景实焦纵深长景，电影运镜

用户已提供满意库存图的B类镜头，直接绑定，跳过生成。

**013镜头生成（条件性，需 `[Brand_Input]`）：** 根据用户在故事板确认时选定的方案执行，详见 `references/formats/brand-frame.md`。

⏸ **条件性暂停：** 若 `shot_candidates = 3`，暂停并等待用户逐镜头筛选所有候选版本（A类+B类+013）；若 `shot_candidates = 1`，直接进入下一步，无需筛选。

### 步骤8 · 背景音乐生成

生成 ambient cinematic 风格背景音乐，无歌词。情绪弧：开篇舒缓 → 004-005升温 → 006-008平静 → 011-012渐弱。色调参照 `[Environment_Input]` 的整体氛围匹配音乐风格。时长与最终视频总时长匹配。

### 步骤9 · 最终剪辑合成

按固定镜头顺序（001→002→003→004→005→006→007→008→009→010→011→012→013条件性）合成最终视频。

**时间线规格：**
- 总时长：60-75秒（含013时延长至63-79秒）
- 画面比例：由 `Final_Video_Spec.md` 中用户选择决定
- 帧率：24fps

**转场规范：**

| 衔接 | 方式 | 时长 |
|---|---|---|
| 001→002 | 直切 | — |
| 002→003 | 直切 | — |
| 003→004 | 直切，节拍点对齐 | — |
| 004→005 | 叠化 dissolve | 0.5秒 |
| 005→006 | 叠化 dissolve | 0.8秒 |
| 006→007 | 直切 | — |
| 007→008 | 直切 | — |
| 008→009 | 直切 | — |
| 009→010 | 直切，节拍点对齐 | — |
| 010→011 | 直切 | — |
| 011→012 | 叠化 dissolve，渐出 | 1秒 |
| 012→013 | 渐黑至纯黑 | 1.5秒（仅当013存在） |
| 013结尾 | 淡出至黑 | 0.8秒 |

节奏原则：001-004节奏紧；004-008叠化放缓；009-012重新收紧后渐弱收尾；013独立收束，与前片留有黑场间隔。

**音频轨道规范：**
- 视频轨道全部静音（mute all video audio tracks）
- BGM置于独立音频轨道
- BGM音量：-12dB，末尾3秒渐出（fade out）
- 严禁叠加其他音效，除非用户明确要求旁白

**输出规格：**
- 格式：MP4，H.264
- 分辨率：9:16 → 1080×1920；16:9 → 1920×1080
- 码率：≥ 8Mbps

**依赖关系：** 步骤1优先；2→1；3→2；4→3；5→4；6→5；7→4,3；8→3；9→6,7,8

## 12镜头叙事模板

核心原则：本模板只规定每个镜头的景别、叙事位置、情绪功能和影像技法。所有内容（人物外形、首饰款式、环境风貌、品牌元素）均从输入图提取，不套用固定的场景、服装或道具描述。

### 001 — ECU · 首饰局部特写（A类）

- **景别：** 极近景，身体局部（锁骨/手/耳颈）。面部上半（眼睛、额头）不入画。根据首饰类型，面部仅出现一小部分。对于项链，聚焦于面部下半部分至胸口区域。
- **内容：** `[Jewelry_Hero]` 作为画面核心，`[Character_Main]` 身体局部入画提供皮肤/服装质感
- **构图：** 角色面部完全侧脸（Full Profile），身体四分之三转体（Three-Quarter），躯干相对于镜头约四分之三旋转偏折，略微侧向/背离镜头，形成从面部到胸口的流畅斜线构图。当首饰是戒指、手镯类型时，仅展现手部。
- **运动：** 镜头以首饰挂坠为中心支点，沿弧形轨迹缓慢横向移动，模拟摄影师手持相机围绕主体做弧线位移。整体运动幅度克制，属于微环绕，非大角度旋转。景深保持稳定，主体始终对焦，浅景深背景持续虚化。
- **功能：** 感官引入，悬念建立，产品首次曝光
- **提取依据：** 首饰形态与佩戴方式来自 `[Jewelry_Input]`

### 002 — MS · 环境站姿（A类）

- **景别：** 中景，腰部以上半身。角色面部四分之三侧面（3/4 Profile），脸朝向画面一侧，表情自然。身体躯干基本正对镜头，与面部朝向形成轻微扭转感，姿态放松自然。
- **内容：** `[Character_Main]` 在 `[Environment_Ref]` 对应环境氛围中自然站立或行走，`[Jewelry_Hero]` 可见但非焦点，人物与环境形成真实共存感。
- **构图：** 角色位于画面一侧，不居中。环境沿透视汇聚线（Leading Lines）向画面纵深延伸，强烈空间纵深感。浅景深，角色清晰，远端背景轻微虚化。首饰清晰可见，视觉层次分明。
- **光线：** 环境侧光从画面一侧上方打入，在角色发丝与肩部形成柔和轮廓光。环境光影层次丰富，整体氛围有质感。
- **运动：** 镜头平稳匀速运动。角色向镜头方向走来时，镜头同步向后退让，速度基本匹配。角色前进与镜头后退接近平衡，景别维持在中景（MS）→ 中近景（MCU）稳定区间。
- **功能：** 人物与场景建立
- **提取依据：** 背景环境视觉语言来自 `[Environment_Input]`

### 003 — 低角度CU · 动态细节（A类）

- **景别：** 地面或极低视角，`[Character_Main]` 局部（腿/脚/手）。展现腿脚时画面截取地面至小腿下段区域，仅呈现脚部、鞋子与服装小腿区域，为身体局部极近特写。
- **内容：** 环境地面细节（地砖/落花/草地/落叶，取决于 `[Environment_Input]`）与 `[Character_Main]` 局部动态同框，轻微运动模糊。
- **运动：** 镜头从极低角度（虫视 Worm's-Eye View）以平稳有节奏感方式向后移动（Dolly Out），后退速度与角色前行步伐精准匹配，形成「脚步迎面而来 × 镜头同步退让」的动态平衡。运动模糊动感真实，运动平稳有节律与步伐韵律同步，无明显抖动。
- **功能：** 行进感，在地氛围
- **提取依据：** 地面质感与环境细节来自 `[Environment_Input]`

### 004 — MCU · 光晕情绪帧（A类）

- **景别：** 中近景，肩部以上侧面。截取肩部至头顶区域，呈现角色肩颈、侧脸与发丝，为上半身特写。面部完全侧脸（Full Profile），标准正侧面——鼻梁、嘴唇、下巴侧面轮廓清晰，眼眸微闭或半闭，神情迷离空灵，非正对镜头。身体四分之三转体，与侧脸朝向一致，颈部延伸线与肩部弧度自然流畅。极浅景深，角色轮廓与发丝为焦点，背景完全虚化，前景有若有若无的虚化遮挡物。
- **内容：** `[Character_Main]` 侧脸，画面叠加暖色光晕（物理遮挡或光泄漏），轻微运动模糊。光线色调参照 `[Environment_Input]` 的光线特征延伸处理。
- **光线：** 光源来自角色身后偏上方，强光打出清晰发丝轮廓光（Rim Light）。光晕（Halo）包裹角色头部与肩部，近乎梦幻视觉氛围。镜头光斑（Lens Flare）逆光触发横向或放射状光斑，增强电影感与自然感。光泄漏（Light Leak）画面边缘有轻微光泄漏效果，强化光线物理真实感。
- **运动：** 轻微手持晃动
- **功能：** 情绪爆发，电影感最强帧

### 005 — MS · 逆光剪影（A类）

- **景别：** 中景，背对镜头。角色虚焦前景（Out-of-Focus Foreground），身体呈现为虚化前景剪影，位于画面一侧边缘。虚焦处理使角色退为环境叙事的框架元素而非视觉主体，姿态隐约可见为站立状，背部或侧背对镜头。
- **内容：** `[Character_Main]` 背影轮廓（面部特征不需要），以 `[Environment_Ref]` 自然环境元素（植被/天空/光源）形成散景背景，逆光欠曝。
- **构图：** 肩上构图（Over-the-Shoulder）逻辑，角色虚焦前景占据画面一侧或一角，视觉重心引导至实焦背景，强烈透视纵深感。
- **光线：** 从画面侧面/斜前方打入，形成光影分界，提升画面戏剧张力，画面层次丰富。
- **运动：** 微动态，电影运镜，画面靠植被轻摆与光束营造「活的静止」感。
- **功能：** 情绪顶点，去个体化
- **提取依据：** 背景散景色调与植被类型来自 `[Environment_Input]`

### 006 — ECU · 环境微距（B类）

- **景别：** 极近景，纯环境细节，无人物
- **内容：** 从 `[Environment_Input]` 中提取的代表性材质或自然元素（植物/纹理/水面/玻璃/砖墙），极浅景深，全画面虚化
- **运动：** 电影运镜，手持质感，赋予画面自然呼吸感与真实在场感
- **功能：** 强制呼吸，叙事减速
- **提取依据：** 微距对象来自 `[Environment_Input]` 中的材质特征

### 007 — LS · 纯环境空镜（B类）

- **景别：** 全景，纯场景，无人物
- **内容：** 从 `[Environment_Input]` 中提取最具代表性的建筑或空间全貌，突出环境纵深感与光线特征
- **运动：** 电影运镜
- **功能：** 场景转场，叙事呼吸
- **提取依据：** 建筑风格与空间全貌来自 `[Environment_Input]`

### 008 — MS · 人物/环境叙事帧（B类）

- **景别：** 复合景别（Composite Framing），前景虚焦人物 × 背景实焦长景的复合结构——前景角色以MCU近距离存在，背景呈现为全景（LS）规模纵深空间，两者形成景深上的强烈对比。
- **内容：** 以 `[Environment_Ref]` 提取的空间元素为主体（橱窗/拱廊/庭院/走廊/任何具有纵深的空间），`[Character_Main]` 作为虚焦前景存在
- **构图：** 角色位于画面一侧三分之一处，仅呈现头部、颈部与上肩区域，细节模糊，服务于环境叙事而非人物叙事。角色有一定轮廓光，为虚焦剪影增添质感。
- **运动：** 电影运镜
- **功能：** 场所标定，环境叙事
- **提取依据：** 空间类型与构图层次来自 `[Environment_Input]`

### 009 — FS · 全身造型帧（A类）

- **景别：** 全身景，头顶至鞋。人物位于画面一侧三分线位置，另一侧留白展现环境深度。
- **内容：** `[Character_Main]` 在 `[Environment_Ref]` 场景中完整呈现，造型可完整读取，`[Jewelry_Hero]` 清晰可辨
- **运动：** 呈现角色慢步走动的动态，体态轻盈自然，视线看向画面一侧光源处（避开镜头），电影运镜
- **功能：** 造型信息完整呈现，全片最可读的人物帧

### 010 — MCU · 首饰+面部，焦在首饰（A类）⭐核心广告帧

- **景别：** 中近景，面部下半至胸口，面部朝向画面一侧，呈标准正侧面，视线投向镜头外，非直视镜头，神情沉静内敛。身体姿态亦呈侧面站立，与面部朝向一致，重心自然分布，无明显倾斜，站姿松弛且有气质。
- **内容：** `[Jewelry_Hero]` 为对焦主体，呈现工艺细节；`[Character_Main]` 面部下半部分在焦平面内可见；侧光在首饰金属/宝石面形成高光反射点
- **运动：** 缓慢推进（Slow Dolly-in），有机手持微抖动（Organic Handheld Micro-movement），赋予画面自然呼吸感。随镜头运动光影斑驳纹路在角色身上的位移更加明显，强化光与肌肤的互动叙事。
- **功能：** 产品信息植入，面孔揭示前最高注意力帧

### 011 — CU · 面孔正面特写（A类）

- **景别：** 近景，胸部以上，面部为核心
- **内容：** `[Character_Main]` 正面或略低头，发丝轻扫面部，`[Jewelry_Hero]` 可见，眼神自然，非刻意对镜头pose
- **运动：** 极缓慢推进（Slow Dolly-in / Push-in），镜头以极度克制、匀速节奏缓慢向前推进，沿镜轴方向逐步靠近角色面部，「人物揭示」的情感张力持续升温，亲密感逐帧加深。镜头动态包括：角色自然生命感微动态、发丝飘动与斑驳投影位移（Hair Sway & Dappled Shadow Shift）、光晕与镜头光斑波动（Halo & Lens Flare Fluctuation）、首饰闪烁（Jewelry Glint）、在方向性强光下首饰细微镜面反光（Specular Glint）等。
- **功能：** 人物揭示，情感高潮，与001首尾呼应

### 012 — LS · 背影离场（A类）

- **景别：** 全景，`[Character_Main]` 虚焦前景，背景实焦。人物全身镜头（Full Shot / LS），根据环境人物位于居中或镜头一侧。
- **内容：** `[Character_Main]` 背对镜头走向 `[Environment_Ref]` 场景纵深，背景环境元素（路牌/建筑/光源）保持实焦
- **运动：** 人物行进，电影运镜
- **功能：** 开放式结尾，与001首尾呼应

### 013 — 品牌标识帧（条件性 · 仅当提供 `[Brand_Input]` 时生成）

- **景别：** 平面图形构图，无透视，无景深
- **内容：** `[Brand_Ref]` 品牌logo居中，背景方案由用户在故事板确认时选择（见 `references/formats/brand-frame.md`）
- **运动：** 静帧，或黑场淡入（Fade in from black）
- **时长：** 3-4秒
- **功能：** 品牌收尾，强化品牌记忆，全片收束
- **条件：** 未提供 `[Brand_Input]` 时自动跳过，不纳入故事板与生成流程

- 类型：ambient cinematic，无歌词
- 情绪弧：开篇舒缓 → 004-005升温 → 006-008平静 → 011-012渐弱

## 输出契约

每个镜头的 prompt 须遵循以下结构：
```
[风格标签] + [主体描述] + [镜头语言] + [光影色彩] + [质感情绪] + [负向提示词]
```

**全片统一风格标签：**
```
cinematic film still, analog photography, 35mm film grain,
editorial fashion photography, natural candid moment
```

**全片统一负向提示词：**
```
no direct eye contact with camera, no advertising pose,
no heavy makeup, no over-smoothed skin, no completely blurred background,
no subtitles, no watermark, no text overlay, no music, no sound effects
```

**光影色彩基准：**
从 `[Environment_Input]` 提取色温与光线方向，转化为 prompt 语言。基准描述：
```
natural side lighting, [环境色温描述], low contrast highlights,
visible skin texture, no harsh flash, no studio lighting
```

详细 prompt 文法、镜头语言关键词与材质还原关键词见 `references/formats/video-prompt-grammar.md`。

**视频生成方式：** 每个镜头时长均在3-5秒，≤15s，用一次视频生成即可拿到完整片段。参考图引用格式：
```
图[1] [Character_Main 正面/侧面元素图]
图[2] [该镜头关键帧图]
```
运动描述规范：
- 静帧：camera static, subtle natural movement only (hair, breath, fabric)
- 推镜：slow imperceptible dolly push in
- 严禁使用 zoom，一律替换为 dolly 或 tracking shot
