
# 013 品牌标识帧生成规范

> 013镜头为条件性镜头，仅在用户提供 `[Brand_Input]` 时生成。背景方案由用户在故事板确认时三选一。

## 方案A · 纯黑

- **背景：** #000000
- **Logo：** 以原色或白色居中呈现，尺寸为画面宽度的30-40%
- **输出：** 静态图像帧，后续在剪辑合成时叠加淡入效果
- **运动：** 静帧，或黑场淡入（Fade in from black）

## 方案B · 品牌色调

- **背景：** 从 `[Brand_Input]` 提取主色调，降低饱和度（S ≤ 20%），作为纯色背景
- **Logo：** 居中，以高对比度色值呈现（通常深色背景配浅logo，或浅色配深logo）
- **生成：** 生成1个版本，若不满意可调整色值重试
- **运动：** 静帧，或黑场淡入

## 方案C · AI创意设计

- **参考：** 以 `[Brand_Input]` 作为直接参考
- **风格标签：** `cinematic, high-end jewelry brand, editorial, minimal, luxury`
- **生成：** 生成3个候选版本供用户选择
- **运动：** 静帧，或黑场淡入

## 通用规格

- **景别：** 平面图形构图，无透视，无景深
- **时长：** 3-4秒
- **功能：** 品牌收尾，强化品牌记忆，全片收束
- **与012衔接：** 渐黑至纯黑（fade to black）1.5秒
- **结尾：** 淡出至黑（fade out）0.8秒

## 条件

未提供 `[Brand_Input]` 时自动跳过，不纳入故事板与生成流程。
