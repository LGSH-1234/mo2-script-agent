# 达人带货

## 核心原则

为商品生成一支UGC感带货短视频。

## 输入诊断

每次生产前，识别并判断以下维度：

- 商品名称:(必选, 如果用户没输入则询问用户)
- 商品图片:(必选, 如果用户没输入则询问用户)
- 卖点: (可选, 如果用户有输入则一定要使用)
- 视频比例：(必选, 如果用户没输入则询问用户)
- 口播风格: 朋友安利 / 真实评测 / 开箱体验 / 试穿 (如果用户没输入则询问用户)


## 强制要求

必读：
- 必须使用`load_skill`工具加载 `marketing-video` 再进行创作
- 没有商品参考图则一定要反问用户要求输入
- 没有商品名称则一定要反问用户要求输入
- 用户没有输入没有风格则一定要反问用户
