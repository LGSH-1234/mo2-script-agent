# 多宫格分镜 / 故事板 Skill（专注分镜图生成）

## 目标

把用户的「多宫格分镜 / 故事板」需求**直接生成为一张高质量的分镜图文件**，而不是只给 prompt 文本。本 skill 必须调用 `sandbox_generate_image` 完成实际生成，交付物是**分镜图图片文件**，prompt 只是中间产物。任何情况下都不能停在"给用户一段 prompt 就结束"。

> 职责边界：本 skill 只做"多宫格分镜图"。视频生成、逐格严格复刻、轨道补全等都不在范围内——若用户需要，明确告知这是能力边界，本 skill 不承接。

## 核心认知

多宫格分镜图的价值在于**用一张图讲清楚一段故事的镜头调度**：顺序、角色关系、动作走向、景别节奏、场景氛围。一张好的分镜图应当满足两个层次：

- **能用**：真的调用工具出了图，画面干净、格数合理。
- **好用（本 skill 的追求）**：画面内无乱码、每格是不同且递进的关键帧、景别有呼吸感、构图撑满、角色跨格一致，整张图连起来是一个能读懂的完整故事段落。

## 目标生成模型

- **图片（分镜图）**：使用 `sandbox_generate_image`，画幅默认 16:9，强调"干净线稿、白底、细黑分格、画面内无文字"。
- 若平台可用工具名称不同，按实际暴露的工具签名调用；工具不可用时，降级为"输出可直接复制的出图 prompt + 明确的手动操作步骤"，并告知用户当前为降级模式。

## 执行流程（触发后严格按此走）

### 第 0 步：理解输入与补齐信息

- 判断用户提供了什么：故事/创意方向、角色图、场景图、风格参考图。这些都是"生成分镜图的素材"。
- 若用户上传的已经是一张多宫格分镜图并要求"优化/重画"，把它作为构图与剧情参考。
- 缺信息时按"信息兜底"用合理默认补齐，不要输出带 `[……]` 占位符的空泛 prompt。
- 边界提醒：若用户要求"生成视频"或"逐格严格复刻"，说明本 skill 只产出分镜图、不做视频与严格对齐。

### 第 1 步：先列 shot list（决定成败的一步）

在对话里逐格写"景别 + 动作 + 与上一格的差异"，并自查：

- 各格互不重复、剧情连续递进（效果层铁律 2）。
- 景别有节奏（见"镜头语言与叙事节奏"），不是全程同一景别。
- 整体符合一个叙事结构（建置 → 冲突/发展 → 高潮 → 收束）。

确认 shot list 合格后，再进入出图。

### 第 2 步：生成分镜图

1. 依据"分镜图设计原则""镜头语言与叙事节奏""出图 Prompt 结构"组织 prompt，**务必带上"画面内无文字 / 撑满格子"约束**。
2. **调用 `sandbox_generate_image`** 生成分镜图，保存到工作目录。
3. **生成后自检**（效果层铁律 4）：检查画面内文字/乱码、重复格、空白格、角色一致性、景别节奏；不合格自动改 prompt 重生成（最多 2 次）。
4. 把合格分镜图返回给用户。

### 第 3 步：交付与迭代

- 明确列出产物文件（分镜图路径）。
- 简述格数、布局、风格、故事线。
- 主动给出 1-2 个可迭代方向（如某格景别、整体叙事节奏、风格强度、角色特征强化）。

## 信息兜底（避免产出空泛占位符）

生成前若缺少关键信息，**先用合理默认补齐**：

- 缺故事：根据用户给的只言片语或参考图，自动补一个 1 句话故事梗概，并告诉用户"已按此设定生成，可修改"。
- 缺人物设定：无明确指定或素材参考时，默认使用欧美 / 拉美人种长相，五官符合当地自然审美，避免刻板模板。
- 缺格数：默认 12 格。
- 缺风格：默认黑白简约线稿 / 火柴人预可视化。
- 缺布局：默认按格数取整齐排布（如 12 格用 4列3行，9 格用 3列3行）。

## 效果层铁律（决定"好用"而非"能用"，最高优先级）

以下四条来自真实成品复盘，是分镜图质量崩坏的主因，任何时候不得违反：

1. **禁止画面内任何文字（消除乱码，第一铁律）**
   图像模型在小字上必然产出乱码（如 `TREDIUM`、`odd ЫЫal`、重复编号），严重拉低成品观感与可用性。因此：**分镜图内不画任何标题、镜头编号、图例、颜色标注文字、字幕**。镜头功能说明只在对话里以文字清单给用户，不写进图。出图 prompt 必须显式写明 `no text, no captions, no labels, no numbers, no legend inside the image`。

2. **每格必须是唯一且递进的关键帧（消除重复）**
   出图前**先在对话里列一份 shot list**，确认 N 格互不重复、剧情连续递进后，再逐格写进出图 prompt。禁止出现两格同动作（如连续骑车）、禁止镜头编号重复。

3. **画面撑满每格，统一版式（消除空格浪费）**
   每格构图必须撑满整个格子，禁止格内大片留白或空白说明区。所有格统一边距、统一分格线粗细。出图 prompt 写明 `each panel fully filled edge to edge, uniform margins, no empty caption area`。

4. **生成后自检 → 不合格自动重生成（质量闭环）**
   分镜图生成后，先自查：① 画面内是否有文字/乱码？② 是否有重复或空白格？③ 角色一致性（服装/道具/发型）是否稳定？④ 景别是否有节奏？任一不通过，**自动调整 prompt 并重新生成一次**，最多重试 2 次，仍不达标则如实告知用户并给出建议。

## 镜头语言与叙事节奏（把"分镜"做专业的关键）

一张好分镜图不是"N 个不同画面"的堆砌，而是"一段会讲故事的镜头序列"：

1. **叙事结构**：整组镜头应有起承转合。常用节奏为 建置（交代人物/环境）→ 发展（推进动作/制造悬念）→ 高潮（冲突/关键动作）→ 收束（结果/情绪落点）。12 格约可分配为 3/4/3/2。
2. **景别呼吸感**：远景（交代空间）、全景（交代人物全身动作）、中景（交代交互）、近景/特写（放大情绪与关键细节）交替使用，避免全程同一景别造成呆板。开场多用大景别建置，关键情绪/动作用特写强调。
3. **视线与运动方向连贯**：人物朝向、运动方向、进出画面方向在相邻格之间保持逻辑一致，让读者一眼读懂顺序。
4. **动作优先**：动作戏每格都应有可见运动、身体动量或镜头动势，不要从静态站姿或冗长介绍开始。
5. **构图多样**：善用低角度、俯视、过肩、环绕、长焦压缩、宽阔负空间等，让每格有视觉张力，但不喧宾夺主。

## 分镜图设计原则

1. **格数控制**：优先 8 / 9 / 12 格，通常不超过 15 格。避免 18 格及以上（易导致静止、顺序错乱、模型受限）。格数越少越容易保证每格干净、唯一、撑满。
2. **画风简约**：线稿、火柴人、简约铅笔草图、黑白钢笔线稿、预可视化草图。避免脏乱、过度锐化、杂乱 AI 直出质感。
3. **画面干净**：白底、清晰分格、细黑边框、无水印、无 logo、无字幕、无画面内文字（见效果层铁律 1）。
4. **一致性锚点**：在 prompt 中固定角色的关键识别特征（服装颜色/配饰/发型/道具），要求跨格保持一致，避免时有时无。
5. **标注系统默认关闭**：默认**不使用**任何颜色箭头/图例标注（它们会引入画面内文字与乱码）。仅当用户明确要求专业标注版且能接受乱码风险时，才启用红=动作/蓝=运镜/绿=构图/橙=光线/紫=情绪/黄=VFX，并单独说明。

## 画风选择参考

- **黑白钢笔/铅笔精细线稿**：适合剧情向、氛围向题材（修仙、悬疑、都市），细腻、有质感、高级。
- **火柴人/极简线条预可视化**：适合动作戏、快速排布，强调动量与轮廓可读性，轻量、动态、未完成感。
- **概念分镜草图**：介于两者之间，适合广告/短片提案，重在讲清调度而非细节。
- 默认给黑白简约线稿；根据题材在对话里说明选择理由，让产出更有设计感而非千篇一律。

## 出图 Prompt 结构（第 2 步用）

```text
使用参考素材：[列出角色图/场景图/风格图及其指代关系；无则省略]
创建 [8/9/12/15] 格多宫格电影分镜故事板，[布局，如 4列3行 / 3列3行]，16:9，每格为独立完整镜头画面，每格构图撑满整个格子。

主题与故事：……

叙事结构：建置 → 发展 → 高潮 → 收束（按实际故事编排）。

画面风格：[黑白线稿 / 简约铅笔草图 / 火柴人预可视化 / 概念分镜]，统一角色、统一世界观、统一美术风格，白底、细黑线分隔。

角色一致性锚点：[固定服装颜色/配饰/发型/关键道具]，跨格保持一致。

镜头设计（逐格，来自已确认的 shot list，互不重复、剧情递进、景别有节奏）：
1. [景别] …… 2. [景别] …… 3. [景别] …… （逐格写清动作、景别与差异）

关键约束（务必包含）：
- no text, no captions, no labels, no numbers, no legend anywhere inside the image（画面内绝对无任何文字）
- each panel fully filled edge to edge, uniform margins, no empty caption area（撑满、统一版式、无空白区）
- clean white background, thin black panel borders, no watermark, no logo
- not overly sharpened, no messy AI texture, no extra characters, not overcrowded
```

## 质量检查清单（产出前自检）

- 是否理解了输入并补齐了缺失信息（无 `[……]` 占位符残留）？
- 是否先列了 shot list 并确认各格唯一、递进？
- 是否**实际调用了 `sandbox_generate_image`** 生成分镜图（而非只给 prompt）？
- **分镜图画面内是否确认无任何文字/乱码/图例？**（效果层铁律 1，最高优先）
- **各格是否互不重复、无空白格、构图撑满？**（效果层铁律 2、3）
- **景别是否有节奏、整组是否构成完整叙事？**（镜头语言与叙事节奏）
- 角色识别特征（服装/道具/发型）是否跨格一致？
- 分镜图是否已过"生成后自检"，不合格是否已重生成？
- 格数是否 ≤ 15、优先 12？
- 是否明确列出了交付文件并给出迭代方向？
