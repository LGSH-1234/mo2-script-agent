
# 多宫格分镜 Prompt 模板库（专注出图）

> 说明：本 skill 的交付物是**一张多宫格分镜图文件**。以下模板用于组织传给 `sandbox_generate_image` 的 prompt，模型调用后需把图片产物返回给用户，而不是只贴 prompt。本 skill 不生成视频。
>
> ⚠️ 效果层铁律（务必先读 SKILL.md 对应章节）：① 分镜图**画面内绝对不写任何文字/编号/图例**（会出乱码）；② 出图前先列 shot list，保证每格唯一、递进；③ 每格构图撑满、统一版式；④ 生成后自检，不合格自动重生成。以下模板已按此更新，历史"图例/标注文字"写法已废弃。

## 一、出图 Prompt 模板（传给 sandbox_generate_image）

### 模板 1：线稿剧情故事板（氛围向）

```text
使用角色参考图[你的人物图]。
创建12格多宫格电影分镜故事板，4列3行整齐排布，16:9，黑白精细钢笔素描线稿，写实古代修仙题材，统一美术画风、统一人物角色、统一场景世界观，每格为独立完整镜头且构图撑满整个格子。

叙事结构：建置（超远景交代世界）→ 发展（研究地图、起身启程、赶路）→ 高潮（抉择/关键动作）→ 收束（倾斜构图情绪落点）。

角色一致性锚点：固定服装/发带/佩剑等关键识别特征，跨格保持一致。

镜头设计（逐格，互不重复、剧情递进、景别有节奏）：超远景建立世界 → 中景研究地图 → 物件特写 → 侧脸思考 → 起身启程（全景）→ 长焦远景赶路 → 低角度仰拍 → 快速转头扫镜（近景）→ 高空顶视 → 环境环绕 → 抉择特写 → 倾斜构图收尾。（按实际故事替换）

关键约束（务必包含）：
- no text, no captions, no labels, no numbers, no legend anywhere inside the image（画面内绝对无任何文字）
- each panel fully filled edge to edge, uniform margins, no empty caption area（撑满、统一版式）
- clean white background, thin black panel borders, no watermark, no logo
- 纯线稿无上色，细腻素描排线，电影级构图；not overly sharpened, no messy AI texture, no extra characters, not overcrowded
```

### 模板 2：火柴人动作故事板（动作向）

```text
创建以极端身体动作为重点的舞剑修炼故事板。使用参考图像作为角色和场景依据：图1是一位擅长舞剑的少年侠客，图2是世外桃源场景参考。

16:9，12个电影风格面板，每格构图撑满。仅使用黑白：粗糙简约铅笔线条、最小细节、快速手势能量、简单解剖结构、强烈轮廓可读性。保持画面轻量、动态、未完成，像早期打斗预可视化。

直接从动作开始，不要以平静站姿或缓慢介绍开始。

角色一致性锚点：固定少年的服装/发型/长剑造型，跨格一致。

逐格动作（互不重复、连续递进、景别有节奏）：手腕反转剑划圆弧（中景）→ 眼神一凛踏步（近景）→ 向前突刺（全景）→ 提气纵身 → 空中旋转 → 单手握剑切枝（特写）→ 下坠 → 稳稳落地重心下沉（全景）→ 剑锋平举 → 缓缓站直 → 反手藏剑 → 回望镜头（近景）。

镜头语言：手持能量、鞭抽平移、环绕、头顶镜头、侧面轮廓、侵略性特写、长焦压缩、极端低角度、宽阔负空间、强烈视差。

关键约束（务必包含）：
- no text, no captions, no labels, no numbers, no legend anywhere inside the image
- each panel fully filled edge to edge, uniform margins, no empty caption area
- clean white background, thin black borders, no watermark, no logo, no extra characters, not overcrowded
```

### 模板 3：概念分镜简写（提案向）

```text
创建一张多宫格电影分镜故事板，[格数/布局]，16:9，[画风]。按一个完整连贯的故事顺序编排镜头，有起承转合；每格是不同且递进的关键帧，景别在远/全/中/近之间有节奏地变化；角色、场景、美术风格跨格统一。

关键约束：画面内绝对无任何文字/编号/图例；每格构图撑满、统一版式、无空白区；白底细黑分格、无水印无 logo、无额外角色、不过度拥挤、不脏乱锐化。
```

## 二、端到端出图示例（本 skill 的标准跑法）

用户输入："帮我做一个少年侠客舞剑的分镜。"

1. **理解输入**：仅有创意方向、无参考图 → 告知用户"将生成一张 12 格线稿分镜图"。
2. **补齐**：无人物设定，默认拉美/欧美长相少年；默认 12 格、黑白火柴人线稿、4列3行。
3. **列 shot list**：在对话里逐格写"景别 + 动作 + 差异"，自查互不重复、剧情递进、景别有节奏（建置→发展→高潮→收束）。
4. **出图**：用「模板 2」组织 prompt，务必带上"画面内无文字/撑满格子"约束，调用 `sandbox_generate_image` 生成分镜图并保存。
5. **生成后自检**：检查乱码/重复/空白/一致性/景别节奏；不合格自动改 prompt 重生成（最多 2 次）。
6. **交付**：列出分镜图文件，简述格数、布局、风格、故事线，给出 1-2 个迭代方向（如某格景别、整体节奏、角色特征强化）。

## 降级模式

若当前环境未暴露 `sandbox_generate_image`：明确告知用户进入降级模式，输出可直接复制的出图 prompt，并给出"去何处生成、按什么参数操作"的手动步骤。
