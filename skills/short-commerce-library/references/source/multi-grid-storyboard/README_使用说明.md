
# 多宫格分镜 Skill · 简介与使用说明

## 一句话简介

「多宫格分镜」是一个**多宫格分镜图生成器**：你给一个故事创意或一组参考素材，它直接生成一张干净、专业、会讲故事的多宫格线稿分镜图。交付的是**分镜图图片文件**，而不是一段让你自己去别处生成的 prompt。本 skill 专注出图，不生成视频。

## 它能做什么

- 🎬 **创意直出**：只给故事/脚本/方向，自动出一张「12 格线稿分镜图」。
- 🖼️ **参考素材融合**：给角色图/场景图/风格图，锁定识别特征生成一致的分镜图。
- 🧹 **画面干净**：分镜图内不写任何文字，杜绝乱码；每格唯一、递进、撑满，无重复无空格。
- 🎞️ **会讲故事**：镜头按起承转合编排，景别有远/全/中/近的呼吸感，不是画面堆砌。
- 🔁 **自动质检**：出图后自查乱码/重复/空格/角色一致性/景别节奏，不合格自动重生成。

## 它不做什么

- ❌ 不生成**视频**。本 skill 只产出分镜图；出片请用下游的视频能力。
- ❌ 不做**逐格严格复刻 / 轨道补全**。多宫格是"参考级"分镜表达。

## 怎么用（模拟用户测试步骤）

1. 直接说需求，例如："帮我做一个外卖员发现神秘发光包裹的分镜，欧美都市风，12 格。"
2. Skill 会先给你一份 **shot list**（逐格文字清单）确认剧情不重复、景别有节奏。
3. 生成**分镜图**并交付图片文件。
4. 如需调整，告诉它改某格景别、整体节奏或风格强度即可迭代。

## 测试时重点验收这几点

- 分镜图**画面里有没有任何文字/乱码**？（应完全没有）
- 各格是否**各不相同、剧情连贯**，有没有重复镜头或空白格？
- 镜头**景别是否有节奏**（远/全/中/近交替），整组连起来是不是一个完整故事？
- 角色的服装/发型/道具**跨格是否一致**？
- 是否真的**产出了图片文件**，而不是只给你一段 prompt？

## 建议的测试话术（可直接复制）

- "帮我做一个少年侠客在竹林舞剑的分镜，黑白火柴人线稿，12 格。"
- "我有一张角色图（已上传），做一个都市悬疑短片的 9 格分镜。"
- "做个宠物咖啡馆日常的温馨分镜，人物用拉美长相，概念草图风格。"
- （压力测试）"顺便把它做成视频。" → 观察它是否会正确提示"本 skill 只出分镜图、不生成视频"。
