## 小红书文案规范

### 结构

```
【标题】（带1-2个emoji，不过度）
正文第一段：探店开场白，交代人物身份感和美食主题（2-3句）
正文第二段：环境/氛围描述（2-3句）
正文第三段：菜品逐一推荐+口感描述（每道菜1-2句，含具体感官词）
正文第四段：价格/适合人群/小贴士（1-2句）
结尾互动句：引导评论或收藏

标签：5-8个，含以下类型——
  美食品类标签：#火锅 #烧烤 #日料 等
  探店标签：#美食探店 #探店日常 #本地美食
  地点标签：#城市名美食 #商圈名
  风格标签：#烟火气探店 / #精致探店 / #性价比美食
```

### 写作要求

- 总字数200-300字，分段落，不堆砌
- 不使用极限词（最好、第一、天花板等）
- 菜品描述用具体感官词替代空泛赞美
- 语气自然真实，像跟朋友推荐，不像写广告
- 避雷点客观描述，不恶意抹黑
- 未填写店铺名时用「本地人气小店」，未填写地址时用「本地热门商圈」

### 示例

```
终于来打卡这家藏在巷子里的老火锅🔥

门头看着不起眼，走进去烟火气拉满。老板自己炒的锅底，牛油味很正，坐下来就能闻到辣香。

必点三样：
🥩嫩牛肉：切得厚实，涮15秒刚好，肉质嫩滑带点嚼劲，蘸香油碟一口满足
🫀鲜毛肚：七上八下烫到微微卷起，脆嫩爽口，咬下去咯吱响
🥬鸭血：冷锅下进去煮透，滑嫩入味，吸满汤汁

人均大概90左右，适合三五朋友聚餐。建议避开饭点去，不然要排队。

你们还有什么宝藏火锅店推荐吗？评论区聊聊👇

#火锅 #美食探店 #本地美食 #烟火气探店 #火锅控 #探店日常 #宝藏小店
```

## 评论区预埋问答规范

### 数量与结构

3-5组问答，模拟真实评论互动。每组包含一个用户评论和一个博主回复。

### 常见问题类型

| 类型 | 示例问题 | 回答方向 |
|---|---|---|
| 地址问询 | 地址在哪？有导航吗？ | 给出商圈/街道大致位置，引导私信或主页 |
| 价格确认 | 人均多少？两个人去够吗？ | 给出人均范围，推荐适合人数 |
| 菜品追问 | 那个XX菜叫什么？ | 回答菜品名，附简短口感描述 |
| 排队情况 | 周末去要排队吗？ | 给出排队建议时段 |
| 值不值 | 值得专门去一趟吗？ | 客观评价，适合什么人群去 |
| 对比 | 和XX家比怎么样？ | 不拉踩，各有特色 |
| 避雷追问 | 有什么不推荐的吗？ | 客观描述口味特点，不说「难吃」 |

### 示例

```
Q: 地址在哪呀？周末去会不会排队
A: 在XX商圈附近，周末饭点去大概率要排队，建议11点半前到或者下午2点后去错峰

Q: 两个人去点这些够吗？
A: 三道菜加个素菜拼盘两个人完全够，人均90左右吃得挺饱

Q: 不能吃辣去能行吗
A: 可以点番茄锅底或者菌汤锅底，味道一样很鲜，辣锅可以让老板调微辣
```

## BGM推荐规范

### 按风格推荐

**市井接地气**：
- 轻快民谣/吉他弹唱，温暖慵懒调
- 市井风情纯音乐，手风琴或口琴元素
- 适合段落：开场用轻快旋律，试吃段加节奏，结尾回归舒缓

**精致氛围感**：
- lofi chill / jazz hip-hop，低饱和质感
- 法式香颂或bossa nova，文艺慵懒
- 适合段落：全程舒缓统一，试吃段可稍提节奏

**性价比测评**：
- 节奏感电子/轻快pop，快剪辑适配
- 动感背景beat，数据展示段加鼓点
- 适合段落：开场节奏明快，价格展示段最强，结尾收束

### 输出格式

每条推荐包含：风格方向（1句话）+ 适合的节奏段落说明（1-2句话）。推荐1-2个风格方向即可，不指定具体歌曲名。

## 短视频标题规范

### 要求

- 3条备选
- 控制在20字以内
- 包含美食品类关键词
- 符合所选探店风格调性
- 不使用极限词

### 各风格调性参考

**市井接地气**：口语化、有烟火气，如「这家藏在巷子里的火锅，牛油味太正了」
**精致氛围感**：文艺感、注重氛围，如「周末的日式小馆，一个人也很治愈」
**性价比测评**：数据感、强调划算，如「人均30吃到撑，这家粉面店太实在了」

## 封面大字文案规范

### 要求

- 3组备选
- 每组1-2行大字
- 每行控制在8字以内
- 视觉冲击力强，适合竖屏封面
- 不使用极限词

### 各风格调性参考

**市井接地气**：直接有力，如「这家火锅 / 必须排队」
**精致氛围感**：简洁有调性，如「治愈系 / 日式小馆」
**性价比测评**：数字冲击，如「人均30 / 吃到撑了」
