## 通用Prompt结构

每个分镜的画面提示词按以下结构编写：

```
[人物一致性描述前置] + [场景描述] + [菜品/动作描述] + [镜头运镜] + [光线色调] + [氛围修饰]
```

- 人物一致性描述必须在每个镜头prompt开头完整写出，不省略、不缩写
- 用 @图片N 引用用户上传的人物照片
- 正向措辞，描述「要什么」而非「不要什么」
- 菜品描述必须包含具体感官词（热气、油光、色泽、质地）
- 避免抽象情绪词，用具体画面元素传达氛围

## 市井接地气路线

**视觉关键词**：手持纪实、暖黄自然光、烟火气、轻微胶片颗粒、街边小店、真实食客背景

**光线**：暖黄色自然光为主，店内灯光杂但不刻意修饰，窗边自然光透入

**色调**：暖色调，略高饱和度，轻微胶片颗粒感，不磨皮不滤镜

**运镜**：手持微晃跟拍，快速横移，偶尔失焦再对焦，纪实感强

**prompt句式示例**：
```
@图片1所示人物（圆脸、短发、30岁左右男性、穿白色T恤和牛仔裤、中等身材）站在一家老旧火锅店门口，手持镜头微微晃动，暖黄色街灯自然光，门头招牌泛旧带烟火气，轻微胶片颗粒质感，画面真实纪实风格
```

## 精致氛围感路线

**视觉关键词**：柔光浅景深、低饱和色调、干净摆盘、精致桌面、打卡美感

**光线**：柔和侧光或窗边漫射光，浅景深虚化背景，光线均匀细腻

**色调**：低饱和度，偏冷淡风或暖灰调，色彩干净统一

**运镜**：稳定慢速推拉，横移平滑，特写镜头浅景深虚化，偶用俯拍

**prompt句式示例**：
```
@图片1所示人物（鹅蛋脸、长发、25岁左右女性、穿米色针织衫、纤细身材）坐在日式吧台前，柔光侧照浅景深虚化背景，低饱和色调，面前摆着精致刺身拼盘，干净木质桌面，画面安静有质感
```

## 性价比测评路线

**视觉关键词**：分量展示、价格标签露出、对比镜头、快节奏剪辑、数据感

**光线**：明亮均匀，店内灯光清晰，确保菜品和价格牌都清楚可见

**色调**：正常饱和度，色彩还原度高，画面干净利落

**运镜**：快速切换，固定镜头拍菜品全景展示分量，近景拍价格牌，对比切换快

**prompt句式示例**：
```
@图片1所示人物（方脸、寸头、28岁左右男性、穿黑色卫衣、健壮身材）站在大排档桌前，明亮灯光，桌上摆满菜品分量充足，镜头固定展示全景，旁边有手写价格牌可见，画面清晰利落快节奏感
```

## 时长Beat规划

### 15秒（4-5个镜头）

| Beat | 时间 | 内容 | 镜头数 |
|---|---|---|---|
| Hook | 0-3s | 强钩子：最诱人的菜品特写或人物夸张试吃反应 | 1 |
| 展示 | 3-8s | 快速展示2-3道代表菜品 | 1-2 |
| 试吃 | 8-12s | 人物试吃+真实表情 | 1 |
| 推荐 | 12-15s | 人物对镜头简短推荐+店铺信息 | 1 |

### 30秒（7-9个镜头）

| Beat | 时间 | 内容 | 镜头数 |
|---|---|---|---|
| 开场 | 0-4s | 门头/店铺外观+人物到达 | 1 |
| 环境 | 4-8s | 进店落座，环境展示 | 1-2 |
| 菜品 | 8-16s | 2-3道菜品特写+上桌 | 2-3 |
| 试吃 | 16-24s | 人物试吃每道菜+表情反应 | 2 |
| 评价 | 24-30s | 人物对镜头总结评价+推荐 | 1 |

### 60秒（12-15个镜头）

| Beat | 时间 | 内容 | 镜头数 |
|---|---|---|---|
| 开场 | 0-5s | 门头+人物到达介绍 | 1 |
| 环境 | 5-12s | 进店、环境、落座、菜单 | 2 |
| 菜品展示 | 12-25s | 3道代表菜品逐一上桌特写 | 3 |
| 试吃 | 25-40s | 每道菜试吃+人物反应+口感描述 | 3 |
| 互动 | 40-50s | 人物与服务员互动或额外细节 | 1-2 |
| 总结 | 50-60s | 价格汇总+适合人群+推荐总结 | 1-2 |

## 镜头类型库

| 镜头类型 | 画面描述 | 适用风格 |
|---|---|---|
| 门头介绍 | 人物站在店门口，中景，展示招牌和门面 | 全部 |
| 进店落座 | 人物走入店内或坐下，跟拍或固定 | 全部 |
| 环境展示 | 店内环境空镜，广角或横移 | 全部 |
| 菜品上桌 | 菜品端上桌的瞬间，近景，展示热气/色泽 | 全部 |
| 菜品特写 | 菜品微距特写，展示纹理/汤汁/油光 | 全部 |
| 夹菜动作 | 人物夹菜或端菜的手部动作，近景 | 全部 |
| 试吃反应 | 人物吃菜的面部表情，近景特写 | 全部 |
| 评价口播 | 人物对镜头说话，中景 | 全部 |
| 价格展示 | 账单或价格牌特写 | 性价比测评 |
| 对比镜头 | 两道菜品并排对比 | 性价比测评 |
| 氛围空镜 | 店内细节装饰/其他食客虚化背景 | 精致氛围感 |
| 制作过程 | 厨师制作菜品的动作 | 全部 |

## 人物引用规范

1. 每个镜头prompt必须以 `@图片N` 引用用户上传的人物照片开头
2. 紧跟完整人物特征描述（从人物一致性画面提示词中复制）：
   - 脸型轮廓
   - 发型与发色
   - 年龄段与气质
   - 服装风格
   - 体态比例
3. 不得使用「同上」「保持一致」「和之前一样」等隐式引用
4. 不得省略人物描述，每个镜头独立完整
5. 明确写出「保持同一人物形象，不换脸，不变成其他人物」的约束

**正确写法**：
```
@图片1所示人物（圆脸、黑色短发、30岁左右男性、穿白色T恤和牛仔裤、中等身材，保持同一人物形象，不换脸，不变成其他人物）坐在火锅店桌前，手持筷子从红油锅底夹起一片毛肚...
```

**错误写法**：
```
同上人物坐在桌前吃火锅...
人物和之前一样夹起毛肚...
```
