# 美食探店Vlog

## 核心原则

美食探店Vlog的核心是「真实体验感」：观众要觉得这个人是真的去吃了，而不是在念广告。人物的真实反应（眼神、咀嚼、表情变化）比任何文案都有说服力。菜品的感官细节（热气、油光、汤汁沸腾、酥脆断裂声）是让屏幕前的人咽口水的关键。

### 持久引擎（因果链）

**用户上传人物照片 → 人物形象锚定 → 美食主题确定菜品与场景 → 探店风格决定视觉语言 → 时长决定内容密度 → 门头/环境/菜品/试吃/评价按节奏编排 → 每个镜头保持同一人物 → 感官细节填充口感描述 → 全套物料输出**

### 质量测试（可证伪）

如果删掉所有文字文案和口播，只看画面，观众仍然能认出这是同一个人物在不同场景吃同一种美食，并且能被某个镜头勾起食欲——则创意成立。如果人物在不同镜头间看起来像换了人，或菜品画面与口播描述对不上，则不通过。

## 输入诊断

落 prompt 前必须明确或合理假设以下维度：

**必需输入：**
- `userImage`：用户上传的人物照片，是视频主角，所有镜头保持同一人物形象（脸型、发型、年龄气质、服装风格、体态比例）
- `foodTheme`：美食主题/探店对象，决定菜品设计、场景氛围和口感描述方向
- `duration`：视频时长（15s / 30s / 60s），决定内容密度和节奏
- `style`：探店风格（市井接地气 / 精致氛围感 / 性价比测评），决定镜头语言、光线、色调和文案调性

**可选输入（有默认值）：**
- `shopName`：店铺名称，未填写默认「本地人气小店」
- `area`：商圈地址，未填写默认「本地热门商圈」
- `avgPrice`：人均消费，未填写根据美食主题合理默认
- `recommendFood`：必点菜品，未填写根据美食主题自动推荐3道代表菜品
- `avoidFood`：避雷点，未填写则不强行制造避雷内容，只客观描述口味特点或用餐注意事项
- `extraReq`：额外要求，用户自由补充

**风格诊断：**
- 市井接地气：手持纪实镜头，暖黄自然光，烟火气，轻微胶片颗粒，街边小店/老店氛围，真实食客背景
- 精致氛围感：柔光浅景深，低饱和色调，干净摆盘，精致桌面，适合约会/打卡记录
- 性价比测评：突出价格、分量、必点组合、人均计算，强调划算感

**合规敏感点：**
- 禁止使用极限词（最好、第一、全网最强、天花板等）
- 避雷点必须客观克制，不恶意抹黑商家
- 菜品描述调动感官，用具体口感词（香气、汤汁、油润、酥脆、软糯、鲜嫩、酸辣、鲜香）替代空泛赞美
- 不虚构食品安全信息，不暗示治疗效果

## 工作流

### Step 1：接收与解析输入

1. 读取用户上传的人物照片，记录人物特征（脸型、发型、年龄气质、服装风格、体态比例），生成人物一致性画面提示词
2. 解析美食主题，确定该品类的代表菜品、典型场景氛围、核心口感关键词
3. 解析视频时长，确定内容密度：
   - 15秒：强钩子开场 → 快速展示代表菜品 → 人物试吃 → 简短推荐
   - 30秒：环境/门头 → 菜品特写 → 试吃 → 评价完整
   - 60秒：门头环境 → 进店落座 → 菜品逐一展示 → 试吃互动 → 口感细节 → 价格和适合人群总结
4. 解析探店风格，确定视觉语言基调
5. 填充默认值（店铺名称、商圈地址、人均消费、必点菜品、避雷点）

### Step 2：生成人物一致性画面提示词

基于用户上传的人物照片，编写一条贯穿所有镜头的人物描述提示词，包含：
- 脸型轮廓（如圆脸/方脸/瓜子脸/鹅蛋脸）
- 发型与发色
- 年龄段与整体气质
- 服装风格（如休闲T恤牛仔/轻商务/运动风）
- 体态比例（身高体型描述）
- 明确指令：所有镜头中保持同一人物形象，不换脸，不变成其他人物

将此提示词作为每个分镜画面提示词的前置约束。

### Step 3：编写口播稿（带时间轴）

按时长规则编写口播稿，每个时间段标注时间码。口播调性跟随探店风格：
- 市井接地气：口语化、接地气、像跟朋友聊天
- 精致氛围感：文艺感、注重氛围描述、节奏舒缓
- 性价比测评：理性分析、价格敏感、强调性价比数据

口播稿中不使用极限词。菜品描述必须包含具体感官词。

### Step 4：编写分镜脚本

分镜脚本格式：【时间｜人物/画面内容｜镜头运镜｜画面提示词】

按时长规划分镜数量：
- 15秒：4-5个镜头
- 30秒：7-9个镜头
- 60秒：12-15个镜头

每个分镜的画面提示词必须：
1. 以人物一致性提示词为前置约束
2. 包含该镜头的具体动作、场景、菜品、光线、色调
3. 引用用户上传的人物照片（用 @图片N 语法）
4. 符合所选探店风格的视觉语言

镜头类型参考：
- 门头介绍：人物站在店门口，中景，展示招牌和门面
- 进店落座：人物走入店内或坐下，跟拍或固定镜头
- 环境展示：店内环境空镜，广角或横移
- 菜品特写：菜品上桌特写，微距或近景，展示热气/油光/汤汁
- 端菜/夹菜：人物端菜或夹菜的手部动作，近景
- 试吃：人物吃菜的面部表情，近景特写
- 评价：人物对着镜头说话，中景

### Step 5：编写AI视频生成总Prompt

将分镜脚本转化为可直接用于视频生成的完整prompt。每个镜头的prompt包含：
1. 人物一致性描述（前置，每次都写完整人物特征）
2. 场景描述
3. 菜品描述
4. 镜头运镜
5. 光线与色调
6. 画面氛围

时长 ≤15s 的成片用一次视频生成即可拿到完整片段，分镜中的 beat 时间轴描述在同一条 prompt 内表达即可。成片超过 15s 时，拆成若干 ≤15s 片段各自一次生成，再做后处理拼接、配乐、加字幕。

### Step 6：生成全套物料

按输出契约的结构，一次性生成全部9项物料。

### Step 7：静默自检

出稿前内部跑一遍质检（不外显）：
- 人物一致性提示词是否覆盖脸型、发型、年龄、服装、体态五项
- 每个分镜的画面提示词是否引用了人物照片
- 口播稿是否使用了极限词（命中则替换为具体感官描述）
- 菜品描述是否包含具体口感词（香气/汤汁/油润/酥脆/软糯/鲜嫩/酸辣/鲜香等）
- 避雷点是否客观克制（不恶意抹黑）
- 时长与分镜数量是否匹配
- 全套9项物料是否齐全
- 默认值是否正确填充
- 风格视觉语言是否贯穿一致
- 画面提示词是否正向措辞（不堆否定式约束）

### 各项物料规范

**① 短视频标题**：3条备选，控制在20字以内，包含美食品类关键词，符合所选风格调性。不用极限词。

**② 视频封面大字文案**：3组备选，每组1-2行大字，控制在8字以内/行，视觉冲击力强，适合竖屏封面。

**③ 视频口播稿**：带时间轴标注（如 [0-3s] / [3-7s]），口播文字自然口语化，总时长与用户输入时长一致。菜品描述含具体感官词。

**④ 分镜脚本**：每行格式为【时间｜人物/画面内容｜镜头运镜｜画面提示词】，画面提示词中用 @图片N 引用人物照片，并包含完整人物特征描述作为前置约束。

**⑤ AI视频生成总Prompt**：每个分镜对应一段完整prompt，可直接用于视频生成。prompt以中文书写，正向措辞。≤15s的成片用一次生成完成，beat时间轴在同一条prompt内表达；>15s拆成多个≤15s片段分别生成再拼接。

**⑥ 人物一致性画面提示词**：独立一段，描述人物的脸型、发型、年龄气质、服装风格、体态比例，明确指令保持同一人物形象，不换脸，不变成其他人物。所有分镜prompt引用此提示词。

**⑦ BGM推荐**：根据探店风格推荐1-2首BGM风格方向（如「轻快民谣/暖色烟火气」「lofi chill/精致氛围」「节奏感电子/性价比快剪」），并说明适合的节奏段落。

**⑧ 小红书配套文案**：包含标题（带emoji但不过度）、正文（200-300字，分段落，含菜品推荐和体验感受）、标签（5-8个，含美食品类+地点+探店相关标签）。不用极限词。

**⑨ 评论区预埋问答**：3-5组问答，模拟真实评论互动，如「人均多少」「地址在哪」「值得去吗」「排队久吗」等常见问题，回答风格自然真实。
