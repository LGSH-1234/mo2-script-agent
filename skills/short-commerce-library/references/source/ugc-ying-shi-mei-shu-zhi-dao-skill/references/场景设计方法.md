# 场景设计方法

## 1. 功能可信

- 先确定地点为何存在、谁使用、如何进入、停留、工作、撤离和维护。
- 让主要物体具备功能、结构、文化或叙事理由，避免随机撒道具。
- 用人物动作反推通道宽度、视线、遮挡、台阶、停留区和安全边界。

## 2. 空间拓扑

按以下顺序设计：

1. 地形、边界、天际线、主要体块和空洞；
2. 功能区、建筑、平台、道路、楼梯、水路和门槛；
3. 设施群、家具群、设备、车辆和植被；
4. 小型生活证据、维修、磨损和历史痕迹。

明确路线在哪里连接、分支、终止、绕行或从区域后方通过。不要只写“有机”“不规则”“纵深感强”。

## 3. 密度与留白

- 指定密集区、普通区和安静区的位置。
- 让空地承担通行、集散、操作、观看、危险隔离或情绪留白功能。
- 避免所有建筑等距、同高、同朝向，也避免因“太空”而填满每个缝隙。

## 4. 建筑、材质与文化

- 让结构体系、气候、当地材料、施工方式和时代技术相互支持。
- 用修补、加建、所有权、阶层、信仰和使用习惯表现文化，而不是堆装饰符号。
- 老化集中在门槛、接缝、排水、接触面和暴露边缘，大面积材质保持安静。

## 5. 单张画面

- 从剧情动作选择一个主要视觉重点；大场景最多增加一个次级地标。
- 前景负责入口、尺度或合理遮挡；中景负责主要事件与空间关系；背景负责目的地或世界延伸。
- 构图线索应来自真实道路、栏杆、楼梯、建筑和阴影，不为构图添加无功能物件。
- 视觉重点只主导这张图，不得无理由变成整个场景的功能中心。

## 6. 光色

- 设定一个主要光源或主要亮区，并让阴影方向一致。
- 先分几块大明暗，再处理局部灯光。
- 使用环境基础色、事件色和少量点缀色；不要默认套青橙、暗曝光、雾、颗粒和镜头光晕。

## 7. 常见失败与修正

- 路线看不懂：补相对方位、连接、分支和终点。
- 场景像模型展台：把道路和设施从视觉中心轴解耦。
- 元素过多：保留与功能和故事直接相关的设施，降低远处细节。
- 氛围靠压暗：用空间状态、色彩关系和功能停摆表达情绪。
- 废弃等于全屏破损：改用关闭入口、停止设备、局部损坏和缺少维护。
