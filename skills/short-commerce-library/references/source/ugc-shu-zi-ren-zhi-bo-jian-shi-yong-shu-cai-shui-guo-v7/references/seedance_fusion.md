# Seedance 2.0 Fast 视频融合调用指南

本文档说明阶段五如何调用 **Seedance 2.0 Fast** 视频融合模型，以背景视频 + 数字人口播视频为参考，直接生成数字人在场景中介绍水果的一体化融合视频。

**核心原则：不使用抠像/叠加合成技术**。数字人与场景由 AI 模型一次性融合生成，人物完整、不透明、光照与场景自然统一，效果优于传统绿幕抠像叠加。

## 一、模型输入

| 输入项 | 内容 | 来源 |
|-------|------|------|
| 参考视频一 | 背景场景视频（果园/农场等） | 阶段四确认的视频 |
| 参考视频二 | 数字人口播视频（说话+肢体动作） | 步骤 5.2 数字人模型生成 |
| 融合 prompt | 描述数字人在场景中介绍水果的画面 | 见下方模板 |
| 画面比例 | 横屏 16:9 / 竖屏 9:16 | 与阶段四背景视频一致 |
| 目标时长 | 用户在步骤 5.3 确认的最终视频时长 | 步骤 5.3 确认值 |

## 二、融合 Prompt 模板

### 2.1 标准模板（按位置与风格填空）

```
以参考视频一为场景、参考视频二为人物，生成一段数字人直播间介绍视频：
- 一位{数字人风格：3D卡通数字人/写实人物}主播站在{场景描述：果园/农场/水果摊位}中，
  位于画面的{左侧/中间/右侧}，面向镜头声情并茂地介绍手中的{水果名称}
- 人物完整出现在画面中，全身或半身均不得被画面边缘裁剪
- 人物为实体不透明人物，形象、五官、服饰、手持物品与参考视频二完全一致
- 人物口型与参考视频二的口播内容同步，肢体动作自然连贯
- 人物光照方向、色温与场景环境一致，脚下有自然接地阴影，如同真实站在场景中拍摄
- 背景延续参考视频一的取景、光线与氛围，画面稳定无闪烁
- 画面清晰流畅，整体风格统一自然
```

```
- 背景延续参考视频一的果园取景、光线与氛围，画面稳定无闪烁

```

### 2.3 Prompt 必含要素清单

| 要素 | 对应用户需求 | 模板中的表述 |
|------|-------------|-------------|
| 人物位置 | 步骤 5.1 用户选择 | "位于画面的{左侧/中间/右侧}" |
| 完整性 | 不裁剪 | "人物完整出现在画面中，不得被画面边缘裁剪" |
| 不透明 | 不出现透明体 | "人物为实体不透明人物" |
| 一致性 | 形象/口播同步 | "形象、五官、服饰与参考视频二完全一致；口型与口播内容同步" |
| 自然融合 | 融入场景 | "光照方向、色温与场景一致，脚下有自然接地阴影" |
| 场景延续 | 背景保持 | "背景延续参考视频一的取景、光线与氛围" |

## 三、时长控制

### 3.1 时长确认（步骤 5.3 已完成）

- 默认：最终视频时长 = 数字人口播时长（按口播文案字数 ÷ 语速估算，约每分钟 220~260 字）
- 用户可指定时长（30秒/60秒/90秒等），生成时以此为总时长目标

### 3.2 分段生成与拼接

Seedance 2.0 Fast 单次生成有时长上限（以实际接入的模型规格为准）。当目标时长超过单次上限时：

```
1. 计算所需段数 N = ceil(目标时长 / 单段最大时长)
2. 将数字人口播视频按时长均分为 N 段（按句子/语义边界切分，避免半句截断）
3. 每段携带对应口播片段 + 完整背景参考，调用模型生成对应融合片段
4. 片段间口播内容按时间顺序衔接，人物位置、机位、场景描述保持一致，确保无缝
5. 按顺序拼接全部片段，得到总时长达标的最终视频
6. 拼接点若出现轻微跳变，可在拼接处做 0.3~0.5 秒交叉过渡
```

### 3.3 时长不符的处理

| 情况 | 处理方式 |
|------|---------|
| 生成时长 < 用户确认时长 | 询问用户：接受较短版本 / 补充生成延长段落 / 重新生成 |
| 生成时长 > 用户确认时长 | 询问用户：接受较长版本 / 按确认时长裁剪尾部 / 重新生成 |
| 用户指定时长 < 口播时长 | 提示回阶段三精简文案或加快语速后重新生成口播 |

## 五、生成质量自检清单

融合视频生成后、交付用户确认前，逐项自检：

| # | 检查项 | 判定标准 | 不达标处理 |
|---|-------|---------|-----------|
| 1 | **完整性** | 数字人完整入画，头顶/左右/底部无被裁剪 | prompt强化"完整出现、不得裁剪"后重新生成 |
| 2 | **不透明** | 数字人为实体不透明人物，无半透明/透明区域 | prompt强化"实体不透明人物"后重新生成 |
| 3 | **位置正确** | 数字人位于用户选择的左/中/右位置 | 修正prompt中的位置描述后重新生成 |
| 4 | **形象一致** | 五官、服饰、手持物品与口播视频一致 | prompt强化一致性描述；必要时重新生成口播视频 |
| 5 | **口型同步** | 口型与口播内容/音频对齐 | 强调"口型与口播内容同步"后重新生成 |
| 6 | **融合自然** | 光照/色温与场景一致，有接地阴影，无"贴图感" | 强调光照与接地阴影描述后重新生成 |
| 7 | **场景延续** | 背景取景与参考视频一致，无突变闪烁 | 强调背景延续性后重新生成 |
| 8 | **时长达标** | 实际时长与用户确认时长一致（±2秒内） | 按第三节时长不符处理流程执行 |

自检全部通过后，向用户展示视频并**明确告知实际时长**，进入用户确认环节。

## 六、常见问题处理

| 问题 | 解决方案 |
|------|---------|
| 数字人被画面边缘裁剪 | prompt中强化"人物完整出现在画面中，不得被边缘裁剪"；适当缩小人物在画面中的占比描述 |
| 数字人出现半透明/透明 | prompt中强化"实体不透明人物"；重新生成 |
| 人物像"贴"在背景上 | prompt强化"光照方向与场景一致、脚下有自然接地阴影、如同真实站在场景中拍摄" |
| 人物形象与口播视频不一致 | 强化"形象、五官、服饰与参考视频二完全一致"；参考视频质量不佳时先重新生成口播视频 |
| 口型与音频不同步 | 强化"口型与参考视频二口播内容同步"；检查口播视频本身是否音画同步 |
| 分段拼接处跳变 | 统一各段prompt中的人物位置/机位/场景描述；拼接处加0.3~0.5秒交叉过渡 |
| 生成时长与确认时长不符 | 按第三节3.3流程与用户确认处理方式 |
| 背景氛围与参考视频偏差大 | 强化"背景延续参考视频一的取景、光线与氛围"后重新生成 |
