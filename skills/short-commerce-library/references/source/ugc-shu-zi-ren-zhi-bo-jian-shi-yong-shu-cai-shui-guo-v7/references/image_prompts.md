# ImageGen Prompt 模板

本文档提供数字人形象创建阶段调用 ImageGen 工具的 prompt 模板。

数字人形象支持两种风格：
- **3D卡通数字人**：皮克斯/迪士尼风格3D卡通渲染
- **实景人像（写实人物）**：照片级写实风格

## 一、自拍照片转3D卡通数字人（图生图模式）

当用户上传自拍照片并选择"3D卡通数字人"风格时，使用 image-to-image 模式。

### Prompt 模板

```
将这张人物照片转换为3D卡通风格数字人形象。要求：
- 保留人物的五官特征和脸型轮廓
- 转换为Q版3D卡通渲染风格（类似皮克斯/迪士尼3D动画角色）
- 皮肤质感细腻光滑，大眼睛，柔和的面部线条
- 穿着适合直播卖水果的休闲服饰（围裙或休闲T恤）
- 背景为纯白色或浅色，突出人物主体
- 人物面向正前方，表情亲切微笑
- 半身像构图，从胸部以上
```

### 调用示例

```
工具：ImageGen
模式：image-to-image
prompt：[上述模板]
输入图片：用户上传的自拍照片路径
```

## 二、自拍照片转写实人像（图生图模式）

```

- 照片级写实渲染，皮肤纹理自然真实，细节丰富
- 光影自然，人物立体感强
- 穿着适合直播卖水果的休闲服饰（围裙或休闲T恤）
- 背景为纯白色或浅色，突出人物主体
- 人物面向正前方，表情亲切微笑
- 半身像构图，从胸部以上
- 整体形象专业、干净、有亲和力
```

### 调用示例

```
工具：ImageGen
模式：image-to-image
prompt：[上述模板]
输入图片：用户上传的自拍照片路径
```

## 五、自定义数字人重新生成（文生图或图生图模式）

当用户要求自定义外形时，根据用户输入的自定义参数生成。自定义时保持用户当前所选风格（3D卡通或写实），用户也可要求切换风格。

## 六、ImageGen 调用注意事项

1. **背景要求**：所有数字人形象图片必须使用纯白色或浅色背景，突出人物主体，便于数字人模型识别与驱动
2. **构图要求**：半身像（胸部以上），面向正前方，确保五官清晰可见
3. **风格统一**：同一用户的数字人形象在自定义调整时保持风格一致（3D卡通或写实），除非用户明确要求切换风格
4. **表情要求**：微笑表情，适合直播场景
5. **保存路径**：生成后记录图片文件路径，后续合成阶段需要使用
6. **写实风格注意**：写实人像需特别注意皮肤纹理、光影的自然度，避免恐怖谷效应
