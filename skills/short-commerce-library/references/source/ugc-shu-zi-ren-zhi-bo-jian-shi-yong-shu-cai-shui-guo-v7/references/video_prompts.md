# VideoGen Prompt 模板

本文档提供直播背景视频生成阶段调用 VideoGen 工具的 prompt 模板。

## 一、文生视频（无用户素材时生成水果场景背景）

当用户没有上传素材时，根据水果种类生成15秒的水果农场/果园场景背景视频。

### 通用水果场景 Prompt 模板

```
{水果种类}果园/农场实景视频，阳光明媚，{水果特征描述}，
镜头缓缓移动展示果园全景，新鲜的{水果名称}挂在枝头，
绿叶衬托，果实饱满诱人，自然光拍摄，高清画质，真实感强，
适合直播背景使用，无文字水印。
```

## 二、图生视频（用户上传图片时）

当用户上传图片作为直播背景时，将图片转换为15秒动态视频。

### Prompt 模板

```
将这张{水果名称}场景图片转换为动态视频，镜头缓缓推进/平移，
画面保持稳定流畅，光影自然变化，营造直播氛围感。
```

### 调用方式

```
工具：VideoGen
模式：image-to-video
prompt：[上述模板]
输入图片：用户上传的图片路径
时长：15秒
尺寸：根据用户选择的横屏/竖屏
```

## 三、用户上传短视频处理

当用户上传短视频（30秒以内）时：

1. 如果视频时长 ≤ 15秒：直接作为背景使用，后续合成时循环播放
2. 如果视频时长 > 15秒且 ≤ 30秒：截取前15秒作为背景
3. 如果需要风格化处理：调用 VideoGen 进行风格转换

### 风格化 Prompt 模板（可选）

```
将这段视频转换为更加明亮鲜艳的风格，增加饱和度和暖色调，
使其更适合水果直播场景，保持画面稳定流畅。
```

## 四、背景视频修改建议处理

当用户对生成的背景视频不满意时，根据用户反馈调整 prompt：

| 用户反馈 | prompt 调整 |
|---------|------------|
| "场景太暗了" | 增加"明亮阳光照射，高亮度" |
| "想要更近的特写" | 改为"镜头特写水果细节，展示果实质感" |
| "加入采摘场景" | 加入"果农正在采摘水果的画面" |
| "换个角度" | 改为"俯拍/仰拍/平拍视角" |
| "加入水流/溪水" | 加入"旁边有清澈溪水流过" |
| "更真实一些" | 强调"纪录片风格，真实拍摄" |
| "加入阳光光晕" | 加入"阳光透过树叶形成光晕效果" |

## 五、注意事项

1. **无文字水印**：所有视频生成 prompt 必须包含"无文字水印"要求，避免背景视频出现干扰文字
2. **循环友好**：视频开头和结尾画面应尽量接近，便于循环播放时过渡自然
3. **背景简洁**：场景不宜过于复杂，避免分散观众对数字人和水果的注意力
4. **亮度适中**：背景亮度不宜过高，确保数字人叠加后主体突出
5. **保存路径**：生成后记录视频文件路径，后续合成阶段需要使用
