# 数字人模型API对接参考

本文档说明数字人口播视频生成的API对接方式。

## 一、概述

数字人口播视频生成依赖外部数字人平台API。该API接收数字人形象图片和口播文案文本，输出口播视频（数字人朗读文案的说话视频）。

## 二、调用流程

```
输入：
  - 数字人形象图片（阶段一确认的图片路径，支持3D卡通风格或写实人像风格）
  - 口播文案文本（阶段三确认的文案）
  - 口播参数（阶段1.5配置：口音方言、声音性别、语速、肢体动作、手持物品、直播动作）
  - 音色/语调参数（可选）

输出：
  - 数字人口播视频文件（MP4格式）
  - 视频时长信息（用于背景循环计算）
```

> **风格说明**：数字人形象支持3D卡通与写实人像两种风格。卡通形象适合2D/3D动画驱动模式，写实人像适合照片驱动模式。提交时需根据所选风格选择对应的数字人驱动模式，确保口型同步与表情自然。

## 三、平台选择建议

以下为常见的数字人平台，可根据实际对接情况选择：

### 1. 腾讯智影数字人

- 平台：腾讯智影
- 能力：照片驱动数字人口播、多音色支持、表情自然
- 对接：通过API接口提交图片+文本，获取口播视频
- 适用场景：国内直播平台

### 2. 硅基智能数字人

- 平台：硅基智能
- 能力：2D/3D数字人口播、多语言支持、情感表达
- 对接：通过API接口提交形象+文案，获取口播视频

### 3. 其他平台

- 百度智能云数字人
- 阿里云数字人
- 讯飞数字人

## 四、API调用参数参考

### 请求参数示例

```json
{
  "model": "digital-human-v1",
  "input": {
    "avatar_image": "<数字人形象图片路径或URL>",
    "avatar_style": "3d_cartoon | photorealistic",
    "text": "<口播文案文本>",
    "voice_config": {
      "voice_type": "friendly_female",
      "voice_gender": "female | male",
      "voice_accent": "mandarin | cantonese | sichuan | northeast | henan | shaanxi",
      "speed": 1.0,
      "emotion": "enthusiastic"
    },
    "action_config": {
      "gesture_mode": "natural | moderate | static",
      "hold_item": "none | fruit | prop",
      "hold_item_desc": "如：手持芒果、举着车厘子篮",
      "live_action": "none | tasting | peeling | weighing | cutting",
      "live_action_desc": "如：试吃品尝、剥皮展示果肉、称重展示"
    }
  },
  "output": {
    "format": "mp4",
    "resolution": "1080p",
    "background": "transparent"
  }
}
```

> `avatar_style` 参数说明：`3d_cartoon` 为3D卡通驱动模式（用于卡通数字人形象），`photorealistic` 为照片驱动模式（用于写实人像形象）。根据阶段一用户选择的风格传入对应值。
>
> **口播参数说明（对应阶段1.5用户配置）**：
> - `voice_gender`：声音性别，`female` 女声 / `male` 男声（可独立于形象性别指定）
> - `voice_accent`：口音方言，`mandarin` 普通话 / `cantonese` 粤语 / `sichuan` 四川话 / `northeast` 东北话 / `henan` 河南话 / `shaanxi` 陕西话（具体支持范围以平台为准）
> - `speed`：语速，慢速≈0.8、正常≈1.0、快速≈1.2（平台标准语速为基准）
> - `gesture_mode`：肢体动作，`natural` 自然手势 / `moderate` 适度比划 / `static` 静态讲解
> - `hold_item`：手持物品，`none` 不手持 / `fruit` 手持水果 / `prop` 手持道具（配合 `hold_item_desc` 描述具体物品）
> - `live_action`：直播动作，`tasting` 试吃 / `peeling` 剥皮展示 / `weighing` 称重 / `cutting` 切开展示 / `none` 无（配合 `live_action_desc` 描述具体动作）

### 响应示例

## 五、音色/语调选择建议

根据水果类型和直播风格选择合适的音色：

| 水果类型 | 推荐音色 | 推荐语调 |
|---------|---------|---------|
| 苹果/橙子等日常水果 | 亲和女声 | 温和亲切 |
| 芒果/荔枝等热带水果 | 活泼女声 | 热情活力 |
| 车厘子/葡萄等高端水果 | 知性女声 | 专业优雅 |
| 西瓜等夏季水果 | 清爽女声 | 活泼明快 |
| 男性数字人 | 阳光男声 | 热情大方 |

### 口音方言选择建议

| 口音方言 | 适用场景 |
|---------|---------|
| 普通话（mandarin） | 通用场景，全国范围观众，默认推荐 |
| 粤语（cantonese） | 粤港澳大湾区及海外华人观众 |
| 四川话（sichuan） | 川渝地区观众，亲和接地气 |
| 东北话（northeast） | 东北地区观众，幽默感强，直播氛围活跃 |
| 河南话（henan） | 中原地区观众，朴实亲切 |
| 陕西话（shaanxi） | 西北地区观众，特色鲜明 |

> 方言口播时，口播文案可适度加入当地方言特色词汇（如东北话"贼拉甜"、四川话"巴适得板"），增强代入感。方言支持范围以实际数字人平台为准，平台不支持时提示用户并回退普通话。

## 六、口播视频要求

1. **画面质量**：口播视频画面清晰稳定、人物主体完整，作为 Seedance 2.0 Fast 融合生成的"人物参考视频"使用（无需透明背景/绿幕，也无需抠像）
2. **人物位置**：数字人在画面中居中，半身像构图
3. **表情自然**：口型与语音同步，表情自然生动
4. **画质要求**：至少1080p分辨率
5. **时长记录**：获取视频时长信息，用于估算口播时长并与用户确认最终视频时长

## 七、异常处理

| 异常情况 | 处理方式 |
|---------|---------|
| API调用超时 | 重试1次，仍失败则提示用户稍后重试 |
| 图片格式不支持 | 转换为支持的格式后重新提交 |
| 文案过长超限 | 将文案分段生成，后续拼接 |
| 音色不可用 | 使用默认音色并通知用户 |
| API未配置/不可用 | 提示用户："数字人口播服务暂不可用，请确认数字人平台API已正确配置。" |

## 八、注意事项

1. 此文档为参考指南，实际API参数需根据所使用的数字人平台文档进行调整
2. 使用前需确认API密钥已配置、服务可用
3. 数字人视频生成通常需要一定时间（30秒-2分钟），需向用户说明等待
4. 生成的口播视频文件路径需保存，后续调用 Seedance 2.0 Fast 融合生成阶段作为人物参考视频使用
