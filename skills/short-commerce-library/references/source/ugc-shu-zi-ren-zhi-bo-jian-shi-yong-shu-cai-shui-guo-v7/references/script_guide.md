# 口播文案美化指南

本文档提供将用户输入的水果卖点信息美化为直播间口播文案的方法和模板。

## 一、美化原则

### 直播间口播文案特点

1. **口语化**：使用日常口语，避免书面语和生硬的广告词
2. **互动感**：加入互动话术，如"家人们"、"宝宝们"、"亲们"
3. **节奏感**：短句为主，节奏明快，适合朗读
4. **情绪饱满**：热情、兴奋、有感染力
5. **卖点突出**：核心卖点要重复强调
6. **行动引导**：包含明确的购买引导（点击下方链接、限时优惠等）

### 禁止事项

- 不添加虚假宣传内容（如"全网最低价"、"包治百病"等违规词）
- 不添加用户未提供的价格信息（除非用户明确提供）
- 不夸大产品功效

## 二、文案结构模板

### 标准直播口播结构

```
【开场问候】→ 【产品介绍】→ 【卖点讲解】→ 【优惠信息】→ 【行动引导】→ 【收尾】
```

### 详细模板

```
家人们大家好！欢迎来到我们的直播间！{开场互动}

今天给大家带来的是咱们{产地/特色}的{水果名称}！{产品亮点描述}

{卖点1详细讲解}
{卖点2详细讲解}
{卖点3详细讲解}

{发货时间信息}
{优惠活动信息}

数量有限，喜欢的家人抓紧时间下单啦！点击下方链接直接购买，咱们今天下单{发货时间}就发走！

感谢大家的支持，记得关注我们的直播间哦！
```

### 方言口播示例（东北话版）

**用户输入**：水果名称：草莓，产地：丹东，规格：大果，口音：东北话

**美化后口播文案**：

```
（开场）家人们，今天给大家整点好东西——丹东大草莓！
（卖点）这草莓贼拉甜！嘎嘎香！个大得跟小拳头似的，一口咬下去汁水直冒！
```

> 方言文案需与阶段1.5配置的口音一致。使用方言时，适当加入当地方言特色词汇增强代入感（如东北话"贼拉甜"、"嘎嘎香"、四川话"巴适得板"）。

## 四、文案时长估算

口播文案的朗读时长估算（用于背景视频循环计算）：

| 文案字数 | 预估朗读时长 |
|---------|------------|
| 100字以内 | 约20-30秒 |
| 100-200字 | 约30-60秒 |
| 200-300字 | 约60-90秒 |
| 300-500字 | 约90-150秒 |
| 500字以上 | 约150秒以上 |

> 估算依据：直播口播平均语速约200-250字/分钟，数字人朗读可适当放慢至180-200字/分钟以保证清晰度。

## 五、用户修改文案处理

当用户要求修改口播文案时，根据用户反馈类型选择处理方式：

| 用户反馈类型 | 处理方式 |
|------------|---------|
| "更热情一点" | 增加感叹号、互动话术、情绪词 |
| "加入价格XX元" | 在优惠活动部分加入具体价格 |
| "缩短到30秒内" | 精简文案至100字以内，保留核心卖点 |
| "更专业一些" | 减少口语化表达，增加产地、品种等专业信息 |
| "加入产地XX" | 在产品介绍部分加入产地信息 |
| "加入规格/大小等级" | 在卖点讲解部分加入果实规格（如"5J大果"、"单个10斤"） |
| 直接给出修改后的文案 | 直接使用用户修改的版本 |
