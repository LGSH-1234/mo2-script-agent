# 知识图解视频

## 制作要求

制作与验收遵循以下要求：

1. **整条成片的旁白必须来自一次完整讲稿的成功生成。** 全文一次提交，不分句、分镜或分章节生成后拼接。重试或改稿时完整重做并整体替换。全文超出能力时说明限制，由用户选择缩短内容或提供整段配音。
2. **需要字幕时，先有主旁白，再取真实字幕时间。** 优先使用本次配音实际返回的句/词时间戳或这份音频已有的字幕；否则使用可用的听辨能力实测句界，波形和停顿只作定位辅助。字幕时间必须对应真实读词，不能按字数或镜头预算估算。用户明确不要字幕时，走 audio 参考中的无字幕路线，不额外转写。
3. **同一份音频、字幕和镜头时间轴一起交付。** 修改声音后重新取得并核对时间戳；不要混用旧 SRT、旧分镜时间或旧渲染。字幕语言跟随实际口播，用户明确要求翻译字幕时保留原句时间并另存译文。
4. **字幕由验证后的时间轴统一烧录。** HTML/SVG/Canvas 负责图像、标题与对象标注；口播字幕由附带脚本读取同批 `timing.json`，生成 ASS 并在最终合成时烧录。画面工程与字幕合成共用一份时间轴，避免重复绘制字幕。
5. **必要文字在可读时段必须完整可见、互不遮挡。** 标题、说明与标签使用实际加载字体测量宽高，检查运动后的完整字框；文字锚点在屏内不代表整段文字在屏内。先重排、换行或分时显示，不用裁切、叠层或持续缩小字号掩盖问题。
6. **检查最终交付文件，并根据检查结果返修。** 技术检查必须实际覆盖画面执行；抽帧必须覆盖首帧、机制变化和字幕时段。没有运行样本、只有摘要或未看过画面，都不能记录为视觉验收通过。

## 1. 明确视频需求

提取主题、受众、核心问题、时长、语言、画幅及现有素材。只问会改变讲解内容的缺失信息。未指定时默认中文、16:9、1080p、30fps、约 30 秒，讲清一个问题；不要自动扩写成几分钟。明确要求更长时保留用户范围，先确认整篇配音能完成。

读取 [runtime.md](references/runtime.md) 建立任务目录，确认渲染环境；需要新配音时确认 `sandbox_generate_audio` 已加载；需要字幕时先按 [audio.md](references/audio.md#选择字幕时间来源) 检查时间来源。已有整段配音优先复用。

先写完整 `narration.txt`。第一句点明对象和问题，开场画面建立对应情境与主体；允许简短、有意义的入场，不用数秒空背景拖延主题。中段展示必要机制，结尾回答问题并保留关键适用边界。30 秒中文稿可先从约 80–110 字起草，实际时长以生成结果为准，不能靠字数保证。术语、数据和因果关系核实后记录在 `sources.md`，教学简化标“示意”。

## 2. 设计视觉与分镜

**默认以专业科普短片为质量目标，画面要有高级感、美感和完成度。** 用明确的艺术方向、精细主视觉、成熟排版、清楚的空间关系和服务讲解的动作节奏来实现，不把“内容正确、能够播放”当作完成。简约可以成立，但不能粗糙；主体过小、信息堆叠、素材拼贴生硬或全片机械重复时，必须返修。

主动设计丰富、连贯的动效，将主体变化、关键文字、镜头调度和场景衔接一起编排。标题、关键词、数字与结论可随讲解分步出现，并与对应图形联动强调；避免全片主要由静态画面配文字淡入组成。文字动效要留足完整可读的停留时间，具体做法见 [关键文字动效](references/visual-direction.md#关键文字动效)。

读取 [visual-direction.md](references/visual-direction.md)。有参考片时先查看整体和关键动作的前中后帧，提取可执行的字体层级、主体比例、图像质量、材质、光照和运动方式；不要只抄配色。

在 `storyboard.md` 中写清每镜“看什么、发生什么、最后看懂什么”，确定主要对象、构图、初态→变化→结果及与前镜的连接。为镜头和关键事件取稳定 ID，按 [review.md](references/review.md) 为每镜指定一张代表帧：主体和标注已到位、相关字幕在屏，不能自动用场景起点或时间中点代替。复杂机制再选变化前中后帧。让同一主体被放大、拆开、比较或改变状态；运动路径和标注锚点由主体的共同坐标计算，文字框在最终画幅中独立排布。为每镜确定标题与标签的宽度、行数和安全间距，避免最长文案或转场中两组文字共同出现时挤压。

先选适合解释的视觉语言，再精修两张实际尺寸画面：开场主视觉、核心机制最密帧。二维线稿、矢量图解、数据图和写实素材都可达到专业完成度；按所选风格做好轮廓、比例、线宽、字体与层次。需要展示真实外观时寻找高质量现成素材，需要解释内部关系时用清楚的剖面、示意或局部图。每镜选最容易看懂关系的视角，避免把所有解释塞进固定分栏。

构图可以沿用：左右分栏、暗底、大留白都不是问题本身。检查留白是否形成焦点、主体是否有足够信息、视线是否随机制推进。不能只换背景、换版式或增加粒子来补偿主图质量不足。

## 3. 生成完整配音并对齐字幕

读取 [audio.md](references/audio.md)，按其中的时间来源选择执行：

下列为有声字幕路线。用户明确要求无字幕时仍只生成一条完整旁白，按参考中的 `--without-subtitles` 导入和 `--no-subtitles` 合成。

1. 全文一次生成主旁白，保存返回的原始音频路径并实测时长。明确目标时长的容差；未指定容差时按约 ±10% 检查，偏离后先精简或扩展全文并整体重做。在渲染前完成时长核对。
2. 获取与该完整音频匹配的真实短句时间：使用实际返回的 TTS 时间戳、已有字幕，或听辨实测。保存来源；无时间戳时可用轻量波形脚本辅助定位，再听辨确认。总时长不是句级时间，不能按比例切分。
3. 用 `audio_pipeline.py import-master` 通过 `--srt` 和真实 `--timing-source` 导入旁白、已核对的字幕与完整讲稿，检查文本、短句长度、时间范围和音频来源，生成同一批次的 WAV、SRT、timing。
4. 根据真实短句时间重新安排镜头和机制动作。分镜暂定秒数从此不再作为字幕或切场依据。

字幕的切分不是声音的切分。长段时间戳不能按字数伪造成短句时间；处理方法见音频参考。实际口播超出时长时精简全文后一次重做，不截句、不加速压缩；语速自然和解释完整优先于密集塞知识点。

## 4. 制作画面与动画

读取 [composition.md](references/composition.md)，以原生 HTML、SVG、Canvas 及合适的本地素材创作。实现方式服从视觉，不把作品限制成同一套简化几何模板。需要时间控制的实现示例时，再读取该参考中的“示例”；示例的布局、主题和色板不作为新作品的默认艺术方向。

按画面制作参考中的“文字排版”实现可测量的文字：DOM/SVG 读取实际字框；Canvas 文字使用附带 helper 记录绘制位置。渲染前执行逐帧布局检查，修复越界、文字碰撞和裁剪；未覆盖 Canvas 文字不能记录为检查通过。

使用真实音频时间安排动作：口播提到对象时它已可辨认；讲变化时画面正在显示变化；给出结果时结果已稳定。用短语起止而非整段字幕驱动，不让字幕提前泄露下一场解释。

字幕在最终合成时叠加，每条一到两行；图形工程为其保留安全位置，不绘制字幕文本或底条。背景覆盖实际画幅，关键标签避开字幕位置，不常驻预留一条无用途的底部空带。

## 5. 检查与交付

按 [runtime.md](references/runtime.md) 完成全时间范围的运行检查，修复异常后渲染；按 [audio.md](references/audio.md) 烧录字幕与合成主旁白。随后执行 [review.md](references/review.md)：先逐张打开每镜代表帧，分别检查布局、文字、原理画法和风格，记录具体观察；联系图只作全片总览。字幕闪烁、遗漏或时序变动另做字幕专项检查。

- **内容与过程**：关键机制的前中后三帧展示真实状态变化；核对比例、方向、作用位置、连接和结果。数学或几何关系由同一模型计算，并验证一至三个关键约束，不能靠独立动画把结果画成预期样子。
- **视觉完成度**：开场与核心帧达到已选视觉方向；主体细节、字体层级、光照材质和构图有一致性。缩至手机观看尺寸，主旨和关键标签仍可读。
- **同步**：抽查第一句、跨场句、中段和最后一句，同时核对说话内容、字幕起止和画面动作。每个场景至少核对一个短句；仅容器时长相同不能证明同步。
- **音频来源**：只使用一份全文生成的主旁白，禁止将不同 TTS 结果拼接。最终混音使用对应 timing 记录的 WAV。
- **工程**：前后 seek 状态一致；实际尺寸、帧率、时长、编码正确，最终 MP4 完整解码无错误。

检查按“具体时刻—实际观察—问题—修改—同点复查”记录。先修缺字、闪屏、报错、遮挡等硬错误，再优化主体尺度、信息落点与视觉节奏；只重做受影响阶段。文字问题还要复查最密、最靠边和转场共存的状态；仅修正一张代表帧不能证明整个动作已修好。最终文件改变后重新抽帧，不沿用旧截图。静帧确认改动后，再连续播放最终版检查转场、阅读停留和音画配合。只能看图或只能收到媒体文字摘要时，分别保留播放或视觉验收缺口，不用命令成功、自评分或同一时间表代替实际检查。

完成后调用 `present_sandbox_file` 展示实际最终 MP4，仍有后续操作时使用 `interrupt=false`。默认只交成片及简短说明；工程、分镜和字幕留在任务目录，用户需要时再提供。缺配音或真实字幕时明确标为未完成的预览，不能冒充最终有声字幕版。
