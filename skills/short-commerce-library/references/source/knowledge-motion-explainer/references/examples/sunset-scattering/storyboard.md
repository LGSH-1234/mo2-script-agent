
# 日落散射示例

## 创作目标

用同一束光解释“日落时，太阳为什么偏红”。26 秒，1920×1080，30 fps。`index.html` 是原生 HTML + Canvas 的静音视觉示例；`narration.txt` 是完整旁白稿。本例没有生成旁白，也没有附带音频。

本例不绘制口播字幕。镜头时间是人工视觉编排，**不是语音时间戳**。制作有声版本时，先生成完整旁白和真实字幕时间，重新编排镜头，再由统一合成脚本烧录字幕；不能把 26 秒直接用于新音轨。

## 艺术方向

- 主体：同一太阳、光束、固定观察者与地球大气曲面。地球曲面一直保留，入射角变化时直接重算光在壳层中的路径，避免换一张无关联示意图。
- 风格：暖灰宋体大标题、清晰无衬线标签；深墨背景、暖金阳光、灰蓝大气与短波散射。字体、颜色角色贯穿全片。
- 景观：原创程序山脊、暮光、水面反射与轻量颗粒。没有照片截图或第三方视频帧。
- 层级：大标题确定当前问题，右侧主图解释变化，局部标签贴近对象，为最终字幕留出安全位置。颜色与材质服务主题，不靠通用卡片装满画幅。
- 连续性：保留同一观察者与地球轮廓，用低角度光路和淡化的高角度光路比较；改变的是方向与路径长度，而不是随意切换视角。
- 文字坐标：本例按最终 1920×1080 画幅排版，没有相机缩放。对象锚点和几何变化共用模型，标题与局部标签的字框独立安排；派生版本增加相机变换时，只投影锚点，再在最终画幅布局文字，不把字号与整组主体一起放大。

## 分镜安排

| 静音编排时间 | 画面与信息 | 可检查的实际变化 |
| --- | --- | --- |
| 0–5 秒 | 暮色风景与开场问题，首帧已是完成构图 | 同一太阳、远山和反射建立生活直觉 |
| 5–11.6 秒 | 风景进入地球大气示意；观察者固定，太阳由高处变成低角度 | 光线方向连续变化；大气入口与在大气中的线段随几何关系变化 |
| 11.6–20.4 秒 | 保留低角度长路径，短波光沿多个方向散开 | 蓝色粒子离开直达方向；暖色粒子仍沿直达路径前进；光束颜色逐渐变暖 |
| 20.4–26 秒 | 回到同一暮色风景，回答开场问题 | 文字结论与颜色变化对应，保留实际颜色受其他条件影响的说明 |

制作有声版本时，将 `narration.txt` 全文一次提交生成主旁白。

## 文字排版

字体加载完成后测实际字框；以下是本例的设计预算，不是“数字满足就不用看图”的验收替代：

| 文字角色 | 最终画幅中的安排 | 重点复查 |
| --- | --- | --- |
| 主标题与说明 | 左侧距边 120 px；开场/结尾宽 44%，机制段宽 34%；标题和说明分别保持两行，标题行高 1.45 | 最长文案、字体替换后的实际换行、同段行框间距和说明底边 |
| 机制标签 | 指认观察者、地球、大气与两类路径；以绘制时实际字体记录完整字框 | 标签之间以及与主体、引线、散射粒子的关系 |
| 两行散射说明 | 同一说明使用 `scatter-note` 组，两行分别记录 ID | 组内也不得真实重叠；不能把整镜所有文字归为同一组 |
| 顶部章节与底部边界说明 | 左右距边 120 px；字号与位置独立于主体 | 转场前后、最终字幕叠加后的可读性 |

地球曲面可以有意延伸出画幅，文字不能继承“整张 Canvas 允许越界”的豁免。本例 `text()` 使用 `LayoutAudit.fillText` 真实绘制并记录字框；DOM 文字由检查器自动采集。`draw()` 的 `ctx.reset()` 会清空旧画布记录，不另行调用 `beginFrame()`。检查器在每次 seek 前管理采样状态，覆盖正向播放的每个实际输出帧。

文字检查不识别所有主体遮挡。例如低角度路径标签需避开向下散射的粒子，因此标签在路径括号下方略向右排布；仍需人工查看散射过程的前中后帧。改为有声版后，以真实字幕叠加的最终帧继续核对，不能用静音示例的通过结果代替最终成片检查。

## 准备工程

先把本例目录复制到任务工作目录，再准备本地依赖：

```text
project/
  index.html
  vendor/gsap.min.js
  vendor/layout_audit.js
  fonts/title.ttc
  fonts/body.ttc
```

`vendor/gsap.min.js` 使用实际环境已提供或已安装的 GSAP 文件；把本 Skill 的 `references/scripts/layout_audit.js` 复制为 `vendor/layout_audit.js`，在示例脚本前加载。标题字体选择有完整中文字形的宋体/衬线字体，正文字体选择有完整中文字形的无衬线字体。例中的 `.ttc` 是本地路径占位；若环境提供 `.otf`、`.ttf`、`.woff2`，同步改动 HTML 的两个 `@font-face` 路径。确认字体加载成功并实际查看中文关键帧，不依赖系统碰巧存在的字体名称。

本包不附带字体和 GSAP 二进制；从环境资源复制时保留其使用许可。字体职责不绑定具体品牌，项目源文件只引用相对路径。

在准备好的目录中运行：

```bash
hyperframes check --at 0,3,6,9.5,13,17,21.5,25.5 --json
hyperframes snapshot --at 0,3,6,9.5,13,17,21.5,25.5 --output ../frames --describe false
hyperframes render --fps 30 --quality looks --output ../silent-example.mp4
```

这里使用已经解析到的本地 `hyperframes` 命令；只有环境要求时才换成对应的 `npx` 或平台命令。无声成片用于检查画面，不代表已完成有声交付。

在本机项目预览服务已启动后，使用本 Skill 的 `check_composition.mjs --layout-check` 检查完整 26 秒、30 fps 共 780 帧，而不只检查上面的关键时刻。下列路径和端口替换为当前任务的实际值：

```bash
node /path/to/skill/references/scripts/check_composition.mjs \
  --url http://127.0.0.1:3000/ \
  --browser-module /absolute/path/to/puppeteer-core \
  --executable /absolute/path/to/chromium \
  --layout-check --output ../runtime-layout-check.json
```

确认报告中运行与布局采样数量均覆盖 780 帧、Canvas 文字已被实际测量、资源和字体加载成功，并修复所有布局问题，再抽帧。画面按声明尺寸由渲染器呈现；直接缩小浏览器视口打开 HTML 不能代替最终画幅检查。

## 时间控制与渲染

Canvas 画面完全由绝对时间计算；每帧先重置绘制状态，并固定使用适合读回像素的 Canvas 配置，避免历史帧状态残留。GSAP 驱动带 setter 的时间属性，使正向播放、跳时、反向 seek 都重画同一状态；不读取现实时间，不使用未设种子的随机数或 `requestAnimationFrame`。字体就绪后注册一条暂停的时间线，注册名与根 composition ID 一致。

检查开场、入射方向变化的起中终、散射过程的起中终、结尾，以及两次视觉过渡两侧。连续的粒子运动代表方向变化，不是测量或真实粒子轨迹。除浏览器检查外，仍需实际查看完整尺寸帧；自动检查不能判断一幅画面是否达到参考审美。

## 科学原理与示意范围

大气厚度、曲率、光束宽度与太阳距离均为解释而夸张，没有表达比例数值。这里只说明低太阳角度时大气路径变长，短波成分更易离开直达方向，直达光相对偏暖；不表示所有蓝光消失，也不表示所有散射只朝上。太阳并非光源本身突然变红。实际颜色还会受气溶胶、云和观测条件等影响。

- [NASA Earth Observatory：Crepuscular Rays and Light Scattering](https://science.nasa.gov/earth/earth-observatory/crepuscular-rays-and-light-scattering-150090/)：低太阳角度与更长路径，以及短蓝波相对长橙红波更强的散射。
- [NASA：Rayleigh and Mie Scattering](https://acd-ext.gsfc.nasa.gov/anonftp/acd/daac_ozone/Lecture4/Text/Lecture_4/raymie.html)：直达光中的蓝色成分减少与日落颜色。
