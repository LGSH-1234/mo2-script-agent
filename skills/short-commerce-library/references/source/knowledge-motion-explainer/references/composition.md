
# 画面与动画制作

## 选择表现方式

用原生 HTML/CSS 排版，按需要组合本地图像、SVG、Canvas：

- 照片/渲染/插画：建立可信主体，保留高质量边缘、光影和细节；先确定裁切与视角。
- SVG：结构、标注、曲线、矢量主体；可用蒙版、渐变、滤镜及受控路径变换。
- Canvas：连续场景、噪声、粒子、动态曲线或程序景观；每帧从时间和固定输入重算。
- DOM：标题、正文、数字与对象标注；字号、字重和字体角色明确。口播字幕交由最终合成层处理。

可以混用，不能为了适配一种输入格式而降低主体质量或删掉关键过程。全片采用一个确定性时间入口，不播放录屏，不依赖 CSS 自动动画或实时计时器。

## 工程结构要求

```html
<div id="root" data-composition-id="main"
     data-width="1920" data-height="1080" data-fps="30" data-duration="30">
  <div class="background" aria-hidden="true"></div>
  <section class="clip" data-start="0" data-duration="30">
    <!-- 主体与图解；每个需要动画的对象使用稳定 ID -->
  </section>
  <!-- 口播字幕在 FFmpeg 合成阶段叠加，工程中不绘制字幕 -->
</div>
```

`html`、`body` 和 root 都要有真实视口尺寸；body 去 margin，root 相对定位并按设计裁切。背景绝对定位覆盖画布。核对 DOM 实际宽高，不只看 data 属性。Canvas 的 backing width/height 与目标尺寸一致，不用浏览器默认 300×150。

框架管理 clip 显隐；动画只作用于其内部节点。所有引用使用本地相对路径，字体与主素材加载完成后才注册完成的时间线。字体加载失败或图片缺失要修复，不能让默认字体、空图悄悄进入最终渲染。

创建唯一暂停 GSAP timeline，构建后注册到 `window.__timelines["main"]`。实际 composition ID 与注册键一致。不要使用 GSAP 插件而不加载它，也不要依赖 CDN 或其他未验证在线资源。

## 支持任意时间定位的动画

随机 seek 到同一时刻必须得到同一帧。用时间决定位置、形态、数值与对象标签，不靠前一帧累积。

DOM/SVG：初态明确，tween 的起止状态与时间写定；跨场复用对象时保留 ID 和语义角色。连续变换的路径或参数应由当前时间算出，不在 seek 时越加越多节点。

Canvas 可使用示例中的“由属性 setter 调用绘制”的方式，避免只靠 onUpdate 回调：渲染器可能带 suppressed callbacks seek。原理示例：

```javascript
let current = 0;
const clock = {
  get seconds() { return current; },
  set seconds(value) { current = value; draw(value); }
};
const tl = gsap.timeline({paused: true});
tl.fromTo(clock, {seconds: 0},
  {seconds: duration, duration, ease: "none", immediateRender: true});
window.__timelines = window.__timelines || {};
window.__timelines.main = tl;
```

`draw(t)` 每次清空并重画，先画背景，再画远景、主体、关系、标注。固定种子生成粒子初值，轨迹由时间求值。禁止 `Date.now()`、无种子 `Math.random()`、`requestAnimationFrame` 驱动状态或逐帧位置累加。字体、图像未 ready 前不暴露可渲染完成状态。

用当前 HyperFrames 实际抽帧验证，并按 runtime 的逐帧检查器覆盖完整时间范围，捕获抛错和资源失败。首次跳到中段、从结尾倒回、顺序播放应得到同一状态。不能捕获异常后忽略它，也不能让某一帧绘制失败后保留上一帧冒充成功。

共享几何参数与样式变量：部件、运动路径、标尺端点和标签锚点都从同一对象坐标计算。颜色、字体和层级集中定义；插值函数返回合法数值或完整颜色值。先检查数值范围与资源，再开始全片渲染。

机制状态与表现动画分开：先从输入和当前时间计算机制状态，再用它绘制主体、结果和标注。涉及和差、比例、顺序或几何关系时，让结果由同一组输入计算；不能单独对结果做一个看似正确的 tween。位置与透明度的入场缓动可独立设计，所表达的知识关系仍须成立。为核心关系设置少量可验证约束，分别检查变化前、中、后，数值检查与像素审阅互相补充。

## 文字排版

先确定每镜的标题、说明与标签占位，再放置文字。每个文字块有稳定 ID、最大宽度、预计行数和可读时段；使用最长实际文案、最大动态数值及实际字幕行数检验。版式由本片决定，不强制分栏。可从画幅四周各 4% 的文字安全边距、1080p 下独立文字块至少 12 px 的净间距起步，再按字体与画面调整；安全边距以内仍需检查文字互相遮挡。

**测整段文字，不只测定位点。** 字体加载后再获取实际尺寸，计入换行、行高、对齐、字距和描边。Canvas 独用的字体须先用 `document.fonts.load()` 请求实际字体与字重，再等待加载完成；单独等待 `document.fonts.ready` 不能保证尚未使用的字体已经请求。DOM 使用真实布局后的文本行框，SVG 使用变换后的文字边界；Canvas 使用当前字体的 `measureText` 与当前变换计算画布中的字框。不能用字数乘字号或固定猜测宽度代替。多行文本应检查各行及总高度，同一标题内部也不能行距过小而压字。

将主体坐标和文字排版分开：先把主体锚点投影到最终画幅，再选择标签侧向与位置，最后连接引线。标签框需避开当前可见标题、其他标签和字幕区域；靠右时按真实宽度改为右对齐或移到锚点另一侧，不能只把起点限制在画布内。主体可以有意出画，解释文字仍应完整可读；图形的溢出许可不能用于文字。

空间不足时按实际原因调整：移动整个文字块或换侧 → 自然换行并重新测量 → 精简与口播重复的标签 → 将次要标签分时出现或切到局部镜头。移动标签后更新引线，避免为了避碰而失去指向。不能只抬高 `z-index`、加 `overflow:hidden`、遮罩裁字、突然隐藏必要标签或将字号缩小到难读。纯排版返修保留原始语音和已核对的字幕时间；若需重新编排图解动作，仍依附同一真实时间轴。

入场与退场优先在安全范围内完成。检查全文字的移动、缩放与交叉淡化过程，尤其是前后镜文字同时可见的时刻；起点与终点不碰撞，不代表中途没有穿过标题。若使用有意的文字揭示遮罩，必须保留检查器的裁剪记录、准确时段与实际看图证据，说明它只发生在揭示过程，不能记为自动布局检查通过；完整可读时段不能残留裁字。无法实际看图确认时，采用完整字框在安全区内淡入。

### 文字布局测量

DOM/SVG 文字由检查器自动读取。多行或富文本属于同一文字块时，在其共同容器设置 `data-layout-group="标题的稳定ID"`；只对这个文字块使用，不能给整镜或全部标签设同一组。同组只免除文字块间的额外净间距，实际文字框交叉仍需修复。

Canvas 标签通过 [layout_audit.js](scripts/layout_audit.js) 实际绘制并记录测量。将该文件复制为项目的 `vendor/layout_audit.js`，在绘图脚本之前加载：

```html
<script src="./vendor/layout_audit.js"></script>
```

```javascript
// ctx.font / textAlign / textBaseline / transform 使用当前实际绘制值。
// id 在镜头内稳定；不要用随机数或每帧变动的文字内容作为 ID。
LayoutAudit.fillText(ctx, labelText, x, y, {id: "stage-label"});
// 同一多行标签每行独立 ID，共用 group；绘制前已确定合理行距。
LayoutAudit.fillText(ctx, line1, x, y, {id: "note-line-1", group: "note"});
LayoutAudit.fillText(ctx, line2, x, y + lineHeight, {id: "note-line-2", group: "note"});
```

helper 不自动移动、缩小或裁掉文字。保留原来的逐帧清屏与确定性重画方式，不在绘图函数里调用 `LayoutAudit.beginFrame()` 清除检查状态；检查器在 seek 前管理采样。直接调用原生 Canvas 文字方法、遗漏记录或使用无法测量的绘制方式，必须作为覆盖缺口处理。复杂文本若无法可靠测量，改用可测量的 DOM/SVG 覆盖层。

按 [runtime.md](runtime.md) 运行 `--layout-check`，逐帧检查当前可见文字。报告的包围盒碰撞是保守候选，需要看问题时点确认；DOM 文本行框包含字体度量中的留空，旋转文字的外接框也可能包含空角；这类候选需按原图确认。确属字框空区交叉时记录图像证据与判断范围，不能把整类文字排除或宣称自动检查通过。可优先增加合理行距，使版面更易读且通过保守检查。覆盖缺口、非预期的越界/裁字/碰撞及可读时段的文字不完整不能放行；有意揭示仅按前述保留证据的人审方式处置，不修改 helper 阈值或标记掩盖报告。确需调整安全边距或间距时，要根据本片设计与最终帧确认，并保留报告中实际使用的值。

检查结果是几何问题与覆盖范围，不替代最终像素审阅。FFmpeg 后加的口播字幕不在浏览器文本框集合里，需按实际字号、行数和位置为其避让，再检查合成画面；不要留一条空黑带代替设计。

## 统一时间轴

旁白经 [audio.md](audio.md) 导入后，读取本批次 `timing.json`：

- `duration` 决定主旁白长度；
- `captions[].start/end/text` 是经核验的语音短句，保留观察时间，供动作编排参考；`observed_captions` 另存导入字幕的原始文字；
- 场景由连续的短句组覆盖，动作在对应短句内安排；
- 少量无口播开头/收尾按真实需求添加，偏移必须同时应用到音频、字幕和镜头，不能单独平移其中一项。

优先让视频从 0 秒使用主旁白，避免不必要的偏移。镜头边界根据实际语音安排。镜头变化时不能把下一场整段字幕提前显示。

选每镜 `review_at` 时，把动画到位区间与该镜相关字幕的显示区间一起考虑；明确无字幕时只检查画面状态。不要自动取镜头起点或字幕中点。如果关键状态尚未到位、字幕已退场，就调整入场、停留或镜头编排，再选点，不要只挑一张“最好看”但无法核对讲解关系的帧。

图形工程可以读取 timing 编排动作，但不创建口播字幕节点、Canvas 字幕或字幕选择器。由音频脚本读取同批字幕文件，编译并烧录；字幕与场景绘制互相独立。间隙应没有字幕，不用上一句、最后一句或其他文本填补。不要用场景开始时间覆盖语音开始时间。

画面先渲染无音轨、无口播字幕的 MP4，再使用音频脚本绑定的 WAV 和字幕合成，避免重复播放或双层字幕。

## 示例

`examples/sunset-scattering/` 提供一个原生工程示例：编辑式字体层级、原创景观、大气曲面、同一光路径的连续变化，以及从任意时间重画的 Canvas。它是无旁白、无字幕的静音设计示范，镜头秒数不是语音时间戳。

复制到当前项目，按其 storyboard 配好实际本地字体和 GSAP；用户主题变化时重新设计主体与镜头，不能只换标题。有声版本使用本次主旁白和已核对的字幕时间重新编排。
