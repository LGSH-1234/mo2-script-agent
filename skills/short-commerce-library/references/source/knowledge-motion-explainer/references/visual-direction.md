
# 视觉设计

## 质量目标

制作具有高级感、美感和专业完成度的知识短片。艺术方向服从主题和受众；不能用一个固定深色模板、字体组合或转场套路套所有主题。精致来自比例、层级、细节和节奏的统一，不要求所有题材都使用写实材质、复杂特效或三维模型。

以下标准用于实际画面审阅：

- **主视觉能独立成立。** 开场取作封面时，主题、主体和视觉重心明确；主要对象有足够尺度和辨识细节，不能只是小图标旁堆长文。
- **排版有编辑设计。** 标题、说明、数值与标注有明确角色、对齐和间距；中文断行自然，关键信息在缩略图里仍能读到。必要文字不得超出画幅、被裁断或与其他文字重叠；这类错误应先修正，不能用风格化解释。删去重复文字，避免全屏同字号、同权重。
- **画面有完整关系。** 主体、背景、标注和素材边缘经过统一设计；真实物体的轮廓、结构与光影可信，抽象图的几何、线条与测量关系精确。留白集中视线，细节服务解释。
- **变化有观看节奏。** 用全貌、局部、过程和比较推进理解；同一布局持续使用时必须出现新的关系或状态。动作分主次，关键结果停稳供阅读，不把所有元素同时淡入或一直漂浮。
- **全片有一致气质。** 字体、色彩角色、线宽、圆角、材质与转场共享少量规则；素材的色温、清晰度和裁切相容，没有占位图、默认样式或随意拼贴的痕迹。

开场主视觉与核心机制帧未达到这些要求时，先优化它们，再扩展全片。最终抽帧如果仍显得粗糙、拥挤、空泛或机械重复，即使功能检查通过也不能记录为审美合格。每轮优先解决一至三个最影响观感的具体问题，并用同一时点的新画面验证变化。

## 分析参考片的设计

有参考片时，先看开场、主要机制、结尾的完整画面，再看关键动作前、中、后及切场附近。记录具体决定，不写“高级、科技感、有创意”：

- 标题、正文、数字、标注分别是什么字体性格，字号和字重如何拉开层级；
- 主体占多大画幅，用什么视角、轮廓、细节和裁切形成重心；
- 光源在哪里，是否有体积、投影、材质、环境层次；
- 哪个对象贯穿多个镜头，哪些颜色、纹理、轮廓持续保留；
- 讲解过程中究竟改变了位置、形状、数量、连接、比例还是图像细节；
- 留白围绕什么形成焦点，字幕怎样与主体共存。

参考提供的是视觉方法。其中的技术数字和结论需另行核实。不要把参考中的整帧换个标题当作新知识图解。

## 确定设计方案

编码前在 storyboard 顶部确定下列项目，值来自当前主题与参考，不把这张表当固定皮肤：

| 决定 | 要落到可执行内容 |
| --- | --- |
| 主视觉资产 | 实际素材文件或原创对象；列出辨识所需轮廓、结构与细节，确定观察视角 |
| 字体角色 | 实际可用的标题字体、正文/标签字体、数字字体；确认中文覆盖 |
| 层级 | 最大的焦点、第二重心、辅助标签各是什么；避免每块内容同尺寸同权重 |
| 文字占位 | 每个标题、说明与标签的最大宽度、行数、避让范围；用最长实际文案及最大动态读数校验 |
| 色彩 | 背景、文字、强调色、变量编码；保留足够对比，不用高饱和彩虹装饰 |
| 材质与光 | 光源方向、明暗、表面质感、空间层次；图像和图解保持同一视觉语气 |
| 运动逻辑 | 同一主体从什么状态到什么状态；镜头何时靠近、保留或退出 |

编辑感科普可尝试宋体/衬线标题、清楚的黑体正文、窄体或等宽数字；几何、儿童、医学等题材根据受众调整。不要全片所有文字都用同一默认字体、同一字重。1080p 的起点可为主标题 76–110 px、章节题 56–80 px、关键标注 28–38 px、字幕 40–52 px；关键数字可以明显放大。非必要的微小索引可以更小，但不能把知识点藏在看不清的小字中。

有意设计的暗底、浅底、左右分栏、居中或大留白都可使用。风格统一不等于每场必须换色；构图变化也不是场次数量任务。

## 主视觉质量

画面质量首先来自主对象。先判断需要观众认出实物外观，还是看清结构、变量和作用关系，再选择表现方式。简洁的二维线稿也能成为成熟的主视觉，其质量取决于轮廓、比例、线条、留白和连接是否经过设计，不以绘制元素多寡或是否三维衡量。选择适合观察任务的素材方式：

- 高质量照片、实物渲染或插画建立直觉，代码负责精确标尺、剖面、路径、数值和状态；
- 原创程序图形适合自然景观、几何、粒子、抽象结构和机制。曲面、层次、光照、细线与局部纹理要围绕同一主体设计；
- 纯图表题材可以极简，但基线、比例、单位和局部强调要明确，不需要伪造实物材质。

简化时保留辨识特征和解释所需的关键部件；轮廓、比例与连接要可信。删去与讲解无关的细节，让观众能定位输入、作用部位和输出。素材不足时先完成一个精细、可控的主图，不添加更多卡片、彩色圈或背景粒子来掩盖主体未完成。

同一素材在多个镜头中可以通过裁切、放大、角度选择和标注承担不同解释：先看设备，再看关键部位，再用抽象图说明部位如何工作。表现形式按解释需要选择。

先把主要对象放大到能承担解释，再安排文字；检查关键部件在 640 px 宽缩略图里能否辨认。全貌容不下结构细节时切入局部，不把所有部件塞进缩小的整物图标。照片、模型与程序图形都需要明确观察目标，搜索过素材不等于最终画面已经使用了它。

## 构图与镜头连续性

第一句提出具体问题，开场尽早建立主对象、情境和观看方向。允许短暂的描线、移动或文字入场；第 0 帧应是有意设计的起始状态，不能是资源未加载的空白。分别检查第 0 帧和入场结束帧，不把尚在入场的画面当作最终构图，也不让观众等数秒才知道主题。

用贯穿对象组织讲解，例如：

- 同一对象：初始状态 → 作用过程 → 状态变化 → 回到观测结果；
- 同一组数据：原始信息 → 转换后的结构 → 连接关系 → 结果；
- 同一设备：整体 → 局部 → 状态变化 → 效果比较。

镜头间保留可辨认的轮廓、颜色、纹理、位置或 ID。需要转为抽象图时，用局部放大、对应标记或连续变换说明它来自哪里，避免观众每场重猜主体。

连续性还包括空间关系：对象的结构、路径、测量点、标注端点复用同一套几何参数。局部放大时重新投影标注锚点，再在最终画幅内安排文字框与引线；文字不必随主体一起放大或移出屏幕。既不能让标签指向空处，也不能只顾端点正确而忽略整段文字的位置。具体测量与避让见 [文字排版](composition.md#文字排版)。

稳定的编辑网格能降低理解成本。若同一组对象正在建立新关系，保留左右结构完全合理；换场依据是观察任务，而不是“上一场已经用过这个布局”。用真实主图、过程图、同尺度比较和局部特写安排节奏，不强制每片凑够几种版式。

安排镜头时选择当前最有解释力的画法：生活情境建立问题，局部结构定位作用位置，展开图或过程图说明关系，同尺度对比展示结果。可以保留章节位置、边距和字体等共同框架，同时改变主体尺度与观察方式。局部部件转成独立过程图时保留身份标记；结果回到原情境时让观众认出前后关联。

文字分工明确：标题提炼问题，标签贴近对象，数字指出关键差异，字幕跟随口播。不要把标题、摘要、正文、字幕四份讲稿同时堆屏。次要内容主动退后，重要变化出现时视线只有一个主要目的地。

让颜色持续代表语义角色，同一对象、变量和对应词语使用一致编码。主关系突出、辅助结构退后；颜色不能随换场随意换含义。图形标签指出“在哪里、是什么、发生了什么”，字幕承载完整口语句；不要重复抄写同一段解释。

## 关键文字动效

将标题、关键词、数字和结论作为动画叙事的一部分。根据语义安排出现、强调、停留和退出时机，让文字与主体动作共同推进理解。

- **标题分步建立问题**：按完整短语分组入场，可用错时位移、缩放或揭示形成节奏；核心问题尽早完整可读。
- **关键词随讲解出现**：讲到对应概念时，让关键词进入画面，并与相关部位、路径或变量同步变色、放大或突出；强调完成后保留清楚的标签位置。
- **数字随变量变化**：数值、单位和图形状态同步更新，在关键值处停留。中间读数应来自真实数据或明确的示意模型。
- **结论在结果形成时呈现**：随着机制完成，逐步汇聚或呈现结论短语，再留出阅读时间；上一阶段的次要文字可退场或转为辅助标注。

在分镜中明确关键文字对应的语义时点和联动对象。按内容选择动效组合，保持全片统一的运动风格；强调动作完成后让文字稳定可读，避免持续抖动、闪烁或循环入场干扰阅读。转场中同时可见的文字，以及位移、缩放后的完整字框，都纳入布局检查；使用揭示遮罩时按 [文字排版](composition.md#文字排版) 检查揭示过程与最终完整状态。

这里的动效用于画面标题与图解标注。口播字幕仍由同一份已核对时间轴统一合成，保持逐句完整、稳定显示。图内关键词提炼当前重点，避免把整句口播再复制成另一层动态字幕。

## 材质与空间层次

材质与空间表现服从所选视觉语言；平面图解可用统一底色、细线、局部填色和轻微纹理完成，不需要强加立体光照。需要材质时，在图形关系清楚之后统一处理，不能用滤镜替代构图：

- 明暗与投影服从同一光源；边缘高光、遮挡和前后大小帮助说明体积。
- 背景、中景、前景的层次要有主题依据：山脊与水面、设备外壳与内部、数据主体与连接关系。不是每场强塞相同的光晕和网格。
- 暗色可用带色相的近黑、暖灰文字和局部强调；浅色依靠结构线与明度差保持层次。全片素材的色温、对比和颗粒感一致。
- 细颗粒、暗角和柔光的强度应适合画面风格，并保持文字清晰、避免压缩脏块。静止背景也可以成立，不要求所有装饰持续运动。
- 图像边界须设计：自然延展、明确画框、合理蒙版或前后叠放。不要把一块矩形风景突兀贴在背景上。

## 编排机制动画

区分“素材在动”与“机制被解释”。镜头推近、视差和淡入只能引导观看，机制场还要发生真正的状态变化。

每个关键动作写出四件事：对象的初态、触发条件、可观察变量、最终状态。按因果顺序编排，例如：

- 先看见输入沿路径进入，再看处理区域状态改变，最后输出变化；
- 改变输入参数时，由同一模型更新相关路径与输出状态；
- 粒子沿路径移动时保留位置身份，不能每帧随机换一批点；
- 对比使用同尺度、同基线，差值出现后再高亮关键数值；
- 图像压缩/结构转化时，保留原图颜色或纹理，使观众知道还是同一个对象。

先建立对象，再推进变化，再留住结果。可用约 0.3–0.7 秒入场、0.6–1.5 秒关键变换作为起点，持续过程按实际配音展开；不要每个元素同速淡入，也不要每场都用弹跳、旋转、镜头漂移。

把显示结果的时机绑到事件：到达测量位置再更新数值，作用发生后再显现变化，对比建立后再突出差异。一次只增加当前需要的信息，完成后的结果可停稳供阅读。动画速度用于表达关系时，应由相应变量决定；仅作示意的缓动不能暗示真实测量。

动作幅度须在手机尺寸可见。描线不是“流动”的全部，透明度变化不是“形态变化”；语音说“数量增加”“形状改变”“压力减弱”时，画面必须改变对应变量。

## 准确性与可读性

美术处理不能改变结论。夸大的厚度、粒径、速度或距离标“示意”，不能把演示当测量值。明确区分实物、空间轨迹、状态曲线和统计图，不混淆不同物理过程。没有单位和数据依据的读数条只表达定性变化，不暗示测量精度。

为核心机制写一至三个可以核对的约束：对象的连接是否成立，标注是否落在被解释的位置，结果是否由当前输入推导，比较是否共享基线或尺度。动态标签锚点与显示变量由同一份数据更新。先核对计算或几何关系，再看变化前中后帧是否把关系正确呈现；不能因为末帧看起来合理，就认定中间过程正确。

背景覆盖真实画布；留白服务焦点。检查源素材黑边、容器高度、画幅比例，避免把内容挤在上半屏。字幕衬底只包文字，主体背景延续到下方，关键标签与字幕留出间距。

## 检查实际画面

先渲染开场主视觉和最复杂机制的完成帧，与参考对照主体质量、字体、材质、尺度和留白。写出具体差距并修正这两帧，通过后再扩展全片；不能等全部做完才发现主图只是草图。

随后按 [review.md](review.md) 先看每镜代表帧，再做有目的的补查：

1. 全片联系图作总览，然后逐张打开每镜代表帧：检查布局、文字、原理画法和风格，记录具体观察。重复布局是否仍承载新的关系。
2. 机制前、中、后三帧：状态变量真的改变，而不是同图淡入。
3. 切场前后：对象没有突然失去对应关系，画面没有无意空屏。
4. 文字最密、运动最靠边与转场共存帧：先看完整画幅，再放大标题区与四周，检查完整文字框；不能只看图解中心。字幕与手机尺寸另查：主旨和关键标签读得清，字幕不跨多知识点挂屏，不遮住过程。
5. 最终渲染：检查的是实际交付版本，不沿用修改前的截图结论。

按 [review.md](review.md) 对最终 MP4 执行抽帧、批注、修改和同点复查。程序对比度、布局和解码检查是技术检查，不能代替上述判断。只有媒体摘要时，不宣称已验证细节、美感或声画同步。
