## 〇·一、顶层创意总原则

文旅底层目标：展示城市独有风光，吸引游客实地游览；画面以景观为主体，搭配松弛人群，杜绝全程清冷空镜。

### 城市辨识度锚（强制规范）

&gt; 每座城市的15s短片必须具备"一眼可辨"的独特辨识度，禁止拍成换掉字幕就能通用的风光模板。

| 维度  | 要求  |

| --- | --- |

| **地标锚** | 3-9s核心段必须出现该城市独有地标（非通用古建/山水），且该地标在视频生成Prompt中必须显式命名 |

| **人文锚** | 9-13s文化体验段必须展示该城市独有非遗/民俗/美食（非通用模板），实际内容必须搜索确认 |

| **色彩锚** | 全片色调需贴合城市气质——人文古城暖黄温润、山水康养青绿通透、海滨城市蓝白明亮 |

| **Slogan锚** | 片尾Slogan必须凝练城市独有定位，不可套用通用文案（详见§四 M-T06） |

### 简化文旅视觉分层库

&gt; 15s短片不使用长片Gen分层架构，按以下简化层级组织素材：

| 层级  | 内容  | 15s用途 |

| --- | --- | --- |

| **场景层（L）** | 城市实景地标/街区/自然景观参考图 | 每段分镜1-2张，提供场景基调 |

| **角色层（R）** | 人物形象参考图（含服装、年龄、行为） | 需要人物出镜的段落1张，含2-3人结伴设定 |

| **道具层（P）** | 非遗器物/文化符号/特产等 | 需要特写或文化展示时1张 |

| **BGM层** | 匹配文旅类型的背景音乐 | 全片统一1条，合成阶段混入 |

&gt; 单个分镜引用参考图片总计不得超过9张。详见§十三参考素材数量约束。

### 人物孤寂红线

&gt; ⚠️ **踩坑记录**：桂林文旅短片初版各时段仅安排1名人物独行（1名漫步者驻足、1名筏工静泊、1名农人弯腰），成片观感静谧但偏孤寂，与甲方"我们这里很美、很好玩、大家来玩"的传播意图不符。

禁止全段大量单人独行静态空镜；优先2-3人结伴互动（拍照、品茶、徒步）；单镜头仅1人时远景必须附带其他行人，杜绝单人空旷死寂画面。

**执行规范**：

1. **人物数量**：各时段人物应优先使用2-3人（说明书允许的上限区间），而非最低值1人
2. **人物行为**：从独行静态改为结伴互动——如2-3名游客结伴拍照、筏工与游客互动交谈、农人相邻劳作偶尔交谈
3. **情绪导向**：人物行为应传递"游览体验感"（观赏、拍照、交谈、体验），而非"独处沉思感"（驻足发呆、独行远眺）
4. **自检标准**：若全片4段中3段以上为单人独行，判定为孤寂感风险，需调整至2-3人结伴

### 人文场景允许/禁止

| ✅ 允许 | ❌ 禁止 |

| --- | --- |

| 整洁古街、非遗作坊、有序美食市集、山间步道茶园 | 密集人群、杂乱地摊、网红扎堆摆拍、大规模无序集市 |

| 零散人物日常体验、劳作活动（2-3人结伴，分散松弛） | 杂乱集市、无序喧闹 |

| 人物与景观自然互动（茶农采茶、手工艺人创作、茶客品茗） | 网红打卡扎堆、摆拍群体 |

### 人物画面占比（全文仅百分比，无分数）

人文古城型：画面人物占比 ≤ 10%山水康养型：画面人物占比 ≤ 20%混合型：取两种类型中更宽松的值 ≤ 20%

&gt; 无人物人文载体：古建筑、雕塑、文化地标、非遗器物等不受画面占比约束，可自由搭配使用。

### 无人场景 / 雨雪天气人物兜底规则

&gt; 部分城市部分时段因景观性质（如纯自然风光）或天气条件（雨雪雾）不适合安排人物，需按以下规则兜底：

| 场景类型 | 兜底规则 |

| --- | --- |

| **纯自然风光段**（如雪山、峡谷、海岸线无人区） | 允许0人物，但须在该段Prompt中显式注明"纯风光段，无人物"，且全片4段中至多2段为0人物 |

| **雨雪天气段** | 允许0人物或仅保留1名撑伞/穿雨衣的远景剪影，但该段需在方案中标注"雨雪兜底" |

| **夜景段** | 允许0人物，但须用灯光/窗火等人文痕迹替代人物生机感 |

| **全片0人物判定** | 若4段全部为0人物，判定为"孤寂空镜风险"，必须调整至少2段加入2-3人结伴人物 |

## 一、创作前置确认流程

接收任务先核验5项：目标城市、文旅类型、成片模式、画幅、画质增益卡。

### 文旅类型判定标准

1. **人文古城**：核心资源为古建筑、古街区、非遗；代表城市：西安、苏州、丽江、平遥、泉州
2. **山水康养**：核心资源为峰林、江河、温泉、森林；代表城市：桂林、黄山、张家界、三亚
3. **15s专属混合型简化规则**（无Gen分层，不适用45s主从架构）
  - 用户指定业态则以指定为主；
  - 无指定取城市第一文旅名片；
  - **山水/人文资源均衡时默认山水为主**；
  - 全片光影、构图、人物占比跟随主业态，从业态仅少量穿插在3-9s、9-13s，不拆分宏观微观两段。

&gt; 混合型详细判定条件与画面分配规则详见§三·3.4。

| 模块  | 时长  | 镜头数量 | 情绪曲线 | 标准运镜 | 标准景别分配 |

| --- | --- | --- | --- | --- | --- |

| 3-9s 自然人文核心 | 6s  | 4-6镜 | 中→峰值 | 缓慢推进（4-6拍） | 全景30% 中景40% 近景20% 特写10% |

| 9-13s 文化体验配套 | 4s  | 3-4镜 | 峰值→中 | 轻度环绕（3-6拍） | 全景40% 中景40% 近景15% 特写5% |

| 13-15s 收尾双态段 | 2s  | 1-2镜 | 中→低 | 先拉远航拍、后静态定格 | 全景40% 中景30% 近景20% 特写10% |

### 单镜头短片适配规则

单镜头无法多景切换时，依靠运镜渐变覆盖景别标准；13-15s双态要求：动态拉远→全景定格，定格实景画面留存≥2s。

### M-V02 三级对焦通用规则

优先级：一级核心主体 &gt; 二级场景元素 &gt; 三级远景环境；

收尾定格画面强制对焦城市核心地标，远景、建筑杂物全部虚化后置。

## 三、双类型差异化创作规范

### 3.1 人文古城型

**情绪基调**：厚重、古朴、温润

**允许光影**：晨昏侧暖光、漫射柔光、窗棂光影切割

**推荐构图**：中轴对称、街巷纵透视、门洞框架式

**人物类型**：非遗匠人、茶客、古城游客

#### 各时段内容填写指南

**0-3s 城市印象钩子**

- 古城天际线（城墙轮廓、古塔飞檐）、历史街区鸟瞰、古城地标远景
- 构图侧重：中轴对称构图（古城墙、城楼）、纵透视引导线构图（古街巷道）
- 人文点缀提示：2-3名结伴游客沿街巷行走或驻足观赏，人物占比≤10%

**3-9s 自然人文核心（权重40%）**

- **必须查城市特色人文资源**，不可用通用古建+非遗模板
- 展示城市独有的古建群落、历史街区、非遗场景本身，不是景区大门或游客中心
- 构图侧重：纵透视构图、框架式构图（门洞/窗棂框景）、对称构图
- 人文点缀提示：2-3名结伴人物（游客结伴观赏、品茶者交谈），人物占比≤10%
- **人文古城城市示例**（实际内容必须查目标城市，以下仅参考）：
  - 西安 → 古城墙、大雁塔、碑林、回民街
  - 苏州 → 园林精粹（拙政园漏窗、留廊）、昆曲水袖、平江路水巷
  - 丽江 → 古城纳西建筑、四方街、东巴造纸
  - 平遥 → 古城墙、票号建筑、明清街巷
  - 泉州 → 开元寺双塔、西街骑楼、南音演奏

**9-13s 文化体验配套**

- 非遗手工艺场景（木雕、刺绣、制茶、酿酒等技艺现场）
- 民俗文化活动（戏曲表演、祭祀仪式、节庆场景，画面整洁）
- 美食街市（整洁有序的传统美食场景，非杂乱集市）
- 构图侧重：中景叙事构图（人物+器物+场景三合一）

**13-15s 收尾双态段**（通用定义见§四）

- 第一态：镜头沿古城中轴拉远、抬升航拍，展现古城全貌
- 第二态：定格古城天际全景（城墙、古塔、飞檐轮廓线）
- 片尾Slogan叠加：在定格画面上叠加M-T06三层Slogan（详见§四）

**光影核心**：利用晨昏斜射光强化建筑立体感与历史质感；阴天漫射光利于还原古建彩绘与木雕原色；窗棂光影切割是古建独有光影语言。

&gt; **光影边界约束（15s短片强制规范）**：15s短片全程使用单套固定静态光影，从0s到15s光影调性不变。禁止自动做昼夜渐变、色温漂移、光线方向变化。时序动态光影为45s长片专属规范，15s短片不适用。

### 3.2 山水康养型

**情绪基调**：空灵、治愈、通透

**允许光影**：晨雾柔光、黄昏金调逆光、日间清透自然光

**推荐构图**：山水广角、三分留白、河流引导线

**人物类型**：采茶人、徒步者、温泉体验客

#### 各时段内容填写指南

**0-3s 城市印象钩子**

- 山水全景（山峦天际线、江河湖海全景）、自然生态入城景观
- 构图侧重：山水广角构图、三分法构图（天地水三分）
- 人文点缀提示：2-3名结伴人物作为自然尺度参照，人物占比≤20%

**3-9s 自然人文核心（权重40%）**

- **必须查城市特色山水资源**，不可用通用山+水模板
- 展示城市独有的自然景观本身（名山大水、峰林瀑布、梯田花海、温泉溪流）
- 构图侧重：山水广角构图、留白构图、引导线构图
- 人文点缀提示：2-3名结伴人物（竹筏上的筏工与游客、结伴徒步者），人物占比≤20%
- **山水康养城市示例**（实际内容必须查目标城市，以下仅参考）：
  - 桂林 → 喀斯特峰林、漓江竹筏、龙脊梯田
  - 张家界 → 石英砂岩峰林、天门山、金鞭溪
  - 黄山 → 迎客松、云海日出、奇石怪岩
  - 武夷山 → 九曲溪竹筏、大红袍茶园、天游峰
  - 三亚 → 亚龙湾海岸线、热带雨林、蜈支洲岛

**9-13s 文化体验配套**

- 康养体验场景（温泉养生、禅修静坐、茶园采茶、森林徒步）
- 构图侧重：人与自然比例构图（人物小、自然大，凸显自然磅礴）

**13-15s 收尾双态段**（通用定义见§四）

- 第一态：镜头持续拉远、抬升航拍，展现山水全貌与天地辽阔
- 第二态：定格山水天际全景（山峦轮廓+水面倒影+天空留白）
- 片尾Slogan叠加：在定格画面上叠加M-T06三层Slogan（详见§四）

**光影核心**：晨雾漫射光营造"水墨晕染"的空灵感；黄昏逆光制造光晕与剪影，传递治愈温暖；清透自然光展现山水本色。注重给天空和水面大面积留白。

&gt; **光影边界约束（15s短片强制规范）**：15s短片全程使用单套固定静态光影，从0s到15s光影调性不变。禁止自动做昼夜渐变、色温漂移、光线方向变化。时序动态光影为45s长片专属规范，15s短片不适用。

### 3.4 混合型简化判定与画面分配规则

&gt; 适用于兼具人文古城与山水康养双重核心资源的城市（如厦门=鼓浪屿万国建筑+环岛路海岸）。不使用长片Gen分层架构，按以下简化规则判定与分配。

#### 判定条件

城市同时满足以下两项时判定为混合型：

1. 3-9s核心段的独有地标中，人文类与自然类资源数量相当（差距≤1项）
2. 收尾定格画面无法单一归属古城天际线或山水天际线（如海岸+建筑共存）

&gt; **山水/人文资源均衡时默认山水为主。**

#### 画面分配规则

| 时段  | 分配原则 | 说明  |

| --- | --- | --- |

| 参数  | 符文规定值 |

#### 8. FFmpeg实现命令

&gt; Ease In Out缓动无法直接用FFmpeg fade滤镜（fade为线性），需使用Python生成带alpha通道的PNG序列帧叠加。

**方案A：Python生成Ease In Out alpha遮罩 + FFmpeg overlay叠加（✅ 推荐正确方案）**

```
# Step 1: Python生成带Ease In Out渐入alpha通道的Slogan透明底PNG序列帧

# （使用PIL生成，alpha值按 ease_in_out(t) = 0.5*(1-cos(π*t)) 计算）

# 背景层: 0.0~1.2s (帧0~35, 30fps)

# 主Slogan层: 0.2~1.6s (帧6~47)

# LOGO/附属层: 0.6~2.0s (帧18~59)



# Step 2: PNG序列帧直接overlay到S4成片上（跳过中间视频编码）

# ⚠️ 严禁先编码为yuva420p透明视频再overlay！h264透明通道不可靠，会导致底层画面被黑色覆盖！

# ✅ 必须用filter_complex直接将PNG序列帧逐帧overlay

ffmpeg -y -i S4_final.mp4 -framerate 30 -i slogan_frames/frame_%04d.png \

  -filter_complex "[1:v]setpts=PTS-STARTPTS[slogan];[0:v][slogan]overlay=0:0:format=auto[v]" \

  -map "[v]" -map 0:a? -c:v libx264 -crf 18 -preset medium -r 30 -c:a aac -b:a 192k S4_slogan.mp4



# Step 3: 黑屏验证（强制执行，不可跳过）

ffmpeg -i S4_slogan.mp4 -vf "blackdetect=d=0.1:pix_th=0.10" -an -f null - 2&gt;&amp;1 | grep -iE "black"

# 必须输出"无黑屏"才能继续后续合成
```

**方案B（简化）：使用FFmpeg fade滤镜近似实现（线性渐入，非严格Ease In Out）**

```
# 简化版：仅叠加主Slogan文字层（最常用场景）

ffmpeg -y -i S4_final.mp4 -i slogan.png \

  -filter_complex "[1:v]format=rgba,fade=t=in:st=0.2:d=1.4:alpha=1[s];[0:v][s]overlay=(W-w)/2:H*0.72[v]" \

  -map "[v]" -map 0:a? -c:v libx264 -crf 18 -preset medium -r 30 -c:a aac -b:a 192k S4_slogan.mp4
```

### Storyboard JSON结构防合并规范（强制执行）

&gt; ⚠️ **踩坑记录（storyboard自动合并问题）**：调用generate_idea生成storyboard时，系统可能自动将4个分镜合并为2个（如S1+S2合并、S3+S4合并），导致后续无法按四段独立生成视频。此问题在桂林、杭州、厦门三城制作中均反复出现，严重影响创作效率。

1. **生成后立即验证**：generate_idea返回后，必须读取storyboard JSON文件，检`shot_list`数组长度是否等于4
2. **验证字段**：逐一核对4个shot_id分别为"S1"/"S2"/"S3"/"S4"，shot_duration_ms分别为4000/6000/4000/4000
3. **合并处理流程**：若发现shot_list长度≠4，必须使用sandbox_edit手动修正JSON：
  - 读取被合并的shot的description字段，按四段时序切分为4个独立shot对象
  - 每个shot对象必须包含：shot_id、description（含location/role/product引用标签）、first_frame_id（空）、shot_duration_ms、use_material_audio（false）、material_id（空）、video_path（null）、voiceover（空）、scene_id
  - 修正后再次验证shot_list长度=4
4. **分镜视频生成时逐段调用**：generate_shot_video必须对S1/S2/S3/S4分别独立调用，每次仅生成1个shot，禁止在单次调用中传入多个shot_id

### FFmpeg统一合成流程（xfade全程禁用）

&gt; 以下规范基于实际执行中踩坑总结，必须严格按此流程操作。踩坑速查表统一归入文末附录A.1。

#### 第一步：精确裁切

&gt; ⚠️ **踩坑记录**`-c copy`在关键帧处截断，会产生0.1-0.17s的时长偏差，无法精确到目标时长。

裁切必须使用重新编码方式`-c:v libx264`），禁`-c copy`：

```
# 正确：重新编码精确裁切

ffmpeg -y -i S1.mp4 -t 3.0 -c:v libx264 -crf 18 -preset medium -c:a aac -r 30 S1_final.mp4

ffmpeg -y -i S4.mp4 -t 2.0 -c:v libx264 -crf 18 -preset medium -c:a aac -r 30 S4_final.mp4
```

裁切后用 `ffprobe` 确认时长精确到目标值（3.000s / 2.000s）。

#### 第二步：统一编码格式与时间基

&gt; ⚠️ **踩坑记录**：不同分镜视频的 `video_track_timescale` 可能不一致（如15360 vs 1000000），直接拼接会报错。

```
# 对未经裁切处理的S2、S3进行标准化

ffmpeg -y -i S2.mp4 -c:v libx264 -crf 18 -preset medium -r 30 \

  -video_track_timescale 15360 -c:a aac -b:a 192k -ar 44100 S2_normalized.mp4

ffmpeg -y -i S3.mp4 -c:v libx264 -crf 18 -preset medium -r 30 \

  -video_track_timescale 15360 -c:a aac -b:a 192k -ar 44100 S3_normalized.mp4
```

#### 第三步：段间淡入淡出转场处理（xfade全程禁用）

&gt; ⚠️ **踩坑记录**：FFmpeg的 `xfade` 滤镜在转场期间会重叠两段视频，导致总时长减少（每次0.5s转场吃掉0.5s时长，3次转场共减少1.5s，15s变13.5s）。**xfade滤镜全程禁用，仅采用以下方案。**

**唯一正确方案：段尾淡出 + 下段开头淡入 + concat拼接**，总时长不减少：

```
# S1：仅尾部淡出0.25s

ffmpeg -y -i S1_final.mp4 -vf "fade=t=out:st=2.75:d=0.25" \

  -c:v libx264 -crf 18 -preset medium -r 30 -c:a aac -b:a 192k S1_fade.mp4



# S2：开头淡入0.25s + 尾部淡出0.25s

ffmpeg -y -i S2_normalized.mp4 -vf "fade=t=in:st=0:d=0.25,fade=t=out:st=5.75:d=0.25" \

  -c:v libx264 -crf 18 -preset medium -r 30 -c:a aac -b:a 192k S2_fade.mp4



# S3：开头淡入0.25s + 尾部淡出0.25s

ffmpeg -y -i S3_normalized.mp4 -vf "fade=t=in:st=0:d=0.25,fade=t=out:st=3.75:d=0.25" \

  -c:v libx264 -crf 18 -preset medium -r 30 -c:a aac -b:a 192k S3_fade.mp4



# S4：仅开头淡入0.25s

ffmpeg -y -i S4_final.mp4 -vf "fade=t=in:st=0:d=0.25" \

  -c:v libx264 -crf 18 -preset medium -r 30 -c:a aac -b:a 192k S4_fade.mp4
```

&gt; 淡出起始时间 = 段时长 - 0.25s。淡入淡出时长0.25s为推荐值，不宜超过0.5s。

#### 第四步：concat拼接合成

```
# 创建文件列表

printf "file 'S1_fade.mp4'\nfile 'S2_fade.mp4'\nfile 'S3_fade.mp4'\nfile 'S4_fade.mp4'\n" &gt; concat_list.txt



# concat拼接（各段编码参数已统一，可直接copy）

ffmpeg -y -f concat -safe 0 -i concat_list.txt -c copy final_video.mp4
```

#### 第五步：验证成片

```
ffprobe -v quiet -show_entries format=duration:stream=codec_type,codec_name,width,height,r_frame_rate final_video.mp4
```

确认项：总时长≈15s（±0.3s）、分辨率16:9、帧率30fps、编码H.264。

- ❌ 不得将4段合并为2段或1段生成

| xfade合成后总时长减少1.5s | xfade转场重叠期间吃掉时长 | **xfade全程禁用**，改用fade淡入淡出+concat拼接方案 |

| 合成后BGM不连贯、4段音乐拼接 | 分镜视频各自配了不同BGM | 分镜阶段不配BGM，合成完成后统一混入一条完整BGM |

| overlay后S4画面变黑屏 | 先编码yuva420p透明视频再overlay，h264透明通道不可靠 | 必须PNG序列帧直接overlay，跳过中间视频编码 |

### A.2 转场规则详细定义

**淡入淡出**：通用渐变转场，段尾画面亮度渐降至黑+下段从黑渐升至正常。独立15s全片模式段间使用。

**叠化**：相邻两段画面交叉溶解，上一段未完全消失时下段已开始显现。多段15s拼接长片时段衔接使用。

**全景遮挡**：依靠画面内实景前景（山体、林木、建筑墙体、桥梁、拱门）横向/纵向移动，完全填满画面、遮蔽全部背景后切入下一镜头。

- 人文古城型全景遮挡前景：门洞、拱门、廊柱、建筑墙体
- 山水康养型全景遮挡前景：山体、林木、岩壁、桥洞

&gt; ⚠️ **全景遮挡与叠化转场独立区分，不可混用归类。全屏叠化覆盖属于通用淡入淡出，不属于全景遮挡。**

encode_standard() {

  # $1=输入 $2=输出 $3=裁切时长(可选,0=不裁切)

  local input="$1" output="$2" cut_dur="$3"

  if [ "$cut_dur" != "0" ] &amp;&amp; [ -n "$cut_dur" ]; then

    echo "[裁切+编码] $input → $output (时长${cut_dur}s)"

    ffmpeg -y -i "$input" -t "$cut_dur" \

      -c:v libx264 -crf ${CRF} -preset medium -r ${FPS} \

      -video_track_timescale ${TIMESCALE} \

      -c:a aac -b:a ${AUDIO_BR} -ar ${AUDIO_SR} \

      "$output" 2&gt;&amp;1 | tail -3

  else

    echo "[标准化编码] $input → $output"

    ffmpeg -y -i "$input" \

      -c:v libx264 -crf ${CRF} -preset medium -r ${FPS} \

      -video_track_timescale ${TIMESCALE} \

      -c:a aac -b:a ${AUDIO_BR} -ar ${AUDIO_SR} \

      "$output" 2&gt;&amp;1 | tail -3

  fi

}



apply_fade() {

  # $1=输入 $2=输出 $3=段时长 $4=头部淡入(0/1) $5=尾部淡出(0/1)

  local input="$1" output="$2" dur="$3" fade_in="$4" fade_out="$5"

  local vf=""

  if [ "$fade_in" = "1" ]; then

    vf="fade=t=in:st=0:d=${FADE_DUR}"

  fi

  if [ "$fade_out" = "1" ]; then

    local fade_st=$(echo "$dur - $FADE_DUR" | bc)

    if [ -n "$vf" ]; then

      vf="${vf},fade=t=out:st=${fade_st}:d=${FADE_DUR}"

    else

      vf="fade=t=out:st=${fade_st}:d=${FADE_DUR}"

    fi

  fi

  echo "[淡入淡出] $input → $output (vf: ${vf:-none})"

  if [ -n "$vf" ]; then

    ffmpeg -y -i "$input" -vf "$vf" \

      -c:v libx264 -crf ${CRF} -preset medium -r ${FPS} \

      -c:a aac -b:a ${AUDIO_BR} -ar ${AUDIO_SR} \

      "$output" 2&gt;&amp;1 | tail -3

  else

    cp "$input" "$output"

  fi

}
