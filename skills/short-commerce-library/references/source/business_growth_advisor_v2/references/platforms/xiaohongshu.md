
# 小红书 方法论 v0.1.9

## 先确认

- 场景：自然笔记、搜索种草、直播、店铺、蒲公英达人合作、聚光投放、私域引流。
- 主体：账号、店铺、商品、笔记、达人、直播间、投放计划、关键词。
- 业务目标：曝光、互动、收藏、搜索排名、种草转化、店铺成交、线索留资、品牌声量。
- 数据时间窗：单篇笔记、近 7 天、近 30 天、活动周期、单场直播、单个计划。
- 指标口径：曝光、阅读、点击、互动、收藏、转粉、商品点击、成交、线索、ROI 是否来自同一后台。

## 常见指标

### 账号 / 内容

- 曝光、阅读、阅读率。
- 点赞、收藏、评论、分享、关注。
- 互动率、收藏率、评论质量。
- 粉丝画像、内容垂类、笔记发布时间。

### 搜索 / 种草

- 关键词覆盖、搜索曝光、搜索点击。
- 标题关键词、正文关键词、话题标签。
- 排名位置、同类笔记竞争、评论区真实问题。
- 收藏和评论是否证明用户进入决策阶段。

### 商品 / 店铺

- 商品点击、加购、成交、转化率、客单价。
- 商品图、标题、价格、评价、买家秀、售后承诺。
- 店铺评分、物流、优惠、达人背书。

### 达人 / 蒲公英

- 达人垂类、粉丝画像、历史内容质量。
- 合作笔记曝光、阅读、互动、收藏、评论、进店或成交。
- 种草内容是否被搜索持续承接。

### 聚光 / 投放

- 消耗、曝光、点击、CTR、CPC、转化、CPA、ROI。
- 人群、关键词、素材、落地页或商品承接。
- 笔记互动和成交目标不要混用同一判断标准。

涉及 CPA、ROI、线索成本或成交利润测算时，先确认目标是互动、线索、进店还是成交，并使用程序计算；不要把互动优化口径和成交口径混在一起比较。

## 诊断方向

- 有曝光没阅读：封面、标题、首图信息密度、关键词匹配、用户兴趣不准。
- 有阅读没互动：内容没有真实经验感、信息不够有用、缺少对比/清单/步骤/避坑。
- 有互动没转化：商品承接弱、价格/评价/信任不足、购买路径不清。
- 收藏高成交低：用户有兴趣但决策周期长，需要搜索承接、复访内容、测评证明或优惠节点。
- 评论多但不精准：选题吸引了泛人群，卖点或人群标签需要收窄。
- 搜索弱：标题、正文、标签没有覆盖用户真实搜索词，内容缺少可被搜索理解的关键词。
- 达人合作弱：达人粉丝和商品人群不匹配，脚本过广告化，缺少真实使用细节。
- 投放 ROI 弱：笔记吸引错人、承接不一致、商品页信任不足或目标设置不匹配。

## 内容和视频机会

优先推荐：

- 痛点场景笔记：从真实问题切入，例如“为什么用了很多方法还是……”
- 清单/攻略型：步骤、避坑、对比、选购指南。
- 真实测评：开箱、使用前后、细节展示、长期体验。
- 评论问题答疑：把评论区高频疑问做成单独笔记或视频。
- 搜索承接内容：围绕核心关键词做标题、封面和正文。
- 达人种草 brief：强调真实体验、场景细节和人群语言。
- 短视频版种草：把图文笔记中的高收藏点转成 15-45 秒视频。

## 小红书视频 / 笔记方案最小 brief

- 商品和价格。
- 目标人群和使用场景。
- 当前目标：曝光、收藏、搜索、成交、线索或达人合作。
- 关键词或用户搜索问题。
- 已有笔记/视频/达人素材和表现。
- 评论区高频问题或用户顾虑。
- 核心证明点：真实体验、对比、评价、买家秀、成分/材质/效果证据。
- 合规和禁忌：功效、医疗健康、虚假承诺、夸大对比、引流限制。
- 可用素材、参考截图、关键帧或可读取参考内容。
