
# 通用诊断框架

## 诊断顺序

1. 用户正在痛的具体问题是什么。
2. 这个问题更像素材/卖点、投放、人群、承接、价格竞争、门店场景还是 B2B 表达问题。
3. 目标是否清楚。
4. 数据口径是否一致。
5. 漏斗卡点在哪里。
6. 当前动作是否匹配目标。
7. 问题是商品、内容、素材、人群、投放、价格、履约还是平台规则。
8. 哪些判断有数据支撑，哪些只是猜测。
9. 当前最值得验证的假设是什么。
10. 下一步最小实验或执行计划是什么。

## 漏斗视角

### 内容/短视频

- 曝光/播放：平台是否给流量。
- 3 秒/5 秒/完播：开头是否留住人。
- 点击/商品点击：卖点和行动引导是否有效。
- 评论/收藏/转发：内容是否有讨论点或保存价值。
- 成交/转化：商品力、价格、信任和页面承接是否足够。

### 投放

- 消耗：能否花出去。
- CTR：素材是否吸引目标人群点击。
- CVR：落地页、商品、价格、信任是否承接。
- CPA/ROI/ROAS：是否达成经营目标。涉及测算时必须先确认口径，并通过程序计算。
- 频次/衰退：素材是否过度消耗。
- 计划结构：预算、人群、出价、素材是否互相干扰。

### 痛点入口

| 用户痛点 | 优先判断 | 优先产出 |
|---|---|---|
| 不知道拍什么 | 商品、人群、场景和卖点是否能支撑不同视频方向 | 3 条视频方向 + hook |
| 素材不转化 | 开头、卖点、人群、证明和承接哪个最弱 | 素材诊断 + 改版变量 |
| 投流亏钱 / ROI 掉 | 素材吸引力、CVR 承接、成本口径和竞争变化 | 卡点定位 + 创意测试矩阵 |
| 同行卷价格 | 是否有非价格卖点和证明素材 | 差异化卖点脚本 |
| 门店客流少 | 到店理由、活动表达、团购承接和本地场景 | 门店短视频方向 |
| 产品专业但客户看不懂 | 功能参数是否翻译成客户问题和结果 | B2B 价值表达脚本 |

### 商品/店铺

- 商品力：需求、卖点、价格、评价、物流、库存。
- 页面承接：主图、标题、详情、评价、优惠。
- 信任：评分、达人背书、内容证明、售后。
- 竞争：同类商品价格、卖点、内容表达。

## 诊断对象

先判断问题对应哪个经营对象，不要把不同对象混在一起：

- 平台：TikTok Shop、抖音电商、其他平台。
- 账号/店铺：主店、品牌号、达人号、投放账户。
- 商品/SKU：单品、套装、新品、利润品、引流品。
- 素材：自然视频、投放视频、直播切片、商品图、脚本。
- 动作：自然内容、投放、直播、达人合作、商品页优化、活动促销。

如果用户同时提供多个平台、多个商品或多个账号，先拆对象，再逐个判断。

## 指标定位问题

| 表现 | 更可能的问题 | 下一步 |
|---|---|---|
| 有曝光但 CTR/点击弱 | 素材开头、封面、卖点或人群表达弱 | 改前 3 秒、封面、标题和主卖点 |
| CTR 不弱但 CVR 弱 | 商品页、价格、信任证明、优惠或承接弱 | 检查详情页、评价、优惠、证明和一致性 |
| 3 秒/5 秒弱 | 视觉开头或首句没有停住人 | 做不同 hook 版本 |
| 完播弱 | 中段信息无关、节奏慢、证明不足 | 改 3-15 秒 on-ramp 和中段结构 |
| 高转化低点击 | 卖点有效但吸引力弱 | 强化开头、封面和人群识别 |
| 高点击低转化 | 钩子可能吸错人或承接不一致 | 检查承诺、落地页和商品页一致性 |
| ROI 衰退 | 素材疲劳、流量质量变化、成本上升、竞争变化 | 先看时间窗、频次、素材生命周期和新素材供给 |

## 最小实验原则

- 一次尽量验证一个核心变量：开头、卖点、场景、证明、价格表达或 CTA。
- 样本不足时用低成本测试，不要直接做大制作。
- 优先复用用户已有商品图、历史素材、评论和参考。
- 每个实验都要写清楚复盘指标和时间窗。
- 涉及 ROI、CPA、保本点或利润比较时，先用程序算出基线，再设计实验目标。
