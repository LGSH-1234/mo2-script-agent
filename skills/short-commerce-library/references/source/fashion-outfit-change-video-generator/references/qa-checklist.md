# 两阶段验收与状态

只报告实际观察到的结果。提示词完成不等于图片或视频已生成；提交生成任务不等于媒体已完成。

## 阶段 A：每张穿搭图硬检查

- [ ] 成图数量与用户服装套数一一对应，顺序正确。
- [ ] 模特与默认／用户替换的模特参考是同一身份；没有继承默认图的深蓝运动服、中文标注或四视图排版。
- [ ] 模特是完整全身，头顶、手、腿、双脚和鞋均清楚，无多肢、断肢、融合手指或比例畸变。
- [ ] 当前套装的上衣、下装／连衣裙、外套、鞋、包、腰带、手表和首饰与服装参考一致，没有串入其他套装。
- [ ] 颜色、材质、版型、长度、图案、五金和配件数量没有明显漂移。
- [ ] 凳子保持米白座面、镀铬支柱、脚踏和圆盘底座，结构完整，只有一张。
- [ ] 人物在右半区自然坐姿，一脚落地、一脚脚踏，身体与凳子有真实接触。
- [ ] 左半区黑色细线框高度与人物可见高度一致，单品竖排、完整、互不重叠、短黑线分隔。
- [ ] 左框单品与人物实穿一一对应，没有遗漏、重复或额外单品。
- [ ] 左框、人物和凳子互不遮挡；背景是左右一致的白色无缝摄影棚。
- [ ] 肤色白皙通透、冷中性、有真实皮肤纹理与柔和面光，没有暗黄、灰脏、蜡感或过曝漂白。
- [ ] 没有额外人物、背景道具、标题、乱码、水印或参考图版式残留。

身份、服装、凳子或左框映射任一失败，该图不得进入视频阶段。

## 阶段 B：视频硬检查

- [ ] 总时长约 15 秒，时码连续；标准三套版两次换装均存在。
- [ ] 第一帧已经看到凳子和走向镜头的同一位模特，没有空镜。
- [ ] 全片是一镜到底；只有触镜时短促轻晃和末尾缓慢拉远，没有切镜、跳镜或闪白。
- [ ] 始终是同一张脸、同一发型、同一身体比例，不生成三位不同人物。
- [ ] 0—5 秒依次完成走近、触镜、后退、坐下、脚踏姿势、整理头发和微笑。
- [ ] 5—5.5 秒人物与凳子连续缩小到右侧，左框淡入，没有切镜。
- [ ] 两次旋转都从正面向画面右侧转开，完整 360°，没有反向、回摆或只转半圈。
- [ ] 服装只在旋转背面遮挡中段切换，返回正面时稳定；左框与服装同帧同步更新。
- [ ] 第二、第三套服装及配饰分别与 `@图片2`、`@图片3` 一致，没有串套或混搭。
- [ ] 左框出现后持续约 1% 画面宽度的轻微水平摆动，框内单品不各自乱动。
- [ ] 11—13 秒自然站起，凳子留在原位；13—15 秒左框消失，人物走到中央，镜头拉远。
- [ ] 行走、坐下、站起、衣料、头发、包带和凳子遵循真实重力、惯性、摩擦和接触。
- [ ] 白色摄影棚、柔和面光、白皙通透肤色、凳子、曝光和白平衡全片连续。
- [ ] 没有多余人物、重复肢体、重复凳子、遮挡、重影、闪烁、字幕、乱码、水印或参考图外场景。

双套版删除第二次旋转相关检查；单套版不要求换装，但不得伪报为换装视频。

## 状态词

- `PROMPT_READY`：提示词已完成，未生成媒体；
- `IMAGE_GENERATED_QA_PENDING`：图片已生成，尚未检查；
- `IMAGE_APPROVED`：该穿搭图通过阶段 A；
- `VIDEO_GENERATED_QA_PENDING`：视频已生成，尚未检查；
- `VIDEO_APPROVED`：视频通过阶段 B；
- `FAILED_QA`：媒体已生成但未通过硬检查；
- `BLOCKED`：缺少关键输入、工具不可用、权限不足或连续失败。

## 重试与报告

- 每张穿搭图、每个视频批次最多两次针对性修复；每次只改变实际失败项。
- 连续失败后停止，不无限消耗额度；保留最后一个可复现提示词和失败说明。
- 只有实际查看媒体并通过清单后才能标记 `IMAGE_APPROVED` 或 `VIDEO_APPROVED`。
- 需要外部账号、付费生成、上传、发布或删除远端结果时，先取得用户明确授权。
