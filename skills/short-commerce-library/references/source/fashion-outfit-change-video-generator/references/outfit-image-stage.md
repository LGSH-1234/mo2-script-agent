# 阶段 A：逐套穿搭图

每套服装独立生成一张竖版穿搭图。最终提示词必须替换全部花括号；没有的单品删除，不能把模板占位符交给生成模型。

## 平台参数

参数在图片平台界面设置，不写入提示词正文：

- 画幅：9:16 竖版；
- 质量：优先 2K 或平台可用的高质量档；
- 参考图：3 张；
- `@图片1`：默认或用户明确替换的模特参考；
- `@图片2`：默认或用户明确替换的凳子参考；
- `@图片3`：当前套装服装图；
- 每套单独运行一次，不把多套服装同时送入同一次图片生成。

## 参考层级

1. `@图片1` 只控制模特身份、发型、身材和比例，不继承深蓝运动服、中文文字或四视图排版。
2. `@图片3` 是服装与搭配的唯一真值，控制所有穿戴单品与左侧平铺单品。
3. `@图片2` 只控制凳子的形状、材质、颜色、结构和比例。
4. 用户文字控制摄影棚、构图、肤色、姿势和版式。

## 最终图片提示词模板

```text
@图片1 是固定成年女模特的身份参考，只继承她的五官、脸型、自然长发、身材和人体比例；忽略参考图中的深蓝运动服、中文标注、特写与四视图版式。@图片2 是固定凳子参考，保持米白软包弧形座面、镀铬支柱、脚踏和圆盘底座的形状、材质、颜色与比例。@图片3 是本套服装和搭配的唯一参考。

生成同一位真实成年女模特的全身商业穿搭摄影。她完整穿着 @图片3 中的{完整服装清单}，所有单品的颜色、材质、版型、长度、图案、五金、配件和数量与参考一致；鞋、包、腰带、手表、首饰均按参考准确佩戴或自然持拿，不增加参考图中不存在的单品。她自然坐在 @图片2 的凳子上，身体位于画面右半区，一只脚完整落地，另一只脚自然放在凳子脚踏上，双腿与双脚结构清楚，头顶到鞋底完整入镜，手臂和手指自然可见，服装关键结构没有被手、头发或凳子遮住。

画面由两个等宽竖向区域组成。左半区放置一个由黑色细线构成的竖向黑框，黑框的顶部与底部对应右侧模特从头顶到鞋底的可见高度。框内只展示 @图片3 中的{左侧展示框单品顺序}，采用干净的电商平面展示图形式，每件单品完整、独立、等比例、互不重叠，按从上到下合理排列，相邻单品之间用很短的黑色细线分隔。左框不进入右半区，不遮挡人物或凳子；右侧人物和凳子也不进入左框。左框中的单品与模特身上实穿单品一一对应。

背景是统一纯净的白色无缝摄影棚，左右两部分的地面、背景、曝光和白平衡完全一致。柔和的大面积摄影棚主光从镜头左前方照射，镜头正前方有柔和面部补光，阴影边缘柔和。模特呈冷中性、白皙通透的自然真人肤色，保留细腻皮肤纹理和健康血色，面部清晰柔亮，不出现暗黄偏色、灰脏阴影、蜡像质感或过曝漂白。整体是清爽奶油风商业电商摄影，干净、通透、真实材质、自然比例。

只出现同一位模特、同一张凳子和本套服装展示框；没有额外人物、额外肢体、重复凳子、重复单品、文字标题、乱码、Logo 水印、背景道具或遮挡。模特面孔、发型、身材、凳子和摄影棚在全部套装成图中保持一致，只有服装搭配和左框单品随 @图片3 改变。
```

## 生成策略

- 有多参考编辑／生成能力时，同时传入三张参考图。
- 只能使用一张参考图的平台不适合直接执行此流程；优先换用多参考工具，不把三张图拼接后假装拥有独立权重。
- 若模特面孔漂移，强化 `@图片1` 身份锁，不要追加新的五官描述。
- 若服装漂移，逐项列出服装身份卡，并强调 `@图片3` 是唯一服装真值。
- 若左框错位，只修版式与单品顺序，锁定面孔、服装、凳子、姿势、光线和背景。
- 若只错一个配件，做最小局部修复，不重建整张图。

## 文件命名

默认另存为：

```text
穿搭图_01_{简短套装名}.png
穿搭图_02_{简短套装名}.png
...
```

不得覆盖用户原图或上一版成图。
