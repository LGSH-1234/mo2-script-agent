# Generate Ecommerce Hook Videos

为一个商品设计三个路线明确、强度达标的 5 秒片头 Hook，动态推荐最适合的一条；选定后完成资产检查、Seedance Prompt 编译与视频生成。

## Scope

- 只生成接在卖点展示之前的 Hook；不在 5 秒内解释卖点、完成证明、加入 CTA 或制作完整广告。
- 默认时长 5 秒、画幅 9:16；遵循用户明确指定的其他画幅。
- 默认处理单个商品；暂不编排批量任务。
- 不建立生成后自动质检或重试闭环。
- 不要求用户预先决定商品何时出现、是否使用人物或如何衔接正片；从 Hook 机制倒推。
- 不把创意策略、评分、资产状态或业务字段写入 Seedance Prompt。
- 不改变 `seedance-reprompt-skill` 的任务分类、引用方式或 Prompt 结构。

## Core Model

内部使用以下组合，不要把它输出为 Seedance 字段或业务 JSON：

```text
注意力机制 × 商品/品类母题 × 创意路线 × 主表达载体 × 可选辅助载体 × 商品出场策略 × 执行语法 × 真实感档位 × 结束动作
```

视觉、非语言声音和语言是表达载体，不是三个互斥的注意力机制。先决定为什么停，再决定用什么传达。

常用注意力机制包括：异常与违和、日常痛点与近失、信息缺口、感官满足、结果先行、尺度与数量反差、第一人称介入、冲突与挑战、身份与反应、已提供活动话术的物理化。

每条 Hook 只使用一个主机制、一个主载体和最多一个辅助载体。

## Three User-Facing Routes

### 1. 商品原生视觉冲击

从商品的外形、动作、材质、声音、成品效果或使用现场长出视觉事件。让撕、抽、扣、吸附、旋转、展开、倾倒、穿戴、揉、拧、甩等原生动作成为画面骨架；可信 ASMR 或瞬态声音可以共同强化攻击，但不要用普通展示代替 Hook。

优先推荐给原生动作、纹理、声响、结构或成品效果强的商品。

### 2. 口播语义冲击

用一句有表演质感的口播建立信息差、矛盾、计数、身份点名、命令、经历或反应，并让可见动作在重音处回答这句话。拒绝普通商品描述和与画面无关的万能台词。

优先推荐给视觉普通但痛点、身份、场景、名称或已提供话术强的商品。

### 3. 通用爆点骨架 × 商品专属峰值

使用极端入场、环境接管、镜头撞击、尺度倒置、开合触发、熟悉动作反转、格式劫持、强运动矢量等可迁移骨架。允许骨架本身跨品类复用，但必须为当前商品重写峰值：商品成为刺激源、异常原因、动作对象、悬念答案或结果锚点，而不是事后插入的 Packshot。

优先推荐给原生资源较弱、适合隐喻或 VFX，或用户明确要求奇观、极端入场与强视觉事件的商品。

推荐项必须动态选择，不固定偏向第一条。

## Workflow

### 1. Normalize The Product Input

从文字和素材中提取：

- 商品名称、细分类目、真实用途与可辨识外观
- 颜色、材质、包装、结构、配件、反射与纹理
- 商品原生动词和可信声源
- 可瞬间识别的场景、人物身份、痛点、结果或情绪
- 用户明确提供的价格、活动、数量、促销和短话术
- 商品图、人物图、场景图、风格图、视频与音频参考
- 禁止出现的主体、表达、人物、场景与创意方向

不要要求固定表单。缺少非关键字段时自行推断；只有无法识别商品，或商业事实是所选 Hook 不可替代的核心时，才提出一个最小必要问题。

不要补写未提供的卖点、价格、折扣、精确销量、评价、功效、认证或背书。允许把“用了30天”“正在爆火”用作不带具体结果、排名或销量的短 Hook 框架；默认不用“同类都含有”之类范围性事实。

### 2. Build The Creative Profile

读取 `category-routing.md`，按实际商品而不是类目名称判断：

- 原生 Hook 强度：`strong`、`medium`、`weak`
- 最强感知资源：外形、动作、材质、声音、结果、人物关系、痛点、数量或语义
- 真实感档位：真实原生、现实放大、强奇观
- VFX 亲和度
- 商品出场策略：商品先行、峰值揭晓、结果/答案揭晓或由正片自然接入
- 商品在峰值中的角色：刺激源、动作对象、异常原因、悬念答案或结果锚点
- 三条路线中最值得默认推荐的一条

不要求商品首帧出现。先让最低理解成本的注意力事件发生，再把商品放在峰值、答案或结果位置。商品出现前的视觉、声音或语言必须与它形成可读的因果或语义连接。

### 3. Build A Route-Balanced Candidate Pool

为三条路线分别生成 2–3 个内部候选，共 6–9 个，不直接输出。按路线渐进读取对应 Ref。

所有候选必须：

- 从当前商品、可信场景或已提供话术长出来。
- 在开场立即发动注意力，不写准备过程。
- 只设置一个异常事件、一个主机制和一个高潮。
- 让声音成为具体事件，让口播驱动画面，让 VFX 服务机制。
- 把痛点停在问题建立，把挑战停在测试建立，不完成卖点证明。
- 压缩为“触发 → 单一发展 → 峰值/交接”三个功能状态。

### 4. Keep One Winner Per Route

读取 `candidate-ranking.md` 与 `safety-boundaries.md`。先应用重 Hook 硬门槛，再在每条路线内部选择最高分方案，最终固定得到三个用户选项。

使用同等强度的安全替换，不要把危险创意简单降级为平淡展示。三个方案应在注意力机制或执行语法上实质不同。

动态推荐综合最优的一条，并把它视为默认选中项。若用户明确指定某条路线，仍默认给该路线内三个不同执行方案；若用户只要一个方案、直接要 Prompt、直接生成或已经选定创意，则直接采用最高排名方案，不再次确认。

### 5. Present The Three Options

使用路线专属字段，标记动态推荐且默认选中的方案：

```markdown
### 1. 商品原生视觉冲击：<Hook 名称>（推荐）
- 抢夺瞬间：<第一个视觉/声音攻击>
- 5秒动作链：<触发 → 发展 → 峰值/交接>
- 商品峰值：<商品如何成为峰值>
- 声音/口播：<具体声音事件或短台词；没有则写“无”>
- 适配原因：<为什么只属于该商品>

### 2. 口播语义冲击：<Hook 名称>
- 核心台词：<一句话>
- 口播表演：<语气、节奏、重音、距离>
- 画面响应：<动作如何响应台词>
- 商品峰值：<商品在何处回答台词>
- 适配原因：<一句话>

### 3. 通用爆点骨架 × 商品专属峰值：<Hook 名称>
- 使用骨架：<一个通用骨架>
- 抢夺瞬间：<第一攻击>
- 商品专属绑定：<为什么换商品就必须重写峰值>
- 声音/口播：<具体重音>
- 适配原因：<一句话>
```

只呈现选择所需的信息，不输出内部评分或完整 Seedance Prompt。需要用户选择时，请用户回复 `1 / 2 / 3` 或提出修改，然后停止生成。

### 6. Check Continuity Assets

用户选定或 Skill 直接选定方案后，读取 `asset-consistency.md`。只检查必须与后续商品视频保持一致的商品、角色、关键道具、场景、视觉风格和声音身份。

复用已提供素材；安全可设计的虚构资产可以生成；真实人物、真实商品、品牌包装和专有场景缺失时要求上传；非必要锚点改成通用元素。只有资产实际存在并已附加时，才映射为稳定的 `@图片N`、`@视频N` 或 `@音频N`。

### 7. Compile The Selected Hook

1. 保留一个主注意力机制、一个主表达载体和最多一个辅助载体。
2. 让第一帧、首个动作或首个可听瞬间立即发生事件。
3. 让峰值明显高于开场，并在峰值给商品一个清晰、稳定、可辨识的状态。
4. 明确关键声音的声源、动作、起音、质地、距离、节奏、收尾与同步点。
5. 口播默认一句，明确语气、节奏、重音与对应动作；精确屏幕文字优先后期添加。
6. 删除第二个高潮、完整卖点解释、不必要的场景切换和普通展示尾巴。
7. 从动作自然倒推遮镜、甩镜、未完成动作、亮场/黑场、持续运动或揭示停顿。
8. 完整遵循 `seedance-reprompt-skill` 的原结构，只引用实际附加素材。

不得增加 `HookPlan`、`strategy_id`、`score`、`asset_status`、`bridge`、JSON 或其他业务字段。

### 8. Generate And Deliver

使用当前环境可用的 Seedance 视频能力提交 Prompt 与参考素材，并持续执行到获得视频结果。工具要求登录、确认或不可替代素材时，只转达最小必要动作。

默认交付：

- 生成的视频或可访问结果
- Hook 名称、路线与一句话说明
- 仅当新生成或上传连续资产时，附上可复用的资产路径、句柄或标签映射

只有用户明确要求时，附上完整 Prompt、候选评分或详细创意解释。

## Trigger Examples

- “给这款纸巾做一个 5 秒开头 Hook。”
- “分别给我商品原生、口播、通用爆点三个方向。”
- “商品不用首帧出现，在注意力峰值揭晓。”
- “声音要有 ASMR 质感，口播跟画面动作同步。”
- “给这个耳机做一个真实但有 VFX 的开场。”
- “检查人物和场景资产，然后直接生成视频。”
