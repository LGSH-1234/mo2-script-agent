# 家居改造 Vlog

## 核心原则

家居改造 Vlog 的核心不是"好看"，而是"变化明显"。观众要看到一个人亲手把凌乱空间变成舒适角落的过程——这个过程本身就是内容。人物是主角而非背景板，家具布置是主线而非室内展示。

持久引擎（因果链）：
**人物照片（身份锚定）→ 改造前空间（建立问题：拥挤/杂乱/暗）→ 人物开始劳动（搬运/整理，真实动作）→ 空间逐步变化（家具归位/留白增加/光线通透）→ 改造后全景（对比冲击）→ 人物在新空间中放松（治愈回报）→ 观众获得"我也能做到"的代入感**

## 质量测试

如果去掉改造前后的空间对比，这个视频就只是一段普通居家画面而非"改造 Vlog"——则创意不成立。改造前必须可见"问题"（拥挤/杂乱/光线不足），改造后必须可见"改善"（整洁/通透/留白），且两个状态在同一空间内发生。

## 工作流

### 第 1 步：解析人物照片

读取用户上传的人物照片，提取以下身份锚定信息：
- 脸型、五官比例
- 发型、发色
- 年龄气质
- 可见性别表达
- 服装风格
- 是否包含房间背景（若有则分析空间基调、光线、家具风格）

这些信息将在 prompt 中以正向措辞描述，确保生成视频时人物身份一致。

### 第 2 步：确定空间与风格

- 若照片包含房间：沿用照片中的空间基调、光线和家具风格作为改造前状态
- 若照片不含房间：根据人物气质和服装风格自动补全一个合理的居家改造场景
- 从 references/industries/home-makeover-styles.md 选择匹配的空间风格方向

### 第 3 步：确定视频版本

根据用户输入或默认选择确定版本路线（见路由表）。不同版本的差异主要体现在：
- 沉默式整理版：少台词，强环境音，慢动作细节多，突出整理解压感
- 前后对比版：开场改造前，结尾改造后，对比更强烈
- 人物情绪版：人物从疲惫到放松，通过空间变化带动情绪变化
- 小户型干货版：强调靠墙、留白、动线、收纳，可加入少量字幕

### 第 4 步：构建 Prompt

从 references/formats/video-prompt-grammar.md 获取 prompt 文法和 beat 结构模板，结合人物信息、空间风格、版本路线构建完整视频生成 prompt。

核心 prompt 模板：

```
用户上传一张人物照片，以照片中的人物为唯一人物身份参考，生成一条真实自然的家居改造 Vlog。保持人物{脸型}、{五官比例}、{发型}、{年龄气质}、{可见性别表达}和{服装风格}一致，面部清晰自然，人体比例真实。视频开始是略显{拥挤/杂乱/光线不足}的{空间类型}，人物进入房间并开始调整家具布局；随后人物{推动小柜子/整理桌面/折叠毯子/摆放绿植和抱枕}，动作符合真实居家劳动逻辑；最后展示{整洁/通透/留白增加}的改造完成空间，人物轻松坐在新布局中环顾四周。真实手机 Vlog 质感，自然光，低饱和，温暖治愈，轻微手持感但画面稳定，镜头节奏流畅，包含全景、中景、近景和结尾轻微环绕展示。声音使用轻柔 BGM，搭配脚步、拖动、布料、摆件等环境拟音，无口播，无画面文字。
```

### 第 5 步：生成视频

15 秒（含）以内的成片用一次视频生成即可拿到完整片段。上述多段 beat（0-2s/2-6s/6-10s/10-13s/13-15s）是同一条 prompt 内的时间轴描述，不需要分段多次生成再拼接。只有成片超过 15 秒时，才拆成多个不超过 15 秒的片段分别生成，再做后处理拼接。

### 第 6 步：交付

将生成的视频展示给用户。若用户需要调整，可基于当前结果修改 prompt 参数重新生成。

## 输出契约

### 标准 15 秒 beat 结构

| 时间 | 画面内容 | 镜头重点 | 声音 |
|---|---|---|---|
| 0-2s | 改造前房间全景，人物进入画面 | 建立空间问题：拥挤、杂乱、光线不足 | 轻柔 BGM 起 |
| 2-6s | 人物开始挪动家具、清空桌面 | 中景记录劳动过程，动作自然 | 脚步声、拖动声 |
| 6-10s | 调整沙发/书桌/床柜位置，整理细节 | 近景展示对齐、摆放、收纳 | 布料声、摆件声 |
| 10-13s | 改造后空间展示，人物在新布局中停留 | 前后对比明显，画面变整洁通透 | BGM 抬升 |
| 13-15s | 稳定成品全景，人物微笑或轻松坐下 | 收尾定格，营造治愈感 | 音乐收束 |

### 人物形象约束

必须保持：
- 人物身份一致（来自用户上传照片）
- 面部清晰自然
- 人体比例真实
- 动作符合家居劳动逻辑
- 不改变用户可见性别表达

允许自然生成：
- 补全身体、手臂、手部动作
- 生成搬家具、推柜子、整理桌面、铺毯子、摆放绿植等动作
- 服装可保持原图或根据居家场景做自然延续

禁止：
- 换脸成其他人
- 过度美化导致失真
- 夸张表演
- 不符合物理逻辑的动作
- 改变人物种族、年龄阶段、可见性别表达

### 人物动作库

进入空间：走进房间 / 环顾四周 / 整理前停顿
搬运调整：推小柜子 / 搬收纳盒 / 拉沙发垫 / 调整书桌位置 / 抱起抱枕
细节整理：折叠毯子 / 摆放绿植 / 整理桌面物品 / 对齐相框 / 收纳杂物
完成状态：坐在新空间里 / 靠墙休息 / 环顾成品空间 / 轻松微笑

### 声音设计

音乐选项：轻柔钢琴 / 治愈吉他 / Lo-fi 居家氛围 / 温暖轻音乐
环境音：脚步声 / 家具轻拖声 / 物品落地声 / 布料摩擦声 / 开窗声 / 摆件轻碰声
台词策略：默认无口播；如需旁白可选——"换个布局，家就不一样了。" / "整理家具，也整理心情。" / "今天，把房间变成喜欢的样子。"

### 文字策略

默认：不显示字幕，保持沉浸式 Vlog 观感。
可选极简文字卡："改造前" / "开始整理" / "换个布局" / "完成" / "家，慢慢变成喜欢的样子"
文字要求：字体简洁，白色或浅米色，小字号，出现在画面安全区，不遮挡人物脸部和主要家具。

### 物理与空间合理性

家具运动逻辑：移动方向合理 / 人物受力自然 / 手与物体真实接触 / 重物不漂浮 / 柜子沙发桌子有稳定支撑
空间逻辑：房间透视统一 / 光源方向统一 / 人物与家具比例协调 / 前后镜头房间结构一致 / 地面墙面门窗不跳变
镜头逻辑：避免快速晃动 / 避免无意义特写 / 避免人物突然换位 / 避免家具瞬间消失或变形

### 前后对比规则

改造前状态：家具拥挤 / 桌面杂物多 / 动线不畅 / 光线偏暗 / 缺乏留白
改造后状态：家具靠墙或对齐 / 桌面整洁 / 通道通畅 / 光线通透 / 留白增加 / 软装风格统一
对比镜头：尽量同一机位 / 开场展示问题空间 / 结尾展示完成空间 / 可用 0.5 秒闪白转场连接前后

## 静默自检

出稿前逐项检查，不通过则修正后重新生成：

- [ ] 人物是否来自用户上传照片，身份稳定一致
- [ ] 视频主线是否清楚：进入空间 → 整理布置 → 完成展示
- [ ] 改造前后是否有明显视觉变化
- [ ] 动作是否自然，符合物理逻辑（手与物体有接触、重物不漂浮）
- [ ] 画面是否真实手机 Vlog 质感，不像广告或效果图
- [ ] 镜头节奏是否适合短视频观看（全景→中景→近景→全景收尾）
- [ ] 声音是否统一，不喧宾夺主
- [ ] 是否未生成与用户照片无关的陌生人物
- [ ] 空间透视和光源是否前后一致
- [ ] 成片是否不超过 15 秒（若是则一次生成完整片段）
- [ ] 措辞是否正向（不堆否定式约束）
- [ ] 全文语言是否与目标市场一致
