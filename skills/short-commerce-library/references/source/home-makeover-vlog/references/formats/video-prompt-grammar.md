## Prompt 组装结构

一条完整的家居改造 Vlog prompt 按以下顺序组装：

```
[人物身份锚定] + [空间状态描述] + [动作序列] + [改造后状态] + [画面风格] + [镜头节奏] + [声音] + [文字]
```

### 基础模板

```
用户上传一张人物照片，以照片中的人物为唯一人物身份参考，生成一条真实自然的家居改造 Vlog。保持人物{脸型}、{五官比例}、{发型}、{年龄气质}、{可见性别表达}和{服装风格}一致，面部清晰自然，人体比例真实。视频开始是略显{拥挤/杂乱/光线不足}的{空间类型}，人物进入房间并开始调整家具布局；随后人物{推动小柜子/整理桌面/折叠毯子/摆放绿植和抱枕}，动作符合真实居家劳动逻辑；最后展示{整洁/通透/留白增加}的改造完成空间，人物轻松坐在新布局中环顾四周。真实手机 Vlog 质感，自然光，低饱和，温暖治愈，轻微手持感但画面稳定，镜头节奏流畅，包含全景、中景、近景和结尾轻微环绕展示。声音使用轻柔 BGM，搭配脚步、拖动、布料、摆件等环境拟音，无口播，无画面文字。
```

## Beat 结构模板

15 秒标准 beat（同一次生成内的时间轴，不是分段生成）：

| Beat | 时间 | 画面 | 镜头 | 声音 |
|---|---|---|---|---|
| B1 | 0-2s | 改造前房间全景，人物走入画面 | 全景，固定机位，建立空间 | 轻柔 BGM 起 |
| B2 | 2-6s | 人物挪动家具、清空桌面 | 中景，轻微手持跟拍 | 脚步声、家具拖动声 |
| B3 | 6-10s | 调整家具位置、整理细节 | 近景，手部特写交替 | 布料声、摆件轻碰声 |
| B4 | 10-13s | 改造后空间展示，人物在新布局中停留 | 全景回到固定机位，对比冲击 | BGM 抬升 |
| B5 | 13-15s | 成品全景，人物微笑或轻松坐下 | 轻微环绕或平移，收尾定格 | 音乐收束 |

8 秒精简版 beat：

| Beat | 时间 | 画面 | 镜头 |
|---|---|---|---|
| B1 | 0-1s | 改造前全景 | 全景固定 |
| B2 | 1-4s | 人物搬运整理 | 中景跟拍 |
| B3 | 4-6s | 近景细节整理 | 近景手部 |
| B4 | 6-8s | 改造后全景收尾 | 全景轻微平移 |

10 秒版 beat：

| Beat | 时间 | 画面 | 镜头 |
|---|---|---|---|
| B1 | 0-2s | 改造前全景 | 全景固定 |
| B2 | 2-5s | 人物搬运调整 | 中景跟拍 |
| B3 | 5-7s | 近景整理细节 | 近景手部 |
| B4 | 7-10s | 改造后全景收尾 | 全景轻微环绕 |

## 人物身份锚定写法

在 prompt 中用正向措辞描述从照片中提取的人物特征：

```
保持人物{圆脸/方脸/瓜子脸}、{双眼皮单眼皮}、{短发/长发/扎发}、{发色}、{约25-30岁年轻女性/男性}气质、{穿着白色T恤和牛仔裤的休闲居家风格}，面部清晰自然，人体比例真实
```

注意：
- 用"保持"而非"不要改变"（正向措辞）
- 描述实际看到的特征，不猜测不可见信息
- 服装描述保持与照片一致或标注"自然延续为居家休闲风格"

## 版本变体 Prompt 差异

### 沉默式整理版（默认）

在基础模板上调整：
- 增加"慢动作展示放下、铺开、摆正的治愈瞬间"
- 强调"环境拟音清晰，BGM 低声量"
- 动作节奏更慢，近景占比更多

### 前后对比版

在基础模板上调整：
- 开场增加"镜头停留 1-2 秒充分展示改造前的拥挤杂乱"
- 结尾增加"镜头回到与开场相同机位，展示改造后的整洁通透，形成强烈前后对比"
- 可加入"0.5 秒闪白转场连接前后状态"

### 人物情绪版

在基础模板上调整：
- 开场"人物面带疲惫走入略显杂乱的房间"
- 中段"人物专注整理，表情逐渐轻松"
- 结尾"人物在新空间中微笑坐下，表情满足放松"
- 强调"通过空间变化带动人物情绪从疲惫到治愈的转变"

### 小户型干货版

在基础模板上调整：
- 强调"家具靠墙摆放释放通道""桌面只保留必要物品""增加墙面收纳"
- 可加入极简字幕卡："改造前""靠墙留白""收纳对齐""完成"
- 镜头更偏向俯拍和全景以展示空间布局变化

## 正向措辞规则

prompt 中使用正向描述，不堆否定式约束：

| 避免（否定式） | 推荐（正向式） |
|---|---|
| 不要让人物换脸 | 保持人物身份一致 |
| 不要过度美化 | 面部清晰自然，人体比例真实 |
| 不要夸张表演 | 动作自然符合居家劳动逻辑 |
| 不要家具漂浮 | 家具有稳定支撑，手与物体真实接触 |
| 不要快速晃动 | 画面稳定，轻微手持感 |
| 不要房间结构跳变 | 房间透视统一，前后镜头结构一致 |

## 镜头语言词库

### 开场全景
- 固定机位全景展示空间
- 人物从画面边缘走入
- 建立空间问题感

### 中景劳动记录
- 轻微手持跟拍
- 人物搬运、推动、整理
- 动作连贯自然

### 近景细节
- 手部特写：折叠毯子、对齐相框、摆放绿植
- 慢动作强调治愈瞬间
- 浅景深突出细节

### 结尾展示
- 回到固定机位或轻微环绕
- 全景展示改造后空间
- 人物在新空间中放松停留
- 定格收尾

## 声音与文字 Prompt 写法

### 声音

默认写法：
```
声音使用轻柔 BGM，搭配脚步声、家具轻拖声、布料摩擦声、摆件轻碰声等环境拟音，无口播
```

加旁白写法：
```
声音使用轻柔 BGM 搭配环境拟音，加入简短旁白"换个布局，家就不一样了"
```

### 文字

默认写法：
```
无画面文字
```

加字幕写法：
```
画面中加入极简文字卡，白色小字号，出现在画面安全区：开场显示"改造前"，中段显示"开始整理"，结尾显示"完成"，不遮挡人物脸部和主要家具
```
