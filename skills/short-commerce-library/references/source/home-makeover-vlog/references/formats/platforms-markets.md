## 画幅与平台适配

| 画幅 | 适用平台 | 特点 |
|---|---|---|
| 9:16 竖屏 | 抖音/快手/小红书短视频 | 默认，适合手机竖屏浏览 |
| 4:5 竖屏 | 小红书图文/Instagram | 适合生活方式内容 |
| 16:9 横屏 | B站/YouTube | 适合长 Vlog 展示 |

---

## 合规约束

### 人物形象合规
- 不改变人物种族
- 不改变人物年龄阶段
- 不改变人物可见性别表达
- 不过度美化导致失真
- 不生成与用户上传照片无关的陌生人物

### 内容合规
- 家居改造场景为日常生活内容，无特殊合规限制
- 不涉及医疗健康宣称
- 不涉及金融产品
- 不涉及未成年人单独出镜
- 不涉及危险动作（如攀高搬重物等）

## 生成参数默认值

| 参数 | 默认值 | 可选值 |
|---|---|---|
| 时长 | 15 秒 | 8 秒 / 10 秒 / 15 秒 |
| 比例 | 9:16 竖屏 | 4:5 / 16:9 |
| 人物来源 | 用户上传照片 | 保持人物身份一致 |
| 场景 | 居家空间 | 卧室 / 客厅 / 书桌角落 / 出租屋 |
| 风格 | 真实治愈 Vlog | 原木风 / 奶油风 / 极简风 / 复古温暖风 |
| 声音 | 轻音乐 + 环境音 | 加简短旁白 |
| 文字 | 无字幕 | 极简字幕卡 / 前后对比标签 |
| 视频版本 | 沉浸式整理版 | 前后对比版 / 人物情绪版 / 小户型干货版 |

时长说明：15 秒（含）以内的成片可一次生成完整片段，不需要分段拼接。超过 15 秒时拆成多个不超过 15 秒的片段分别生成再做后处理拼接。
