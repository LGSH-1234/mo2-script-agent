
# 配音与背景音乐设计规范

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 旁白/配音层

### 脚本来源（优先级从高到低）

1. 用户上传的文本脚本
2. 基于产品卖点和品类张力自动生成的脚本
3. 用户口述的要点

### 脚本编写原则

- 每段配音对应一个镜头，按句子完整性切分
- 不直接按时间切分——在完整句子结束后切分
- 语调与数字人设定一致（亲和/专业/活力/沉稳）
- 产品卖点用具体、可见的表达（"抹上去 3 秒就吸收"而非"吸收很好"）
- 避免绝对化宣称（"最""第一""100%"等），保持保守可证
- 结尾包含 CTA（"点击下方链接""试试看"等）

### 配音规格

- 声音标识：与数字人性别/年龄/语调匹配
- 语速：中等偏快，保持节奏感
- 情感：真诚、自然、不过度表演

## 背景音乐层

### 基本要求

- 至少一条全局背景音轨
- 音量低于配音，不干扰口播清晰度
- 风格与场景/品类匹配（居家温馨/健身房动感/办公室沉稳等）
- 无歌词，避免与配音语义冲突

### 品类-音乐风格速查

| 品类 | 推荐背景音乐风格 |
|---|---|
| 美妆/个护 | 轻柔钢琴/Lo-fi |
| 食品饮料 | 轻快原声吉他/轻电子 |
| 消费电子/AI | 简约电子/氛围音 |
| 健康/保健 | 平缓钢琴/自然音 |
| 运动/健身 | 节奏感鼓点/Electronic |
| 时尚/服饰 | 时尚电子/R&B |

## 音频时间轴对齐

- 配音的入点/出点必须与镜头的时间码匹配
- 背景音乐全程铺设，在配音段落自动降低音量（ducking）
- 每个镜头的视频生成引用对齐的音频片段

## 落 prompt 前自检

- 配音脚本是否按句子完整性切分、未按时间硬切？
- 语调是否与数字人设定一致？
- 卖点是否用具体可见的表达、无绝对化宣称？
- 背景音乐是否无歌词、不干扰配音？
- 配音时间轴是否与镜头时间码对齐？
- 是否包含 CTA？
