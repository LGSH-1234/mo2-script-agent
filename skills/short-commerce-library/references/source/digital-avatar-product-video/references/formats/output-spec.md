
# 视频规格与输出规范

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## Final_Video_Spec.md 模板

```markdown
# 视频规格

标题：<视频标题>
类型：数字人广告与产品视频
比例：9:16
时长：<总时长>秒
视觉风格：写实摄影，干净灯光，智能手机前置摄像头拍摄风格
模型偏好：
  生图：高分辨率多模态图像模型（2K）
  生视频：音频驱动口型同步模型（1080p）
语言：<对白语言>
```

## 关键帧规范

- 分辨率：2K
- 取景：中近景（MCU）或胸像，脸部占比大且清晰
- 产品可见性：产品必须清晰可读，偏好被数字人拿在手中或佩戴在身上
- 构图：主体（数字人+产品）占据前景，背景简洁不杂乱
- 一致性：全片使用同一张关键帧 asset_id，灯光/构图/产品拿取方式不变

## 镜头时长规则

- 单镜头 ≤15s 时，一次视频生成即可拿到完整成片
- 单镜头 >15s 时，拆成若干 ≤15s 片段分别生成再拼接
- 镜头切分以配音句子完整性为优先，不直接按时间切

## 最终合成规范

- 以配音时间轴为定时的唯一事实来源
- 按顺序拼接每个镜头的视频
- 将生成片段上的额外音频轨道静音
- 不改变播放速度
- 不对资产或视频轨道做音频淡出处理

## Beat 时间码模板（≤15s 单镜头）

```
0-3s: <主体入画+产品首曝> <语调定调>
3-7s: <核心卖点展示> <配音主段落>
7-12s: <证据/使用过程> <配音支撑段落>
12-15s: <CTA> <品牌语/记忆点>
```

## 落 prompt 前自检

- 视频规格是否完整（比例/时长/风格/语言）？
- 关键帧取景是否为 MCU 或更紧？
- 产品在关键帧中是否清晰可读、占比合理？
- 镜头时长是否 ≤15s？
- 合成规则是否以配音时间轴为准？
