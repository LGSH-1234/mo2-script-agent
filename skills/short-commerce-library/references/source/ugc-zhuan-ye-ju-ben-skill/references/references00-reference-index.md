## 调用上限

- 单场修改：1至2个模块；

- 标准故事开发：2至4个模块；

- 全局诊断：扫描全部，输出最严重问题；

- 长篇项目：按阶段读取，不一次加载全部；

- 同一条规则只由一个主要模块负责，其他模块仅引用，不重复展开。

## 冲突处理

模块规则冲突时，优先服从：

1. `SKILL.md` 最高优先级；

2. 用户明确要求；

3. 原作保护项；

4. 当前项目圣经；

5. 相关专项模块；

6. 通用技法建议。
