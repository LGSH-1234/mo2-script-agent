# 导演调度、动作与视听技法库

## 一、导演化原则

只写观众能感知、演员能表演、摄影机和声音能执行的内容。

导演建议必须服务：

- 人物目标；

- 空间可读性；

- 情绪；

- 权力变化；

- 动作因果；

- 类型体验。

不为了专业感堆砌景别和镜头术语。

## 二、文戏调度

检查：

- 谁占据空间中心；

- 谁靠近门、证据、武器或关键人物；

- 谁能离开；

- 谁被堵住；

- 谁接近；

- 谁退后；

- 谁看对方；

- 谁回避视线；

- 谁处于高位；

- 权力何时转移。

空间动作必须来自人物意图。

## 三、道具

道具可用于：

- 隐藏信息；

- 争夺控制权；

- 暴露关系；

- 触发记忆；

- 形成选择；

- 制造后果；

- 完成情感回响。

不机械添加喝茶、点烟、翻照片等空动作。

## 四、武戏前提

开打前明确：

- 双方目标；

- 是否必须击败对方；

- 谁不愿真正伤害谁；

- 出口和危险区域；

- 环境资源；

- 能力状态；

- 伤势和体力；

- 失败代价。

## 五、动作因果

每个重要动作至少承担：

- 造成伤害；

- 展示能力或性格；

- 改变攻守；

- 暴露信息；

- 改变空间；

- 迫使选择；

- 造成后续限制。

保证观众理解：

- 谁在哪里；

- 为什么这么做；

- 动作是否成功；

- 造成什么后果；

- 下一动作如何由前一动作引发。

## 六、武戏节奏

可参考：

1. 建立空间和规则；

2. 初次交锋；

3. 攻守转换；

4. 新变量或真实代价；

5. 喘息、迟疑或判断；

6. 不可逆的高潮行动；

7. 结果和余韵。

不强制固定动作数量、镜头秒数、快剪或慢动作。

## 七、动作性格化

不同人物可以表现为：

- 沉稳：动作少、判断快、重视效率；

- 狡猾：利用环境、误导和偷袭；

- 狂暴：持续压迫、忽视防守；

- 精准：攻击弱点、控制消耗；

- 新手：动作不完整、依赖本能；

- 保护型：路线始终围绕需要保护的人；

- 逃生型：避免纠缠，优先制造出口。

不得用风格标签突破能力边界。

## 八、环境参与

环境应实际改变：

- 路线；

- 视线；

- 高度；

- 武器；

- 时间压力；

- 声音；

- 光线；

- 暴露风险；

- 安全区域。

被破坏的环境必须保留后果。

## 九、声音

声音可用于：

- 提前引入下一场；

- 掩盖行动；

- 暴露位置；

- 建立节奏；

- 制造主观体验；

- 与画面形成反差；

- 在高潮后留下余韵。

不要只写背景音乐。优先考虑场内真实声音。

## 十、光影和VFX

建立底层规则：

- 来源；

- 颜色；

- 形态；

- 范围；

- 强度；

- 触发条件；

- 使用代价；

- 环境反应；

- 残留；

- 对人物身体的影响。

同一种能力的光影和VFX应保持辨识度和连续性。

## 十一、镜头建议

需要分镜时，优先明确：

- 镜头目的；

- 主体；

- 景别；

- 空间方向；

- 运动；

- 进入和退出；

- 声音；

- 前后镜头连接。

动作场面先建立空间，再决定是否加快剪辑。

## 十二、高潮画面

高潮画面应同时承载：

- 行动结果；

- 人物选择；

- 关系变化；

- 能力代价；

- 类型兑现；

- 情绪余波。

不能只追求规模增大。
