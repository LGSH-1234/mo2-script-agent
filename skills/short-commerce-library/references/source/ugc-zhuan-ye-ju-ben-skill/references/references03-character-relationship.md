# 人物、关系与冲突技法库

## 一、主角模型

建立：

- 外在目标；

- 内在需要；

- 错误信念；

- 核心缺陷；

- 核心能力；

- 能力与缺陷的共同来源；

- 最怕失去的东西；

- 想向谁证明什么；

- 面对压力的旧策略；

- 道德底线；

- 可能越过的界线；

- 可见的个人习惯和语言特征。

人物特征必须进入选择和后果，不能停留在设定表。

## 二、能力与缺陷同源

优先设计同源关系：

- 独立既使人物生存，也使其拒绝信任；

- 敏锐既能识破谎言，也会制造过度怀疑；

- 幽默既能化解危机，也会逃避真实情绪；

- 责任感既能保护团队，也会演变为控制欲。

高潮不是简单消除缺陷，而是改变使用能力的方式。

## 三、人物决策轨迹

每个关键节点记录：

- 面临的问题；

- 旧策略；

- 当次选择；

- 直接代价；

- 关系影响；

- 后续目标变化。

人物弧光通常表现为：

&gt; 旧策略有效 → 旧策略制造问题 → 旧策略造成重大损失 → 人物被迫选择是否改变。

允许人物拒绝成长，但必须承担相应结果。

## 四、对手

对手需要：

- 独立目标；

- 自认为正当的理由；

- 恐惧；

- 底线；

- 资源；

- 主动计划；

- 对主角策略的学习能力；

- 与主角相似或相反的价值观。

检验：

- 主角不存在时，对手是否仍会行动？

- 从对手视角讲述，故事是否仍然成立？

- 对手是否迫使主角面对自身缺陷？

## 五、配角自主性

主要配角应明确：

- 想从主角那里得到什么；

- 不愿主角知道什么；

- 何时会拒绝主角；

- 自己的目标；

- 与主角的关系变化；

- 没有主角时会做什么。

功能相同且不可区分的配角可考虑合并。

## 六、关系弧光

记录：

- A想从B得到什么；

- B想从A得到什么；

- 双方分别误解什么；

- 谁掌握权力；

- 谁更依赖谁；

- 什么秘密阻止靠近；

- 哪个事件改变关系定义；

- 高潮中双方如何选择。

关系变化可以是：

- 陌生到利用；

- 利用到合作；

- 合作到信任；

- 信任到怀疑；

- 怀疑到背叛；

- 背叛到理解、决裂或重建。

不机械套用顺序。

## 七、三层冲突

重要段落可同时包含：

- 外部冲突：敌人、制度、环境、时间和资源；

- 关系冲突：信任、控制、背叛和依赖；

- 内心冲突：恐惧、羞耻、欲望和价值判断。

高潮尽量让三层冲突汇合。

## 八、目标—阻碍—选择—后果

检查：

&gt; 人物想做什么 → 遇到什么阻碍 → 选择什么方法 → 造成什么后果 → 新后果如何改变目标。

若事件不因人物选择而变化，人物可能过于被动。

## 九、两难选择

有效两难：

- 两边都有合理理由；

- 两边都有真实损失；

- 暴露人物价值排序；

- 后果不可轻易撤销；

- 不存在突然出现的完美第三选项。

## 十、镜像人物

镜像人物面对相似问题，却作出不同选择。

用途：

- 展示主角可能成为的样子；

- 呈现主题；

- 暴露旧策略的终点；

- 制造价值观冲突。

镜像人物仍需拥有独立目标，不能只作为象征。
