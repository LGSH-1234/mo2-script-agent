# 剧本质量门禁

## 一、问题等级

### 阻断级

必须修复：

- 核心因果不成立；

- 主角动机断裂；

- 世界规则自相矛盾；

- 高潮依赖无铺垫能力；

- 结局无法由前文推出；

- 关键角色知道不可能知道的信息。

### 高风险

应优先修复：

- 主角长期被动；

- 类型承诺未兑现；

- 中段重复；

- 对手工具化；

- 核心关系无变化；

- 反转缺乏公平线索；

- 情感重场被错误笑点破坏。

### 优化级

可定向提升：

- 对白辨识度；

- 场景进出点；

- 调度；

- 视觉意象；

- 笑点精度；

- 转场；

- 语言质感。

不得用大量优化级修改掩盖阻断级问题。

## 二、故事门禁

- 主角目标明确；

- 发动机能持续产生冲突；

- 类型承诺可识别；

- 中段发生方向变化；

- 高潮由主角行动促成；

- 结局处理核心问题；

- 重大承诺得到处理。

## 三、人物门禁

- 主角通过选择呈现；

- 旧策略有形成、有效、失效的轨迹；

- 对手拥有独立计划；

- 配角具有最低限度自主性；

- 关系变化具有因果；

- 人物没有突破知识和能力边界。

## 四、场景门禁

- 场景有明确作用；

- 场景产生变化或新理解；

- 进出点无明显拖延；

- 动作和空间清楚；

- 场尾能承接下一场；

- 没有机械使用统一模板。

## 五、对白门禁

- 重要台词具有功能；

- 无无效重复；

- 潜台词来自真实动机；

- 直接表达出现在合理时刻；

- 人物语言可区分；

- 沉默和动作被合理使用。

## 六、幽默门禁

- 笑点符合人物；

- 符合知识范围；

- 不依赖降智；

- 不破坏重场；

- 不抹除代价；

- 第四面墙规则一致。

## 七、导演与动作门禁

- 空间可读；

- 动作有因果；

- 环境参与；

- 伤势延续；

- 能力规则一致；

- 视听设计服务人物和剧情；

- VFX不是临时解决问题的工具。

## 八、交付门槛

满足以下条件才进入定稿：

- 无阻断级问题；

- 高风险问题已修复或被用户明确接受；

- 核心连续性通过；

- 保护项未被擅自改变；

- 结局与人物轨迹成立；

- 输出符合目标篇幅和媒介。

## 九、基准测试

用四类任务测试系统：

1. 只有一个模糊类型；

2. 一场平淡对话；

3. 一场空间混乱的武戏；

4. 增加吐槽和第四面墙。

检查：

- 是否正确路由；

- 是否调用过多模块；

- 是否越过确认节点；

- 是否机械套模板；

- 是否维护人设和因果；

- 是否给出可直接使用的成果。
