# 结构、悬念、反转与回收技法库

## 一、结构原则

结构不是固定比例，而是因果和压力的组织方式。

至少明确：

- 开场状态；

- 诱发事件；

- 主角首次主动承诺；

- 首次重大代价；

- 中段方向变化；

- 关系或价值观破裂；

- 最低谷；

- 最终两难；

- 高潮行动；

- 结果和余韵。

每个节点记录：

&gt; 发生什么 → 为什么发生 → 谁作出选择 → 导致什么后果。

## 二、信息差

管理：

- 观众知道、人物不知道；

- 人物知道、观众不知道；

- 不同人物各知道一部分；

- 人物误解了什么；

- 信息为何被隐藏；

- 何时揭示；

- 揭示后改变什么。

不得让人物为了悬念而隐瞒正常情况下必然会说的信息。

## 三、悬念链

不是重复同一个问题，而是：

&gt; 问题A得到部分答案 → 答案产生问题B → 问题B触及更深风险。

每次答案应：

- 缩小部分未知；

- 扩大事件意义；

- 改变行动；

- 提高代价。

## 四、反转

有效反转需要：

- 前期有公平线索；

- 回看能够成立；

- 重新解释旧事件；

- 改变人物行动；

- 改变目标、关系、立场或代价；

- 不依赖临时新增规则。

反转类型包括：

- 身份反转；

- 立场反转；

- 目标反转；

- 因果反转；

- 胜利即陷阱；

- 保护者与威胁者互换；

- 主角发现自己一直在帮助错误目标。

避免只靠“死人复活”和“盟友突然是反派”。

## 五、伏笔与回收

可采用三次递进：

1. 首次出现：在当前场景自然成立；

2. 再次出现：改变意义或增加重要性；

3. 最终回收：参与选择、结果或情感回响。

不是每个细节都必须回收，但主动制造的重大期待必须处理。

## 六、高潮

高潮应同时处理尽可能多的内容：

- 外部目标；

- 核心关系；

- 内心冲突；

- 类型承诺；

- 主题选择；

- 前期伏笔；

- 能力或规则代价。

高潮必须由主角关键行动促成。

外部援助可以存在，但不能替代主角的最终选择。

## 七、结局

结局需要处理：

- 事件结果；

- 人物变化；

- 关系结果；

- 代价；

- 类型满足；

- 主题回响；

- 未解决内容是否属于主动留白。

可以使用前后呼应：

- 相似场景；

- 相同问题；

- 同一道具；

- 相同台词；

- 不同选择。

重点是展示变化，不是机械重复。

## 八、承诺回收

必须追踪：

- 开场承诺；

- 类型承诺；

- 人物承诺；

- 关系承诺；

- 谜题承诺；

- 道具承诺；

- 情感承诺；

- 视觉意象。

未回收时选择：

- 正式兑现；

- 合理转化；

- 明确否定；

- 删除最初承诺。

不能让重大承诺无声消失。
