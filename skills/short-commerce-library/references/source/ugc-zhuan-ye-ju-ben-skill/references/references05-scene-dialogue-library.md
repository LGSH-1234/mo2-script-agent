# 场景与对白技法库

## 一、场景价值

场景应改变状态，或改变人物与观众对状态的理解。

可变化：

- 目标；

- 信息；

- 关系；

- 权力；

- 情绪；

- 资源；

- 时间；

- 空间；

- 身份；

- 对事实的理解。

安静场和余波场可以用于消化损失、建立气氛和重新理解前一场。

## 二、进出点

优先晚进早出：

- 从行动、冲突或异常已开始处进入；

- 删除无功能的进门、落座和寒暄；

- 在决定、后果、关系变化或强烈意象出现后离场。

氛围建立有明确价值时，可以慢进。情感需要停留时，可以晚退。

## 三、场景模板库

### 谈判或审讯

试探 → 刺探 → 反制 → 权力变化。

### 行动任务

目标 → 阻碍 → 变招 → 后果。

### 关系冲突

接近 → 回避或误解 → 失控 → 余波。

### 悬疑调查

发现 → 验证 → 错误解释 → 新确认。

### 情感爆发

克制 → 触发 → 崩塌 → 坦白或重新伪装。

### 喜剧场景

建立期待 → 重复 → 升级 → 违背期待。

### 余波场

处理后果 → 暴露变化 → 形成下一行动方向。

模板是候选工具，不得强制每场凑齐节拍。

## 四、权力转移

检查：

- 谁先提出议题；

- 谁掌握信息；

- 谁控制出口或关键道具；

- 谁可以离开；

- 谁需要说服谁；

- 谁在场景末获得主动权。

权力变化可通过：

- 新证据；

- 沉默；

- 站位；

- 第三方出现；

- 信息暴露；

- 主动让步；

- 拒绝参与。

## 五、潜台词

适用于人物：

- 不敢说；

- 不能说；

- 不愿承认；

- 试探对方；

- 保护秘密；

- 维持体面；

- 欺骗自己。

潜台词不等于永远答非所问。

当直接表达构成认罪、突破、决裂、失控或成长时，直说更有力量。

## 六、对白功能

重要台词至少主要承担一项：

- 推动行动；

- 改变关系；

- 揭露信息；

- 隐藏信息；

- 塑造人物；

- 制造节奏；

- 完成回响。

允许日常话语存在，只要它承担防御、试探、拖延或关系功能。

## 七、对白节奏

可选择：

- 抢话；

- 打断；

- 沉默；

- 停顿；

- 重复；

- 故意听完；

- 答非所问；

- 突然直说；

- 动作代替回答；

- 长句后接短句；

- 一个人失控而另一个人不回应。

不要求每场都有打断。

## 八、语言指纹

为主要人物区分：

- 词汇范围；

- 句子长短；

- 是否使用比喻；

- 是否直接表达；

- 对谁说话更客气；

- 紧张时如何变化；

- 撒谎时的习惯；

- 不会说什么。

遮住角色名后，应尽量能判断说话者。

## 九、视觉化

将抽象心理转化为：

&gt; 身体动作 + 空间选择 + 道具行为 + 环境或声音反应。

避免所有人物都用攥拳、发抖、流泪表达情绪。

动作应具有角色特异性。

## 十、场尾推动力

场尾可以留下：

- 悬念；

- 决定；

- 后果；

- 关系变化；

- 情绪余波；

- 视觉回响；

- 喜剧回扣；

- 无声确认。

不强制每场使用电话响起、敲门或突然出现的新人物。
