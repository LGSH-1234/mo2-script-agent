# 美食吃播 ASMR 广告 · 极速上手指南（skill-intro.md）

> **一句话定位**：以 TikTok/抖音爆款美食吃播 ASMR 为标杆，用极致食物微距特写、真实咀嚼酥脆 ASMR 声场、大口爆汁拉丝断面与满足吃播表情，把美食转化为可见的食欲种草欲望。**食欲即钩子，声音即沉浸，爆汁即高潮。**

## 🚀 30 秒上手流程

1. **锁基准资产**：先定 `@CHAR_FOODIE`（美食博主 Model Card）+ `@FOOD_HERO`（招牌料理）+ `@SCN_TABLE`（暖调餐桌）+ `@PROP_UTENSIL`（餐具道具），一次性锁定，全程 @ 引用禁止链式改（食物特写与吃播须同一份食物、同一张脸）。
2. **选文生图版本**：默认用 `SKILL.md §二` 的 MJ v8 专属版或常规通用版；用户点名"角色资产卡/Model Card/定妆卡"时才输出第三版本（10 格）。
3. **写剧本**：套四段式吃播——①食物诱人特写开场 → ②大口吃播 ASMR → ③断面爆浆美食高潮 → ④食谱店铺种草 CTA（详见 `02-viral-script-hooks.md`）。
4. **生成视频**：套 `SKILL.md §三` 的 11 段式多参引擎，**除台词外整体描述必须用中文**，竖屏 9:16 手机原生，逐段注入食物质地动力学 + 光影五子层。
5. **配音效**：ASMR 咀嚼音/酥脆音/爆汁音 + 轻柔 BGM + 满足口播（详见 `03-sound-design-asmr.md`）。

## 🎯 五大不可动摇配方速查

| 配方 | 数值锚点 |
|---|---|
| **暖调食欲光** | 暖调柔光箱右侧 40° 3800K CRI 95 显油亮质感，热气逆光后方 160° +1.2 档边缘光晕，Key:Fill 2:1 通透食欲 |
| **微距食物质感特写** | 手机竖屏微距 100mm 等效 T2.8 焦点锁酱汁光泽，齐桌高度 0.9m，方位角 20° 四分之三侧，竖屏 9:16 |
| **真实咀嚼 ASMR** | 咀嚼音/酥脆音/爆汁音/切菜音真实录制，声画同步精准，纯食物空镜 AU 转译为食物质地动力学并声明 `[本镜无角色主体]` |
| **爆汁拉丝高潮** | 断面微距特写爆汁飞溅/芝士拉丝垂坠/酥脆掉渣，食欲高潮顶点，暖调高饱和食欲色 |
| **满足吃播 AU** | 咬下 AU26 张口（C 级），满足 AU6+AU12 眯眼陶醉（D 级），回味 AU17（B 级），享受食物真实满足 |

## ⚠️ 三条红线
- **严禁食物失真**：真实食物质感须保留油亮/纹理/热气，绝不允许塑料假食物、人工假摆盘、失真配色。
- **严禁假吃摆拍**：吃播须真实咀嚼吞咽，绝不允许假吃、催吐、浪费粮食式猎奇大胃王（平台严打）。
- **字幕铁律**：No subtitles.（字幕/食谱/店铺花字绝不由模型生成，须后期硬压）；台词保留原语言口语化，口型同步精准。
