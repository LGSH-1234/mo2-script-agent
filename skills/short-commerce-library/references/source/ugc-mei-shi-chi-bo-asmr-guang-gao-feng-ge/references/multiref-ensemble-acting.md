## 一、 资产 @ 引用与绝对禁止链式修改公理

### 1. 固定 @ 形式资产引用体系 (Asset @ Anchor System)
- 在项目开篇，必须通过首轮生图确立并固化四大资产底图，赋予唯一的具名 `@` 标签：
  - `@CHAR_角色名_基准`：锁定角色骨相面容、发型、身形比例与经典服饰剪裁；
  - `@PROP_道具名_基准`：锁定核心道具材质、工艺划痕包浆与物理结构；
  - `@SCN_场景名_基准`：锁定场景建筑透视网格、环境空间布局与光影基调；
  - `@MAT_材质名_基准`：锁定微观材质证据链（如冷铁深灰、钛金属倒角、越前和纸纤维）。
- **引用纪律**：后续所有分镜生图与图生视频（I2V）提示词中，必须显式以 `@形式` 联合输入引用，严禁脱离底图凭空描述！

### 2. 绝对禁止链式修改 (Ban Chained Modification — 资产漂移之源)
- ❌ **致命错误（Chained Modification 链式篡改）**：
  ```
  基准资产 → (修改) → 受伤态 → (再修改) → 重伤态 → (再修改) → 战损态
  ```
  *病理分析*：生成式模型具有迭代误差放大效应。每多一次修改 pass，模型就会平滑掉一层皮肤微观毛孔与真实织物纹理，色彩产生微漂移；改到第 3 次时，角色五官必演变为僵硬、高度对称的塑料死人脸，彻底丧失初始神韵！
- ✅ **唯一正确工业公理（Single-Source Axiom 单一基准衍生 — 每个状态只过两次模型）**：
  所有派生状态，必须**无条件、100% 以最初锁定的基准资产为唯一底图**一次性点修改直出：
  ```text
  基准资产 ──单次点修改──> @CHAR_角色_受伤
  基准资产 ──单次点修改──> @CHAR_角色_重伤
  基准资产 ──单次点修改──> @CHAR_角色_战损 (受伤+换装+湿 一次性从基准改出)
  ```
  场景与道具严格同理：
  ```text
  @SCN_基准日景 ──单次点修改──> @SCN_夜景
  @SCN_基准日景 ──单次点修改──> @SCN_暴雨战损
  @PROP_基准完好 ──单次点修改──> @PROP_断裂受损
  ```

## 二、 四层解耦多参矩阵调度规范

1. **四层独立解耦**：
   - 角色层（`@CHAR`）：仅负责面容表情与肢体运动动力学；
   - 道具层（`@PROP`）：仅负责器物交互与机械物理位移；
   - 场景层（`@SCN`）：仅负责空间纵深、光照角度与大气粒子；
   - 运镜层（`@CAM`）：仅负责焦段、运镜轨迹与快门开角。
2. **群戏阶梯错落站位**：
   - 多人同框时，依剧情重力分布安排前景、中景、后景阶梯错落站位，杜绝平行呆板站位；
3. **多向视线与避障阴影**：
   - 确保各角色的视线焦点各自独立且具备空间因果导向，严密计算角色脚下与物体接触面的投影与物理遮挡。

## 三、 11 段式多参 I2V 提示词骨架（Multi-Ref I2V 11-Step Skeleton）

| 段序 | 区块名 | 必填内容 |
|---|---|---|
| ① | 多参考素材锁定层 | 列出 `@CHAR` / `@PROP` / `@SCN` / `@MAT` 资产路径与一句话身份描述 |
| ② | 总时长与画幅 | `5-second / 16:9 / 24fps / 180° shutter` |
| ③ | 时间轴分段 [0.0s-X.Xs] | 每段动作、位移、表情变化（中文描述） |
| ④ | FACS/AU 表演微动作 | AU 编号 + A~E 强度 + 0.2s 视线先导 + AU45 眨眼抑制 |
| ⑤ | CineDance 运镜与光学 | 焦段、运镜轨迹、快门开角、光圈、滤镜 |
| ⑥ | 光影角度量化 | 主/辅/轮廓/底光方位角 + 俯仰角 + 距离 + 修饰器 + 光比 |
| ⑦ | 色温与显色 | Kelvin + CRI + 白平衡偏移 |
| ⑧ | 微观质感证据链 | 每种材质 ≥3 条微观物理证据 |
| ⑨ | 大气体积介质 | 湿度、粒子、体积光、大气透视 |
| ⑩ | 台词与声音 Foley ASMR | 同期声台词（中文）+ 拟音层 + 环境声 |
| ⑪ | 全局负向禁止项 | No subtitles / No music / No BGM / 风格反制词 |

## 四、 ⭐ V4.1 多图参考图生视频提示词中文描述铁律（MANDATORY）

> **用户级系统铁律**：图生视频阶段（I2V）与多图参考生视频阶段（Multi-Ref I2V），提示词**除台词（Dialogue）外，整体描述必须用中文表示**。

### 4.1 中文强制范围
- ✅ **必须中文**：时间轴分段描述、FACS/AU 表演微动作、CineDance 运镜与光学、光影角度量化、色温显色、微观质感证据链、大气体积介质、全局负向禁止项；
- ✅ **允许英文**：`@CHAR` / `@PROP` / `@SCN` / `@MAT` 资产标签名（保持引用一致性）、技术参数单位（如 `45°`、`T2.0`、`5600K`、`CRI 98`、`180° shutter`、`f/2.0`）、AU 编号（`AU4_D`）、镜头型号（`Cooke Panchro/i 40mm`）、摄影机型号（`ARRI ALEXA 35`）；
- ✅ **台词例外**：角色对白、旁白、画外音 VO 保持原语言（中文广告用中文台词，英文广告用英文台词），并用引号 `"…"` 显式标注。

### 4.2 标准输出模板（中文描述 + 英文台词例外）

