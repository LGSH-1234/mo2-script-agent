# 美食吃播 ASMR 3D 白模与轨迹锁定（whitebox-3d-rendering-guide.md）

1. **食物质感解算锁定**：先用 3D 白模（greybox）锁定 `@FOOD_HERO` 招牌料理的形态基准与 `@CHAR_FOODIE` 面部骨相基准，食物质感用真实 PBR（酱汁次表面散射 SSS/油亮高光/酥脆凹凸/芝士黏连），确保食物特写与吃播为"同一份食物"（严禁食物漂移失真）。
2. **爆汁拉丝动力学**：爆汁飞溅用流体粒子解算，芝士拉丝用柔体/黏性流体解算（黏连垂坠拉丝），热气升腾用体积雾/流体模拟，酥脆掉渣用刚体碎块解算，确保食物质地动力学物理可信诱人。
3. **咀嚼咬合动作轨迹**：@CHAR_FOODIE 夹起食物送入口中、咬合咀嚼的动作须用动画曲线锁定关键姿态与轨迹，手部/餐具/口部对齐，咀嚼节奏与 ASMR 音对齐，避免手部穿模与动作僵硬。
4. **暖调食欲光渲染**：暖调柔光箱须用面光源模拟——右侧 40° 3800K 食欲塑形显油亮高光、热气逆光后方 160° +1.2 档边缘光晕、Key:Fill 2:1 通透食欲，暖琥珀偏置调色，确保食物油亮食欲光落地。
5. **真实食物质感 PBR 工作流**：食物用真实 PBR（酱汁光泽/食材纹理气孔/酥脆碎屑/热气氤氲，拒绝塑料假食物），餐具/桌面真实材质，皮肤暖调真实拒绝磨皮，确保微观质感证据链落地。
6. **单一源公理铁律**：@CHAR_FOODIE/@FOOD_HERO/@SCN_TABLE/@PROP_UTENSIL 的 3D 资产模型一旦锁定为基准，所有镜头状态（开场特写→吃播→断面高潮→CTA）从同一基准模型渲染，严禁链式修改导致面部骨相/食物质感漂移。
