# 美食吃播 ASMR 剧本钩子（02-viral-script-hooks.md）

1. **四段式吃播骨架（20 秒）**：①[0-4s] 食物诱人特写开场（热气/爆汁/拉丝钩子）→ ②[4-9s] 大口吃播 ASMR（咀嚼/酥脆音）→ ③[9-15s] 断面爆浆美食高潮（满足表情）→ ④[15-20s] 食谱店铺种草 CTA，食欲递进至高潮收尾。
2. **3 秒钩子（食欲特写）**：开场必须用最诱人的食物特写锁住停留——热气升腾、酱汁流淌、爆汁拉丝、金黄酥脆的极致质感，配"这也太香了吧！"式食欲花字（后期硬压），3 秒内触发"想吃"冲动。
3. **吃播 ASMR 段落**：大口咬下的真实咀嚼音/酥脆音是沉浸核心，@CHAR_FOODIE 满足表情 + 食物特写交替，边吃边口语化点评口感（"外酥里嫩""爆汁了"），真实吃货感而非念稿广告腔。
4. **断面高潮模板**：食欲高潮靠"断面瞬间"——掰开/切开/咬断的微距特写，爆汁飞溅、芝士拉丝垂坠、内馅流淌、酥脆掉渣，配满足眯眼陶醉表情，是全片记忆点与转发触发点。
5. **种草 CTA 收尾**：满足回味后口播推荐食谱/店铺/购买清单，@FOOD_HERO 与品牌定格，配"链接在哪""求食谱"式互动召唤花字（后期硬压），把食欲转化为购买/到店行动。
6. **单一源公理铁律**：所有镜头必须从 `@CHAR_FOODIE` 基准博主资产一次性生成，食物特写与吃播面部骨相 100% 一致（同一张脸），@FOOD_HERO 招牌料理在特写与吃播保持基准一致（同一份食物），严禁链式修改导致面部/食物漂移。
