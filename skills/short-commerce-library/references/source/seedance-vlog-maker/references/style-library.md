
# 风格库

本文件提供各类片型风格的表达模板。根据用户需求选择并组合，把匹配的句式写入 Prompt。

## 1. 旅行 / 旅居 Vlog

适合关键词：泰国旅居、城市漫游、新朋友、周末游玩、海边、夜市、咖啡馆、街头、美食

表达方式：
```
轻松、有网感、生活流、真实旅拍、朋友之间自然互动，画面有阳光、热带城市、街边小店、夜市灯光和松弛感。
```

色彩方向：阳光感、热带色彩、明亮温暖、轻微胶片质感

节奏方向：轻快、卡点、生活流，有自然的情绪递进

## 2. 手绘动态涂鸦抠像风格

适合关键词：手绘涂鸦、动态贴纸、抠像、网感、趣味 vlog、图片微微动起来

表达方式：
```
在保持原图人物和场景高度一致的基础上，为人物周围添加手绘线条、动态箭头、小星星、表情贴纸、旅行标签、手写文字和轻微弹跳感。人物可做轻微 live photo 动态，如眨眼、发丝微动、衣角轻摆、镜头轻推拉，但不要改变原图人物五官、服装、姿态和背景结构。
```

贴纸元素参考：手绘箭头、小星星、波浪线、旅行标签、拍立得边框、趣味表情贴纸、地图线条

## 3. 电子相册

适合关键词：电子相册、15 秒相册、照片合集、回忆感、参考 BGM

表达方式：
```
以照片为主体，使用轻微推拉、平移、景深、胶片闪白、纸张翻页、节拍卡点等方式，让静态图片形成连贯相册感。
```

转场参考：胶片闪白、拍立得翻页、快门声、滑动切换、节拍卡点

色彩方向：保持原图色彩，可轻微增强亮度、对比度和氛围

## 4. 参考视频复刻

适合关键词：参考 vid1、BGM 也用一样的、节奏同款、转场类似、风格参考

表达方式：
```
参考 vid1 的整体剪辑节奏、镜头切换密度、BGM 情绪、转场方式和画面氛围，但主体内容使用 img1-imgN，不复制 vid1 中的具体人物身份或无关画面。
```

BGM 复刻表达：
```
音频参考 vid1 的 BGM 情绪、节奏速度、段落起伏和卡点方式，尽量保持同款音乐氛围和剪辑节拍。
```

## 5. 音频与 BGM 编排参考

用户要求"生成具有网感的趣味音频或者 BGM"：
```
BGM 使用轻快、有网感、适合旅行 vlog 的节奏，带有热带鼓点、轻电子、俏皮采样和轻松律动。节奏与画面切换卡点，开场有轻微 whoosh 音效，中段加入快门声、手绘贴纸弹出声、朋友笑声氛围，结尾用温暖上扬的音乐尾音收束。
```

用户要求"不要 BGM"：
```
不要添加 BGM，只保留用户提供的原始音频或环境声。
```

用户要求"不要字幕"：
```
不要生成字幕，不要自动添加歌词字幕，不要添加大段文字说明。
```

## 落 Prompt 前自检

- 风格描述是否与用户关键词匹配？
- 如果用户要求原图一致，是否写入了原图一致性控制条款？
- BGM 描述是否与用户要求一致（生成/复刻/不要）？
- 贴纸和文字是否避免遮挡人物脸部？
- 如果用户要求"干净高级"，是否减少了贴纸和花字？
