
# 深度视频运镜复刻指南

深度视频（近亮远暗灰度）承载了源视频的**运镜轨迹、主体动作、画面节奏**，但不含颜色、纹理、身份信息——所以能把"镜头语言"从"画面内容"里剥出来，换上全新的人物/场景复刻同款。

## 一、Prompt 骨架（固定句式）

```
@视频1 严格按照深度视频的运镜和动作，使用@图片1 和 @图片2 的人物或场景进行视频复刻。[画风与氛围一句]。保持无字幕，避免画面生成字幕，不要生成水印。
```

- **第一句是固定骨架**："严格按照深度视频的运镜和动作"不得改写、不得删"严格"二字——这是让模型贴着深度轨迹走的关键指令。`@视频1` 直接引用，句首禁加"参考"二字（会被误判为参考任务，丢失逐帧对齐）。
- 参考图数量按实际素材增减：只有人物图一张就写"使用@图片1 的人物"；人物+场景两张则写"使用@图片1 的人物和@图片2 的场景"。每张图在句中的角色（人物/场景）必须点明。
- **画风与氛围一句**：写目标风格（如"写实电影感""2D 日漫风格"）与光线氛围，防止风格漂移。不要描述具体动作和镜头——动作与运镜以深度视频为准，文字另写一套只会打架。
- 结尾防崩固定尾注照抄：`保持无字幕，避免画面生成字幕，不要生成水印`。

## 二、生视频参数清单（逐项检查）

| 参数 | 取值 | 说明 |
|------|------|------|
| `Prompt` | 上述骨架 | `@视频1`/`@图片N` 编号与 List 顺序一一对应 |
| `VideoList` | `[深度视频路径]` | 必填，只放深度视频这一个 |
| `ImageList` | `[人物图, 场景图]` | 至少 1 张；多人物各 1 张，编号在 Prompt 中点明 |
| `Duration` | 深度视频时长（秒，向上取整） | 从脚本 stdout 的 `wrote` 行读时长；超过 {{.max_video_duration}} 时先裁剪深度视频再复刻 |
| `Ratio` | 按深度视频宽高比就近选 | 1440x720→16:9，1080x1920→9:16 |
| `Resolution` | `720p` | 与深度视频规格对齐 |

## 三、参考图要求

- **用户上传的图**：直接用。人物图优先选正面、主体完整、无遮挡的；人脸重要时可裁出人脸区域作为额外参考图防 ID 漂移。
- **AI 生成参考图**（用户选"帮我生成"）：
  - `sandbox_generate_image` 生成，`OutputRatio` 与深度视频宽高比一致；
  - 人物图：全身、姿态自然、纯色或简单背景（避免背景元素被误当场景）；
  - 场景图：空场景无人物，视角与源视频首帧构图接近；
  - 生成后 present 给用户过目再进入生视频（人物形象是复刻的身份锚点，错了整片报废）。

## 四、常见问题

| 现象 | 处理 |
|------|------|
| 用户想保留原片环境/场景 | 深度视频不携带环境信息，向用户说明后从 720p 视频抽一帧无主体遮挡的画面作场景参考图传入 ImageList：`ffmpeg -y -ss <秒> -i upload/用户视频_720p.mp4 -frames:v 1 scene_ref.png` |
| 成片动作对但运镜漂 | 确认 Prompt 首句未加"参考"、未删"严格"；深度视频放 VideoList 唯一位 |
| 人物长相不稳 | 人脸区域单独裁剪加一张参考图；人物图放 ImageList 首位并在 Prompt 前部点名 |
| 画面出现灰度/黑白倾向 | 画风句里补一句"画面为彩色"，明确目标色彩风格 |
| 成片时长与深度视频不符 | Duration 必须显式传深度视频时长，不要留默认值 |
| 复刻多个不同人物版本 | 同一深度视频可多次调用，仅换 ImageList 与人物描述，逐个生成 |
