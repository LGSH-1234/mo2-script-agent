Seedance 2.0 提示词生成指导（最终优化版）

基于你提供的三组高质量提示词的结构特点，结合我们之前建立的全部方法论，以下是将两种结构优势融合后的**完整指导文档**。

### 一、核心方法论：三层金字塔结构 + 导演式分镜

优秀提示词的本质是**用导演思维编写分镜脚本**，而非简单描述画面。其核心结构可抽象为以下三层：

```

┌─────────────────────────────────────────────────────────────────┐

│ 顶层：全局视觉与音频规范                                          │

│ → 风格、画质、帧率、声音设计原则（全局常量）                        │

│ 示例："电影级别专业构图，极致光影，超高清，30帧，动漫电影，           │

│       无字幕，无BGM，仅音效"                                      │

├─────────────────────────────────────────────────────────────────┤

│ 中层：资产与角色绑定                                              │

│ → 图片/音频素材与故事角色的映射关系                                │

│ 示例："图片2的音色为音频1，图片3音色为音频2，图片1体型为正常猫咪大小" │

├─────────────────────────────────────────────────────────────────┤

│ 底层：精确时间轴镜头序列                                          │

│ → 每个镜头的：起止时间 + 景别 + 运镜 + 动作 + 音效触发点            │

│ 示例："第一个镜头总时长为2s，从第2s开始切镜头拍摄第二镜头..."        │

└─────────────────────────────────────────────────────────────────┘

```

这三组提示词的核心成功要素：**将“导演意图”拆解为AI可执行的精确指令**，而非让AI自由发挥。

### 二、从优秀案例中提取的八大核心原则

#### 原则1：全局规范前置（顶层约束）

所有优秀提示词都以**统一的视觉和音频规范**开头，作为全局常量：

```

✅ 正确格式：

电影级别专业构图，极致光影，超高清，30帧，动漫电影，无字幕，

不要出现背景音乐和BGM，只需要出现音效而不是音乐，场景内有微风。

❌ 错误格式：

做一个好看的动画视频（没有具体规范）

```

**要点**：

- 画质要求：`电影级别专业构图 / 极致光影 / 超高清 / 8K`

- 帧率设定：`30帧 / 60fps / 120fps升格`

- 风格类型：`动漫电影 / 写实CGI / 3渲2风格`

- 字幕控制：`无字幕，不要出现字幕`

- 音频控制：`无BGM，只需音效`

#### 原则2：资产编号映射（中层绑定）

AI无法理解“主角”“反派”这类抽象概念，必须用**具体的素材编号**绑定：

```

✅ 正确写法：

图片2的音色为音频1，图片3音色为音频2，图片1体型为正常猫咪大小，

大背景为图片4。

❌ 错误写法：

主角的声音很好听，猫咪很小（AI不知道该用哪个素材）

```

**映射内容包括**：

- 角色外观：`图片X` / `@图片X`

- 角色音色：`音频X` / `@音频X`

- 体型比例：`图片1体型为正常猫咪大小`

- 场景背景：`大背景为图片4` / `背景为图片4的墙壁`

#### 原则3：精确时间轴控制（底层核心）

每个镜头必须有明确的起止时间和切换点，形成**连续无重叠的时间线**：

```

✅ 正确写法：

第一个镜头总时长为2s，从第2s开始切镜头拍摄第二镜头...

第二镜头总时长为3s，从第5s开始切镜头拍摄第三镜头...

第三镜头总时长为2s，从第7s开始拍摄第四镜头...

❌ 错误写法：

先拍一个镜头，然后切另一个镜头（无时间控制）

```

**时间轴公式**：

- 镜头N起始时间 = 前N-1个镜头时长之和

- 镜头N结束时间 = 起始时间 + 本镜头时长

- 切换标记：`从第X秒开始切镜头拍摄第Y镜头`

#### 原则4：镜头语言专业化

使用专业术语代替模糊描述：

| 模糊描述（❌） | 专业术语（✅） |

|----------------|----------------|

| “拉近一点” | “缓慢推近” / “推至特写” |

| “转着圈拍” | “半圈环绕” / “360度旋转运镜” |

| “从上面拍” | “俯拍” / “大俯拍” / “上帝视角” |

| “跟着他跑” | “稳定跟拍” / “手持跟拍” |

| “脸的特写” | “近景” / “面部特写” / “极致特写” |

| “从背后拍” | “过肩镜头” / “后背视角” |

| “第一人称” | “POV视角” / “第一人称主观视角” |

**你的案例中的优秀运用**：

- `拍摄图片2正面上半身近景`

- `仰拍，近景拍摄图片2蹲下来的样子`

- `从图片2第一人称POV视角拍摄图片1`

- `过肩镜头，从图片3背对镜头的肩膀处拍摄`

#### 原则5：动作具体化与序列化

将抽象动作拆解为**具体的动作序列**，并按时间顺序描述：

```

✅ 正确写法（你的案例）：

四处张望，微微挑眉 → 看向地面，缓缓蹲下 → 微笑着伸手拍了拍脑袋

✅ 正确写法（动作序列）：

四肢着地趴在地上 → 尾巴竖起来 → 尾巴抖了抖 → 表情由思索变成微微惊讶

❌ 错误写法：

猫跑开了（太模糊）

```

**动作描述公式**：

- `[角色]进行[具体动作1]，[具体动作2]，表情由[状态A]变为[状态B]`

- `在这一刻开始切镜头拍摄[动作关键帧]`

#### 原则6：多角色调度与互动

当场景中有多个角色时，明确描述**每个角色的位置、动作和互动关系**：

```

✅ 正确写法（你的案例）：

拍摄图片2和图片3二人在图片4场景内一边走一边四处打量的样子，

图片2看向地面，缓缓蹲下，前景为图片1，图片1蹲坐在图片2的脚边，

图片2看着图片1，微笑着伸手拍了拍图片1的脑袋。

❌ 错误写法：

两个人带着猫走路（不明确）

```

#### 原则7：音效与台词精确触发

明确标注**音效、台词的触发时间点和具体内容**：

```

✅ 正确写法（你的案例）：

图片2的声音在画外传来，声音有些急促，催促道：“快回，快过来了！”

在这一刻开始切镜头，拍摄图片3被吓了一跳，连忙看向画面右侧。

✅ 正确写法（台词规范）：

图片2淡淡笑着说道：“B梦，去定位能源核心的位置。”

❌ 错误写法：

有人说了一句话（不明确）

```

**音频规范**：

- 环境音：`场景内有微风`

- 角色音色：`图片2的音色为音频1`

- 画外音：`图片2的声音在画外传来`

- 语气描述：`声音有些急促` / `淡淡笑着说道`

#### 原则8：特殊效果精确标注

对于慢动作、子弹时间等特殊效果，**明确标注**在哪个时刻、哪个动作上触发：

```

✅ 正确写法（你的案例）：

就在图片3经过图片5场景内墙上贴着的一张照片时，切镜头，

从照片的位置拍摄图片3，拍摄图片3跑步的姿势，子弹时间，慢动作特写，

图片3头发舞动，唯美，缓缓侧着头看向镜头。

❌ 错误写法：

这里要慢动作（不明确）

```

**特效触发公式**：

- `就在[角色]进行[特定动作]时，切镜头`

- `在这一刻开始[特效类型]，[特效描述]`

| 环境音 | `场景内有微风` / `场景内有鸟鸣` | 氛围音效 |

#### 4.2 中层（资产绑定）填写要点

| 项目 | 示例 | 说明 |

|------|------|------|

| 场景背景 | `大背景为图片4` / `背景为图片4的墙壁` | 明确场景素材 |

| 特殊资产 | `以图片5分镜为基础` | 参考已有分镜 |

#### 4.3 底层（镜头序列）填写要点

**每个镜头必须包含以下要素：**

| 要素 | 示例 | 说明 |

|------|------|------|

| 表情变化 | `表情由思索变成微微惊讶` | 情绪递进 |

| 台词/音效 | `说道：“具体台词”` / `画外音传来` | 精确触发 |

### 七、快速开始清单

按以下顺序准备，即可生成专业级提示词：

- [ ] **第一步：确定全局规范**

  - 视觉风格：`电影级别专业构图，极致光影`

  - 画质帧率：`超高清，30帧` / `8K，60fps`

  - 视频类型：`动漫电影` / `写实CGI`

  - 音频规则：`无字幕，无BGM，只需音效`

  - 环境音：`场景内有微风`

- [ ] **第二步：绑定资产**

  - 角色音色：`图片X的音色为音频X`

  - 体型比例：`图片X体型为正常猫咪大小`

  - 场景背景：`大背景为图片X`

- [ ] **第三步：规划时间轴**

  - 计算总时长（所有镜头时长之和）

  - 确定每个镜头的起止时间

  - 标注切换点：`从第X秒开始切镜头`

- [ ] **第四步：填写每个镜头**

  - 景别：`正面上半身近景` / `中景` / `大俯拍`

  - 拍摄对象：`图片2` / `图片2和图片3二人`

  - 动作描述：`四处张望，微微挑眉` / `缓缓蹲下`

  - 表情变化：`表情由A变为B`

  - 台词/音效：`说道：“具体台词”`

- [ ] **第五步：检查与优化**

  - 时间线是否连续无重叠？

  - 动作描述是否具体可执行？

  - 资产绑定是否完整？

  - 是否标注了所有切换点？

  - 是否有多余的BGM/字幕描述？
