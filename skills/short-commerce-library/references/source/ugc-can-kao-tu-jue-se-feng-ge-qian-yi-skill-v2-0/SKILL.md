参考图角色风格迁移 Skill v2.1

## 一、Skill 概述

本 Skill 用于基于参考图（真人照片、二次元插画、像素图等）提取角色核心设定，通过**纯提示词驱动**生成目标风格的角色图像，支持风格迁移、半身补全、画风转换等场景。核心特点是「参考图只提供设定，不做最终底图」，在风格化的同时最大程度保留角色辨识度。

## 二、适用范围

### 2.1 支持的输入参考图类型


|              |        |                           |
| ------------ | ------ | ------------------------- |
| 输入类型         | 支持度    | 处理逻辑                      |
| 真人照片         | ✅ 完全支持 | 提取人物、服装、姿态、场景，转换为目标风格     |
| 二次元插画 / 动画截图 | ✅ 完全支持 | 提取角色设定、服装结构、标志性特征，重建为目标风格 |
| 像素风角色图       | ✅ 完全支持 | 提取轮廓、配色、动作，重建为目标风格        |
| 纯文字设定        | ✅ 完全支持 | 直接基于文字生成，无需参考图            |


### 2.2 支持的输出风格

- 二次元类：赛璐璐动画、厚涂插画、复古动画、美少女插画
- 真人类：真人电影剧照、Cosplay 写真、商业时尚大片
- 其他类：像素风、概念艺术、漫画分镜

## 三、核心设计原则

1. **纯提示词驱动原则**：最终生成环节仅使用提示词，不传入参考图作为底图，避免原图残留与风格污染
2. **角色辨识优先原则**：角色核心识别特征优先级高于画风，风格化不能丢失角色身份
3. **分级锚点原则**：将角色特征分为不同优先级，优先保证高权重特征准确
4. **自然真实原则**：真人化输出避免塑料感、违和感，二次元输出保留原作辨识度

## 四、完整工作流程

```Plain
接收参考图 → 询问目标风格 → 提取角色辨识锚点 → 分级：一级硬锚点/二级造型锚点/可变项
→ 确定输出构图与比例 → 编写完整正向+负面提示词 → 展示给用户确认 → 用户确认后调用 image_gen 纯提示词生成
```

### 4.1 步骤详解

1. **参考图接收**：用户上传参考图后，先读取画面主体、角色特征、服装、姿态与场景。
2. **询问目标风格**：在分析完成后，必须先询问用户想要的输出风格，例如真人电影感、Cosplay 写真、二次元赛璐璐、像素风、概念艺术等。
3. **锚点提取**：拆解参考图，列出所有角色特征并分级。
4. **风格匹配**：根据目标风格调整特征的写实度 / 夸张度。
5. **提示词编写**：按照规范结构编写完整正向与负面提示词，并完整展示给用户。
6. **生成确认**：展示提示词后，必须询问用户是否确认生成；用户确认后再执行。
7. **结果校验**：核对核心锚点是否保留，给出优化方向。

## 五、角色辨识锚点分级体系

### 5.1 一级锚点：角色身份硬特征（必须优先保留）

直接影响角色辨识度的核心特征，提示词中必须前置描述，且明确**数量、位置、形态**。


|            |                    |                                                                                                                                                             |
| ---------- | ------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 类别         | 示例                 | 描述规范                                                                                                                                                        |
| 面部标记       | 泪痣、伤疤、雀斑、异瞳        | 必须说明「数量 + 精确位置 + 视角说明 + 数量否定」 例：`one tiny dark mole exactly beneath her left eye (right side for viewer), exactly one facial mole, not two, no extra moles` |
| 发型结构       | 呆毛、双马尾、齐刘海、姬发、特定分缝 | 必须说明「数量 + 位置 + 形态」 例：`one single iconic ahoge on top center of head, natural slightly curved shape`                                                         |
| 核心配色       | 发色、瞳色、服装主色         | 明确色相与饱和度 例：`vibrant orange-red twin tails, bright blue eyes`                                                                                                |
| 标志性配饰      | 眼罩、眼镜、标志性发饰、项圈     | 明确佩戴位置与形态 例：`black medical eye patch over her right eye`                                                                                                    |
| 标志性身材 / 比例 | 特定身高、体型特征          | 符合目标风格的前提下保留识别度                                                                                                                                             |


### 5.2 二级锚点：造型特征（尽量保留）

影响造型完整度的特征，可根据目标风格适度调整。


|      |                 |
| ---- | --------------- |
| 类别   | 示例              |
| 服装结构 | 水手服、旗袍、战斗服、特定剪裁 |
| 服装细节 | 花纹、编号、配饰、面料质感   |
| 姿态动作 | 站姿、坐姿、手势、身体朝向   |
| 表情气质 | 冷酷、活泼、御姐、呆萌     |


### 5.3 可变项：可风格化调整

不影响角色身份的元素，可根据目标风格自由优化。


|      |                |
| ---- | -------------- |
| 类别   | 示例             |
| 画风   | 赛璐璐、写实、像素、厚涂   |
| 背景   | 可替换、可优化、可虚化    |
| 光影   | 可根据风格调整软硬、方向   |
| 构图   | 可调整景别、镜头角度     |
| 画面质感 | 动画截图、电影胶片、游戏立绘 |


## 六、分场景执行规范

### 6.1 真人参考 → 二次元风格

- 提取真人的服装、姿态、场景，重构为二次元角色设计
- 优化面部比例为二次元审美，保留真人的核心气质
- 提示词重点：`character design, clean lineart, cel shading, anime proportions`

### 6.2 二次元参考 → 真人风格

#### （1）真人电影剧照感

- 弱化二次元夸张比例，还原为真实人体结构
- 服装、配饰保留设计，但改为真实材质质感
- 提示词重点：`cinematic film still, natural skin texture, real fabric, realistic human proportions`

#### （2）Cosplay 写真感

- 更高程度还原角色造型、配色、细节
- 保留二次元角色的标志性特征，兼顾真实感
- 提示词重点：`cosplay portrait, accurate costume, character likeness, professional photography`

### 6.3 像素风参考 → 任意风格

- 提取角色轮廓、配色、动作核心
- 目标风格重建时保留原角色的识别特征
- 像素输出时明确：`pixel art, limited color palette, blocky shading, clear silhouette`

### 6.4 半身图补全全身规范

1. 必须明确标注「保留所有一级辨识锚点不变」
2. 补全部分符合角色设定与整体风格
3. 提示词必须包含：`full body, preserve all iconic facial features and hairstyle`
4. 禁止补全时丢失面部痣、疤、呆毛等小特征

## 七、提示词编写规范

### 7.1 正向提示词结构模板

```Plain
[一级锚点：发型+面部核心特征],
[二级锚点：服装+姿态+表情],
[场景与环境],
[目标风格关键词],
[光影与构图],
[画质强化词]
```

### 7.2 负面提示词规范

必须包含四类负面约束：

1. **画质排除**：`low quality, worst quality, blurry, text, watermark, logo`
2. **风格排除**：根据目标风格排除冲突画风，例真人输出加 `anime, cartoon, illustration`
3. **人体错误**：`deformed anatomy, wrong proportions, extra limbs, missing fingers`
4. **锚点反向约束**：针对一级锚点的错误情况，例：`no extra moles, no missing eye patch`

### 7.3 编写禁忌

- 禁止模糊描述核心特征，如只写「泪痣」不写数量位置
- 禁止一级锚点放在提示词末尾
- 禁止真人化输出不做人体比例修正
- 禁止半身补全不做特征保留声明

## 八、工具调用约束

### 8.1 标准调用规则

- 最终生成**必须使用** `image_gen`，纯提示词驱动
- 禁止默认使用 `image_edit` 传入参考图
- 参考图仅用于前期分析设定，不进入生成环节

### 8.2 例外情况

仅当用户明确要求「保留原图构图，只修改局部 / 改风格」时，才可使用 `image_edit`，且需在生成前说明。

### 8.3 比例参数规范

- 竖版角色：默认 3:4 或 9:16
- 横版场景：默认 16:9
- 正方形立绘：默认 1:1
- 用户指定比例按用户要求执行

## 九、质量校验清单

### 9.1 生成前校验

- 用户上传参考图后，已先询问目标风格
- 一级锚点是否全部提取并写入提示词
- 核心特征是否明确了数量、位置、视角
- 正向与负面提示词是否完整展示
- 是否已询问用户是否确认生成
- 是否使用了 `image_gen` 而非 `image_edit`
- 半身补全是否标注了特征保留

### 9.2 生成后校验

- 一级锚点是否全部正确保留
- 目标风格是否统一自然
- 人体结构是否合理
- 是否存在原图残留痕迹
- 构图与景别是否符合要求

## 十、常见问题与修正方案


|             |               |                                                              |
| ----------- | ------------- | ------------------------------------------------------------ |
| 问题          | 原因            | 修正方案                                                         |
| 泪痣 / 伤疤数量变多 | 模型默认对称生成，描述模糊 | 增加「exactly one, not two, no extra moles」多层否定，补充视角说明          |
| 呆毛丢失        | 特征权重低，放在提示词末尾 | 将呆毛等发型特征移至提示词开篇，明确数量形态                                       |
| 左右特征颠倒      | 模型以人物自身视角判断左右 | 补充「观众视角」说明，例：`right side for the viewer`                     |
| 真人化脸部违和     | 二次元比例直接套用     | 加入 `natural human facial features, realistic proportions` 约束 |
| 半身补全丢失细节    | 补全时模型重绘面部     | 明确加入 `preserve all iconic facial features` 声明                |
