
# Seedance 2.5 编译器

仅当活动运行时明确解析为 Seedance 2.5 家族时才加载。这是一份面向模型的编译层，而非创作工作流。根 Skill 掌管已确认内容、家族画像、请求数量、披露、授权与执行。

来源依据:《Seedance 2.5 提示词指南》，Lark 文档 `OsiUdR1OxoDqvnxsK8LczYx7nPd`，于 2026-08-05 在修订版 460 读取。

**先读 `_shared-compiler-rules.md`。** 它承载与版本无关的规则:编译器边界、主体与素材绑定、多图借鉴与局部修改、开启与使用动作、达人 / 产品角色分离、声音 / 字幕 / 文字规范、家族画像保真以及共享出口检查。本文件只补充 2.5 家族特有的内容。

## 生成控制

为每个实际请求解析出一份紧凑的控制计划:

```yaml
generation_control:
  task_type: generate | edit | extend | keyframe | one_click | transition
  duration_seconds:
  aspect_ratio:
  resolution:
  image_roles: []
  video_roles: []
  audio_roles: []
  first_frame_role:
  last_frame_role:
  preserve: []
  change: []
  dependency:
```

只保留生效且受支持的字段。每一段源视频、关键帧、白模参考、音频参考或转场端点，都必须已存在于已确认的素材计划中，或是一个已确认的派生依赖。

## 能力默认值

当运行时未暴露上限时，把 2.5 指南用作兜底:

- 混合参考素材总计最多 50 份;
- 最多 30 张图片，每张不大于 4K;
- 最多 10 段视频，输入总时长 30 秒;
- 最多 10 段音频，输入总时长 30 秒;
- 对视频 edit，指南推荐源视频在 20 秒以内，配 1-5 张参考图。

推荐的稳定范围小于硬性上限:1-8 个图片主体、1-5 个主要音频/视频主体，以及 1-5 张 edit 参考图。运行时证据会覆盖这些默认值。输入越多不会自动越好;只传入具有生效场景或控制角色的素材。

## 基础 Prompt 公式

在所选家族画像内部，表达:

`主体 + 动作/事件 + 可选场景/环境 + 可选视觉风格 + 可选镜头/剪切 + 可选声音`

从"要生成什么"开始。把主流程描述一次，只对决定性的动作补充细节。属于生成接口的参数不应在 Prompt 内重复，除非运行时要求，或执行包为求清晰而需要它们。

## 多素材分组

主体/素材绑定，以及按实际输入顺序使用的标签约定 `@图片N` / `@视频N` / `@音频N`，都在 `_shared-compiler-rules.md` 中定义。在 2.5 中，把复杂素材包组织为:

`逐素材职责 -> 主体映射 -> 类型分组 -> 重要主体定义 -> 逐场景使用`

对素材很多的情况，按 `【人物】`、`【产品/道具】`、`【场景】` 与 `【动作与声音】` 分组。然后为重复出现的重要主体建立一个紧凑的 `【主体设定】`。每个阶段或场景只列出它实际使用的素材。多素材控制意味着正确的选取，而非同时出现。

## 长视频阶段与时间

对一个 30 秒或事件密集的请求，优先采用连续的阶段，每个阶段只有一次主状态变化:

```text
【生成目标】
<类型、主要主体、事件概要>

【阶段一】
开始时：<可观察的初始状态>
主要事件：<一个主事件>
结束时：<人物位置、产品/道具归属、场景与声音状态>

【阶段二】
承接上一阶段：<必须延续的状态>
主要事件：<一个主事件>
结束时：<可观察的完成状态>

【阶段三】
主要事件：<回报、证明、记忆点,或 CTA 事件>
结束时：<最终的可见与可听状态>

【保持一致】
<身份、数量、着装、产品状态、道具归属、画面朝向、
空间、光线,以及声音关系>
```

仅对重要的 Hook 预算、交接、进出场、转场、对白或与节拍同步的事件使用时间戳。时间范围必须连续且不重叠;它们分配的是事件预算，而非逐帧精确的剪辑。不要让一秒钟承载多个复杂动作。

所有请求 Prompt 都使用从 `0s` 起算的请求本地时间。成片中的整体位置仍属于请求元数据。

## Generate、Edit、Extend 与 Keyframe 模式

### Generate

绑定已确认的参考素材，为每份素材指派角色，按场景选取素材，并描述事件阶段、镜头、声音、证明与结束态。保留权威身份与产品真实性，只允许已确认的改动。

### Edit

把源视频视为唯一主控素材:

```text
【编辑目标】<源、区间/物体/声音类别、精确改动>
【原视频职责】@视频1 是人物、场景、动作、
构图、镜头、遮挡、声音与事件顺序的唯一主控。
【目标素材职责】<每张目标图片/音频各自贡献什么>
【编辑范围】<仅限被界定的物体、区域、区间或声音类别>
【保持内容】<所有被保留的维度>
```

对替换，说明目标数量，并沿用原物体的出现时刻、路径、速度、遮挡与离场时机。对背景替换，只修改被保留主体之外的区域。对声音编辑，指明说话人或声音类别，并保留所有其它声音类别。

2.5 指南指出，视频 edit 会沿用源视频的比例与大致的源视频时长;这些数值无法单独设定，且时长可能有约 0.3 秒的浮动。若当前运行时 schema 与此不同，则以其为准，并在确认前披露实际的锁定情况。

### Extend

2.5 指南指出，extend 会沿用源视频比例，而延长时长仍可设定。界定方向:

- 向后/之后:第一帧生成画面直接衔接源视频尾部状态，随后开始新动作;
- 向前/之前:生成前置动作，并让最后一帧生成画面明确对齐源视频首帧。

描述边界构图、主体姿态/朝向、产品与道具状态、背景几何、镜头、光线、声音与运动趋势。其它参考素材可以定义身份或道具，但不能取代源视频的边界控制。同一主体保持为一个连续物体，数量与部件稳定。

### Keyframe

在多模态参考模式下，分别标识每个锚点:

```text
@图片1作为首帧，定义<起始构图与状态>。
@图片2作为尾帧，定义<结束构图与状态>。
@图片3用于<主体属性>，不改变首尾帧构图。
<从首帧到尾帧的连续动作路径>
```

指南指出，首帧比例锁定输出比例，而时长仍可设定。首帧与尾帧应共用同一比例。帧约束构图与状态，但不能取代运动、事件、声音或连续性指令。

对多个关键帧，先声明 `以@图片1至@图片N的顺序作为关键帧`，再分别定义每张图片的阶段结束态。独立关键帧控制的是顺序与关键状态，而非逐帧复刻。

## 高级参考模式

### 分镜网格

用网格来控制大致的镜头顺序与构图，而非精确复刻分格。优先用至多 15 个干净、少文字的分格。声明阅读顺序、被忽略的线稿/文字/占位维度，然后描述每个镜头的主体动作、景别/镜头、最终视觉风格与声音。

### 白模参考

在提示之前先分类:

- 粗白模:提供运动路径、走位、镜头、剪切、光线时机、声音节奏或空间关系;把每一处几何体映射到一个最终主体，并用已确认参考替换外观/世界;
- 细白模:保留完整的结构、动作、空间、镜头与剪切，同时重新渲染材质、颜色、人物、场景或 Style。

除非明确需要，否则不要沿用轨迹、坐标轴、操控件、镜头锥、灰模材质或空白背景。

### 一键成片

对以图片为主导的拼装，写作:

`素材职责 -> 图片顺序 -> 运动幅度 -> 剪辑节奏 -> 视觉包装 -> 声音`

指明顺序是固定的还是主题驱动的。保持主体/产品身份稳定，并使用克制的 Live 运动、视差、推/拉、横移或适合每张图片的局部动作。

### 无缝转场

界定前段源视频、后段源视频、触发动作、镜头方向与速度、形状/材质/光线/空间的可见变换、到达构图、运动趋势与声音交接。目标是生成连贯的转场，而非对两段源片做像素级完全一致的保留。

## 情绪与镜头

把情绪翻译成 2-4 个可观察线索，如眼神、眉、嘴、呼吸、台词表达、肩部紧张、手部动作或焦点转移。对多次情绪转折，把每次变化系到一个可见或可听的触发上。

常见镜头术语可直接使用。对不常见的术语，保留该术语并说明受影响的主体、可见变化、前景/背景关系、方向、速度与最终结果。可见效果比单靠镜头/光圈/快门数值更可靠。

## 2.5 出口检查

在 `_shared-compiler-rules.md` 的共享出口检查之外，另外执行以下检查:

- 生效的控制存在于运行时 schema 中，或是已披露的指南兜底。
- 长视频的各阶段各自承载一次主变化与一个可观察的结束态。
- Edit 使用单一主控素材与有界的 KEEP/CHANGE;extend 对齐边界状态;关键帧被逐一指派。
