
# 品牌片创意引擎与 Prompt 画像

当 `primary_specialist: brand_film` 时使用。归属边界与模型编译层交接是 [`_shared-profile-preamble.md`](_shared-profile-preamble.md) 中的共享规则;请先阅读它。本文件不额外添加归属声明。

## 目的

保留原始品牌片 Prompt 的指纹:一份紧凑、导演可读的处理方案,其中风格、镜头、材质、光线、运动、声音、产品象征以及最终品牌记忆保持可见,而不是被压平成一个通用请求。

## 专项创意引擎（先于 Prompt 画像）

品牌片不是“更精致的商品展示”。先完成这条推导：

`品类张力 → 受众压力/渴望 → 文化时机 → 品牌资产 → 商业片类型 → 视觉大创意 → 主角/世界 → 产品叙事功能 → 品牌证据 → 记忆句`

### 先做九个决定

1. **品牌任务**：新品认知、品类占位、品牌焕新、情感关联、价值主张、活动传播或产品欲望；
2. **品类张力**：受众在该品类里怕什么、渴望什么、反感什么陈词滥调；
3. **品牌资产**：可被反复识别的颜色、形状、动作、声音、材质、人物、仪式或语言；
4. **单一品牌主张**：只保留一个需要被记住的判断；
5. **表达形态**：真人实拍、CG/VFX、动态图形、动画、混合媒介、纪录片碎片或屏幕形式；
6. **商业片类型**：从感官产品片、奇观片、叙事生活片、情绪片、品牌宣言片、产品测试片、格式仿拟片中选一个主类型；
7. **产品叙事功能**：产品必须引发、证明、连接、打断、象征或化解事件；
8. **运动主脊**：整片由一种可识别的运动/材质/剪辑规则推进；
9. **最终助记**：末尾画面、动作、声音或短句必须从前面已埋元素生长，不是临时贴 Logo。

### 类型选择

- 产品形态、触感、味觉、香气或精密结构本身能承载欲望 → **感官产品片**；
- 需要瞬时传播、规模感或不可能画面，且产品能解释后果 → **奇观/VFX 片**；
- 关系、生活压力、仪式或文化情绪承载说服 → **叙事生活片**；
- 要建立季节世界、审美领地或态度 → **情绪片**；
- 品牌主张、群体或公共立场是核心 → **品牌宣言片**；
- 功能可通过可信条件与结果证明 → **产品测试片**；
- 熟悉媒体格式被产品改写能形成记忆 → **格式仿拟片**。

选一个主类型，其他类型最多贡献一个制作维度。不得把“电影感、质感、高级”当作创意。把类型翻译成镜头、光线、材质、剪辑、声音、主体和场景规则。

### 30 秒参考节奏

`0-3s 品牌世界/张力 → 3-8s 品类压力 → 8-14s 主角或世界展开 → 14-21s 产品/品牌机制可见 → 21-27s 后果或情绪回报 → 27-30s 助记收束`。

节奏可按时长缩放，但产品或品牌机制必须在转折前埋下。品牌片可无硬 CTA，却必须有具体品牌记忆。

### 专项退出标准

- 即使去掉 Logo，世界规则、品牌资产或产品行为仍能指回该品牌，而非任意“高级广告”；
- 产品/品牌导致了画面或情绪变化，不是可拆卸的尾帧 packshot；
- 只有一个主类型、一个运动主脊和一个最终助记；
- 至少有一个大胆而可执行的区别点：世界规则、视觉格式、声音规则、表演机制或材质行为；
- 品牌主张通过具体事件或证据成立，不靠万能大词。

## 必需载荷结构

按此顺序写出完整的 Prompt 载荷:

```text
【任务与成片】
<视频类型、请求本地时长、与 Prompt 相关时的交付比例、语言>

【标题】
<简短的工作标题>

【风格与视觉参考】
<媒介形式、真实度、镜头/构图规则、美术指导、色板/材质、
光线行为、剪辑节奏、转场质感,以及声音方向>

【场景】
<地点、时间、空间纵深、道具、氛围、光源,以及
产品或品牌资产在这个世界中所处的位置>

【主体】
<仅列出出现的、反复出现的人物、产品、物体或品牌符号>

【各个分镜的具体内容】
阶段或镜头1：
- 拍法：<景别、角度、镜头运动、构图、节奏>
- 画面内容：<可见事件、材质/光线行为、完成状态>
- 品牌/产品露出：<结构性的品牌或产品职责>
- 声音：<对白/旁白、环境声、拟音、音乐、静默>

<对每个已确认的节拍重复>

【最终品牌记忆】
<记忆点画面、短语、手势、声音、产品状态,或品牌收束定格>
```

不要把 `风格与视觉参考` 简化为情绪形容词。把每一个具名风格翻译成制作语法。把镜头专属的手法放进各自的分镜里,而不是另加一段无关的镜头术语表。

## 家族投射

- Hook 用开场画面或声音建立品牌张力，并可作为世界规则或母题贯穿；后续每次出现都要新增品牌意义、产品后果或助记价值。
- Style 在这里最强,必须统领整个视听系统。
- Play 成为品牌主导的运动、材质、世界观或转场规则。
- 产品或品牌必须引发、组织、象征、证明或收束这部片子。
- 当已确认的职责是品牌回想时,以记忆为主导的结尾可以刻意省略硬 CTA。

## 检查

- 一个成片构造与一条运动主脊拥有整部片子。
- Style 通过镜头、美术指导、材质、光线、剪辑与声音可见。
- 产品或品牌不是一个可拆卸的结尾产品特写。
- 最终记忆点从更早埋下的元素中生长而来。
- 精确 Prompt 仍与已确认的故事、分镜、素材和交付一致。
