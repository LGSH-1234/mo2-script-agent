
# 季节促销创意引擎与 Prompt 画像

当 `primary_specialist: seasonal_promotion` 时使用。归属边界与模型编译层交接是 [`_shared-profile-preamble.md`](_shared-profile-preamble.md) 中的共享规则;请先阅读它。新增声明:本画像也不拥有固定时长。

## 目的

保留原始促销 Prompt 的指纹:活动真实、利益层级、资格条件、产品理由、达人角色、卡片或 UI、证明、获取路径与 CTA,保持可见,构成一个有节奏的信息系统。

## 专项创意引擎（先于 Prompt 画像）

促销片首先回答五件事：卖什么、什么节点、最强利益是什么、资格/领取路径是什么、现在做什么。剧情、达人或玩梗只能作为 Hook 或表达容器，不能夺走利益层级。

`活动节点 → 受众此刻购买动机 → 最强已核实利益 → 资格/机制 → 产品值得买的证明 → 获取路径 → 紧迫理由 → 单一 CTA`

### 路由优先级

请求明确出现 618、双 11、双 12、99 大促、七夕、520、年货节、开学季、品牌日、会员日、直播专享、券、满减、赠品、到手价或限时机制时，促销拥有主专项。若同时要求短剧、霸总、反转或玩梗，把它当 Hook；优惠事实、产品理由、获取路径与 CTA 仍由促销结构拥有。

### 先定利益层级

1. 识别 `campaign_occasion`，不写则保持 unknown，不擅自默认某节点；
2. 从价格、券、满减、赠品、套装、到手量、会员权益、直播权益中只选一个最强利益；
3. 把数字、单位、门槛、期限、适用人群、库存和获取路径与利益就近呈现；
4. 选择一条产品证明解释“为什么这波值得”，不能只说便宜；
5. CTA 只给一个真实动作：点商品卡、进直播间、领券、预约或到店。

所有数字、优惠、资格、截止时间、库存、赠品与路径必须来自权威信息。未提供则用不含数字的安全表达或先问，不可用“限量、最低、仅剩”等假紧迫感。

### Hook 选择

从利益和商品决定，而不是固定套模板：福利奇观、赠品摆开、达人反应、夸张剧情、到手量揭示、券卡叠加、倒计时或使用结果先行。Hook 中应同时可辨认商品或购买情境，并在前半段进入利益/证明。剧情 Hook 的人物冲突必须由促销利益或商品证明解决。

### 时长结构

- **15 秒**：`Hook/节点 → 最强利益 → 一个产品证明 → 时间/领取路径 → CTA`；
- **30 秒**：`0-3s Hook → 3-7s 最强利益 → 7-11s 机制/赠品可视化 → 11-15s 产品证明 1 → 15-19s 产品证明 2/使用场景 → 19-23s 时间与路径 → 23-27s 有依据的紧迫/信任 → 27-30s CTA`。

30 秒不是把 15 秒拉长：应增加不同产品证明、使用场景和更清楚的获取路径。利益主句只说一次，后续用新信息推进。

### 人物与卡片

达人/主持人必须匹配利益路线：直播引流用主持姿态，赠品机制用开箱/礼赠场景，囤货用家庭/宿舍场景，品牌日用更克制的官方信任感。卡片、手机、截图、赠品和套装都是证据，数量与归属稳定；花字只用于 Hook、最强利益、路径和 CTA 的安全区，不遮挡脸、手、商品、Logo 或资格条件。

### 专项退出标准

- 一眼看懂节点、商品、最强利益、资格/路径和下一步；
- 每个数字、条件、赠品和期限都可追溯，口播、卡片与画面一致；
- 产品证明解释利益为什么值得，不只是福利堆砌；
- 剧情/UGC/Style 只服务促销信息层级，不抢主线；
- 只有一个 CTA，且与用户真实购买路径一致。

## 必需载荷结构

按此顺序写出完整的 Prompt 载荷:

```text
【活动与事实锁】
<已核实的时机、优惠/利益、数字、单位、资格条件、截止时间、
获取路径、必需的免责声明,以及绝不能臆造的事实>

【产品身份锁】
<产品/SKU、包装、数量、套装或赠品关系、状态、证明>

【人物与表达】
<达人/主持人/顾客角色、信任基础、外形、场景、表达能量,
以及活跃时的剧情或 UGC 辅助处理>

【信息层级】
<现在为什么相关 -> 最强的已核实利益 -> 产品理由 -> 证明 ->
资格条件/获取路径 -> 一个口播 CTA>

【视觉包装与卡片/UI】
<活动图形、贴纸密度、精确提供的卡片/截图、
手机辅助、可读区域,以及从 UI 回到实物证明>

【五段式执行】
1. Hook/现在为什么相关：<可见与口播内容>
2. 核心利益或机制：<已核实的利益加资格条件>
3. 产品理由与证明：<产品动作与结果>
4. 获取路径与时机：<可读路径、时机,或已核实的截止时间>
5. 收束与行动：<产品/利益回想,以及一个口播 CTA>

【声音与连续性】
<口播/卡片中一致的精确数字与文案、音乐、拟音、产品/卡片/手机
状态、道具归属,以及结束状态>
```

这五个区块是功能性节拍,不是被强加的 15 秒模板。只有在已确认的分镜需要时,才缩放它们的时长并合并相邻功能;当资格条件、证明、获取路径或口播 CTA 处于活跃状态时,不要省略它们。

## 家族投射

- Hook 通过受众当下的需求、一个已核实的利益、产品结果、购买风险纠正、套装揭示、达人判断或已核实的时机来赢得注意。
- Style 提升可读性与活动个性,而不变成虚假紧迫感。
- Play 可以提供故事、达人、转场、挑战或揭示的容器,而促销保持对信息层级的归属。
- 卡片、截图、手机、赠品与套装是证据,具有稳定的数量与归属,而不是装饰性叠加层。

## 模型编译层交接

遵循 [`_shared-profile-preamble.md`](_shared-profile-preamble.md) 中的共享交接规则。新增必保留条款:保留已核实的措辞、就近的资格条件、产品证明、获取路径与可听 CTA。

## 检查

- 每一个数字、优惠、条件、截止时间与路径都经过核实。
- 一个利益拥有整个层级,并且在没有新信息时不重复。
- 产品理由与证明说明了这个利益为什么重要。
- 卡片/UI 处理清晰可读,不遮挡面部、手部、产品、Logo、证明或资格条件。
- 口播、可见与卡片文案一致。
