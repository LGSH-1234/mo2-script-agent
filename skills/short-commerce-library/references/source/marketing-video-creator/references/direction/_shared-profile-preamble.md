# 方向画像 — 共享前言

请将本文件与你加载的具体方向画像(`brand-film.md`、`creator-ugc.md`、`general-marketing.md`、`seasonal-promotion.md` 或 `story-commerce.md`)一起阅读。每个画像文件都会声明自己的路由键,并拥有各自的必需载荷结构、家族投射与检查。下面两条规则对每一个画像都成立;每个画像文件只说明它在此之上额外添加的内容。

## 归属边界

每个方向画像拥有面向模型的 Prompt 的家族专属结构。它不拥有工作流、确认、模型能力、请求数量或执行。若某画像的家族需要,可在开篇第一行声明放弃对某一额外项的归属(例如 UGC 也不拥有人像生成;Seasonal Promotion 也不拥有固定时长)。

## 模型编译层交接

将画像的载荷传给当前生效的 Seedance 编译层时,含义保持不变。编译层只可调整面向模型的表层 —— 主体标签、引用记法、任务语法/动词、阶段/时间戳/时序表达,或素材限制 —— 但绝不可重排、移除、合并或削弱任何承载已确认或活跃信息的区块。每个画像会添加自己家族专属的必保留条款(保留所有小节及其内容职责;不移除活跃区块,不合并达人/产品身份锁;保留已核实的措辞、资格条件、产品证明、获取路径与可听 CTA;不重排因果链,不削弱已确认的对白/证明/反应/结尾;保留已确认内容)。在这条通用规则之上,遵守该条款。
