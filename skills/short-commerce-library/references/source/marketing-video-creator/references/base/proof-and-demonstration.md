
# 证明与演示

将卖点转化为可见或可听的信任理由。当合身度、质感、性能、便利性、workflow、对比、转变或效果承担说服作用时，均可参考本文档。

## 证明契约

```yaml
证明契约:
  主张:
  买家顾虑:
  证明方式:
  初始状态:
  商品动作:
  可观察结果:
  对用户的意义:
  见证者:
  受控变量: []
  所需规模:
  所需时长:
  事实边界:
```

使用能够回应买家顾虑的最小证明。包装展示只能标识商品，无法构成证明。口头讲解只能诠释证明，无法替代证明。

## 证明类别

- `wear`:全身合身度、比例、动态、舒适感提示、造型完整度、服装细节;
- `apply`:用量、质感、涂抹、吸收、在一致光线下的妆效;
- `consume`:开启、倾倒、蒸汽、质感、声音、分量、第一口或第一饮、可信的反应;
- `operate`:安装设置、输入、操作、反馈、完成的产出、清理或收纳;
- `remove_or_clean`:清晰可辨的初始状态、施用、过程、可控的呈现、结果;
- `contain_or_organize`:物品集合、装载顺序、容量、取出、携带规模;
- `compare`:相同条件、一个有意义的变量、并排或先后的结果;
- `endure`:重复使用或相关压力测试,不做无依据的时间压缩;
- `social`:在可见证据之后,收礼者、同伴、顾客、家人或专家的反应;
- `workflow`:压力、输入、操作、成果或结果、改变后的任务后果。

## 证明设计

明确观众在动作发生前看到什么、确切的商品交互、发生了什么变化,以及镜头与声音如何让这一变化清晰可辨。让手部、支撑、重力、比例、接触、顺序与时机保持可信。

只有在条件公平且易于理解时才使用对比。在相关情况下保持角度、光线、用量、表面、距离、时机与对象一致。不得通过剪辑、滤镜或不同条件制造虚假结果。

证明必须适配真实商品信息。不要为了让卖点更可视化而虚构产品外观、背面/侧面标签、配料表、成分表、认证、规格、容量、口味、内部内容、剖面结构、附件或未提供的功效机制。若某个卖点缺少可见依据，优先使用口播解释、用户感受、见证者反应、场景结果、同条件泛化对照；确实需要补充依据时，回到素材检查并给用户选项：上传参考图/参考视频、文字描述修正、回避未知视角或改成低风险展示。

产品动作必须符合产品形态、大小和物理规律。软袋、硬盒、瓶罐、管状、泵头、服饰、配件、电子产品、App 页面等各自使用方式不同，不能互相套用。打开、倒出、喷洒、涂抹、穿戴、安装、点击等动作不确定时，不要硬写高风险动作；默认先改成素材已证明的状态、低风险展示或结果证明。只有用户明确要求完整动作、核心证明依赖动作，或降级会改变用户意图时，才询问参考视频或按顺序的多状态产品图。

对于便利、舒适、清爽、时尚或轻松等定性主张,应将词语转化为行为:

- 便利 -> 步骤更少、单手使用、便携轻巧、取用更快、任务完成;
- 舒适 -> 行走、坐姿、动态、无压迫的操作、场景收尾时的从容;
- 清爽 -> 倾倒、凝露、第一口饮用、不含医疗暗示的呼吸或姿态变化;
- 时尚 -> 完整轮廓、比例、搭配、姿态、社交场景;
- 轻松 -> 清晰的安装设置、清晰可辨的操作、干净的结果、极少的修正。

## 证明与故事

在演示中,证明是主干。在 UGC 中,达人见证或亲自执行证明。在剧情带货中,证明促成了改变后的结果。在品牌片中,证明可以化为一种仪式、材质法则或令人难忘的后果。在促销中,证明解释了为何该利益值得行动。

## 收尾检查

- 证明回应了一个真实的顾虑。
- 初始状态、商品动作与结果均可见。
- 镜头比例与时长使结果在投放平台上清晰可读。
- 台词不做超出证据所示的主张。
- 卖点和证明均来自已验证文本、商品图可见信息或用户补充素材，没有虚构包装文字、背标、配料表、内部内容或功效机制。
- 产品形态、大小比例、使用方式和开合动作符合用户商品图与物理规律。
- 对比变量保持受控。
- 证明出现在回报、判断或 CTA 之前。
