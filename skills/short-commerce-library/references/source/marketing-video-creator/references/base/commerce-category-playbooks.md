
# 电商品类打法手册

用于普通电商商品。只选择最接近的品类章节,然后将其与所选的营销专项、证明约定、渠道以及提供的 Hook/Style/Play 结合。品类知识本身绝不选择专项。

## 目录

- 品类交接
- 美妆与个护
- 服装、鞋、包与配饰
- 食品与饮料
- 家居、清洁、日用与护理用品
- 电子与小家电
- 通用实物商品
- 品类退出检查

## 品类交接

解析:

```yaml
品类交接:
  品类:
  目标用户:
  买家或决策者:
  使用场景:
  购买动机:
  主要价值:
  买家顾虑:
  可信证明: []
  达人角色: []
  故事压力: []
  品牌张力: []
  视觉优先级: []
  常见失败: []
  适配动作: []
```

从完整的文本提示词与权威素材推断品类。商品、达人、Hook、Style、Play、ID 与描述可能都嵌入在一条文本提示词中;不要求结构化的上游字段。

## 美妆与个护

包含护肤、彩妆、香水、护发、修饰、卫生与美容仪器。

- 动机:自信、社交自在、贴合日常、感官愉悦、妆效、色彩、舒适,或对某个具体烦恼的缓解;
- 异议:夸大功效、色号或肤质不合、质地厚重、使用困难、加了滤镜的效果、通用背书;
- 证明:用量、质地、色卡、上妆、吸收、半脸或受控对比、自然光下的妆效、发丝摆动、日常流程中的位置、克制的反应;
- 达人角色:美妆试用的朋友、日常流程分享者、彩妆教程达人、修饰测评者、目标用户同侪;
- 达人外观:匹配可能的用户与使用资格;保留自然的肤质或发质;避免默认的完美网红脸;
- 故事压力:近距离观看、活动准备、日常摩擦、镜头自信、社交距离,或某个可解决的个护不便;
- 品牌张力:外部评判对自我定义、转变对被认可、护理即掌控力;
- 避免:无支撑的医学或长期效果、即时治愈、虚假完美、前后条件不一致、羞辱不可改变的特征。

美妆 UGC 应说明达人为何是可信的用户,以及什么样的实物证据承载该主张。仅有一张干净的脸并非证明。

## 服装、鞋、包与配饰

- 动机:合身、比例、舒适、场合准备、身份、品味、多样性、地位、容量,或搭配完成度;
- 异议:整体轮廓不清、尺码不合身、穿着不适、难以搭配、小件缺乏尺度参照、通用的高端话术;
- 证明:全身试穿、站立与行走、转身、腰/肩/下摆细节、面料动态、侧面轮廓、鞋底弯折或相关抓地、上身尺度、容量装载、搭配前后对比;
- 达人角色:试穿测评者、目标穿着者、造型师朋友、通勤者、旅行者、务实测评者、送礼顾问;
- 达人外观:匹配穿着者或买家;身材比例必须保持自然与稳定;服装必须让商品的合身度与轮廓读得出来;
- 故事压力:通勤、开会、约会、旅行、面试、聚会、合影、打包,或旧对新的搭配选择;
- 品牌张力:归属感、品味焦虑、身材自信、地位、亚文化、姿态,或该单品让穿着者进入或拒绝的世界;
- 避免:只有平铺展示的证明、隐藏轮廓、鞋类不走路、包类不展示容量、含糊的 `高级感`、失控的身体或服装形变。

对于换装,先定义所有服装或造型,保留人物与权威商品的不变项,并使用刻意的切换、遮挡、匹配动作或重置过渡。当当前运行时支持完整包时,不要为每个造型创建一个视频请求。

## 食品与饮料

包含零食、饮品、预制食品、调味品、餐食套装、礼品食品与食品定位的商品。

- 动机:味道、新鲜、慰藉、记忆、分享、便利、仪式感、分量、送礼,或提神;
- 异议:没有感官证据的形容词、假反应、分量不清、备制可信度差、以商品摆拍替代商品体验;
- 证明:开启、倾倒、冰块或凝露、蒸汽、拉丝质地、脆响、切开、分量、备制、第一口或第一啜、反复取用、分享、可信的反应;
- 达人角色:美食爱好者、办公室或学生分享者、日常用户、家庭厨师、务实的家庭用户、送礼顾问;
- 达人外观:契合场合与社交角色;保持表演克制,使感官证据仍占主导;
- 故事压力:饥饿、思乡、待客、分享、犒赏、时间压力、尴尬场合,或某个小小的关系仪式;
- 品牌张力:温暖、犒赏、仪式、怀旧、好客、本地自豪,或社交连接;
- 避免:只有摆拍的构建、塑料感的质地、证据之前的反应、无支撑的营养或健康效果、不安全的食用。

当目标是欲望时,从最易读的感官阈值开始:开启、切开、倾倒、蒸汽、质地,或第一口之前的那一刻。

## 家居、清洁、日用与护理用品

包含清洁、收纳、厨房工具、家庭用品、家居用品、母婴用品、宠物用品、玩具与重复使用的日用品。

- 动机:消除摩擦、省力、省空间、改善秩序、提升舒适、简化护理、支持重复使用,或感到胜任与有准备;
- 异议:抽象的功能清单、结果太小或被隐藏、不可能的清洁或修复、不安全的操作、只在问题消失后才出现的商品;
- 证明:清晰的初始状态、涂抹或使用、过程、结果、手指擦拭、单手使用、装载或整理、清理、重复使用提示、家长/主人操作、尺寸契合、安置与取回;
- 达人角色:真实的家庭用户、务实测评者、家长或照护者、问题解决者、租客、宠物主人、家居造型师;
- 达人外观:契合真实的角色与环境;使用可信的居家着装、姿态、工具与商品关系,而非影棚式的广告造型;
- 故事压力:客人到访、家人评判、照护责任、杂乱、反复的劳作、临时救场、检查、小空间摩擦,或旅行准备;
- 品牌张力:无形的照护、居家胜任力、保护、舒适,或让生活变轻松所需的付出;
- 避免:没有商品介入的结果、在移动端太小的证明、不安全的儿童或宠物操作、强迫的动物反应、无支撑的安全或健康保证。

使用完整链条 `问题状态 -> 商品动作 -> 结果状态 -> 人的后果`。危机与化解是内部节拍,而非拆分请求的自动理由。

## 电子与小家电

包含数码配件、消费电子、工具、厨房电器、便携电器与任务导向的设备。

- 动机:速度、便携、可靠输出、清晰、易于设置、更少步骤、舒适、娱乐,或完成的工作;
- 异议:没有操作的美图、不可读的 UI、无支撑的规格、假界面、不清晰的输出、夸大的一键结果;
- 证明:输入、设置、操作、反馈、输出、并排对比、声音或延迟提示、支持时的充电或便携、清理、收纳、完成的任务;
- 达人角色:务实测评者、通勤者、上班族、学生、玩家、家庭用户、烹饪测评者、从业者;
- 达人外观:匹配任务与环境;服装、书桌、厨房、汽车、健身房或旅行道具应确立真实的专长,而不凭空捏造权威;
- 故事压力:截止期限、反复的设置、通勤、早餐赶时间、小空间、忘带的设备、旧工作流,或某次任务失败;
- 品牌张力:无形的能力、掌控、时间成本、复杂度、可靠性,或围绕技术的人的掌控力;
- 避免:界面巡览、通用的未来感蒙太奇、无支撑的电池/功率/速度/容量主张、未经顺序操作就出现的输出。

将 `方便` 或 `高效` 转化为一个完成的任务。展示放进去什么、商品做了什么、出来什么,以及用户的什么发生了改变。

## 通用实物商品

当没有更接近的品类适用时使用。

解析物品类别、买家、使用场景、物理交互、主要摩擦、一个可见属性、一次完成的使用、结果、尺度、收纳或携带行为,以及可能的重复使用情境。

优先使用操作、合身、材质、容量、操作、对比或结果,而非通用的美图。只有当某人的可信度能实质提升信任时才选择达人。否则保持 `general_marketing`。

## 品类退出检查

- 只有一个最接近的品类章节生效;不要把每个品类都当作并行建议加载。
- 人设、证明、故事压力与视觉优先级与商品和买家一致。
- 品类指导不凭空捏造事实,也不强行选择专项路由。
- 证明在移动端可读,且先于反应或 CTA。
- Hook、Style 与 Play 在各自范围内保持为用户拥有的约束。
