
# 营销基础与路由

为每个任务构建一个基础营销判断，然后只激活能实质性提升说服力的专项机制。

**前置（硬性）**：涉及具体商品时，做下面的基础营销判断之前，**先按 [contract-product-truth.md](../../contract-product-truth.md)「商品建模合同」为每个 `产品1` 建一份商品模型**（参数与形态 + 功能与使用，写进 `营销脑图.md`，结构见[输入与项目状态](intake-and-project-state.md)的「商品模型」）。商品语义、价值、证明与卖点都只能从模型里已知（非 `unknown`）的事实中推导，不得据未知的面或用法臆造。建模暴露的缺口与下面的关键事实红线合并，优先以图/视频方式一次向用户问清。

## 基础营销契约

确定：

```yaml
营销策略:
  受众:
    目标用户:
    购买情境:
    当前压力:
    潜在渴望:
    主要顾虑:
  商品语义:
    品类归属:
    目标使用者:
    人与商品的关系:
    使用或展示情境:
    购买动机:
    可信互动: []
  价值:
    主要价值:
    对用户的意义:
    最小可见价值:
  信任:
    壁垒:
    依据:
  证明:
    主张:
    方式:
    可见结果:
    需要的见证:
  情绪:
    起始状态:
    目标状态:
    情绪回报:
  记忆:
    唤起目标:
    品牌资产:
  行动:
    下一步:
    此刻理由:
  创意契约:
    营销对象:
    目标受众:
    期望认知:
    说服机制:
    必要情境: []
    必要证明: []
    须避免: []
```

保持单一的主价值主线。次要利益点可以澄清它，但不能创造并行的故事。

## 商品语义

解读商品是如何被使用、穿着、消费、操作、展示、赠送、信任或分享的；什么情境使其价值变得有意义；以及哪种动作、材料行为、产出、对比、反应或结果能够证明它。

有用的说服机制包括亲身使用、透明过程、公平对比、产品机制、已验证的专业性、社会反应、关系后果、品牌仪式以及已验证的场合或优惠。

商品或品牌应当充当证据、工具、仪式物品、剧情钥匙、连接者、身份信号、纠错、保护、转变触发器、记忆载体或世界规则。如果同一视频在没有它的情况下也能得到完全相同的结果，则强化它的角色。

对于普通电商商品，阅读 [电商品类打法手册](commerce-category-playbooks.md)。对于性能、感官、贴合、工作流或结果类声称，阅读 [证明与演示](proof-and-demonstration.md)。

## 低风险推断

在置信度充分时，推断可能的受众、购买情境、压力、欲望、异议、证明方式、达人角色、场景、Hook 类型、推进、CTA 以及兼容的平台。**低风险推断只适用于创意性、不构成购买理由、也不影响成片可信度的空白**（如运镜、氛围、次要转场、镜头顺序偏好）。

将所有上游上下文视为文本优先。商品、达人、Hook、Style、Play、ID 和素材描述可能以带标签或不带标签的短语形式出现在一条提示词中。在不要求 schema 的情况下解析语义。ID 是上下文，而非那些未提供、也未由可用运行时来源解析的事实的证明。

**关键事实红线（禁止推断，缺失必问，见 [contract-product-truth.md](../../contract-product-truth.md)「关键信息保守收集合同」）：** 商品功能/功效/用途/工作原理、尺寸/尺码/容量/规格/重量/数量、材质/面料/成分/工艺、颜色/款式/型号/SKU 区分、构成主要购买理由或差异点的 `P00` 卖点，以及价格、折扣、优惠券、赠品、库存、截止日期、资格、排名、背书、认证、成分、规格、实测功效、医疗或财务效果、官方历史或客户结果。这些一律**不得**推断为已验证的事实，也不得用"通常/一般/应该"或行业惯例值补全。权威来源里没有的，标 `unknown` 并汇总向用户问清（**尽量一次问齐，确有必要时可追加补问**），绝不臆造。绝不把没给尺码的商品脑补成"均码/S-XL"、把没说明的面料写成"亲肤棉质"、把用户没提的功能编造进脚本。

## 专项路由

```yaml
routing:
  base: general_marketing
  primary_specialist: null | brand_film | creator_ugc | story_commerce | seasonal_promotion
  supporting_treatment: null | brand | ugc | story | promotion
  selection_reason:
  confidence: high | medium | low
```

上面的 `routing` 块是**内部机器路由标识**，其中 `primary_specialist`、`brand_film`/`creator_ugc`/`story_commerce`/`seasonal_promotion`/`general_marketing` 等英文枚举与方向创意文件名绑定，仅供 Agent 内部选文件用，**绝不能原样写进面向用户的 `营销脑图.md`**。当在 `营销脑图.md` 的「创意方向」里记录所选方向时，一律用下面的中文名，不要写 `primary_specialist: creator_ugc` 这类原始标识：

| 内部标识 | 营销脑图里写的中文名 |
|---|---|
| `brand_film` | 品牌片 |
| `creator_ugc` | 达人 UGC |
| `story_commerce` | 剧情带货 |
| `seasonal_promotion` | 季节促销 |
| `general_marketing` | 通用营销 |

对于普通的商品展示、演示、造型、感官呈现、公平对比、固定脚本可视化或简单的商品加 CTA 工作，保持 `general_marketing`（营销脑图里记为「通用营销」）。

准确地选定 `primary_specialist`，然后**只阅读匹配的那一个方向创意文件**：

- 当品牌含义、品类立场、情感关联、文化时机或助记记忆承载说服力时，`primary_specialist: brand_film`，阅读 [品牌片方向创意](../direction/brand-film.md)；
- 当达人可信度、亲身使用、测评、推荐或演示承载信任时，`primary_specialist: creator_ugc`，阅读 [达人 UGC 方向创意](../direction/creator-ugc.md)；
- 当压力、因果、悬念、误会或反转承载说服力时，`primary_specialist: story_commerce`，阅读 [剧情带货方向创意](../direction/story-commerce.md)；
- 当已验证的场合、利益、紧迫感、优惠机制或获取路径提供当下的理由时，`primary_specialist: seasonal_promotion`，阅读 [季节促销方向创意](../direction/seasonal-promotion.md)；
- 当以上专项机制都不居于核心地位时，保持 `general_marketing`（默认方向），阅读 [通用营销方向创意](../direction/general-marketing.md)。

方向文件不是只在最终阶段套一个 Prompt 格式。它在三个位置生效：

1. **第 2 步创意路由**：决定该方向真正靠什么说服、商品在其中承担什么角色；
2. **第 4 步故事脚本**：先在内部生成 3 个机制不同的候选，再按方向专属退出标准选一个；
3. **第 6 步 Prompt 编译**：把已选创意翻译成该方向的模型载荷结构。

“机制不同”至少改变说服机制、商品角色、主证明、人物关系、世界规则或视觉构造中的一项；只换场景名、人物名或台词措辞不算新候选。候选不默认全部展示给用户，只有它们会造成实质方向选择且置信度不足时才让用户拍板。

**方向创意文件的用途**：它是这个营销方向专属的**故事脚本写法指南**，只作用于「产出故事脚本」这一步——规定该方向下故事脚本要写清哪些信息块、按什么顺序组织、必备哪些字段与特征（例如剧情带货必有「压力→选择→产品介入→可见证据→见证反应→转化」的因果链，达人 UGC 必有达人可信度/产品真相/原生镜头/口播/证明等生成要素）。选定方向后，据它撰写 `故事脚本.md` 的内容。它不改动工作流、确认时机、模型能力或请求数量。

不要从表面形式进行路由。画面中有人物不会自动成为 UGC；按时间顺序排列的镜头不会自动成为故事；精致不会自动成为品牌；快节奏剪辑不是促销；而 Play 绝不会独自选定一个专项。

最多使用一个主专项。仅当某辅助处理拥有一个不重叠维度时才添加它，而且只借该维度，不加载第二套完整结构：剧情拥有因果，达人可信度拥有信任，品牌含义拥有记忆，已验证的场合或利益拥有行动。例如“剧情主专项 + UGC 辅助”只借真实镜头与可信表演，不把整片改写成达人测评；“品牌主专项 + 剧情辅助”只借一个关系转折，不套完整短剧节拍；“促销主专项 + 剧情辅助”只把剧情当 Hook，优惠层级与购买路径仍由促销拥有。

对于仅意图的输入，路由可以塑造构建。对于所提供的故事或分镜，保留它并只添加兼容的营销要求。当某个方向明显最强时，选择它并加以解释。当两三种机制都会实质性地改变结果且置信度较低时，展示这些选项并等待。

## 退出检查

- 营销对象、受众、主要价值、信任基础、证明、记忆和行动是清晰的。
- 商品或品牌具有结构性角色。
- 事实边界已被记录。
- 品类指导为证明提供信息，但不会独自选定一个专项。
- 专项由说服机制激活，而非由外观激活。
- 营销契约足够具体，能够指导创意和分镜工作。
