
# 渠道与市场

当提供了投放平台或市场,或需要一个低风险默认值时,校准形式、观看关系、信息密度、达人行为、文字与 CTA。

## 通用规则

用户指定的平台、比例、语言与市场具有权威性。平台改变的是表达方式,而非商品事实、故事归属或确认策略。当请求的各平台观看关系存在实质差异时,不要将同一脚本照搬到这些平台。

当一个普通的国内电商请求既未提供平台也未提供比例时,采用低风险的 9:16 抖音风格假设,并将其披露为用户可修改的 agent 假设。不要添加阻断式的平台问卷。

## 国内平台

### 抖音电商

- 竖屏、移动优先的投放,快速建立相关性,商品尽早出现;
- Hook 过渡到一个可见的证明;
- 尽管节奏更快,达人或商品动作仍保持连贯;
- 一个清晰的购买提示或商品卡 CTA。

### 小红书

- 个人选品逻辑、体验、对比、教程或生活方式场景;
- 有美感但可信的环境与自然细节;
- 资质说明与"为何适合"比强烈的紧迫感更重要;
- 在合适时使用收藏、搜索、评论或软性商品种草。

### 快手

- 接地气的日常场景、实用性、性价比、数量、耐用性或复购;
- 直白的口播逻辑与清晰可读的证明;
- 避免削弱真实可信度的不必要活动感包装;
- 仅在有支撑时直接引导商品、直播间、优惠券或购买动作。

### 微信视频号

- 类熟人推荐、家庭或服务信任、适中的节奏;
- 清晰的价值、流程或可信度提示;
- 避免过度压缩的俚语或未加解释的平台原生元素。

## 海外

仅当用户明确要求海外平台、目标语言、双语输出或市场本地化时才启用。

使用自然的目标语言表达、文化上合理的场景与达人行为、仅在有支撑时使用本地单位与 CTA,以及平台原生的视觉证明。不要将国内的优惠券、直播间、商品卡或俚语惯例直译。

### 市场—语言—人物本地化

本地化不是只翻译口播。对有人物的营销视频同时确定 `目标市场 / 平台 / 口播语言 / 画面文字语言 / 人物本地化 / 人物参考权限`：

- 明确市场优先；没有市场但“单一当地语言 + 当地电商语境”高度一致时，采用可修改的本地化默认值。例如全片仅泰语、投 TikTok/TikTok Shop 且无相反信息，默认泰国市场。
- 人物没有被用户明确锁定时，默认使用目标市场的当地可信人物和当代生活场景。泰国市场采用泰国成年人物与自然的泰国城市/居家商业语境，不用泛化西方面孔，也不堆夸张民族符号。
- 系统搜索、自动生成或未锁定的人物参考只是一种候选，不能压过目标市场。人物图“清晰、无畸变、白底干净”只表示视觉质量通过，不能表示本地化通过。
- 用户明确上传并锁定某个人物身份时，保持该人物，不按市场自动换脸；在内部记录 `user_locked_character_override`。若用户上传的人物图只作为风格/服装参考，不得把其脸部身份误锁。
- 质量检查必须同时通过：视觉完整、素材角色正确、目标市场匹配、语言/场景/CTA一致。未锁定的西方人物用于泰国本地广告属于不通过，自动重生或换候选，不询问用户做普通纠错。

## 文字与 CTA

保持视频内文字简短、稳定、易读。字幕默认不加——视频生成阶段不烧录、交付阶段也默认交付无字幕成片。但 AI 生成不稳定,模型可能违规把字幕烧进画面,故成片产出后按"用户一开始是否要字幕"分两条问卷路径处理(均解释原因、明确字幕擦除扣积分、按 1 秒 1 积分):要求无字幕时用问卷只问是否擦除;要求有字幕时用问卷二选一「无需擦除,直接添加字幕」/「擦除视频异常生成的字幕,再添加字幕」,后者由 `render_video` 后期生成干净字幕。面向用户只说"字幕擦除"与"扣积分(1 秒 1 积分)"即可。切勿遮挡面部、手部、商品、证明、标签或有支撑的优惠信息。

选择一个存在于目标去处的下一步动作:商品卡、购买链接、收藏、搜索、评论、直播间、预约、导航或了解更多。不要臆造平台 UI 或不可用的购买路径。

## 收尾检查

- 平台假设被披露,而非呈现为用户的选择。
- 开场速度、达人行为、证明比例、文字密度与 CTA 契合该渠道。
- 本地化改变表达而不改变事实。
- 人物未被用户锁定时，选角与目标市场一致；人物参考权限与本地化覆盖已记录。
- 同一商品证明在渠道适配后仍清晰可读。
