# 网红探店 Vlog 剧本钩子（02-viral-script-hooks.md）

1. **四段式探店结构**：①到店门口悬念开场（0-6s 门头/排队人气，4 秒探店钩子）→ ②店内环境氛围沉浸探店（6-14s 装修/氛围/客座）→ ③招牌产品试吃试用高潮（14-21s 惊艳反应）→ ④探店总结地址种草 CTA（21-26s 推荐指数/人均/地址）。
2. **4 秒到店钩子**：开场即"最抓人的悬念"——排队王/网红店终于来了/隐藏神店/这道菜火遍全网，用"值不值得专门跑一趟"的探店痛点抓住观众，绝不允许棚拍开场。
3. **招牌试吃高潮模板**：招牌呈现（热气/摆盘/上菜）+ 达人第一口惊艳反应（AU26 张口 + AU6+AU12 满足眯眼）+ 真实口感描述，把"招牌爆品"转化为探店高潮顶点，惊艳须真实自然。
4. **沉浸探店脚本**：第一人称走进店内，环境广角扫过装修/氛围/客座，达人真实好奇环视（AU1），配合甩镜/跳切 Vlog 转场，制造"跟着达人逛店"的沉浸代入。
5. **探店总结落点**：CTA 用达人真实口播给"推荐指数/人均消费/地址定位/避雷建议"，客观真诚 AU6+AU12，把决策信息交还观众，沉浸探店种草收尾，严禁虚假好评叫卖。
6. **单一源公理铁律**：全片达人 `@CHAR_INFLUENCER`、店铺 `@SCN_STORE`、招牌 `@PROD_STORE`、道具 `@PROP_VLOG` 从基准资产一次性生成，四段式探店所有镜头 @ 显式引用，店铺须同一空间同招牌，严禁链式修改导致漂移。
