# 网红探店 Vlog 3D 白模与轨迹锁定（whitebox-3d-rendering-guide.md）

1. **店内空间布局锁定**：先用 3D 白模（greybox）锁定 `@SCN_STORE` 店铺的空间布局基准（门头/客座/吧台/装修）与 `@CHAR_INFLUENCER` 面部骨相基准，确保同一店铺在到店/进店/招牌/CTA 所有镜头为"同一空间同招牌同装修"（严禁换店/改装修漂移）。
2. **第一人称运镜轨迹锁定**：第一人称 Vlog 运镜（自拍杆视角/手持跟随/走进店内）须用动画曲线锁定相机轨迹与高度（1.5m），甩镜/跳切转场的运动路径与节奏锁定，避免运镜漂移与穿模。
3. **环境与产品动力学解算**：招牌菜品热气用流体/粒子解算，摆盘呈现/上菜动作用刚体解算，排队人气/空间氛围用群集/环境解算，确保环境与产品动力学物理可信。
4. **招牌高潮机位对齐锁定**：招牌试吃高潮须锁定招牌 `@PROD_STORE` 与达人相对位置，50mm 特写机位参数（位置/高度/角度/焦段）锁定，热气/摆盘呈现与达人惊艳反应对齐，确保高潮真实可信。
5. **店内真实环境光渲染**：窗光 + practical 暖调吊灯须用面光源/光度学光源模拟——右侧 40° 4200K CRI 93 真实环境塑形、暖调钨丝逆光后方 150° +0.6 档温馨光晕、Key:Fill 1.8:1 自然氛围，真实暖调店铺调色，浅景深店铺虚化，确保真实到店光落地。
6. **单一源公理铁律**：@CHAR_INFLUENCER/@SCN_STORE/@PROD_STORE/@PROP_VLOG 的 3D 资产模型一旦锁定为基准，所有镜头状态（到店→进店→招牌→CTA）从同一基准模型渲染，严禁链式修改导致达人面部/店铺空间/招牌漂移。
