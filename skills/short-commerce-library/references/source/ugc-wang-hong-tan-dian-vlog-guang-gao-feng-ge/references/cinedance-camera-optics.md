# 网红探店 Vlog 运镜光学（cinedance-camera-optics.md）

1. **第一人称自拍杆 POV**：手机竖屏第一人称手持 Vlog（自拍杆/稳定器），自拍杆视角高度 1.5m，方位角 10° 微侧，这是探店 Vlog 的灵魂机位——制造"跟着达人一起到店"的沉浸代入，绝非旁观者三脚架视角。
2. **环境广角 24mm**：到店门口与店内空间用 24mm 等效广角，容纳门头招牌/排队人气/装修氛围/客座环境，展现店铺真实空间感，广角畸变轻微可控还原 Vlog 质感。
3. **招牌特写 50mm**：招牌产品/菜品用 50mm 等效 T2.0 特写，焦平面锁定招牌质感（热气/摆盘/色泽），浅景深店铺虚化，把"招牌爆品"放大为视觉种草焦点。
4. **Vlog 转场语言**：跳切（jump cut）/甩镜转场（whip pan）/遮挡转场（object wipe）串联到店→店内→招牌，招牌高潮缓推（slow push-in），运动轻快真实手持感，还原 Vlog 转场节奏。
5. **竖屏 9:16 沉浸构图**：手机竖屏 9:16 构图，达人与店铺/招牌占画面主体，快门等效 180° 自然运动模糊，去广告化真实手持微动感，绝非影棚滑轨机械运镜。
6. **单一源公理铁律**：所有运镜机位服务于 @CHAR_INFLUENCER 达人与 @SCN_STORE 店铺的真实探店，从基准资产一次性生成，达人面部骨相/店铺空间招牌 100% 一致，严禁链式修改导致机位漂移与店铺失真。
