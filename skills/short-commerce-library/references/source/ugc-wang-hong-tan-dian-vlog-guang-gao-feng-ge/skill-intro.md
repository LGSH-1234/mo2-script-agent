# 网红探店 Vlog 广告 · 极速上手指南（skill-intro.md）

> **一句话定位**：以 TikTok/抖音/小红书爆款网红探店 Vlog 为标杆，用真实到店体验、第一人称手持沉浸运镜、达人真实惊艳反应与招牌产品呈现，把线下店铺转化为可见的沉浸式探店种草欲望。**到店即真实，沉浸即代入，招牌即种草。**

## 🚀 30 秒上手流程

1. **锁基准资产**：先定 `@CHAR_INFLUENCER`（探店达人 Model Card）+ `@SCN_STORE`（店铺，同一空间同招牌同装修）+ `@PROD_STORE`（招牌产品/菜品）+ `@PROP_VLOG`（手持稳定器/自拍杆），一次性锁定，全程 @ 引用禁止链式改（严禁换店/改装修）。
2. **选文生图版本**：默认用 `SKILL.md §二` 的 MJ v8 专属版或常规通用版；用户点名"角色资产卡/Model Card/定妆卡"时才输出第三版本（10 格）。
3. **写剧本**：套四段式探店——①到店门口悬念开场 → ②店内环境氛围沉浸探店 → ③招牌产品试吃试用高潮 → ④探店总结地址种草 CTA（详见 `02-viral-script-hooks.md`）。
4. **生成视频**：套 `SKILL.md §三` 的 11 段式多参引擎，**除台词外整体描述必须用中文**，竖屏 9:16 手机原生，达人逐段注入 AU 微表情、店铺/招牌注入环境与产品动力学 + 光影五子层。
5. **配音效**：店内真实环境音（人声/餐具/氛围）+ 轻快 Vlog BGM + 达人探店口播（详见 `03-sound-design-asmr.md`）。

## 🎯 五大不可动摇配方速查

| 配方 | 数值锚点 |
|---|---|
| **店内真实环境光** | 窗光 + practical 暖调吊灯右侧 40° 4200K CRI 93 真实环境塑形，暖调钨丝逆光后方 150° +0.6 档温馨光晕，Key:Fill 1.8:1 自然氛围 |
| **第一人称 Vlog 运镜** | 手机竖屏第一人称手持（自拍杆/稳定器），环境广角 24mm 等效（到店/店内）+ 招牌特写 50mm 等效 T2.0，自拍杆视角高度 1.5m，方位角 10° 微侧 |
| **Vlog 转场语言** | 跳切/甩镜转场/遮挡转场串联到店→店内→招牌，招牌高潮缓推，轻快真实手持感，纯环境空镜 AU 转"环境与产品动力学"并声明 `[本镜无角色面部主体]` |
| **招牌惊艳高潮** | 招牌产品试吃试用惊艳反应 AU26 张口 + AU6+AU12 满足眯眼（C 级），热气/摆盘呈现，探店高潮顶点 |
| **探店期待 AU** | 到店期待 AU1+AU2 挑眉（B 级），进店好奇 AU1 环视（B 级），CTA 满足真诚 AU6+AU12（B 级），真实到店反应 |

## ⚠️ 三条红线
- **严禁虚假好评**：真实到店体验客观呈现，绝不允许刷单炒信、收钱说好话、虚构排队人气、隐瞒真实体验（《反不正当竞争法》禁止虚假宣传）。
- **软广须依法标注**：恰饭探店/商务合作须主动披露利益关系并标明"广告/合作"，绝不允许"暗广"隐瞒；价格/优惠真实，严禁虚假折扣误导到店。
- **字幕铁律**：No subtitles.（字幕/地址信息/探店花字绝不由模型生成，须后期硬压）；台词保留原语言口语化真实自然，口型同步精准。
