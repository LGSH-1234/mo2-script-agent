# 时装短片创作

## 核心原则

不要只做"穿衣服的人站在镜头前"，而要做"面料与身体在空间中的对话"。一条好的时装短片，让观众记住的不是模特的脸，而是面料如何受力、光泽如何折射、廓形如何在运动中形变——服装是唯一的主角，模特是面料的载体，场景是面料的剧场。

持久引擎（因果链）：

**服装资产解析 → 风格类型锁定(Runway/Lifestyle) → 刀版三视图(结构基准) → 模特服饰卡(形象一致性锚点) → 场景方案(氛围容器) → 空场景图(光线与留白基准) → 六宫格分镜(节奏与景别蓝图) → 15 秒视频(面料动态的最终呈现) → BGM 与组装(情绪弧线收束)**

### 质量测试（可证伪）

**如果遮住面料纹理与廓形动态，这条视频就退化成一段普通的街头散步或室内摆拍，则创意不成立。** 服装必须在至少 3 个镜头中通过运动、光线或特写展现出不可替代的物理质感（垂坠/折射/肌理/惯性），而非仅作为遮体的布料出现。

## 输入诊断

生产前，识别或合理假设以下维度：

- **服装款式与剪裁廓形**：廓形类型、领口、袖型、裙摆/裤型
- **面料材质**：质地类型（丝绸/毛呢/皮革/纱/针织等）、光泽度、透明度、厚重感
- **色彩特征**：主色、辅色、图案/纹样的色相与饱和度
- **动态物理预判**：面料在运动中的垂坠感与摆动惯性（真丝漂浮 vs 毛呢迟滞）
- **风格类型**：秀场走秀(Runway) 还是 买家秀/街拍(Lifestyle)——阶段一锁定，全片不变
- **目标画幅**：默认竖屏 9:16，可按需调整
- **对白语言**：遵循用户设定
- **视觉风格基调**：电影质感/胶片色调/高反差/自然光
- **服装套数**：单套或多套（多套时各自独立走完全流程，资产隔离）
- **场景数量**：单场景或多场景
- **配件与道具**：显著影响视觉的饰品（首饰/包/鞋/帽）
- **BGM 风格偏好**：依服装风格匹配（休闲/街头 → Nu-Jazz/Lo-fi；礼服 → Chamber Jazz/交响弦乐；机能 → Industrial Techno/Dark Ambient；民族 → 融合民族乐器当代编曲）
- **合规敏感点**：模特形象合规、品牌商标规避

## 工作流（步骤）

### 阶段一：全局参数锁定

创建 `Final_Video_Spec.md`，锁定以下参数：片名、画面比例（默认 9:16 竖屏）、时长意图（单套服装 15 秒）、视觉风格基调、对白语言。

同时依据服装类型与用户意图，在 `Final_Video_Spec.md` 中明确锁定拍摄风格类型：**秀场走秀（Runway）** 或 **买家秀/街拍（Lifestyle）**。后续所有阶段（场景选择、故事板、提示词风格）均以此为分支依据，不得在后期阶段再做判断。

风格类型触发条件：

| 风格类型 | 触发条件 | 整体基调 |
|---|---|---|
| 秀场走秀（Runway） | 礼服、晚装、高定、概念/机能装；用户明确要求"秀场感" | 强戏剧光影、极简背景、模特全程保持走秀步态与表情克制 |
| 买家秀/街拍（Lifestyle） | 休闲、街头、日常穿搭、保暖、民族传统；用户明确要求"真实感/日常感" | 自然环境光、真实生活场景、模特有自发性互动与情绪表达 |

### 阶段二：服装资产解析（如有用户上传）

若用户提供服装图片或参考视频，先提取以下结构化信息，供故事板阶段生成场景匹配方案与镜头动态描述时使用：

- **款式与剪裁轮廓（Silhouette）**：廓形类型、领口、袖型、裙摆/裤型
- **面料材质**：质地类型（丝绸/毛呢/皮革/纱/针织等）、光泽度、透明度、厚重感
- **色彩特征**：主色、辅色、图案/纹样的色相与饱和度特点
- **动态物理预判**：面料在运动中的垂坠感与摆动惯性（如真丝漂浮 vs 毛呢迟滞），为镜头动态描述提供依据

参考 `references/industries/garment-analysis.md` 中的面料质感词库。

### 阶段三：服装与角色设计确认（逐步推进，每步后必须暂停等待用户明确确认，不得自动进入下一步）

**步骤 3a — 服装刀版三视图**

生成单张横向宽幅图（2K 分辨率），三格并排：正面 / 侧面 / 背面纯技术平面图，无模特、无背景（纯白或浅灰）。精确还原款式廓形、缝线结构、拉链/纽扣/图案等工艺细节；面料材质以标注文字辅助说明。

提示词要点：
- 明确指定"三视图技术平面图（正面 / 侧面 / 背面）横向并排，纯白背景"
- 描述款式廓形、结构线、缝合细节、五金配件
- 在图中关键细节旁可要求生成标注文字（面料名称、工艺说明）
- 无人体、无阴影、无环境，保持工程图风格

**暂停，明确等待用户回复"确认"或提出修改意见后，方可进入步骤 3b。**

**步骤 3b — 模特服饰卡**

以刀版图为参考，生成单张横向宽幅图（2K 分辨率），左右两区布局：
- **左侧**：模特面部特写（半身，突出妆容、骨相、发型与皮肤质感）
- **右侧**：穿着服装的三视图（正面 / 侧面 / 背面全身定格），重点还原真实面料物理质感（垂坠/折叠/反光/纹理），中性背景

模特形象质感提升词组（必选，按风格叠加）：
- **通用基础层（所有风格必加）**：editorial fashion model, striking bone structure, high-contrast facial features, defined cheekbones, sharp jawline, luminous skin with subtle texture, confident yet neutral expression, elongated proportions
- **秀场走秀（Runway）专属**：haute couture posture, severe angular beauty, piercing gaze, statuesque silhouette, razor-sharp brow arch
- **买家秀/街拍（Lifestyle）专属**：approachable yet aspirational look, natural warm skin tone, soft expressive eyes, effortlessly cool demeanor, candid beauty
- **妆容精度词**：Runway → sculpted contouring, graphic eyeliner, editorial lip；Lifestyle → dewy no-makeup makeup, brushed-up brows, glossy natural lip

面料质感强调词组（按材质选用）：
- 真丝 → flowing liquid drape, light-catching sheen
- 毛呢 → dense woven texture, structured weight, matte surface
- 皮革 → high-gloss specular, tight grain, stiff silhouette
- 针织 → ribbed knit relief, soft stretch, micro-loop texture

中性摄影棚光，无风，高反差背景衬托轮廓；禁止服装形变、禁止非预期配饰。

多套服装或多角色时，按 A/B/C 顺序为每个角色单独生成一张服饰卡。

**暂停，明确等待用户确认模特形象与面料还原度后，方可进入步骤 3c。**

**步骤 3c — 场景候选方案呈现**

根据 `Final_Video_Spec.md` 中已锁定的风格类型（Runway / Lifestyle）和服装解析结果，直接以文字形式向用户呈现 3 个场景候选方案，无需调用生成工具。每个方案包含：场景类型名称、核心氛围描述（1-2 句）、推荐光线基调（主光源方向 + 色温）、与该服装风格的匹配理由。

Runway 场景映射参考 `references/formats/runway-style.md`：
- 礼服/晚装 → 宴会厅或古典剧院，Chiaroscuro 侧光，丝绸/亮片折射
- 机能/概念 → 工业废墟或超现实数字空间，结构主义线条
- 高定/民族 → 传统建筑或高反差摄影棚，高纯度色彩衬布

Lifestyle 场景选择逻辑参考 `references/formats/lifestyle-style.md`：
- 休闲/通勤 → 城市街道（人行道、斑马线、玻璃幕墙反射）；顺光或侧逆光
- 咖啡/社交 → 独立咖啡馆、书店或画廊走廊；暖调漫射窗光
- 自然户外 → 公园草坪、林间小道、海边礁石；黄金时段侧逆光
- 都市夜间 → 霓虹便利店门口、湿润沥青路面；混合色温
- 居家/轻生活 → 落地窗边、书房、浴室门口；柔和自然侧光
- 保暖/冬季 → 北欧雪地、暖调室内咖啡座；低色温暖光
- 民族/传统 → 古镇街巷、庭院回廊、自然山野；高纯度环境色

若用户有自定义场景需求，直接按用户描述执行。

**暂停，等待用户从候选方案中选择或提供自定义方向，收到明确选择后方可进入步骤 3d。**

**步骤 3d — 空场景图生成**

依据用户在步骤 3c 选定的方案，为每个场景各生成一张空场景图（2K 分辨率，横向宽幅）：无人物、无服装，仅呈现环境氛围——空间结构、主光源方向与色温、明暗比例、景深层次。

- **Runway 场景**：突出人工布光质感（方向、阴影硬度、高光落点），背景极简，留有大面积视觉留白供后期模特入画。
- **Lifestyle 场景**：体现真实环境光与生活道具（咖啡桌、街道、窗边等），允许适度景深模糊，背景有生活气息但不杂乱。场景内保留真实生活道具（咖啡杯、购物袋、书、自行车等），但道具不抢主体；背景允许适度虚化行人或环境元素，制造生活感景深；避免过度对称的秀场式走廊构图，优先街头/随拍感透视角度。

**暂停，等待用户确认场景风格与光线基调符合预期后，方可进入故事板阶段。**

### 阶段四：故事板设计、资产绑定与分镜确认

**步骤 4a — 故事板设计**

声明 key_elements 与 shot 列表：

**Key Elements 声明规范：**
- **模特角色（element character）**：描述面部特征、肤色、妆容风格、发型；锁定与步骤 3b 模特三视图一致，不得矛盾
- **服装（element）**：以步骤 3a 刀版三视图为锚点，精确描述款式廓形、面料材质（质地/光泽/厚重感）、色彩及关键细节（拉链/纽扣/刺绣/图案/特殊肌理），作为全片视觉一致性基准
- **核心场景（element scene）**：依据用户在步骤 3c 中已确认选择的场景方案，描述空间结构、主光源方向与色温、明暗比例、视觉留白区域设计；描述须与步骤 3d 空场景图保持一致；多场景时为每个场景单独声明
- **配件与道具（element）**：显著影响视觉的饰品（首饰/包/鞋/帽）作为独立 element 声明

**六宫格电影分镜设计规范：**

六宫格采用竖屏（9:16）布局，3 行 × 2 列排列，代表全片六个核心画面节点：

| 格位 | 景别 | 叙事功能 |
|---|---|---|
| 格 1 | 全景 WS | 建立场景与模特入场，交代空间关系与整体廓形 |
| 格 2 | 中景 MS | 走秀步态或转身，展现服装剪裁轮廓与面料动态形变 |
| 格 3 | 近景 MCU | 上半身构图，聚焦妆容、发型与服装上部细节及配件 |
| 格 4 | 特写 CU | 面料微观肌理、针脚、拉链、刺绣等高反差细节；或角色表情/配饰特写 |
| 格 5 | 动态定格 | 升格/甩镜瞬间，捕捉裙摆展开、外套飘动等面料受力动态；或角色互动/情绪动作定格 |
| 格 6 | 收尾全景 | 模特走远或侧背镜，与场景融合，留白收束视觉 |

多场景时，每个场景独立规划六宫格；单场景中若有明显情绪转折可适当调整格位功能。

**每个 shot 须包含：**
- 关联的场景、模特、服装、配件 element ID
- 景别、摄影机运动（Push-in 推轨、Pan 摇镜、Whip-pan 甩镜、Lock-off 锁定、Crane 升降等）
- 模特动作与互动细节：步态节奏、转身角度、手部动作、表情管理（眼神方向/微表情）、与场景道具的互动
- 光影质感描述（必须包含以下全部四项）：① 主光源方向与色温；② 阴影硬度与覆盖比例；③ 高光落点（面料或皮肤的具体位置）；④ 环境反射填充色（周围环境对主体的色彩渗透）
- 视觉留白指引：画面中留白区域的位置与比例意图
- 服饰特殊肌理标注：该镜头需重点还原的面料物理特性（垂坠感/摆动惯性/折射光谱等）
- 时长建议（单套服装全部 shot 总时长目标约 15s，不得超出 15s 上限）
- 景别连贯性标记：标注该 shot 与相邻 shot 的景别关系（"景别不同→剪切过渡"或"景别相同→合并一镜到底"）

**独立音频轨道设计：**
- 一条贯穿全片的 BGM 轨道，依服装风格选择基调：休闲/街头 → Nu-Jazz 或 Lo-fi Hip-hop；礼服/晚装 → Chamber Jazz 或交响弦乐；机能/概念 → Industrial Techno 或 Dark Ambient；民族/传统 → 融合民族乐器的当代编曲
- 可酌情规划 Foley 音效层（高跟鞋落地、面料摩擦声）作为独立 audio_layer

key_element 描述须与步骤 3b 模特三视图、3d 空场景图保持一致，不得矛盾。

**步骤 4b — 资产绑定**

将步骤 3b 生成的模特穿着三视图绑定至故事板对应的 element character；将步骤 3d 生成的每张空场景图绑定至故事板对应的 element scene。若有多套服装对应多个角色 element，逐一绑定。

此步骤为视频生成前的必要前置操作，未完成绑定不得进入后续步骤。

**步骤 4c — 六宫格分镜预览图**

以已绑定的 element character 图（步骤 3b）和 element scene 图（步骤 3d）为参考输入，生成六宫格电影质感分镜预览图（2K 分辨率）。

生成单张竖版宽幅图（9:16 纵向构图），3 行 × 2 列六宫格排列，每格对应故事板中一个核心 shot 的静帧构图；每格内保持人物、服装、场景与 key_element 描述一致；统一电影胶片色调。

提示词要点：
- 参考模特服饰卡与空场景图
- 明确"竖版 9:16 构图，3 行 × 2 列电影故事板网格，统一银盐胶片色调，每格内为竖屏视角构图"
- 每格依次描述对应 shot 的景别、摄影机角度、模特姿态与场景光影
- 光影质感词：chiaroscuro side lighting、golden hour rim light、diffused overcast fill（按场景选用）
- 视觉留白指引：在适当格位指定"大面积负空间留白于画面上方/侧方，主体偏置三分之一构图"
- 服饰肌理增强词：macro fabric grain visible、thread-level weave detail、specular highlight on surface micro-texture

**暂停，等待用户确认分镜构图、场景搭配与景别节奏。**

### 阶段五：视频生成

用户确认六宫格分镜后，以六宫格分镜预览图为主要参考输入，配合已绑定的 element character 模特服饰卡和 element scene 场景图，在单次生成任务中输出一条完整的 15 秒时装短片。

15 秒（含）以内的视频用一次生成即可拿到完整成片，无需拆分为多个独立 shot 分别生成。六宫格分镜的六格叙事顺序对应同一条提示词内的时间轴节拍，不是分段多次生成。

提示词按六宫格的叙事顺序分段描述各节拍（全景建立 → 走秀/互动 → 近景妆造 → 特写肌理 → 动态定格 → 收尾留白），以动作节拍衔接替代绝对时间戳。

参考输入顺序：
1. 六宫格分镜预览图（来自步骤 4c，作为核心构图与节奏参考）
2. 模特服饰卡（element character 绑定资产，来自步骤 3b，锁定角色形象一致性）
3. 空场景图（element scene 绑定资产，来自步骤 3d，锁定场景光线与氛围）

固定负面约束：no clothing morphing, no subtitles, no music（BGM 独立生成时）。

**Runway 风格提示词指令层级：**
摄影机运动 → 模特步态与肢体控制 → 服装材质动态（垂坠惯性/摆幅/折射光谱）→ 光影层次描述 → 场景人工布光与留白 → Foley 音效标签
- 强调步态的仪式感与克制感；禁止模特自发性微笑或随意互动
- 光影指令优先描述人工布光的方向性与硬度，阴影比例高（≥50%），强化高反差戏剧感
- 推荐光影词组：single-source hard sidelight casting deep chiaroscuro、rim light tracing the garment silhouette against dark void、specular glide along silk surface with 90% shadow fill

**Lifestyle 风格提示词指令层级：**
场景环境与自然光 → 摄影机运动（允许手持感/轻微晃动）→ 模特自然动作 → 服装随动态的物理形变 → 情绪/微表情描述 → 光影层次描述 → 环境音效标签
- 摄影机描述可加入 handheld slight sway、candid street photography feel 等词组营造非刻意感
- 动作描述优先从 Lifestyle 动作库抽取，保持非表演感
- 服装动态侧重"受重力与风力的自然形变"而非走秀式夸张摆动
- 情绪词组示例：genuine half-smile、lost in thought gaze、caught mid-laugh
- 光影优先描述自然光的方向与漫射特性，阴影柔和
- 推荐光影词组：golden hour backlight diffusing through fabric weave、overcast diffused daylight wrapping evenly over texture、warm window spill casting a soft elongated shadow on the wall、mixed-temperature ambient — warm tungsten bounce from pavement, cool open-sky fill from above
- 允许环境中有虚化路人或真实街道噪声，增加生活质感
- 禁止描述任何走秀步道或 T 台相关意象

Lifestyle 模特互动动作库详见 `references/formats/lifestyle-style.md`。

**多套服装处理：** 每套服装（Outfit_01、Outfit_02……）独立完成阶段三至阶段五全流程，各自产出一条 15 秒完整视频；不同 Outfit 的 element 资产严格隔离，不得跨组引用。

### 阶段六：音频与组装

**BGM 生成：**
生成与服装风格匹配的 BGM。提示词描述风格基调、核心乐器配置、BPM 范围、情绪弧线（开场建立 → 中段展示 → 收尾留白）。提示词不得出现知名艺术家姓名。BGM 提示词规范详见 `references/formats/bgm-prompt.md`。

**视频组装：**
- 每套服装对应一条由阶段五直接生成的 15 秒完整视频，无需再做内部切分
- 多套服装输出时，各组视频依序排列，组间可加简短黑场过渡（0.5s）或直接硬切，依风格而定
- BGM 可共用一条贯穿全片，也可按 Outfit 风格差异分段换轨——以故事板 audio_layer 规划为准
- BGM 节拍点对齐镜头切换点；Foley 音效可采用 J-Cut 提前入画，强化动作预感
- 每段视频收尾镜头淡出与对应 BGM 段落尾音同步
- BGM 作为底层背景，Foley 音效在动作峰值处短暂提升至前景，二者不抢叙事空间

### 「一轮 = 一套分镜 + 一条视频」原则

- 每次完整流程（阶段三→六）产出一个场景 + 一套分镜 + 一条 15 秒视频，这是一个独立的创作单元
- **更换场景：** 当前轮视频生成完毕后，用户提出新的场景需求，从步骤 3c（场景候选）重新开始，沿用已有的模特服饰卡（element character 资产不需要重新生成），生成新的空场景图 → 新的六宫格分镜 → 新的 15 秒视频
- **更换服装：** 用户提出新的服装需求，从步骤 3a（刀版三视图）重新开始，走完完整阶段三至六流程，产出新的服饰卡与视频
- 每轮生成的视频独立存在，用户可自由决定是否与其他轮次的视频合并组装；如需合并，在所有目标视频完成后统一处理，BGM 可共用一条或按轮次分段
- 每轮结束后主动询问用户：是否需要更换场景或更换服装，继续新一轮创作

## 静默自检

交付前内部跑清单并重写弱项，不暴露给用户。

- 风格类型（Runway / Lifestyle）是否在阶段一锁定且全片一致？
- 质量测试是否通过（面料物理质感是否在至少 3 个镜头中不可替代）？
- 刀版三视图 → 模特服饰卡 → 空场景图 → 六宫格分镜 → 视频，资产链是否完整且一致？
- key_element 描述是否与各阶段生成图一致，无矛盾？
- 每个 shot 是否包含光影四要素（主光源/阴影/高光/环境反射）？
- 六宫格是否覆盖全景→中景→近景→特写→动态→收尾六个叙事节点？
- 视频提示词是否以动作节拍衔接替代绝对时间戳？
- 成片是否 ≤15s？若是，是否作为一次生成的完整片段（六格节拍写在同一条提示词内），而非分段拼接？
- Runway 风格是否保持了步态克制与高反差光影？Lifestyle 风格是否保持了自然动作与柔和光影？
- 多套服装时资产是否严格隔离？
- BGM 提示词是否未出现知名艺术家姓名？
- 全文语言是否与目标市场一致、无混杂？
