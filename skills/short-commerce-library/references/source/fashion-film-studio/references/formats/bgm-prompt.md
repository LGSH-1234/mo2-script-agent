
# BGM 提示词规范

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 风格匹配

依服装风格选择 BGM 基调：

| 服装风格 | BGM 基调 | 核心乐器参考 |
|---|---|---|
| 休闲/街头 | Nu-Jazz 或 Lo-fi Hip-hop | 电钢琴、刷鼓、低音贝斯、采样 |
| 礼服/晚装 | Chamber Jazz 或交响弦乐 | 弦乐四重奏、钢琴、竖琴 |
| 机能/概念 | Industrial Techno 或 Dark Ambient | 合成器、鼓机、低频脉冲、金属质感采样 |
| 民族/传统 | 融合民族乐器的当代编曲 | 民族弹拨/吹奏乐器 + 电子节奏层 |

## 提示词结构

BGM 提示词须包含以下要素：

- **风格基调**：1-2 句描述整体音乐氛围
- **核心乐器配置**：列出主要乐器
- **BPM 范围**：依风格给出合理区间（如 Lo-fi: 70-90 BPM；Techno: 120-140 BPM；Chamber Jazz: 80-110 BPM）
- **情绪弧线**：三段节奏
  - 开场建立：氛围铺垫，引入主题动机
  - 中段展示：节奏推进，配器丰富化，对应服装展示核心段
  - 收尾留白：渐弱或悬停，留出视觉余韵

## 合规要求

- 提示词不得出现知名艺术家姓名
- 不得模仿特定歌曲旋律
- 不得包含品牌名或商标

## 音量层次规范

- BGM 作为底层背景
- Foley 音效（高跟鞋落地、面料摩擦声）在动作峰值处短暂提升至前景
- 二者不抢叙事空间
- BGM 节拍点对齐镜头切换点
- Foley 音效可采用 J-Cut 提前入画，强化动作预感
- 每段视频收尾镜头淡出与对应 BGM 段落尾音同步

## 落 prompt 前自检

- BGM 风格是否与服装风格匹配？
- 提示词是否包含风格基调、乐器、BPM、情绪弧线？
- 是否未出现知名艺术家姓名？
- 情绪弧线是否覆盖开场→中段→收尾三段？
