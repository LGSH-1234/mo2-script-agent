
# 视频提示词文法与光影描述规范

> 可适配的模式与句式，按场景改写，不要逐字照搬。

## 视频生成提示词结构

以六宫格分镜预览图为主要参考输入，按六格叙事顺序分段描述各节拍，以动作节拍衔接替代绝对时间戳（禁用 "0-3s" 等绝对时间标记）。

### 参考图占位顺序
1. 六宫格分镜预览图 — 构图与节奏主锚
2. 模特服饰卡 — 角色形象一致性
3. 空场景图 — 光线与氛围锚定

### 节拍叙事顺序
节拍1（全景建立）→ 节拍2（走秀/互动）→ 节拍3（近景妆造）→ 节拍4（特写肌理）→ 节拍5（动态定格）→ 节拍6（收尾留白）

### 固定负面约束
no clothing morphing, no subtitles, no music（BGM 独立生成时）

## 光影描述核心规范（所有风格通用）

每个 shot 的光影描述必须包含以下五个层次：

### 1. 主光源定位
明确光源方向、色温及入射角度：
- 方向：正侧光 / 侧逆光 / 顶光 / 窗光 / 逆光 / 顺光
- 色温：暖 2700K-3200K / 中性 5000K-5500K / 冷蓝调 6500K+
- 入射角度：如"45度侧上方入射"

### 2. 阴影塑形
描述阴影硬度与覆盖比例：
- 硬阴影：sharp cast shadow
- 柔阴影：soft feathered shadow
- 覆盖比例：如"阴影占画面 40%，强化立体轮廓"

### 3. 高光落点
指定高光在面料或皮肤的具体位置：
- 如"高光沿肩线滑落，过渡至手背"
- 如"亮片在侧逆光下形成点状散射光晕"
- 如"丝绒面料在受光面呈现深色到浅色的方向性渐变"

### 4. 环境反射填充
描述周围环境对主体的色彩反射：
- 如"玻璃幕墙将城市蓝光漫射至服装背面"
- 如"暖调墙面向模特左颊补入环境色"
- 如"湿润沥青路面将霓虹灯光反射至裙摆下沿"

### 5. 光影情绪锚定
最后一句以感性词收尾，锚定整体光影氛围：
- 如"光影铺陈出疏离而克制的电影质感"
- 如"漫射光让面料质感温柔浮现，如同胶片正片"
- 如"高反差光影雕刻出廓形的雕塑感，冷峻而有力"

## 六宫格分镜预览图提示词规范

- 参考模特服饰卡与空场景图
- 明确"竖版 9:16 构图，3 行 × 2 列电影故事板网格，统一银盐胶片色调，每格内为竖屏视角构图"
- 每格依次描述对应 shot 的景别、摄影机角度、模特姿态与场景光影
- 光影质感词：chiaroscuro side lighting、golden hour rim light、diffused overcast fill（按场景选用）
- 视觉留白指引：在适当格位指定"大面积负空间留白于画面上方/侧方，主体偏置三分之一构图"
- 服饰肌理增强词：macro fabric grain visible、thread-level weave detail、specular highlight on surface micro-texture

## 刀版三视图提示词规范

- 明确指定"三视图技术平面图（正面 / 侧面 / 背面）横向并排，纯白背景"
- 描述款式廓形、结构线、缝合细节、五金配件
- 在图中关键细节旁可要求生成标注文字（面料名称、工艺说明）
- 无人体、无阴影、无环境，保持工程图风格

## 模特服饰卡提示词规范

- 横版宽幅布局：左侧面部特写（半身），右侧穿着服装三视图（正面/侧面/背面全身站立）
- 模特形象质感提升词组（通用基础层必加，按风格叠加专属层）
- 面料质感强调词组（按材质选用）
- 中性摄影棚光，无风，高反差背景衬托轮廓
- 禁止服装形变、禁止非预期配饰

## 全局语言规则

若用户使用中文交互或加载中文界面，提示词正文以中文撰写；对白语言遵循 Final_Video_Spec 中的输出语言设定。

## 落 prompt 前自检

- 光影描述是否包含全部五层（主光源/阴影/高光/环境反射/情绪锚定）？
- 视频提示词是否以动作节拍衔接替代绝对时间戳？
- 参考图占位顺序是否正确（六宫格→模特卡→空场景）？
- 负面约束是否已写入？
- 提示词语言是否与用户交互语言一致？
