# Seedance 2.5 · 官方提示词协议（模型无关 · 默认 Seedance 2.5）

> 吸收自字节跳动官方《Doubao-Seedance-2.5 企业级业务场景实践指南》。本协议规定所有"图像/视频生成环节"的
> 提示词结构、参考素材职责、声音与文字标记语法，以及"先确认后生成"门控。全项目通用，跨模型可适配，
> **默认目标模型为 Seedance 2.5**；用户明确指定其他模型（可灵/Runway/Sora/Pika/Midjourney/即梦等）时，
> 能力全部保留，按对应模型的语法适配执行。

---

## 0 · 执行铁律（每次生成前必守）

1. **模型与参数先确认，绝不替用户默认**：任何文生图/图生视频/配乐环节执行前，模型、分辨率、尺寸、
   风格若未确认，必须停在确认门向用户提问，不得自行选择。这是全流程的一致纪律。
2. **默认值说明**：用户未指定时，视频目标模型默认 **Seedance 2.5**；若用户改选其他模型则切换，能力不丢。
3. **生成参数不写进提示词**：时长、分辨率、比例、运动强度等可调参数由生成页面/接口设置，提示词只描述内容与意图。
4. **正向描述优先**：画面内容优先用正向语言表达；只有"素材职责、编辑范围、易误带入内容"需要显式限制。
5. **一份参考素材 = 唯一职责**：每张/每段素材声明它具体提供什么，并写明"不采用什么"，不要让模型自行猜测。

## 1 · 文本指令基础公式（组合式，可省略不需要的部分）

```
<主体> + <动作或事件> + <场景与环境>（可选）+ <视觉风格>（可选）+ <运镜或切镜>（可选）+ <声音>（可选）
═or═ 基础模板
<主体>在<场景与环境>中<主要动作或事件>。
画面呈现<视觉风格>。
镜头采用<景别、机位、运镜或切镜>。
声音包括<对白、环境声、音效或音乐>。
```

要点：
- **主体+动作**：说明"谁或什么在做什么"，动作优先概括主要过程，只为关键动作写具体细节，避免重复描述同一动作。
- **场景与环境**：地点、时间、天气、空间关系、背景状态。
- **视觉风格**：光线、色彩、材质、画面质感、整体氛围。
- **运镜/切镜**：景别、机位、镜头运动、对焦对象、镜头衔接。
- **声音**：对白、音色、环境声、音效、音乐。

### 范例
```
一名陶艺师在清晨的工作室里完成一只浅蓝色陶杯，将它从转盘上取下并放到木架中央。
窗外柔和晨光照入室内，湿润陶土呈现细腻光泽，工作台保持整洁。
镜头先以中景记录拉坯动作，再缓慢推近陶杯表面的纹理，最后切到木架正面。
保留转盘低沉转动声、陶土摩擦声和轻微室内环境声。
```

## 2 · 有参考素材时：明确素材职责（映射必须写进提示词）

上传参考后，必须说明每份素材具体提供什么；素材中的人物/背景/构图容易被误带入成片时，还要写明"不采用什么"。
不要只依赖图片里的文字标注，也不要让模型自行判断多份素材分别对应谁。

```
模板：
@图片1用于<主体>的<外貌、服装、结构或材质>。@视频1用于<动作、运镜或节奏>。@音频1用于<角色>的<音色、台词、环境声或音乐>。
<主体>在<场景>中完成<主要动作或事件>。画面呈现<视觉风格>，镜头采用<镜头表达>。

示例：
@图片1用于<陶艺师>的五官、发型和深绿色围裙，不采用图片背景。
@图片2用于<陶艺工作室>的木质工作台、窗户位置和晨间光线，不采用图中人物。
@视频1用于双手拉坯、托起陶杯和放置陶杯的动作节奏，不采用视频中的人物身份、服装和场景。
```

**同物体多视角**（同一人物/商品的不同视角）：
```
@图片1定义同一盏折叠台灯的正面外观。@图片2定义同一盏折叠台灯的左侧结构。
@图片3定义同一盏折叠台灯的右侧结构。@图片4定义同一盏折叠台灯的背面结构。
四张图片共同定义同一盏折叠台灯，成片中始终只有一盏折叠台灯。
```

**参考视频已准确给出动作/运镜/顺序时**：提示词只需说明继承哪些内容，不必逐动作复述（重复描述可能与素材冲突）。
白模视频主要提供运动与空间骨架，仍需写清希望生成的主体、场景、动作、风格。

## 3 · 声音与文字的特殊字符（自然语言外显区分）

| 内容 | 符号 | 示例 |
|---|---|---|
| 音乐 | `()` | (背景播放舒缓节奏的钢琴乐) |
| 音效 | `<>` | <远处传来钟声> |
| 台词 | `{}` | {你好，欢迎回来} |
| 字幕 | `【】` | 【第一章：启程】 |

- 需要控制字幕/声音时，直接写明保留和不采用的声音类别：
  ```
  无背景音乐，只保留人物对白、环境声和动作音效。
  不要字幕。不要任何声音。
  ```
- **非中文台词**：在台词前明确语言——`女孩用日语轻声说：{もう大丈夫です}`
- **控制语言/口音**，推荐公式：`台词语言 + 地区变体或口音 + 表达方式 + 说话人 + {台词内容}`：
  ```
  台词语言：美式英语。女孩用自然、口语化的美式英语说：{I thought you weren't coming.}
  台词语言：地道的洛杉矶美式英语。年轻男子用自然的洛杉矶口语说：{No way, you actually made it.}
  ```

## 4 · 跨模型适配（能力全部保留）

| 目标模型 | 适配要点 |
|---|---|
| **Seedance 2.5 / 即梦（默认）** | 上文本公式 + 参考角色映射 + 特殊字符直接适用；精简、不堆比喻；每镜2-3s；只出音效 |
| 可灵 | 中文可加深语义理解；运镜参数0.4-0.6；参考图角色职责同样写清 |
| Runway | 运动控制词优先（Gen-3运动参数）；镜头运动显式 |
| Sora | 详细物理因果关系，自然语言长句；口型/台词按Sora语法 |
| Midjourney / Flux / SD（文生图） | 关键词式英文；`--ar`/`--style raw` 等仅用户明确指定时使用 |
| Suno / Udio（配乐） | Style Prompt短而准、Genre放首位；Lyrics完整有结构标签 |

## 5 · 确认门（Hard-Stop，模型无关通用）

```
生成前必停：🛑【确认门】已完成设计方案与提示词。请确认以下参数后执行生成：
  · 目标模型：[默认 Seedance 2.5 ／ 用户指定]
  · 分辨率 / 时长 / 尺寸 / 画幅：[已确认 ／ 待确认]
  · 风格基调：[已锁定 ／ 待确认]
用户确认后，才进入文生图/图生视频/配乐执行；用户未确认则绝不替其选择。
```

**未指定模型时默认 Seedance 2.5；用户指定其他模型则按其能力执行，所有能力与工艺细节完整保留。**
