## 二、六维逐维详解

### ① 景别节奏（Shot Size Rhythm）

**核心问题**：相邻镜头的景别变化是否符合视觉认知规律？

**景别梯度（从近到远）：**
```
大特写(BCU) → 特写(ECU) → 近景(CU) → 中近景(MCU) → 中景(MS) →
中全景(MLS) → 全景(FS) → 远景(LS) → 大远景(ELS)
```

**理想节奏模式：**
| 模式 | 说明 | 适合场景 |
|------|------|---------|
| 渐进式 | 特写→中景→全景（逐级拉远） | 揭示/释放 |
| 渐进式 | 全景→中景→特写（逐级推进） | 聚焦/紧张 |
| 波浪式 | 中景→特写→中景→全景（均匀波动） | 对话/常规叙事 |
| 跳跃式 | 大远景→特写（两极跳） | **仅在以下场景可用：** 惊吓/节奏突变/风格化 |

**危险模式（禁止，除非用户明确要求硬切）：**
- 特写→大远景（中间跳过多级，观众视觉迷失）
- 连续3镜以上同景别（产生"跳帧"感，除非固定机位对话）

**增强技巧**：在跳切中加入"桥梁帧"——如特写跳全景前，先让主体入画走出画，或者前景遮挡过渡。

### ② 机位逻辑（Camera Position Logic）

**核心问题**：相邻镜头的机位是否在同一180度线内？

**180度线规则：**
```
         [主人物A]
             |
   镜1←------+------→镜2（越轴）
             |
         [主人物B]

镜1: A的过肩看B（机位在B侧，拍A背+脸）
镜2: B的过肩看A（机位在A侧，拍B背+脸） ← 越轴！
正确：镜2应在B的另一侧，拍B背+脸
```

**如何合法越轴（必须有"转场桥梁"）：**

| 桥梁技法 | 做法 | 示例 |
|---------|------|------|
| 人物穿镜 | 角色从镜头前走过遮挡 | ①→[角色走过镜头全黑]→②（已越轴） |
| 推近/拉远跨线 | 推至大特写，切另一侧中景 | ①推至A眼部特写→②切B过肩（已越轴） |
| 中性镜头插入 | 插入一个沿轴线方向的镜头 | ①→②插入沿轴线拍的POV→③（已越轴） |
| 镜头自身横移 | 镜头横摇跨越轴线 | ①横摇从A左侧到A右侧→②新机位 |
| 大空镜过渡 | 插入无方向性的环境空镜 | ①→②天花板/云朵→③（已越轴） |

---

### ③ 运动方向（Movement Direction Continuity）

**核心问题**：上一镜的运动方向与下一镜的承接方向是否连续？

**运动连续性三大法则：**

**法则1 · 出画入画一致性**
```
人物从画左出画 → 下一镜人物应从画左入画（视觉上"继续从左边走进来"）
人物从画右出画 → 下一镜人物应从画右入画
```

**法则2 · 运动矢量连续性**
```
人物向左跑 → 下一镜继续向左（运动矢量不变）
人物向左跑 → 下一镜变为向右（运动矢量反转=视觉断裂，除非叙事需要"转身"）
```

**法则3 · 视线方向一致性**
```
人物看画右 → 下一镜揭示的是画右的内容
人物看画右 → 下一镜切到人物正面但视线方向转为画左（断裂×）
```

**常见断裂模式（禁止）：**
- 追逐戏中：追逐者从左向右跑→下一镜从右向左跑（感觉在往回跑）
- 对话时A看画右→切A近景再看画左（观众困惑A在看谁）
- 汽车从左向右行驶→下一镜汽车从右向左行驶（方向反转）

---

### ④ 光影色温（Lighting & Color Temperature Continuity）

**核心问题**：相邻镜头的色温和光影风格是否跳变？

**色温基准表：**
| 光源 | 色温(K) | 视觉特征 | 场景示例 |
|------|---------|---------|---------|
| 烛光/篝火 | 1800-2200 | 极暖橙红 | 烛光晚餐/篝火夜 |
| 白炽灯 | 2700-3200 | 暖黄 | 居家/咖啡馆/酒店 |
| 卤素灯 | 3200-4000 | 暖白 | 室内实用光 |
| 荧光灯 | 4000-4800 | 中性偏冷 | 办公室/便利店 |
| 正午阳光 | 5200-5600 | 纯白 | 户外日景 |
| 阴天/阴影 | 6000-7000 | 冷蓝 | 阴天/树下阴影 |
| 蓝天 | 7000-10000+ | 极冷蓝 | 高海拔/黄昏蓝调 |

**连续性规则：**
- 同场景连续镜头：色温变化不得超过 ±500K（有合理理由除外，如日落）
- 跨场景切换：色温变化可以有，但需与叙事时间推进合理对应
- 同侧光位：主光方向应保持一致（如人物左侧45°光源应是A侧→B侧统一的）

**光影跳变解决方案：**
| 问题 | 解决方案 |
|------|---------|
| 户外→室内色温跳 | 用人物过门洞的过渡镜 + 色温渐变 |
| 阳光→烛光色温跳 | 用太阳落山的缩时 + 屋外变暗的过渡镜 |
| 光位不统一 | 在场景设定时锁定主光方向作为 @SceneID 特征之一 |

### ⑤ 主体位置（Subject Position Continuity）

**核心问题**：关键主体在画面中的位置是否发生瞬移？

**三分法坐标定位：**
```
┌──────┬──────┬──────┐
│ 左1/3│ 中1/3│ 右1/3│
│ (A区) │ (B区) │ (C区) │
├──────┼──────┼──────┤
│ 左1/3│ 中1/3│ 右1/3│
│ (D区) │ (E区) │ (F区) │
└──────┴──────┴──────┘
```

**连续性规则：**
- 对话/双人场景：A始终在左区→B始终在右区（不得静默互换位置）
- 单人追踪：人物持续在画左移动→下一镜应还在画左（不能瞬移至画右）
- 反应镜头：上一镜A看画右→下一镜应是A的正面（视线匹配），而不是A从画左看画右

**位置瞬移修复方法：**
| 问题 | 修复方案 |
|------|---------|
| A在画左→切镜后A在画右 | 插入人物走动换位的过渡镜 |
| 道具在画面前景→切镜后消失 | 检查 @PropID 引用是否一致 |
| 多人场景中人物顺序改变 | 锁定站位编码作 @CharID 特征之一 |

### ⑥ 情绪强度（Emotional Intensity Continuity）

**核心问题**：相邻镜头的情绪强度是否有合理递进/承接？

**情绪强度分级标准：**
```
★ 平静    —— 日常状态，表情中性，光线均匀
★★ 微澜   —— 轻微关注，微表情，开始变化
★★★ 波动  —— 明显反应，面部肌肉参与，呼吸变化
★★★★ 强烈 — 剧烈情绪，瞳孔变化，呼吸急促/屏住
★★★★★ 爆裂 — 爆发，失控，生理极限反应
```

**递进规则：**
- 同场景情绪是**波浪式运动**，不能长时间平线
- 情绪跳变（★→★★★★）可以，但必须有叙事触发事件
- 情绪回落（★★★★→★★）需要缓冲——中间加道具/环境/行走镜头
- **最常见的情绪断裂**：激烈争吵后直接切到平静的日常——缺情绪缓冲带（需要"余波"镜）

**情绪转译物理参数对照表**（确保情绪词不在提示词中出现，而是转为光学参数）：

| 情绪 | 转译后的光学参数 |
|------|----------------|
| 悲伤 | 低饱和度(-20%)，偏蓝绿白平衡(6200K)，柔光漫射，眼周局部欠曝-0.3EV |
| 紧张 | 手持微晃，浅景深f/2，快速呼吸感焦点漂移，高对比度，暗部裁切 |
| 温暖 | 暖调3200K，柔光侧45°，光比2:1，暖色调HSL偏移，轻微扩散柔光 |
| 孤独 | 广角14-24mm，人物偏左/右1/3，大面积负空间，冷调4800K，长阴影 |
| 震撼 | 缓慢推进，超广角，宏大全景，高饱和度+10%，锐度提升，静态中的人物体 |
| 恐惧 | 手持极晃，极浅景深f/1.4，欠曝-1EV，冷调7000K，不稳定的焦段呼吸 |
| 希望 | 光晕渐变，魔幻时刻光线，暖橙渐变，正对逆光+40%曝光补偿，柔焦 |
| 疯狂 | 倾斜角度，广角变形，高饱和+20%，极端对比，霓虹色，旋转运镜 |

## 四、常用转场技法六维影响矩阵

```
技法            ①景别   ②机位   ③方向   ④色温   ⑤位置   ⑥情绪
──────────────────────────────────────────────────────────
切(Cut)           自由    自由    注意    注意    注意    自由
匹配剪辑(MC)      匹配    (可跳)   匹配    自由    匹配    匹配
视线引导(LTR)     自由    连续    连续    自由    自由    自由
动作匹配(AM)      自由    (可跳)   匹配    自由    自由    自由
叠化(Dissolve)    自由    自由    自由    过渡    自由    自由
声音桥(SB)        自由    自由    自由    自由    自由    承接
前景遮挡(FO)      自由    桥梁    自由    自由    过渡    自由
Wipe              自由    自由    自由    自由    自由    自由
急推/急拉(PZ)    聚焦    自由    自由    自由    聚焦    增强
黑场(Blackout)    (重置)  (重置)  (重置)  (重置)  (重置)  (重置)

备注：
- "自由" = 该技法对此维度无特殊约束
- "注意" = 该技法下此维度仍需手动检查
- "匹配" = 该技法会自动或通常在此维度保持连续
- "过渡" = 该技法擅长处理此维度的变化
- "桥梁" = 该技法可用于合法越轴
- "(可跳)" = 该技法允许此维度跳跃（因为匹配点在别处）
- "(重置)" = 黑场后所有维度可以重新建立，类似"新章节开始"
```

## 五、常见衔接问题速查

```
问题现象                  → 涉及维度 → 修复方案
────────────────────────────────────────────────
画面突然跳远/跳近         → ①景别    → 插入中间景别或加前景遮挡
人物看的方向不对           → ②机位    → 检查180度线，补中性镜头
追逐戏感觉在往回跑         → ③方向    → 统一所有镜头的运动矢量
室内光线忽暖忽冷           → ④色温    → 统一场景色温锚定值
人物在画面左右瞬移         → ⑤位置    → 锁定主体位置坐标+过渡镜
情绪还没到就切镜了         → ⑥情绪    → 延长停留时间+补反应镜头
连续三镜同景别像跳帧       → ①景别    → 重剪至少一镜的景别
看着像图片轮播而不是视频   → 全维度   → 全六维逐对排查，最可能缺③⑥
