## 一、图片提示词双版本输出规则（0822强制 · 每次文生图按用户需求交付）

**图像模型按用户需求输出两个版本——常规版 + Midjourney 专属版，每个版本均含【中文版】+【英文版】：**

### 常规版（平台无关三段式）
结构：`【引用表】→【正文】→【条件式负向约束】`
- **引用表**：`@CHAR_xxx（3/4面部+全身+表情组）、@SCENE_xxx（3/4视角+锚点物件）、@PROP_xxx、@PALETTE_xxx`——资产逐一点名
- **正文**：身份锚（外貌/服装/体态）→ 光影（单一动机光源+方向）→ 构图（景别/对称或非对称/透视）→ 色彩（主色/辅色/点缀 60:30:10）→ 材质细节（皮肤毛孔/布料纹理/环境颗粒）
- **条件式负向约束**：以"除非…否则不要…"或"画面中禁止…"的肯定式改写（不依赖模型原生负面词）

### Midjourney 专属版（MJ 语法适配版）
保留全部视觉决策（身份锚/光影/构图/色彩），按 MJ 语法改写：
1. 正文以**自然语言短句**组织（MJ 不吃多行分段结构），风格词前置、细节压缩，逗号连接；
2. 参数**外置**到行尾：`--ar 2.39:1 --style raw --v 6.1`（画幅/风格/版本按实际需求）；
3. **省略负向约束**（MJ 无原生负面词），用正向可见描述替代（例：不写"不要文字"，写"干净的画面上无任何文字"——改为描述画面里确切有什么）；
4. 保留 `@CHAR_` 引用与中英双语——中文版供用户审阅，英文版供 MJ 执行。

**示例（角色身份展板）：**
```
【中文版】同一角色的三格电影身份展板：左侧正面全身（无头）、中间背面全身、右侧3/4面部特写（无表情+抿嘴双版本），底部身高刻度尺，中灰背景，方向性电影灯光，真实皮肤毛孔。--ar 21:9 --style raw
【英文版】Side-by-side film character identity board of the same person on flat mid-grey backdrop: headless front full-body left, back full-body center, 3/4 face close-up right (neutral + lip-press versions), height ruler along edge, soft directional cinematic lighting, pore-level skin. --ar 21:9 --style raw
```

### 双版本交付纪律
- 用户明确指定 Midjourney → 交付 MJ 专属版为主；用户指定其他平台/模型 → 跟随用户（常规版适配即可）；用户无指定 → 双版本并行交付供其选择。
- **视频提示词不套用此双版本规则**——仍按既有骨架（14段/7-Block/15区块）中英双语交付。
- 中英双语规则持续生效：所有提示词必须【中文版】+【英文版】成对交付。

## 二、叙事五元素引擎（场景级细化）

每个场景在动笔前，用五元素做一次"场景体检"——五元素全部回答完才可落镜：

| # | 元素 | 体检问题 | 落镜判据 |
|---|---|---|---|
| 1 | 人物（WHO） | 这一场戏里，谁在渴望什么？ | 每个角色的 want 一句话可复述，且彼此冲突或错位 |
| 2 | 事件（WHAT） | 这场戏真正发生的事是什么？ | 用"X 使 Y 发生了 Z"陈述，删掉它剧情缺一块 |
| 3 | 空间（WHERE） | 空间在怎么参与叙事？ | 空间有"性格"——压迫/开放/迷宫/祭坛，且随剧情改变 |
| 4 | 时间（WHEN） | 时间在怎么流动？ | 昼夜/季节/血迹/道具状态跨镜一致（时间链） |
| 5 | 因果（WHY） | 这场戏为什么存在？ | 每镜至少挂一条叙事链（因果/情绪/空间/视线/时间/主题） |

**五元素引擎的本 skill 用法**：五元素全部完成后才进入分镜；任何一镜若无法回答"它推动五元素中的哪个"→ 该镜可删（对照本 skill 已有的砍留取舍铁律执行）。

## 三、共享真相与双重真相定律

### 共享真相（Shared Truth）——先于六件套/七块/十四段
- 一场戏开写前，先锁定"这一场的共享真相"：一句话说清这一场**对观众而言真相是什么**（例：朴式复仇中"复仇者其实是最大的囚徒"）。
- 共享真相决定所有镜头的取舍基准——任何镜头若削弱共享真相，删；若强化，留。
- 共享真相写进场景上下文，逐镜保持（空间图+主镜头锚定），根除"镜头各自为政"。

### 双重真相定律（Level 5 表演 = AND 非 THEN）
- 顶级表演不是"先A后B"（then），而是**同时**呈现两种矛盾真相（and）——角色一边微笑一边握紧刀，一边说"我原谅你"一边瞳孔收缩。
- 提示词写法：把矛盾状态写成**共存**（"嘴角上扬的同时，下颌线绷紧；声音平静的同时，指节发白"），不写成先后序列。
- 本 skill 风格化的双真相：愤怒的人最安静、复仇者在熨衣服、爱意与杀意同框——这正是双真相定律的范例。

## 四、对比配对（Contrast Pairing · 四轴镜像）

同一场戏内，用四轴做"镜像对比"，让风格浓度成倍提升：

| 轴 | 配对方式 | 例 |
|---|---|---|
| 尺度轴 | 巨↔微 | 巨构建筑↔一枚徽章特写；人群↔一只眼睛 |
| 动静轴 | 动↔静 | 疯狂的动作↔凝固的凝视；喧嚣↔突然静默 |
| 明暗轴 | 光↔影 | 一盏烛光↔大片黑暗；高光面↔浓重阴影 |
| 情绪轴 | 暖↔冷 | 温情动作↔冰冷眼神；甜蜜色彩↔残酷事件 |

**纪律**：每段落至少植入一组对比配对，且配对的两端必须在同一画面或紧邻两镜内同框出现（远距离割裂不算配对）。

## 五、锁模式目录（9把锁 · 状态而非过渡）

跨镜/跨段锁定以下 9 个维度，任何一锁未锁即视为状态漂移风险：

| 锁 | 锁定内容 | 提示词写法 |
|---|---|---|
| SCALE | 画面内事物尺度比例 | "THE SCALE LAW：巨物给具体米数+人形参照物，什么情况算失败" |
| HEIGHT | 摄影机高度/人物身位 | "camera at chest height, character eye line at X" |
| COUNT | 画面内人数/物件数 | "EXACT 3 CHARACTERS—NO DUPLICATES" |
| EMOTION | 情绪状态（1-10） | "emotion 7/10, held" |
| OFF-SCREEN | 画外空间关系 | "the door is 1m left of frame, sounds approach from left" |
| EYELINE | 视线目标 | "eyes locked on X"（不写"看向那边"） |
| SPEECH-COUNT | 每角色台词句数 | "Only-the-Line：每人只说引号里那一句" |
| TIMECODE | 时间戳/时长 | "00:00-00:12, beats at 00:04/00:08" |
| IN-FRAME-STATE | 帧内状态 | "the wound stays, the blood stays, the prop state stays" |

**纪律**：每镜提示词至少显式锁 3 把锁；动作密集镜加锁 TIMECODE 与 IN-FRAME-STATE；跨镜锁写"NOT NEGOTIABLE"。

## 六、消除AI感10大光学法则（生成后逐条验收）

| # | 法则 | 验收标准 |
|---|---|---|
| 1 | 胶片压缩 | 暗部有信息、高光不过曝，整体像胶片而非HDR测试图 |
| 2 | 皮肤次表面散射 | 皮肤透光、耳廓泛红、指缝透光，不"塑料" |
| 3 | 湿角膜 | 瞳孔有catch-light高光，眼睛是湿的、活的 |
| 4 | 变形宽银幕椭圆焦外 | 焦外光斑为竖向椭圆（anamorphic bokeh） |
| 5 | 地面摩擦 | 物体与地面有接触阴影、有尘埃，不悬浮 |
| 6 | 布料延迟 | 衣物有重力与惯性，跟随身体动作滞后半拍 |
| 7 | 气溶胶 | 空气中有尘/雾/烟/雨，光可见（体积光） |
| 8 | 操作员呼吸 | 手持/肩扛镜头有极轻微呼吸感，不绝对静止 |
| 9 | 单一动机光源 | 全画面只有一组光源逻辑，绝无"两个太阳" |
| 10 | 非对称细节 | 人物/环境有不对称的微小瑕疵（痣、破损、偏移），不完美对称到假 |

**纪律**：质量门检查时逐条对照；任一法则不过 → 进 Loop 按本 skill 既有治理硬顶修订。

## 七、颜色世界预设矩阵（60:30:10）

每个项目先选定"颜色世界"，全片色彩纪律基于它执行：

| 预设 | 60%主色 | 30%辅色 | 10%点缀 | 适用 |
|---|---|---|---|---|
| 冷峻阴谋 | 低饱和青灰 | 深蓝/黑 | 单一警示色（如铁锈橙） | 悬疑/权谋/谍战 |
| 暖调怀旧 | 琥珀/赭石 | 褪色奶油 | 红铜高光 | 年代/回忆/温情 |
| 高反差黑白 | 纯黑 | 纯白 | 单一强调色（如血红） | 极端戏剧/复古 |
| 低饱和写实 | 自然灰 | 泥土色 | 环境原色微调 | 纪录片/写实 |
| 超现实高饱和 | 主色一（如玫红） | 主色二（如青） | 荧光点缀 | 时尚/幻想/音乐影像 |
| 单色极简 | 单一色相全阶 | 同色相深/浅 | 无或近白 | 极简/概念/海报感 |

**纪律**：①项目启动即锁定颜色世界（写进场景资产与 @PALETTE）；②跨镜色彩统一（相邻镜头观感一致，调色师只精修不发明）；③本 skill 的风格色彩宪法（如有）优先于通用矩阵，冲突时以本 skill 为准。

## 八、尾音跨接（Tail-Feeding）与静默框架

### 尾音跨接
- 对话宽镜：把上一镜台词的**尾音**喂进本镜首秒（帮唇形与节奏对上）；
- 每段新生成：用上一段收尾那句台词开场——情绪随文本跨过剪辑点。

### 静默框架
- 每场戏开场留**安静一秒**（无台词无动作，可让某人说一个短词如"嗯"），让模型把站位/物件/光线"拍"下来——省掉这一秒，人物就开始在镜头之间换位置；
- 台词前后各留 1 秒静默（前置音频上下文：先把环境底噪立起来，再让台词落地）；
- 用一条共享的连续环境底噪把生成的镜头粘合成同一空间。

## 九、状态资产物理论证（防塑料化铁律）

- **一张图永不完整过模型两次**：换装/伤口/老化等状态变化，只在基准资产上做蒙版局部修改（mask只放行改动部位，其余像素不动）——每多一次pass毁一次纹理、漂一次颜色（状态变化约每次衰减20%）；
- **链改禁止**：基准→受伤→重伤→战损的链式修改3次即塑料化；组合状态从基准一次性叠加生成；
- **单一衍生源公理**：每个状态资产都以最初锁定压测通过的基准资产为唯一底图；
- **压测三关**：十连生成（不同姿势不同光线，10/10可认出）+ 与其他资产同框测 + 放进真实场景光线测——不过关，问题在描述文字不在模型，改词重测。

## 十、十五次迭代止损铁律

- 十到十五次迭代仍不收敛 → 问题不在措辞，在结构——拆成两个镜头/去掉一个动作/换个角度，结构问题只能靠结构简化解决；
- 一次只改一处：每次迭代只改一行，其余逐字保留；版本/改动/裁决全部记日志；
- 与既有治理硬顶（revision≤3/send_back≤3）并存：3轮=修订轮次上限，15-20次=整镜累计迭代上限，两者都不可突破。

## 十一、控制图系统（5种 · 复杂项目必用）

| 图 | 作用 | 何时画 |
|---|---|---|
| 分镜图 | 每镜一格的视觉节奏总览 | 分镜完成后 |
| 深度图 | 前/中/后景层次，防扁平 | 空间复杂场景 |
| 轨迹图 | 人物/物体运动路径 | 动作密集镜头 |
| 摄影机路径图 | 运镜轨迹与动机 | 长镜头/复杂运镜 |
| 空间图 | 地标/方位/机位侧/永不越线 | 多镜场景（GEO空间锁升级） |

**纪律**：多镜场景先画空间图再写分镜；长镜头先画摄影机路径图再生成；控制图是"内部工作纸"，不进交付物。

## 十二、分镜图四安全铁律 + 连接器块

### 分镜图四安全铁律
1. **图面无字母**：分镜参考图内不出现任何文字/字母/水印（模型会把字母画进画面）；
2. **正向连接器**：跨镜连接只用正向可见元素（人物面向、光线方向、物件位置），禁止负向描述；
3. **前视图禁俯视蓝图**：建筑/场景分镜用前视或3/4视角，禁止俯视蓝图式（模型会输出"设计图纸"感）；
4. **原始帧打底重绘**：以真实帧为底图局部重绘，不裸写文字让模型自由发挥起点。

### 连接器块标准语法（跨镜连续性）
`[CONNECTOR: prev end → next start | character position | light direction | prop state | audio carry]`
每个新生成段开头粘贴上一段的连接器块，逐字不差。

## 十三、风格渗漏三通道防线

跨项目/跨风格工作时，用三通道防线防止风格污染：
1. **图像通道**：资产卡中性化（平光/中性背景/真实材质），风格只存在于场景卡与提示词中；
2. **文本通道**：Style Prefix 逐字复制，禁止混入其他项目风格词；
3. **结构通道**：@命名字典独立维护，禁止翻译回写/跨项目共用资产标签。

**本 skill 用法**：本 skill 风格词只从本 skill 的 style-dna/style prefix 取用；切换风格时先清空上一项目文本残留再开工。
