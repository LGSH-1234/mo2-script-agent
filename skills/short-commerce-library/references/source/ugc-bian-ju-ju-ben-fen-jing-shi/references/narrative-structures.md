# 叙事结构库 · 完整版

> **核心原则**：不默认套三幕剧。从八种结构中按题材精准匹配，并至少运用一种创意颠覆技法。

---

## 一、八种叙事结构选型指南

### 1. 三幕剧（冲突升级式）

**结构：** 建置(Act 1) → 对抗(Act 2) → 解决(Act 3)

**节拍点骨架（标准90分钟）：**
```
第一幕（0-25min）：
  · 开场画面（1-3min）：展示世界常态
  · 主题陈述（5min）：有人说出"核心命题"
  · 催化剂（10-12min）：打破常态的事件
  · 第一转折点（25min）：主角决定踏上旅程

第二幕（25-85min）：
  · 副线开始（30min）：爱情/友情线引入
  · 中点（55min）：伪胜利或伪失败， stakes升级
  · 反派逼近（60-75min）：压力持续增大
  · 一切尽失（75min）：最低谷，希望破灭
  · 灵魂暗夜（80min）：主角重新认识自己
  · 第三转折点（85min）：获得新的解决方案

第三幕（85-120min）：
  · 高潮（110min）：终极冲突
  · 结局（110-120min）：新的常态
```

**AI视频缩短版（15-60秒）：**
```
· 建置（前20%）：展示世界/角色常态
· 催化（20%-30%）：触发事件（只需1-2镜）
· 对抗/升级（30%-70%）：冲突不断升级（最集中的部分）
· 低谷（70%-80%）：短暂停顿/危机（1镜即可）
· 解决（80%-100%）：高潮+新的常态（快节奏收束）

【15秒TVC版】
· 常态（0-3s）→ 问题/触发（3-5s）→ 行动/冲突（5-12s）→ 解决/释放（12-15s）
```

**适合题材：** 剧情片、悬疑、动作、科幻、几乎一切传统叙事

---

### 2. 起承转结

**结构：** 起（引入）→ 承（发展）→ 转（变化）→ 结（收束）

**节拍点（按时长四等分）：**
```
起（前25%）：引入角色/场景/常态——"这是谁、在哪、什么状态"
承（25-50%）：动作开始、情感建立——"发生了什么、开始在意"
转（50-75%）：关键变化、情绪转折——"事情变得不一样了"
结（75-100%）：结果呈现、情绪释放——"所以……"
```

**适配时长：** 15秒 / 30秒 / 45秒短视频

**例：** 15秒宠物罐头广告
```
· 起(0-3s)：清晨厨房，主人自己随便应付早餐
· 承(3-8s)：猫咪蹭腿，抬头看向主人
· 转(8-12s)：主人郑重为猫咪开一罐营养罐头
· 结(12-15s)：猫咪满足进食，主人微笑，产品logo淡入
```

**为什么这个结构适合短视频：**
- 不需要让观众深度共情角色（三幕剧需要"先爱上角色再经历冲突"）
- 情绪曲线平滑，适合竖屏滑动式消费
- 每个1/4只有一个信息点，不容易滑走

---

### 3. 环形结构

**结构：** 结尾呼应开头，形成闭环

```
开场镜头 ↔ 结尾镜头（画面/动作/声音完全呼应或反向呼应）
     ↓              ↑
   展开1  ← 收束3 ←
     ↓              ↑
   展开2 → 高潮 → 收束1
```

**适合题材：** 文艺片、哲学思考、人生感悟、欲望都市式旁白

**AI视频注意事项：**
- 环形结构在短片中容易被观众理解为"没讲完"——必须确保闭环有"增量"
- 首尾呼应的画面应该在结尾时已经**被新的情绪注解**（同一句旁白/同一片风景，但心态变了）

---

### 4. 多线叙事

**结构：** 多个独立故事线最终汇合

```
线A ──→ ──→ ──→ ──→ ┐
线B ──→ ──→ ──→ ──→ ┼──→ 汇合点 → 结局
线C ──→ ──→ ──→ ──→ ┘
```

**交叉频率建议：**
| 时长 | 交叉频率 | 说明 |
|------|---------|------|
| 15-30秒 | 每3-5秒切换 | 快节奏交叉，用视觉风格区分各线 |
| 30-60秒 | 每5-8秒切换 | 可稍长停留建立每线情绪 |
| 60秒+ | 每8-15秒切换 | 标准多线蒙太奇节奏 |

**适合题材：** 群像故事、社会题材、城市宣传片、品牌多角色TVC

**AI视频风险：** 用户容易没有时间建立对任何一条线的共情，建议保持线数 ≤ 3

---

### 5. 碎片化叙事

**结构：** 非时间线性、情感驱动的碎片拼接

```
碎片C ←---- 碎片A -----→ 碎片E
  ↑                       ↓
碎片D ←---- 碎片B -----→ 碎片F
                    ↓
               情感核心
```

**特征：**
- 不按时间顺序排列
- 靠情绪/主题/视觉母题连接而非因果关系
- 观众通过拼图式理解获得参与感

**适合题材：** 王家卫风格、MV、艺术短片、个人情感纪录

**要求：**
- 必须有强大的情感核心/视觉母题贯穿全部碎片，否则会变成一推无意义的镜头
- 每个碎片在"情绪光谱"上必须有明确位置（不能所有碎片同一情绪强度）
- 视觉风格必须高度统一（色彩/质地/镜头语言），否则拼接感太强

---

### 6. 章节式结构

**结构：** 工整分段的独立章节，每章有自己的小结构

```
标题卡1 → 第一章(起承转) → 标题卡2 → 第二章(起承转) → 标题卡3 → 第三章(起承转结)
```

**视觉特征：**
- 标题卡/中断作为结构标记
- 每章有自身的小节拍
- 各章之间通常有并列而非因果的关系

**适合题材：** 韦斯·安德森风格、产品说明书式广告、传记式短片、教育/科普

**AI视频技巧：**
- 标题卡是极好的"重置"机会——六维衔接可以在标题卡后重新建立
- 各章之间可以完全不同风格（但整体色板建议统一）

---

### 7. 倒叙/时间折叠

**结构：** 从非原点开始，通过时间标记非线性展开

```
现在──→┐
        ↓
    时间标记A → 过去事件A1 → 过去事件A2 → 回到现在
        ↓
    时间标记B → 过去事件B1 → 回到现在
        ↓
    时间标记C → 过去事件C1 → 过去事件C2 → 回到现在 → 结局
```

**关键节点（诺兰式）：**
- 时间标记（明显的视觉提示：颜色变化/日期字幕/锚点道具）
- 多个时间层同时运作（如《盗梦空间》四层梦境）
- 每一层有自己的"物理规则"和"时间流速"

**适合题材：** 诺兰风格、悬疑、犯罪、侦探、时间主题

**AI视频风险：**
- 时间折叠在短于60秒的内容中极难执行——观众没有时间建立"时间层"的心理地图
- 短于60秒建议改为：双时间层（现在+回忆），用明显视觉标识区分
- 长于60秒可以用：三时间层（现在+近过去+远过去），用色彩空间区分

---

### 8. 单镜头/实时

**结构：** 无剪辑，一个镜头从头到尾

```
[单镜头全片 —— 没有剪辑点]
```

**变体：**
- 真·单镜：一个镜头拍到底（如《1917》《Birdman》）
- 假·单镜（缝合式）：多个镜头通过前景遮挡/匹配剪辑/暗转缝合
- 实时单镜：时间流速=现实时间（适合访谈/监控类）

**AI视频优势：** 无需要处理六维衔接问题（没有镜头切换！）

**AI视频风险：**
- 画面中不能出现任何"生硬变化"——所有运动必须物理因果驱动
- 人物不能瞬移、光线不能突变、道具不能消失
- 对AI视频生成能力要求最高（长镜头一致性仍是AI弱项）
- 建议使用"缝合式单镜"——用前景遮挡+黑场做隐蔽切点

## 二、结构选型决策树

```
用户需求
  │
  ├─ 有明确故事线、冲突 → 三幕剧
  │
  ├─ 短视频/品牌广告/15-30s → 起承转结
  │
  ├─ 情感驱动、非线性 → 碎片化（王家卫方向）/ 环形（文艺方向）
  │
  ├─ 群像、城市、组织 → 多线叙事
  │
  ├─ 工整、复古、幽默 → 章节式（韦斯·安德森方向）
  │
  ├─ 悬疑、时间主题 → 倒叙/时间折叠
  │
  ├─ 沉浸、实时感 → 单镜头
  │
  └─ 不确定 → 起承转结（最安全）+ 一种创意颠覆技法
```

## 三、创意颠覆技法库

**选型后必须从以下库中选至少一种，并说明"颠覆了观众的哪层预期"：**

### 技法1 · 视角转换
**做法：** 把故事从传统主角的视角转为反派/配角/道具/环境的视角讲。
**示例：** 一则咖啡广告从"咖啡杯"的视角见证无数人的独处与重逢。
**颠覆：** 观众以为要讲人的故事，但其实贯穿始终的"观察者"是一个物品。

### 技法2 · 类型混搭
**做法：** 将两种看似冲突的类型融合。
**示例：** 爱情+悬疑（对方是什么身份？为什么接近我？），喜剧+灾难（末日来了但大家还在搞笑）。
**颠覆：** 观众进入类型A的期待框架，但情节发展遵循类型B的逻辑。

### 技法3 · 时间颠倒
**做法：** 从结局开始讲。
**示例：** 第一个画面是婚礼宣誓→然后倒回到"他们是怎么走到这一步的"（其实讲的是分手的故事）。
**颠覆：** 观众从一开始就知道"结果"，所以注意力从"发生了什么"转移到"为什么发生"。

### 技法4 · 沉默主角
**做法：** 主角不说话，观众只能通过他人的反应/行动来理解主角。
**示例：** 一个哑巴女孩的故事全程没有她的台词，但所有人都在"替她说话"。
**颠覆：** 传统叙事靠对话推动，现在对话变成了"围观的噪音"，主角的沉默成了最强音。

### 技法5 · 旁白不可靠
**做法：** 旁白所说的与画面呈现的不一致——观众逐渐意识到旁白在撒谎/粉饰/选择性记忆。
**示例：** 旁白说"那个夏天是我们最快乐的时光"，画面是两人在空荡的房间里沉默吃泡面。
**颠覆：** 观众最初相信旁白的权威性，后来发现旁白本身就是戏中人，有他的立场和盲区。

### 技法6 · 类型反转
**做法：** 前半部按类型A走，节拍点恰好一切转为类型B。
**示例：** 前40秒是温馨家庭片，直到发现"家人"已经去世多年（转为悬疑/心理片）。
**颠覆：** 观众已经完全接受了类型A的设定，突然的转换造成强烈认知冲击。

### 技法7 · 嵌入式故事
**做法：** 一个故事套另一个故事，外层故事成为内层故事的"评论"。
**示例：** 一个导演在拍一部电影/一个作家在写一个小说，内外情节互相映照。
**颠覆：** 观众同时在两层现实中，外层说"这只是虚构"，但内层的情绪穿透了外层。

## 四、节拍点密度计算器（按时长倒推）

```
总时长 → 节拍点数量 → 每个节拍的镜头数

15秒   → 4个节拍点（起承转结）  → 每节拍1-3镜
30秒   → 4-5个节拍点            → 每节拍1-4镜
45秒   → 5-6个节拍点            → 每节拍1-5镜
60秒   → 6-8个节拍点            → 每节拍1-6镜
90秒   → 7-10个节拍点           → 每节拍1-8镜
3分钟  → 10-15个节拍点          → 每节拍1-10镜（部分可多镜展开）
5分钟+ → 15-25个节拍点          → 标准三幕剧节拍分配

通用公式：节拍点数 = 总秒数 ÷ 8（向上取整），但不小于4
         每节拍平均镜头数 = 1-2（主镜）+ 0-2（插入镜/反应镜）
         总镜头数 ≈ 节拍点数 × 1.5
```

## 五、陈词滥调雷达（大纲阶段必查）

以下情节/对话出现时，必须标记并建议修改：

```
- "镜子里看自己然后移开视线"（太烂俗）
- "下雨天分手/吵架/重大决定"（除非有真正新颖的角度）
- "闹钟响→起床→发呆→洗漱"的早晨蒙太奇
- "主角对镜子说'你可以的'"（自我鼓励的陈词滥调）
- "打开冰箱门，凝视空荡荡的内部"
- "电梯门开/关时遇见了那个人"
- "半夜惊醒，满头大汗"
- "机场/车站的告别奔跑（错过/追上）"
- "在雨中仰天大笑/哭泣"
- "翻开相册回忆过去的叠化蒙太奇"

修改策略：保留功能（告诉观众角色状态）+ 更换具体行为
例：冰箱凝视（展示孤独）→ 改为"烧了一壶水，但忘记倒进杯子，看着水蒸气发呆"
