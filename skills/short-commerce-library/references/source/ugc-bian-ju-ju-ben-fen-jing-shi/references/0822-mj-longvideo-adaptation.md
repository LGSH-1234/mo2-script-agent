## 一、Midjourney 专属版——通用语法与参数体系

### 1.1 专属版与常规版的映射关系（双版本同源）

| 常规版元素 | MJ 专属版映射 | 说明 |
|---|---|---|
| 引用表 @Char/@Scene/@Prop | `--cref` / `--sref` / `--cref URL` 或 `--sref URL` | 官方角色/风格引用参数（多图用 URL 逗号分隔） |
| 正文描述 | 自然语言短句（≤40词，逗号分隔，风格词前置） | MJ 不吃长句，靠词序加权 |
| 条件式负向约束 | **省略**，改正向可见描述 + `--no` 排除词 | MJ 无负面提示，`--no` 只支持物体词 |
| 六件套/七块/十四段骨架 | 保留骨架语义、压缩为关键词序列 | 光影/机位/画幅词保留，句法扁平化 |
| 中英双语 | 【中文版】供校验 + 【英文版】供执行 | 双语铁律不因 MJ 豁免 |

### 1.2 MJ 参数速查表（2024-2026 常用）

| 参数 | 取值示例 | 用途 | 各 skill 专属建议 |
|---|---|---|---|
| `--ar` | `--ar 2.39:1` / `--ar 16:9` / `--ar 9:16` / `--ar 1:1` | 画幅 | 见各 skill 专属表 |
| `--style` | `raw` / `expressive` / `cute` / `scenic` / `original` | 风格化强度与方向 | `raw` 适合写实/胶片类；`expressive` 适合插画/动漫类；`original` 适合摄影/设计类 |
| `--v` | `6.1` / `7` | 模型版本 | 按当日最新稳定版，旧图重绘前确认 |
| `--stylize` | `0-1000`（默认 100） | 美学自由度 | 低=贴词保守；高=美学发散。写实导演风建议 50-250；插画/华丽风建议 400-750；纯艺术/超现实建议 750-1000 |
| `--no` | `--no text watermark logo` | 排除物体词 | 各 skill 专属排除项（如文字/水印/现代物/审美的反面） |
| `--cref` / `--sref` | `--cref <url> --cw 100` | 角色/风格引用 | 锁角色与风格时使用；`--cw` 0-100 控制相似度 |
| `--chaos` | `0-100` | 结果变化度 | 探索期 50-100；锁定期 0-10 |
| `--weird` | `0-3000` | 非常规实验 | 超现实/无厘头类 skill 可用 250-1000 |
| `--profile` | 预设组合 | 复用小参数组 | 长项目锁定 profile 防漂移 |

### 1.3 MJ 提示词组织法（专属版三段式）

```
[风格词前置序列（来自各skill专属表）], [主体/角色+动作], [场景+环境], [光线+氛围], [镜头/构图/画幅], [材质/质感细节]
--ar [各skill专属] --style [各skill专属] --v 6.1 --stylize [各skill专属区间] --no [各skill专属排除词]
```

- 风格词前置序列：2-4 个词，放在最前加权最大（各 skill 专属表给出）
- 逗号分隔、英文、短句、具体名词优先于抽象形容词
- 一次只改一处（对应十五次迭代止损）；锁定期 `--chaos 0-10`
- 需要一致性资产时用 `--cref`/`--sref`，禁止仅靠文字反复描述特征

## 二、Seedance 2.5 长视频能力——通用结构方法论（30-180s）

### 2.1 长视频时长分层与场景分配

| 时长段 | 场景数建议 | 单镜时长 | 结构策略 |
|---|---|---|---|
| 30-45s | 3-5 场景 | 4-6s | 单幕结构：引子→推进→收束，每场景 1-2 镜 |
| 45-90s | 5-8 场景 | 5-8s | 双幕：建置→冲突→转折→高潮，场景成组推进 |
| 90-120s | 8-12 场景 | 6-10s | 三幕完整：每幕 3-4 场景，幕间用转场镜衔接 |
| 120-180s | 12-18 场景 | 8-15s | 长片结构：多线交织/章节式，需场景分割表+时间戳控制 |

### 2.2 长视频场景分割表（生成前必填·内部工作纸）

| 字段 | 内容 | 说明 |
|---|---|---|
| 总时长 | 30-180s | 用户确认，绝不默认 |
| 场景序号 | S1-Sn | 按叙事链分组 |
| 场景时长 | 秒 | 单场景 8-30s 为佳，跨度过大必拆 |
| 镜数 | 1-4 镜/场景 | 长镜头或分切 |
| 核心动作 | 一句话 | 该场景"推动哪个五元素" |
| 首帧锚点 | 描述或 @引用 | 承接上一场景尾帧，防跳变 |
| 尾帧状态 | 描述 | 喂给下一场景首帧（尾音/尾帧跨接） |
| 共享资产 | @CharID/@SceneID/@PropID | 跨场景必须锁定的资产 |

### 2.3 长视频跨段连续性五铁律（30s 以上必守）

1. **资产全局锁定**：角色/场景/道具/音色在项目启动即注册，跨段只允许 `@引用`，禁止新生成主资产（补拍/变体除外）
2. **首尾帧接力**：每段首帧 = 上一段尾帧（或明确的时间戳+状态描述），禁止各段独立抽卡
3. **时间戳文本控制**：`[0:05]` `[0:12]` 等时间戳驱动事件，视频延长/续写时保持全局时钟
4. **音频先行**：长视频先定声音结构（音乐段落/台词/音效卡点），画面按音频节拍切分
5. **人物不串脸/不换装**：多段混剪前过"十连同框压测"，跨段服装/发型/伤情状态与资产表一致

### 2.4 长视频节奏骨架（通用）

- **前 15%**：世界建立 + 共享真相锚定（广角+环境声，不急入戏）
- **15-45%**：建置推进，每 10-15s 一个叙事节拍点
- **45-70%**：冲突/转折区，节奏加密（镜长缩短），高潮前留静默 1s
- **70-90%**：高潮+余波，情绪峰值后留"呼吸镜"
- **90-100%**：收束，尾音跨接+字幕/主题呈现

### 2.5 长视频 vs 短视频生成差异（务必切换心智）

| 维度 | 短视频（≤30s） | 长视频（30-180s） |
|---|---|---|
| 生成方式 | 单段直出 | 分段生成 + 延长/续写/拼接 |
| 一致性 | 单段内自洽即可 | 跨段全局锁定（资产+时间戳+首尾帧） |
| 确认门 | 每镜确认 | 每**场景**确认（更省、更稳） |
| 失败回滚 | 重抽该镜 | 回退到该场景首帧重来，禁止链式修改 |
| 质量门 | 逐镜过 | 场景级过 + 全片拼接后复检接缝 |

### 2.6 长视频专属多模态参考用法（Seedance 2.5 能力）

- **@视频**：白模/预演/参考片段做运动轨迹锚定（冠军白模渲染）
- **@图片**：场景/角色/道具多参考图锁定（分镜多参考 I2V 管线）
- **@音频**：BGM/人声/音效驱动节奏与口型（音频驱动口型同步）
- **多参考混合**：每镜建议图片 3-5 张 + 音频 1 段 + 视频 ≤1 段，超限做优先级取舍
- 视频延长/前后续写：以时间戳+尾帧接力续写，禁止从零重抽

## 三、双版本×长视频组合交付流程（0822 完整交付形态）

```
用户需求
 ├─ 视频（默认Seedance 2.5）→ 长视频：分段生成+跨段锁定（§二）；短视频：单段直出
 └─ 图片（按用户需求）→ 常规版【中文+英文】 + MJ专属版【中文+英文】（§一+各skill专属表）
```

- 文生图/图生视频/编辑所有提示词均【中文版】+【英文版】（双语铁律）
- 用户指定 Midjourney → 以专属版为主；指定其他 → 跟随用户；无指定 → 双版本并行
- 长视频项目必须交付：场景分割表 + 跨段连续性五铁律核对清单 + 时间戳控制
