# 视频大师评审团 · 全流程独立质量门（三问裁决）

> **来源**：视频Agent·大师评审迭代系统Claude版本-0804.md（规整为共享参考）
> **定位**：独立于"生成"之外的审核机制。任一环节产出后不直接放行，召集该环节最相关的顶尖大师视角以挑剔眼光重审。**只出诊断与可执行修改建议，不代替生成**。

## 核心信条

- **存在必须证明价值，不是默认无罪。** 一个镜头/台词/道具/配乐，默认不是"留着没坏处"，而是"要么证明必要，要么证明有吸引力，否则砍掉"。评审团经常应让内容变得更短。
- **吸引力是"类型契约"下的对味，不是必须花哨。** 悬疑=让观众比角色早一点起疑；治愈=留白里的克制；史诗=缓慢堆积的仪式感。先判断类型契约，再套用对应标准。
- **必要性两条独立理由，占一条就该留。** ①叙事/功能必要（空间关系/铺垫/世界观代价感）②吸引力必要（让观众记住/重看/分享）。两条都不占才删除或合并。
- **去AI感是底线不是加分项。** 含画面材质、台词书面语、剪辑节奏机械对称、音色贴标签式表演等软性AI味。
- **大师视角是借来的标准，不是编造的语录。** 以"以某大师公开可考的技法/标准衡量…"，绝不写大师第一人称虚构引语。

## 通用三问与裁决逻辑

```
① 必要性：删掉它，故事推进/世界观代价感/空间认知会不会受损？
② 吸引力：留着它，是否真的让目标类型契约观众更想看/更易记住？
③ 合理性：它和前后内容、物理逻辑、已锁定资产设定对不对得上？

若①或②至少占一条 → 保留（③有问题顺带标"优化"）
若①②都不占       → 删除，或与相邻单元合并
若①②都成立但③出问题 → 优化（先修正逻辑硬伤，不因小瑕疵一票否决）
```

裁决只有四种：**保留 / 优化 / 合并 / 删除**。每条裁决必须落在具体理由上，禁止"不够精彩""感觉一般"这类空泛评语。

## 陪审团组成（每环节2-4位常任大师，以公开可考技法衡量）

| 环节 | 常任大师（技法/标准） |
|---|---|
| 故事与世界观 | 诺兰（高概念结构、代价法则）· 是枝裕和（日常留白）· 塔伦蒂诺（非线性、对话张力） |
| 分镜与剪辑逻辑 | 默奇（情绪优先剪辑六要素）· 希区柯克（悬念取舍、纯视觉叙事）· 埃德加·赖特（动感节奏） |
| 视觉提示词（去AI感） | 狄金斯（动机光源）· 杜尔（色彩情绪）· 霍伊特玛（实景质感、呼吸感） |
| 声音与配乐 | 本·伯特（标志性声音设计）· 默奇（声音分层叙事）· 配音导演标准（盲听匹配） |

## 五环节迭代评审流程（每环节：诊断→修改建议→复审，直至过三问）

### 🧩 环节1：故事与世界观（主审：诺兰、是枝裕和、塔伦蒂诺）
- Hook强度（前3秒类型契约心理真空）、世界观代价感、角色执念自毁倾向、场次必要性（是枝裕和减法）、类型契约一致性。
```
🔍 故事世界观评审 [第X轮]
| 序号 | 被审内容 | 主审标准 | 必要性/吸引力 | 合理性问题 | 裁决 |
| 1 | 世界观规则"魔法无代价" | 诺兰代价法则 | 吸引力弱，无代价则无紧张感 | 无 | 优化：补记忆磨损式代价 |
```

### 🎬 环节2：分镜与剪辑（主审：默奇、希区柯克、赖特）
- 镜头必要性剪除（漂亮但无信息的空镜砍掉）、景别权力审查（全景处境/特写情绪/中景叙事）、剪辑预埋（视线/动势/色彩关联）、无声测试（关声音仅画面能否叙事）、**删镜连锁复核**（删镜后复核前后两镜直接衔接流畅度）。

### 🎨 环节3：视觉提示词电影质感（主审：狄金斯、杜尔、霍伊特玛）
- AI污染清除（塑料皮肤/对称呆滞脸/无源荧光/过度锐化）、物理灯光逻辑（光源位置/色温/阴影硬度）、镜头与胶片参数（型号/光圈/胶片）、构图叙事化（站位/视线偏移/前景遮挡有心理依据）、道具功能性（无功能道具建议删除）。

### 🔊 环节4：角色声音与配乐（主审：本·伯特、默奇、配音导演标准）
- 声线-角色盲听匹配（遮住角色名能否反推年龄/创伤/阶层）、潜台词演绎（重音/停顿/气息）、空间声音叙事（混响暗示空间与心理距离）、音乐动机记忆点（3-5音符内可识别，进入/退出情感节点精准）。

### ✂️ 环节5：整体节奏与大众吸引力终审（主审：默奇+认知心理学）
- 前3秒生存率、节奏心电图（窒息处给呼吸，松弛处刺张力）、结尾余味（"故事结束"vs"脑海翻涌"）、分享动机（必须讨论才能确认的反转/密码时刻）。

## 与上游制作协作方式

- 评审团**只出裁决和可执行修改建议**，不直接重写成百上千字完整脚本/提示词，具体改写交上游按建议执行。
- 裁定删除某镜后，必须提示复核其前后两镜直接衔接流畅性。
- 完整项目在资产锁定/分镜定稿/终审交付前，裁决建议需经用户确认；轻量任务可直接给出采纳级建议。
- **Loop硬顶联动**：单环节三问裁决迭代≤3轮，超限→输出当前最优+标注待优化点，禁止无限"再优化"。

## 评审团自查清单（交付裁决前）

- 有没有为了显"专业"而强行挑刺？找不出具体理由的"优化"应改判"保留"。
- 有没有用"必须刺激/必须反转"套本该慢/留白的项目？先确认类型契约。
- 每条"删除"能否一句话说清"删掉后损失了什么、为何可接受"？说不清就不能删。
- 每条"优化/删除"是否都搭配了至少一个可执行替代方向？拒绝单纯否定。

## 与 skill 内质量门衔接

skill 内质量门（技术参数/风格纯度/去AI）负责**参数与纯度验收**；本评审团负责**存在价值与大众吸引力裁决**。联动：
1. 产出物先过 skill 内质量门（技术/风格/去AI）
2. 再召集本评审团执行三问裁决（必要性/吸引力/合理性）
3. 裁决"删除/合并"的单元回上游执行最小改动
4. 复审通过后才进入下一环节或交付
