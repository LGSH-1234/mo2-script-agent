# 14类场景镜头序列库 · 完整版

> **核心用途**：分镜阶段加速，按场景类型调用标准镜头序列模板。
> 每个模板包含：建立镜 → 核心镜 → 插入细节 → 特写/POV → 广角收束

---

## 使用说明

```
每个场景模板是一套"最小可行镜头序列"（3-7镜），
根据需要可以：
· 缩短：取核心2-3镜
· 扩展：在两镜之间插入反应/细节/过渡镜
· 组合：两个场景序列拼接
· 自定义：替换模板中的具体内容

⚠️ 即使使用模板，每镜仍需：四段式输出 + 六维衔接声明
```

## 1. 驾驶场景（旅程开始或到达）

```
── 标准序列（5镜）──

镜1：【建立】大远景/航拍——车在路上的全景，环境+方向
镜2：【内部】过肩拍司机——方向盘+前窗视角，操作换挡/摸烟
镜3：【细节】侧镜/倒后镜——后方风景或跟车的视觉
镜4：【反应】副驾/后座——乘客表情，期待/疲惫/不安
镜5：【收束】前景车后景目的地——到达或驶入新环境

情绪变体：
· 归家：温暖金色阳光，车内慢速，侧脸剪影
· 逃亡：颠簸，手持跟拍，雨/夜，频频看后视镜
· 旅程开始：推进式，侧光，后备箱满，微笑/期待
· 悬疑：路面固定机位→车入画→不停，不安感

建议时长：每镜2-4秒 / 总10-20秒
```

## 2. 对话场景（两人/多人）

```
── 标准序列（5镜）──

镜1：【建立】双人中景——两人位置关系、环境信息
镜2：【A侧过肩】拍B——A的肩/耳前景，B在说话/倾听
镜3：【B侧过肩】拍A——B的肩/耳前景，A回应/反应
镜4：【单人中景】——关键台词时的说话者全身反应
镜5：【特写反应】——听者的微妙微表情（关键信息）

扩展方法：
· 长对话：在2-4之间循环，每次换景别
· 紧张升温：加快剪辑速度，景别越来越近
· 和解软化：拉远景别，加入环境空镜

情绪变体：
· 争吵：手持+近景+快切，越轴（焦虑感）
· 秘密：过肩极近，耳语，切环境空镜（隔墙有耳）
· 告白：慢慢推近，最后一镜拥抱/牵手

⚠️ 注意：对话场景最容易犯的衔接错误是"视线方向不匹配"和"位置瞬移"
→ A始终在画左看画右/ B始终在画右看画左

建议时长：每镜2-5秒 / 按对话节奏定
```

## 3. 动作/追逐场景

```
── 标准序列（5镜）──

镜1：【建立】全景/航拍——追逐A和B的空间关系、行进方向
镜2：【中景跟拍】——A在跑/追，障碍物，喘气
镜3：【特写碰撞】——手/脚/工具的碰撞，物理冲击
镜4：【POV追逐】——主观快速运动，晃动，呼吸声
镜5：【收束】全景——追上/没追上，方向转换/撞入

扩展（激烈动作）：
· 插入"慢镜关键帧"——跳跃/碰撞/翻滚的瞬间
· 插入"环境反应镜"——旁观者/鸟/落叶被扰动
· 增加障碍物镜——翻越/闪躲/撞击

情绪变体：
· 英雄追逐：正面跟拍，阳光/开阔，慢镜英雄时刻
· 恐怖追逐：夜/暗，POV+极晃，失焦，突然暗转
· 喜剧追逐：低角度广角，笨拙动作，环境后果(碰倒东西)

⚠️ 运动方向铁律：追逐中AB运动矢量必须一致
→ A从左向右跑，下一镜必须继续从左向右
→ 如需转向，插入转向动作过渡镜

建议时长：每镜1-3秒 / 总8-15秒 / 节奏递进加速
```

## 4. 情感揭示场景

```
── 标准序列（5镜）──

镜1：【环境铺垫】慢速建立环境——氛围、时间、光线
镜2：【中景慢推】人物进入或坐着，环境氛围包围
镜3：【特写微表情】眼部/嘴角——压抑的波澜
镜4：【大特写细节】手部颤抖/眼泪滑落/物品破碎
镜5：【拉远留白】人物+环境全景——情绪在空间中回荡

节奏特征：
· 慢——比其他场景每镜停留时间长50%
· 安静——给观众消化情绪的时间
· 留白——情绪充分释放后才切到下一场

技巧：
· 情感揭示前3镜用匹配色温（如冷白6200K暗示悲伤）
· 揭示瞬间可用色温微调（如从6200K→5800K暖1度）
· 大特写细节的瑕疵词最丰富（泪痕高光/皮肤纹理/布料折叠）

建议时长：每镜3-6秒 / 总15-30秒
```

## 5. 到达新地点

```
── 标准序列（5镜）──

镜1：【大远景建立】目的地全貌——规模/年代/氛围
镜2：【摇镜环境】从左到右/从下到上环视——关键细节透露
镜3：【人物入画】从边缘进入画面——走向目的地
镜4：【中景反应】人物停下来看——表情（惊叹/失望/怀念）
镜5：【特写细节】角色摸门把/门槛/招牌——"到了"的瞬间

变体：
· 首次到访：更慢，更多摇镜，更多细节揭示
· 故地重游：更快，闪回叠化，特写一个旧痕迹
· 宏伟到达：航拍→人极小→大仰角

建议时长：每镜2-5秒 / 总10-25秒
```

## 6. 沉思/独处场景

```
── 标准序列（4镜）──

镜1：【环境空镜】半分钟的环境——无人，只有氛围（雨/光/影）
镜2：【人物中景】人物在环境中静止——靠窗/坐/站
镜3：【手部/道具特写】日常动作但心不在焉——转笔/搅咖啡/翻页
镜4：【面部大特写】最后揭示真正的情绪——长停留

情绪变体：
· 孤独：窗光/雨痕/咖啡冷/烟灰长
· 思考：走动→停→拿出某物看→放回
· 等待：看钟→再看门 →再看手机→再看钟

⚠️ 不要给沉思镜头加无意义的手持晃动——观众需要"静止来感受静止"
建议时长：每镜3-8秒 / 总12-32秒
```

## 7. 通话/远程场景

```
── 标准序列（5镜）──

镜1：【人物近景】拿手机/话筒——表情先于声音变化
镜2：【设备特写】手机/话筒/电脑屏幕——通过屏幕信息感知对话内容
镜3：【对面空镜】对方所在空间的空镜——"他在哪"的潜意识信息
镜4：【人物反应】听到关键信息时的第一反应——屏住呼吸/坐下
镜5：【情感落点】挂断后的人物状态——留在动作中静止

变体：
· 视频通话：分屏构图 / 移轴拍屏幕 / 光线反射面部
· 留音信箱：长时间无人接听→对面留言→挂断后沉默
· 偷听：门缝/走廊视角/过肩——信息片段揭示

建议时长：每镜2-4秒 / 总10-20秒
```

## 8. 悬疑/调查场景

```
── 标准序列（5镜）──

镜1：【细节特写】关键物件的细节——残缺/标记/异常
镜2：【环境横摇】缓慢环视空间——可疑处被忽略（让观众看见但角色没看见）
镜3：【人物警惕】主角的视角/动作——找/听/闻
镜4：【发现线索】手/工具触及某物——停、反应
镜5：【反应定格】特写表情——发现的信息在脸上显现

技巧：
· 80%的真实信息在环境里暗示（不是通过台词说的）
· "什么东西不见/变了"比"出现了什么"更具悬疑感
· 用不合常理的声音(低频/高频/静音)制造紧张
· 景别越近=紧张度越高

建议时长：每镜3-5秒 / 总15-25秒
```

## 9. 角色介绍场景

```
── 标准序列（5镜）──

镜1：【远景出场】人物从远处走近/从环境中显现
镜2：【中景动作】做一件代表性的事——走路姿势/点烟/整理
镜3：【特写面部】清晰的第一次看脸——停留让观众记住
镜4：【标志性道具】手/身体某部位的标志性细节——戒指/刺青/疤
镜5：【姓名字幕】特写+名字出现——"第一印象"定型

角色介绍的好坏决定了观众是否在意这个角色。
核心问题：观众在这个场景结束时，记住角色的什么？

不同风格：
· 英雄：正面光+慢动作+昂首挺胸
· 反派：背光剪影→逐步照亮→吓人特写
· 神秘角色：不露脸/遮挡局部/视角限制

建议时长：每镜2-4秒 / 总10-20秒
```

## 10. 闪回序列

```
── 标准序列（5镜）──

镜1：【触发物】现在时——看到/听到/闻到触发物
镜2：【转场】虚焦/旋转/光晕（色彩偏移）→过渡到过去
镜3：【过去画面】过去时的关键场景——色调/画幅/帧率不同
镜4：【关键信息】闪回中的核心——必须有一个"新信息"
镜5：【拉回现实】回到触发物/同一异构图——现在已被新信息改变

色调标识规则：
· 过去：降低饱和度20%、增加暖调(或冷调)、增加颗粒
· 现在：正常色温、正常画幅
· 幻觉/想象：高饱和、超现实色调、慢镜
· 未来：冷蓝/高锐度/轻微色差边缘

⚠️ 闪回内容必须给"现在"带来新信息（不能是已知信息重复）
建议时长：每镜2-5秒 / 总10-25秒
```

## 11. 揭示/发现场景

```
── 标准序列（5镜）──

镜1：【推向主体】缓慢/快速地推向关键物体
镜2：【停顿】停在被揭示物上——画面静止1-2秒
镜3：【反应镜头】发现者从"不理解"到"理解"到"震惊"
镜4：【细节验证】特写关键细节——"确认是真的"
镜5：【全景释放】情绪释放/展开——退后/坐下/转身走

四种揭示节奏：
· 慢揭示：缓慢推进，全貌呈现——如太空船缓缓出现
· 瞬间揭示：爆发惊现——如怪物跳出
· 逐步揭示：先局部→中景→再全景——如发现一个房间
· 逆向揭示：先全景/大景→推近到关键细节——如发现线索

建议时长：每镜2-5秒 / 总10-25秒
```

## 12. 醒来/早晨场景

```
── 标准序列（5镜）──

镜1：【特写睁眼】眼部大特写——从闭到微睁
镜2：【视角模糊】POV起床——抓手机看时间/遮光
镜3：【窗帘光】窗边——光从窗帘透入，灰尘飞舞
镜4：【起身中景】人物从躺着到坐起/站起——衣服/状态
镜5：【日常节奏】1-2个日常动作——喝水/洗脸/发呆

情绪变体：
· 幸福早晨：大窗光+暖色+舒展动作
· 宿醉/疲惫：侧光/逆光+缓慢+停顿
· 战时/末日：冷色+警觉的快速起床+检查装备
· 压抑日常：灰色调+闹钟硬切+机械动作

⚠️ 早晨镜头最怕"过于精确/明亮"——利用镜头呼吸感、对焦漂移、自然瑕疵
建议时长：每镜2-5秒 / 总10-25秒
```

## 13. 梦境/超现实场景

```
── 标准序列（5镜）──

镜1：【扭曲开场】反常的物理——水往上流/时钟倒转/重力异常
镜2：【熟悉但不同】熟悉的人物/场景但细节完全错误
镜3：【色彩/空间异常】不可能的色彩空间(绿天紫草)/透视错误
镜4：【虚实边界模糊】主角发现异常/不觉得异常（暗示深度梦境）
镜5：【惊醒/跳切】突然睁开眼/坠落/出画→回到现实

风格化技巧：
· 光学异常：鱼眼/分裂透镜/色彩分离/光晕过曝
· 物理反常：违背重力/因果倒置/循环动作
· 时间反常：加速/减速/停止/重复
· 空间反常：无限走廊/变换的房间/多重反射

⚠️ 梦境需要"逻辑异常中的内部逻辑一致性"——不能是随意不相关镜头的拼接
建议时长：每镜2-5秒 / 总10-25秒
```

## 14. 表演/舞台场景

```
── 标准序列（5镜）──

镜1：【广角舞台】全场——舞台+观众+灯光
镜2：【中景表演】表演者——唱歌/跳舞/乐器/演讲
镜3：【特写表情】表演中的情绪——汗水/投入/即兴
镜4：【观众反应】观众的反应——笑/哭/沉默/站起
镜5：【高潮定格】最精彩一刻+掌声响起/高潮音符

变体：
· 幕后：排练+紧张+上场前+上场(不拍表演)
· 独奏/独唱：全程特写+情感波动
· 广场表演：人群围观+低角度+高角度航拍

技巧：
· 运动方向必须匹配表演的节奏(BPM)
· 特写焦点在"与平时不同的瞬间"（破音/汗水/即兴）
· 观众反应镜是情绪放大器——不要省略

建议时长：每镜2-5秒 / 总10-25秒
```

## 场景模板快速查找表

```
需要拍什么？              → 用哪个模板     → 调整建议
─────────────────────────────────────────────────────
开车出发/到达            → ①驾驶场景     → 增加风景空镜
两个人说话               → ②对话场景     → 根据关系调整过肩距离
追逐/打斗/逃亡           → ③动作场景     → 增加慢镜关键帧
告白/分手/崩溃           → ④情感揭示     → 最长停留时间
首次去某个地方            → ⑤到达新地点   → 增加人物反应
一个人待着               → ⑥沉思独处     → 减少镜头数=增强孤独感
打电话/视频/留言          → ⑦通话场景     → 增加设备特写
找东西/查案/跟踪          → ⑧悬疑调查     → 增加环境暗示
新角色出场               → ⑨角色介绍     → 增加标志性道具
回忆过去                 → ⑩闪回         → 色调标识必须明显
发现秘密/宝藏/真相        → ⑪揭示发现     → 停顿最重要
起床清醒                 → ⑫早晨醒来     → 增加细节特写
做梦/幻觉/抽象           → ⑬梦境超现实   → 物理规则要一致
演出/比赛/发表           → ⑭表演舞台     → 观众反应不能少
```
