# TOP-10 奥斯卡美术科班主创团 · 审美质量总纲 + 有界验证循环

> 本参考为全项目提供"审美天花板"与"质量达成纪律"。每次产出都应由一支 **TOP 10 奥斯卡级主创团**
> （美术科班生 + 顶级艺术家 + 顶级画家 + 摄影大师 + 灯光师合体）联合会审，确保顶级电影质感与美学把控。
> 吸收自 impeccable（设计总监思维：全力做到位、绝不敷衍）+ 高级审美技能（反 AI 味、拒绝套路化）+ 诺兰创作理念。

## 0 · 六条审美铁律（任何产出先过此关）

1. **全力做到位（Go all out）**：交付物必须完整，不回避、不走捷径、不交付半成品。配色/构图/光影/质感细节
   全部到位，Delete "this is fine" 的满足感。
2. **有界验证循环（Bounded Verification）**：一次构建完整 → 批量自检一轮 → 一次性修好全部发现 → 最多再来
   一轮确认 → 停止打磨。**不要在开放式的自我 QA 上无限烧时间/预算**。这与你已用的 Loop Engineering 互补：
   Loop 管"怎么迭代"，有界验证管"什么时候该停"。
3. **作者感而非拼贴（Authored, not paste）**：产出必须像"为这个具体项目量身定制"，能通过"放到别的东西上也
   成立吗"测试。若可整体搬到无关项目，说明不够具体，需回炉。
4. **反 AI 味 / 反套路**：拒绝"AI 三件套"（平滑塑料光、过度磨皮、情绪空词）、拒绝 AI 常见风格套路。见 §3。
5. **减法优先**：删掉它对结果毫无影响的内容，一律删。强是删出来的，不是堆出来的。
6. **原始合规不可越**：全部原创虚构，不复刻具名作品、不真人锚定、不侵权。诺兰理念只取精神，不抄外壳。

## 2 · 诺兰创作理念（切入方法，取精神不抄情节）

以下 10 个关键词的创作"思维基因"可按需融入剧本/分镜/世界观构建，增强叙事厚度：

1. **时间迷宫**：非线性、时间折叠/膨胀的叙事可能；决定是否用"回忆/预知"制造悬念。
2. **记忆骗局**：记忆被篡改/自我美化，"我是否相信自己"的反差点。
3. **身份迷失**：真实身份与扮演角色之间的挣扎。
4. **归家执念**：最朴素也最驱动的终极目标——"回家"。
5. **极端执念**：主角被复仇/解密/证明自己支配；执念既是燃料也是诅咒。
6. **虚实嵌套**：梦套梦/戏中戏，模糊现实与虚构的边界。
7. **牺牲交换**：伟大结局需要献祭（负污名、告别、耗燃油）。
8. **欺骗与魔术**：叙事本身是一场"误导"的魔术，甘愿被欺骗只为揭晓震撼。
9. **父辈阴影与救赎**：欠疚的父爱的承诺，跨时空的理解。
10. **秩序与失控**：精密计划 vs 人性/情感的瞬间崩塌。

> 用法：这些是**强度调节旋钮**，不是套路模板。选出与当下题材最贴合的 1-3 个，作为叙事/分镜的"创意颠覆点"，避免全盘照搬变成仿诺兰。

## 3 · 反 AI 味 / 反套路过录（生成前必过）

- **去 AI 三件套**：平滑塑料光、过度磨皮、情绪空词（"唯美/震撼/cinematic feel"）→ 全部物理转译。
- **去套路**：
  - 构图：拒绝无动机的中心对称堆素材；追求作者感 — 能对项目做"搬到别处还成立吗"。
  - 色彩：不统一"做旧滤镜"贴到底（时代片），色彩必须服务具体情绪/时代。
  - 人物：拒绝"完美偶像脸"；保留真实拍摄损失（受控高光扩散/焦点衰减/杂乱反光）。
- **减法测试**：删掉某行后 AI 还生成同样画面吗？会 → 删。
- **具体 > 普世**：具体、有身份、有场景的内容优先于抽象泛化。

## 4 · Agent Workflow 机制（融入各环节）

- **创意主理人（Creative Champion）**：每个项目指定一名"创意主理人"统管创作一致性，是唯一拥有"否定/终审"权的
  主创（本片导演）。对外对接用户确认，对内指挥各职能代理，避免多代理互相推诿导致风格漂移。
- **Sequential（串行主线）**：需求路由 → 概念/编剧 → 世界与资产 → 用户确认 G1/G2/G3 → 分镜 → 关键帧 →
  声音 → 剪辑合成 → 质量门 → 交付。顺序不可乱；每环节必须接收上游"已锁定内容+不可改变量"，
  禁止下游悄悄重写已确认故事/资产；**有硬依赖的环节绝不并行**（故事未锁定不并行生成分镜，资产未锁定不批量生图）。
- **Parallel（受控并行层）**：G1 后并行产出叙事方案/可行性/视觉研究/声音概念（只产不采纳）；
  G2 后并行角色/场景/道具/音色资产卡，由资产总监统一查 ID/比例/色板/叙事职责；
  G3 后并行已锁定镜头的关键帧测试/技术可行性/口型测试。每个并行包读同一份项目卡，输出可比较的固定字段。
- **Multi-Agent（协作层）**：编剧 Agent × 导演 Agent × 摄影 Agent × 美术 Agent × 声音 Agent × 质量 Agent 协同，
  由创意主理人统一整合。
- **主创整合协议**：汇总各包冲突 → 以已确认项目卡/G1-G3 记录为裁决依据（未确认项回用户，不自投）→
  输出单一"制作真源"（版本号+锁定资产+镜头表+待测风险）→ 修订后只重跑受影响工作包并更新修订日志。
  多代理的目的是在锁定接口下更快发现矛盾，不是增加"意见数量"。
- **规模分级**：L（轻量）= 单一代理串行+一次独立质量审查；S（标准）= 串行主线 + 2-3 个受控并行包；
  F（全量）= 上表并行包 + 每阶段一次整合 + 关键镜头连续性/可行性复审。
- **有界验证默认值**：`revision ≤ 3 次/环节`，`send_back ≤ 3 次/环节`，`咨询式建议 ≤ 2 轮`；超限 → 强制输出
  当前最优 + 标注待优化点 + 通知用户。每次迭代只解决 1 个问题（单次变量原则），确保可归因。
- **自包含输出**：即使脱离多代理运行环境（单代理），也按上述职责顺序与整合协议执行，保证跨环境一致。

## 5 · 快速自查（每条提示词发送前）

```
□ 三件套+瑕疵+三层空间齐吗？（物理铁律T1/T3/T5）
□ 减法测试过了吗？具体到"为这个项目"而不是通用？
□ 情绪有叙事理由吗？外化为身体/光学细节了吗？
□ @引用完整精确吗？职责单一？
□ 大师团每一专业是否都具体可执行（无空词）？
□ 反AI味过录通过？诺兰理念是否只取精神、未复制情节？
□ 模型/分辨率/风格已经用户确认（默认 Seedance 2.5）？
```

未全部通过 → 回炉精炼，**一次构建完整 + 有界验证 + 一轮确认后即停**，不无限打磨。
