# 质量门 · 完整自检与评分体系

> **核心用途**：P4验证阶段逐项过检，确保交付物达到专业级标准。
> 通过标准：12项全部通过 + 五维评分 ≥ 门槛值。

---

## 一、12项自检清单（逐项核对）

### 编剧组

| # | 检查项 | 通过标准 | 不通过时 |
|---|--------|---------|---------|
| 1 | 叙事结构已选定并落地为具体节拍点 | 表格中有结构名+至少4个节拍点+每个节拍点有具体描述，非仅有"三幕剧"三个字 | 补节拍点表 |
| 2 | 至少运用一种创意颠覆技法 | 在节拍点表或项目简报中有标注技法名称+说明颠覆了观众哪层预期 | 追加创意颠覆技法 |
| 3 | 对照陈词滥调雷达核查过大纲 | 大纲中没有雷达清单中的陈词滥调情节 | 标记并替换具体行为 |
| 4 | 每个核心角色有完整七维DNA+小传 | 七维齐全、小传300-600字、至少1处矛盾细节 | 补全缺失维度/小传 |
| 5 | 反派动机通过行为展示而非临终独白 | 反派的动机在2+场戏中以行为/选择/牺牲呈现 | 重写反派线，删独白 |
| 6 | 对白遵守Show-Don't-Tell | 无直接情绪词台词、无"如你所知"式解释对白、无廉价转折词 | 逐句改写 |
| 7 | 每场戏有"进入状态"与"离开状态"变化 | 每场戏的角色情绪/关系/认知在结尾与开头不同 | 无变化场次删除或重写 |

### 资产锁定组

| # | 检查项 | 通过标准 | 不通过时 |
|---|--------|---------|---------|
| 8 | 核心角色/场景完成锁定特征+@ID | 每个@ID有3-5项具体锁定特征、已获用户确认 | 补锁定特征+等待确认 |

### 分镜组

| # | 检查项 | 通过标准 | 不通过时 |
|---|--------|---------|---------|
| 9 | 每条分镜提示词满足物理三件套 | 有摄影机/介质+焦段mm+主光方向色温 | 补缺失参数 |
| 9a | 情绪词已转译为具体光学参数 | 无残留"精美/震撼/cinematic feel"等空词 | 逐条转译 |
| 9b | 瑕疵密度≥3词跨2类 | 每条提示词≥3个瑕疵美学词，至少跨越2个类别 | 补瑕疵词 |
| 9c | 前中背景三层空间 | 每条提示词有明确的近景/中景/背景描述 | 补空间层次 |
| 10 | 每个可见主体有对应@引用 | 画面主体数=@引用数，清单与正文双重呈现 | 补@引用和正文内联 |
| 11 | 相邻镜头逐对通过六维衔接检查 | 衔接对数>=镜头数-1，每对有完整六维声明 | 补缺失衔接声明 |

### 交付完整性组

| # | 检查项 | 通过标准 | 不通过时 |
|---|--------|---------|---------|
| 12 | 全篇无占位表达/台词完整 | 无"同上/略/见前文"；台词字幕均为完整引号文本 | 替换占位+补全文 |

## 二、五维评分体系

### 评分方法
```
每维按0-10分打分，取小数点后1位（如9.5）
低于门槛值的维度需修复后重新评分
最终评分 = 五维平均值
```

### 评分维度

**① 故事完整度（门槛 ≥ 9.5）**
```
评估问题：
- 结构选型是否正确匹配题材？
- 节拍点是否按时长精确倒推且全部落地？
- 世界观五维是否齐全（尤其是法则维的"代价"）？
- 人物七维是否齐全且有矛盾细节？
- 人物是否扁平工具人？有没有让观众在意的"理由"？

减分项：
- 结构只有名没有节拍点表 → -2.0
- 人物小传缺矛盾细节 → -1.5
- 世界观法则缺"代价" → -2.0
- 人物是常见原型模板 → -1.0
```

**② 物理精确度（门槛 ≥ 9.0）**
```
评估问题：
- 每条分镜提示词是否都有三件套(摄影机+焦段+主光色温)？
- 有无残留未转译的抽象情绪形容词？
- 瑕疵词是否≥3词跨2类？
201 - 三层空间（前中后）是否都描述了？

减分项：
- 1条提示词缺三件套 → -1.0（每条）
- 残留抽象情绪词 → -1.5（每处）
- 瑕疵密度不足 → -1.0
- 缺空间层次 → -0.5（每条）
```

**③ 资产一致性（门槛 10.0）**
```
评估问题：
- @引用是否全程未发生特征漂移？
- 锁定特征是否在所有分镜中保持一致？
- 每个@引用是否只有唯一职责？
- 资产锁定是否在分镜前获用户确认？

减分项：
- 同角色在不同镜中明显不一致 → -3.0（每次）
- 用户未确认就出分镜 → -5.0
- @引用一引用多职 → -1.0（每次）
- @引用与正文双重呈现不完整 → -1.0
```

**④ 镜头丝滑度（门槛 10.0）**
```
评估问题：
- 相邻镜头六维衔接声明是否逐对完成？
- 是否有无意的跳跃感硬伤？（越轴/方向对撞/位置瞬移/色温跳变）
- 出画/入画是否连续？
- 情绪强度是否有合理的递进曲线？

减分项：
- 缺一对衔接声明 → -3.0
- 存在明显跳跃硬伤 → -2.0（每次）
- 情绪曲线平线无变化 → -1.5
- 所有转场都是"切" → -1.0
```

**⑤ 结构效率（门槛 10.0）**
```
评估问题：
- 是否按阶段合理分批输出（而非一次性甩全部内容）？
- 有无冗余重复内容？
- 有无占位偷懒（同上/略等）？
- 长内容输出前是否先出了大纲供用户确认方向？

减分项：
- 出现占位表达 → -3.0（每次）
- 一次性输出超过100行未先出大纲 → -2.0
- 有冗余重复段落 → -1.0（每处）
- 输出结构混乱难以阅读 → -1.5
```

## 三、质量门执行流程

```
P4验证阶段流程：

STEP 1 · 自检跑表
    ↓ 逐一过12项自检清单
    ↓ 每项标记 ✓ 或 ✗
    ↓ 未通过项记录原因

STEP 2 · 五维评分
    ↓ 每个维度独立打分
    ↓ 低于门槛值项标记为"需修复"
    ↓ 记录低分原因

STEP 3 · 修复
    ↓ 按修复动作表逐项处理
    ↓ 修复后回到STEP 1重新跑检
    ↓ 三遍仍不通过→标记为"建议人工审阅"

STEP 4 · 交付
    ↓ 输出质量门检查结果摘要
    ↓ 通过项 ✓ + 未通过项原因+修复建议
    ↓ 若用户要求完整交付文档→汇总为可交付文档

STEP 5 · Loop记录
    ↓ 记录本次发现的问题类型
    ↓ 纳入 LearningLog（防止同类问题重复出现）
```

## 五、修复动作表

```
问题类型           → 修复动作
──────────────────────────────────────────
抽象情绪词残留     → 查情绪转译表，替换为具体光学参数
@引用缺失          → 补@引用清单 + 正文中内联插入
衔接声明缺失       → 补六维逐对检查声明
资产特征漂移       → 回溯锁定特征表，排查所有引用镜并回正
瑕疵密度不足       → 补≥3个瑕疵美学词，跨至少2类
占位表达           → 替换为完整精确的内容
景别跳跃过大       → 插入中间景别桥梁镜
人物位置瞬移       → 插入位置过渡镜或加前景遮挡
运动方向对撞       → 统一全镜运动矢量或加转向过渡
色温跳变           → 加过渡镜或调整色温至合理变化范围
情绪平线           → 重新设计情绪曲线，加入反应/留白镜
三件套缺失         → 每条补全[摄影机/介质+焦段mm+主光方向色温]
```
