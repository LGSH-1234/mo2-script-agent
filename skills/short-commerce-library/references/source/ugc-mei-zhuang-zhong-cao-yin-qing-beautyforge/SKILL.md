## **核心定位**

**做什么**：把一句话想法或现成脚本，变成可直接生成视频的六区块提示词 + 全套美术资产 + 合规检查。

**不做什么**：不生成视频本身，不写长剧剧本，不做动漫/水墨/3D 卡通风格（固定电影写实），不做非化妆品品类。

**执行方式**：严格按阶段1→8顺序执行，每阶段完成后暂停确认，再进下一阶段。

**每个阶段完全独立自包含**——这个阶段需要的所有知识、规则、模板、质检都在这个阶段里，不需要跳转读取其他内容。

**版本**：V2.0（八阶段独立结构，每阶段自包含全部知识）。

## **阶段1：问询配置 + 合规预检**

### **1.1 做什么**

通过五层问询卡收集用户配置，确定化妆品子类、产品、人物、场景、平台，并执行合规预检。关系类型（子类+达人范式）决定后续所有阶段的设计方向。

### **1.2 化妆品品类世界观认知（配置时必须理解）**

**三子类核心差异**：


| **维度** | **护肤类**                | **彩妆类**                  | **工具类**             |
| :------ | :---------------------- | :------------------------ | :------------------- |
| 核心动作   | 指腹打圈/掌心按压/乳化/提拉按摩/点涂拍开 | 海绵弹压/刷子晕染/Z字刷法/精准描画/指腹渐变 | 打圈按摩/提拉滑动/缠绕定型/弹压上妆 |
| 情绪调性   | 温和/滋养/仪式感/专业           | 精致/显效/自信/色彩冲击力           | 科技感/效率/专业/品质        |
| 视觉基调   | 柔侧光/蓝金 grading/皮肤纹理真实  | 侧逆光突出妆效/微距色号/妆容层次        | 冷白科技调/金属质感/操作演示清晰   |
| 动作速度   | 慢（精准展示手法）              | 中快（精准利落）                 | 中（科技感流畅）            |
| 动作基因数量 | 16 个                   | 21 个                     | 6 个                 |


**人物+产品双重强锁定铁律（化妆品版十要素）**：


| **层级**     | **约束内容**         | **化妆品版量化标准**     |
| :---------- | :---------------- | :---------------- |
| L1 参考图锁定   | 严格遵循人物参考图+产品九宫格  | 关键帧相似度≥90%       |
| L2 面部锁定    | 五官位置/比例/表情变化范围   | 面部特征偏差≤5%        |
| L3 身材锁定    | 头身比/肩宽/腰臀比/四肢比例  | 比例偏差≤3%          |
| L4 服装锁定    | 款式/颜色/材质/饰品      | 颜色偏差 ΔE≤5        |
| L5 产品锁定    | 颜色/材质/logo/尺寸/包装 | **ΔE≤3（化妆品收紧）**  |
| L6 手部锁定    | 手型/指长/指节角度/指甲    | 指节 30-90°，手腕≤70° |
| L7 关键帧锁定   | 接触帧/使用帧/效果帧      | 三帧相似度≥90%        |
| L8 肤色锁定    | 跨镜头肤色 Lab 色值     | **ΔE≤3**         |
| L9 妆效锁定    | 同一色号跨镜头妆效颜色      | **ΔE≤3**         |
| L10 产品质地锁定 | 膏体/液体/粉末物理状态     | 跨镜头质地状态一致        |


**合规红线（化妆品专属）**：

- 特殊化妆品（美白/祛斑/防晒/防脱/染发/烫发）必须有特证号
- 禁用医疗术语/绝对化用语/虚假承诺/成分虚标/未经检测对比
- BA 对比必须挂测试条件声明四要素
- 儿童化妆品功效白名单严格限制
- 广告标识 + AI 生成标识双重强制

### **1.3 关键规则**

1. 画幅必须用户明确选择，禁止默认9:16。画幅决定后续所有构图方向。
2. 时长体系三级：L1单镜(1.5-8s)/L2段落(15-60s)/L3完整(60-120s)。单次视频输出时长上限默认10s。
3. 语速档位默认动态变速 4.0-6.0 字/秒（基础段4.5-5.0/信任段3.5-4.0/带货段5.0-6.0）。
4. 化妆品子类必须先选（护肤/彩妆/工具），子类决定动作基因库调用。
5. 合规预检强制：特殊化妆品无特证号 → 话术自动降级为普通妆字号表述。
6. 肤色锁定 ΔE≤3，妆效锁定 ΔE≤3，比通用 ΔE≤5 收紧。

### **1.6 推演引擎（链式锁定·候选制）**

**推演链**：产品种子 → 子类（护肤/彩妆/工具）→ 动作基因（从43动作库调用）→ 双重锁定（人物+产品+肤色）→ 痛点定位（P1-P10）→ 节奏板（钩子→痛点→方案→效果→CTA）→ 情绪曲线（好奇→共鸣→渴望→惊喜→行动）→ 视觉方向（主色+光感+质地）。

**推演五规则（强制）**：

1. **候选制**：每步≥2候选，带推导来源和差异轴
2. **可解释**：标注推导来源（为什么选这个）
3. **具体化**：可直接写进prompt的量化描述（角度/百分比/色温K值/时长s）
4. **方向约束**：不违反已锁铁律/负面词库
5. **链式锁定**：确认后写回后续阶段

**五件套联动确认**：

## **阶段2：剧本 + 动作设计**

### **2.1 做什么**

先做导演构思（主题/意象/视觉宣言），再生成或解析结构化种草剧本（种草节奏板五段），然后设计每个核心动作（动作设计卡+表演节拍表）。动作先于叙事——产品使用动作是种草广告的核心表演。

### **2.2 导演构思（构思时必须执行）**

**主题提炼（化妆品三候选）**：


| **候选** | **主题词**   | **含义**                             | **推导来源**                 |
| :------ | :--------- | :---------------------------------- | :------------------------ |
| A      | **真实可信**  | “我真的在脸上用给你看/我的手告诉你它好用”——动作真实性=信任   | ← 种草表演本质 + 化妆品行业“虚假宣传”痛点 |
| B      | **功效证明**  | “看得见的变化/同一个角度同一个光线的对比”——BA对比=证据    | ← 化妆品核心决策因子“效果存疑”        |
| C      | **仪式感悦己** | “护肤是属于自己的15分钟/上脸的瞬间是享受”——使用过程=情绪价值 | ← 高端护肤/香氛长期主义品牌打法        |


**核心意象（可执行画面）**：

- 特写：真实手部在上脸操作的瞬间（指腹按压/海绵弹开/刷子晕染），自然光，手部纹理清晰，皮肤毛孔可见，浅景深
- 微距：膏体/液体/粉末在皮肤或玻璃上的质地变化（拉丝/推开/扬起/成膜），产品色占比60%+
- 中近景：人物对镜检查妆效/肤况，满意微笑或惊喜表情，真实梳妆台环境
- 分屏对比：左半before（暗沉/粗糙/瑕疵可见）→ 右半after（光泽/细腻/均匀），同机位同光线

**减法美学清单（化妆品专属8项）**：

1. 不出现网红滤镜感（过度磨皮/美白/锐化）→替代为保留真实皮肤纹理与毛孔颗粒感
2. 不出现假上脸动作（产品悬浮/手没接触就假装涂抹）→替代为真实接触反馈
3. 不出现塑料假质感（瓶身镜面反射/膏体像橡皮泥）→替代为真实材质
4. 不出现色号漂移（同一支口红跨镜头颜色不一样）→替代为色号锁定ΔE≤3
5. 不出现虚假BA对比（before用丑照/after用精修）→替代为同机位同光线四要素标注
6. 不出现满屏卖点轰炸（&gt;3条功效同屏）→替代为单条大字卖点逐条出现
7. 不出现医疗暗示画面（白大褂/显微镜暗示医疗效果）→替代为真实梳妆台场景
8. 不出现高饱和糖果色（&gt;30%饱和度）→替代为自然低饱和调色（0-15%）

## **阶段7：视频生成 + 装配**

### **7.1 做什么**

用阶段6产出的视频提示词执行视频生成，并在生成前后进行质检。然后执行装配（字幕/BGM/合规标识/三级响度归一化）。

### **7.2 视频生成执行（三条硬规则）**

**规则1：提示词原文照搬**

- prompt字段必须直接复制阶段6产出的提示词原文
- 禁止任何改写、压缩、整理、翻译
- 禁止把六区块改成一段描述
- 禁止删掉安全约束/负面词/治僵硬
- 禁止把代号&lt;主体1&gt;改回角色名

**规则2：时长拆段检查**

- 单次调用时长≤15秒
- 超过15秒必须拆段，按输出打包方案执行
- 拆段时按镜头边界拆分，不在镜头中间拆

**规则3：尾帧按需抽取（不是每段都必须抽）**

- 需要抽尾帧：输出2起/段与段之间需要无缝衔接
- 不需要抽尾帧：第1段/段之间有明确转场不需要衔接
- 抽帧方法：ffmpeg -i 上一段.mp4 -vframes 1 -copyts -f image2 尾帧.png
- 禁止用视频节点替代尾帧图片

**执行流程**：

text

```
用阶段6产出的视频提示词执行视频生成 → 检查时长≤15s（超过则拆段）
→ 第1段生成（无需尾帧）
→ 判断是否需要尾帧衔接？
   ├─ 需要：ffmpeg抽尾帧PNG → 放入下一段素材引用 → 生成下一段
   └─ 不需要：直接生成下一段
→ 全部生成完毕 → 进入7.3装配
```

**分段生成+强制确认门**：一段一段生，每段生完停下确认才生下一段。确认项：

- ①人物是否变形
- ②产品是否一致（颜色/logo）
- ③动作是否真实自然（用力/物理）
- ④表情是否到位
- ⑤产品使用动作是否卡住卖点

### **7.3 装配（阶段6）**

**顺接**：各段硬切拼接（≥70%），品牌转场≤30%必须有理由，禁随意叠化/淡入淡出。

**合成前**：

① **加字幕**：

- 口播字幕42-54px / 卖点大字条72-96px（1080p基准）
- 纯白字+深色描边（字号8-10%）或半透明黑底条
- 单行不换行，字体思源黑体
- 安全区距底部≥15%画面高度
- 卖点条逐条出现 ≤3条同屏

② **铺BGM**：

- 人声段BGM闪避至-20~-25dB
- 无口播段回升至-12~-15dB
- BGM场景≤60%
- 静默三角——Hook后0.5-1s/卖点揭示前1-1.5s/CTA前0.8-1s
- 总静默占比5-8%

③ **叠图**：品牌logo/片尾CTA按钮PNG

④ **合规标识叠加（P0强制）** ：

- 广告标识——画面右上角或左下角叠加“广告”文字（字号≥画面高度3%即1080p≥58px，停留≥3秒或全程，半透明白底黑字或黑底白字）
- AI生成标识——前5秒画面左下角叠加“AI生成”文字（字号≥画面高度2.5%即1080p≥48px，停留≥5秒），发布时同步勾选平台AI标签（隐式标识）

⑤ **品类强制标注**：

- 特殊化妆品标注特证号
- 防晒类标注SPF/PA实测值
- 儿童化妆品标注小金盾

**合成导出**：压平合成为成片，**三级响度归一化**：

- 混音电平（人声0dB参考/音乐-6~-10dB/环境-10~-15dB/动作音效-12~-18dB）
- 按目标平台归一化——社交平台-14 LUFS / 广电-23.0 LUFS ±0.5，短时-18 LUFS，真峰值-1 dBTP
- 母带24-bit/48kHz
