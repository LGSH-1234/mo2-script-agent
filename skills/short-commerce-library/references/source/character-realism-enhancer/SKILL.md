# 真人质感设定图

## 核心原则

始终以「图生角色概念」的方式解决用户需求，而非通用美化。把上传图片当作精确的身份/设计参考，在保留角色核心身份的前提下，重建真实人体结构、真实皮肤质感和真实材质体积，使结果接近电影/TVC前期美术可用的角色设定图，而非油腻AI肖像或平面插画。

### 持久引擎（因果链）

**输入图片 -> 源图分类 -> 身份锁定（脸型/五官/发型/服装/气质/道具） -> 假感诊断（油腻/AI感/塑料感/扁平） -> 材质体积重建（皮肤/头发/布料/道具） -> 真实光源重建 -> 输出模式选择 -> 提示词产出 -> 反向约束**

### 质量测试（可证伪）

**如果最终图片的皮肤仍然发油、发亮、像塑料或蜡像，或者角色身份与原图不一致（换脸、改人、网红脸），则判定失败，必须重做。** 通过的标准是：皮肤呈现真实人体的柔和漫反射、有自然毛孔和细微纹理，且角色身份与原图可辨识为同一人/同一角色。

## 输入诊断

落提示词前必须明确或合理假设以下维度：

- **源图类型**：真人照片 / AI人物图 / 二维插画或动漫 / 半写实角色图 / 草图或粗略概念 / 参考图
- **角色身份要素**：脸型比例、五官关系、发型轮廓与方向、服装大形与配色、姿态方向、角色气质与年龄印象、道具与身份设定
- **假感来源**：油腻反光 / AI磨皮 / 塑料皮 / 玻璃皮 / 蜡像感 / 橡胶皮肤 / 扁平线稿 / 低完成度上色
- **输出模式**：默认单张设定图 / 全身设定图 / 三视图设定表 / 电影关键帧
- **是否需要去油优先**：用户是否反馈结果仍油腻、发亮、有AI感
- **构图需求**：半身 / 三分之四 / 全身
- **背景与世界观**：角色所属世界的氛围线索
- **最终用途**：电影前期美术 / TVC设定 / 游戏前期美术 / AI视频首帧

## 工作流

### 步骤 1：检查输入图片

如果用户上传了图片，先观察图片内容，识别源图类型、角色身份要素和假感来源。

### 步骤 2：分类源图

按路由表分类源图类型，确定处理路线和重点。

### 步骤 3：选择输出模式

按路由表选择输出模式。默认为单张角色设定图。仅在用户明确要求时切换为全身、三视图、电影关键帧或去油优先模式。

### 步骤 4：组装提示词

按以下结构顺序组装最终提示词，使用中文（除非用户另有要求）：

1. 根据上传图片生成人物设定图
2. 保留角色身份/设计
3. 转换源图类型
4. 真实人体结构
5. 真实皮肤质感
6. 服装/头发/道具材质
7. 构图/输出模式
8. 光线/色彩/电影概念质感
9. 最终用途
10. 反向约束

### 步骤 5：输出

返回三部分：最终提示词、反向约束、使用建议。

## 提示词模板

### 默认提示词

根据上传的人物照片、AI人物图、二维人物图、半写实角色图或草图，生成一张真实可信的人物概念设定图。

严格保留原图角色的核心身份和设计：脸型比例、五官关系、发型轮廓、服装大形、角色气质、姿态方向、配色倾向、道具和身份设定。不要换脸，不要改成人偶脸，不要改成网红脸，不要改变角色是谁。可以补全原图缺失的细节，但所有补全都必须服务于原角色设计。

如果原图是真人照片，把人物转化为电影/TVC前期美术可用的角色设定图，保留真实身份和自然人体结构。如果原图是AI人物图，去除AI生成感、假脸感、塑料感和过度精修感。如果原图是二维插画或草图，不要照搬平面线稿质感，而是将角色设计翻译成真实体积、真实材质和真实光影下的人物设定图。

皮肤必须真实、克制、非油腻。去除额头、鼻梁、鼻头、脸颊、下巴、脖子、锁骨、胸口、手臂和手部的油亮反光、湿亮水光、玻璃皮、蜡像感、塑料皮和AI磨皮。皮肤应呈现真实人体的柔和漫反射，有自然毛孔、细微纹理、轻微肤色不均、淡淡红润、真实阴影过渡和局部细小瑕疵。不要美白换肤色，不要磨成无毛孔，不要让皮肤像硅胶、橡胶、瓷娃娃或3D假材质。

重建真实材质：头发要有自然发丝束和层次，不要湿塑料感；布料要有织纹、厚度、褶皱、缝线和磨损；皮革、金属、玻璃、饰品、鞋子和道具要有准确但不过曝的物理反光；服装层次要清楚，能体现角色职业、阶层、时代、气候和性格。

构图为专业人物设定图，角色轮廓清晰可读，身体比例自然，面部结构真实，手部和关节可信。背景简洁但有轻微电影氛围，用来说明角色所属世界，不要抢主体。画面可以是半身、三分之四或全身；如果原图适合全身设定，请让角色从头到脚完整可见，鞋子、手部和服装轮廓清楚。

光线使用真实摄影逻辑：明确方向性主光、柔和阴影过渡、适度边缘光或环境反射。避免美容灯、假HDR、过曝白斑、全脸均匀发亮和廉价电影滤镜。整体质感像真实摄影参考、电影角色概念设计和高端TVC设定图的结合，细节清晰但不过度锐化。

最终效果：真实、有角色设计感、有皮肤细节、有材质厚度、有电影前期设定图价值。看起来像专业角色概念艺术家根据原图重新完成的一张人物设定图，而不是AI头像、塑料娃娃、二次元插画、网红写真或过度磨皮CG。

### 大师版提示词

当用户要求纯净最终版时，使用此版本。按需追加模式附加段。

请基于上传图片生成一张电影级真实人物设定图。输入图片可能是真人照片、AI人物图、二维人物图、半写实插画、草图或粗略角色参考；无论输入是哪一种，都要把它统一转化为可用于电影、TVC、游戏前期美术或AI视频首帧的人物概念设定图。

第一优先级：保留原角色。严格保留原图人物/角色的核心身份、脸型比例、五官关系、发型轮廓、服装大形、姿态方向、角色气质、配色倾向、道具和身份设定。不要换脸，不要改成另一个人，不要改成网红脸，不要把角色随机重设计。可以补全缺失细节，但所有补全都必须服务于原角色。

第二优先级：重建真实人体与真实皮肤。把原图中所有AI感、假脸感、油腻感、塑料感、蜡像感、玻璃皮、水光肌、过度磨皮、硅胶皮肤、橡胶身体和不真实反光全部去掉。脸、额头、鼻梁、鼻头、脸颊、下巴、脖子、锁骨、胸口、手臂和手部的皮肤都必须变成真实人体皮肤：自然毛孔、细微纹理、轻微肤色不均、淡淡红润、真实阴影过渡、细小瑕疵、柔和漫反射。皮肤不能油亮，不能像涂油，不能像玻璃，不能像3D假材质，不能美白换肤色。

第三优先级：把二维或AI质感转成真实设定图质感。如果原图是草图、插画、动漫、半写实或低完成度图，不要照搬平面线稿和塑料上色，而是把原角色设计翻译成真实体积、真实骨骼结构、真实面部转折、真实身体厚度、真实服装结构和真实材质反应。让角色像真实摄影参考和电影概念设计结合，而不是普通AI头像。

第四优先级：材质必须可信。头发要有自然发丝束、层次和干湿关系，不要湿塑料感；布料要有织纹、厚度、褶皱、缝线、边缘和磨损；皮革、金属、玻璃、饰品、鞋子和道具要有准确物理反光，但不要过曝。服装层次要清楚，能体现角色职业、阶层、时代、气候和性格。

构图：专业人物设定图，角色轮廓清晰，面部结构真实，身体比例自然，手部和关节可信。背景简洁但有轻微电影氛围，用来说明角色所属世界，不要抢主体。画面要清晰、有设计价值、方便后续扩展成三视图、服装细节图或视频首帧。

光线：使用真实摄影逻辑的方向性主光，柔和阴影过渡，适度边缘光或环境反射。不要美容灯、假HDR、全脸均匀发亮、过曝白斑、廉价电影滤镜和AI生成的油亮高光。

最终效果：真实、克制、有皮肤细节、有材质厚度、有角色设定价值。看起来像专业角色概念艺术家根据上传图重新完成的一张真实人物设定图，而不是AI头像、塑料娃娃、二次元插画、网红写真或过度磨皮CG。

### 模式附加段

**全身附加段**（用户要求全身人物设定图时追加）：

全身人物设定图，从头到脚完整可见，头部、脸、手、身体、腿部、鞋子全部清楚，不要半身裁切，不要截断脚，不要让前景或背景遮挡身体轮廓。站姿稳定，角色剪影清晰，服装层次和鞋子设计可用于后续三视图延展。

**设定表附加段**（用户要求三视图/设定表时追加）：

生成人物设定表版式，包含主视角完整角色图，并可加入正面、侧面、背面或服装/道具细节小图。所有视角保持同一角色身份、同一脸型、同一服装设计和同一材质逻辑。版面干净，不要乱码文字，不要水印。

**去油急救附加段**（用户反馈结果仍油腻/发亮/有AI感时追加）：

这次以去油光为最高优先级，电影感、高级感、夕阳高光、皮肤光泽和嘴唇润泽全部让位于真实皮肤。只保留光影图案和明暗结构，不保留皮肤上的镜面反光。

把脸、额头、鼻梁、鼻头、鼻翼、脸颊、苹果肌、下巴、脖子、锁骨、肩膀、胸口、手臂和手部的强反光、水光肌、玻璃皮、油膜感、湿亮皮肤和蜡质高光明显压暗 80%-90%。皮肤不能再像涂油、打蜡、玻璃反射、硅胶、橡胶或AI美颜滤镜。高光只允许是极弱、分散、贴合骨骼结构的真实皮肤受光。

压掉反光后补回真实皮肤微细节：自然毛孔、细小纹理、轻微凹凸、肤色层次、淡淡红润、局部暗沉、真实阴影过渡和细微颗粒感。不要美白，不要磨平，不要把皮肤糊成一片。嘴唇保留唇纹和自然颜色，但去掉塑料亮面和湿亮反光。

## 静默自检

出稿前内部检查，不外显：

- 角色身份是否与原图一致（脸型、五官、发型、服装、气质）
- 皮肤是否仍有油腻/反光/塑料感/蜡像感/AI磨皮痕迹
- 是否包含了自然毛孔、细微纹理、肤色不均等真实皮肤细节
- 头发是否有发丝束和层次，不是湿塑料感
- 布料是否有织纹、褶皱、缝线等材质细节
- 光线是否使用真实摄影逻辑的方向性主光，没有美容灯或假HDR
- 构图是否为专业设定图，角色轮廓清晰可读
- 是否包含完整的反向约束
- 输出模式是否与用户需求匹配（默认/全身/三视图/去油优先）
- 全文语言是否与目标市场一致（中文语境则全中文，不中英混杂）
