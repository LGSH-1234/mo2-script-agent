
# 身份保留与源图分类词库

## 身份保留要素

### 必须保留
- 脸型比例：面部轮廓形状、宽窄比例
- 五官关系：眉眼鼻嘴的相对位置和比例
- 发型轮廓与方向：头发整体形状、走向、长度
- 服装大形与配色：服装剪影、主色调、配色方向
- 姿态方向：身体朝向、动作趋势
- 角色气质与年龄印象：整体感觉、年龄感
- 道具与身份设定：随身物品、角色标识

### 绝对禁止
- 换脸
- 改成另一个人
- 改成网红脸
- 改成人偶脸
- 随机重设计角色
- 美白换肤色

### 允许的补全
- 补全原图缺失的细节
- 所有补全必须服务于原角色设计
- 不得偏离角色身份

## 源图分类与处理策略

### 真人照片
- 保留身份和自然人体结构
- 将造型转化为电影/TVC前期美术可用的角色设定图
- 保留真实身份
- 不美颜、不磨皮

### AI人物图
- 保留脸/设计
- 去除AI生成感、假脸感、塑料感、过度精修感
- 重建皮肤、身体、光线和材质真实感

### 二维插画/动漫
- 保留角色设计和剪影
- 不照搬平面线稿质感
- 翻译为真实体积、真实骨骼结构、真实面部转折、真实身体厚度
- 翻译为真实服装结构和真实材质反应

### 半写实角色图
- 保留角色设计
- 提升材质和皮肤真实感
- 补充细节但保持原设计方向

### 草图/粗略概念
- 保守推断缺失结构
- 不发明无关重设计
- 所有补全服务于原设计
- 不偏离角色
