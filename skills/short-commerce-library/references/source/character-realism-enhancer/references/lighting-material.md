
# 光源与材质词库

## 真实光源

### 正面描述
- 方向性主光：明确光源方向，有方向感的主光
- 柔和阴影过渡：明暗交界线自然过渡，不硬切
- 适度边缘光：轮廓光贴合身体边缘，不过曝
- 环境反射：周围环境的微弱反射光
- 真实摄影逻辑：遵循物理光照规律

### 负面描述（需避免）
- 美容灯（beauty lighting）：全脸均匀发亮
- 假HDR：不自然的高动态范围
- 过曝白斑：局部过曝白色斑块
- 全脸均匀发亮：缺乏阴影层次
- 廉价电影滤镜：不真实的色调滤镜
- AI生成的油亮高光：不符合物理规律的反光

## 材质重建

### 头发
- 正面：自然发丝束、层次感、干湿关系、发丝方向、头发体积
- 负面：湿塑料感、假发感、一片式平面头发

### 布料/服装
- 正面：织纹、厚度、褶皱、缝线、边缘、磨损、面料垂坠感、服装层次
- 负面：平面贴图感、无纹理布料、塑料布料

### 硬材质
- 皮革：哑光或半光泽，有纹理
- 金属：准确物理反射，不过曝
- 玻璃：透明度和折射
- 饰品：适度反光，不抢主体

### 鞋子与道具
- 准确物理反光
- 材质可辨识
- 不过曝

## 服装叙事

服装层次应能体现：
- 角色职业
- 社会阶层
- 时代背景
- 气候环境
- 性格特征
