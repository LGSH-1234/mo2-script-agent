# 逛街 Vlog 工坊

## 1. 核心原则

一个人逛街的快乐，不在于买了什么，而在于「走、看、挑、拿、付、拎」这六个动作本身的松弛节奏感。本技能的核心机理：**用人物形象的绝对恒定 + 真实逛街动作的物理连贯性，制造「这就是真实日常」的沉浸感**，让观众觉得自己也在逛街。

### 持久引擎（因果链）

**人物照片 → 锁定五官/发型/穿搭 → 逛街动线剧本 → 逐段场景生成（每段保持同一人物）→ 段落间动作衔接 → 拼接成片 → 配乐+字幕 → 松弛感日常 Vlog**

这条链的每一环都不可断：
- 人物锁定断了 → 观众立刻出戏，「这不是同一个人」
- 动线逻辑断了 → 瞬移、场景乱跳，「AI 感」暴露
- 动作物理断了 → 悬浮拿物、穿模、怪异姿势，日常感崩塌
- 节奏断了 → 变成商品广告而非生活 Vlog

### 质量测试（可证伪）

**如果删掉人物形象锁定（让每段场景里的人脸/穿搭不同），观众会在第一段到第二段之间就察觉「不是同一个人」，则本技能不成立。** 反之，如果六段场景看完观众觉得「就是同一个人在逛街」，则技能成立。

另一条：**如果把逛街动线打乱（比如先结账再进店），观众会觉得「动作不合逻辑」，则不成立。** 动线必须遵循「进店→挑选→拿取→结账→离开」的物理因果。

## 2. 输入诊断

生成前必须明确或合理假设以下维度：

| 维度 | 必需 | 说明 |
|---|---|---|
| 人物照片 | ✅ 必需 | 单人正面或半侧面照片，五官清晰 |
| 画幅比例 | ✅ 必需 | 用户自选：9:16 竖屏 / 16:9 横屏 / 1:1 方形 |
| 目标市场与语种 | ✅ 必需 | 抖音中文 / TikTok 英文 / 多市场兼顾（默认中文为主，英文本地化） |
| 目标平台 | ⬜ 默认抖音/TikTok | 影响节奏和字幕风格 |
| 成片时长 | ⬜ 默认约30秒 | 拆分为 2-3 段 ≤15s 片段分别生成，再拼接 |
| 视觉风格 | ⬜ 默认温柔暖调 | 暖色调、柔光、日系滤镜感 |
| BGM 风格 | ⬜ 默认温柔轻音乐 | 松弛感流行轻音乐 |
| 字幕文案语言 | ⬜ 跟随目标市场 | 中文：「平凡日常」「治愈逛街」风格；英文：「simple joys」「city wander」风格 |
| 人物穿搭风格 | ⬜ 从照片提取 | 根据输入照片自动识别并锁定 |
| 合规敏感点 | ⬜ 自动检查 | 不出现品牌商标、不暗示消费主义焦虑、保持正面健康生活态度 |

**缺失处理：** 仅「人物照片」和「画幅比例」为必需追问项，其余维度有合理默认值，不追问。用户上传照片时主动询问画幅即可。

## 5. 工作流

### 阶段一：人物形象锁定

1. 读取用户上传的单人照片，识别五官特征、发型、穿搭风格、肤色、体型。
2. 生成一张人物形象参考图（全身或半身），标注关键特征用于后续所有场景的人物一致性。

**人物参考图 prompt 要点：** 正面全身/半身，自然站姿，背景纯色或简洁，光线柔和均匀，清晰展示五官/发型/服装/鞋子/配饰。这张图将作为所有后续场景的 ImageList 参考输入。

### 阶段二：逛街动线剧本生成

按以下六段动线自动生成剧本，每段定义场景、动作、运镜、氛围：

| 段号 | 场景 | 动作 | 运镜 | 时长 |
|---|---|---|---|---|
| 1 | 城市街道 / 出门 | 人物走在阳光明媚的街道上，步伐轻松 | 平稳跟随镜头，轻微手持感 | 5-6s |
| 2 | 商超入口 / 推门进入 | 人物推开玻璃门走进商超，环顾四周 | 从门外跟到门内，自然过渡 | 4-5s |
| 3 | 货架区 / 挑选商品 | 人物在货架前浏览，拿起商品端详 | 中景固定，偶尔轻微推近 | 5-6s |
| 4 | 冷柜区 / 拿取饮品 | 人物从冷柜取出一瓶饮料，看向包装 | 侧面中景，手部动作清晰 | 4-5s |
| 5 | 收银台 / 结账付款 | 人物在收银台前扫码付款，与收银员简短互动 | 中景，正面略侧 | 5-6s |
| 6 | 街头 / 手提购物袋漫步 | 人物拎着购物袋走出店铺，走在街上，微笑 | 背跟镜头转正面，收束全片 | 5-6s |

**总时长约 30 秒，拆分为 2-3 段 ≤15s 片段分别生成，再拼接。**

拆分方案：
- **方案 A（2 段）：** 段 1-3 合为第一段（约15s），段 4-6 合为第二段（约15s）
- **方案 B（3 段）：** 段 1-2（约10s），段 3-4（约10s），段 5-6（约10s）

优先使用方案 A（2 段），减少拼接缝。每段生成时，**必须**在 ImageList 中传入阶段一的人物参考图，在 prompt 中用 `@图片1` 引用并描述「图中人物以相同五官、发型、穿搭出现在以下场景中」。

### 阶段三：逐段视频生成

对每段 ≤15s 片段：

1. **组装 prompt：** 读取 `references/formats/vlog-prompt-grammar.md`，按当前段的场景/动作/运镜/氛围拼装完整 prompt。prompt 必须包含：
   - 人物描述（五官/发型/穿搭，从照片提取，逐段复用同一描述）
   - `@图片1` 引用人物参考图
   - 场景环境描述（街道/商超/货架/冷柜/收银台）
   - 人物动作描述（走路/推门/挑选/拿取/结账/拎袋）
   - 运镜描述（跟随/固定/推近/背跟转正）
   - 光线与色调（温柔暖调、柔光、自然光）
   - 氛围词（松弛、日常、治愈、生活感）
2. **生成视频：** 每段一次性生成完整 ≤15s 片段。
3. **检查人物一致性：** 生成后确认人物五官/发型/穿搭与参考图一致。如出现漂移，在 prompt 中强化人物描述后重新生成。

### 阶段四：拼接与后处理

1. **拼接：** 将 2-3 段视频按动线顺序拼接，段落间用 0.5s 交叉淡入淡出过渡。
2. **配乐：** 自动叠加温柔轻音乐 BGM，音量低于画面环境音，营造背景氛围感。
3. **字幕：** 每段叠加一句松弛感短句字幕（文案库见 `references/formats/vlog-prompt-grammar.md`），字幕位置在画面底部居中，字体温柔圆润，半透明白底或纯白描边。
4. **色调统一：** 全片统一暖调滤镜，确保段落间色调一致无跳变。

### 阶段五：交付

将最终成片展示给用户。

## 6. 输出契约

### 视频片段 prompt 模板

每段视频的 prompt 按以下结构组装：

```
[画幅] [时长]s 视频，@图片1 所示人物（[五官描述]、[发型描述]、[穿搭描述]）在[场景描述]中[动作描述]。[运镜描述]，[光线描述]，温柔暖调，松弛日常氛围。画面干净，无杂乱路人，无崩坏建筑，场景整洁高级。[氛围词]
```

### 字幕文案库（中文）

- 段1：「又是出门逛街的一天」/「阳光刚刚好」/「走走停停 就是周末的意义」
- 段2：「进来逛逛 看看有什么好东西」/「货架永远有惊喜」
- 段3：「慢慢挑 总能找到喜欢的」/「这个好看 那个也想要」
- 段4：「来一瓶 冰的刚刚好」/「今天的快乐是这瓶饮料给的」
- 段5：「扫码 完事 利索」/「买完单的满足感 谁懂」
- 段6：「拎着战利品 慢慢走回家」/「平凡日常 最治愈」/「今天也是开心的一天」

### 字幕文案库（英文）

- 段1：「Just another day out」/「Perfect sunlight, perfect mood」
- 段2：「Let's see what's inside」/「Always something new on the shelves」
- 段3：「Taking my time to choose」/「This one's cute, that one too」
- 段4：「A cold drink, just right」/「Today's happiness in a bottle」
- 段5：「Scan and done」/「That satisfying feeling after checkout」
- 段6：「Bags in hand, walking home slow」/「Simple days are the best」/「Another happy day」

### 成片规格

- 画幅：用户自选（9:16 / 16:9 / 1:1）
- 总时长：约 30 秒
- 段数：2-3 段（每段 ≤15s，一次生成完整片段）
- BGM：温柔轻音乐，音量适中不抢画面
- 字幕：每段一句，底部居中，温柔字体
- 色调：统一温柔暖调

## 7. 静默自检

出稿前内部逐条检查，不通过则修正后重出，不向用户暴露检查过程：

- [ ] 人物照片是否已识别五官/发型/穿搭并生成参考图
- [ ] 每段视频的 ImageList 是否都传入了人物参考图
- [ ] prompt 中是否用 `@图片1` 显式引用了人物参考图
- [ ] 六段动线顺序是否为「出门→进店→挑选→拿取→结账→离开」，无跳序
- [ ] 每段时长是否 ≤15s（如是则一次生成完整片段，不分多次）
- [ ] 拼接后总时长是否约 30s
- [ ] 段落间是否有交叉淡入淡出过渡
- [ ] BGM 是否为温柔轻音乐风格
- [ ] 字幕文案是否每段一句、风格统一
- [ ] 字幕语言是否与目标市场一致（中文/英文）
- [ ] 全片色调是否统一暖调无跳变
- [ ] 画面是否无杂乱路人、无崩坏建筑、无瞬移
- [ ] 人物动作是否符合物理逻辑（无悬浮、无穿模、无怪异姿势）
- [ ] 成片中是否无品牌商标暴露
- [ ] 全文语言是否与目标市场一致，无中英混杂（除非多市场版本）
