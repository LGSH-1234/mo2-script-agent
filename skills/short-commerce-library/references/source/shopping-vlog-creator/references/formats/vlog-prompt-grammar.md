# 逛街 Vlog Prompt 文法与场景用词库

> 本文件是 SKILL.md 路由表指向的核心参考。落 prompt 前必读，把相关词汇与句式写进实际产出。

## 一、人物描述模板

从照片提取后，每段视频 prompt 中复用同一人物描述：

```
@图片1 所示人物，[脸型]脸，[肤色]皮肤，[发型描述]，身穿[上装描述]，[下装描述]，[鞋子描述]，[配饰描述]
```

示例：
```
@图片1 所示人物，鹅蛋脸，白皙皮肤，黑色长直发披肩，身穿米白色针织开衫，浅蓝色牛仔裤，白色帆布鞋，背一个棕色小方包
```

**关键规则：**
- 人物描述在所有段落中逐字一致，不可增减细节
- 每段 prompt 都必须包含 `@图片1` 引用
- 人物描述放在 prompt 最前面，确保模型优先锁定人物

## 二、六段动线 Prompt 组件库

### 段1：城市街道 / 出门漫步

**场景词：** 阳光明媚的城市街道，两侧有行道树，路面干净整洁，远处有低矮建筑，蓝天白云
**动作词：** 步伐轻松地走在人行道上，偶尔看向路边橱窗，微微仰头感受阳光
**运镜词：** 平稳跟随镜头，从身后斜45度跟拍，轻微手持摇晃感，保持人物在画面中央偏左
**光线词：** 自然日光，暖色调，树荫间漏下的柔和光斑
**氛围词：** 松弛、日常、惬意、周末午后

**prompt 示例（9:16）：**
```
9:16 竖屏 6s 视频，@图片1 所示人物（鹅蛋脸，白皙皮肤，黑色长直发披肩，身穿米白色针织开衫，浅蓝色牛仔裤，白色帆布鞋，背棕色小方包）在阳光明媚的城市街道上步伐轻松地漫步，偶尔看向路边橱窗，微微仰头感受阳光。平稳跟随镜头从身后斜45度跟拍，轻微手持摇晃感，人物在画面中央偏左。自然日光暖色调，树荫间漏下柔和光斑。松弛日常惬意氛围。画面干净，无杂乱路人，街道整洁。
```

### 段2：商超入口 / 推门进入

**场景词：** 现代商超玻璃门入口，门内灯光明亮，可见货架轮廓，门口干净无杂物
**动作词：** 伸手推开玻璃门，自然走进商超，进门后环顾四周
**运镜词：** 从门外跟拍到门内，镜头跟随人物推门动作自然过渡，进门后略微拉远展示店内环境
**光线词：** 门外自然光与门内暖白灯光交汇，推门瞬间光线变化自然
**氛围词：** 好奇、轻松、走进新空间

**prompt 示例（9:16）：**
```
9:16 竖屏 5s 视频，@图片1 所示人物（鹅蛋脸，白皙皮肤，黑色长直发披肩，身穿米白色针织开衫，浅蓝色牛仔裤，白色帆布鞋，背棕色小方包）在现代商超玻璃门入口伸手推门走进店内，进门后环顾四周。镜头从门外跟拍到门内，跟随推门动作自然过渡，进门后略微拉远展示店内环境。门外自然光与门内暖白灯光交汇，推门瞬间光线变化自然。轻松好奇氛围。店内干净明亮，货架整齐。
```

### 段3：货架区 / 挑选商品

**场景词：** 整洁商超货架区，货架上商品排列整齐，灯光明亮均匀，地面干净反光
**动作词：** 在货架前慢慢走动浏览，伸手拿起一件商品端详，微微点头
**运镜词：** 中景固定镜头，人物在货架前走动，偶尔轻微推近到手部特写再拉回
**光线词：** 商超暖白顶灯，柔和均匀，货架区无阴影死角
**氛围词：** 专注、放松、慢慢挑选的乐趣

**prompt 示例（9:16）：**
```
9:16 竖屏 6s 视频，@图片1 所示人物（鹅蛋脸，白皙皮肤，黑色长直发披肩，身穿米白色针织开衫，浅蓝色牛仔裤，白色帆布鞋，背棕色小方包）在整洁商超货架前慢慢走动浏览，伸手拿起一件商品端详，微微点头。中景固定镜头，偶尔轻微推近到手部再拉回。商超暖白顶灯柔和均匀。专注放松的挑选乐趣氛围。货架上商品排列整齐，地面干净。
```

### 段4：冷柜区 / 拿取饮品

**场景词：** 商超冷柜区，冷柜玻璃门上有轻微水雾，柜内饮料排列整齐，冷柜灯光偏冷白
**动作词：** 拉开冷柜玻璃门，从中取出一瓶饮料，关上柜门，看向饮料包装
**运镜词：** 侧面中景，手部动作清晰可见，拿取后镜头略微上摇至人物面部
**光线词：** 冷柜冷白光与环境暖白灯交汇，冷柜门拉开时有轻微雾气散开
**氛围词：** 清凉、满足、小确幸

**prompt 示例（9:16）：**
```
9:16 竖屏 5s 视频，@图片1 所示人物（鹅蛋脸，白皙皮肤，黑色长直发披肩，身穿米白色针织开衫，浅蓝色牛仔裤，白色帆布鞋，背棕色小方包）在商超冷柜前拉开冷柜玻璃门，取出一瓶饮料，关上柜门，看向饮料包装。侧面中景，手部动作清晰，拿取后镜头略微上摇至面部。冷柜冷白光与环境暖白灯交汇，拉开柜门时轻微雾气散开。清凉满足小确幸氛围。冷柜内饮料排列整齐。
```

### 段5：收银台 / 结账付款

**场景词：** 商超收银台区域，收银台整洁，旁边有小型商品展示架，灯光明亮
**动作词：** 将商品放在收银台上，拿出手机扫码付款，收银员操作收银机，人物微笑点头
**运镜词：** 中景正面略侧角度，包含人物和收银台，扫码时轻微推近到手部
**光线词：** 收银区暖白灯光，明亮均匀
**氛围词：** 满足、利落、日常仪式感

**prompt 示例（9:16）：**
```
9:16 竖屏 6s 视频，@图片1 所示人物（鹅蛋脸，白皙皮肤，黑色长直发披肩，身穿米白色针织开衫，浅蓝色牛仔裤，白色帆布鞋，背棕色小方包）在商超收银台前将商品放在台上，拿出手机扫码付款，微笑点头。中景正面略侧角度，扫码时轻微推近到手部。收银区暖白灯光明亮均匀。满足利落的日常仪式感氛围。收银台整洁，旁边商品架整齐。
```

### 段6：街头 / 手提购物袋漫步

**场景词：** 城市街道，夕阳暖光，路边有行道树和店铺橱窗，街景干净温柔
**动作词：** 手提购物袋走出店铺，在街上漫步，面带微笑，偶尔低头看看购物袋
**运镜词：** 先从背后跟随，人物走在街上，然后自然转到正面，夕阳逆光勾勒人物轮廓
**光线词：** 夕阳暖金色光，逆光/侧逆光，柔和光晕，温暖收束感
**氛围词：** 满足、温暖、归途、治愈

**prompt 示例（9:16）：**
```
9:16 竖屏 6s 视频，@图片1 所示人物（鹅蛋脸，白皙皮肤，黑色长直发披肩，身穿米白色针织开衫，浅蓝色牛仔裤，白色帆布鞋，背棕色小方包）手提纸质购物袋走出店铺，在城市街道上漫步，面带微笑，偶尔低头看看购物袋。先从背后跟随拍摄，再自然转到正面。夕阳暖金色逆光勾勒人物轮廓，柔和光晕。满足温暖治愈的归途氛围。街景干净温柔，无杂乱路人。
```

## 三、画幅适配参数

| 画幅 | 运镜调整 | 构图要点 |
|---|---|---|
| 9:16 竖屏 | 跟拍为主，人物居中偏左/右，保留头顶空间 | 纵向构图，突出人物全身或大半身，街道/货架作垂直背景 |
| 16:9 横屏 | 可用更大景别，侧面跟拍，环境信息更丰富 | 横向构图，人物占画面1/3，环境氛围更突出 |
| 1:1 方形 | 中景为主，人物居中，构图紧凑 | 正方形构图，人物半身到全身，背景对称简洁 |

## 四、色调统一参数

全片统一应用以下色调描述（写入每段 prompt 结尾）：

**温柔暖调：** 暖色调，偏黄偏橙的柔和滤镜，日系胶片质感，高光柔和不过曝，暗部有暖色偏移，整体明亮通透

**色调一致性关键：** 拼接前确保每段的色调描述完全一致，不可一段偏冷一段偏暖。
