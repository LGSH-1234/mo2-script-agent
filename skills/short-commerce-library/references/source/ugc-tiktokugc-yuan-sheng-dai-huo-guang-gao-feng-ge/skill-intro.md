# TikTok UGC 原生带货广告 · 极速上手指南（skill-intro.md）

> **一句话定位**：以 TikTok/抖音爆款 UGC 原生带货为标杆，用手机原生竖屏质感、真实素人测评、3 秒钩子与去广告化信任感，把产品转化为"像朋友推荐"的可见种草欲望。**真实即信任，钩子即留存，原生即转化。**

## 🚀 30 秒上手流程

1. **锁基准资产**：先定 `@CHAR_CREATOR`（真实素人创作者 Model Card）+ `@PROD_HERO`（主推产品）+ `@SCN_HOME`（明亮居家场景）+ `@PROP_PHONE`（手机自拍支架），一次性锁定，全程 @ 引用禁止链式改。
2. **选文生图版本**：默认用 `SKILL.md §二` 的 MJ v8 专属版或常规通用版；用户点名"角色资产卡/Model Card/定妆卡"时才输出第三版本（10 格）。
3. **写剧本**：套五段式钩子带货——①3 秒钩子 → ②痛点共鸣 → ③产品真实测评 → ④效果见证 → ⑤CTA 行动号召（详见 `02-viral-script-hooks.md`）。
4. **生成视频**：套 `SKILL.md §三` 的 11 段式多参引擎，**除台词外整体描述必须用中文**，竖屏 9:16 手机原生，逐段注入产品物理动力学 + 光影五子层。
5. **配音效**：TikTok 热门 BGM 卡点 + 口语化真实口播 + 环境同期声 + 音效点缀（详见 `03-sound-design-asmr.md`）。

## 🎯 五大不可动摇配方速查

| 配方 | 数值锚点 |
|---|---|
| **手机原生平光** | 环形灯 ring light 正面 0° 4500K 柔和均匀，自然窗光补光 Key:Fill 1.5:1 通透低对比，12 点钟环形眼神光 |
| **竖屏自拍视角** | 手机前置 26mm 等效自拍，手持微晃真实感，齐胸到齐眼 1.4m，竖屏 9:16，严禁稳定器电影运镜 |
| **去广告化真实** | 真实皮肤毛孔拒绝美颜塑料感，居家生活化杂乱，口语化种草，"像朋友推荐"非硬广腔 |
| **产品物理动力学** | 纯产品镜头 AU 转译为质地流动/开合结构/光泽反射/蒸汽水珠，声明 `[本镜无角色主体]` |
| **3 秒黄金钩子** | 0-3s 痛点/悬念/利益前置直视镜头，快节奏卡点，15-30s 信息密集，TikTok 热门 BGM 卡点 |

## ⚠️ 三条红线
- **严禁电影级精致**：UGC 须手机原生真实感，绝不允许电影布光、专业模特腔、稳定器运镜、过度调色。
- **严禁美颜塑料**：真实皮肤毛孔细纹须保留，绝不允许美颜滤镜、磨皮塑料感、失真瘦脸。
- **字幕铁律**：No subtitles.（字幕绝不由模型生成，须后期硬压）；台词保留原语言口语化，口型同步精准。
