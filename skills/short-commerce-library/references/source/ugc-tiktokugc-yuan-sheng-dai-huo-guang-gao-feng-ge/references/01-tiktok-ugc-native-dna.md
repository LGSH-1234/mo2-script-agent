# TikTok UGC 原生带货基因（01-tiktok-ugc-native-dna.md）

1. **去广告化原生信任感**：核心是"看起来不像广告，像真实朋友推荐"——手机原生质感、真实素人、口语化种草、居家生活化场景，构建可信的原生信任，绝不硬广腔、绝不专业模特。
2. **手机原生竖屏质感（9:16）**：手机前置 26mm 等效自拍视角，环形灯平光 + 自然窗光，明亮通透高饱和，手持微晃真实感，轻微噪点颗粒，绝不电影级布光、绝不 2.39:1 横屏。
3. **真实素人创作者**：主角为邻家亲和的真实感创作者——非专业模特，真实皮肤毛孔细纹（拒绝美颜塑料），舒适日常装，"像你身边那个爱分享的朋友"。
4. **3 秒黄金钩子**：TikTok 信息流的生死线——0-3s 必须用痛点/悬念/利益前置抓住留存，直视镜头对话感，快节奏卡点，15-30s 信息密集。
5. **五段式钩子带货结构**：3 秒钩子 → 痛点共鸣 → 产品真实测评 → 效果见证（前后对比）→ CTA 行动号召（点购物车/评论区），转化导向。
6. **V4.1 光影角度量化铁律**：即使手机原生也强制携带五子层——光源角度（环形灯 0° 平光+窗光 70°）、色温显色（4500K CRI 92+手机原生）、视角机位（26mm 自拍+1.4m+竖屏 9:16）、微观质感证据链（真实毛孔/针织起球/产品指纹）、大气体积介质（明亮通透居家零电影雾霭）。
