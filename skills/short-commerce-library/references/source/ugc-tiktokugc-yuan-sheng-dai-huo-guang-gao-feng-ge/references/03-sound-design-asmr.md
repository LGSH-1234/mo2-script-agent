# TikTok UGC 原生带货声场工程（03-sound-design-asmr.md）

1. **TikTok 热门 BGM 卡点**：选用平台热门/上升 BGM，节奏卡点对齐画面切换（钩子/测评/见证/CTA 转场踩点），15-30s 快节奏，音乐驱动留存，绝不舒缓背景乐。
2. **口语化真实人声口播**：真实素人口语化中文（或原语言），非念稿非播音腔，"跟朋友安利"的松弛语气，语速偏快信息密集，口型同步精准。
3. **环境同期声层**：居家真实环境声（拆包装窸窣、产品开合咔哒、使用现场声），强化"真实拍摄"的原生感，避免棚拍死寂。
4. **音效点缀（Sound FX）**：关键信息点配叮（提示）、whoosh（转场）、弹出音（字幕/贴纸）、上扬音（见证惊喜），提升节奏感与信息强调。
5. **动态范围铁律**：0-3s 钩子 BGM 强起 + 口播利益前置 → 3-7s 测评口播主导 BGM 铺底 → 7-12s 见证 BGM 卡点高潮 + 惊叹音效 → 12-15s CTA 口播号召 + BGM 收尾，快节奏无冷场。
6. **台词与字幕铁律**：口播台词保留原语言口语化，口型同步精准锁定；No subtitles.（字幕绝不由模型生成，须后期硬压花字/贴纸）。
