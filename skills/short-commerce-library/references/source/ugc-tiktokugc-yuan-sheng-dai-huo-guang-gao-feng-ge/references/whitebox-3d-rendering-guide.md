# TikTok UGC 原生带货 3D 白模与轨迹锁定（whitebox-3d-rendering-guide.md）

1. **手机自拍轨迹白模锁定**：先用 3D 白模（greybox）搭建居家空间比例与手机自拍机位轨迹（手持微晃/产品特写推拉），锁定竖屏 9:16 构图与镜头路径，再进入渲染，避免构图失衡与视角漂移。
2. **产品物理动力学**：`@PROD_HERO` 的质地流动（膏体/液体）、开合结构（翻盖/旋转）、光泽反射须用刚体/流体动力学模拟，确保产品演示物理可信，卖点可视化真实。
3. **手持微晃动力学**：手机手持微晃须用噪声位移曲线（noise transform）模拟真实手抖，非机械稳定，保留呼吸感，避免"稳定器电影感"破坏 UGC 原生信任。
4. **环形灯光照渲染**：环形灯 ring light 须用环形面光源（ring area light）模拟——正面 0° 柔和均匀平光、12 点钟圆形眼神光、Key:Fill 1.5:1 低对比，确保手机原生讨喜平光。
5. **真实质感 PBR 工作流**：皮肤用真实 PBR（毛孔/细纹/雀斑，拒绝美颜磨皮），针织面料自然起球，产品真实材质指纹，居家生活化杂乱，确保去广告化微观质感证据链落地。
6. **单一源公理铁律**：@CHAR_CREATOR/@PROD_HERO/@SCN_HOME/@PROP_PHONE 的 3D 资产模型一旦锁定为基准，所有镜头状态（钩子→测评→见证→CTA）从同一基准模型渲染，严禁链式修改导致面部/产品漂移。
