# Vlog 与本地生活（适配指南）

先确认实际素材与人物授权，再决定“记录已有经历”还是“创作示意内容”。只有一张人像时，不能把生成的进店、试吃或体验写成这个人的真实经历。

## 生活过程成为叙事

| 场景 | 可用顺序 | 决定可信度的细节 |
|---|---|---|
| 探店/美食 | 到店缘由 → 环境 → 商品/菜品 → 使用/体验 → 适合谁 | 店名地址与价格有来源，食物变化对应动作 |
| 通勤 | 出发 → 路线节点 → 小阻碍 → 到达 | 天气、衣着、时间和交通衔接 |
| 家居改造 | 初始问题 → 选择与过程 → 改造后使用 | 空间结构与施工范围一致，示意效果需区分 |
| 购物/穿搭 | 需求 → 选款/试穿 → 比较 → 选择理由 | 商品款式与配件保持一致，品牌信息不编造 |
| 健身 | 目标 → 准备 → 动作过程 → 反馈 | 动作连贯，不编造体型变化、医疗或减脂结果 |
| 文旅/POV | 进入地点 → 可辨识地标 → 人物互动 → 离开 | 地理位置、地标和季节不张冠李戴 |

每镜有一个明确动作，动作引出下一镜；场景转移用门口、手部、路标或声音作过渡。不要为了“生活感”给每镜堆杂物、抖动和噪声。

人物一致性卡记录参考资产、发型、衣服、随身物品和情绪走向。光线与服饰的变化应能由时间或地点解释。POV 镜头明确视线高度、手部入画、人与镜头的距离和互动对象，防止视角突然跳到第三人称。

口播和字幕分开写；画面可以演示的内容少重复解释。商品推荐说明适合人群、具体场景与已知限制，不自动补“必点菜”“避雷”“人均消费”等事实。

## 进入当前工具链

只有用户要热点选题时进入热点检索；已有商品、门店资料或脚本可直接规划。使用 `douyin-short` 的出片链时保持 brief、实拍来源和素材映射契约，不把散文脚本硬塞成 brief。风格按实际 `list_video_styles` 的配方，来源里的新风格名称是创作参考，不是新增的工具参数。
