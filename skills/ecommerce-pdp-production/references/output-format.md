## 七段结构定义

每屏固定输出以下 **7 段**，顺序不可调整：

```
屏N（第N屏 / 功能定位）：[标题]

【一、页面骨架与信息层级】
屏高 + 视觉重心 + 信息点数量（≤3）+ 与上下屏的逻辑关系

【二、首屏卖点与转化逻辑】
本屏要解决的决策疑虑 + 卖点表述 + 支撑依据 + 期望用户反应

【三、视觉风格与品牌一致性】
主色/辅色/点缀色色号 + 材质呈现方式 + 光影方向 + 字体层级 + 留白率

【四、文案体系与信任构建】
主标题 + 副标题 + 支撑文案 + 信任状（数据/认证/评价/对比）

【五、真实性工程】
瑕疵可见项 + 使用痕迹 + 场景真实性 + 反摆拍措施 + 排除词

【六、规格与合规锁】
尺寸/分辨率/文件大小 + 绝对化用语检查 + 效果声明限定 + 品类专项合规

【七、配套素材与分发】
社媒尺寸延展 + 短视频钩子 + 搜索关键词 + 页内锚点
```

### 为什么是这七段

| 段 | 回答的问题 | 顺序理由 |
|---|---|---|
| 一 | 这一屏在页面里承担什么 | 先定位置与信息预算，后面才有边界 |
| 二 | 解决用户什么疑虑 | 内容决定视觉与文案的方向 |
| 三 | 长什么样 | 视觉服务于卖点，不能倒过来 |
| 四 | 说什么 | 文案在视觉确定后才有正确的语气 |
| 五 | 怎么让它像真的 | 方案成型后消除破绽 |
| 六 | 能不能上架 | **质量保障段**：不合规的产物等于零 |
| 七 | 怎么分发 | **交付规格段**：让产物可被直接使用 |

> **关键**：第 5、6 段是质量保障段，第 7 段是交付规格段。
> 第六段放合规是刻意的——合规不过的页面，前面做得再好都是废稿。

## 生产指令的分层架构

七段设计完成后，整合为**可直接交给设计/生成工具执行的指令**。

**必须按此分层，每层用空行分隔：**

```
1. 页面规格声明     → 尺寸、宽度、文件大小上限、平台要求
2. 全局视觉参数     → 品牌色、字体、留白率、光影方向（每屏复用）
3. 商品呈现基准     → 商品外观、角度、比例（跨屏一致）
4. 本屏构图指令     → 具体机位/构图/元素位置
5. 文案内容         → 主标题 / 副标题 / 支撑文案（逐字给定）
6. 材质与细节指令   → 需强调的质感点（如有）
7. 排除项           → 本屏特有的禁忌
```

### 各层的写作要求

| 层 | 要求 | 反例 |
|---|---|---|
| 1 规格声明 | 数值化，含上限 | ❌「按平台要求」 |
| 2 全局参数 | 每屏复制，不写"同上" | ❌「沿用上一屏视觉」 |
| 3 商品基准 | 锁定角度与比例 | ❌「商品正常呈现」 |
| 4 构图指令 | 给坐标/比例/占比 | ❌「商品放中间」 |
| 5 文案 | 逐字给出，不要"生成类似" | ❌「写一句吸引人的标题」 |
| 6 细节 | 具体到可辨识 | ❌「突出质感」 |
| 7 排除项 | 具体缺陷 | ❌「不要有问题」 |

## 强制注入规则

### 规则 1：商品外观锚定

每屏必须声明商品的关键识别特征：

```
格式：商品全程锚定：<主色>，<形态特征>，<标志性细节>，<材质>
示例：商品全程锚定：哑光墨绿，立领直筒，暗门襟五粒贝壳扣，19姆米桑蚕丝双绉
```

**要求**：
- 必须是**视觉可见**的特征，不是参数（「哑光黑」不是「黑色」）
- 跨屏必须完全一致，禁止某屏突然改变光泽度/比例
- 首次出现时锚定，后续复用

### 规则 2：品牌色纪律

- 全页品牌色 ≤3 个（主色 + 辅色 + 强调色）
- 每屏必须给出**色号**，不能写「品牌蓝」
- 强调色使用面积 ≤10%，超出会破坏高级感

### 规则 3：信息点数量硬上限

```
单屏信息点 ≤3 个
```

超出时必须拆屏，不允许"压缩进去"。

> 原因：用户在详情页的停留时间是秒级的。
> 一屏塞 5 个信息点 = 一个都记不住。

### 规则 4：留白率底线

```
留白率 ≥30%（极简风格 ≥45%）
```

留白是"呼吸"，不是"浪费"。挤满的页面读作"廉价"。

### 规则 5：信任状必须可验证

每个信任状必须能回答「凭什么」：

| 类型 | 可验证形式 | 不可接受形式 |
|---|---|---|
| 销量 | 「近30天售出 X 件」（有后台数据） | 「销量领先」 |
| 评价 | 真实截图（含头像/时间/型号） | 手写体好评、无来源 |
| 认证 | 证书编号 + 发证机构 | 「权威认证」无编号 |
| 成分 | 含量百分比 + 检测方 | 「富含XX」 |
| 对比 | 同条件同光线，标注条件 | 修图前后 |

### 规则 6：场景必须带真实杂讯

生活场景图不能是"样板间"：

- 必须有 ≥2 处生活痕迹（褶皱/水渍/其他物品/不完全对称）
- 光线必须有方向与色温，不能是均匀平光
- 禁止纯白背景 + 商品 + 装饰道具的"棚拍拼贴"

> 这一条是「反摆拍」的核心。真实感来自**不完美**。

## 完整示例

```
【页面规格】宽 750px，屏高 800px，PNG，≤3MB，无外链水印。

【全局视觉】主色 #2B3A34 深墨绿，辅色 #E8E4DC 米白，强调色 #B8863B 古铜金（使用面积 ≤8%）。
字体：标题 思源宋体 SemiBold，正文 思源黑体 Regular。
留白率 38%。光影方向：左上 45° 柔光。

【商品锚定】哑光墨绿真丝衬衫，立领，暗门襟五粒贝壳扣，19姆米双绉，垂坠不起皱。

【本屏构图】商品正面平铺，占画面 62%，微俯 5°。左侧留白承载文案，右侧 30% 为纯色块。
下方 1/3 为一道极浅接触阴影。

【文案】
主标题：一件不用熨的真丝衬衫
副标题：19姆米双绉 · 出差行李箱里拿出来就能穿
支撑：洗后 30 次测试，褶皱恢复率 92%（内部实验室，2026.03）

【材质指令】领口内侧可见贝壳扣的天然纹理差异（不统一），面料边缘有极轻微卷边（真实双绉特性）。

【排除项】无硬广红底，无"爆款""秒杀"字样，无绝对化用语，无塑料光泽，无过度磨皮的手模。
```

## 通用负向库

### 视觉类
```
无塑料光泽，无过度磨皮，无锐化白边，无死白背景（#FFFFFF），无平光无阴影，无变形拉伸，无比例失真
```

### 真实性类
```
无完美对称，无零褶皱，无样板间感，无无来源道具，无虚假使用痕迹（过于刻意的水渍）
```

### 文案类
```
无绝对化用语（最/第一/唯一/100%/永久/彻底），无无依据效果承诺，无贬低竞品，无虚假紧迫感（限时却不写具体时间）
```

### 合规类
```
无未标注的 AI 生成图（如平台要求），无未授权肖像，无未授权品牌元素，无医疗功效暗示（非医疗品类）
```

### 使用方式

**分两层写**：
1. 先写**具体缺陷**（无塑料光泽、无锐化白边……）
2. 再写**风格级反向禁令**（禁止促销感视觉、禁止模板化排版……）

## 屏间衔接规则

| 规则 | 说明 | 检查点 |
|---|---|---|
| **信息递进** | 每屏解决一个疑虑，不重复上一屏 | 相邻屏的疑虑是否不同 |
| **视觉节奏** | 全貌 → 细节 → 场景 → 全貌，避免连续三屏同景别 | 连续同类型屏 ≤2 |
| **色彩连续** | 主色贯穿，强调色点缀 | 每屏主色占比是否一致 |
| **文案语气** | 首屏定调，中屏说理，末屏促动 | 语气是否突变 |
| **行动指引** | 末屏必须有明确的下一步 | 是否有 CTA |

### 衔接的三条底线

1. **禁止断层**：相邻两屏的视觉风格不能突变（除有意的节奏转折）
2. **禁止重复**：同一卖点不在多屏重复陈述
3. **禁止跳跃**：不能从"这是什么"直接跳到"快买"，中间必须有"凭什么信"

每屏输出后立即检查：

- [ ] 七段齐全，无缺段
- [ ] 生产指令七层完整
- [ ] 强制注入规则 6 条全部执行
- [ ] 信息点 ≤3
- [ ] 留白率 ≥30%
- [ ] 品牌色 ≤3 且强调色 ≤10%
- [ ] 无绝对化用语
- [ ] 信任状可验证
- [ ] 场景有真实杂讯
- [ ] 无元数据头
- [ ] 与上一屏的疑虑不重复

**任一项不通过 → 当场重写。**
