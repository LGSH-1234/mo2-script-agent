## 平台规格锁定

| 参数 | 默认值 | 说明 |
|---|---|---|
| 主图尺寸 | **800×800**（1:1） | 天猫/京东标准；抖音可 1:1 或 3:4 |
| 主图背景 | **纯白 `#FFFFFF`** | 平台硬要求（详情页内可用暖白） |
| 主图数量 | 5 张 | 第 1 张必须为白底全貌 |
| 详情页宽度 | **750px** | 移动端标准；PC 端可 790px |
| 单图文件大小 | **≤3MB** | 超出会被压缩导致糊 |
| 详情页总高度 | ≤ 20,000px | 超出部分可能不加载 |
| 图片格式 | JPG（照片）/ PNG（含文字或透明） | — |
| 水印 | 详情页可加，主图禁止 | — |

### 强制规则

- [ ] **每屏指令中必须重复完整规格**，禁止写「同上」
- [ ] 主图与详情页内图**规格不同**，不可混用
- [ ] 不允许 Agent 自行降低分辨率以「减小文件」
- [ ] 确认门中必须让用户看到最终规格

> **为什么禁止「同上」**：单屏指令常被单独交给设计师。
> 依赖上下文的规格一旦脱离语境就会失效，是最隐蔽的错误源。

## 一致性基线

商品与品牌的**唯一性与稳定性**是质量的基础。

### 锁定项

| 要素 | 锁定内容 | 违反后果 |
|---|---|---|
| **商品外观** | 主色、形态、比例、标志性细节 | 用户认为是两个商品 |
| **品牌色** | ≤3 个色号，全页一致 | 品牌识别崩坏 |
| **字体** | ≤2 族，层级固定 | 排版杂乱 |
| **价格** | 数字与表述方式固定 | 用户怀疑真实性 |
| **规格参数** | 尺寸/重量/成分固定 | 合规风险 |

### 强制规则

- [ ] **商品外观全程锁定**：不同屏的呈现必须完全一致
- [ ] **禁止中途漂移**：不允许某屏突然改变光泽度/颜色/比例
- [ ] **品牌色 ≤3 个**：主色 + 辅色 + 强调色，超出必删
- [ ] **字体 ≤2 族**：标题族 + 正文族
- [ ] **锚定优先**：先确认商品外观基准，再开始制作，禁止在某屏重新描述

> **锚点机制**：一致性不靠「描述得足够详细」，而靠「只引用不重写」。
> 一旦某屏重新描述商品，就有了第二个版本的起点。

## 视觉基线

### 通用规则

- [ ] **首屏必须有商品全貌**（不能一上来就是局部特写）
- [ ] **信息点 ≤3/屏**（超出必须拆屏）
- [ ] **留白率 ≥30%**（极简风格 ≥45%）
- [ ] **有接触阴影**（商品不漂浮）
- [ ] **光影方向全页一致**（不能这屏左上、那屏右上）
- [ ] **禁止死白背景** `#FFFFFF`（详情页内；主图除外）
- [ ] **强调色面积 ≤10%**
- [ ] **单屏文案 ≤3 段**（主标题 + 副标题 + 支撑）

### 留白率的计算

```
留白率 = (1 - 内容像素面积 / 画面总面积) × 100%
```

内容 = 商品 + 文字 + 图形元素。阴影算留白。

| 留白率 | 观感 |
|---|---|
| <25% | 挤、廉价、像促销单页 |
| 25-30% | 偏满（仅促销场景可接受） |
| 30-45% | 舒适（标准） |
| 45-60% | 高级、克制 |
| >60% | 空、可能显廉价（除非奢侈品） |

### 信息点的定义

一个「信息点」= 一个用户需要处理的独立信息单元。

- 「19姆米真丝」= 1 个信息点
- 「免烫、透气、不起皱」= **3** 个信息点（不是 1 个）
- 同一卖点的主标题 + 副标题 + 图 = 1 个信息点

## 真实性基线

### 材质真实

- [ ] **保留天然不完美**：面料有织纹不均、金属有加工痕迹、食品有不规则断面
- [ ] **禁止完全均匀**：读作塑料/合成
- [ ] **禁止过度锐化**：会出现白边，读作 AI 增强

### 场景真实

- [ ] **必须有 ≥2 处生活痕迹**（褶皱/水渍/其他物品/不完全对称）
- [ ] **光线必须有方向与色温**（不能均匀平光）
- [ ] **禁止棚拍拼贴**（纯白背景 + 商品 + 装饰道具）
- [ ] **道具要有来源**（不能凭空出现的"氛围道具"）

### 人物真实（有模特时）

- [ ] **皮肤有毛孔与纹理**（不是磨皮塑料）
- [ ] **手部有指节与指甲的真实结构**
- [ ] **姿态有重心**（不是悬浮摆拍）
- [ ] **表情自然**（不是僵硬微笑）

### 瑕疵美学原则

**「完美」是最明显的假货信号。** 必须有意识地引入不完美：

- [ ] 至少 **3 项**真实感细节，跨越至少 **2 个类别**
- [ ] 细节必须**自然分布**，不是刻意的"脏"
- [ ] **不得破坏可读性**（不能脏到看不清商品）

| 类别 | 可选细节 |
|---|---|
| 材质 | 织纹不均、轻微起毛、加工痕迹、色差微变 |
| 使用 | 自然褶皱、轻微磨损、使用后状态 |
| 环境 | 背景杂物、光影不均、轻微失焦前景 |
| 人物 | 毛孔、指节、自然肤色不均、发丝散乱 |

## 合规基线

- [ ] 无绝对化用语（详见 `compliance.md`）
- [ ] 效果类表述有条件限定
- [ ] 对比图为同条件同光线，标注条件
- [ ] 认证/资质有编号可查
- [ ] 无医疗功效暗示（非医疗品类）
- [ ] 无未授权肖像
- [ ] 无未授权品牌元素（含竞品 logo 露出）
- [ ] AI 生成图按平台要求标注

> 完整合规规则见 `compliance.md`。**合规不通过时，即使视觉完美也不得交付。**

## 特殊品类自动检测

**Phase 1 自动执行，命中即追加对应专项合规规则。**

| 检测项 | 触发条件 | 追加规则 |
|---|---|---|
| **食品** | 商品为可食用物 | 必须标注配料表、净含量、保质期、生产许可；禁止功效宣称 |
| **美妆/护肤** | 商品为化妆品 | 必须有备案号；禁止"治疗""修复受损"等医疗用语；成分表按含量降序 |
| **母婴** | 目标客群含 0-3 岁 | 必须有 3C 认证；材质需可入口级说明；禁止"绝对安全"表述 |
| **医疗器械** | 商品宣称医疗用途 | 必须有医疗器械注册证；宣传范围严格受限于注册证 |
| **电器** | 商品含电路/电池 | 必须有 3C 认证；能效标识；禁止"永久耐用" |
| **保健品** | 商品为膳食补充剂 | 必须有蓝帽子标志；禁止疾病预防治疗宣称 |

### 检测的判定方式

```
1. 从商品描述中提取品类特征
2. 匹配检测表
3. 命中 → 在需求解析报告中声明「自动检测：[命中品类]」
4. 读取 compliance.md 对应章节，将规则并入 Phase 4
```

### 检测灵敏度

| 情况 | 处理 |
|---|---|
| 明确命中 | 强制执行专项规则 |
| 疑似命中 | 报告标注「疑似X品类，已按X品类处理」，用户可纠正 |
| 未命中 | 不追加 |

> **宁可误判也不漏判**：专项规则通常只是「更严格的约束」，
> 误加的成本（文案稍微保守）远低于漏加的损失（页面被下架/罚款）。

## 基线冲突的处理

1. **合规 > 一切**：合规要求覆盖视觉与转化诉求
2. **用户明确要求 > 默认基线**（合规除外）
3. **具体规则 > 通用规则**
4. **无法判定时**：在输出中显式标注冲突，让用户决策

**禁止**：静默忽略某条基线而不说明。
