## Quality Gate 1

**执行时机**：AGENT-1A（卖点结构）与 AGENT-1B（视觉工艺）完成后，进入精修前。

**目的**：确保「说什么」与「长什么样」彼此对齐，拦截结构性错误。

### 四维检查清单

| 检查项 | 审查内容 | 通过标准 |
|--------|----------|----------|
| **卖点 ↔ 视觉** | 视觉是否强化了主卖点，而非各说各话 | 主卖点有对应的视觉证据（面料卖点→有微距；免烫卖点→有洗后对比） |
| **规格 ↔ 平台** | 尺寸/大小/白底/水印是否合规 | 主图 800×800 白底、详情宽 750px、单图 ≤3MB、无水印 |
| **转化手法 ↔ 决策阶段** | 每屏的手法是否匹配用户此刻的心理阶段 | 首屏打认知（这是什么）、中屏打比较（凭什么信）、末屏打促动（怎么买） |
| **品牌色 ↔ 品类路由** | 色彩是否符合品类惯例（或有意的打破并有理由） | 与 `style-routing.md` 路由一致，或明确说明打破理由 |

### 输出格式

```
Quality Gate 1 审查
| 检查项 | 结果 |
|--------|------|
| 卖点 ↔ 视觉？ | [通过 / 不通过 + 原因] |
| 规格 ↔ 平台？ | [通过 / 不通过 + 原因] |
| 手法 ↔ 决策阶段？ | [通过 / 不通过 + 原因] |
| 品牌色 ↔ 品类路由？ | [通过 / 不通过 + 原因] |
→ [全部通过 → 进入 Phase 4 / 不通过项 → 回到 Phase 2 修正：[具体改什么]]
```

### 判定规则

- **全部通过** → Phase 4
- **任一不通过** → 回到 Phase 2，**必须写明改哪个具体项**
- 「卖点无视觉支撑」是最常见的阻塞项——要么补视觉，要么删卖点

## Quality Gate 2 三代自检

**执行时机**：AGENT-3 七段式整合输出完成后。

### Pass 1 转化维度

- [ ] 每屏都解决了一个具体的决策疑虑（不是泛泛介绍）
- [ ] 决策疑虑的排序符合用户真实决策顺序（先"适合我吗"再"值不值"）
- [ ] 每个卖点都有可验证的支撑依据
- [ ] 末屏有明确行动指引
- [ ] 无重复陈述同一卖点

### Pass 2 视觉维度

- [ ] 品牌色 ≤3 个，且全页色号一致
- [ ] 强调色使用面积 ≤10%
- [ ] 留白率 ≥30%（逐屏核对）
- [ ] 字体 ≤2 族，层级清晰（标题/副标题/正文/注释）
- [ ] 商品外观跨屏一致（光泽/比例/颜色）
- [ ] 连续同类型屏 ≤2（全貌/细节/场景交替）
- [ ] 无 `#FFFFFF` 死白背景
- [ ] 有接触阴影，商品不漂浮

### Pass 3 合规维度

- [ ] 无绝对化用语（最/第一/唯一/100%/永久/彻底/顶级）
- [ ] 效果类表述有条件限定（「在XX条件下」/「测试环境下」）
- [ ] 对比图为同条件同光线，且标注条件
- [ ] 认证/资质有编号可查
- [ ] 特殊品类已过专项合规（食品/美妆/母婴/医疗器械/电器）
- [ ] 无医疗功效暗示（非医疗品类）
- [ ] 无未授权肖像/品牌元素
- [ ] 无空洞词（「质感很好」「品质卓越」「匠心打造」）

## 五重会审

三代自检通过后，从**五个专业视角**会审。

### 会审格式

```
五重会审：
| 席位 | 追问 | 结果 |
|------|------|------|
| 转化设计师 | 决策疑虑是否逐屏解决？卖点是否有依据？行动指引清晰？ | [通过 / 不通过 + 说明] |
| 品牌视觉总监 | 色彩系统统一？留白达标？字体层级清晰？气质是否符合品牌定位？ | [通过 / 不通过 + 说明] |
| 视觉摄影指导 | 光影方向一致？商品呈现可信？有真实杂讯还是棚拍拼贴？ | [通过 / 不通过 + 说明] |
| 合规审核官 | 绝对化用语？效果声明有据？品类专项？对比图同条件？ | [通过 / 不通过 + 说明] |
| 目标用户代表 | 我看得懂这是什么吗？我信吗？我知道下一步做什么吗？ | [通过 / 不通过 + 说明] |
→ [全部通过 → 进入确认门 / 不通过 → 回到对应 Phase 修正]
```

### 各席位关注点

**转化设计师**
- 每屏的疑虑是否**真实**（用户真会这么问吗）
- 卖点排序是否符合决策顺序
- 是否存在「说了但没证明」的卖点
- 末屏 CTA 是否明确、单一

**品牌视觉总监**
- 色彩是否形成系统（不是东一块西一块）
- 排版是否有呼吸（留白、行距、层级）
- 气质是否与价位带匹配（高价位不能有廉价感）
- 是否落入了「电商模板」的俗套

**视觉摄影指导**
- 光影方向是否全页一致（不能这屏左上，那屏右上）
- 商品角度是否有变化但不失控
- 场景是「真实生活」还是「棚拍摆道具」
- 材质微距是否用了掠射光（正面光等于没拍）
- 是否有过度锐化/过度磨皮

**合规审核官**
- 绝对化用语逐条排查（含变体：顶级、极致、首个、独创）
- 效果声明的限定条件是否完整
- 特殊品类的资质是否齐备
- 对比是否构成不正当竞争
- 价格表述是否有依据（原价/划线价的合规性）

**目标用户代表**
- 3 秒内能否看懂「这是什么」
- 有没有让我产生「这说的就是我」的瞬间
- 我最大的疑虑被回答了吗
- 我还差什么才会下单

## 确认门

双重 Quality Gate 通过后，锁定用户确认。

### 确认项清单

```
[确认门]
方案已通过双重 Quality Gate + 五重会审。执行前，请确认：

1. 方案整体是否符合品牌意图？
   [概述：N屏 / 主卖点X / 视觉调性Y / 长度Z]

2. 请选择图片生成/拍摄方式：
   [列出候选供用户选择，系统不预设]
   - 实拍（需提供商品与场景）
   - AI 生成（需确认平台是否允许）
   - 混合（商品实拍 + 场景生成）

3. 详情页长度？
   - 短版 5 屏（快速上线）
   - 标准 9 屏（推荐）
   - 长版 15 屏（高客单价/高决策成本）

4. 是否需要社媒素材延展？
   [是 → 追加尺寸清单 / 否 → 跳过]
```

### 确认门规则

- **生成/拍摄方式必须由用户指定，系统不预设**
- 详情页长度必须由用户确认
- 用户可跳过社媒延展
- **全部确认后才可进入执行阶段**
- 执行时的产出**不加元数据头**，直接给可执行的指令或文案

> **为什么「方式不预设」是硬规则**：
> AI 生成图在部分平台需要标注，且实拍与生成的信任度差异巨大。
> 默认选择会让用户在不知情下承担合规风险。

## 门禁的三层约束体系

| 层级 | 作用 | 违反后果 | 定义位置 |
|---|---|---|---|
| **默认基线** | 全局红线（规格/一致性/合规） | 页面不可上架 | `default-baseline.md` |
| **技法卡命门** | 局部底线（如掠射光、轮廓光强度） | 技法失效、页面降级 | `cards/*.md` |
| **门禁清单** | 交付前检查 | 退回重做 | 本文件 |

**三层的关系**：基线管「什么绝对不能出现」，命门管「什么技巧不能打折」，门禁管「交付前还差什么」。

### 特别提醒

电商场景下，**合规层优先于视觉层**。
一张再美的图，如果带绝对化用语或未授权元素，就是负资产。
所以 Pass 3 不通过时，即使 Pass 1/2 全过，也必须退回。
