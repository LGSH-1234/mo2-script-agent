## 品类路由表

根据品类自动路由到对应的视觉与文案策略。
路由结果为：**视觉调性 + 主色方向 + 证明方式 + 首屏策略 + 详情页长度**。

| 品类 | 视觉调性 | 主色方向 | 证明方式 | 首屏策略 | 长度 |
|---|---|---|---|---|---|
| **服饰** | 生活感 / 模特实穿 | 中性色 + 商品自带色 | 上身效果 + 面料微距 + 洗后状态 | 全貌 + 上身穿搭 | 标准 9 屏 |
| **美妆** | 干净 / 微距质感 | 白 + 品牌色 | 质地微距 + 使用前后（同条件）+ 成分表 | 产品全貌 + 核心功效 | 长版 15 屏 |
| **食品** | 食欲 / 真实食物 | 暖色系（橙/红/棕） | 断面 + 拉丝/流心 + 原料实拍 | 成品诱惑 + 一口特写 | 标准 9 屏 |
| **家居** | 空间感 / 场景实拍 | 木色 / 灰白 | 空间比例 + 材质触感 + 使用场景 | 场景全景 + 单品 | 长版 15 屏 |
| **数码** | 科技 / 精密 | 深色 + 冷光 | 参数表 + 工艺微距 + 极限测试 | 产品全貌 + 核心参数 | 长版 15 屏 |
| **母婴** | 柔和 / 安全 | 低饱和暖色 | 材质检测 + 认证 + 细节安全设计 | 使用场景 + 核心防护 | 长版 15 屏 |
| **保健品** | 专业 / 克制 | 白 + 深绿/深蓝 | 成分 + 资质 + 用户实证 | 功效说明 + 资质 | 长版 15 屏 |
| **珠宝配饰** | 高级 / 暗调 | 深色 + 金属反光 | 微距 + 佩戴效果 + 证书 | 单品特写 + 佩戴 | 标准 9 屏 |

### 路由修正规则

| 用户指定 | 修正动作 |
|---|---|
| 「极简」 | 留白率提至 ≥45%，信息点降至 ≤2，去掉所有装饰元素 |
| 「促销感」 | 允许高饱和主色，但必须保留商品全貌，文案可加价格锚点 |
| 「高级感」 | 主色去饱和 -20%，暗调优先，字体改衬线或极细无衬线 |
| 「年轻化」 | 提高色彩明度，加入动态/社媒元素，文案口语化 |
| 指定竞品参照 | 提取其视觉 spec，做差异化而非模仿 |

**修正优先级**：用户明确偏好 > 品类惯例 > 品牌规范 > Agent 判断

## 复杂度档位

| 档位 | 屏数 | 单屏信息点 | 所需素材 | 制作路径 |
|---|---|---|---|---|
| **S（简）** | 5 屏 | 1-2 | 3-5 张商品图 | 可跳过 Phase 2 的 1A/1B 并行，直接串行 |
| **M（中）** | 9 屏 | 2-3 | 8-12 张（含场景/细节） | 标准全流程 |
| **L（繁）** | 15 屏 | 2-3 | 15-25 张（含模特/UGC/对比） | Phase 2 可能需要多轮；分 3 组制作 |

### 档位对流程的影响

- **S 档**：Gate1 简化为二维（卖点↔视觉、规格↔平台）
- **M 档**：标准
- **L 档**：建议按「首屏组 / 卖点组 / 信任组」分批推进，每批过一道 Gate2

## 需求解析报告模板

```
[需求解析报告]

>> 品类：[具体] / [路由到的品类]
>> 核心卖点：[1 个主卖点 + 2-3 个辅卖点]
>> 目标客群：[年龄/场景/价格敏感度]
>> 平台：[平台]（决定规格与合规）
>> 复杂度档位：[S/M/L]（[N]屏，[N]张素材）
>> 路由结果：→ [品类]行 → [调性] + [主色] + [证明方式] + [首屏策略]
>> 自动检测：[命中特殊品类] → [追加合规规则]
>> 品牌资产：[有/无] → [沿用/新建]
>> 素材现状：[已有清单] / [缺失清单]
>> 信息充足：[是 → 进入 Phase 2 / 否 → 需补充：[缺失项]]
```

### 判定标准

| 字段 | 判定方式 |
|---|---|
| 核心卖点 | 从用户给的候选里选 1 个「最可验证且有差异化」的作为主卖点 |
| 复杂度档位 | 按品类路由表的「长度」列 + 素材数量判定 |
| 自动检测 | 食品/美妆/母婴/医疗器械/电器 命中即追加合规 |
| 信息充足 | 缺商品图或平台 → 判「否」；缺客群可标【暂定】 |

## 决策疑虑映射速查

<!--
核心思路：详情页每一屏 = 回答用户一个决策疑虑。
这张表把「品类」映射到「用户会问什么」，再映射到「用哪种证明方式回答」。
-->

| 品类 | 用户真实疑虑 | 该用什么证明 | 该放第几屏 |
|---|---|---|---|
| 服饰 | 「会不会显胖/显矮」 | 多体型模特实穿 + 尺寸表 + 版型说明 | 第 3-4 屏 |
| 服饰 | 「洗了会不会变形」 | 洗后对比 + 面料成分 + 工艺细节 | 第 6-7 屏 |
| 美妆 | 「我这种肤质能不能用」 | 肤质分类说明 + 成分表 + 敏感肌测试 | 第 4-5 屏 |
| 美妆 | 「效果能维持多久」 | 时间轴对比（同光线同角度） | 第 6-8 屏 |
| 食品 | 「是不是真材实料」 | 原料实拍 + 断面/拉丝 + 配料表 | 第 2-3 屏 |
| 食品 | 「分量够不够」 | 称重实拍 + 参照物对比 | 第 4-5 屏 |
| 家居 | 「放我家合不合适」 | 空间尺寸标注 + 多户型场景 | 第 3-5 屏 |
| 数码 | 「参数是不是虚标」 | 实测数据 + 测试条件说明 | 第 3-4 屏 |
| 数码 | 「用久了会不会卡/坏」 | 老化测试 + 保修政策 | 第 8-10 屏 |
| 母婴 | 「材质安不安全」 | 检测报告 + 认证标识 + 材质细节 | 第 2-3 屏 |
| 保健品 | 「有没有用/有没有资质」 | 成分含量 + 批准文号 + 用户实证 | 第 2-4 屏 |
| 珠宝 | 「是不是真货」 | 证书 + 微距细节 + 克重/成色 | 第 2-3 屏 |

### 使用方式

```
1. 确定品类 → 查表得到「用户会问什么」
2. 按「该放第几屏」规划信息层级
3. 每个疑虑配一个「该用什么证明」
4. 无法提供对应证明时 → 该屏降级为「说明」而非「证明」，并在输出中标注
```

> **关键**：不能证明的卖点不要硬写。
> 标「说明」比假装「证明」安全得多——前者只是弱，后者是违规。

## 路由的失败模式

| 失败模式 | 表现 | 修正 |
|---|---|---|
| **模板套用** | 所有品类都用「白底+大字」 | 按品类路由，服饰要生活感、食品要食欲 |
| **顾虑错配** | 服装页大讲面料参数，不讲显瘦 | 查决策疑虑表，按真实疑虑排序 |
| **过度促销** | 高饱和+满屏利益点，高级感全无 | 只有低价快消品类允许 |
| **忽略平台** | 用天猫规格做抖音素材 | 平台决定尺寸与合规，必须最先确认 |
