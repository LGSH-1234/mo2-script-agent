## 通用红线：绝对化用语

### 禁用词表

**绝对化（《广告法》第九条）**：
```
最、最佳、最好、最优、最强、最大、最高、最低、最先进、最便宜
第一、首个、首创、独家、唯一、独创、领先
国家级、世界级、顶级、极致、极品、绝佳
100%、百分百、全效、彻底、永久、终身、永不
万能、无所不能、包治、根治、痊愈
```

**变体也要排查**：
```
No.1、TOP1、销量王、断货王、国民首选、全网最低、史上最强
天花板、封神、天花板级、YYDS、无敌
```

### 替代表达

| 禁用 | 可用替代 |
|---|---|
| 最好用 | 广受好评 / 用户反馈良好 |
| 全网最低价 | 本期活动价 XX 元 |
| 100% 有效 | 在 XX 条件下，实测有效率达 XX% |
| 永久耐用 | 正常使用条件下，质保 N 年 |
| 顶级材质 | 19 姆米桑蚕丝（可量化就量化） |
| 独家配方 | 自有配方（如确有专利则写专利号） |

> **核心原则**：能量化就量化，能加条件就加条件，都不行就删。

## 效果声明的限定规则

任何效果类表述必须有**限定条件**，且条件必须完整、可验证。

### 限定三要素

```
1. 条件：在什么情况下有效
2. 时间：多久见效 / 持续多久
3. 依据：谁测的 / 测了多少样本
```

### 合格示例

```
✅「连续使用 28 天，在 32 名受试者中，86% 反馈肤感改善
    （第三方检测机构 XX，报告编号 XXX，2026.03）」
```

### 不合格示例

```
❌「快速见效」            ← 无条件、无时间、无依据
❌「大多数人都会改善」    ← 「大多数」无定义
❌「经测试有效」          ← 谁测的？测什么？
```

### 功效宣称的品类边界

| 品类 | 可宣称 | 禁宣称 |
|---|---|---|
| 普通护肤品 | 保湿、清洁、舒缓、改善肤感 | 治疗、修复受损、祛斑、抗炎、去痘（医疗用语） |
| 保健品 | 补充营养素 | 预防、治疗疾病 |
| 食品 | 口感、配料、营养成分 | 任何功效 |
| 普通服饰 | 材质、版型、工艺 | 抗菌、防辐射（需检测报告支撑） |
| 家电 | 参数、能效 | 医疗健康功效 |

## 对比与比较合规

### 同条件原则

对比图必须满足：

- [ ] **同光线**：同一光源、同一色温、同一强度
- [ ] **同角度**：同一机位、同一焦段
- [ ] **同后期**：同样的调色与修图程度
- [ ] **同条件标注**：必须在图上或图旁标注「同等条件拍摄」

### 禁止的对比形式

```
❌ 修过的自己 vs 没修的竞品
❌ 精修图 vs 实拍图
❌ 不同光线下的前后对比
❌ 用他人产品图做负面示例（不正当竞争）
❌ 暗示竞品有缺陷而不点名（"普通产品"暗指）
```

### 合法的对比

```
✅ 同条件前后（自用效果）
✅ 与自身旧款对比（并说明升级点）
✅ 与行业标准对比（有标准号）
✅ 参数对比表（数据可查证）
```

## 价格表述合规

| 表述 | 合规要求 |
|---|---|
| 划线价 / 原价 | 必须是**本次促销前 7 日内最低成交价**，且有历史记录 |
| 「原价 XXX，现价 XXX」 | 原价需真实存在过 |
| 「限时」 | 必须写明**具体结束时间** |
| 「前 N 名」 | 必须公示名额与规则 |
| 「到手价」 | 需说明优惠构成（券/满减/赠品折算） |
| 「低价」 | 需有同期对比依据 |

### 禁止

```
❌ 虚构原价（从未按该价销售过）
❌ 「限时」不写时间
❌ 「仅剩 N 件」但库存充足（虚假紧迫）
❌ 用「起」字模糊最低配价格（如「9.9元起」实际主推款 199）
```

## 信任状合规

| 类型 | 可接受 | 不可接受 |
|---|---|---|
| **销量** | 「近 30 天售出 X 件」（有后台截图） | 「销量领先」「热销爆款」 |
| **评价** | 真实截图（含头像、时间、购买型号） | 手写体好评、无来源的对话截图 |
| **认证** | 证书名称 + 编号 + 发证机构 + 有效期 | 「权威认证」「国际认证」无细节 |
| **检测** | 检测机构 + 报告编号 + 检测项 | 「经检测合格」 |
| **专利** | 专利类型 + 专利号 | 「专利技术」 |
| **奖项** | 奖项名称 + 年份 + 颁发方 | 「获多项大奖」 |
| **代言** | 有授权合同的真实代言 | 暗示代言（用了明星同款图） |

### 评价截图的具体要求

```
✅ 必须有：头像（可打码）、昵称（可打码）、评价时间、购买型号/规格
✅ 必须真实：不能编造，不能只截好评不说明
✅ 建议标注：「用户评价，个体体验存在差异」
```

## 特殊品类专项

### 食品

- [ ] 配料表（按含量降序）
- [ ] 净含量
- [ ] 保质期与储存条件
- [ ] 生产许可证编号（SC 开头）
- [ ] 营养成分表
- [ ] 过敏原提示
- **禁止**：任何功效宣称、疾病预防治疗暗示

### 美妆 / 护肤

- [ ] 化妆品备案号（国产）或进口备案
- [ ] 全成分表（按含量降序）
- [ ] 生产企业 + 生产许可证
- [ ] 使用期限
- **禁止**：医疗用语（治疗/修复/祛斑/抗炎）、绝对化安全宣称

### 母婴（0-3 岁相关）

- [ ] 3C 认证编号
- [ ] 材质安全性说明（可入口级）
- [ ] 适用年龄明确标注
- [ ] 警示语（小零件/窒息风险等）
- **禁止**：「绝对安全」「零风险」

### 医疗器械

- [ ] 医疗器械注册证编号
- [ ] 生产企业许可证
- [ ] 适用范围（严格受限于注册证）
- **禁止**：超出注册证范围的任何宣称

### 电器

- [ ] 3C 认证编号
- [ ] 能效标识
- [ ] 额定电压/功率
- [ ] 保修条款
- **禁止**：「永久耐用」「零故障」

### 保健品

- [ ] 蓝帽子标志 + 批准文号（国食健字）
- [ ] 保健功能（严格受限于批准范围）
- [ ] 「本品不能代替药物」声明
- **禁止**：疾病预防、治疗功能宣称

## AI 生成内容标注

| 情况 | 要求 |
|---|---|
| 平台要求标注 | 按平台规则标注（如抖音需标注"AI生成"） |
| 商品实拍 + AI 场景 | 商品部分不需标注，场景部分需说明 |
| 全 AI 生成 | 必须标注 |
| 人物形象 AI 生成 | 必须标注，且不得暗示真实代言 |

### 标注方式

```
✅ 图片角落标注「AI 生成」
✅ 详情页底部说明「本页面部分场景图为 AI 生成，商品以实物为准」
✅ 视频开头或结尾标注
```

## 自检清单

每屏输出前逐项核对：

### 文案层
- [ ] 无绝对化用语（含变体）
- [ ] 效果声明有完整限定（条件/时间/依据）
- [ ] 无医疗用语（非医疗品类）
- [ ] 无空洞词（质感很好 / 品质卓越 / 匠心打造）
- [ ] 无虚假紧迫感

### 图片层
- [ ] 对比图同条件并标注
- [ ] 无未授权肖像
- [ ] 无竞品元素露出
- [ ] AI 生成部分已标注（如需）
- [ ] 主图白底无水印

### 信任状层
- [ ] 认证有编号可查
- [ ] 评价截图真实且完整
- [ ] 专利/奖项有具体信息
- [ ] 无不正当比较

### 品类专项
- [ ] 已执行命中的特殊品类规则
- [ ] 资质文件齐备

**任一项不通过 → 修改后重新自检，不得带病交付。**

## 合规审查的优先级

当合规与其他要求冲突时：

```
合规 > 视觉美感
合规 > 转化效果
合规 > 用户明确要求（用户要求也不能违反法规）
```

**这不是保守，是最低成本的策略**：
一次下架/处罚的损失，远大于一句文案的转化提升。
