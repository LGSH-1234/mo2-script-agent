# 技法卡索引（电商详情页）

本目录是 `ecommerce-pdp-production` 的技法卡库。

每张卡统一格式：`name` / `一句话` / `适用` / `屏位` / `强度` / `意图` / `参数表` / `已知坑` / `参考实现`。

---

## 使用规则

1. **先选卡再写指令**：规划信息层级时先从本目录选卡，读卡全文，再按参数表写入七段式输出
2. **已知坑不得降档**：标注"命门"的参数是质量底线
3. **手法去重**：同一页面内同一张卡 **≤2 次**，重复 = 廉价
4. **卡是起点不是终点**：参数表是调校过的起点，实战须以真实商品回验

## 扩展原则

1. 统一格式（frontmatter + 参数表 + 已知坑 + 参考实现）
2. 每张卡只讲一个技法
3. 必须标注"命门"参数
4. 必须关联到 `references/` 下的实际文档
5. 屏位、强度、意图三要素不可缺

### 命名规范

```
category__card-name.md
```

示例：`hero__single-product-hero.md`、`detail__macro-texture.md`

### 什么时候该建新卡

| 情况 | 该建卡 |
|---|---|
| 同一构图/文案结构在多品类反复使用 | ✅ |
| 某参数组合有明确命门 | ✅ |
| 有明确失败模式可记录 | ✅ |
| 一次性的特殊处理 | ❌ 写进项目文档 |
| 现有卡的变体 | ❌ 补充到现有卡参数表 |

## 卡片维护

| 场景 | 动作 |
|---|---|
| 实战发现新坑 | 追加到「已知坑」，标注是否命门 |
| 参数被验证更好 | 更新「参数表」典型值，注明来源 |
| 卡片被证伪 | 不删，标注「已废弃 + 原因 + 替代方案」 |
| 新增卡片 | 更新本文件的分类索引表 |
