---
name: lifestyle-context
一句话: 商品在真实生活场景中的使用状态，必须带环境杂讯，用于回答「放我家/穿我身上合不合适」
适用: 服饰（上身穿搭）、家居（空间摆放）、母婴（使用场景）、食品（餐桌场景）、数码（办公/出行场景）
屏位: 第 2-5 屏（场景建立段）
强度: 中（信息密度适中，主要作用是"代入感"而非"证明"）
意图: 这张卡解决的是「想象障碍」——用户看不出商品在自己生活里的样子。但它极易翻车成"棚拍摆道具"：纯白背景 + 商品 + 几本书 + 一盆绿植，读作"我没有生活"。真实感来自**环境的不完美**：桌角有痕、光线有方向、背景有不该出现的东西。全页 1-2 次，多了会让页面变成生活方式杂志。

## 参数表

| 参数 | 典型值 | 调节手感 |
|------|--------|---------|
| 商品占画面比例 | 25-40% | <20% = 商品沦为背景；>50% = 又变回产品图 |
| 相机高度 | 视平线略高 5-15°（俯视生活视角） | 平视 = 广告感；>30° = 样板间俯拍感 |
| 焦距 | 35-50mm（环境人像焦段） | <28mm = 空间夸张变形；>85mm = 压缩空间失去场景感 |
| 光圈 | f/2.8-f/4 | f/1.4 = 背景全糊，失去场景信息；f/8 = 全清晰，杂乱 |
| 生活痕迹数量 | **≥2 处，跨≥2类别** | 少于 2 处 = 样板间；刻意脏污 = 假 |
| 光线方向 | 必须有明确单侧方向（窗光/台灯/日光） | 均匀平光 = 棚拍感，最致命 |
| 色温 | 与全页统一，可有 200-400K 场景偏移 | 偏差 >600K = 与该页其他图脱节 |
| 背景物数量 | 2-5 件，且必须有来源逻辑 | 0 件 = 空洞；>8 件 = 杂乱抢戏 |
| 前景遮挡 | 建议有 1 处轻微前景虚化 | 无前景 = 画面扁平、像贴图 |
| 留白率 | 25-40%（场景图可低于标准） | <20% = 挤；场景图不需要 45% 留白 |

## 已知坑

- **命门：必须有单侧方向光**。均匀平光是场景图第一杀手——它让画面读作"摄影棚白墙"，而不是"有人住的地方"。必须指定光源方向（「左侧窗户自然光」而非「自然光」）。这是本卡的核心参数，不得为了"更清晰"改成补光均匀
- **命门：生活痕迹 ≥2 处且跨 ≥2 类别**。只有一处（比如只有一条褶皱）读作"刻意摆的"；两处同类（两条褶皱）读作"没熨"。必须跨类别：材质类 + 环境类，或使用类 + 人物类
- **命门：商品占比 25-40%**。低于 20% 商品沦为背景（用户找不到主角）；高于 50% 就退化成产品图，失去场景的意义
- 禁止纯白背景（这是场景图，不是产品图）
- 禁止对称构图（对称 = 摆拍）
- 禁止背景道具无来源（凭空出现的"氛围植物""装饰书"）
- 禁止背景物品超过 5 件（抢戏）
- 禁止商品摆放角度过于完美（正面居中 = 摆拍）
- 禁止同页使用超过 2 次（会变成生活方式杂志）
- 禁止用"滤镜感"代替真实光线（过度的暖调/胶片滤镜读作假）
