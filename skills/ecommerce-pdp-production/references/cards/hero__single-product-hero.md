---
name: single-product-hero
一句话: 商品居中、微仰角 8-12°、柔和轮廓光分离背景，3 秒内建立「这是什么 + 什么档次」
适用: 新品首屏、独立站首页 banner、主图第 1 张、品类页卡片图
屏位: 第 1 屏（唯一），或主图第 1 张
强度: 中高（要立住质感，但不能抢掉后续屏的信息任务）
意图: 首屏不承担说服任务，只承担「识别 + 定调」。微仰角让商品显得有分量（不是俯视的"审视感"），轮廓光让商品从背景里"浮"出来而不是贴上去。背景必须干净但不死白——纯 #FFFFFF 会让商品失去空间感，读作抠图。全页只允许一处用这张卡。
---

## 参数表

| 参数 | 典型值 | 调节手感 |
|------|--------|---------|
| 商品占画面比例 | 55-70% | 低于 50% = 商品没有主角感；高于 75% = 压迫、无呼吸空间 |
| 相机高度 | 商品中段略低 8-12°（微仰） | 平视 = 平淡目录感；仰角 >20° = 夸张广告感 |
| 背景色 | `#F7F7F5` 暖白 / `#F2F4F6` 冷白（二选一） | 纯 `#FFFFFF` = 抠图感；深色 = 高端但压商品 |
| 主光 | 45° 侧前上方，柔光箱，光比 2:1 | 光比 >4:1 = 硬调戏剧感，不适合日常品类 |
| 轮廓光 | 背面双侧 35-45°，强度为主光的 40-60% | <30% = 商品边缘融进背景；>70% = 出现"发光描边"假感 |
| 景深 | 商品全清晰，背景虚化 f/5.6-f/8 | f/2.8 = 商品后半部虚掉；f/16 = 全平 |
| 留白率 | ≥35%（上 40% / 下 25% / 左右各 17%） | <25% = 挤；>50% = 空、显廉价 |
| 投影 | 极浅接触阴影，透明度 8-15% | 无阴影 = 漂浮；>25% = 压在台面上的沉重感 |
| 分辨率 | ≥2000px 长边（源图），输出按平台 | 主图 800×800 时源图不足会糊 |

## 已知坑

- **命门：轮廓光强度 40-60%**。低于 30% 商品边缘与背景糊在一起，读作"抠图没抠干净"；高于 70% 出现发光描边，读作"廉价特效"。这是本卡的核心参数，不得降档，也不得为了"更亮"往上堆
- **命门：背景不能是纯白 `#FFFFFF`**。纯白会让商品完全失去空间参照，观众读作"贴上去的"。必须用 `#F7F7F5` 或 `#F2F4F6` 这类有极微色温的"暖白/冷白"
- **命门：微仰角 8-12°**。平视读作"目录册"；超过 20° 读作"广告夸张"，且会让商品底部变形
- 禁止商品占画面 <50%（没有主角感）或 >75%（无呼吸空间）
- 禁止无接触阴影（商品会漂浮）
- 禁止在首屏加超过 3 个文字元素（标题+副标题+一个利益点，够了）
- 禁止首屏出现价格（价格属于第 2-3 屏的决策环节，首屏放价格会打断"识别"任务）
- 禁止同页第二次使用本卡（首屏唯一）
- 禁止复杂背景（花纹/场景/渐变）——背景的任务是"承托"，不是"表演"
