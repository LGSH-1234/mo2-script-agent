---
name: before-after
一句话: 同条件同光线的前后对比，用差异本身说话，不加任何修饰性文案
适用: 美妆（肤质/色号）、清洁（去污）、修复（划痕/褪色）、护理（毛躁/柔软）、收纳（整理前后）
屏位: 第 5-8 屏（卖点证明段）
强度: 高（说服力最强，但风险也最高）
意图: 对比是"证据"，不是"效果展示"。它成立的前提是**除变量外一切相同**——同光线、同角度、同后期、同时间跨度。任何一处不同，用户都会认为"是修图修的"，反噬品牌信任。这张卡的价值在于"约束"而非"效果"。
---

## 参数表

| 参数 | 典型值 | 调节手感 |
|------|--------|---------|
| 光线一致性 | 完全相同（同光源/同位置/同强度） | 任何偏差 = 质疑修图 |
| 角度一致性 | 完全相同（同机位/同焦段/同构图） | 微差即可读作"换了角度就变好看" |
| 色温一致性 | 完全相同（±50K 内） | 偏差 >100K = 被指控调色造假 |
| 后期一致性 | 完全相同的修图程度 | 一边精修一边原图 = 明确的虚假对比 |
| 变量数量 | **严格 1 个**（只有"是否使用"不同） | 多变量 = 无法归因，说服力归零 |
| 时间跨度 | 必须明显但标注（如 28 天） | 太快 = 不可信；不标注 = 违规 |
| 画面分割 | 中线对称 50:50，或上下 50:50 | 比例失衡 = 一方获得视觉优势 |
| 标注 | **必须**标注条件与样本 | 无标注 = 违规 |
| 分辨率 | 两侧完全相同 | 一侧更清晰 = 读作"故意拍糊一边" |

## 已知坑

- **命门：光线/角度/色温/后期必须完全一致**。这四项任何一项不同，整个对比就失效——不是"效果差一点"，而是"用户认定你在骗人"。这是本卡的核心约束，不存在"差不多就行"的余地
- **命门：变量必须严格只有 1 个**。如果同时改变了产品使用 + 拍摄设备 + 时间，无法归因，说服力归零
- **命门：必须标注条件与样本**。不标注即违规（《广告法》要求效果宣称可验证）。必须写明：使用周期、样本量、拍摄条件
- 禁止修图前后对比（自己修过的 vs 没修的）
- 禁止不同设备/不同光线下拍摄
- 禁止只展示成功案例而不说明个体差异
- 禁止夸大时间跨度（如标注28天但实际拍了3天）
- 禁止把"使用后"放在更有利的视觉位置（如更亮的半边）
- 禁止不加声明直接用于医疗/功效类宣称（超出品类边界）
- 禁止用他人产品作为"使用前"示例
