---
name: macro-texture
一句话: 微距 1:1-2:1 放大单一材质特征，靠纹理本身说服人，不需要任何文案辅助
适用: 服饰面料（织纹/绒感）、美妆质地（膏体/粉质）、食品断面（拉丝/流心）、珠宝工艺（镶嵌/打磨）、数码工艺（金属拉丝/CNC 倒角）
屏位: 第 3-6 屏（卖点证明段）
强度: 中（信息密度高但视觉冲击低，需要节奏上给它"停一拍"的空间）
意图: 微距是"证据"，不是"美感"。它的作用是让用户相信"这个材质是真的"，因此必须保留材质的天然不完美——完全均匀的表面反而读作"塑料/合成"。全页建议 1-2 次，多了会让页面变成材质样本册。
---

## 参数表

| 参数 | 典型值 | 调节手感 |
|------|--------|---------|
| 放大倍率 | 1:1 - 2:1（等效） | <1:1 读作"大特写"不是微距；>3:1 失去材质语境 |
| 焦距 | 90-105mm 微距镜头 | 短焦微距畸变严重，材质会变形 |
| 光圈 | f/8-f/11 | f/2.8 = 景深过浅，只有一条线清晰；f/16 = 衍射导致细节发软 |
| 焦点位置 | 材质最具特征的 1/3 处 | 焦点在正中 = 构图呆板；在边缘 = 特征不清 |
| 光线角度 | 低角度侧光 15-30°（掠射） | 正面光 = 纹理被压平，看不出立体；>45° = 阴影过重 |
| 光比 | 3:1 - 4:1 | <2:1 = 平淡无立体；>6:1 = 暗部死黑丢细节 |
| 色温 | 与全页统一（±200K 内） | 微距最容易色偏，必须与主图对齐 |
| 表面不完美度 | 必须保留 ≥2 处天然特征 | 完全均匀 = 塑料感，读作"假的" |
| 画面占比 | 材质填满画面 85-95% | <80% = 变成"产品局部图"，失去微距属性 |

## 已知坑

- **命门：掠射光角度 15-30°**。正面打光会把纹理完全压平——这是微距失败的第一大原因。纹理靠阴影显形，没有低角度侧光就等于没拍。这是本卡的核心参数，不得为了"更亮更清楚"改成正面光
- **命门：光圈 f/8-f/11**。很多人为了"突出主体"用 f/2.8，结果只有一条线清晰，其余全糊，材质完全无法判断。微距的景深本来就浅，必须收光圈
- **命门：必须保留 ≥2 处天然不完美**。完全均匀的表面读作"合成材料"。面料要有轻微起毛/织纹不均，食品要有不规则断面，金属要有细微加工痕迹
- 禁止画面占比 <80%（会退化成"产品局部图"）
- 禁止加装饰元素（边框/文字标签/箭头）——微距画面里任何叠加物都会破坏"证据感"
- 禁止过度锐化（会出现白边，读作"AI 增强"）
- 禁止背景纯白或纯黑（会失去材质所处的语境）
- 禁止同页使用超过 2 次（会变成材质样本册，失去说服节奏）
- 禁止色温与主图不一致（微距最易色偏，必须对比校准）
