---
name: ugc-screenshot
一句话: 使用已授权真实用户评价的截图式呈现，用「别人的话」建立社会认同
适用: 所有品类的信任屏；尤其高决策成本品类（美妆/数码/母婴/家居）
屏位: 第 7-12 屏（信任构建段）
强度: 中（信息密度高但视觉弱，是"阅读型"屏）
意图: 用户评价的说服力来自**具体与不完美**——"用了三天，第二天就发现袖口有点起球，但客服直接补发了"比"太好用了五星"可信一百倍。这张卡的风险在于伪造：编造评价是明确违规，正式交付必须使用真实评价；示例仅用于内部版式占位。
---

## 参数表

| 参数 | 典型值 | 调节手感 |
|------|--------|---------|
| 评价数量 | 3-6 条/屏 | <3 = 样本太少不可信；>8 = 阅读疲劳 |
| 评价长度 | 混合（1 条长 40-80 字 + 数条短 10-30 字） | 全部等长 = 明显伪造 |
| 评分分布 | 按真实评价原样保留 | 不得为营造真实感改星级或添加抱怨 |
| 具体信息密度 | 每条至少 1 个具体细节（型号/场景/使用天数） | 全是"很好""不错" = 空话 |
| 头像/昵称 | 需有但可打码 | 全无 = 编造感 |
| 时间戳 | 保留真实时间，可按授权要求脱敏 | 不得改时间制造分散发布的假象 |
| 截图完整度 | 需包含评价入口、星级、时间、型号 | 只截文字 = 断章取义感 |
| 排版 | 模拟真实 App 界面（含边框/间距/灰色辅助文字） | 设计感过强 = 像广告不像评价 |
| 留白率 | 25-35%（阅读型屏可偏低） | 太低 = 挤 |

## 已知坑

- **命门：星级和评价内容保持原样**。不能为了营造可信感添加差评、轻微抱怨或修改评分；真实样本全为五星时如实展示并说明样本范围。
- **命门：正式交付必须使用真实评价；示例仅用于内部版式占位**。编造评价属于虚假宣传，是明确违规。如果暂无真实评价，内部方案仅标注「待补真实评价」并保留版式位置，正式素材不加入虚构证言
- **命门：每条评价必须有具体细节**。「太好用了」是空话；「洗了五次没变形，就是袖口有点松」才是评价
- 禁止所有评价等长、同语气（明显的批量生成痕迹）
- 禁止修改时间戳；真实评价集中在同一天时保留原始记录
- 禁止只截取好评片段而隐藏上下文（断章取义）
- 禁止设计感过强（用户评价就该有 App 的粗糙感）
- 禁止使用明星/网红头像暗示代言
- 禁止不加「个体体验存在差异」的说明
- 禁止把评价文字做成艺术字体/手写体（读作伪造）
