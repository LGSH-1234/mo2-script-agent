# 电商详情页全流程生产

商品种草钩子、服装/美妆/珠宝视觉、品牌套图、批量素材和增长复盘，可按需加载 `short-commerce-library`。本技能负责详情页逐屏结构；商品视频采用扩展库的视频分镜指南，不强制套用七段式详情页。

> 本文件是「多智能体编排套件」的**完整实例化示例**，用于验证方法论在非视频领域的可迁移性。
> 领域：电商详情页（PDP, Product Detail Page）

## 当前项目的执行约定（适用于下文及全部参考资料）

- 在 `/type 5` 或 `/type 电商` 使用。先读本篇，再用 `load_skill_reference(skill="ecommerce-pdp-production", name="workflow-phases")` 等按需取当前阶段资料。卡片要带目录，例如 `name="cards/detail__macro-texture"`。不用一次全读，也不要把其他文件夹当成已经提供的资源。
- 本套资料保留了源实例的工作流和示例；下文的 AGENT-1A/1B/2A/2B/2C/3 是职责分工，当前由主 Agent 按阶段执行。五重会审是五个视角的自检，不代表已部署独立专家或自动化审核器。
- 需求与逐屏规划用 `save_draft(kind="outline")`，每屏七段式方案、文案、生产指令和检查报告用 `save_draft(kind="copy")` 保存；摘要包含商品名与屏号。修订时填原资产 `parent_id`，屏号不使用短剧的 `episode` 参数。
- 商品文件先 `fs_list` / `view_image` 盘点；`fs_import` 登记资产，需公网参考图时 `host_file`。生成底图用 `gen_image` 并带同一商品参考图；生产指令中的文字交给本地排版，不放进生图 prompt。`make_poster` 叠字后 `view_image` 检查，再 `fs_export` 到当前产物目录。
- `make_poster` 仅提供固定尺寸和模板，不能保证自定义屏高、品牌字体、750px 宽或 ≤3MB。先检查实际产物，不满足的交付设计方案和待适配清单，不能把示意图称为已可上架。未生成图片时明确交付的是方案/指令。
- 单张电商首屏使用 `make_poster(template="ecommerce")`：`product_name` 标识商品，`title` / `subtitle` 建立文案层级，`features` 最多三项有依据的特点；`background_asset_id` 传完整商品净图。该模板支持 1:1、3:4、9:16，以完整适配保留商品全貌，不裁掉配件。除非用户只要求净图，不要把无字底图当成完整电商海报交付。
- 共同创作时用 `request_review` 评审已保存的方案；模板复用和自主模式按已授权范围连续推进，不重复确认已明确的方式、屏数或风格。付费生成遵循项目现有预算与权限机制。仅文案或方案任务不要求先选拍摄方式，不自动发布或上架。
- 用户明确的屏数与范围优先于品类表的推荐长度。缺商品图时可以先交拍摄清单或【AI暂定】方案；缺平台时先补平台或标为待核验，不声称通过平台审核。
- 平台尺寸、白底/水印、AI 标注、专项资质和法规词表来自用户提供的参考材料，**尚未核验现行适用性**。使用前按销售地区、平台、具体品类和日期核对来源；未核验项在报告中标「待核验」。禁词是风险筛查线索，不是法律结论，也不能把所有母婴/电器/补充剂一概视为适用同一认证。
- 测试数据、评价、证书、价格与材质只使用可追溯依据；示例数字不是商品事实，不能靠加限定词把无依据声明变成事实。真实感只保留实物已有细节，不捏造磨损、效果或用户证言；白底商品图不套用生活场景的杂物与背景规则。
- 门禁未通过时修正具体项；同一问题修正两次仍不通过，保存草稿并列明缺失证据/素材，停止重试，不伪造通过结果。

## 任务目标

- **本 Skill 用于**：从一个商品和它的卖点，产出可直接上架的详情页全套内容（结构 + 文案 + 视觉指令 + 合规校验）
- **能力包含**：需求解析与品类路由、卖点结构化与转化路径设计、视觉风格与品牌一致性、真实性工程（去摆拍感）、广告合规校验、结构化七段式输出、配套素材与分发设计
- **触发条件**：用户提到详情页、主图、卖点文案、商品图、种草素材、转化率优化、SKU 上新

## 调用时先判断模式

本流程有**三种**互不合并的模式。开始前先判断用户是否已明确选择；已选择时直接执行，不重复询问。

1. **模板复用模式**：用户点名某品类模板或参考店铺时，直接按该模板的信息层级、视觉节奏、文案结构执行，只替换商品与卖点。

2. **自主自由创作模式**：用户说"你定""直接出"时，Agent 从需求解析连续推进到合规终检，不逐阶段等待确认。

3. **共同创作模式**：默认模式。Agent 先提方案，由用户依次确认需求解析、视觉方向、卖点结构，放行后再产出完整内容。

**例外一**：用户点名具体技法卡（如"用 `macro-texture` 做主图"）→ 跳过模式介绍，直接读卡执行。

**例外二**：用户只要单个模块（如只要主图文案）→ 视为单点任务，直接结构化输出。

## 输入清晰度判断

**DETAIL 模式**（默认）：
- 缺商品实拍图、缺价格带、缺目标客群、缺平台
- 提出 2-3 个澄清问题，**绝不超过 3 个**

**BASIC 模式**：
- 用户提供了商品图 + 卖点清单 + 平台，或说"直接出"
- 立即交付，不提问

**判断信号**：
- `商品图 + 卖点列表 + "做详情页"` → **BASIC**
- `"帮我做个详情页"` → **DETAIL**

## 核心理念（始终生效）

1. **详情页不是介绍商品，是替代导购的决策辅助。**
   执行标准：每一屏必须回答用户一个具体的决策疑虑（「会不会显胖」「洗了会不会变形」），而不是罗列参数。

2. **卖点必须是「可验证的差异」，不是「形容词的堆砌」。**
   执行标准：每个卖点必须能回答「凭什么这么说」——有材质参数、有对比参照、有测试数据、有第三方背书。写不出依据的卖点删除。

3. **信任的建立是单向的：一次虚假声明毁掉整页。**
   执行标准：绝对化用语（最、第一、100%、永久）零容忍；效果类表述必须有条件限定（「在XX条件下」）；对比图必须同条件拍摄。

4. **高级感来自克制与真实细节，不来自堆满卖点。**
   执行标准：单屏不超过 3 个信息点；留白率 ≥30%；避免「满屏红黄大字」的促销视觉，除非品类明确需要（如低价快消）。

5. **视觉系统必须从商品自身生长，不能套用模板皮肤。**
   执行标准：先从商品材质/色彩/形态提取设计 spec（主色、质感关键词、光影方向），全页复用，禁止中途换风格。

6. **验收贯穿全程，首检永远不能交给用户。**
   每屏产出后必须三维自检（转化 / 视觉 / 合规），交付前做独立终检。自检不通过的不交付。

7. **确定性优先，随机是敌人。**
   商品外观、品牌色、字体、价格、规格参数全程锁定，禁止中途漂移。同一商品在不同屏的呈现必须完全一致。

8. **已知坑标注的参数不得降档。**
   技法卡中标注"命门"的参数是质量底线，不得为了省事降低标准。

## 默认基线（摘要，全文见 `references/default-baseline.md`）

- **平台规格锁定**：主图 800×800（白底）/ 详情页宽 750px / 单图 ≤3MB
- **一致性基线**：商品外观、品牌色（≤3 色）、字体（≤2 族）、价格全程锁定
- **视觉基线**：留白率 ≥30%、单屏信息点 ≤3、首屏必须有商品全貌
- **真实性基线**：瑕疵可见（不修成塑料）、场景真实（非纯白棚拍堆砌）、使用痕迹合理
- **合规基线**：绝对化用语禁用、效果声明需限定、对比图需同条件、进口/认证需可查
- **自动检测**：食品/化妆品/母婴/医疗器械/电器 五类特殊品类，命中则追加对应合规规则

## 工作流总览

```
Phase 1 需求解析 → 品类路由 → 信息充足判断
    |
Phase 2 AGENT-1A 卖点结构与转化路径 + AGENT-1B 视觉与品牌工艺
    |
Phase 3 Quality Gate 1（四维审查）
    |
Phase 4 AGENT-2A 真实性工程 → AGENT-2B 合规与规格锁 → AGENT-2C 配套素材
    |
Phase 5 AGENT-3 七段式整合输出（逐屏）
    |
Phase 6 Quality Gate 2（三代自检 + 五重会审）
    |
Phase 7 确认门（工具/长度/风格/配套）
    |
执行生产
```

## 七段式输出（每屏）

```
屏N（第N屏 / 功能定位）：[标题]

【一、页面骨架与信息层级】
屏高 + 视觉重心 + 信息点数量（≤3）+ 与上下屏的逻辑关系

【二、首屏卖点与转化逻辑】
本屏要解决的决策疑虑 + 卖点表述 + 支撑依据 + 期望用户反应

【三、视觉风格与品牌一致性】
主色/辅色/点缀色色号 + 材质呈现方式 + 光影方向 + 字体层级 + 留白率

【四、文案体系与信任构建】
主标题 + 副标题 + 支撑文案 + 信任状（数据/认证/评价/对比）

【五、真实性工程】
瑕疵可见项 + 使用痕迹 + 场景真实性 + 反摆拍措施 + 排除词

【六、规格与合规锁】
尺寸/分辨率/文件大小 + 绝对化用语检查 + 效果声明限定 + 品类专项合规

【七、配套素材与分发】
社媒尺寸延展 + 短视频钩子 + 搜索关键词 + 详情页内的锚点
```

## 质量门禁

**Quality Gate 1（四维）**
1. 卖点 ↔ 视觉：视觉是否强化了卖点，而非各说各话
2. 图片规格 ↔ 平台要求：尺寸/大小/白底/水印是否合规
3. 转化手法 ↔ 决策阶段：首屏打认知、中屏打比较、末屏打临门一脚
4. 品牌色 ↔ 品类路由：色彩是否符合品类惯例（或有意打破并有理由）

**Quality Gate 2（三代 + 五重会审）**
- Pass 1 转化：决策疑虑是否被逐屏解决 / 卖点是否有依据 / 行动指引是否清晰
- Pass 2 视觉：色彩系统统一 / 留白达标 / 字体层级清晰 / 商品呈现一致
- Pass 3 合规：无绝对化用语 / 效果声明有据 / 品类专项合规 / 无虚假对比

五重会审席位：**转化设计师 / 品牌视觉总监 / 视觉摄影指导 / 合规审核官 / 目标用户代表**

## 局部返工原则

用户指出某屏问题时：**只重做该屏并检查与相邻屏的衔接**，不重做全部。
若问题源于卖点结构（Phase 2），则需回到 Phase 2 修正后重跑 Phase 5。
