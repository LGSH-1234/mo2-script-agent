# MO² 本地网站与分镜 Agent

本地入口：http://127.0.0.1:8766/

在原 MO² 导航的 Agent 后新增「分镜」，进入文本驱动的脚本分镜 Agent。没有新增画布。网站与 Agent 共用一个本地地址，项目和版本保存在本机。

## 页面与操作

|入口|已实现|
|---|---|
|首页 `/`|按 REA 获取的中文版页面还原布局、样式、图片和演示片；创建故事进入分镜 Agent|
|我的项目 `/series`|读取本地真实项目，搜索、新建、打开指定项目|
|关于我们 `/about`|复刻公开页面；作品观看跳转原作品平台|
|Agent|保留原站 `https://ai.momostudio.top/` 链接|
|分镜 `/storyboard`|导演输入、真实 DeepSeek 写脚本、拆分镜、提示词、单镜修改提案、版本确认、视频模拟、导出|
|价格方案 `/pricing`|复刻积分展示；购买与实时席位方案转往官网，不在本地交易|

首页精选视频的加号打开灵感卡片，点击「以此灵感创作分镜」将标题、方向带入导演文本。不会凭空声称已导入原站画布模板。

### 脚本文件导入

导演输入页增加「导入脚本」，支持 PDF、DOC、DOCX、TXT、Markdown、RTF 多选。前端卡片显示文件名、格式、大小，可逐个移除，相同文件重复选择会去重。附件保留在当前页面内存中，刷新、新建或切换项目后清空；本阶段不上传、不解析、不作为模型输入。进入自己新建的脚本工作区时仍显示本次选择的附件。

## 演示路线

1. 首页 → 分镜 → 载入案例。
2. 查看脚本和 6 镜分镜表，点击镜头查看右侧详情。
3. 确认当前版本，再选择镜头，提交视频模拟。
4. 在视频结果播放样例；回到我的项目可再次打开。
5. 新建项目并输入自己的文本，可调用已配置的 DeepSeek 编写脚本和分镜。

视频任务是模拟流程，播放的是 6 秒技术样例。真实视频供应商尚未接入。原产品登录、组织、支付和私有后端没有复刻。

## 实现

公开页面由 REA 渲染后 DOM 与源 CSS 重建；移除了所有原站 JavaScript 和内联事件，公共图片、图标、字体已缓存到 `web/public/site/assets`。两个公开展示视频保留已观察到的原始地址，因此播放仍需网络。

本地页面交互位于 `web/public/site/local.js`。分镜和项目列表使用现有 React / Vite 前端；FastAPI 分发静态页面与 API。新增导航未改变 DeepSeek、SkillHub、版本确认及任务幂等机制。

`?project=ID` 精确打开已保存项目；`?new=1` 进入空白创作，不恢复上次项目；`brief` 参数只预填输入，不自动提交模型。未知项目会显示错误，不切换到其他项目。
